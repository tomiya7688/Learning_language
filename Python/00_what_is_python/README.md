# 0. Python とは？

この章では、Python がどのようなプログラミング言語なのかを簡単に確認します。

まだコードを書けなくても問題ありません。
まずは「Python は何に使われるのか」「どんな特徴があるのか」を知ることが目的です。

---

## 0-1. Python はプログラミング言語

Python は、コンピュータに処理を指示するための **プログラミング言語** のひとつです。

Python で書いたプログラムは、たとえば次のような用途に使われます。

- 日常作業の自動化
- Web アプリケーション
- データ分析
- AI・機械学習
- 画像処理
- ファイル操作
- ネットワーク処理
- 学習用の小さなプログラム

Python は特定の用途だけに限定された言語ではなく、
さまざまな分野で利用されています。

---

## 0-2. Python の特徴

Python の大きな特徴のひとつは、比較的読みやすい文法です。

たとえば、画面に文字を表示するコードは次のように書けます。

```python
print("Hello, World!")
```

何をしているのかを完全に理解する必要はまだありません。

このコードは、

> Hello, World! という文字を画面に表示する

ためのプログラムです。

Python では、同じ処理を書く場合でも、
比較的短く読みやすいコードになることが多いです。

---

## 0-3. Python はインタプリタ型の言語

Python のコードは、一般的には Python の実行環境を使って実行します。

たとえば、

```text
hello.py
```

という Python ファイルがある場合、Windows では、

```powershell
python hello.py
```

のように実行します。

macOS / Linux では、

```bash
python3 hello.py
```

のように実行することがあります。

この時点では、

> Python のコードを動かすには、Python の実行環境が必要

と理解しておけば十分です。

次の章で実際に環境を用意します。

---

## 0-4. Python 2 と Python 3

Python には過去に **Python 2** と **Python 3** という大きな系列がありました。

現在、この教材では **Python 3** を扱います。

古い Web ページや古い書籍では Python 2 のコードが残っていることがあります。

そのため、検索して見つけたコードが現在の Python でそのまま動かない場合は、
古い Python を前提にしていないか確認するとよいでしょう。

---

## 0-5. Python のファイル

Python のソースコードは、一般的に `.py` という拡張子のファイルへ保存します。

例:

```text
hello.py
calculator.py
game.py
```

この `.py` ファイルの中に Python のコードを書きます。

---

## 0-6. Python を学ぶときに大切なこと

最初からすべての用語や文法を暗記する必要はありません。

この教材では、

1. 小さなコードを見る
2. 実際に動かす
3. コードを少し変更する
4. 何が変わったか確認する
5. 必要な文法を少しずつ覚える

という流れで進めます。

エラーが出ることも学習の一部です。
エラーメッセージの読み方や、つまずきやすい点も必要に応じて説明します。
