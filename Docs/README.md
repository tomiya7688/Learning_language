# Learning_language - Repository Guide

## このリポジトリについて

このリポジトリは、プログラミング言語を初めて学ぶ人のために、
**読みやすい解説と、コメント付きの小さなサンプルコード**をまとめることを目的としています。

特に、一般的な入門資料が少ない言語や、古い資料・断片的な資料しか見つからない言語についても、
「最初に何を書けばよいか」「どう実行するか」「そのコードが何をしているか」を追いやすい形で残します。

Python や JavaScript のように教材が豊富な言語も対象にできますが、
情報の少ない言語ほど、このリポジトリで扱う価値が高いと考えています。

## 最初に扱う言語

最初の教材は **Python** とします。

まず Python で教材の構成、説明量、コメントの書き方などの感触を確認し、
その形式を今後ほかの言語へ展開していきます。

## 基本構成

リポジトリ全体に関する説明は `Docs/` に置きます。

各プログラミング言語は言語ごとのディレクトリに分け、
その中に説明用 Markdown とサンプルコードを配置します。

例:

```text
Learning_language/
├─ Docs/
│  └─ README.md
│
├─ <Language>/
│  ├─ README.md
│  ├─ ...
│  └─ sample source files
│
└─ ...
```

各言語では、学習項目を番号順に並べます。

最初の項目 `0` は、その言語を実行するための **環境構築** とします。

## 教材の基本方針

教材は、初学者が次の順序で理解できることを重視します。

1. その言語がどのような言語なのかを知る
2. 実行環境を用意する
3. 最小のプログラムを動かす
4. サンプルコードをコメントと解説を読みながら理解する
5. 変数、条件分岐、繰り返し、関数などの基本機能を学ぶ
6. その言語特有の考え方や機能を学ぶ

## サンプルコード

サンプルコードには、初学者が読んでも処理内容を追えるように
**適切なコメントを付けます**。

コメントは単にコードを日本語へ置き換えるだけではなく、
必要に応じて以下も説明します。

- 新しく登場した構文の意味
- 値や変数がどのように扱われるか
- 処理が行われる順序
- その言語特有の考え方
- 初学者がつまずきやすい点

一つのサンプルに多くの概念を詰め込みすぎず、
できるだけ小さく、実際に動かして確認できるコードを優先します。

## Markdown の方針

解説は GitHub 上でそのまま読みやすい Markdown とします。

必要に応じて以下を含めます。

- 短い説明
- コード例
- 実行方法
- 実行結果
- 補足
- 関連する次の学習項目
