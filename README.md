# Learning_language

プログラミング言語を初めて学ぶ人のための、
**読みやすい解説とコメント付きサンプルコード**をまとめるリポジトリです。

一般的な言語だけでなく、資料が少ない言語についても、
「最初に何をすればよいか」から追える教材を目指します。

## ディレクトリ

- [教材](./教材/) - 実際の学習教材
- [資料](./資料/) - このリポジトリ全体の方針・構成・運用説明

## 教材

現在は Python から作成しています。

- [Python](./教材/Python/)
- [コンピュータ基本用語・OS操作](./教材/コンピュータ基礎/)

コンピュータ基本用語は補助教材です。
各プログラミング言語の教材だけを読み進めても学習できるよう、
その言語を進めるために必要な操作や用語は可能な限り各教材内でも説明します。
