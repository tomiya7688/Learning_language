# Tk7. 割り算を用意する

Tk6で、

```text
+
-
*
```

まで使えるようになりました。

あと1つです。

> **「あと割り算あれば四則演算じゃん！」**

今回は `/` を追加します。

ただし割り算には、1つだけそのまま放置できない問題があります。

---

## Tk7-1. 0では割れない

たとえば、

```text
10 / 0
```

です。

普通の計算でも、0で割ることはできません。

Pythonでそのまま計算するとエラーになります。

> **「0で割っただけでアプリ落ちたんだけど！！！」**

電卓としては困るので、今回は落とさず画面へ理由を出します。

---

## Tk7-2. 今回使うもの

[division_calculator.py](./division_calculator.py) を開いてください。

追加するのは、

```text
/
```

ボタンです。

Pythonでは割り算を `/` で書きます。

---

## Tk7-3. 割り算も共通処理へ追加する

Tk5から使っている、

```python
def add_operator(operator):
```

を今回も使います。

割り算は、

```python
def select_division():
    add_operator("/")
```

です。

> **演算子を1個増やすだけなら、入力側の仕組みは作り直さなくていい。**

これが共通処理の強みです。

---

## Tk7-4. / ボタンを追加する

```python
division_button = tkinter.Button(
    window,
    text="/",
    command=select_division
)
division_button.pack()
```

これで、

```text
+
-
*
/
=
```

がそろいます。

---

## Tk7-5. 掛け算と割り算は同じ優先順位

普通の計算では、

```text
*
/
```

は、

```text
+
-
```

より先に計算します。

なのでTk7では、

```text
1回目
掛け算と割り算を処理

2回目
足し算と引き算を処理
```

という2段階にします。

---

## Tk7-6. 掛け算なら今まで通り

```python
if operator == "*":
    addition_and_subtraction_parts[-1] = (
        addition_and_subtraction_parts[-1] * number
    )
```

ここはTk6と同じです。

---

## Tk7-7. 割り算なら / を使う

```python
elif operator == "/":
```

で割り算を見つけます。

0でなければ、

```python
addition_and_subtraction_parts[-1] = (
    addition_and_subtraction_parts[-1] / number
)
```

と計算します。

---

## Tk7-8. 0ならその場で止める

割る数が0だったら、

```python
if number == 0:
    result_label.config(
        text="0では割れません"
    )
    calculation_parts.clear()
    return
```

とします。

これでアプリが落ちる代わりに、

```text
0では割れません
```

と表示されます。

> **エラーになる前に、自分で「これは無理」と判断して止める。**

今回はこれだけ覚えれば十分です。

---

## Tk7-9. 例外処理はまだ深追いしない

Pythonには、実際にエラーが起きたときに処理する仕組みもあります。

それが例外処理です。

でもこのTkルートでは、今必要な範囲だけにします。

今回は、

```python
if number == 0:
```

で先に見つけて止めます。

例外処理そのものは、正番号の13章で詳しく扱います。

---

## Tk7-10. 四則演算がそろった

これで、

```text
+
-
*
/
```

が全部使えます。

たとえば、

```text
10 + 8 / 2
```

なら、

```text
8 / 2 = 4
10 + 4 = 14
```

となります。

---

## Tk7-11. 試してみる

まず、

```text
10
/
2
=
```

と入力してください。

結果は、

```text
5.0
```

です。

次に、

```text
10
/
0
=
```

なら、

```text
0では割れません
```

と表示されます。

---

## Tk7-12. ここまでで覚えること

1. Pythonの割り算は `/`
2. `add_operator("/")` で既存の入力処理を再利用できる
3. 掛け算と割り算は足し算・引き算より先に計算する
4. 0で割る前に条件分岐で止められる
5. エラーで落とす代わりに、画面へ理由を表示できる
6. 四則演算が全部使えるようになった
