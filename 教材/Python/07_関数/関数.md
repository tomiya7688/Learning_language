# 7. 関数

この章では、処理に名前を付けて、必要なときに呼び出す方法を学びます。

今回作るのは、**名前を渡すと挨拶文を作ってくれる関数**です。

---

## 7-1. 今回作るもの

まず、次のような関数を作ります。

```python
def make_greeting(name):
    return f"こんにちは {name}"
```

この関数を呼び出すと、

```python
message = make_greeting("たろう")
print(message)
```

次のように表示されます。

```text
こんにちは たろう
```

別の名前を渡せば、

```python
message = make_greeting("さくら")
print(message)
```

```text
こんにちは さくら
```

のように、同じ処理を何度でも使えます。

### なぜ関数が必要なの？

たとえば、プログラムの中で「名前を受け取って挨拶文を作る処理」を3か所で使いたいとします。

関数を使わなければ、同じような処理を何度も書くことになります。

```python
name = "たろう"
message = "こんにちは " + name
print(message)

name = "さくら"
message = "こんにちは " + name
print(message)

name = "けん"
message = "こんにちは " + name
print(message)
```

これでも動きます。

しかしあとから、

> 「こんにちは」ではなく「ようこそ」に変えてください

と言われたら、同じ処理を書いた場所をすべて直さなければなりません。

1か所直し忘れると、

```text
ようこそ たろう
ようこそ さくら
こんにちは けん
```

のように、1人だけ昔の世界に取り残されます。

関数にしておけば、処理を1か所にまとめられます。

```python
def make_greeting(name):
    return f"ようこそ {name}"
```

この1か所を直すだけで、この関数を使っている場所すべてに変更を反映できます。

関数は、**よく使う処理に名前を付けて、再利用しやすくする仕組み**です。

---

## 7-2. サンプルコード

[greeting_function.py](./greeting_function.py) を開いてください。

`greeting` は「挨拶」、`function` は「関数」という意味です。

```python
# name を受け取り、挨拶文を返す関数です。
def make_greeting(name):
    return f"こんにちは {name}"


# 関数を呼び出し、返ってきた文字列を変数へ保存します。
message1 = make_greeting("たろう")
message2 = make_greeting("さくら")

# 関数が返した結果を表示します。
print(message1)
print(message2)
```

実行結果:

```text
こんにちは たろう
こんにちは さくら
```

---

## 7-3. `def` とは

関数を作るときは `def` を使います。

```python
def make_greeting(name):
    return f"こんにちは {name}"
```

`def` は、

> ここから関数を定義します

という意味です。

この例では、`make_greeting` という名前の関数を作っています。

---

## 7-4. 関数名を付ける

```python
def make_greeting(name):
```

の `make_greeting` が関数名です。

関数名には、

> その関数が何をするのか

が分かる名前を付けると読みやすくなります。

たとえば、

```text
make_greeting
calculate_total
show_message
check_score
```

のような名前です。

今回の `make_greeting` は、

- `make` = 作る
- `greeting` = 挨拶

なので、「挨拶を作る」という意味です。

---

## 7-5. 関数は作っただけでは動かない

関数は定義しただけでは実行されません。

```python
def make_greeting(name):
    return f"こんにちは {name}"
```

これだけでは、画面には何も表示されません。

関数を実行するには、**呼び出す**必要があります。

```python
make_greeting("たろう")
```

このように、

```text
関数名(...)
```

と書くことで、その関数を呼び出せます。

---

## 7-6. 引数とは

次の部分を見てください。

```python
make_greeting("たろう")
```

この `"たろう"` のように、関数へ渡す値を **引数** と呼びます。

関数側では、

```python
def make_greeting(name):
```

の `name` で受け取っています。

イメージとしては、

```text
"たろう"
   ↓
name
```

です。

そのため、

```python
make_greeting("たろう")
make_greeting("さくら")
```

のように、呼び出すたびに違う値を渡せます。

---

## 7-7. `return` とは

`return` は、関数の中で作った結果を、呼び出した場所へ返すために使います。

```python
def make_greeting(name):
    return f"こんにちは {name}"
```

たとえば、

```python
message = make_greeting("たろう")
```

とすると、

```text
make_greeting("たろう")
        ↓
"こんにちは たろう"
        ↓
message
```

という流れになります。

そのため、

```python
print(message)
```

で結果を表示できます。

---

## 7-8. `print()` と `return` は違う

ここは少し混乱しやすいところです。

`print()` は、

> 画面に表示する

ために使います。

```python
print("こんにちは")
```

一方、`return` は、

> 関数の結果を呼び出した場所へ返す

ために使います。

```python
return "こんにちは"
```

たとえば、

```python
message = make_greeting("たろう")
```

のように結果を変数へ保存したい場合は、`return` が便利です。

今は、

```text
print()  → 画面に表示する
return   → 関数の外へ結果を返す
```

と覚えておけば十分です。

---

## 7-9. 関数の中もインデントする

関数の中で実行する処理は、右へずらして書きます。

```python
def make_greeting(name):
    return f"こんにちは {name}"
```

この `return` は、`make_greeting` の中にある処理です。

次のようにインデントしないと正しくありません。

```python
def make_greeting(name):
return f"こんにちは {name}"
```

この教材では、インデントには **半角スペース4個** を基本として使います。

---

## 7-10. `:` を忘れない

`def` の行の最後には `:` を書きます。

```python
def make_greeting(name):
```

この `:` を忘れるとエラーになります。

---

## 7-11. 引数を2つ渡すこともできる

関数には、複数の値を渡すこともできます。

```python
def add_numbers(number1, number2):
    return number1 + number2
```

呼び出すときは、

```python
answer = add_numbers(10, 20)
print(answer)
```

と書けます。

実行結果:

```text
30
```

4章で書いた計算処理も、関数としてまとめることができます。

---

## 7-12. 繰り返しと関数は何が違う？

前の章では、`for` を使って同じ処理を繰り返しました。

関数も同じ処理を再利用するので、少し似ています。

大まかには、

```text
繰り返し
→ その場所で、同じ処理を何回も実行する

関数
→ 処理そのものに名前を付けて、必要な場所から呼び出す
```

という違いがあります。

もちろん、関数の中で繰り返しを使うこともできます。

この先は、今まで学んだ機能を組み合わせることが増えていきます。

---

## 7-13. GUIで関数を使う

GUIアプリでは、関数がとてもよく使われます。

たとえば、

- ボタンを押したときに計算する
- 入力内容を確認する
- 表示を書き換える
- 保存処理を実行する

といった処理を、それぞれ関数にまとめられます。

イメージとしては、

```text
ボタンを押す
    ↓
決めておいた関数を呼ぶ
    ↓
処理を実行する
```

です。

次のGUI章では、この考え方を実際の画面で使っていきます。

---

## 7-14. 自分で変えてみる

挨拶を変えてみましょう。

```python
def make_greeting(name):
    return f"ようこそ {name}さん"
```

また、別の関数を作ってみても構いません。

```python
def double(number):
    return number * 2
```

```python
answer = double(5)
print(answer)
```

実行結果:

```text
10
```

「値を渡す → 処理する → 結果を返す」という流れを確認してみてください。
