# Pg5. pygame「敵を実装する」

Pg4では、プレイヤーから弾を撃てるようになりました。

でも、まだ何も倒せません。

> **「撃てるようになった。で、何を撃つん？？？」**

今回は、画面上から敵を出して、弾が当たったら消えるようにします。

ここまで来ると、一気にシューティングゲームらしくなります。

---

## Pg5-1. 今回作るもの

[enemy_collision.py](./enemy_collision.py) を開いてください。

`enemy` は「敵」、`collision` は「衝突・当たり判定」という意味です。

今回は、

```text
敵が上から降りてくる
↓
スペースキーで撃つ
↓
弾が当たる
↓
敵が消える
```

ところまで作ります。

---

## Pg5-2. サンプルコード

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("敵を実装する")

clock = pygame.time.Clock()

player_x = 320
player_y = 400
player_speed = 5

bullets = []
bullet_speed = 8

enemies = [
    [160, 80],
    [320, 40],
    [480, 100]
]
enemy_speed = 1

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                bullets.append([player_x, player_y - 20])

    keys = pygame.key.get_pressed()

    if keys[pygame.K_LEFT]:
        player_x = player_x - player_speed

    if keys[pygame.K_RIGHT]:
        player_x = player_x + player_speed

    if keys[pygame.K_UP]:
        player_y = player_y - player_speed

    if keys[pygame.K_DOWN]:
        player_y = player_y + player_speed

    player_x = max(20, min(620, player_x))
    player_y = max(20, min(460, player_y))

    for bullet in bullets:
        bullet[1] = bullet[1] - bullet_speed

    bullets = [bullet for bullet in bullets if bullet[1] > -20]

    for enemy in enemies:
        enemy[1] = enemy[1] + enemy_speed

    bullets_to_remove = []
    enemies_to_remove = []

    for bullet in bullets:
        bullet_rect = pygame.Rect(
            bullet[0] - 3,
            bullet[1] - 10,
            6,
            20
        )

        for enemy in enemies:
            enemy_rect = pygame.Rect(
                enemy[0] - 20,
                enemy[1] - 15,
                40,
                30
            )

            if bullet_rect.colliderect(enemy_rect):
                bullets_to_remove.append(bullet)
                enemies_to_remove.append(enemy)

    for bullet in bullets_to_remove:
        if bullet in bullets:
            bullets.remove(bullet)

    for enemy in enemies_to_remove:
        if enemy in enemies:
            enemies.remove(enemy)

    screen.fill((10, 10, 30))

    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    for bullet in bullets:
        pygame.draw.rect(
            screen,
            (255, 240, 100),
            (bullet[0] - 3, bullet[1] - 10, 6, 20)
        )

    for enemy in enemies:
        pygame.draw.rect(
            screen,
            (255, 100, 100),
            (enemy[0] - 20, enemy[1] - 15, 40, 30)
        )

    pygame.display.flip()

    clock.tick(60)

pygame.quit()
```

## Pg5-3. 敵も複数いる

敵も1体とは限りません。

なので、

```python
enemies = [
    [160, 80],
    [320, 40],
    [480, 100]
]
```

と、リストにまとめます。

1体の敵は、

```python
[x, y]
```

で持っています。

Pg4の弾と同じです。

---

## Pg5-4. 敵を動かす

```python
for enemy in enemies:
    enemy[1] = enemy[1] + enemy_speed
```

で、全部の敵を下へ動かしています。

下へ動くので、yを増やします。

```text
上へ行く
→ yを減らす

下へ行く
→ yを増やす
```

でした。

---

## Pg5-5. 敵の見た目

今回は敵を四角形で描きます。

```python
pygame.draw.rect(
    screen,
    (255, 100, 100),
    (enemy[0] - 20, enemy[1] - 15, 40, 30)
)
```

プレイヤーは青い三角形、敵は赤い四角形です。

今は、

> **見分けられれば十分**

です。

最後の方で同梱素材へ差し替えます。

---

## Pg5-6. 当たり判定が必要

弾と敵を描いただけでは、重なっても何も起きません。

> **「当たってるやん！なんで素通りすんねん！！！」**

そこで、

> 弾の場所と敵の場所が重なっているか

を調べます。

これが **当たり判定** です。

---

## Pg5-7. `pygame.Rect` を使う

まず弾を四角形として考えます。

```python
bullet_rect = pygame.Rect(
    bullet[0] - 3,
    bullet[1] - 10,
    6,
    20
)
```

これは、

```text
左
上
横幅
高さ
```

を指定しています。

敵も同じように、

```python
enemy_rect = pygame.Rect(
    enemy[0] - 20,
    enemy[1] - 15,
    40,
    30
)
```

とします。

---

## Pg5-8. Rectは「当たり判定用の四角」

今描いている弾と敵も四角形なので、今回はそのまま分かりやすいです。

```text
弾
┌──┐
│  │
│  │
└──┘

敵
┌────────┐
│        │
└────────┘
```

この2つが重なったかを調べます。

---

## Pg5-9. `colliderect()`

```python
if bullet_rect.colliderect(enemy_rect):
```

は、

> 弾の四角形と敵の四角形が重なったら

という意味です。

重なったら、

```python
bullets_to_remove.append(bullet)
enemies_to_remove.append(enemy)
```

として、あとで消すリストへ入れます。

---

## Pg5-10. その場ですぐ消さない理由

`for` でリストを順番に見ている途中に、そのリストから要素を消すと、処理が分かりにくくなったり、飛ばしてしまうことがあります。

なので今回は、

```text
当たったものを記録
↓
判定が全部終わる
↓
あとからまとめて消す
```

という流れにしています。

---

## Pg5-11. 当たった弾を消す

```python
for bullet in bullets_to_remove:
    if bullet in bullets:
        bullets.remove(bullet)
```

で、当たった弾を消します。

---

## Pg5-12. 当たった敵も消す

```python
for enemy in enemies_to_remove:
    if enemy in enemies:
        enemies.remove(enemy)
```

で、当たった敵も消します。

これで、

> **弾が敵に当たると、弾も敵も消える**

ようになります。

---

## Pg5-13. ついに「撃って倒す」ができた

ここまでで、

```text
プレイヤーを動かす
↓
弾を撃つ
↓
敵が動く
↓
当たったか判定する
↓
敵を消す
```

までできました。

まだゲームとしては単純ですが、

> **撃ったら敵が倒れる**

だけで一気にシューティングらしくなります。

## Pg5-16. まだ敵は何もしてこない

今の敵は、

```text
出てくる
↓
下へ動く
↓
撃たれたら消える
```

だけです。

> **「敵、ただの的じゃん」**

その通りです。

## Pg5-17. ここまでで覚えること

1. 敵も複数いるのでリストにまとめられる
2. 敵のyを増やすと下へ動く
3. `pygame.Rect` で当たり判定用の四角形を作れる
4. `colliderect()` で2つのRectが重なったか調べられる
5. 当たった弾と敵をあとから削除できる
6. ループ中のリストをその場で直接消さず、消す対象を別にまとめる方法がある
7. 図形だけでも「撃って倒す」ゲームは作れる
