# Pg5. pygame「敵を実装する」

Pg4では、プレイヤーから弾を撃てるようになりました。

でも、まだ何も倒せません。

> **「撃てるようになった。で、何を撃つん？？？」**

今回は、画面上から敵を出して、弾が当たったら消えるようにします。

ここまで来ると、一気にシューティングゲームらしくなります。

---

## Pg5-1. 今回作るもの

[enemy_collision.py](./enemy_collision.py) を開いてください。

`enemy` は「敵」、`collision` は「衝突・当たり判定」という意味です。

今回は、

```text
敵が上から降りてくる
↓
スペースキーで撃つ
↓
弾が当たる
↓
敵が消える
```

ところまで作ります。

---

## Pg5-2. サンプルコード

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("敵を実装する")

clock = pygame.time.Clock()

player_x = 320
player_y = 400
player_speed = 5

bullets = []
bullet_speed = 8

enemies = [
    [160, 80],
    [320, 40],
    [480, 100]
]
enemy_speed = 1

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                bullets.append([player_x, player_y - 20])

    keys = pygame.key.get_pressed()

    if keys[pygame.K_LEFT]:
        player_x = player_x - player_speed

    if keys[pygame.K_RIGHT]:
        player_x = player_x + player_speed

    if keys[pygame.K_UP]:
        player_y = player_y - player_speed

    if keys[pygame.K_DOWN]:
        player_y = player_y + player_speed

    player_x = max(20, min(620, player_x))
    player_y = max(20, min(460, player_y))

    for bullet in bullets:
        bullet[1] = bullet[1] - bullet_speed

    bullets = [bullet for bullet in bullets if bullet[1] > -20]

    for enemy in enemies:
        enemy[1] = enemy[1] + enemy_speed

    bullets_to_remove = []
    enemies_to_remove = []

    for bullet in bullets:
        # Rectは画面へ描かず、弾の位置と大きさを持つ四角を用意します。
        # 幅6・高さ20の中心をbulletの座標へ合わせます。
        bullet_rect = pygame.Rect(
            bullet[0] - 3,
            bullet[1] - 10,
            6,
            20
        )

        for enemy in enemies:
            # enemyは敵1体です。幅40・高さ30の中心をenemyの座標へ合わせます。
            # pygame.Rect()は四角を用意するだけで、ここではまだ描画しません。
            enemy_rect = pygame.Rect(
                enemy[0] - 20,
                enemy[1] - 15,
                40,
                30
            )

            # 弾の四角と敵の四角が重なればTrueになり、ifの中を実行します。
            if bullet_rect.colliderect(enemy_rect):
                bullets_to_remove.append(bullet)
                enemies_to_remove.append(enemy)

    for bullet in bullets_to_remove:
        if bullet in bullets:
            bullets.remove(bullet)

    for enemy in enemies_to_remove:
        if enemy in enemies:
            enemies.remove(enemy)

    screen.fill((10, 10, 30))

    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    for bullet in bullets:
        pygame.draw.rect(
            screen,
            (255, 240, 100),
            (bullet[0] - 3, bullet[1] - 10, 6, 20)
        )

    for enemy in enemies:
        # RGB(255, 100, 100)の赤系の色で、幅40・高さ30の敵を描きます。
        # 左上を中心座標から20px左、15px上へずらして中心を合わせます。
        pygame.draw.rect(
            screen,
            (255, 100, 100),
            (enemy[0] - 20, enemy[1] - 15, 40, 30)
        )

    pygame.display.flip()

    clock.tick(60)

pygame.quit()
```

## Pg5-5. 敵の見た目

今回は敵を四角形で描きます。

```python
pygame.draw.rect(
    screen,
    (255, 100, 100),
    (enemy[0] - 20, enemy[1] - 15, 40, 30)
)
```

`pygame.draw.rect()` は、四角形を**実際に画面へ描く**関数です。

今回は左から順に、

```text
screen
→ どの画面へ描くか

(255, 100, 100)
→ 何色で描くか

(enemy[0] - 20, enemy[1] - 15, 40, 30)
→ 左端・上端・幅・高さ
```

`(255, 100, 100)` はRGBです。

```text
赤 = 255
緑 = 100
青 = 100
```

赤が強いので、敵は赤系の色になります。ここでの255・100・100は**色の強さ**です。

最後の4つは、敵の位置と大きさをピクセル単位で指定しています。

```text
enemy[0] - 20
→ 左端のx座標

enemy[1] - 15
→ 上端のy座標

40
→ 幅40ピクセル

30
→ 高さ30ピクセル
```

`enemy` は、`enemies` から1体ずつ取り出した**敵1体**です。

```text
enemy[0] → その敵の横位置
enemy[1] → その敵の縦位置
```

この教材では、この座標を敵の中心として使います。

幅40の半分は20、高さ30の半分は15なので、

```text
40 ÷ 2 = 20
30 ÷ 2 = 15
```

中心から20ピクセル左、15ピクセル上を左上にすると、**幅40・高さ30の四角形の中心をenemyの座標へ合わせられます**。

プレイヤーは青い三角形、敵は赤い四角形です。

今は、

> **見分けられれば十分**

です。

最後の方で同梱素材へ差し替えます。

## Pg5-6. 当たり判定が必要

弾と敵を描いただけでは、重なっても何も起きません。

> **「当たってるやん！なんで素通りすんねん！！！」**

そこで、

> 弾の場所と敵の場所が重なっているか

を調べます。

これが **当たり判定** です。

---

## Pg5-7. `pygame.Rect` を使う

当たり判定をする前に、弾と敵の**位置と大きさを持つ四角**を用意します。

まず弾です。

```python
bullet_rect = pygame.Rect(
    bullet[0] - 3,
    bullet[1] - 10,
    6,
    20
)
```

`pygame.Rect()` は、

```text
左端のx
上端のy
幅
高さ
```

の順で四角形の情報を受け取ります。

弾は幅6・高さ20なので、半分の3と10を引き、弾の座標を四角形の中心へ合わせています。

敵も同じです。

```python
enemy_rect = pygame.Rect(
    enemy[0] - 20,
    enemy[1] - 15,
    40,
    30
)
```

敵は幅40・高さ30なので、半分の20と15を引いて中心を合わせます。

大事なのは、**`pygame.Rect()` を実行しただけでは画面には何も描かれない**ことです。

ここでは、あとで位置の比較に使える四角形の情報を用意しています。

---

## Pg5-8. Rectは「位置と大きさを持つ四角」

`Rect` は、左上の位置・幅・高さを持つ四角形です。

今回は当たり判定に使いますが、**Rectそのものが当たり判定専用というわけではありません**。

```text
pygame.Rect(...)
→ 四角形の位置と大きさを用意する
→ 画面には描かない

pygame.draw.rect(...)
→ 四角形を実際に画面へ描く
```

今描いている弾と敵も四角形なので、同じ位置と大きさのRectを用意すると分かりやすいです。

```text
弾
┌──┐
│  │
│  │
└──┘

敵
┌────────┐
│        │
└────────┘
```

次に、この2つのRectが重なっているかを調べます。

---

## Pg5-9. `colliderect()`

```python
if bullet_rect.colliderect(enemy_rect):
```

では、

```text
bullet_rect → 弾の四角形
enemy_rect  → 敵の四角形
```

を比較しています。

`bullet_rect.colliderect(enemy_rect)` は、

- 2つのRectが重なっている → `True`
- 重なっていない → `False`

を返します。

`if` は結果が `True` のときだけ中の処理を実行するので、この1行は、

> **弾の四角形と敵の四角形が重なったら、次の処理をする**

という意味です。

重なったときは、

```python
bullets_to_remove.append(bullet)
enemies_to_remove.append(enemy)
```

として、当たった弾と敵をあとで消すリストへ入れます。

重なっていなければ `False` なので、この2行は実行されません。

---

## Pg5-10. その場ですぐ消さない理由

`for` でリストを順番に見ている途中に、そのリストから要素を消すと、処理が分かりにくくなったり、飛ばしてしまうことがあります。

なので今回は、

```text
当たったものを記録
↓
判定が全部終わる
↓
あとからまとめて消す
```

という流れにしています。

---

## Pg5-11. 当たった弾を消す

```python
for bullet in bullets_to_remove:
    if bullet in bullets:
        bullets.remove(bullet)
```

で、当たった弾を消します。

---

## Pg5-12. 当たった敵も消す

```python
for enemy in enemies_to_remove:
    if enemy in enemies:
        enemies.remove(enemy)
```

で、当たった敵も消します。

これで、

> **弾が敵に当たると、弾も敵も消える**

ようになります。

## Pg5-14. 敵の速度を変えてみる

`enemy_collision.py` の **22行目** を変更します。

VS Codeで **Ctrl + F**、macOSでは **Command + F** を押して、

```text
enemy_speed = 1
```

を検索してください。

変更前:

```python
enemy_speed = 1
```

変更後:

```python
enemy_speed = 3
```

保存して、もう一度 `enemy_collision.py` を実行します。

敵が変更前より速く下へ進めば成功です。

まだ敵は攻撃してこないので、今は単純に下へ流れてくるだけです。

## Pg5-15. 敵の位置を増やしてみる

を検索してください。
