# Pg10. pygame「ボスが強すぎる」

Pg9で、ボスにも弾を撃たせました。

実際に遊んでみたら、

> **「いやデカすぎ！！！避ける場所ないやん！！！」**

となりました。

では、

> **「なんでこんな避けられんの？？？」**

原因を探します。

---

## Pg10-1. まず数字を見る

[balanced_boss.py](./balanced_boss.py) を開いてください。

Pg9のボス弾は、

```python
boss_bullet_width = 700
boss_bullet_height = 80
```

でした。

画面は、

```python
screen = pygame.display.set_mode((640, 480))
```

です。

つまり、

```text
画面の横幅 640
ボス弾の横幅 700
```

です。

> **「弾の方が画面よりデカいやん！！！」**

そりゃ左右に逃げても避けられません。

---

## Pg10-2. 原因が分かった

今回のボスが強すぎた主原因は、

> **ボス弾の横幅がデカすぎる**

ことでした。

弾速は、

```python
boss_bullet_speed = 4
```

です。

異常な超高速弾ではありません。

まずは、一番おかしいところから直します。

---

## Pg10-3. 弾サイズを小さくする

Pg10では、

```python
boss_bullet_width = 48
boss_bullet_height = 48
```

にします。

これで、

- 弾が見える
- 左右に避ける場所がある
- 当たり判定も分かりやすい

状態になります。

---

## Pg10-4. 発射間隔も確認する

Pg9では、

```python
boss_fire_interval = 60
```

でした。

60FPSなら約1秒に1発です。

Pg10では、

```python
boss_fire_interval = 120
```

として、約2秒に1発へ戻します。

ボスHPはPg9と同じ、

```python
boss_hp = 50
```

のままです。

---

## Pg10-5. 一気に全部変えない

ゲームバランス調整では、

```text
遊ぶ
↓
問題を見つける
↓
原因を探す
↓
一番怪しい数字を変える
↓
また遊ぶ
```

を繰り返します。

> **「難しいから全部変えよ！」**

とすると、どの変更が効いたのか分からなくなります。

---

## Pg10-6. 見た目と当たり判定を揃える

```python
boss_bullet_rect = pygame.Rect(
    boss_bullet[0] - boss_bullet_width // 2,
    boss_bullet[1],
    boss_bullet_width,
    boss_bullet_height
)
```

描画でも当たり判定でも、

- `boss_bullet_width`
- `boss_bullet_height`

を使っています。

なのでサイズを変えれば、見た目と当たり判定が一緒に変わります。

> **「見た目避けたのに当たったんだけど？？？」**

という事故を起こしにくくできます。

---

## Pg10-7. 正解の数字は1つではない

今回は、

```python
boss_bullet_width = 48
boss_bullet_height = 48
```

にしています。

でも、

```python
40
```

でも、

```python
60
```

でも、遊べるかもしれません。

大事なのは、

> **正解の数字を暗記することではありません。**

実際に遊んで、

> **これなら避けられる**

というところを探します。

---

## Pg10-8. まだ強すぎるなら次を見る

弾サイズを直してもまだ強すぎるなら、

```python
boss_bullet_speed
```

や、

```python
boss_fire_interval
```

を見ます。

たとえば、

```python
boss_bullet_speed = 3
```

なら少し遅くなります。

```python
boss_fire_interval = 150
```

なら攻撃間隔が長くなります。

---

## Pg10-9. 弱くしすぎてもつまらない

逆に、

```python
boss_bullet_speed = 1
boss_fire_interval = 600
```

では、ほとんど攻撃してこなくなります。

> **「避けられるようにしろとは言ったけど、寝てても勝てるようにしろとは言ってない！」**

難しすぎず、簡単すぎず。

その間を探すのがゲームバランス調整です。

---

## Pg10-10. Pg9と比べる

### Pg9

```python
boss_hp = 50
boss_bullet_width = 700
boss_bullet_height = 80
boss_bullet_speed = 4
boss_fire_interval = 60
```

### Pg10

```python
boss_hp = 50
boss_bullet_width = 48
boss_bullet_height = 48
boss_bullet_speed = 4
boss_fire_interval = 120
```

ボスHPも弾速も同じです。

主に、

- 弾サイズ
- 発射間隔

を調整しています。

---

## Pg10-11. CIでも確認する

Pg9は、教材上わざと画面を覆う巨大弾になっています。

Pg10では通常のバランス基準へ戻します。

つまりCIでも、

```text
Pg9
→ 問題のある状態を残す

Pg10
→ 調整後の状態を確認する
```

という役割を分けています。

---

## Pg10-12. 調整もゲーム開発

ゲームでは、

```text
機能を作る
↓
遊ぶ
↓
問題に気付く
↓
原因を探す
↓
調整する
↓
また遊ぶ
```

までが開発です。

> **コードが動いた。はい完成！**

ではありません。

---

## Pg10-13. ここまでで覚えること

1. 遊んでから問題の原因を探す
2. 画面サイズと弾サイズを比較できる
3. 一番おかしいパラメータから直す
4. 見た目と当たり判定は同じサイズ変数を使う
5. 正解の数値は1つではない
6. 弾速や発射間隔もゲームバランスに関係する
7. 調整もゲーム開発の一部
