# 0. Python とは？

この章では、Python がどのようなプログラミング言語なのかを確認します。

ただし、最初に一番大切なのは、**Python を学ぶと何が作れるようになるのか**を知ることです。

> **文法だけ延々覚えて、「で、これ何に使うん？」になったら意味ないやろ！**

この教材は、文法暗記大会をするためのものではありません。

目的のないまま文法だけを覚えるより、
「これを作るために、この文法が必要なんだ」と分かっている方が学習は進みやすくなります。

---

## 0-1. この教材を一通り終えると何ができる？

この教材を一通り終えるころには、Python の基本文法を使って、
自分で小さなプログラムを組み立てられることを目標にします。

たとえば、次のようなものです。

- 数字を入力して計算する簡単な電卓
- 条件によって結果が変わる診断プログラム
- 複数のデータを集計するプログラム
- テキストファイルを読み書きするツール
- フォルダ内のファイル名をまとめて変更するツール
- CSV を読み込んで集計する小さな自動化ツール
- Web API からデータを取得するプログラム
- 簡単なゲームやクイズ
- 自分用の作業自動化スクリプト

ここで重要なのは、これらを丸暗記して作ることではありません。

> やりたい処理を小さく分けて、必要な文法を組み合わせて作る

ことができるようになるのが目標です。

この教材では、変数、条件分岐、繰り返し、関数、ファイル操作などを学びます。
それぞれは単独で覚えるためのものではなく、**何かを作るための部品**です。

たとえば「フォルダ内のファイルをまとめて処理したい」という目的があれば、

1. ファイル一覧を取得する
2. 繰り返しで1つずつ処理する
3. 条件分岐で対象を選ぶ
4. 必要なら名前を書き換える

というように、学んだ要素を組み合わせます。

この教材は、文法を覚えること自体をゴールにはしません。
**自分が作りたいものを作るために、必要な知識を身につけること**をゴールにします。


---

## 0-2. Python はプログラミング言語

Python は、コンピュータに処理を指示するための **プログラミング言語** のひとつです。

Python で書いたプログラムは、たとえば次のような用途に使われます。

- 日常作業の自動化
- Web アプリケーション
- データ分析
- AI・機械学習
- 画像処理
- ファイル操作
- ネットワーク処理
- 学習用の小さなプログラム

Python は特定の用途だけに限定された言語ではなく、
さまざまな分野で利用されています。

---

## 0-3. Python の特徴

Python の大きな特徴のひとつは、比較的読みやすい文法です。

たとえば、画面に文字を表示するコードは次のように書けます。

```python
print("Hello, World!")
```

何をしているのかを完全に理解する必要はまだありません。

このコードは、

> Hello, World! という文字を画面に表示する

ためのプログラムです。

Python では、同じ処理を書く場合でも、
比較的短く読みやすいコードになることが多いです。

---

## 0-4. Python はインタプリタ型の言語

Python のコードは、一般的には Python の実行環境を使って実行します。

たとえば、

```text
hello.py
```

という Python ファイルがある場合、Windows では、

```powershell
python hello.py
```

のように実行します。

macOS / Linux では、

```bash
python3 hello.py
```

のように実行することがあります。

この時点では、

> Python のコードを動かすには、Python の実行環境が必要

と理解しておけば十分です。

次の章で実際に環境を用意します。

---

## 0-5. Python 2 と Python 3

Python には過去に **Python 2** と **Python 3** という大きな系列がありました。

現在、この教材では **Python 3** を扱います。

古い Web ページや古い書籍では Python 2 のコードが残っていることがあります。

そのため、検索して見つけたコードが現在の Python でそのまま動かない場合は、
古い Python を前提にしていないか確認するとよいでしょう。

---

## 0-6. Python のファイル

Python のソースコードは、一般的に `.py` という拡張子のファイルへ保存します。

例:

```text
hello.py
calculator.py
game.py
```

この `.py` ファイルの中に Python のコードを書きます。

---

## 0-7. Python を学ぶときに大切なこと

最初からすべての用語や文法を暗記する必要はありません。

この教材では、

1. 小さなコードを見る
2. 実際に動かす
3. コードを少し変更する
4. 何が変わったか確認する
5. 必要な文法を少しずつ覚える

という流れで進めます。

エラーが出ることも学習の一部です。
エラーメッセージの読み方や、つまずきやすい点も必要に応じて説明します。
