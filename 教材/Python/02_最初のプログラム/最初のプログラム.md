# 2. 最初のプログラム

この章では、Python で最初のプログラムを作成して実行します。題材として、まずはとにかく1行表示してみます。

最初の目標は、画面に次の文字を表示することです。

> **とりまなんか表示しとけ！おはよう世界！**

```text
Hello World!
```

---

## 2-1. なぜ最初に文字を表示するの？

最初から難しいことをやる必要はありません。

まずは、

```python
print("Hello World!")
```

だけ動かします。

ここで確認したいのは、文章のセンスではありません。

- ファイルを保存できたか
- Pythonが動くか
- ファイルを実行できるか
- 結果が画面に出るか

です。

> **いきなり大作を書いて、動かん原因が環境かコードか分からんようになったら地獄や！**

だから最初は、わざと限界まで小さいプログラムで、

> 書く → 実行する → 結果を見る

という流れだけ確認します。

---

## 2-2. 最初のコードを書く

では、画面へ「Hello World!」と表示する1行を書いてみましょう。

```python
# print関数でHello World!という文字を画面に表示する
print("Hello World!")
```

このコードを用意する方法は2つあります。

### 方法A: 自分で書く

1. VS Code を起動する
2. **ファイル（File）→ 新しいテキストファイル（New Text File）** を選ぶ
3. 表示された白紙の欄に、上の Python コードを書く
4. **ファイル（File）→ 名前を付けて保存（Save As）** を選ぶ
5. 自分が分かる保存先を選ぶ。たとえば「ドキュメント」の中に「Python学習」というフォルダを作り、そのフォルダを選ぶ
6. ファイル名を `hello_world.py` にする
7. **保存（Save）** を押す

`hello` は「こんにちは」、`world` は「世界」という意味です。`.py` は、Python のコードを保存するファイルに付ける拡張子です。

保存したフォルダの場所を覚えておいてください。次の実行手順で使います。

保存後にコードを書き換えたときは、Windows / Linux では **Ctrl + S**、macOS では **Command + S** で再び保存します。

### 方法B: サンプルファイルを使う

この教材には、同じ内容のサンプルファイルも用意しています。

- [hello_world.py](./hello_world.py)

リンクを開き、ファイルを自分のPCへ保存して使っても構いません。

保存したファイル名が、

```text
hello_world.py
```

になっていることを確認してください。

Windowsでは設定によって拡張子が見えず、

```text
hello_world.py.txt
```

になってしまうことがあります。

その場合は `.py` ファイルとして保存し直してください。

---

## 2-3. 保存したファイルを実行する

自分で書いた場合でも、サンプルファイルを保存した場合でも、
ここからの手順は同じです。

### 1. `hello_world.py` を保存したフォルダを確認する

まず、

```text
hello_world.py
```

がどのフォルダにあるか確認します。

たとえば Windows で、

```text
C:\Users\sample\Documents\Python学習
```

というフォルダに保存したとします。

この **ファイルが入っているフォルダの場所** が、このあと必要です。

### 2. 保存したフォルダのパスをコピーする

Windows では、エクスプローラーで `hello_world.py` が入っているフォルダを開きます。

画面上部のアドレス欄をクリックすると、

```text
C:\Users\sample\Documents\Python学習
```

のような場所が表示されます。

この文字列をコピーします。

> コピーするのは `hello_world.py` 自体ではなく、**hello_world.py が入っているフォルダのパス**です。

macOS では Finder で保存したフォルダを確認します。

必要ならフォルダをターミナルへドラッグすると、
そのフォルダのパスを入力できます。

### 3. VS Code でターミナルを開く

VS Code を起動し、上部メニューの **ターミナル（Terminal）→ 新しいターミナル（New Terminal）** を選びます。

画面下側に、文字を入力できる場所が表示されます。この入力画面を **ターミナル** と呼び、そこへ入力する操作の指示を **コマンド** と呼びます。

ここからのコマンドは、Python のコードを書いた欄ではなく、このターミナルへ入力します。1行入力するたびに Enter キーを押してください。

`PS C:\Users\sample>` など、すでに表示されている文字は入力しません。

### 4. `cd` で保存したフォルダへ移動する

`cd` は、ターミナルで現在いるフォルダを変更するコマンドです。

Windows の例:

```powershell
cd "C:\Users\sample\Documents\Python学習"
```

実際には、

```text
C:\Users\sample\Documents\Python学習
```

の部分を、自分でコピーしたパスに置き換えてください。

フォルダ名に空白が含まれていても動くように、
パス全体を `"` で囲んでおくと安全です。

macOS の例:

```bash
cd "/Users/sample/Documents/Python学習"
```

Linux の例:

```bash
cd "/home/sample/Documents/Python学習"
```

どの OS でも、例のパスを自分の保存先に置き換えてください。

### 5. ファイルがあるか確認する

移動できたら、`hello_world.py` があるか確認します。

Windows:

```powershell
dir
```

macOS / Linux:

```bash
ls
```

一覧の中に、

```text
hello_world.py
```

があれば、正しいフォルダに移動できています。

### 6. Python ファイルを実行する

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

次のように表示されれば成功です。

```text
Hello World!
```

ここまでの流れは、

1. 自分で書く、またはサンプルを保存する
2. `hello_world.py` の保存場所を確認する
3. そのフォルダのパスをコピーする
4. VS Codeでターミナルを開く
5. `cd` でそのフォルダへ移動する
6. `dir` / `ls` でファイルを確認する
7. Pythonで実行する

となります。

## 2-4. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

```python
print("Hello World!")
```

### `print`

`print` は、値を画面に表示するために Python が用意している **関数** です。

`print()` は、括弧の中に渡した値を画面へ表示する関数です。関数は、名前を使って呼び出し、ひとまとまりの処理を実行する仕組みです。詳しい使い方は[関数の章](../07_関数/関数.md)で説明します。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、`print` に渡したい値を書きます。

今回渡しているのは、

```python
"Hello World!"
```

です。

### `"Hello World!"`

`"Hello World!"` は **文字列** です。

Python では、文字を値として扱いたいときに、基本的には `"` または `'` で囲みます。

たとえば、次の2つはどちらも文字列です。

```python
"おはよう"
'おはよう'
```

この教材では、特に理由がない限り `"` を使います。

---

## 2-5. コメント

サンプルコードの先頭には、次のような行があります。

```python
# print関数でHello World!という文字を画面に表示する
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

```python
# この行は実行されません。
print("Hello World!")
```

と書いても、表示されるのは次の1行だけです。

```text
Hello World!
```

このリポジトリでは、サンプルコードを初めて読む人でも処理を追いやすいようにコメントを付けています。

---

## 2-6. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

```python
print("おはようPython！")
```

実行結果:

```text
おはようPython！
```

自分の好きな文字に変更して実行してみてください。

たとえば、

```python
print("Pythonの勉強を始めます")
```

と書いても構いません。

---

## 2-7. よくある間違い

### 引用符を付け忘れる

次のコードは正しくありません。

```python
print(Hello World!)
```

`Hello World!` を文字として扱いたいので、引用符で囲む必要があります。

正しくは、

```python
print("Hello World!")
```

です。

### 丸括弧を閉じ忘れる

次のコードも正しくありません。

```python
print("Hello World!"
```

開いた `(` に対応する `)` が必要です。

### 全角の記号を使う

日本語入力のまま、次のような全角記号を入力するとエラーになることがあります。

```text
print（"Hello World!"）
```

プログラムの記号は基本的に半角で入力します。

正しくは、

```python
print("Hello World!")
```

です。

---

## 2-8. ここまでで覚えること

この章で扱った内容をまとめます。

1. Python のファイルは `.py` という拡張子を使う
2. `print()` で画面に値を表示できる
3. 文字列は引用符で囲む
4. `#` から始まる部分はコメントになる
5. Python のファイルをターミナルから実行できる
