# 2. 最初のプログラム

この章では、Python で最初のプログラムを作成して実行します。題材として、まずはとにかく1行表示してみます。

最初の目標は、画面に次の文字を表示することです。

> **とりまなんか表示しとけ！おはよう世界！**

```text
おはよう世界！
```

---

## 2-1. なぜ最初に文字を表示するの？

最初から難しいことをやる必要はありません。

> **とりまなんか表示しとけ！おはよう世界！**

まずは、

```python
print("おはよう世界！")
```

だけ動かします。

ここで確認したいのは、文章のセンスではありません。

- ファイルを保存できたか
- Pythonが動くか
- ファイルを実行できるか
- 結果が画面に出るか

です。

> **いきなり大作を書いて、動かん原因が環境かコードか分からんようになったら地獄や！**

だから最初は、わざと限界まで小さいプログラムで、

> 書く → 実行する → 結果を見る

という流れだけ確認します。

---

## 2-2. サンプルコードを用意する

この章では、次のコードを使います。

```python
# print() は、文字や数字などを画面に表示するための関数です。
# "おはよう世界！" は表示したい文字列です。
print("おはよう世界！")
```

用意する方法は2つあります。

### 方法A: 自分で書く

VS Code で新しいファイルを作り、

```text
good_morning_world.py
```

という名前で保存します。

`good morning` は「おはよう」、`world` は「世界」という意味です。

そのファイルに、先ほどのコードを書いてください。

コードを書いたら保存します。

Windows / Linux:

```text
Ctrl + S
```

macOS:

```text
Command + S
```

### 方法B: サンプルファイルを使う

この教材には、同じ内容のサンプルファイルも用意しています。

- [good_morning_world.py](./good_morning_world.py)

リンクを開き、ファイルを自分のPCへ保存して使っても構いません。

保存したファイル名が、

```text
good_morning_world.py
```

になっていることを確認してください。

Windowsでは設定によって拡張子が見えず、

```text
good_morning_world.py.txt
```

になってしまうことがあります。

その場合は `.py` ファイルとして保存し直してください。

---

## 2-3. 保存したファイルを実行する

自分で書いた場合でも、サンプルファイルを保存した場合でも、
ここからの手順は同じです。

### 1. `good_morning_world.py` を保存したフォルダを確認する

まず、

```text
good_morning_world.py
```

がどのフォルダにあるか確認します。

たとえば Windows で、

```text
C:\Users\sample\Documents\Python学習
```

というフォルダに保存したとします。

この **ファイルが入っているフォルダの場所** が、このあと必要です。

### 2. 保存したフォルダのパスをコピーする

Windows では、エクスプローラーで `good_morning_world.py` が入っているフォルダを開きます。

画面上部のアドレス欄をクリックすると、

```text
C:\Users\sample\Documents\Python学習
```

のような場所が表示されます。

この文字列をコピーします。

> コピーするのは `good_morning_world.py` 自体ではなく、**good_morning_world.py が入っているフォルダのパス**です。

macOS では Finder で保存したフォルダを確認します。

必要ならフォルダをターミナルへドラッグすると、
そのフォルダのパスを入力できます。

### 3. VS Code でターミナルを開く

VS Code の上部メニューから、

```text
ターミナル → 新しいターミナル
```

を選びます。

画面下側に、コマンドを入力できる場所が表示されます。

### 4. `cd` で保存したフォルダへ移動する

`cd` は、ターミナルで現在いるフォルダを変更するコマンドです。

Windows の例:

```powershell
cd "C:\Users\sample\Documents\Python学習"
```

実際には、

```text
C:\Users\sample\Documents\Python学習
```

の部分を、自分でコピーしたパスに置き換えてください。

フォルダ名に空白が含まれていても動くように、
パス全体を `"` で囲んでおくと安全です。

macOS / Linux の例:

```bash
cd "/Users/sample/Documents/Python学習"
```

### 5. ファイルがあるか確認する

移動できたら、`good_morning_world.py` があるか確認します。

Windows:

```powershell
dir
```

macOS / Linux:

```bash
ls
```

一覧の中に、

```text
good_morning_world.py
```

があれば、正しいフォルダに移動できています。

### 6. Python ファイルを実行する

Windows:

```powershell
python good_morning_world.py
```

macOS / Linux:

```bash
python3 good_morning_world.py
```

次のように表示されれば成功です。

```text
おはよう世界！
```

ここまでの流れは、

> 自分で書く、またはサンプルを保存する  
> ↓  
> `good_morning_world.py` の保存場所を確認する  
> ↓  
> そのフォルダのパスをコピーする  
> ↓  
> VS Codeでターミナルを開く  
> ↓  
> `cd` でそのフォルダへ移動する  
> ↓  
> `dir` / `ls` でファイルを確認する  
> ↓  
> Pythonで実行する

となります。

---

## 2-4. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

```python
print("おはよう世界！")
```

### `print`

`print` は、値を画面に表示するために Python が用意している **関数** です。

関数については後の章で詳しく説明します。

今は、

> `print` を使うと、画面に何かを表示できる

と覚えておけば十分です。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、`print` に渡したい値を書きます。

今回渡しているのは、

```python
"おはよう世界！"
```

です。

### `"おはよう世界！"`

`"おはよう世界！"` は **文字列** です。

Python では、文字を値として扱いたいときに、基本的には `"` または `'` で囲みます。

たとえば、次の2つはどちらも文字列です。

```python
"おはよう"
'おはよう'
```

この教材では、特に理由がない限り `"` を使います。

---

## 2-5. コメント

サンプルコードの先頭には、次のような行があります。

```python
# print() は、文字や数字などを画面に表示するための関数です。
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

```python
# この行は実行されません。
print("おはよう世界！")
```

と書いても、表示されるのは次の1行だけです。

```text
おはよう世界！
```

このリポジトリでは、サンプルコードを初めて読む人でも処理を追いやすいようにコメントを付けています。

## 2-6. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

```python
print("おはようPython！")
```

実行結果:

```text
おはようPython！
```

自分の好きな文字に変更して実行してみてください。

たとえば、

```python
print("Pythonの勉強を始めます")
```

と書いても構いません。

---

## 2-7. よくある間違い

### 引用符を付け忘れる

次のコードは正しくありません。

```python
print(おはよう世界！)
```

`おはよう世界！` を文字として扱いたいので、引用符で囲む必要があります。

正しくは、

```python
print("おはよう世界！")
```

です。

### 丸括弧を閉じ忘れる

次のコードも正しくありません。

```python
print("おはよう世界！"
```

開いた `(` に対応する `)` が必要です。

### 全角の記号を使う

日本語入力のまま、次のような全角記号を入力するとエラーになることがあります。

```text
print（"おはよう世界！"）
```

プログラムの記号は基本的に半角で入力します。

正しくは、

```python
print("おはよう世界！")
```

です。

1. Python のファイルは `.py` という拡張子を使う
