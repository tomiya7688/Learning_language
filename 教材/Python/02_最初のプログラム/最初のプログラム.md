# 2. 最初のプログラム

この章では、Python で最初のプログラムを作成して実行します。題材として、プログラミング入門で昔から使われている `Hello, World!` を表示します。

最初の目標は、画面に次の文字を表示することです。

```text
Hello, World!
```

---

## 2-1. なぜ最初に Hello, World! と表示するの？

プログラミングの入門では、最初のプログラムとして

```text
Hello, World!
```

と表示するのが昔からの慣例です。

ただし、**Hello, World! という文字そのものに特別な意味があるわけではありません。**

> **いきなり大作を書いて、動かん原因が環境かコードか分からんようになったら地獄や！**

だから最初は、わざと限界まで小さいプログラムで動作確認します。

最初にこれを使う理由は、できるだけ小さなプログラムで、

- 書いたコードを保存できたか
- Python が正しく動いているか
- ファイルを実行できるか
- 実行結果を画面で確認できるか

を一度に確かめられるからです。

いきなり計算や条件分岐を使うと、
うまく動かなかったときに「環境構築が原因なのか」「書いたコードが原因なのか」が分かりにくくなります。

そのため、まずは処理をできるだけ単純にして、

> 書く → 実行する → 結果を見る

というプログラミングの基本的な流れを確認します。

`Hello, World!` である必要はないので、
仕組みが分かったあとは好きな文字に変えて構いません。

---

## 2-2. サンプルコードを用意する

この章では、次のコードを使います。

```python
# print() は、文字や数字などを画面に表示するための関数です。
# "Hello, World!" は表示したい文字列です。
print("Hello, World!")
```

用意する方法は2つあります。

### 方法A: 自分で書く

VS Code で新しいファイルを作り、

```text
hello_world.py
```

という名前で保存します。

そのファイルに、先ほどのコードを書いてください。

コードを書いたら保存します。

Windows / Linux:

```text
Ctrl + S
```

macOS:

```text
Command + S
```

### 方法B: サンプルファイルを使う

この教材には、同じ内容のサンプルファイルも用意しています。

- [hello_world.py](./hello_world.py)

リンクを開き、ファイルを自分のPCへ保存して使っても構いません。

保存したファイル名が、

```text
hello_world.py
```

になっていることを確認してください。

Windowsでは設定によって拡張子が見えず、

```text
hello_world.py.txt
```

になってしまうことがあります。

その場合は `.py` ファイルとして保存し直してください。

---

## 2-3. 保存したファイルを実行する

自分で書いた場合でも、サンプルファイルを保存した場合でも、
ここからの手順は同じです。

### 1. `hello_world.py` を保存したフォルダを確認する

まず、

```text
hello_world.py
```

がどのフォルダにあるか確認します。

たとえば Windows で、

```text
C:\Users\sample\Documents\Python学習
```

というフォルダに保存したとします。

この **ファイルが入っているフォルダの場所** が、このあと必要です。

### 2. 保存したフォルダのパスをコピーする

Windows では、エクスプローラーで `hello_world.py` が入っているフォルダを開きます。

画面上部のアドレス欄をクリックすると、

```text
C:\Users\sample\Documents\Python学習
```

のような場所が表示されます。

この文字列をコピーします。

> コピーするのは `hello_world.py` 自体ではなく、**hello_world.py が入っているフォルダのパス**です。

macOS では Finder で保存したフォルダを確認します。

必要ならフォルダをターミナルへドラッグすると、
そのフォルダのパスを入力できます。

### 3. VS Code でターミナルを開く

VS Code の上部メニューから、

```text
ターミナル → 新しいターミナル
```

を選びます。

画面下側に、コマンドを入力できる場所が表示されます。

### 4. `cd` で保存したフォルダへ移動する

`cd` は、ターミナルで現在いるフォルダを変更するコマンドです。

Windows の例:

```powershell
cd "C:\Users\sample\Documents\Python学習"
```

実際には、

```text
C:\Users\sample\Documents\Python学習
```

の部分を、自分でコピーしたパスに置き換えてください。

フォルダ名に空白が含まれていても動くように、
パス全体を `"` で囲んでおくと安全です。

macOS / Linux の例:

```bash
cd "/Users/sample/Documents/Python学習"
```

### 5. ファイルがあるか確認する

移動できたら、`hello_world.py` があるか確認します。

Windows:

```powershell
dir
```

macOS / Linux:

```bash
ls
```

一覧の中に、

```text
hello_world.py
```

があれば、正しいフォルダに移動できています。

### 6. Python ファイルを実行する

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

次のように表示されれば成功です。

```text
Hello, World!
```

ここまでの流れは、

> 自分で書く、またはサンプルを保存する  
> ↓  
> `hello_world.py` の保存場所を確認する  
> ↓  
> そのフォルダのパスをコピーする  
> ↓  
> VS Codeでターミナルを開く  
> ↓  
> `cd` でそのフォルダへ移動する  
> ↓  
> `dir` / `ls` でファイルを確認する  
> ↓  
> Pythonで実行する

となります。

## 2-4. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

```python
print("Hello, World!")
```

### `print`

`print` は、値を画面に表示するために Python が用意している **関数** です。

関数については後の章で詳しく説明します。

今は、

> `print` を使うと、画面に何かを表示できる

と覚えておけば十分です。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、`print` に渡したい値を書きます。

今回渡しているのは、

```python
"Hello, World!"
```

です。

### `"Hello, World!"`

`"Hello, World!"` は **文字列** です。

Python では、文字を値として扱いたいときに、基本的には `"` または `'` で囲みます。

たとえば、次の2つはどちらも文字列です。

```python
"Hello"
'Hello'
```

この教材では、特に理由がない限り `"` を使います。

---

## 2-5. コメント

サンプルコードの先頭には、次のような行があります。

```python
# print() は、文字や数字などを画面に表示するための関数です。
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

```python
# この行は実行されません。
print("Hello, World!")
```

と書いても、表示されるのは次の1行だけです。

```text
Hello, World!
```

このリポジトリでは、サンプルコードを初めて読む人でも処理を追いやすいようにコメントを付けています。

## 2-6. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

```python
print("Hello, Python!")
```

実行結果:

```text
Hello, Python!
```

自分の好きな文字に変更して実行してみてください。

たとえば、

```python
print("Pythonの勉強を始めます")
```

と書いても構いません。

## 2-7. よくある間違い

### 引用符を付け忘れる

次のコードは正しくありません。

```python
print(Hello, World!)
```

`Hello, World!` を文字として扱いたいので、引用符で囲む必要があります。

正しくは、

```python
print("Hello, World!")
```

です。

### 丸括弧を閉じ忘れる

次のコードも正しくありません。

```python
print("Hello, World!"
```

開いた `(` に対応する `)` が必要です。

### 全角の記号を使う

日本語入力のまま、次のような全角記号を入力するとエラーになることがあります。

```text
print（"Hello, World!"）
```

プログラムの記号は基本的に半角で入力します。

正しくは、

```python
print("Hello, World!")
```

です。
