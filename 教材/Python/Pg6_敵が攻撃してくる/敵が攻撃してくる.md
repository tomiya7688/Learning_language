# Pg6. pygame「敵が攻撃してくる」

Pg5では、敵を撃って倒せるようになりました。

でも今の敵は、ただ降りてきて撃たれるだけです。

> **「敵、ただの的じゃん。撃ち返してこいや！」**

今回は、敵からも弾を撃たせます。
敵弾がプレイヤーに当たったらHPが減り、0になったらゲームオーバーです。

---

## Pg6-1. 今回追加するもの

[enemy_fire.py](./enemy_fire.py) を開いてください。

追加する主な変数はこれです。

```python
enemy_bullets = []
enemy_bullet_speed = 4
enemy_fire_interval = 90
enemy_fire_timer = 0

player_hp = 3
```

敵弾も複数になるのでリストにまとめます。

---

## Pg6-2. 一定間隔で敵が撃つ

```python
enemy_fire_timer = enemy_fire_timer + 1

if enemy_fire_timer >= enemy_fire_interval:
    for enemy in enemies:
        enemy_bullets.append([enemy[0], enemy[1] + 20])

    enemy_fire_timer = 0
```

`enemy_fire_interval = 90` なので、60FPSならおよそ1.5秒ごとに撃ちます。

---

## Pg6-3. 敵弾は下へ動く

```python
for enemy_bullet in enemy_bullets:
    enemy_bullet[1] = enemy_bullet[1] + enemy_bullet_speed
```

プレイヤー弾は上へ飛ぶのでyを減らしました。

敵弾は下へ飛ぶのでyを増やします。

---

## Pg6-4. 最初から無理ゲーにしない

今回は、

```python
player_speed = 5
enemy_bullet_speed = 4
enemy_fire_interval = 90
```

です。

> **「見えた瞬間当たるやん！避けられん！」**

ではゲームになりません。

まずは見て避けられる速度から始めます。

---

## Pg6-5. プレイヤーにも当たり判定

```python
player_rect = pygame.Rect(
    player_x - 20,
    player_y - 20,
    40,
    40
)
```

でプレイヤーの当たり判定を作ります。

敵弾もRectにして、

```python
if enemy_bullet_rect.colliderect(player_rect):
    player_hp = player_hp - 1
```

とすれば、当たったときHPを減らせます。

---

## Pg6-6. HPは3

```python
player_hp = 3
```

として、画面左上にもHPを表示します。

```python
hp_text = font.render(
    f"HP: {player_hp}",
    True,
    (255, 255, 255)
)

screen.blit(hp_text, (10, 10))
```

---

## Pg6-7. HPが0なら終了

```python
if player_hp <= 0:
    running = False
```

今回は最低限なので、専用のゲームオーバー画面はまだ作りません。

まずは、

> **敵の攻撃を避けないと負ける**

状態になれば十分です。

---

## Pg6-8. 敵が「的」から「相手」になった

Pg5までは、

```text
敵
→ 動く的
```

でした。

Pg6では、

```text
敵
→ 攻撃してくる
→ 避けないとHPが減る
```

になります。

これで初めて、

> **撃つ + 避ける**

の両方が必要なシューティングになります。

---

## Pg6-9. CIでも遊べる速度か見る

pygame教材のCIでは、

- `player_speed`
- `enemy_bullet_speed`
- `enemy_fire_interval`

なども確認します。

> **動けばいいってもんじゃない。避けられなきゃゲームにならん。**

ということです。

Pg10だけは、逆にわざと無理ゲーにします。

---

## Pg6-10. ここまでで覚えること

1. 敵弾も複数なのでリストにまとめる
2. フレーム数を数えると一定間隔で処理できる
3. 敵弾はyを増やすと下へ飛ぶ
4. プレイヤーにもRectで当たり判定を作れる
5. 敵弾が当たったらHPを減らせる
6. HPが0ならゲームオーバーにできる
7. ゲームは「動く」だけでなく「遊べる速度」も大事
