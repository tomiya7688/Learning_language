# Pg6. pygame「敵が攻撃してくる」

Pg5では、敵を撃って倒せるようになりました。

でも今の敵は、ただ降りてきて撃たれるだけです。

> **「敵、ただの的じゃん。撃ち返してこいや！」**

今回は、敵からも弾を撃たせます。
敵弾がプレイヤーに当たったらHPが減り、0になったらゲームオーバーです。

---

## Pg6-1. 今回追加するもの

[enemy_fire.py](./enemy_fire.py) を開いてください。

敵弾とHPのために、主に次の値を追加しています。

```python
enemy_bullets = []
enemy_bullet_speed = 4
enemy_fire_interval = 90
enemy_fire_timer = 0

player_hp = 3
```

それぞれ意味が違います。

### `enemy_bullets = []`

`enemy_bullets` は、画面にある**敵弾の一覧**です。

ゲーム開始時はまだ1発も発射されていないので、空のリスト `[]` から始めます。

### `enemy_bullet_speed = 4`

敵弾が1フレームで進む距離です。

この実装では、**1フレームに4ピクセル**下へ進みます。

### `enemy_fire_interval = 90`

敵が次の弾を撃つまでに数えるフレーム数です。90フレームごとに発射します。

### `enemy_fire_timer = 0`

今何フレームまで数えたかを覚える値です。ゲーム開始時は数え始めなので、0から始めます。

### `player_hp = 3`

プレイヤーの残りHPです。敵弾に1回当たるたびに、

```python
player_hp = player_hp - 1
```

で1減ります。

```text
開始時  3
1回被弾 2
2回被弾 1
3回被弾 0
```

となり、**3回目の被弾で0**になります。

---

## Pg6-2. 一定間隔で敵が撃つ

敵が毎フレーム弾を出すと多すぎるので、発射までのフレーム数を数えます。

```python
enemy_fire_timer = enemy_fire_timer + 1

if enemy_fire_timer >= enemy_fire_interval:
    for enemy in enemies:
        enemy_bullets.append([enemy[0], enemy[1] + 20])

    enemy_fire_timer = 0
```

`enemy_fire_timer` は、発射までに何フレーム進んだかを数える変数です。

最初は `enemy_fire_timer = 0` なので、0から数え始めます。

ゲームループが1回進むたびに、

```python
enemy_fire_timer = enemy_fire_timer + 1
```

で1ずつ増えます。

`enemy_fire_interval = 90` なので、90フレーム数えたら敵弾を発射します。

このゲームは `clock.tick(60)` で約60FPSを上限にしているため、90フレームはおよそ、

```text
90 ÷ 60 = 1.5秒
```

です。

**90は90FPSという意味ではありません。** 発射までに数えるフレーム数です。

発射したら `enemy_fire_timer = 0` へ戻し、また0から数え直します。

---

## Pg6-3. 敵弾は下へ動く

```python
for enemy_bullet in enemy_bullets:
    enemy_bullet[1] = enemy_bullet[1] + enemy_bullet_speed
```

プレイヤー弾は上へ飛ぶのでyを減らしました。

敵弾は下へ飛ぶのでyを増やします。

---

## Pg6-4. 最初から無理ゲーにしない

今回は、

```python
player_speed = 5
enemy_bullet_speed = 4
enemy_fire_interval = 90
```

です。

> **「見えた瞬間当たるやん！避けられん！」**

ではゲームになりません。

まずは見て避けられる速度から始めます。

---

## Pg6-5. プレイヤーにも当たり判定

```python
player_rect = pygame.Rect(
    player_x - 20,
    player_y - 20,
    40,
    40
)
```

でプレイヤーの当たり判定を作ります。

敵弾もRectにして、

```python
if enemy_bullet_rect.colliderect(player_rect):
    player_hp = player_hp - 1
```

とすれば、当たったときHPを減らせます。

---

## Pg6-6. HPは3

```python
player_hp = 3
```

として、画面左上にもHPを表示します。

```python
hp_text = font.render(
    f"HP: {player_hp}",
    True,
    (255, 255, 255)
)

screen.blit(hp_text, (10, 10))
```

---

## Pg6-7. HPが0なら終了

```python
if player_hp <= 0:
    running = False
```

今回は最低限なので、専用のゲームオーバー画面はまだ作りません。

まずは、

> **敵の攻撃を避けないと負ける**

状態になれば十分です。

---

## Pg6-8. 敵が「的」から「相手」になった

Pg5までは、

```text
敵
→ 動く的
```

でした。

Pg6では、

```text
敵
→ 攻撃してくる
→ 避けないとHPが減る
```

になります。

これで初めて、

> **撃つ + 避ける**

の両方が必要なシューティングになります。

---

## Pg6-9. CIでも遊べる速度か見る

pygame教材のCIでは、

- `player_speed`
- `enemy_bullet_speed`
- `enemy_fire_interval`

なども確認します。

> **動けばいいってもんじゃない。避けられなきゃゲームにならん。**

ということです。

Pg10だけは、逆にわざと無理ゲーにします。

---

## Pg6-10. ここまでで覚えること

1. 敵弾も複数なのでリストにまとめる
2. フレーム数を数えると一定間隔で処理できる
3. 敵弾はyを増やすと下へ飛ぶ
4. プレイヤーにもRectで当たり判定を作れる
5. 敵弾が当たったらHPを減らせる
6. HPが0ならゲームオーバーにできる
7. ゲームは「動く」だけでなく「遊べる速度」も大事
