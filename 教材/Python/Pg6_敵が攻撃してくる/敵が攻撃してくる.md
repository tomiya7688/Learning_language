# Pg6. pygame「敵が攻撃してくる」

Pg5では、敵を撃って倒せるようになりました。

でも今の敵は、ただ降りてきて撃たれるだけです。

> **「敵、ただの的じゃん。撃ち返してこいや！」**

今回は、敵からも弾を撃たせます。
敵弾がプレイヤーに当たったらHPが減り、0になったらゲームオーバーです。

---

## Pg6-1. 今回追加するもの

[enemy_fire.py](./enemy_fire.py) を開いてください。

敵弾とHPのために、主に次の値を追加しています。

```python
# enemy_bullets に空のリストを入れる
enemy_bullets = []
# enemy_bullet_speed に4を入れる
enemy_bullet_speed = 4
# enemy_fire_interval に90を入れる
enemy_fire_interval = 90
# enemy_fire_timer に0を入れる
enemy_fire_timer = 0

# player_hp に3を入れる
player_hp = 3
```

それぞれ意味が違います。

### `enemy_bullets = []`

`enemy_bullets` は、画面にある**敵弾の一覧**です。

ゲーム開始時はまだ1発も発射されていないので、空のリスト `[]` から始めます。

### `enemy_bullet_speed = 4`

敵弾が1フレームで進む距離です。

この実装では、**1フレームに4ピクセル**下へ進みます。

### `enemy_fire_interval = 90`

敵が次の弾を撃つまでに数えるフレーム数です。90フレームごとに発射します。

### `enemy_fire_timer = 0`

今何フレームまで数えたかを覚える値です。ゲーム開始時は数え始めなので、0から始めます。

### `player_hp = 3`

プレイヤーの残りHPです。敵弾に1回当たるたびに、

```python
# player_hp に player_hp から1を引いた値を入れる
player_hp = player_hp - 1
```

で1減ります。

```text
開始時  3
1回被弾 2
2回被弾 1
3回被弾 0
```

となり、**3回目の被弾で0**になります。

---

## Pg6-2. 一定間隔で敵が撃つ

敵が毎フレーム弾を出すと多すぎるので、発射までのフレーム数を数えます。

```python
# enemy_fire_timer に enemy_fire_timer と1を足した値を入れる
enemy_fire_timer = enemy_fire_timer + 1

# enemy_fire_timer が enemy_fire_interval 以上なら
if enemy_fire_timer >= enemy_fire_interval:
    # enemies から enemy を1つずつ取り出して繰り返す
    for enemy in enemies:
        # enemy_bullets に [enemy[0], enemy[1] + 20] を追加する
        enemy_bullets.append([enemy[0], enemy[1] + 20])

    # enemy_fire_timer に0を入れる
    enemy_fire_timer = 0
```

`enemy_fire_timer` は、発射までに何フレーム進んだかを数える変数です。

最初は `enemy_fire_timer = 0` なので、0から数え始めます。

ゲームループが1回進むたびに、

```python
# enemy_fire_timer に enemy_fire_timer と1を足した値を入れる
enemy_fire_timer = enemy_fire_timer + 1
```

で1ずつ増えます。

`enemy_fire_interval = 90` なので、90フレーム数えたら敵弾を発射します。

このゲームは `clock.tick(60)` で約60FPSを上限にしているため、90フレームはおよそ、

```text
90 ÷ 60 = 1.5秒
```

です。

**90は90FPSという意味ではありません。** 発射までに数えるフレーム数です。

発射したら `enemy_fire_timer = 0` へ戻し、また0から数え直します。

---

## Pg6-3. 敵弾は下へ動く

```python
# enemy_bullets から enemy_bullet を1つずつ取り出して繰り返す
for enemy_bullet in enemy_bullets:
    # enemy_bullet[1] に enemy_bullet[1] と enemy_bullet_speed を足した値を入れる
    enemy_bullet[1] = enemy_bullet[1] + enemy_bullet_speed
```

プレイヤー弾は上へ飛ぶのでyを減らしました。

敵弾は下へ飛ぶのでyを増やします。

## Pg6-4. 最初から無理ゲーにしない

今回は、

```python
# player_speed に5を入れる
player_speed = 5
# enemy_bullet_speed に4を入れる

# enemy_fire_interval に90を入れる

```

です。

> **「見えた瞬間当たるやん！避けられん！」**

ではゲームになりません。

まずは見て避けられる速度から始めます。

## Pg6-5. プレイヤーにも当たり判定

敵弾とプレイヤーが重なったか調べるため、プレイヤーにもRectを用意します。

```python
# player_rect に pygame.Rect(player_x - 20, player_y - 20, 40, 40) をセットする
player_rect = pygame.Rect(
    player_x - 20,
    player_y - 20,
    40,
    40
)
```

プレイヤーのRectは、幅40・高さ40ピクセルです。

この教材では `player_x` と `player_y` をプレイヤーの中心として使っています。

40の半分は20なので、

```text
player_x - 20
→ 左端

player_y - 20
→ 上端

40
→ 幅

40
→ 高さ
```

となります。

中心から左へ20、上へ20ピクセルずらすことで、40×40の四角形の中心をプレイヤー座標へ合わせています。

敵弾側もRectを作ります。

```python
# enemy_bullet_rect に pygame.Rect(enemy_bullet[0] - 4, enemy_bullet[1] - 8, 8, 16) をセットする
enemy_bullet_rect = pygame.Rect(
    enemy_bullet[0] - 4,
    enemy_bullet[1] - 8,
    8,
    16
)
```

敵弾は幅8・高さ16なので、

```text
8 ÷ 2 = 4
16 ÷ 2 = 8
```

です。

そのため、敵弾の中心座標から左へ4、上へ8ピクセルずらして左上を決めています。

そして、

```python
# enemy_bullet_rect.colliderect(player_rect) が True なら
if enemy_bullet_rect.colliderect(player_rect):
    # enemy_bullets_to_remove に enemy_bullet を追加する
    enemy_bullets_to_remove.append(enemy_bullet)
    # player_hp に player_hp から1を引いた値を入れる
    player_hp = player_hp - 1
```

で、**敵弾の四角形とプレイヤーの四角形**を比較します。

`colliderect()` は2つのRectが重なっていれば `True`、重なっていなければ `False` です。

`True` になったときだけ `if` の中へ入り、その敵弾を消す対象へ入れて、HPを1減らします。

## Pg6-6. HPを画面へ表示する

残りHPは、

```python
# player_hp に3を入れる
player_hp = 3
```

から始めました。

この数字を画面左上へ文字として表示します。

### まず文字の形と大きさを用意する

ファイルの最初の方に、

```python
# font に pygame.font.Font(None, 36) をセットする
font = pygame.font.Font(None, 36)
```

があります。

`font` は、このあと文字を作るために使うフォントへ付けた名前です。

`pygame.font.Font()` の2つの値は、

```text
None
→ pygameの標準フォントを使う

36
→ 文字サイズ
```

です。

### `render()` で文字画像を作る

HP表示は、

```python
# hp_text に font.render(f"HP: {player_hp}", True, (255, 255, 255)) をセットする
hp_text = font.render(
    f"HP: {player_hp}",
    True,
    (255, 255, 255)
)
```

です。

`font.render()` は、文字列から**文字の画像**を作ります。

左から順に、

```text
f"HP: {player_hp}"
→ 表示する文章

True
→ 文字の縁を滑らかにする指定

(255, 255, 255)
→ 文字色
```

です。

`(255, 255, 255)` はRGBで、赤・緑・青がすべて最大なので白になります。

作られた文字画像を `hp_text` に入れています。

ここで重要なのは、**renderしただけではまだ画面には表示されない**ことです。

### `blit()` で文字画像を画面へ描く

次に、

```python
# screen に hp_text を (10, 10) の位置へ描く
screen.blit(hp_text, (10, 10))
```

で、作った `hp_text` を `screen` に描きます。

`(10, 10)` は文字画像の左上位置です。

```text
左から10ピクセル
上から10ピクセル
```

の場所へ置きます。

HP表示は、

```text
Fontで文字の形と大きさを用意
↓
render()で文字画像を作る
↓
blit()でscreenへ描く
↓
pygame.display.flip()で画面へ反映
```

という順番です。

`render()` と `blit()` は同じ処理ではありません。

## Pg6-7. HPが0なら終了

```python
# player_hp が0以下なら
if player_hp <= 0:
    # running に False を入れる
    running = False
```

今回は最低限なので、専用のゲームオーバー画面はまだ作りません。

まずは、

> **敵の攻撃を避けないと負ける**

状態になれば十分です。

## Pg6-8. 敵が「的」から「相手」になった

Pg5までは、

```text
敵
→ 動く的
```

でした。

Pg6では、

```text
敵
→ 攻撃してくる
→ 避けないとHPが減る
```

になります。

これで初めて、

> **撃つ + 避ける**

の両方が必要なシューティングになります。

## Pg6-10. ここまでで覚えること

1. 敵弾も複数なのでリストにまとめる
2. フレーム数を数えると一定間隔で処理できる
3. 敵弾はyを増やすと下へ飛ぶ
4. プレイヤーにもRectで当たり判定を作れる
5. 敵弾が当たったらHPを減らせる
6. HPが0ならゲームオーバーにできる
7. ゲームは「動く」だけでなく「遊べる速度」も大事
