# Tk6. 掛け算を用意する

Tk5では、

```text
1 + 2 - 3 + 4
```

のように、複数の数字を続けて計算できるようになりました。

でも、

> **「掛け算ないん？？？」**

となります。

今回は `*` ボタンを追加します。

ただし、ただ `*` を増やすだけでは終わりません。

---

## Tk6-1. そのまま足すと計算がおかしい

Tk5は左から順番に計算していました。

このまま、

```text
1 + 2 * 3
```

を計算すると、

```text
1 + 2 = 3
3 * 3 = 9
```

になってしまいます。

でも普通の計算では、

```text
2 * 3 = 6
1 + 6 = 7
```

です。

> **「掛け算追加したら答え間違う電卓になったんだけど！！！」**

なので、Tk6では掛け算を先に計算します。

---

## Tk6-2. 今回使うもの

[multiplication_calculator.py](./multiplication_calculator.py) を開いてください。

```python
import tkinter


calculation_parts = []


def add_operator(operator):
    number_text = number_entry.get()

    if number_text == "":
        result_label.config(text="次の数字を入力してください")
        return

    calculation_parts.append(float(number_text))
    calculation_parts.append(operator)

    expression_label.config(
        text="計算式: " + " ".join(str(part) for part in calculation_parts)
    )

    number_entry.delete(0, tkinter.END)
    result_label.config(text="答え:")


def select_addition():
    add_operator("+")


def select_subtraction():
    add_operator("-")


def select_multiplication():
    add_operator("*")


def calculate():
    number_text = number_entry.get()

    if number_text == "":
        result_label.config(text="最後の数字を入力してください")
        return

    calculation_parts.append(float(number_text))

    # 掛け算を先に計算する
    addition_and_subtraction_parts = [calculation_parts[0]]

    for index in range(1, len(calculation_parts), 2):
        operator = calculation_parts[index]
        number = calculation_parts[index + 1]

        if operator == "*":
            addition_and_subtraction_parts[-1] = (
                addition_and_subtraction_parts[-1] * number
            )
        else:
            addition_and_subtraction_parts.append(operator)
            addition_and_subtraction_parts.append(number)

    # 残った足し算と引き算を左から計算する
    answer = addition_and_subtraction_parts[0]

    for index in range(1, len(addition_and_subtraction_parts), 2):
        operator = addition_and_subtraction_parts[index]
        number = addition_and_subtraction_parts[index + 1]

        if operator == "+":
            answer = answer + number
        else:
            answer = answer - number

    expression_label.config(
        text=(
            "計算式: "
            + " ".join(str(part) for part in calculation_parts)
            + f" = {answer}"
        )
    )
    result_label.config(text=f"答え: {answer}")

    calculation_parts.clear()
    number_entry.delete(0, tkinter.END)
    number_entry.insert(0, str(answer))


window = tkinter.Tk()
window.title("掛け算を用意する")
window.geometry("420x360")

number_label = tkinter.Label(window, text="数字")
number_label.pack()

number_entry = tkinter.Entry(window)
number_entry.pack()

expression_label = tkinter.Label(window, text="計算式:")
expression_label.pack()

addition_button = tkinter.Button(
    window,
    text="+",
    command=select_addition
)
addition_button.pack()

subtraction_button = tkinter.Button(
    window,
    text="-",
    command=select_subtraction
)
subtraction_button.pack()

multiplication_button = tkinter.Button(
    window,
    text="*",
    command=select_multiplication
)
multiplication_button.pack()

equals_button = tkinter.Button(
    window,
    text="=",
    command=calculate
)
equals_button.pack()

result_label = tkinter.Label(window, text="答え:")
result_label.pack()

window.mainloop()
```

追加するボタンは、

```text
*
```

です。

Pythonでは掛け算を `*` で書きます。

## Tk6-3. Tk5で作った共通処理を使う

Tk5では、

```python
def add_operator(operator):
```

を作りました。

なので掛け算も、

```python
def select_multiplication():
    add_operator("*")
```

だけで計算式へ追加できます。

> **共通処理にしておくと、機能追加が楽になります。**

---

## Tk6-4. ボタンを追加する

```python
multiplication_button = tkinter.Button(
    window,
    text="*",
    command=select_multiplication
)
multiplication_button.pack()
```

これで `*` ボタンが増えます。

## Tk6-5. 計算式の持ち方は変えない

たとえば、

```text
1 + 2 * 3 - 4
```

なら、

```python
[
    1.0,
    "+",
    2.0,
    "*",
    3.0,
    "-",
    4.0
]
```

のように覚えます。

Tk5と同じです。

変わるのは、

> **計算するときの順番**

です。

---

## Tk6-6. まず掛け算だけ処理する

最初に、

```python
addition_and_subtraction_parts = [
    calculation_parts[0]
]
```

を用意します。

そして演算子を順番に見て、

```python
if operator == "*":
    addition_and_subtraction_parts[-1] = (
        addition_and_subtraction_parts[-1]
        * number
    )
```

とします。

`*` なら、その場で掛け算します。

---

## Tk6-7. + と - はあとに残す

掛け算ではなかったら、

```python
else:
    addition_and_subtraction_parts.append(operator)
    addition_and_subtraction_parts.append(number)
```

とします。

つまり、

```text
1 + 2 * 3 - 4
```

は、掛け算を先に処理して、

```text
1 + 6 - 4
```

のような状態にします。

---

## Tk6-8. 残った + と - を計算する

掛け算が終わったあと、

```python
answer = addition_and_subtraction_parts[0]
```

から始めて、

```python
if operator == "+":
    answer = answer + number
else:
    answer = answer - number
```

とします。

これで、

```text
1 + 2 * 3
```

は、

```text
7
```

になります。

---

## Tk6-9. なんで2回に分けるの？

今回の計算は、

```text
1回目
掛け算を片付ける

2回目
足し算と引き算を計算する
```

という2段階です。

> **優先順位が違うなら、処理する順番も分ける。**

これが今回の本質です。

次を入力してください。

## Tk6-11. Tk5から何を変えた？

増えたのは大きく2つです。

```text
* ボタン
掛け算を先に処理する仕組み
```

入力方法や、

```python
calculation_parts
```

の持ち方はそのままです。

> **全部作り直さず、必要なところだけ増やす。**

これが機能追加です。

---

## Tk6-12. ここまでで覚えること

1. Pythonの掛け算は `*`
2. `add_operator("*")` で既存の仕組みに演算子を追加できる
3. 掛け算には足し算・引き算より高い優先順位がある
4. 優先順位が違う処理は段階を分けて計算できる
5. 共通処理を作っておくと機能追加が楽になる

## Tk6-13. 次は割り算

これで、

```text
+
-
*
```

が使えるようになりました。

次は、

> **「あと割り算あれば四則演算じゃん！」**

ということで、Tk7で `/` を追加します。

ただし割り算には、

```text
10 / 0
```

という問題があります。

そこも一緒に扱います。
