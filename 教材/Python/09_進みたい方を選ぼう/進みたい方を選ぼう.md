# 9. 進みたい方を選ぼう

ここまでで、Pythonの基本として、

- 入力と変数
- 数値と計算
- 条件分岐
- 繰り返し
- 関数
- クラス

まで学びました。

ここから先は、**全員が同じ順番で進む必要はありません。**

> **「全部やらなあかんの？」**
>
> **いいえ。作りたいものに近い道へ行けばいいです。**

Python学習は一本道ではありません。

「もっとPythonの基本文法を続けたい」
「画面のあるアプリを作りたい」
「ブラウザで動くものを作りたい」
「ゲームを作りたい」

など、やりたいことによって進む方向を選べます。

---

## 9-1. まずは進みたい方向を選ぶ

大きく分けると、次の4つのルートがあります。

### 1. Pythonの基本文法をそのまま続けたい

こんな人向けです。

- Pythonそのものを順番に学びたい
- リストや辞書を使いたい
- ファイルを読み書きしたい
- CSVやJSONを扱いたい
- Web APIまで基礎から進みたい
- GUIより先に文法を固めたい

このルートでは、これまでと同じように正番号の教材を続けます。

次に扱う予定なのは **リスト** です。

**こんな人向け**

> 「寄り道せず、まずPythonの基本を一通り覚えたい」

次に読む教材:

- [10. リスト](../10_リスト/リスト.md)

---

### 2. 普通のデスクトップアプリを作りたい

こんなものを作りたい人向けです。

- ボタンのある小さなツール
- 入力欄のあるアプリ
- 電卓
- メモ帳
- ファイル整理ツール

このルートでは **tkinter** を使います。

tkinterはPythonに標準で付属しているため、最初の一歩では追加インストールなしで始めやすいのが特徴です。

まずは空のウィンドウを出して、そのあとLabel、Entry、Buttonなどを置いていきます。

**こんな人向け**

> 「普通のウィンドウアプリを作ってみたい」

次に読む教材:

- [Tk1: tkinter入門「最初のウィンドウ」](../Tk1_最初のウィンドウ/最初のウィンドウ.md)

---

### 3. ブラウザで動く小さなツールやデータ画面を作りたい

こんなものを作りたい人向けです。

- 入力フォーム
- 簡単なデータ表示
- グラフや集計結果の表示
- 小さなダッシュボード
- ブラウザで使う社内ツール

このルートでは **Streamlit** を使います。

Streamlitは、Pythonコードを中心にブラウザ画面を作れるライブラリです。

HTMLやJavaScriptを最初から詳しく知らなくても、比較的早く画面を作れます。

**こんな人向け**

> 「ブラウザで開けるツールをPythonで手早く作りたい」

次に読む教材:

- [Issue #25: Streamlit入門「最初のブラウザ画面」](https://github.com/tomiya7688/Learning_language/issues/25)

---

### 4. ゲームっぽい画面や自由に描画するものを作りたい

こんなものを作りたい人向けです。

- キャラクターを動かす
- キー入力で操作する
- 図形や画像を自由に描く
- 簡単な2Dゲーム

このルートでは **pygame** を使います。

pygameは、ボタンや入力欄を並べるというより、画面へ自分で絵を描き、キー入力やマウス入力を処理する方向に向いています。

**こんな人向け**

> 「ゲーム画面や自由な描画をしてみたい」

次に読む教材:

- [Issue #26: pygame入門「最初のゲーム画面」](https://github.com/tomiya7688/Learning_language/issues/26)

## 9-2. どれか1つに決めなくてもいい

ここで選んだルートを、ずっと続けなければならないわけではありません。

たとえば、

```text
基本文法
    ↓
tkinter
    ↓
また基本文法へ戻る
```

でも構いません。

```text
pygameを少し触る
    ↓
リストが必要になる
    ↓
基本文法へ戻る
```

でも構いません。

実際のプログラミングでは、作りたいものに必要な知識を、その都度学びながら進むこともよくあります。

---

## 9-3. 迷ったら基本文法を続けてもいい

特に作りたいものが決まっていない場合は、基本文法ルートをそのまま続けて構いません。

リスト、辞書、ファイル操作などは、tkinter、Streamlit、pygameのどのルートでも後から役立ちます。

一方で、

> 「とにかく一度ウィンドウを出してみたい」

と思ったなら、tkinterへ寄り道してみるのもよいでしょう。

---

## 9-4. もっと先には別の道もある

ここでは、最初の分岐として代表的な入口だけを示しています。

たとえば将来は、

- 本格的なデスクトップGUI → PySide / PyQt
- WebサイトやWebサービス → Flask / FastAPI / Django
- データ分析 → pandas / NumPy
- 機械学習 → scikit-learn / PyTorch
- 自動化 → ファイル操作 / Web API / ブラウザ操作

など、さらに多くの方向へ進めます。

最初から全部覚える必要はありません。
