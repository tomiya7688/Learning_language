# 8. クラス

この章では、**データと、そのデータに関係する処理をひとまとめにする方法**を学びます。

今回作るのは、「名前」と「点数」を持つ生徒を表す小さなクラスです。

---

## 8-1. 今回作るもの

まず、次のようなクラスを作ります。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show_result(self):
        print(self.name, ":", self.score)
```

このクラスから、

```python
student1 = Student("たろう", 80)
student2 = Student("さくら", 95)
```

のように、複数の生徒を作れます。

そして、

```python
student1.show_result()
student2.show_result()
```

とすると、

```text
たろう : 80
さくら : 95
```

と表示されます。

---

## 8-2. なぜクラスが必要なの？

名前と点数だけなら、変数でも書けます。

```python
name1 = "たろう"
score1 = 80

name2 = "さくら"
score2 = 95
```

でも人数が増えると、

```text
name1 は誰の名前？
score2 は誰の点数？
show_result1 は誰用？
```

のように、関係するデータと処理が散らばってきます。

> 「この人の名前と点数と表示処理、全部ひとまとめにしてくれ！」

となるわけです。

そこで使うのが **クラス** です。

クラスを使うと、

> 「生徒は名前と点数を持ち、結果を表示できる」

というまとまりを1か所に書けます。

---

## 8-3. クラスはそんなに難しいものではない

最初は「オブジェクト指向」という言葉を見ると大げさに感じるかもしれません。

でも、この章でやることはかなり単純です。

```text
Student という種類を作る
        ↓
名前と点数を持たせる
        ↓
表示する処理も持たせる
        ↓
たろう と さくら を実際に作る
```

まずはこれだけです。

継承や複雑な設計は、今は考えません。

---

## 8-4. サンプルコード

[student_class.py](./student_class.py) を開いてください。

`student` は「生徒」、`class` は「クラス」という意味です。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show_result(self):
        print(self.name, ":", self.score)


student1 = Student("たろう", 80)
student2 = Student("さくら", 95)

student1.show_result()
student2.show_result()
```

---

## 8-5. `class` で種類を作る

クラスを作るときは `class` を使います。

```python
class Student:
```

これは、

> `Student` という種類を作ります

という意味です。

クラス名は、Pythonでは先頭を大文字にする書き方がよく使われます。

---

## 8-6. クラスとインスタンス

`Student` はクラスです。

そこから実際に作った、

```python
student1 = Student("たろう", 80)
```

の `student1` は **インスタンス** と呼ばれます。

イメージは、

```text
Student という共通の作り方
        ↓
Student("たろう", 80)
        ↓
student1 という実際の1人
```

です。

もう1回呼べば、

```python
student2 = Student("さくら", 95)
```

別のインスタンスを作れます。

---

## 8-7. `__init__` は最初の設定

次の部分を見てください。

```python
def __init__(self, name, score):
    self.name = name
    self.score = score
```

`__init__` は、インスタンスを作るときに最初に呼ばれる特別なメソッドです。

```python
Student("たろう", 80)
```

と書くと、

```text
name  ← "たろう"
score ← 80
```

が渡されます。

---

## 8-8. `self` って何？

クラスで一番「なんだこれ」となりやすいのが `self` です。

まずは、

> **今扱っている、そのインスタンス自身**

くらいに考えてください。

```python
self.name = name
```

は、

> 今作っている生徒の `name` に、受け取った名前を入れる

という意味です。

同じクラスから、

```python
student1 = Student("たろう", 80)
student2 = Student("さくら", 95)
```

と2人作っても、

```text
student1.name → "たろう"
student2.name → "さくら"
```

のように、それぞれ別の値を持てます。

---

## 8-9. 属性とは

```python
self.name
self.score
```

のように、インスタンスが持っているデータを **属性** と呼びます。

作ったあとも、

```python
print(student1.name)
print(student1.score)
```

のように取り出せます。

ここでも `.` が出てきます。

```text
student1 . name
    ↑       ↑
この生徒   その生徒の名前
```

です。

---

## 8-10. メソッドとは

クラスの中に書いた関数を **メソッド** と呼びます。

```python
def show_result(self):
    print(self.name, ":", self.score)
```

このメソッドは、

```python
student1.show_result()
```

のように呼べます。

つまり、

```text
student1 の show_result を実行する
```

という意味です。

---

## 8-11. データと処理を一緒に置ける

クラスの重要なところは、

```text
データ
- name
- score

処理
- show_result()
```

を同じまとまりの中に置けることです。

これによって、

> 「この処理はどのデータに対するもの？」

が分かりやすくなります。

---

## 8-12. 辞書とは何が違うの？

あとで学ぶ辞書でも、

```python
student = {
    "name": "たろう",
    "score": 80
}
```

のようにデータをまとめられます。

辞書は、データを名前付きでまとめるのが得意です。

クラスはそれに加えて、

> そのデータに関係する処理も一緒にまとめたい

ときに便利です。

今は、

```text
辞書 → 主にデータをまとめる
クラス → データと処理をまとめられる
```

くらいの違いで十分です。

---

## 8-13. `tkinter.Tk()` もクラスだった

Tk1で、

```python
window = tkinter.Tk()
```

と書きました。

実は、この `Tk` もクラスです。

```text
tkinter.Tk
    ↓
ウィンドウを表すクラス
```

そして、

```python
tkinter.Tk()
```

と `()` を付けることで、実際のウィンドウのインスタンスを作っています。

だから、そのあと、

```python
window.title(...)
window.geometry(...)
window.mainloop()
```

のように、`window` が持つメソッドを呼べます。

Tk1で出てきた書き方が、ここでつながります。

## 8-14. 自分で変えてみる

属性を1つ増やしてみましょう。

```python
class Student:
    def __init__(self, name, score, class_name):
        self.name = name
        self.score = score
        self.class_name = class_name
```

そして、

```python
student1 = Student("たろう", 80, "A")
```

のように作れます。

## 8-15. 今は継承までやらなくていい

クラスには、この先、

- 継承
- `super()`
- クラス変数
- 特殊メソッド

などの機能もあります。

でも、最初から全部覚える必要はありません。

まずは、

1. `class` で種類を作る
2. `__init__` で最初の値を入れる
3. `self` でそのインスタンス自身を扱う
4. 属性にデータを持たせる
5. メソッドで処理を持たせる
6. クラスからインスタンスを作る

ここまで分かれば十分です。
