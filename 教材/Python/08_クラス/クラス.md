# 8. クラス

この章では、**変数と関数をひとまとめにする方法**を学びます。

クラスについて最初に覚えてほしいことは、これだけです。

> **クラスは、関係する変数と関数をまとめて置くためのまとまりです。**

「オブジェクト指向」「インスタンス化」といった詳しい話は、もっと後で扱います。

---

## 8-1. なぜクラスが必要なの？

ここまでで、変数と関数を学びました。

たとえば、生徒について、

```python
student_name = "たろう"
student_score = 80

def show_result():
    print(student_name, ":", student_score)
```

と書けます。

これでも動きます。

でも、プログラムが大きくなると、

```text
生徒の名前
生徒の点数
生徒を表示する関数
商品の名前
商品の値段
商品を表示する関数
設定の値
設定を変更する関数
...
```

のように、変数と関数がどんどん増えていきます。

すると、

> 「どの変数とどの関数が仲間なんだよ！」

となってきます。

そこで、関係するものを1か所へまとめます。

それが **クラス** です。

---

## 8-2. 今回作るもの

生徒に関係する変数と関数を、`Student` というまとまりへ入れます。

```python
class Student:
    name = "たろう"
    score = 80

    def show_result(self):
        print(self.name, ":", self.score)
```

これを見ると、

```text
Student
├─ name
├─ score
└─ show_result()
```

というまとまりになっています。

これが、この章で一番大切な考え方です。

---

## 8-3. サンプルコード

[student_class.py](./student_class.py) を開いてください。

`student` は「生徒」、`class` は「クラス」という意味です。

```python
class Student:
    name = "たろう"
    score = 80

    def show_result(self):
        print(self.name, ":", self.score)


student = Student()

print(student.name)
print(student.score)
student.show_result()
```

実行結果:

```text
たろう
80
たろう : 80
```

---

## 8-4. `class` でまとまりを作る

クラスを作るときは `class` を使います。

```python
class Student:
```

これは、

> ここから `Student` というまとまりを作ります

という意味です。

その中へ、関係する変数や関数を書いていきます。

---

## 8-5. クラスの中へ変数を入れる

```python
class Student:
    name = "たろう"
    score = 80
```

これで、

- `name`
- `score`

が `Student` の中にまとまりました。

普通の変数と同じように値を入れています。

違うのは、**Studentに関係する変数としてまとめられている**ことです。

---

## 8-6. クラスの中へ関数を入れる

関数も同じまとまりへ入れられます。

```python
class Student:
    name = "たろう"
    score = 80

    def show_result(self):
        print(self.name, ":", self.score)
```

これで `show_result` も、生徒に関係する処理として `Student` の中にまとまりました。

クラスの中にある関数は **メソッド** と呼ばれます。

ただし、今は名前を覚えることより、

> 関数もクラスの中へまとめられる

と分かれば十分です。

---

## 8-7. クラスの中もインデントする

関数や条件分岐と同じように、クラスの中も右へずらして書きます。

```python
class Student:
    name = "たろう"
    score = 80
```

このインデントによって、

> `name` と `score` は `Student` の中にある

とPythonへ伝えています。

---

## 8-8. `Student()` で使える形を作る

サンプルでは、

```python
student = Student()
```

と書いています。

今は、

> `Student` というクラスから、実際に使う `student` を1つ作る

くらいに考えてください。

詳しく学ぶと、ここには「インスタンス」などの用語が出てきます。

ただし、それはクラスの本質ではありません。

この章では、

> **クラスは変数と関数のまとまり**

を先に覚えます。

---

## 8-9. `student.name` の `.` は何？

```python
print(student.name)
```

は、

> `student` の中にある `name` を使う

という意味です。

```text
student . name
   ↑       ↑
まとまり その中の変数
```

です。

同じように、

```python
student.show_result()
```

は、

> `student` の中にある `show_result` を呼ぶ

という意味です。

---

## 8-10. `self` は今は「このまとまり自身」でよい

サンプルには、

```python
def show_result(self):
    print(self.name, ":", self.score)
```

と `self` が出てきます。

ここは後で詳しく扱います。

今は、

> `self` は「今この処理が使っている、このまとまり自身」

くらいで構いません。

そのため、

```python
self.name
```

は、

> このStudentが持っている `name`

という意味になります。

---

## 8-11. 関数との関係

7章では、関数を、

> 処理をひとまとめにする仕組み

として学びました。

クラスも考え方はかなり近いです。

```text
関数
→ 処理をまとめる

クラス
→ 関係する変数と関数をまとめる
```

です。

だから、クラスを必要以上に特別なものとして考える必要はありません。

---

クラスには、この先、

これらは、モジュールやライブラリを使ったり、もう少し大きなプログラムを書いたりしたあとに学ぶ方が理解しやすくなります。

## 8-13. 自分で変えてみる

変数を1つ追加してみましょう。

```python
class Student:
    name = "たろう"
    score = 80
    class_name = "A"

    def show_result(self):
        print(self.name, ":", self.score)
```

また、別の関数を追加しても構いません。

```python
def show_name(self):
    print(self.name)
```

「同じ話題の変数と関数を1か所へまとめる」感覚を確認してみてください。
