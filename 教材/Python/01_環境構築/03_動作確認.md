# 1-3. Python が動くか確認する

前の [1-2. Python をインストールする](./02_Pythonの導入.md) で、ターミナルの開き方と、Python のバージョンを確認する手順を説明しました。

バージョンが表示されたら、このページでは、ファイルに保存した Python のコードを実行してみます。

---

## VS Code で作業用フォルダを開く

学習用のフォルダを1つ作ります。

例:

```text
Python学習
```

VS Code の **ファイル → フォルダーを開く** から、そのフォルダを開きます。

---

## 最初のファイルを作る

VS Code で `hello.py` を作り、次を書きます。

```python
print("Hello, Python!")
```

保存してください。

---

## ターミナルを開く

VS Code のメニューから **ターミナル → 新しいターミナル** を開きます。

Windows:

```powershell
python hello.py
```

macOS / Linux:

```bash
python3 hello.py
```

次のように表示されれば環境構築は成功です。

```text
Hello, Python!
```

---

## VS Code が使う Python を確認する

複数の Python が入っている場合、VS Code が別の Python を選んでいることがあります。

VS Code のコマンドパレットを開き、

```text
Python: Select Interpreter
```

を選ぶと、使用する Python を選択できます。

環境構築ができたら次へ進みます。
