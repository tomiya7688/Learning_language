# 1-3. Python が動くか確認する

インストールが終わったら、Python が実際に使えるか確認します。

この教材では、基本的に **VS Code の中にあるターミナル** を使ってコマンドを入力します。

---

## VS Code でターミナルを開く

VS Code を起動してください。

画面上部のメニューから、

```text
ターミナル → 新しいターミナル
```

を選びます。

すると、VS Code の画面下側に文字を入力できる場所が表示されます。

Windows では、たとえば次のような表示になることがあります。

```text
PS C:\Users\sample>
```

macOS / Linux では、環境によって表示は異なります。

この行の最後にカーソルが点滅していれば、
そこへコマンドを入力できます。

### どこにコマンドを書くの？

たとえば、

```text
python --version
```

は Python のプログラムを書く場所ではなく、
**今開いたターミナルへ入力します。**

`PS C:\Users\sample>` など、最初から表示されている文字は入力しません。

実際に入力するのは、

```text
python --version
```

の部分だけです。

入力したら Enter キーを押します。

---

## バージョンを確認する

Windows:

```powershell
python --version
```

macOS / Linux:

```bash
python3 --version
```

次のように Python 3 のバージョンが表示されれば、Python 自体は認識されています。

```text
Python 3.x.x
```

---

## VS Code で作業用フォルダを開く

学習用のフォルダを1つ作ります。

例:

```text
Python学習
```

VS Code の **ファイル → フォルダーを開く** から、そのフォルダを開きます。

---

## 最初のファイルを作る

VS Code で `hello.py` を作り、次を書きます。

```python
print("Hello, Python!")
```

保存してください。

---

## ターミナルを開く

VS Code のメニューから **ターミナル → 新しいターミナル** を開きます。

Windows:

```powershell
python hello.py
```

macOS / Linux:

```bash
python3 hello.py
```

次のように表示されれば環境構築は成功です。

```text
Hello, Python!
```

---

## VS Code が使う Python を確認する

複数の Python が入っている場合、VS Code が別の Python を選んでいることがあります。

VS Code のコマンドパレットを開き、

```text
Python: Select Interpreter
```

を選ぶと、使用する Python を選択できます。

環境構築ができたら次へ進みます。
