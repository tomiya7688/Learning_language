# 1. Python の環境構築

この章では、Python のコードを書いて実行できる状態まで準備します。

> **Python入ってないのにPython動かそうとしても、動くわけないやろ！**

まずは「書ける・実行できる」土台を作ります。

一度に全部読む必要はありません。
上から順に進めれば環境構築できます。

1. [Visual Studio Code をインストールする](./01_Visual_Studio_Codeの導入.md)
2. [Python をインストールする](./02_Pythonの導入.md)
3. [Python が動くか確認する](./03_動作確認.md)

ここまで終われば、次の [2. 最初のプログラム](../02_最初のプログラム/最初のプログラム.md) に進めます。

## この教材で使うもの

- Python 3
- Visual Studio Code

Visual Studio Code は Python そのものではなく、
Python のコードを書くためのエディタです。

Python の実行環境と VS Code の両方を用意してから学習を進めます。
