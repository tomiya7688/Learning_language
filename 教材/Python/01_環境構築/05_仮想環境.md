# 1-5. 仮想環境 venv

Python では、プロジェクトごとに使用するライブラリを分けるために **仮想環境** を使えます。

最初の Hello World では必須ではありません。

外部ライブラリを使い始めたときに重要になるため、ここでは作り方だけ紹介します。

## 作成

Windows:

```powershell
python -m venv .venv
```

macOS / Linux:

```bash
python3 -m venv .venv
```

## 有効化

Windows:

```powershell
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

有効になると、ターミナルの先頭に次のような表示が出ることがあります。

```text
(.venv)
```

## 終了

```text
deactivate
```

仮想環境については、**[14章「モジュール・pip・外部ライブラリ」](../14_モジュール・pip・外部ライブラリ/モジュール・pip・外部ライブラリ.md)** でも、pipと一緒に改めて説明します。
