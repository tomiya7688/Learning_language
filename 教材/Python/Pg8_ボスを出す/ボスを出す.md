# Pg8. pygame「ボスを出す」

Pg7では、敵が順番に出てくるようになりました。

でも、通常敵が全部いなくなったあとに何も起きません。

> **「雑魚全部倒した。で、終わり？？？」**

今回は、通常敵の出現が全部終わり、画面上に通常敵がいなくなったらボスを出します。

複雑なAIはまだやりません。

まずは、

> **最後にHPの多い大きな敵が出る**

だけで、1本のゲームとして締まることを体験します。

---

## Pg8-1. 今回作るもの

[boss_battle.py](./boss_battle.py) を開いてください。

`boss` は「ボス」、`battle` は「戦い」という意味です。

今回は、

```text
通常敵が順番に出る
↓
出現予定を全部出し終える
↓
画面上から通常敵がいなくなる
↓
ボス出現
↓
ボスHPを0にする
↓
ゲームクリア
```

まで作ります。

---

## Pg8-2. 「全部出し終えた」を見る

```python
total_enemies = len(spawn_positions)
```

で、出現予定の敵の総数を持っています。

`spawn_index` は「何体目まで出したか」でした。

なので、

```python
spawn_index >= total_enemies
```

なら、

> **出す予定の通常敵は全部出し終えた**

と判断できます。

---

## Pg8-3. 倒し損ねても宇宙空間に取り残さない

ボス出現を「倒した数」で決めると、1体でも画面下へ逃した瞬間に条件を満たせなくなります。

> **「1体逃しただけでボス一生来ないん？？？」**

それは進行不能です。

だから今回は、

> **全部出し終えた + 画面上に通常敵がいない**

をボス出現条件にします。

---

## Pg8-4. ボス用の変数

```python
boss_active = False
boss_x = 320
boss_y = 90
boss_hp = 20
```

を用意します。

`boss_active` は、

> 今ボスが出ているか

を表します。

最初は `False` です。

---

## Pg8-5. 条件が揃ったらボス出現

```python
if (
    spawn_index >= total_enemies
    and not enemies
    and not boss_active
):
    boss_active = True
```

で、

- 出す予定の通常敵を全部出し終えた
- 今、画面上に通常敵が残っていない
- まだボスが出ていない

ならボスを出します。

---

## Pg8-6. ボスは大きく描く

```python
if boss_active:
    pygame.draw.rect(
        screen,
        (180, 80, 255),
        (boss_x - 60, boss_y - 30, 120, 60)
    )
```

通常敵よりかなり大きい四角形にします。

今は見た瞬間に、

> **「こいつだけデカい。ボスだな」**

と分かれば十分です。

---

## Pg8-7. ボスにもRectを作る

```python
boss_rect = pygame.Rect(
    boss_x - 60,
    boss_y - 30,
    120,
    60
)
```

でボス用の当たり判定を作ります。

---

## Pg8-8. 弾が当たったらHPを減らす

```python
if bullet_rect.colliderect(boss_rect):
    bullets_to_remove.append(bullet)
    boss_hp = boss_hp - 1
```

通常敵は1発で消えましたが、ボスはすぐ消えません。

> **「ボスなんだから1発で消えたら困る！」**

ということで、HPを持たせます。

---

## Pg8-9. ボスHPを表示する

```python
boss_text = font.render(
    f"BOSS HP: {boss_hp}",
    True,
    (255, 255, 255)
)
```

として、画面上に表示します。

これで、

> あと何発くらい必要か

が分かります。

---

## Pg8-10. ボスを倒したらクリア

```python
if boss_active and boss_hp <= 0:
    game_clear = True
    running = False
```

とします。

今回は最低限なので、専用のクリア画面はまだ作りません。

まずは、

> **最後の強い敵を倒したら終わる**

というゲームの区切りを作ります。

---

## Pg8-11. ボスも「通常敵の延長」

今回のボスは、特別な魔法を使うわけでも複雑なAIを持つわけでもありません。

やっていることは、

```text
座標がある
↓
大きさがある
↓
Rectがある
↓
弾と当たる
↓
HPが減る
```

です。

つまり、

> **普通の敵を少し大きくして、HPを持たせたもの**

として考えられます。

---

## Pg8-12. これで1本のゲームになる

ここまでで、

```text
プレイヤーを動かす
↓
撃つ
↓
敵が出る
↓
敵も撃つ
↓
通常敵を倒す
↓
ボスが出る
↓
ボスを倒す
↓
クリア
```

までつながりました。

まだ見た目は図形だけですが、

> **ゲームの流れ自体はほぼ完成**

です。

---

## Pg8-13. 次はわざと壊す

今のボスは、まだ普通です。

次のPg9では、わざと

> **ボスの弾がデカすぎて画面を覆い尽くす**

状態にします。

そして、

> **実装できることと、遊べることは別**

を体験します。

---

## Pg8-14. ここまでで覚えること

1. `spawn_index` と `total_enemies` で通常敵を全部出し終えたか判断できる
2. 条件が揃ったらボスを出せる
3. `boss_active` で出現状態を管理できる
4. ボスは通常敵より大きく描けば見分けやすい
5. ボスにはHPを持たせられる
6. 弾が当たるたびにHPを減らせる
7. ボスHPが0になったらゲームクリアにできる
8. ボスも通常敵の延長として考えられる
