# 12. ファイルの読み書き

この章では、**プログラムを終了してもデータを残す方法**を学びます。

今回作るのは、文字をテキストファイルへ保存して、あとからその内容を読み込む小さなプログラムです。

---

## 12-1. 今回作るもの

まず、次の文字をファイルへ保存します。

```text
こんにちは
Pythonを勉強中です
```

保存したあと、そのファイルをもう一度開いて内容を読み込みます。

実行すると、

```text
保存しました
読み込んだ内容:
こんにちは
Pythonを勉強中です
```

のように表示されます。

---

## 12-2. なぜファイルが必要なの？

ここまでの変数、リスト、辞書はとても便利です。

でも、プログラムを終了すると、その中に入っていたデータは消えます。

たとえば、

```python
name = "たろう"
```

と保存しても、プログラムを閉じて次の日に起動したら、その `name` は残っていません。

> 「昨日入力したのに、また最初から？」

となります。

そこで使うのが **ファイル** です。

ファイルへ書き込めば、プログラムが終了してもデータを残せます。

---

## 12-3. サンプルコード

[file_io.py](./file_io.py) を開いてください。

`file` は「ファイル」、`io` は Input / Output、つまり「入力と出力」という意味です。

```python
file_name = "message.txt"

with open(file_name, "w", encoding="utf-8") as file:
    file.write("こんにちは\n")
    file.write("Pythonを勉強中です\n")

print("保存しました")

with open(file_name, "r", encoding="utf-8") as file:
    text = file.read()

print("読み込んだ内容:")
print(text)
```

---

## 12-4. `open()` でファイルを開く

ファイルを扱うときは、`open()` を使います。

```python
open(file_name, "w", encoding="utf-8")
```

ここでは、

- どのファイルを使うか
- 書き込みか読み込みか
- 文字コードは何か

を指定しています。

---

## 12-5. `"w"` は書き込み

```python
with open(file_name, "w", encoding="utf-8") as file:
```

の `"w"` は write、つまり「書き込み」です。

このモードでファイルを開くと、そのファイルへ文字を書けます。

ただし、同じ名前のファイルがすでにある場合は、内容が上書きされます。

今は、

> `"w"` = 書き込み用

と覚えておけば十分です。

---

## 12-6. `.write()` で文字を書く

ファイルへ文字を書くには、`.write()` を使います。

```python
file.write("こんにちは\n")
```

これで、

```text
こんにちは
```

という文字がファイルへ保存されます。

---

## 12-7. `\n` は改行

```python
"こんにちは\n"
```

の `\n` は改行を表します。

```python
file.write("こんにちは\n")
file.write("Pythonを勉強中です\n")
```

と書くと、ファイルの中は、

```text
こんにちは
Pythonを勉強中です
```

のように2行になります。

---

## 12-8. なぜ `with` を使うの？

ファイルを開いたら、使い終わったあとに閉じる必要があります。

`with` を使うと、その処理をPythonに任せられます。

```python
with open(file_name, "w", encoding="utf-8") as file:
    file.write("こんにちは\n")
```

このブロックを抜けると、ファイルは自動で閉じられます。

つまり、

> 開く → 使う → 閉じる

を安全にまとめやすくするのが `with` です。

---

## 12-9. `as file` とは

```python
with open(file_name, "w", encoding="utf-8") as file:
```

の `as file` は、

> 開いたファイルを `file` という名前で使う

という意味です。

そのため、その中で、

```python
file.write(...)
```

と書けます。

---

## 12-10. `"r"` は読み込み

保存したファイルを読むときは、`"r"` を使います。

```python
with open(file_name, "r", encoding="utf-8") as file:
```

`r` は read、つまり「読み込み」です。

---

## 12-11. `.read()` で内容を全部読む

```python
text = file.read()
```

とすると、ファイルの内容をまとめて読み込めます。

読み込んだ文字列を `text` に保存して、

```python
print(text)
```

で表示できます。

---

## 12-12. UTF-8とは

今回、

```python
encoding="utf-8"
```

と書いています。

これは、文字をどのルールで保存・読み込みするかを指定しています。

文字コードが合っていないと、日本語が文字化けすることがあります。

この教材では、基本的に **UTF-8** を使います。

今は、

> 日本語を安全に扱うため、`encoding="utf-8"` を付ける

と覚えておけば十分です。

---

## 12-13. 相対パスとは

今回のファイル名は、

```python
file_name = "message.txt"
```

です。

フォルダ名を書いていません。

このように、今いる場所を基準にした指定を **相対パス** と呼びます。

今回のプログラムを、

```text
12_ファイルの読み書き/
├─ file_io.py
└─ message.txt
```

のような形で使うイメージです。

---

## 12-14. 「今いる場所」が大事

相対パスは、**どこからPythonを実行したか**によって意味が変わります。

ここで初学者がよく混乱します。

たとえば `file_io.py` が、

```text
C:\study\Python\12_ファイルの読み書き
```

にあるなら、そのフォルダへ移動してから実行すると分かりやすいです。

Windowsなら、

```text
cd "C:\study\Python\12_ファイルの読み書き"
python file_io.py
```

のようにします。

macOS / Linuxなら、

```text
cd "/home/user/study/Python/12_ファイルの読み書き"
python3 file_io.py
```

のようにします。

---

## 12-15. パスが分からないとき

Windowsなら、エクスプローラーで `file_io.py` のあるフォルダを開き、上部のアドレス欄からパスをコピーできます。

そのあと、ターミナルで、

```text
cd "コピーしたパス"
```

と入力します。

`cd` は、ターミナルで作業するフォルダを移動するためのコマンドです。

---

## 12-16. 実行してみる

Windows:

```text
python file_io.py
```

または、

```text
py file_io.py
```

macOS / Linux:

```text
python3 file_io.py
```

実行すると、同じフォルダに `message.txt` が作られます。

プログラムを実行したあと、`message.txt` をメモ帳やVS Codeで開いてください。

## 12-18. サンプルデータから読み込む

この章には [sample_message.txt](./sample_message.txt) も用意します。

内容は、

```text
これはサンプルファイルです。
Pythonから読み込めます。
```

です。

たとえば、

```python
with open("sample_message.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(text)
```

とすれば、最初から用意されたファイルを読むこともできます。

---

## 12-19. 上書きしたくない場合は？

`"w"` は、同名ファイルがあると内容を上書きします。

あとから追記したい場合は `"a"` を使う方法もあります。

```python
with open("message.txt", "a", encoding="utf-8") as file:
    file.write("追加の文章です\n")
```

`a` は append、つまり「追記」です。

今回は、まず `"w"` と `"r"` が使えれば十分です。

---

## 12-20. ファイルが存在しないとどうなる？

`"r"` で存在しないファイルを開こうとすると、エラーになります。

たとえば、

```python
open("not_found.txt", "r", encoding="utf-8")
```

で、そのファイルが無ければプログラムは止まります。

このような問題を安全に扱う方法は、次の**例外処理**で学びます。

この章では、次のことが分かれば十分です。
