# 同じ挨拶のコードを何度も書かずに使いたい

たろうとさくらへの挨拶を表示します。挨拶の処理を1か所に書き、名前を変えて2回使います。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備します。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開きます（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# greet は「挨拶する」、name は「名前」という意味
# greet という名前で、name を受け取り、下の処理を行う関数を定義する
def greet(name):
    # 「こんにちは」と name を表示する
    print("こんにちは", name)

# name に「たろう」を指定して greet を呼び出す
greet("たろう")
# name に「さくら」を指定して greet を呼び出す
greet("さくら")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `reuse_greeting.py` という名前で保存します。ファイル名の最後は `.py` にします。

reuse は「もう一度使う」、greeting は「挨拶」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./reuse_greeting.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

### 保存先フォルダのパスをコピーする

`reuse_greeting.py` を保存したフォルダの場所を、次の操作でコピーします。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックします。表示されたフォルダのパス全体を選び、Ctrl + C を押します。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーします。ファイルではなくフォルダを選びます。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーします。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力します。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けます。入力し終えたら Enter キーを押します。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しません。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python reuse_greeting.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 reuse_greeting.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
こんにちは たろう
こんにちは さくら
```

## このコードの読み方

Pythonでは、文字の並びを値として扱うとき、その値を **文字列** と呼びます。コードの中では `"こんにちは"` のように引用符で囲んで書きます。

`print(...)` は、`()` の中で指定した内容をターミナルに表示します。このように、名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。`def greet(name):` は、自分で書いた処理を `greet` という名前で呼び出せるようにする行です。

`def 名前(受け取る内容の名前):` と書き、実行する処理をその下に右へずらして書きます。行頭の空白でまとまりを示す書き方を **インデント** と呼びます。ここでは表示の行の前に半角の空白を4つ入れます。

`greet("たろう")` と書くと、`greet` の中の `name` が「たろう」になり、その下の表示処理を実行します。`name` のように、内容をあとで使うための名前を **変数** と呼びます。`greet` の中の `name` は、その呼び出しで指定した名前を使うためのものです。

`def` の下に書いた処理は、定義しただけでは実行されません。そのあとに `greet(...)` と書いて呼び出します。今回は2人に挨拶するため2回呼び出していますが、挨拶を変更する場所は関数の中の1か所だけです。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

`greet` の中の挨拶を変えます。呼び出す側の2行はそのままです。

VS Codeで `reuse_greeting.py` を開き、**5行目**を探します。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押します。検索欄に次の文字を入力して、対象の行を探します。

```text
print(
```

対象の行と、その直上の処理コメントを、次のように置き換えます。行頭の半角の空白4つも残してください。

変更前：

```python
    # 「こんにちは」と name を表示する
    print("こんにちは", name)
```

変更後：

```python
    # 「おはよう」と name を表示する
    print("おはよう", name)
```

## 保存してもう一度実行する

VS Codeで `reuse_greeting.py` を保存します。Windows / Linuxは Ctrl + S、macOSは Command + S を押します。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

保存先フォルダへ移動済みなら、次の実行コマンドへ進みます。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押します。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python reuse_greeting.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 reuse_greeting.py
```

同じターミナルに次の結果が表示されます。

```text
おはよう たろう
おはよう さくら
```
