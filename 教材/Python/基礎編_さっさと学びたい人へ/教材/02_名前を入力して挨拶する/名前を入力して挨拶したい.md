# 名前を入力して挨拶したい

コードに「たろう」と書いた挨拶は、さくらが使っても「こんにちは たろう」のままです。使う人が変わるたびにコードを書き換えるのは面倒です。

> **「私の名前で表示したい！名前を入力させて！」**

このプログラムは、ターミナルで入力した名前を使って挨拶します。名前だけを入力し直して、別の人への挨拶に変えられます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`greet_name.py` の 1〜6行](./greet_name.py#L1-L6)。

```python
# name は「名前」という意味
# name に「名前を入力してください: 」と表示して入力された内容を入れる
name = input("名前を入力してください: ")

# 「こんにちは」と name を表示する
print("こんにちは", name)
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `greet_name.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

greet は「挨拶する」、name は「名前」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./greet_name.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`greet_name.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python greet_name.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 greet_name.py
```

## 実行結果

`名前を入力してください: ` が表示されたら、同じターミナルで **たろう** と入力し、Enter キーを押してください。例の1行目のうち、`たろう` だけが自分で入力する部分です。名前は引用符で囲まずに入力してください。

```text
名前を入力してください: たろう
こんにちは たろう
```

## このコードの読み方

Pythonでは、文字の並びを値として扱うとき、その値を **文字列** と呼びます。コードの中では `"こんにちは"` のように引用符で囲んで書いてください。

`input("名前を入力してください: ")` は、`()` の中で指定した案内を表示して、ターミナルでの入力を待ちます。Enter キーを押すと、入力した内容を文字列として受け取ります。

`name = ...` は、右側の処理で受け取った内容に `name` という名前を付けます。あとでその内容を使うための名前を **変数** と呼びます。ここでは `name` を使うと入力した名前を使えます。`=` は右側の内容を左側の名前に対応させる書き方です。

`print("こんにちは", name)` は、2つの内容をカンマで区切って指定しています。「こんにちは」と入力した名前の間に空白を入れて表示します。

`input(...)` や `print(...)` のように名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

名前の前に表示する挨拶を変えてください。

VS Codeで `greet_name.py` を開き、**6行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
print(
```

[`greet_name.py` の5〜6行](./greet_name.py#L5-L6)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`greet_name.py` の 5〜6行](./greet_name.py#L5-L6)。

```python
# 「こんにちは」と name を表示する
print("こんにちは", name)
```

変更後：

変更する場所：[`greet_name.py` の 6行](./greet_name.py#L6-L6)。

```python
# 「おはよう」と name を表示する
print("おはよう", name)
```

## 保存してもう一度実行する

VS Codeで `greet_name.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python greet_name.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 greet_name.py
```

再び名前を聞かれたら、同じターミナルで **さくら** と入力し、Enter キーを押してください。

```text
名前を入力してください: さくら
おはよう さくら
```
