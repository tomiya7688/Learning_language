# 「終了」と入力するまで、入力と表示を続けたい

入力したメモを表示するたびにプログラムが終わったら、次のメモを試すために毎回起動し直すことになります。

> **「まだ次を入力したい！終わるかどうかは自分で決めたい！」**

このプログラムは、ターミナルで入力した内容を表示して、次の入力を待ちます。「終了」と入力したときに、入力の繰り返しを終えます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`repeat_input.py` の 1〜15行](./repeat_input.py#L1-L15)。

```python
# answer は「返答」という意味
# answer に何も文字がない文字列を入れる
answer = ""

# answer が「終了」でない間、下の処理を繰り返す
while answer != "終了":
    # answer に「終了するには「終了」と入力してください: 」と表示して入力された内容を入れる
    answer = input("終了するには「終了」と入力してください: ")
    # answer が「終了」でなければ、次の行を実行する
    if answer != "終了":
        # 「入力した内容:」と answer を表示する
        print("入力した内容:", answer)

# 「終了しました」と表示する
print("終了しました")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `repeat_input.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

repeat は「繰り返す」、input は「入力」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./repeat_input.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`repeat_input.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python repeat_input.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 repeat_input.py
```

## 実行結果

最初の案内が出たら、同じターミナルで **おはよう** と入力し、Enter キーを押してください。再び案内が出たら、**終了** と入力し、Enter キーを押してください。例のうち、案内の後ろの `おはよう` と `終了` が自分で入力する部分です。

```text
終了するには「終了」と入力してください: おはよう
入力した内容: おはよう
終了するには「終了」と入力してください: 終了
終了しました
```

## このコードの読み方

Pythonでは、文字の並びを値として扱うとき、その値を **文字列** と呼びます。コードの中では `"こんにちは"` のように引用符で囲んで書いてください。

`answer = ""` は、何も文字がない文字列に `answer` という名前を付けます。あとで内容を使うための名前を **変数** と呼びます。最初から「終了」にしてしまうと一度も入力を待たないので、ここでは空の文字列から始めます。

`while 条件:` は、条件に当てはまる間、その下の右にずらした処理を繰り返します。`!=` は「同じではない」を確認する記号です。繰り返す前に毎回条件を確認するので、`answer` が「終了」になったら次の入力へ進みません。

`input(...)` は案内を表示して入力を待ち、Enter キーで確定した内容を文字列として受け取ります。Pythonはその内容で `answer` を更新します。`if answer != "終了":` は、入力が「終了」ではないときだけ表示する指定です。`print(...)` は指定した内容をターミナルに表示します。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

行頭の空白で処理のまとまりを示す書き方を **インデント** と呼びます。`while` の中は半角の空白4つ、さらにその中の `if` の表示行は8つです。最後の表示行は左端に戻して書くので、繰り返しが終わってから1回だけ実行されます。

次の案内が出たら、そのターミナルに内容を入力して Enter キーを押してください。途中で強制的に止めたい場合は、ターミナル内をクリックして Ctrl + C を押してください（macOSでも Ctrl + C）。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。


[`repeat_input.py` の14〜15行](./repeat_input.py#L14-L15)のコードを、次の内容に置き換えてください。

```python
# 「終了しました」と表示する
print("終了しました")
```

変更後：
