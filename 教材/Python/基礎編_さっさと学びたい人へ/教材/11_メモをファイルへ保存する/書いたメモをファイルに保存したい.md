# 書いたメモをファイルに保存したい

「こんにちは」というメモを、練習用の `purpose_memo.txt` に保存します。プログラムを終了しても、保存した内容をあとから読めます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備します。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

この例は練習用の `purpose_memo.txt` を作り、同じ名前のファイルがあれば中身を書き直します。自分のメモなどと分けるため、新しい練習用フォルダを作り、その中へサンプルを保存して実行します。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開きます（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# file は「ファイル」という意味
# purpose_memo.txt をUTF-8で書き込み用に開き、file という名前で使う
with open("purpose_memo.txt", "w", encoding="utf-8") as file:
    # file が表すファイルへ「こんにちは」と改行を書き込む
    file.write("こんにちは\n")

# 「purpose_memo.txt に保存しました」と表示する
print("purpose_memo.txt に保存しました")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `save_memo.py` という名前で保存します。ファイル名の最後は `.py` にします。

save は「保存する」、memo は「メモ」という意味です。`.py` はPythonのコードを書いたファイルの末尾に付けます。保存先の `purpose_memo.txt` の purpose は「目的」という意味で、この例で使うメモのファイル名です。

[サンプルファイルを開く](./save_memo.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

### 保存先フォルダのパスをコピーする

`save_memo.py` を保存したフォルダの場所を、次の操作でコピーします。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックします。表示されたフォルダのパス全体を選び、Ctrl + C を押します。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーします。ファイルではなくフォルダを選びます。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーします。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力します。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けます。入力し終えたら Enter キーを押します。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しません。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python save_memo.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 save_memo.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
purpose_memo.txt に保存しました
```

VS Codeで **ファイル→ファイルを開く** を選び、練習用フォルダの `purpose_memo.txt` を開くと、次の内容が読めます。

```text
こんにちは
```

## このコードの読み方

`open("purpose_memo.txt", "w", encoding="utf-8")` は、指定したファイルを書き込み用に開きます。ファイルがなければ作り、すでにあれば中身を新しく書き直します。`"w"` は書き込み、`encoding="utf-8"` は日本語の保存に使う文字の記録方法を指定しています。

`as file` は、開いたファイルを `file` という名前で使う指定です。このように値を使うための名前を **変数** と呼びます。`file.write(...)` は、そのファイルへ `()` の中で指定した内容を書き込みます。引用符で囲んで書いた文字の並びを **文字列** と呼び、`\n` は改行を表します。

`with ...:` の下に右へずらして書いた処理が終わると、ファイルは自動的に閉じられます。行頭の空白で処理のまとまりを示す書き方を **インデント** と呼びます。書き込む行の前には半角の空白を4つ入れます。

`print(...)` は、保存したことをターミナルに表示します。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。ファイルの名前だけを指定しているため、保存先はターミナルで `cd` した練習用フォルダです。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

保存するメモを変えます。行頭の空白4つも残してください。

VS Codeで `save_memo.py` を開き、**5行目**を探します。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押します。検索欄に次の文字を入力して、対象の行を探します。

```text
file.write(
```

対象の行と、その直上の処理コメントを、次のように置き換えます。

変更前：

```python
    # file が表すファイルへ「こんにちは」と改行を書き込む
    file.write("こんにちは\n")
```

変更後：

```python
    # file が表すファイルへ「明日はPythonを勉強する」と改行を書き込む
    file.write("明日はPythonを勉強する\n")
```

## 保存してもう一度実行する

VS Codeで `save_memo.py` を保存します。Windows / Linuxは Ctrl + S、macOSは Command + S を押します。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

保存先フォルダへ移動済みなら、次の実行コマンドへ進みます。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押します。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python save_memo.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 save_memo.py
```

同じターミナルに次の結果が表示されます。

```text
purpose_memo.txt に保存しました
```

VS Codeで `purpose_memo.txt` を開き直すと、内容は次のように変わっています。

```text
明日はPythonを勉強する
```
