# 完成したシューティングゲームを動かして読む

矢印キーで自機を動かし、Spaceキーで弾を撃ってボスを倒すゲームを使います。最初に完成したゲームを動かし、その後は同じファイルを先頭から読んで変更します。

## ここから始める

PythonとVS Codeをまだ使えない場合は、コードを書いて実行する準備をします。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

準備ができたら、1のページでコードと画像を保存し、ゲームを起動します。

[進む：1. 完成ゲームを保存して遊ぶ](./01_完成ゲームを動かす.md)

ゲームが動いたら、2のページでコードの先頭を読み、ウィンドウのタイトルと見出しの大きさを変更します。

[進む：2. 画面・時計・文字の準備を読む](./02_画面と文字の準備を読む.md)

次は、画像の場所と読み込みを読み、自機に使う画像を変更します。

[進む：3. 背景・自機・敵・ボスの画像を読み込む](./03_画像の読み込みを読む.md)

## 続きの公開状況

現在公開しているのは、ゲームの保存・起動、画面・時計・フォントの準備、背景と自機・敵・ボスの画像の読み込みを扱う3章です。位置や速さ、敵、入力、画面の切り替え、移動、当たり判定、描画を順に読む専用の章は未公開です。
