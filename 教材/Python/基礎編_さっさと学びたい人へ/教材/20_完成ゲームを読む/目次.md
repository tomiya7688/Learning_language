# 完成したシューティングゲームを動かして読む

> **「ゲームは動いたけど、どこから読めば自分で変えられるの？」**

矢印キーで自機を動かし、Spaceキーで弾を撃ってボスを倒すゲームが、この系列の題材です。最初に完成したゲームを動かしてください。次に、起動に使う `main.py`、ゲーム全体の進行を行う `game.py`、画像を読み込む `resources.py`、自機の開始位置と速さを決める `settings.py` と `player.py` の順に読んでください。

## ここから始める

PythonとVS Codeをまだ使えない場合は、コードを書いて実行する準備をしてください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

準備ができたら、1のページでコードと画像を保存し、ゲームを起動してください。

[進む：1. 完成ゲームを保存して遊ぶ](./01_完成ゲームを動かす.md)

ゲームが動いたら、2のページで `main.py` の `main()`、`game.py` の `Game`、タイトル画面を読み、ウィンドウのタイトルと見出しの大きさを変更してください。

[進む：2. 画面・更新速度・文字の準備を読む](./02_画面と文字の準備を読む.md)

次は、画像の場所と読み込みを読み、自機に使う画像を変更してください。

[進む：3. 背景・自機・敵・ボスの画像を読み込む](./03_画像の読み込みを読む.md)

自機を左から始め、矢印キーでの移動を速くする場合は、第4章で `settings.py` の設定と `player.py` の使い方を読んでください。

[進む：4. 自機の開始位置と移動の速さを変える](./04_自機の位置と速さを読む.md)

## 続きの公開状況

現在公開しているのは、ゲームの保存・起動、画面・更新速度・フォントの準備、背景と自機・敵・ボスの画像の読み込み、自機の開始位置・方向ごとの移動量・画面端で止める処理を扱う4章です。敵の出現順や弾の動き、画面の切り替え・当たり判定・描画を詳しく読む続編は未公開です。
