# 1. 完成ゲームを保存して遊ぶ

完成したシューティングゲームを保存して動かします。起動すると、パソコンの画面上にゲーム用の枠が開きます。この枠を「ウィンドウ」と呼びます。矢印キーで自機を動かし、Spaceキーで弾を撃って敵とボスを倒します。倒されても、タイトルへ戻ってもう一度遊べます。

PythonとVS Codeをまだ使えない場合は、先に準備します。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードと画像を保存する

1. パソコンに練習用の新しいフォルダを作ります。Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderで **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選びます。ここでは `shooting_practice` という名前にします。shooting は「射撃」、practice は「練習」という意味です。
2. 下の完成コードへのリンクを開きます。GitHubのファイル画面では **Raw** を開き、コードだけが表示された状態にします。
3. Windows / Linuxでは Ctrl + A、Ctrl + C、macOSでは Command + A、Command + C を押して、コード全体をコピーします。
4. VS Codeで新しいファイルを開きます（Windows / Linuxは Ctrl + N、macOSは Command + N）。コピーしたコード全体を貼り付けます（Windows / Linuxは Ctrl + V、macOSは Command + V）。
5. Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `clear_title.py` という名前で保存します。clear は「クリア」、title は「タイトル」という意味です。末尾の `.py` まで入力します。

[完成コードを開く：clear_title.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/clear_title.py)

このファイルには、ゲームを始める画面、プレイヤー・弾・敵・ボス、クリアとゲームオーバーの処理が入っています。この後の章でも、このファイルを編集します。

練習用フォルダの中に `assets` というフォルダを作ります。assets は「素材」という意味で、ここにゲームで使う画像を置きます。

下のリンクを1つずつ開き、表示された画像を右クリックして **名前を付けて画像を保存** を選びます。保存先を `assets` にし、リンクに書かれたファイル名のまま保存してください。4枚とも必要です。

[背景を保存：space_background.png（space＝宇宙、background＝背景）](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/space_background.png?raw=true)

[自機を保存：player_ship.png（player＝プレイヤー、ship＝船）](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/player_ship.png?raw=true)

[通常の敵を保存：enemy_ship.png（enemy＝敵）](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/enemy_ship.png?raw=true)

[ボスを保存：boss_ship.png（boss＝ボス）](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/boss_ship.png?raw=true)

保存後は、次の配置になります。

```text
shooting_practice/
├ clear_title.py
└ assets/
  ├ space_background.png
  ├ player_ship.png
  ├ enemy_ship.png
  └ boss_ship.png
```

`clear_title.py` と `assets` は同じフォルダに置きます。画像ファイルをPythonのコード欄へ貼り付ける必要はありません。このゲームでは音声ファイルを用意しません。

[画像の出所とライセンスを見る](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/README.md)

## 保存先のフォルダへターミナルを移動する

ターミナルは、文字で操作を入力する場所です。これからのコマンドは、コードを書いた欄へ入力せず、VS Codeの **表示（View）→ ターミナル（Terminal）** で開いたターミナルへ入力します。

`clear_title.py` が入っている練習用フォルダの場所をコピーします。場所を書いた文字列を「パス」と呼びます。`assets` の場所ではなく、`shooting_practice` の場所を使います。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックし、フォルダのパス全体を Ctrl + C でコピーします。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でそのフォルダのパスをコピーします。ファイルではなくフォルダを選びます。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の入力欄を出し、Ctrl + C でフォルダのパスをコピーします。

VS Codeのターミナルを開き、次の形で入力します。引用符の中を、上の操作でコピーしたフォルダのパスに置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けます。入力したら Enter キーを押します。

```text
cd "コピーした練習用フォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しません。

## ゲームを描く道具を追加して起動する

このゲームは、画面の描画やキー入力に **pygame-ce** という追加の道具を使います。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。

練習用フォルダの `.venv` に、このゲーム用のPython実行環境を作ります。その環境へpygame-ceを追加し、同じ環境のPythonでゲームを動かします。追加するときはインターネット接続が必要です。

### Windows

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
python -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加します。

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行します。

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
.\.venv\Scripts\python.exe clear_title.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
python3 -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加します。

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
.venv/bin/python -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行します。

1. VS Codeのターミナルを開き、次のコマンドを入力します。
2. Enter キーを押します。

```text
.venv/bin/python clear_title.py
```

各コマンドでエラーが表示された場合は、その段階の用意ができていません。次のコマンドへ進む前に、下の「起動できないとき」を確認します。

## ゲームで遊ぶ

起動すると、暗い背景のゲーム画面に、`SPACE SHOOTER`（宇宙のシューティングゲーム）、`Defeat the boss!`（ボスを倒そう！）、青いSTART（始める）ボタンが表示されます。

| 操作 | 起きること |
| --- | --- |
| STARTの内側を左クリック | ゲームが始まる |
| ゲーム中に矢印キーを押す | 自機が上下左右へ動く |
| ゲーム中にSpaceキーを押す | 自機から弾が1発出る |
| ゲームのウィンドウを閉じる | プログラムが終了する |

矢印キーとSpaceキーは、ゲームのウィンドウをクリックしてから押します。弾を続けて撃つ場合は、Spaceキーを押して離す操作を繰り返します。タイトル画面でSpaceキーを押しても始まりません。

HPは、攻撃を受けると減る数値です。0になると自機は倒されます。自機のHPは3から始まります。通常の敵を倒すか画面外へ通過させ、最後の敵もいなくなるとボスが現れます。自機の弾を当てて、ボスのHPを0にします。

自機のHPを残してボスを倒すと、`GAME CLEAR!`（ゲームクリア）、`You defeated the boss!`（ボスを倒した！）、TITLE（タイトル）ボタンが出ます。TITLEの内側を左クリックするとタイトル画面へ戻ります。

自機のHPが0になると、`GAME OVER`（ゲームオーバー）が出ます。左のRESTART（再開）を左クリックすると、そのまま新しいゲームが始まります。右のTITLEを左クリックするとタイトル画面へ戻ります。同じ更新で自機とボスのHPが両方0になった場合は、ゲームオーバーになります。

もう一度STARTを押すと、自機のHPと位置が最初の状態に戻り、前の敵や弾も消えます。

## 起動できないとき

| 表示・状況 | 確認すること |
| --- | --- |
| `python` / `python3` が見つからない | ページ上部のPythonの準備手順を開き、インストールを確認する。インストール後はVS Codeを開き直す |
| `No module named venv` / `ensurepip` のエラー | 専用の実行環境を作るための機能が不足している。Pythonの配布元やOSの案内に従ってvenvを用意する |
| `pip install` が失敗する | ターミナルのエラーを確認する。接続できない場合は通信環境、対応する配布物がない場合はPythonとpygame-ceの対応バージョンを確認する |
| `No module named pygame` | pygame-ceを追加したPythonと、実行に使ったPythonが同じか確認する。このページの `.venv` のコマンドで追加・実行する |
| `No such file or directory` で画像名が出る | `clear_title.py` の隣に `assets` があり、その中に4枚のPNGがあるか確認する |
| 画像を読み込めない | PNGではなくGitHubのページ自体を保存していないか確認する。画像リンクから画像を開き、画像として保存し直す |
| ファイルが見つからない | ターミナルの `cd` 先に `clear_title.py` があるか、末尾が `.py.txt` になっていないか確認する |
