# 1. 完成ゲームを保存して遊ぶ

> **「ゲームのコードはあるのに遊べない！何を保存して、どう起動するの？」**

完成したシューティングゲームを保存して動かしてください。起動すると、パソコンの画面上にゲーム用の枠が開きます。この枠を「ウィンドウ」と呼びます。矢印キーで自機を動かし、Spaceキーで弾を撃って敵とボスを倒すゲームです。倒されても、タイトルへ戻ってもう一度遊べます。

PythonとVS Codeをまだ使えない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードと画像を保存する

1. パソコンに練習用の新しいフォルダを作ってください。Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderで **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。ここでは `shooting_practice` という名前にしてください。shooting は「射撃」、practice は「練習」という意味です。
2. 下の表のPythonファイルを1つずつ開いてください。GitHubのファイル画面では **Raw** を開き、コードだけが表示された状態にしてください。
3. Windows / Linuxでは Ctrl + A、Ctrl + C、macOSでは Command + A、Command + C を押して、コード全体をコピーしてください。
4. VS Codeで新しいファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。コピーしたコード全体を貼り付けてください（Windows / Linuxは Ctrl + V、macOSは Command + V）。
5. Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに、下の表と同じ名前で保存してください。clear は「クリア」、title は「タイトル」という意味です。末尾の `.py` まで入力してください。

## 保存先のフォルダへターミナルを移動する

ターミナルは、文字で操作を入力する場所です。これからのコマンドは、コードを書いた欄へ入力せず、VS Codeの **表示（View）→ ターミナル（Terminal）** で開いたターミナルへ入力してください。

`clear_title.py` が入っている練習用フォルダの場所をコピーしてください。場所を書いた文字列を「パス」と呼びます。`assets` の場所ではなく、`shooting_practice` の場所を使ってください。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックし、フォルダのパス全体を Ctrl + C でコピーしてください。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でそのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の入力欄を出し、Ctrl + C でフォルダのパスをコピーしてください。

VS Codeのターミナルを開き、次の形で入力してください。引用符の中を、上の操作でコピーしたフォルダのパスに置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力したら Enter キーを押してください。

```text
cd "コピーした練習用フォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

## ゲームを描く道具を追加して起動する

このゲームは、画面の描画やキー入力に **pygame-ce** という追加の道具を使います。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。

練習用フォルダの `.venv` に、このゲーム用のPython実行環境を作ってください。その環境へpygame-ceを追加し、同じ環境のPythonでゲームを動かしてください。追加するときはインターネット接続が必要です。

### Windows

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe clear_title.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python clear_title.py
```

各コマンドでエラーが表示された場合は、その段階の用意ができていません。次のコマンドへ進む前に、下の「起動できないとき」を確認してください。

## ゲームで遊ぶ

起動すると、暗い背景のゲーム画面に、`SPACE SHOOTER`（宇宙のシューティングゲーム）、`Defeat the boss!`（ボスを倒そう！）、青いSTART（始める）ボタンが表示されます。

| 操作 | 起きること |
| --- | --- |
| STARTの内側を左クリック | ゲームが始まる |
| ゲーム中に矢印キーを押す | 自機が上下左右へ動く |
| ゲーム中にSpaceキーを押す | 自機から弾が1発出る |
| ゲームのウィンドウを閉じる | プログラムが終了する |

矢印キーとSpaceキーは、ゲームのウィンドウをクリックしてから押してください。弾を続けて撃つ場合は、Spaceキーを押して離す操作を繰り返してください。タイトル画面でSpaceキーを押しても始まりません。

HPは、攻撃を受けると減る数値です。0になると自機は倒されます。自機のHPは3から始まります。通常の敵を倒すか画面外へ通過させ、最後の敵もいなくなるとボスが現れます。自機の弾を当てて、ボスのHPを0にしてください。

自機のHPを残してボスを倒すと、`GAME CLEAR!`（ゲームクリア）、`You defeated the boss!`（ボスを倒した！）、TITLE（タイトル）ボタンが出ます。TITLEの内側を左クリックするとタイトル画面へ戻ります。

自機のHPが0になると、`GAME OVER`（ゲームオーバー）が出ます。左のRESTART（再開）を左クリックすると、そのまま新しいゲームが始まります。右のTITLEを左クリックするとタイトル画面へ戻ります。同じ更新で自機とボスのHPが両方0になった場合は、ゲームオーバーになります。

もう一度STARTを押すと、自機のHPと位置が最初の状態に戻り、前の敵や弾も消えます。

## 起動できないとき

| 表示・状況 | 確認すること |
| --- | --- |
| `python` / `python3` が見つからない | ページ上部のPythonの準備手順を開き、インストールを確認する。インストール後はVS Codeを開き直す |
| `No module named venv` / `ensurepip` のエラー | 専用の実行環境を作るための機能が不足している。Pythonの配布元やOSの案内に従ってvenvを用意する |
| `pip install` が失敗する | ターミナルのエラーを確認する。接続できない場合は通信環境、対応する配布物がない場合はPythonとpygame-ceの対応バージョンを確認する |
| `No module named game` など補助ファイルの名前が出る | 上の表の16個のPythonファイルを同じフォルダへ保存したか確認する |
| `No module named pygame` | pygame-ceを追加したPythonと、実行に使ったPythonが同じか確認する。このページの `.venv` のコマンドで追加・実行する |
| `No such file or directory` で画像名が出る | `clear_title.py` の隣に `assets` があり、その中に4枚のPNGがあるか確認する |
| 画像を読み込めない | PNGではなくGitHubのページ自体を保存していないか確認する。画像リンクから画像を開き、画像として保存し直す |
| ファイルが見つからない | ターミナルの `cd` 先に `clear_title.py` があるか、末尾が `.py.txt` になっていないか確認する |
