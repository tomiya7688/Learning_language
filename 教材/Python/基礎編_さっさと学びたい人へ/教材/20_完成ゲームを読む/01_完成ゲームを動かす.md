# 1. 完成ゲームを保存して遊ぶ

> **「ゲームのコードはあるのに遊べない！何を保存して、どう起動するの？」**

完成したシューティングゲームを保存して動かしてください。起動すると、パソコンの画面上にゲーム用の枠が開きます。この枠を「ウィンドウ」と呼びます。矢印キーで自機を動かし、Spaceキーで弾を撃って敵とボスを倒すゲームです。倒されても、タイトルへ戻ってもう一度遊べます。

PythonとVS Codeをまだ使えない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)


## Pythonファイルの保存場所

コードのファイルが増えると、教材の説明や画像のファイルと混ざって探しにくくなります。Pythonファイルは、練習用フォルダ内の `src` にまとめてください。

`src` はsource（ソース）の略で、ソースコードを入れるフォルダです。ソースコードは、書いたプログラムのことです。

パソコンに練習用の新しいフォルダを作ってください。Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderで **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。ここでは `shooting_practice` という名前にしてください。shooting は「射撃」、practice は「練習」という意味です。

練習用フォルダの中で、Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderの **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。フォルダ名を `src` と入力してEnterキーを押すと、練習用フォルダの中に `src` ができます。すでに `src` がある場合はそのフォルダを使い、保存済みのコードは必要な変更だけを行ってください。

VS Codeで開くフォルダと、ターミナルの `cd` で移動するフォルダは、`src` の一つ上の練習用フォルダです。保存先を選ぶときは `src` を開き、起動するときは練習用フォルダから `src/main.py` を指定してください。実行手順のコマンドは、この練習用フォルダから入力してください。

ゲーム画像の `assets` と、専用のPythonを用意する `.venv` は、`src` の一つ上の練習用フォルダに置いてください。

## コードと画像を保存する

1. 下の表のPythonファイルを1つずつ開いてください。GitHubのファイル画面では **Raw** を開き、コードだけが表示された状態にしてください。
2. Windows / Linuxでは Ctrl + A、Ctrl + C、macOSでは Command + A、Command + C を押して、コード全体をコピーしてください。
3. VS Codeで新しいファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。コピーしたコード全体を貼り付けてください（Windows / Linuxは Ctrl + V、macOSは Command + V）。
4. Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダ内の `src` に、下の表と同じ名前で保存してください。末尾の `.py` まで入力してください。

**16個のPythonファイルを全て、同じ練習用フォルダ内の `src` へ保存してください。実行するファイルは `main.py` です。**

| ファイル | 役割 |
| --- | --- |
| [main.py](./src/main.py) | `main.py` はpygameを使う準備をし、`game.py` のゲーム全体の処理を開始します。 |
| [background.py](./src/background.py) | Background：背景の移動と描画 |
| [battle.py](./src/battle.py) | Battle：1回の戦闘、自機・敵・弾の一覧と更新順 |
| [boss.py](./src/boss.py) | Boss：ボスの位置・HP・発射・描画 |
| [bullet.py](./src/bullet.py) | Bullet：弾の位置・移動・画面外判定・描画 |
| [clear_view.py](./src/clear_view.py) | ClearScreen：クリア画面の入力と描画 |
| [collisions.py](./src/collisions.py) | 弾と機体の当たり判定、弾の削除とダメージ |
| [enemy.py](./src/enemy.py) | Enemy：通常の敵の位置・移動・発射・描画 |
| [game.py](./src/game.py) | Game：ウィンドウ・画面更新の速さ・繰り返し・画面の切り替え |
| [game_over_view.py](./src/game_over_view.py) | GameOverScreen：ゲームオーバー画面の入力と描画 |
| [player.py](./src/player.py) | Player：自機の位置・移動・発射・描画 |

| [settings.py](./src/settings.py) | 画面の大きさ、自機・敵・弾の位置や移動距離、体力、出現・発射間隔を設定名と数値でまとめる |
| [title_view.py](./src/title_view.py) | TitleScreen：タイトル画面の入力と描画 |
| [ui.py](./src/ui.py) | 画面に共通する文字の描画と、ボタンの入力・描画 |

`main.py` はpygameを使う準備と終了時の片付けを行います。ゲームの進行・機体・画像・各画面は、役割ごとに別のファイルへ分けています。編集する場所は後のページでファイル名と処理名を指定します。

練習用フォルダの中に `assets` というフォルダを作ってください。assets は「素材」という意味で、ここにゲームで使う画像を置いてください。

下のリンクを1つずつ開き、表示された画像を右クリックして **名前を付けて画像を保存** を選んでください。保存先を `assets` にし、リンクに書かれたファイル名のまま保存してください。4枚とも必要です。

## 保存先のフォルダへターミナルを移動する

ターミナルは、文字で操作を入力する場所です。これからのコマンドは、コードを書いた欄へ入力せず、VS Codeの **表示（View）→ ターミナル（Terminal）** で開いたターミナルへ入力してください。

`src/main.py` を保存した練習用フォルダの場所をコピーしてください。`src` 自体ではなく、その一つ上のフォルダを使ってください。場所を書いた文字列を「パス」と呼びます。`assets` の場所ではなく、`shooting_practice` の場所を使ってください。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックし、フォルダのパス全体を Ctrl + C でコピーしてください。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でそのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の入力欄を出し、Ctrl + C でフォルダのパスをコピーしてください。

VS Codeのターミナルを開き、次の形で入力してください。引用符の中を、上の操作でコピーしたフォルダのパスに置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力したら Enter キーを押してください。

```text
cd "コピーした練習用フォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

## ゲームを描く道具を追加して起動する

このゲームは、画面の描画やキー入力に **pygame-ce** という追加の道具を使います。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。

練習用フォルダの `.venv` に、このゲーム用のPython実行環境を作ってください。その環境へpygame-ceを追加し、同じ環境のPythonでゲームを動かしてください。追加するときはインターネット接続が必要です。

### Windows

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe src/main.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 -m venv .venv
```

`-m venv` は専用の実行環境を作る指定です。作成が終わったら、その環境へpygame-ceを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python -m pip install pygame-ce
```

`-m pip install pygame-ce` は、コマンドに書いたPythonの環境へpygame-ceを追加する指定です。追加が終わったらゲームを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python src/main.py
```

各コマンドでエラーが表示された場合は、その段階の用意ができていません。次のコマンドへ進む前に、下の「起動できないとき」を確認してください。

## ゲームで遊ぶ

起動すると、暗い背景のゲーム画面に、`SPACE SHOOTER`（宇宙のシューティングゲーム）、`Defeat the boss!`（ボスを倒そう！）、青いSTART（始める）ボタンが表示されます。

| 操作 | 起きること |
| --- | --- |
| STARTの内側を左クリック | ゲームが始まる |
| ゲーム中に矢印キーを押す | 自機が上下左右へ動く |
| ゲーム中にSpaceキーを押す | 自機から弾が1発出る |
| ゲームのウィンドウを閉じる | プログラムが終了する |

矢印キーとSpaceキーは、ゲームのウィンドウをクリックしてから押してください。弾を続けて撃つ場合は、Spaceキーを押して離す操作を繰り返してください。タイトル画面でSpaceキーを押しても始まりません。

HPは、攻撃を受けると減る数値です。0になると自機は倒されます。自機のHPは3から始まります。通常の敵を倒すか画面外へ通過させ、最後の敵もいなくなるとボスが現れます。自機の弾を当てて、ボスのHPを0にしてください。

自機のHPを残してボスを倒すと、`GAME CLEAR!`（ゲームクリア）、`You defeated the boss!`（ボスを倒した！）、TITLE（タイトル）ボタンが出ます。TITLEの内側を左クリックするとタイトル画面へ戻ります。

自機のHPが0になると、`GAME OVER`（ゲームオーバー）が出ます。左のRESTART（再開）を左クリックすると、そのまま新しいゲームが始まります。右のTITLEを左クリックするとタイトル画面へ戻ります。同じ更新で自機とボスのHPが両方0になった場合は、ゲームオーバーになります。

もう一度STARTを押すと、自機のHPと位置が最初の状態に戻り、前の敵や弾も消えます。

## 起動できないとき

| 表示・状況 | 確認すること |
| --- | --- |
| `python` / `python3` が見つからない | [Pythonを書いて動かす準備](../環境構築/環境構築ガイド.md)を開き、Pythonがインストールされているか確認してください。インストール後はVS Codeを開き直してください |
| `No module named venv` / `ensurepip` のエラー | 専用の実行環境を作るための機能が不足している。Pythonの配布元やOSの案内に従ってvenvを用意してください |
| `pip install` が失敗する | ターミナルのエラーを確認してください。接続できない場合は通信環境、対応する配布物がない場合はPythonとpygame-ceの対応バージョンを確認してください |
| `No module named game` など補助ファイルの名前が出る | `main.py` と同じ `src` に `game.py` と必要な補助Pythonファイルを保存したか確認してください |
| `No module named pygame` | pygame-ceを追加したPythonと、実行に使ったPythonが同じか確認してください。このページの「ゲームを描く道具を追加して起動する」のOS別コマンドで、`.venv` へpygame-ceを追加してゲームを実行してください |
| `No such file or directory` で画像名が出る | `main.py` の隣に `assets` があり、その中に4枚のPNGがあるか確認してください |
| 画像を読み込めない | PNGではなくGitHubのページ自体を保存していないか確認してください。このページの「コードと画像を保存する」の画像リンクから画像を開き、画像として保存し直してください |
| ファイルが見つからない | ターミナルの `cd` 先に `main.py` があるか、末尾が `.py.txt` になっていないか確認してください |
