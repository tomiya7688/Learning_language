# 3. 背景・自機・敵・ボスの画像を読み込む

完成ゲームの自機を別の絵に変えたいとき、画像を置いただけでは、ゲームがその画像を選んでくれません。

> **「別の絵で遊びたい！自機の画像を選ぶ場所はどこ？」**

読み込む画像を選ぶ場所は `resources.py` です。最後に自機の画像を通常敵の画像へ切り替え、見た目と当たり判定の大きさを変えてください。

[コードと画像をまだ保存していない場合：1. 完成ゲームを保存して遊ぶ](./01_完成ゲームを動かす.md)

## 画像の場所と読み込みを読む

VS Codeの **ファイル → ファイルを開く** で、練習用フォルダの `resources.py` を開いてください。assets（素材）フォルダはこのファイルと同じフォルダにあり、背景・自機・通常敵・ボスの4枚を置いてあります。

### [resources.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/resources.py) の `load_image`

```python
# load_image の処理を定義する
def load_image(name, size=None):
    # path は画像ファイルの場所です。
    # path に Path(__file__).parent / 'assets' / name を入れる
    path = Path(__file__).parent / "assets" / name
    # image は画像。画面へ描く内容を持ちます。
    # image に pygame.image.load(str(path)).convert_alpha() を入れる
    image = pygame.image.load(str(path)).convert_alpha()
    # size is not None が成り立つなら
    if size is not None:
        # image は画像。画面へ描く内容を持ちます。
        # image に pygame.transform.scale(image, size) を入れる
        image = pygame.transform.scale(image, size)
    # image を返す
    return image
```


`load_image` は「画像を読み込む」という意味です。`name` にファイル名、`size` に変更したい大きさを指定します。`size=None` は大きさを変更しない場合の指定です。

`from pathlib import Path` で、Pythonに最初からあるファイルの場所を扱う道具を読み込みます。`Path(__file__).parent` は `resources.py` が入っているフォルダを示します。`__file__` はこのコードがある `resources.py` の場所を示すため、`main.py` の場所ではありません。

`/ "assets" / name` は、そのフォルダの下のassetsと画像名をつないで場所を作る指定です。`str(path)` はその場所を文字列にします。`pygame.image.load` が画像を読み、`convert_alpha()` が透明部分を扱える描画用の形式へ変換します。画面を作った後にこの関数を呼びます。

大きさを指定した場合だけ `pygame.transform.scale` で変換し、`return image` で呼び出した側へ画像を返します。透明でない背景にも同じ関数を使っています。

## 3枚の機体の画像を読み、各機体へ指定する

### [resources.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/resources.py) の `Images`

```python
# Images という型を定義する
class Images:
    # __init__ の処理を定義する
    def __init__(self):
        # player はプレイヤー。ここでは操作する自機です。
        # self.player に load_image('player_ship.png') を入れる
        self.player = load_image("player_ship.png")
        # enemy は敵。通常の敵1機を表します。
        # self.enemy に load_image('enemy_ship.png') を入れる
        self.enemy = load_image("enemy_ship.png")
        # boss はボス。通常の敵が全ていなくなった後に登場します。
        # self.boss に load_image('boss_ship.png') を入れる
        self.boss = load_image("boss_ship.png")
```


Imagesは「画像のまとまり」です。`Battle()` を作るときに3枚を読み、自機には `self.images.player`、敵には `self.images.enemy`、ボスには `self.images.boss` を指定します。敵を1機出すたびに同じ画像を読み直しません。

### [player.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/player.py) の `Player.__init__`

`settings.py` はゲームで使う数値をまとめた Python ファイルです。`player.py` は `import settings` で読み込み、`settings.PLAYER_X` のように設定名を書いて値を使います。自機の最初の中心位置は、画面左端から320ピクセル、上端から400ピクセルです。`PLAYER_SPEED = 5` は画面を1回更新する間に自機が進む距離（5ピクセル）、`PLAYER_HP = 3` は自機が最初に持つ体力です。

```python
# __init__ の処理を定義する
def __init__(self, image):
    # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
    # self.rect に pygame.Rect(0, 0, 40, 40) を入れる
    self.rect = pygame.Rect(0, 0, 40, 40)
    # self.rect.center に (settings.PLAYER_X, settings.PLAYER_Y) を入れる
    self.rect.center = (settings.PLAYER_X, settings.PLAYER_Y)

    # image は画像。画面へ描く内容を持ちます。
    # self.image に image を入れる
    self.image = image
    # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
    # self.rect に image.get_rect(center=self.rect.center) を入れる
    self.rect = image.get_rect(center=self.rect.center)

    # speed は速さ。1回の更新で動く距離で、単位はピクセルです。
    # self.speed に settings.PLAYER_SPEED を入れる
    self.speed = settings.PLAYER_SPEED

    # hp はhit points（体力）。攻撃1回で1減り、0で倒されます。
    # self.hp に settings.PLAYER_HP を入れる
    self.hp = settings.PLAYER_HP
```


`image.get_rect(center=...)` は画像と同じ大きさの長方形を作り、中心を指定します。自機は描画にも当たり判定にもこのrectを使うので、画像を替えると当たり判定の大きさも変わります。

## 背景を2枚並べる

### [background.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/background.py) の `Background.__init__`

`Background.__init__` は `settings.py` の `WIDTH = 640` と `HEIGHT = 480` を背景画像の幅と高さに使います。どちらも画面上の点1つを数えるピクセル単位です。`self.y2 = -settings.HEIGHT` は、2枚目の背景の上端を画面の上端より480ピクセル上に置きます。

```python
# __init__ の処理を定義する
def __init__(self):
    # image は画像。画面へ描く内容を持ちます。
    # self.image に load_image('space_background.png', (settings.WIDTH, settings.HEIGHT)) を入れる
    self.image = load_image("space_background.png", (settings.WIDTH, settings.HEIGHT))
    # y1 は1枚目の背景の上端の位置です。
    # self.y1 に 0 を入れる
    self.y1 = 0
    # y2 は2枚目の背景の上端の位置です。
    # self.y2 に -settings.HEIGHT を入れる
    self.y2 = -settings.HEIGHT
```


背景画像は640×480ピクセルにして画面と同じ大きさにします。`Background.__init__` は同じ画像を `y = 0` と `y = -480` に置きます。`Background.update()` は2枚を下へ動かし、画面の下端を過ぎた画像をもう一枚の上へ戻します。`Game` は自機を描く前に背景を描きます。

## 自機を通常敵の絵へ変更する

1. `resources.py` を開き、Windows / LinuxはCtrl + F、macOSはCommand + Fで `self.player = load_image` を検索してください。
2. この行の `"player_ship.png"` を `"enemy_ship.png"` へ変更してください。直上のコメントのファイル名も同じように変更してください。
3. 自機の画像を持つ名前 `self.player` は変更しないでください。通常敵の指定 `self.enemy` もそのままです。

## 保存して起動し直す

変更したファイルを、Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。起動中のゲームのウィンドウは先に閉じてください。

練習用の `shooting_practice` フォルダのパスをコピーしてください。Windowsはエクスプローラーでそのフォルダを開き、上のアドレス欄をクリックしてCtrl + Cでコピーしてください。macOSはFinderでそのフォルダを選びOption + Command + C、Linux（GNOMEのファイル）はフォルダを開きCtrl + L、Ctrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開き、次の引用符の中へそのパスを貼り付けて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした練習用フォルダのパス"
```

Windowsでは、VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

macOS / Linuxでは、VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python main.py
```

変更した補助ファイルを個別に実行しないでください。ゲームを起動する `main.py` が同じフォルダの補助ファイルを読み込みます。

STARTを左クリックしてください。自機が通常敵と同じ赤い画像になります。矢印キーの移動、Spaceキーの発射、体力と速さはそのままです。自機の画像は40×40から40×30になり、長方形の当たり判定の高さも30になります。

元へ戻す場合は、自機のファイル名をplayer_ship.pngへ戻し、コメントも合わせ、上の保存・起動の手順を行ってください。

`settings.py` は画面の大きさ、自機や敵の位置・移動距離、体力などの数値をまとめます。`battle.py` はキー入力、当たり判定、描画を行う順番をまとめます。この2つのファイルを順に読む続編はまだ公開していません。
