## 画像を置く場所を確認する

このゲームでは、`clear_title.py` の隣に `assets` フォルダを置き、その中に画像を保存してください。assets は「素材」という意味です。

```text
練習用フォルダ/
├ clear_title.py
└ assets/
  ├ space_background.png
  ├ player_ship.png
  ├ enemy_ship.png
  └ boss_ship.png
```

| ファイル | 内容・名前の意味 | 元のサイズ（横×縦） |
| --- | --- | --- |
| `space_background.png` | 宇宙の背景。space＝宇宙、background＝背景 | 160×120 |
| `player_ship.png` | 自機。player＝プレイヤー、ship＝船 | 40×40 |
| `enemy_ship.png` | 通常の敵。enemy＝敵 | 40×30 |
| `boss_ship.png` | ボス。boss＝ボス | 120×60 |

`.png` は、画像の保存形式を示すファイル名の末尾です。数字の単位はピクセルで、画像を構成する小さな点の数です。

[画像の出所とライセンスを見る](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/assets/README.md)

## 45〜85行目を順に読む

この部分で行うのは、画像の場所の指定、読み込み、背景の拡大です。画像を読み込んだだけではゲーム画面に表示されません。完成コードの後の部分で、読み込んだ画像を `screen.blit(...)` で画面へ描きます。

コードの `#` で始まる行は、直下の処理を説明するコメントです。Pythonはこの行を処理として実行しません。

### 背景画像の場所を指定する

```python
# background_path は「背景画像の場所」という意味
# background_path に Path(__file__).parent / "assets" / "space_background.png" をセットする
background_path = (
    Path(__file__).parent
    / "assets"
    / "space_background.png"
)
```

ファイルやフォルダの場所を「パス」と呼びます。この行は、`background_path` に、背景画像のパスを入れる処理です。`=` は、右側の結果を左側の名前に入れる書き方です。この名前は、次の画像の読み込みでプログラムが使います。

`Path` は、ファイルやフォルダの場所をコードで指定するための道具です。コードの先頭で、Pythonに最初からある `pathlib` から読み込んでいます。Path は「経路」、lib はlibrary（道具の集まり）の略です。

`__file__` は、実行しているPythonファイルの場所を表す名前です。このゲームを実行するときは `clear_title.py` の場所を表します。file は「ファイル」という意味です。前後に付いた2本ずつの `_` も、名前の一部です。

Pythonは `Path(__file__)` で、実行しているファイルのパスを作ります。`.parent` は1つ上の場所で、この場合は `clear_title.py` が入っているフォルダです。parent は「親」という意味です。

この処理では、Pythonが `/ "assets"` で、そのフォルダの中の `assets` を選びます。さらに `/ "space_background.png"` で、その中の背景画像を指定します。ここでの `/` は、`Path` にファイルやフォルダの名前をつなぐ記号です。割り算はしていません。

`"assets"` や `"space_background.png"` は、`"` で囲んだ文字列です。実際に保存した名前と同じ文字を書いてください。

外側の `(` と `)` は、この指定を複数行へ分けて書くために使っています。プログラムは中の指定を上からつないで、1つの画像の場所にします。この処理では、まだ画像の中身を読み込んでいません。

### 背景画像を読み込む

```python
# background_image は「背景画像」という意味
# background_image に pygame.image.load(str(background_path)).convert() をセットする
background_image = pygame.image.load(
    str(background_path)
).convert()
```

`str(background_path)` は、場所を扱う `background_path` を、場所を書いた文字列にします。`str` はstring（文字列）の略です。文字列にしただけでは、画像は読み込まれません。

`pygame.image.load(...)` で、指定した場所の画像をファイルから読み込みます。image は「画像」、load は「読み込む」という意味です。読み込んだ画像は、pygameが画面へ描ける画像になります。

続く `.convert()` は、読み込んだ画像を、先頭の `pygame.display.set_mode(...)` で作った画面に合った形式に変換します。convert は「変換する」という意味です。Pythonはその結果を `background_image` に入れます。

ここで変えるのは、Pythonで使う画像の持ち方です。保存してあるPNGファイルを書き換える処理ではありません。`convert()` は、画像の点ごとの透け具合を引き継ぎません。プログラムは、背景にはこの変換を使い、自機や敵には後に出てくる `convert_alpha()` を使います。

### 背景を画面全体の大きさにする

```python
# background_image に pygame.transform.scale(background_image, (640, 480)) をセットする
background_image = pygame.transform.scale(
    background_image,
    (640, 480)
)
```

`pygame.transform.scale(...)` は、画像を指定した大きさへ拡大・縮小します。transform は「変形する」、scale は「大きさを変える」という意味です。

最初の `background_image` が、変更する画像です。次の `(640, 480)` で、横幅640、縦の高さ480をひと組にして指定します。このゲームの画面も640×480なので、背景が画面全体を覆う大きさになります。

このコードで使う元の背景画像は160×120です。プログラムは、横と縦をどちらも4倍にして640×480にします。拡大した結果を、同じ `background_image` に入れ直します。元のPNGは160×120のままです。

### 自機・敵・ボスの画像があるフォルダを指定する

```python
# assets_path は「素材フォルダの場所」という意味
# assets_path に Path(__file__).parent / "assets" をセットする
assets_path = Path(__file__).parent / "assets"
```

この行では、Pythonが `assets_path` に、`clear_title.py` の隣にある `assets` フォルダの場所を入れます。この行の指定には、画像のファイル名を含めていません。続く3枚の読み込みでは、プログラムが同じフォルダの場所を使います。

### 自機の画像を読み込む

```python
# player_image は「プレイヤーの画像」という意味
# player_image に pygame.image.load(str(assets_path / "player_ship.png")).convert_alpha() をセットする
player_image = pygame.image.load(
    str(assets_path / "player_ship.png")
).convert_alpha()
```

`assets_path / "player_ship.png"` は、素材フォルダの中にある自機の画像を指定しています。`str(...)` で場所を文字列にし、`pygame.image.load(...)` で読み込みます。

`.convert_alpha()` は、画像の点ごとの透け具合を保ったまま、画面に描くための形式に変換します。alpha は「透け具合」を表す情報の名前です。画像の透明な部分には、その後ろに描いた背景が見えます。自機の周りが四角い枠で塗りつぶされず、機体の形が見えます。

変換した結果を `player_image` に入れます。`()` が付いた名前は、その処理を呼び出しています。`convert_alpha()` は、この呼び出しで指定する値がないので、括弧の中が空です。

### 通常の敵の画像を読み込む

```python
# enemy_image は「敵の画像」という意味
# enemy_image に pygame.image.load(str(assets_path / "enemy_ship.png")).convert_alpha() をセットする
enemy_image = pygame.image.load(
    str(assets_path / "enemy_ship.png")
).convert_alpha()
```

プログラムは、同じ素材フォルダの `enemy_ship.png` を読み込みます。透け具合を保った画像を `enemy_image` に入れます。この名前の画像は、後の通常敵の描画に使います。

### ボスの画像を読み込む

```python
# boss_image は「ボスの画像」という意味
# boss_image に pygame.image.load(str(assets_path / "boss_ship.png")).convert_alpha() をセットする
boss_image = pygame.image.load(
    str(assets_path / "boss_ship.png")
).convert_alpha()
```

プログラムは、`boss_ship.png` を読み込み、透け具合を保った画像を `boss_image` に入れます。後のボスの描画に使います。

この3枚は、読み込んだ時点では元のサイズのままです。背景に使った `scale(...)` を、自機・敵・ボスには呼び出していません。

## 自機に使う画像を切り替える

同じ画像ファイルを、自機に使うこともできます。自機の操作を担当する処理はそのままにして、読み込む画像だけを通常敵の画像へ変えてください。

変更するのは、`clear_title.py` の **72行目** の `str(assets_path / "player_ship.png")` です。行番号は、リンク先の公開サンプルを基準にしています。編集中のファイルで行がずれている場合も、次の検索で探せます。

1. VS Codeで `clear_title.py` を開いてください。
2. Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。
3. 検索欄へ次の文字を入力してください。

```text
str(assets_path / "player_ship.png")
```

変更前：

```python
# player_image は「プレイヤーの画像」という意味
# player_image に pygame.image.load(str(assets_path / "player_ship.png")).convert_alpha() をセットする
player_image = pygame.image.load(
    str(assets_path / "player_ship.png")
).convert_alpha()
```

この処理の `"player_ship.png"` を `"enemy_ship.png"` に変えてください。直上の処理コメントに書かれたファイル名も合わせてください。`player_image` という名前はそのまま使ってください。

変更後：

```python
# player_image は「プレイヤーの画像」という意味
# player_image に pygame.image.load(str(assets_path / "enemy_ship.png")).convert_alpha() をセットする
player_image = pygame.image.load(
    str(assets_path / "enemy_ship.png")
).convert_alpha()
```

### 保存してゲームを起動し直す

1. Windows / Linuxは Ctrl + S、macOSは Command + S を押して、`clear_title.py` を保存してください。
2. 実行中のゲームのウィンドウを閉じてください。ファイルの変更は、起動中のゲームへそのまま反映されません。

`clear_title.py` が入っている練習用フォルダのパスをコピーしてください。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックしてください。フォルダのパス全体を Ctrl + C でコピーしてください。
- macOS：Finderで練習用フォルダを選択してください。Option + Command + C でそのフォルダのパスをコピーしてください。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の欄を表示してください。フォルダのパスを Ctrl + C でコピーしてください。

1. VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。
2. 次の形で入力してください。引用符の中を、上でコピーした練習用フォルダのパスに置き換えてください。
3. Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V でパスを貼り付けてください。
4. 入力し終えたら Enter キーを押してください。

```text
cd "コピーした練習用フォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

Windowsでは、次の順に操作してください。

1. VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。
2. 次のコマンドを入力してください。
3. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe clear_title.py
```

macOS / Linuxでは、次の順に操作してください。

1. VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。
2. 次のコマンドを入力してください。
3. Enter キーを押してください。

```text
.venv/bin/python clear_title.py
```

タイトル画面のSTARTを左クリックして、ゲームを始めます。自分で操作する機体が、通常敵と同じ赤い画像になります。矢印キーで動かせる点と、Spaceキーで上へ弾を撃つ点は同じです。出てくる通常敵の画像もそのままです。

読み込んだ画像の大きさは40×40から40×30になります。このゲームでは、画像の大きさを使った四角形で弾との重なりを調べるため、自機の当たり判定の高さも40から30へ変わります。HPの初期値や移動の速さは、この変更では変わりません。

元に戻す場合は、この処理の `"enemy_ship.png"` を `"player_ship.png"` に戻してください。処理コメントのファイル名も戻し、上の保存・起動手順をもう一度行ってください。

## 今回の内容

- `Path(__file__).parent` で、Pythonファイルが入っているフォルダの場所を使う。
- `/` でフォルダ名やファイル名をつなぎ、画像の場所を指定する。
- `load` で画像を読み込み、`convert` または `convert_alpha` で描くための形式にする。
- `scale` で背景を画面の大きさに合わせる。
- 読み込む画像のファイル名を変えると、自機の見た目を変えられる。

続くコードは、背景や自機の位置・速さ、HPなど、ゲームを始めるときの値を用意する処理です。位置と速さ以降を順に読む専用の章は未公開です。
