# 4. 自機の開始位置と移動の速さを変える

> **「弾を避けたいのに、自機が遅い！動く速さはどこで変えるの？」**

自機を速く動かすには、`settings.py` の `PLAYER_SPEED` を変更してください。この章では、自機が最初に現れる場所も左へ移してください。設定した数字を `player.py` がどのように使うかを読み、ゲームを起動し直して違いを比べてください。

[ゲームのファイル・画像・専用のPython環境をまだ用意していない場合：1. 完成ゲームを保存して遊ぶ](./01_完成ゲームを動かす.md)

第3章で自機の画像を赤い敵の絵へ変えた場合も、そのまま進められます。青い自機と赤い自機のどちらでも、開始位置と移動の設定は同じです。第2章で変えたウィンドウ名と見出しの大きさも、この練習には影響しません。

## 開始位置と速さを決める数字を読む

VS Codeの **ファイル → ファイルを開く** で、練習用の `shooting_practice` フォルダにある `settings.py` を開いてください。`settings` は「設定」です。ゲームの大きさや自機の速さを変える数字を、機体の動きを書くファイルから分けています。速さを変えるたびに、長い移動処理から数字を探す手間を減らすためです。

元ファイル：[`settings.py` の1〜19行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/settings.py#L1-L19)。

```python
# WIDTH はゲーム画面の横幅（ピクセル）です。
# WIDTH に 640 を入れる
WIDTH = 640
# HEIGHT はゲーム画面の縦幅（ピクセル）です。
# HEIGHT に 480 を入れる
HEIGHT = 480
# FPS はゲーム画面を1秒間に更新する回数の上限です。
# FPS に 60 を入れる
FPS = 60
# PLAYER_X は自機を最初に置く中心位置です。画面左端からの距離をピクセルで表します。
# PLAYER_X に 320 を入れる
PLAYER_X = 320
# PLAYER_Y は自機を最初に置く中心位置です。画面上端からの距離をピクセルで表します。
# PLAYER_Y に 400 を入れる
PLAYER_Y = 400
# PLAYER_SPEED は、画面更新1回で押した矢印の方向へ進む距離です（ピクセル）。
# 縦と横を同時に押すと、それぞれの方向へ PLAYER_SPEED だけ進みます
# PLAYER_SPEED に 5 を入れる
PLAYER_SPEED = 5
```

ピクセルは、ゲーム画面を構成する点を数える単位です。位置は、画面の左上を基準にした横方向と縦方向の距離で指定します。横の位置を `x`、縦の位置を `y` と書き、この2つの数字の組を「座標」と呼びます。横の数字は右へ行くほど増え、縦の数字は下へ行くほど増えます。

| 設定名と英語の意味 | 最初の値 | 自機と画面の関係 |
| --- | --- | --- |
| `WIDTH`（幅） | `640` | ゲーム画面の横幅を640ピクセルにします。 |
| `HEIGHT`（高さ） | `480` | ゲーム画面の高さを480ピクセルにします。 |
| `FPS`（1秒あたりの画面更新回数） | `60` | ゲーム画面の更新を1秒あたり最大60回に抑えます。毎秒必ず60回動くという意味ではありません。 |
| `PLAYER_X`（自機の横位置） | `320` | 自機の中心を画面左端から320ピクセルに置きます。横幅640の半分なので、横方向の中央です。 |
| `PLAYER_Y`（自機の縦位置） | `400` | 自機の中心を画面上端から400ピクセルに置きます。高さ480の画面で、中心は下端から80ピクセル上です。 |
| `PLAYER_SPEED`（自機の速さ） | `5` | 画面更新1回で、押した矢印の方向へ5ピクセル動かします。右と上を同時に押すと、右へ5、上へ5ピクセル動かします。 |

`PLAYER_X` と `PLAYER_Y` は画像の左上の位置ではなく、自機の中心の位置です。`PLAYER_SPEED` は、このゲームで方向ごとの移動量につけた名前です。斜めに進む距離全体が5ピクセルという意味ではありません。

## 数字が自機の位置と速さになる場所を読む

VS Codeで、練習用フォルダの `player.py` を開いてください。`Player` は「プレイヤー」で、このゲームでは読者が操作する自機を表します。`Player.__init__` は、新しい自機を作るときに位置・画像・速さ・体力を用意する処理です。自機に関する情報を `Player` にまとめ、移動や描画でも同じ自機の情報を使います。

元ファイル：[`player.py` の12〜27行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/player.py#L12-L27)。

```python
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, 40, 40) を入れる
        self.rect = pygame.Rect(0, 0, 40, 40)
        # self.rect.center に (settings.PLAYER_X, settings.PLAYER_Y) を入れる
        self.rect.center = (settings.PLAYER_X, settings.PLAYER_Y)

        # image は画像。画面へ描く内容を持ちます。
        # self.image に image を入れる
        self.image = image
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に image.get_rect(center=self.rect.center) を入れる
        self.rect = image.get_rect(center=self.rect.center)

        # speed は速さ。1回の更新で、押した矢印の方向ごとに動く距離です。単位はピクセルです。
        # self.speed に settings.PLAYER_SPEED を入れる
        self.speed = settings.PLAYER_SPEED
```

`player.py` は `import settings` で、同じフォルダの `settings.py` を読み込みます。`settings.PLAYER_X` は、読み込んだ設定の `PLAYER_X` を使う書き方です。`self` は今作っている自機を指し、`self.rect` はその自機の位置と大きさを持つ長方形です。

`self.rect.center` の `center` は「中心」です。`Player.__init__` は `settings.py` の `PLAYER_X = 320` と `PLAYER_Y = 400` を使い、自機の中心を左端から320、上端から400ピクセルに置きます。続く `image.get_rect(center=self.rect.center)` は画像の大きさに長方形を合わせますが、中心の位置は保ちます。第3章で赤い画像へ変えていても、開始時の中心は同じです。

`self.speed = settings.PLAYER_SPEED` は、設定の5を自機の `self.speed` に保存します。移動中は、設定ファイルの行を毎回読み直すのではなく、保存した速さを使います。ゲームを動かしたまま `settings.py` を保存しても、そのゲームの速さや開始位置は変わりません。設定の変更後は、ゲームのウィンドウを閉じ、保存した `main.py` を起動し直してください。

START（始める）を左クリックすると、[`game.py` の `Game.start_game`（34〜42行）](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/game.py#L34-L42) が `Battle()` を作ります。`Battle` は「戦闘」で、1回のゲームに使う自機・敵・弾を持ちます。[`battle.py` の25〜31行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/battle.py#L25-L31) は `Player(self.images.player)` で新しい自機を作るので、開始時に `Player.__init__` が動きます。

## 矢印キーで位置を変える場所を読む

右へ進むには横の位置を増やし、左へ進むには減らします。上下では縦の位置を変えます。同じ自機に対する4方向の移動と、画面から出ないための処理を `Player.move` にまとめています。`move` は「動かす」という意味です。

元ファイル：[`player.py` の33〜52行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/player.py#L33-L52)。

```python
    # move の処理を定義する
    def move(self, keys):
        # keys[pygame.K_LEFT] が成り立つなら
        if keys[pygame.K_LEFT]:
            # self.rect.x から self.speed を引く
            self.rect.x -= self.speed
        # keys[pygame.K_RIGHT] が成り立つなら
        if keys[pygame.K_RIGHT]:
            # self.rect.x に self.speed を足す
            self.rect.x += self.speed
        # keys[pygame.K_UP] が成り立つなら
        if keys[pygame.K_UP]:
            # self.rect.y から self.speed を引く
            self.rect.y -= self.speed
        # keys[pygame.K_DOWN] が成り立つなら
        if keys[pygame.K_DOWN]:
            # self.rect.y に self.speed を足す
            self.rect.y += self.speed
        # self.rect.clamp_ip(pygame.Rect(0, 0, settings.WIDTH, settings.HEIGHT)) を実行する
        self.rect.clamp_ip(pygame.Rect(0, 0, settings.WIDTH, settings.HEIGHT))
```

`keys` は「キー」で、押されているキーを調べるための情報です。[`battle.py` の76〜77行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/battle.py#L76-L77) は、`pygame.key.get_pressed()` で現在のキーの状態を調べ、`self.player.move(...)` で自機の移動処理へ指定します。`pygame.K_RIGHT` は右矢印キー、`K_LEFT` は左、`K_UP` は上、`K_DOWN` は下を表します。位置を動かす方向とキーの矢印を対応させるため、移動に矢印キーを使っています。

`if keys[pygame.K_RIGHT]:` の下の字下げした行は、右矢印キーが押されているときだけ動きます。`self.rect.x += self.speed` は、自機の長方形の左端の横位置に、保存した速さを足します。`self.rect.y` は長方形の上端の縦位置です。`+=` は足した結果を同じ名前へ保存し、`-=` は引いた結果を保存する書き方です。長方形全体が移動するので、左端が右へ5ピクセル進めば、中心も右へ5ピクセル進みます。

開始時の中心が `(320, 400)` で、`PLAYER_SPEED = 5` の場合、右矢印だけを押した更新1回で中心は `(325, 400)` になります。右と上を同時に押した更新1回では、中心は `(325, 395)` になります。4つの `if` がそれぞれキーを調べるため、縦と横の両方を動かせます。右と左を同時に押すと、横の位置は5を引いた後に5を足すので、横方向には進みません。

ゲームは戦闘中、画面更新ごとに自機の移動処理を実行します。[`game.py` の73〜81行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/game.py#L73-L81) で現在の画面を更新し、[`playing_view.py` の14〜17行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/playing_view.py#L14-L17) で戦闘を更新し、`Battle.update` が自機を動かします。画面の更新上限は `settings.py` の `FPS = 60` です。毎秒60回更新できる場合、速さ5では一方向に毎秒300ピクセル動きます。処理が遅い場合は更新回数が減り、実際の移動も遅くなります。

### 自機を画面から出さない行

`Player.move` の最後にある `self.rect.clamp_ip(...)` は、移動後の自機の長方形をゲーム画面の内側へ戻します。`pygame.Rect(0, 0, settings.WIDTH, settings.HEIGHT)` は、左上が `(0, 0)`、横幅640、高さ480ピクセルの画面全体を表す長方形です。`clamp` は「挟んで固定する」、`ip` は「その場で変更する」という意味で、この行は `self.rect` 自体の位置を直します。

自機を画面外へ動かしたままにすると、読者は自機を見失います。`clamp_ip` があるため、矢印キーを押し続けても自機の画像の端がゲーム画面の端で止まります。画面端にいる場合は、速さが5でも、その方向へ5ピクセル進み切るとは限りません。

## 自機を左から始めて、移動を速くする

VS Codeで練習用フォルダの `settings.py` を開いてください。Windows / Linuxは Ctrl + F、macOSは Command + Fで、次の3つの設定を検索してください。第3章までの練習では `PLAYER_X = 320`、`PLAYER_Y = 400`、`PLAYER_SPEED = 5` のままです。別の数字に変更済みの場合は、今回の比較のために320・400・5へそろえてください。

| 検索する文字列 | 変更する内容 | 起動し直した後に変わること |
| --- | --- | --- |
| `PLAYER_X =` | `320` を `160` に変更してください。直上の `# PLAYER_X に 320 を入れる` の320も160へ変更してください。 | START後の自機の中心が、画面左端から160ピクセルの位置になります。元の320より左へ160ピクセル移ります。 |
| `PLAYER_Y =` | 縦の開始位置は `400` のままにしてください。 | 自機の中心の高さは、画面上端から400ピクセルのままです。 |
| `PLAYER_SPEED =` | `5` を `8` に変更してください。直上の `# PLAYER_SPEED に 5 を入れる` の5も8へ変更してください。 | 画面更新1回で、押した矢印の方向ごとに8ピクセル進みます。同じ更新回数なら、速さ5のときの1.6倍進みます。 |

変更後の `settings.py` の自機の設定は、次の形です。掲載した部分だけを変更し、画面の大きさや敵・弾の設定は残してください。

変更する元の場所：[`settings.py` の10〜20行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/settings.py#L10-L20)。次は練習用の変更後のコードで、元ファイルとは数値とそのコメントが異なります。

```python

# PLAYER_Y は自機を最初に置く中心位置です。画面上端からの距離をピクセルで表します。
# PLAYER_Y に 400 を入れる
PLAYER_Y = 400
# PLAYER_SPEED は、画面更新1回で押した矢印の方向へ進む距離です（ピクセル）。
# 縦と横を同時に押すと、それぞれの方向へ PLAYER_SPEED だけ進みます
# PLAYER_SPEED に 8 を入れる
PLAYER_SPEED = 8
```

## 保存して起動し直す

1. 起動中のゲームのウィンドウを閉じ、VS Codeのターミナルへ再びコマンドを入力できる状態になるまで待ってください。タイトル画面へ戻るだけでは、変更した設定ファイルを読み直しません。
2. VS Codeで変更した `settings.py` を、Windows / Linuxは Ctrl + S、macOSは Command + Sで保存してください。
3. `main.py` と `settings.py` が入っている `shooting_practice` フォルダのパス（場所を表す文字列）を、次のOS別の操作でコピーしてください。

- Windows：エクスプローラーで `shooting_practice` フォルダを開き、上部のアドレス欄をクリックし、Ctrl + Cでフォルダのパスをコピーしてください。
- macOS：Finderで `shooting_practice` フォルダを選択し、Option + Command + Cでフォルダのパスをコピーしてください。
- Linux（GNOMEの「ファイル」）：`shooting_practice` フォルダを開き、Ctrl + Lで場所の入力欄を表示し、Ctrl + Cでフォルダのパスをコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次のコマンドの引用符の中を、OS別の操作でコピーした `shooting_practice` フォルダのパスへ置き換えて入力し、Enterキーを押してください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + Vで貼り付けてください。

```text
cd "コピーしたshooting_practiceフォルダのパス"
```

`cd` は、ターミナルがコマンドを実行するフォルダを変更します。コードを書く欄ではなく、ターミナルへ入力してください。すでに表示されている `PS C:\Users\...>` などの文字は入力しないでください。

### Windowsで起動する

VS Codeの **表示（View）→ ターミナル（Terminal）** で、フォルダを変更したターミナルを表示してください。次のコマンドを入力し、Enterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

第1章で用意した `.venv` のPythonが `main.py` を実行し、ゲームのタイトル画面が開きます。`settings.py` は設定を読み込むファイルなので、単独で実行してもゲーム画面は開きません。

### macOS / Linuxで起動する

VS Codeの **表示（View）→ ターミナル（Terminal）** で、フォルダを変更したターミナルを表示してください。次のコマンドを入力し、Enterキーを押してください。

```text
.venv/bin/python main.py
```

第1章で用意した `.venv` のPythonが `main.py` を実行し、ゲームのタイトル画面が開きます。`settings.py` は設定を読み込むファイルなので、単独で実行してもゲーム画面は開きません。

## 開始位置と動きの変化を比べる

タイトル画面のSTART（始める）の内側を左クリックしてください。矢印キーを押す前の自機は、画面左端から160、上端から400ピクセルを中心にして現れます。横方向の中央ではなく、画面の左半分にいます。自機の色は、第3章で選んだ画像の色です。

ゲームのウィンドウをクリックし、右矢印キーを押してください。キーを押している間、自機は右へ進みます。画面端から離れている場合、更新1回あたりの中心は `(160, 400)` から `(168, 400)` へ進みます。この座標の数字はゲーム画面には表示されません。画面では、開始位置が左へ移ったことと、以前の速さ5より速く動くことを比べてください。

右矢印キーを離し、上と右の矢印キーを同時に押してください。画面端から離れている場合、自機は更新1回ごとに右へ8、上へ8ピクセル進みます。横と縦の移動は別々に行うため、斜めに進む距離は右だけに進む距離より長くなります。

ゲームのウィンドウで右矢印キーだけを押し続けてください。自機の画像の右端が画面の右端で止まります。キーを離し、左矢印キーを押すと、自機は左へ動きます。画面端で止まるのは、`Player.move` の最後で自機の長方形を画面内へ戻すためです。

比較の途中でゲームオーバーになった場合は、RESTART（再開）の内側を左クリックしてください。新しい自機は、変更済みの開始位置 `(160, 400)` と方向ごとの移動量8で戦闘を始めます。

設定を保存しても変化がない場合は、起動中のゲームを終了したか、起動に使った `main.py` と同じフォルダの `settings.py` を編集したかを確認してください。編集後は、このページの「保存して起動し直す」のパスのコピー・`cd`・OS別の実行手順を行ってください。

今回の練習では、`settings.py` の自機の開始位置は `(160, 400)`、方向ごとの移動量は8になりました。敵の位置や弾の速さは変更していません。敵の出現順や弾の動き、画面の切り替え・当たり判定・描画を詳しく読む続編は、まだ公開していません。
