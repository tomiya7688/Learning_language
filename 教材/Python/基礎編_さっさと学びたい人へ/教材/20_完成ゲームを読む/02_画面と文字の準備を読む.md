# 2. 画面・更新速度・文字の準備を読む

完成ゲームを自分のものに変えてみたいとき、ウィンドウの名前や見出しを変える場所が分からなければ、長いコードから探すことになります。

> **「ゲームは動いた！名前や文字の大きさは、どこで変えるの？」**

ウィンドウを用意するのは `game.py`、タイトル画面の文字を用意するのは `title_view.py` です。このページではその場所を開き、ウィンドウのタイトルと文字の大きさを変えてください。

[コードと画像をまだ保存していない場合：1. 完成ゲームを保存して遊ぶ](./01_完成ゲームを動かす.md)

## 起動用の `main.py` を読む

VS Codeの **ファイル → ファイルを開く** で、練習用フォルダの `main.py` を開いてください。`main` はプログラムの起動時に実行する処理の名前です。`def main():` の字下げされた部分がこの処理に含まれます。`main.py` を直接実行すると、Pythonは `main()` を動かし、`Game` がウィンドウを開きます。別のPythonファイルから `main.py` を読み込むだけでは `main()` は動かず、ウィンドウも開きません。

元ファイル：[`main.py` の1〜24行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/main.py#L1-L24)。

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # Pythonは try: の処理が終わったときもエラーで中断したときも、finally: の下の pygame.quit() を実行する
    try:
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygameを終了する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

`from game import Game` は同じフォルダの `game.py` からGameという型を読み込みます。このように読み込めるPythonファイルを「モジュール」と呼びます。`Game()` はその型のゲームを1つ作り、`game.run()` はそのゲームの繰り返しを始めます。`game.run()` と書くと、ゲームの繰り返しを行う `run` が実行されます。

`pygame.init()` はゲームで使うPygameの機能を使える状態にします。`try:` の下にはゲームを作って実行する処理を書きます。Pythonはその処理が正常に終わった場合も途中でエラーが起きた場合も、`finally:` の下にある `pygame.quit()` を実行してPygameを終了します。エラーで中断した場合、PythonはPygameを終了してからエラーを表示します。

## 画面を作る場所はGameの `__init__`

ウィンドウを開く処理と、画面を更新し続ける処理が起動用の `main.py` に並ぶと、起動の準備だけを確認しにくくなります。ゲーム画面の準備・更新・切り替えは `Game` にまとめ、`main.py` はpygameの準備・ゲームの開始・終了時の片付けを行います。

`Game()` を作ると `__init__` の中の処理が動き、`self` はその `Game` を指します。`settings.py` はゲームで使う数値をまとめた Python ファイルです。`game.py` は `import settings` で `settings.py` を読み込み、`settings.WIDTH` と `settings.HEIGHT` をウィンドウの幅と高さに使います。このゲームの幅は640、高さは480ピクセルです。ピクセルは画面上の点1つを表す単位です。

### game.py の `Game.__init__`

元ファイル：[`game.py` の18〜32行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/game.py#L18-L32)。

```python
    # __init__ の処理を定義する
    def __init__(self):
        # settings.pyで決めた幅と高さのウィンドウを開き、あとで色や絵を描く画面を self.screen に保存する
        self.screen = pygame.display.set_mode((settings.WIDTH, settings.HEIGHT))
        # pygame.display.set_caption('クリア後にタイトルへ戻る') を実行する
        pygame.display.set_caption('クリア後にタイトルへ戻る')

        # self.clock.tick(settings.FPS) で、画面更新を1秒あたり最大 settings.FPS 回に抑える
        # pygame.time.Clock() で、画面更新の間隔を測る self.clock を作る
        self.clock = pygame.time.Clock()
        # self.running を True にして、ゲーム画面の繰り返しを続ける
        self.running = True

        # self.show_title() を実行する
        self.show_title()
```


`pygame.display.set_mode((settings.WIDTH, settings.HEIGHT))` は、設定した幅と高さのウィンドウを開きます。`self.screen` に色や絵を描き、`pygame.display.flip()` を呼ぶとその内容がウィンドウに表示されます。`pygame.display.set_caption()` はウィンドウ上部の名前を決めます。画面内に表示する `SPACE SHOOTER` とは別の文字です。`self.running` を `True` にしてからタイトル画面を表示し、`while self.running` の間はゲーム画面を更新します。

### game.py の `Game.run`

元ファイル：[`game.py` の62〜81行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/game.py#L62-L81)。

```python
    # run の処理を定義する
    def run(self):
        # self.running が True の間、ゲーム画面を更新する
        while self.running:
            # self.handle_events() を実行する
            self.handle_events()
            # self.running が False なら、次の画面更新をせず繰り返しを終える
            if not self.running:
                # 画面更新を繰り返す while を終える
                break

            # self.current_screen.update() を実行する
            self.current_screen.update()
            # self.current_screen.draw(self.screen) を実行する
            self.current_screen.draw(self.screen)

            # pygame.display.flip() を実行する
            pygame.display.flip()
            # settings.FPS 回/秒を上限にして、画面更新が速くなりすぎないよう待つ
            self.clock.tick(settings.FPS)
```


読者がウィンドウの閉じるボタンを押すと、Pygameはその操作を `pygame.QUIT` として知らせます。`game.py` の `Game.handle_events()` は `pygame.event.get()` からその知らせを受け取り、`self.running` を `False` にします。`Game.run()` はその変化を見て `break` を実行し、画面更新の繰り返しを終えます。その後 `main.py` に戻り、`finally` の `pygame.quit()` がPygameを終了します。`Game.run()` の途中でエラーが起きた場合にも、Pythonは `pygame.quit()` を実行してからエラーを表示します。

`current_screen.update()` は現在の画面の状態を変え、`current_screen.draw(self.screen)` はその画面を `self.screen` に描きます。`pygame.display.flip()` は描いた内容をウィンドウに表示します。`settings.py` の `FPS = 60` は画面更新の上限を1秒間に60回にします。`self.clock.tick(settings.FPS)` はその上限を超えないよう、次の更新まで待ちます。PCの処理が追いつかない場合、更新は1秒間に60回より少なくなります。

## フォントは使う画面が用意する

`pygame.font.Font(None, 64)` はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を、64ピクセルの大きさで用意します。Noneはフォントファイルを自分で指定しない指定です。文字1個の幅が64になるという意味ではありません。この例の標準フォントは英数字に使います。日本語用フォントとして扱っていません。

| ファイル | 名前・意味 | 使う場所 | 大きさ |
| --- | --- | --- | --- |
| battle.py | font（フォント） | HP表示 | 36 |
| title_view.py | heading_font（見出しのフォント） | SPACE SHOOTER | 64 |
| clear_view.py / game_over_view.py | heading_font | 結果の見出し | 72 |
| 各画面のファイル | sub_font（補足のフォント） | 説明文 | 32 |
| ui.py | Button.font | ボタンの文字 | 40 |

タイトルの文字だけを変えたいのに戦闘の処理まで探すと、変更する場所を見つけにくくなります。`TitleScreen`（タイトル画面）は、タイトルの見出し・説明文・STARTボタンを一緒に用意するための型です。ゲーム全体の進行を扱う `Game` から、タイトルに使う部品の準備を分けています。

### [title_view.py](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/title_view.py) の `TitleScreen.__init__`

元ファイル：[`title_view.py` の10〜26行](../../../基礎編_ゆっくり学びたい人へ/教材/Pg23_クリア後にタイトルへ戻る/title_view.py#L10-L26)。

```python
    # __init__ の処理を定義する
    def __init__(self, game):
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # self.game に game を入れる
        self.game = game
        # heading_font は見出し用のフォントです。
        # self.heading_font に pygame.font.Font(None, 64) を入れる
        self.heading_font = pygame.font.Font(None, 64)

        # sub_font は補足文用のフォントです。
        # self.sub_font に pygame.font.Font(None, 32) を入れる
        self.sub_font = pygame.font.Font(None, 32)
        # buttons はボタンの一覧。表示する文字と押した後の処理を持ちます。
        # self.buttons に [Button((220, 330, 200, 60), 'START', game.start_game)] を入れる
        self.buttons = [
            Button((220, 330, 200, 60), 'START', game.start_game),
        ]
```


フォントを用意しただけでは文字は出ません。`ui.py` の `draw_centered_text()` は、フォントの `render`（画像にする）で文字の画像を作り、描画先の `blit`（画像を貼る）でゲーム画面へ置きます。`title_view.py` はSTARTボタンを作るとき、`game.start_game` という開始処理の名前を指定します。`ui.py` のボタンは、STARTの内側が左クリックされたときに `game.start_game()` を実行します。

## ウィンドウの名前と、見出しの大きさを変える

1. VS Codeで `game.py` を開いてください。Windows / LinuxはCtrl + F、macOSはCommand + Fで `pygame.display.set_caption` を検索してください。
2. 括弧の中の文字列を `"私のシューティングゲーム"` に変更し、直上のコメントも同じ名前へ変更してください。文字列は引用符で囲んだ文字の値です。
3. `title_view.py` を開き、同じ検索操作で `Font(None, 64)` を探してください。64を48に変更し、コメントの数値も48へ変更してください。

## 保存して起動し直す

変更したファイルを、Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。起動中のゲームのウィンドウは先に閉じてください。

練習用の `shooting_practice` フォルダのパスをコピーしてください。Windowsはエクスプローラーでそのフォルダを開き、上のアドレス欄をクリックしてCtrl + Cでコピーしてください。macOSはFinderでそのフォルダを選びOption + Command + C、Linux（GNOMEのファイル）はフォルダを開きCtrl + L、Ctrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開き、次の引用符の中へそのパスを貼り付けて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした練習用フォルダのパス"
```

Windowsでは、VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

macOS / Linuxでは、VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python main.py
```

変更した補助ファイルを個別に実行しないでください。ゲームを起動する `main.py` が同じフォルダの補助ファイルを読み込みます。

ウィンドウの名前が変わり、SPACE SHOOTERの文字が小さくなります。中心は同じ位置です。ボタンは別のフォントなので、STARTの文字の大きさは変わりません。
