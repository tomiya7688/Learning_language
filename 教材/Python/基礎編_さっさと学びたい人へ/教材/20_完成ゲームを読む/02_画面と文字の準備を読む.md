ゲームのウィンドウに付けるタイトルと、ゲーム内の見出しの大きさを変えます。完成コードの先頭から、画面を作り、更新の間隔を調整する時計と文字の形・大きさを用意するところまで読みます。

編集するのは `clear_title.py` です。clear は「クリア」、title は「タイトル」という意味です。VS Codeの **ファイル（File）→ ファイルを開く（Open File）** から、練習用フォルダに保存したファイルを開いてください。このページの抜粋を新しいファイルとして実行するのではなく、完成コードの同じ箇所を読みます。

## 1〜43行目を順に読む

`#` で始まる行は、コードを読むためのコメントです。Pythonはコメントを処理として実行しません。コメントには、直下のコードで何をするかを書いてあります。

### 使う道具を読み込む

```python
# Path は「経路」という意味。ファイルやフォルダの場所を表す
# pathlib から Path をインポートする
from pathlib import Path

# pygame は、画面の描画やキー入力などに使う道具の名前
# pygame をインポートする
import pygame
```

`from pathlib import Path` は、Pythonに最初からある `pathlib` から、ファイルやフォルダの場所を扱う `Path` を読み込みます。path は「経路」、lib はlibrary（道具の集まり）の略です。後の画像の読み込みで、Pythonファイルの隣にある `assets` を探すために使います。

`import pygame` は、追加したpygame-ceの処理を `pygame` という名前で使えるようにします。Pythonを入れただけではpygame-ceは追加されません。ページ上の保存・起動手順にある `pip install pygame-ce` で追加します。

`import` は、別に用意されたPythonの処理を使うための書き方です。`from ... import ...` は、その中の指定した名前を読み込む書き方です。

### pygameの準備をする

```python
# pygame を初期化する
pygame.init()
```

`pygame.init()` で、pygameの文字表示などの機能を使う準備をします。init はinitialize（初期化する）の略です。後でフォントを用意するため、先にここで準備します。

`()` が付いた名前は、その名前の処理を呼び出しています。指定する値が必要なときは、`()` の中に書きます。`pygame.init()` は、この呼び出しで指定する値がないので、括弧の中が空です。

### 画面を作り、ウィンドウのタイトルを付ける

```python
# screen は「画面」という意味
# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
# pygame画面のタイトルに「クリア後にタイトルへ戻る」をセットする
pygame.display.set_caption("クリア後にタイトルへ戻る")
```

`pygame.display.set_mode((640, 480))` で、ゲームを描く画面を作ります。display は「表示」、set_mode は「表示方法を設定する」という意味です。内側の `(640, 480)` は、横幅640、縦の高さ480をひと組にして指定しています。単位はピクセルです。ピクセルは画像や画面を構成する小さな点です。

`screen = ...` の `=` は、右側の結果を左側の名前に入れる書き方です。`screen` には、作った画面へ描くために使うものを入れます。このように値を名前で使う仕組みを「変数」と呼びます。後の `screen.blit(...)` なども同じ画面へ描きます。

`pygame.display.set_caption(...)` は、ゲームのウィンドウに付けるタイトルを決めます。caption は「見出し・説明文」という意味です。`"クリア後にタイトルへ戻る"` を指定すると、ウィンドウのタイトルになります。`"..."` で囲んだ文字を、Pythonでは「文字列」と呼びます。

画面内の `SPACE SHOOTER` は別の処理で描いています。`set_caption` を変えても、ゲーム画面内の文字はそのままです。

ここで画面サイズを変更する場合は、後の背景画像の大きさや、中央へ描く位置も合わせる必要があります。この変更例では、タイトルだけを変えます。

### 更新の間隔を調整する時計を用意する

```python
# clock は「時計」という意味
# 画面更新の間隔を調整する時計を用意する（後でclock.tick(60)に使う）
# clock に pygame.time.Clock() で作った時計を入れる
clock = pygame.time.Clock()
```

`pygame.time.Clock()` は、ゲームの更新の間隔を調整するための時計を作ります。time は「時間」、Clock は「時計」です。作った時計を `clock` という名前で使います。

このゲームは、入力を調べ、位置を動かし、画面を描く処理を繰り返します。後の `clock.tick(60)` で必要な待ち時間を入れ、1秒に行う更新を最大60回に制限します。tick は、時計を進める1回の区切りという意味です。必ず60回になるという指定ではありません。処理に時間がかかれば更新はそれより少なくなります。

時計を作るこの行だけでは、更新回数の制限はまだ行いません。

### 表示する文字の形と大きさを用意する

```python
# font は「フォント」という意味。文字の形と大きさを指定するもの
# Noneで同梱のFreeSans Boldを選び、自機とボスのHP表示用にサイズ36（ピクセル単位）を指定する
# font に pygame.font.Font(None, 36) で作ったフォントを入れる
font = pygame.font.Font(None, 36)

# clear_font は「クリア画面のフォント」という意味。ゲームオーバー画面にも使う
# Noneで同梱のFreeSans Boldを選び、クリア・ゲームオーバーの見出し用にサイズ72（ピクセル単位）を指定する
# clear_font に pygame.font.Font(None, 72) で作ったフォントを入れる
clear_font = pygame.font.Font(None, 72)

# clear_sub_font は「クリア画面の補足文のフォント」という意味。ほかの画面の説明文にも使う
# Noneで同梱のFreeSans Boldを選び、画面の説明文用にサイズ32（ピクセル単位）を指定する
# clear_sub_font に pygame.font.Font(None, 32) で作ったフォントを入れる
clear_sub_font = pygame.font.Font(None, 32)
# button_font は「ボタンのフォント」という意味
# Noneで同梱のFreeSans Boldを選び、ボタンの文字用にサイズ40（ピクセル単位）を指定する
# button_font に pygame.font.Font(None, 40) で作ったフォントを入れる
button_font = pygame.font.Font(None, 40)
# menu_font は「メニューのフォント」という意味。タイトルの見出しに使う
# Noneで同梱のFreeSans Boldを選び、タイトルの見出し用にサイズ64（ピクセル単位）を指定する
# menu_font に pygame.font.Font(None, 64) で作ったフォントを入れる
menu_font = pygame.font.Font(None, 64)
```

「フォント」は文字の形と大きさを指定するものです。`pygame.font.Font(None, 36)` は、pygame-ceに同梱されている **FreeSans Bold（freesansbold.ttf）** を、サイズ36で用意します。

`None` はPythonで「値がない」ことを表すものです。この `Font` の最初の指定を `None` にすると、外部のフォントファイルの代わりに同梱のフォントを使います。2つ目の数値はピクセル単位のサイズです。同じフォントで数値を大きくすれば、文字も大きくなります。表示した文字1個の幅が36ピクセルになるという意味ではありません。

| 名前 | 日本語の意味・用途 | サイズ |
| --- | --- | --- |
| `font` | フォント。自機とボスのHP表示に使う | 36 |
| `clear_font` | クリア画面のフォント。GAME CLEAR!とGAME OVERの見出しに使う | 72 |
| `clear_sub_font` | クリア画面の補足文のフォント。各画面の説明文に使う | 32 |
| `button_font` | ボタンのフォント。START・TITLE・RESTARTに使う | 40 |
| `menu_font` | メニューのフォント。SPACE SHOOTERの見出しに使う | 64 |

同じ形の文字を、見出し・説明文・ボタンで違う大きさにするため、別の名前で用意します。数値は、640×480の画面で見出しを大きくし、説明文やボタンの文字をそれより小さくするために選んでいます。固定されたルールではなく、表示結果を見て調整できます。

`Font` を用意しただけでは文字は画面へ出ません。完成コードの後の部分で、`render(...)` で表示する文字の画像を作り、`screen.blit(...)` で画面へ描きます。`render` は「描画する」、`blit` は画像を別の画像へ写す処理の名前です。

## ウィンドウのタイトルを変える

`clear_title.py` の **16行目** の `pygame.display.set_caption` を変えます。Windows / Linuxは Ctrl + F、macOSは Command + F を押し、検索欄へ次の文字を入力して探します。

```text
pygame.display.set_caption
```

変更前：

```python
# pygame画面のタイトルに「クリア後にタイトルへ戻る」をセットする
pygame.display.set_caption("クリア後にタイトルへ戻る")
```

文字列と、その直上の処理コメントを次のように変えます。

変更後：

```python
# pygame画面のタイトルに「私のシューティングゲーム」をセットする
pygame.display.set_caption("私のシューティングゲーム")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押して `clear_title.py` を保存します。実行中のゲームのウィンドウを閉じます。起動中のゲームには、ファイルの変更はそのまま反映されません。

`clear_title.py` を保存した練習用フォルダのパスをコピーします。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックし、フォルダのパス全体を Ctrl + C でコピーします。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でそのフォルダのパスをコピーします。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の欄を出し、フォルダのパスを Ctrl + C でコピーします。

VS Codeの **表示（View）→ ターミナル（Terminal）** でターミナルを開き、次の形で入力します。引用符の中を、上でコピーした練習用フォルダのパスに置き換えます。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付け、Enter キーを押します。

```text
cd "コピーした練習用フォルダのパス"
```

Windowsでは、同じターミナルへ次のコマンドを入力し、Enter キーを押します。

```text
.\.venv\Scripts\python.exe clear_title.py
```

macOS / Linuxでは、同じターミナルへ次のコマンドを入力し、Enter キーを押します。

```text
.venv/bin/python clear_title.py
```

ゲームを起動し直すと、ウィンドウのタイトルが「私のシューティングゲーム」になります。ゲーム内の `SPACE SHOOTER` やSTARTボタンは変わりません。ウィンドウのタイトルが画面に表示される位置は、OSの表示方法によって異なります。
