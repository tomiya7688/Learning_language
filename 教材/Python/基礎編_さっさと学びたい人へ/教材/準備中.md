# 完成品から学ぶコースの公開状況

> **「今、どの完成品を動かして学べるの？」**

このコースは、完成品を保存・実行して、そのコードを読み、値や処理を変えるための教材です。

[進む：完成品を選ぶ](../目次.md)

## 現在の公開状況

| 完成品 | 動かせる内容 | 完成コードを読む教材 |
| --- | --- | --- |
| **関数電卓** | 四則演算・小数点・sin・cos・答えの表示調整 | **全9章公開**。`app.py` と `calculator.py` を先頭から最後まで読む |
| **シューティングゲーム** | 自機・弾・敵・ボス・タイトル・ゲームオーバー・クリア | 起動・画面準備・画像・自機の位置と速さを読む4章が公開済み。続編は制作中 |
| **ブラウザアプリ** | Streamlitの入力欄に文字を入れ、画面の表示を変える | 起動・コードの読解・変更を公開済み |
| **Webの天気取得** | RequestsとWeb APIから気温・湿度を読み取り、ターミナルへ表示 | 保存・起動・コードの説明・表示の変更を1ページで公開済み |
