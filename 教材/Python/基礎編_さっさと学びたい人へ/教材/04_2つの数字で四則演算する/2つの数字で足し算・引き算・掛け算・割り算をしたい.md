# 2つの数字で足し算・引き算・掛け算・割り算をしたい

10と2を足すだけでなく、引いた答えや掛けた答えも確かめたいとします。答えを自分で計算して表示するコードへ書くのでは、計算を任せられません。

> **「答えは自分で書かずに、Pythonで計算したい！」**

このプログラムは、コードに書かれた2つの数字で足し算・引き算・掛け算・割り算をして、答えを表示します。数字を変えて別の計算も試せます。入力した数字を使う例は、ページ末尾の「入力した2つの数字を足す」にあります。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`calculate_numbers.py` の 1〜19行](./calculate_numbers.py#L1-L19)。

```python
# number1 は「1つ目の数字」という意味
# number1 に8を入れる
number1 = 8
# number2 は「2つ目の数字」という意味
# number2 に2を入れる
number2 = 2

# 足し算
# 「足し算:」と number1 に number2 を足した値を表示する
print("足し算:", number1 + number2)
# 引き算
# 「引き算:」と number1 から number2 を引いた値を表示する
print("引き算:", number1 - number2)
# 掛け算
# 「掛け算:」と number1 に number2 を掛けた値を表示する
print("掛け算:", number1 * number2)
# 割り算
# 「割り算:」と number1 を number2 で割った値を表示する
print("割り算:", number1 / number2)
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `calculate_numbers.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

calculate は「計算する」、numbers は「複数の数字」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./calculate_numbers.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`calculate_numbers.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python calculate_numbers.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 calculate_numbers.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
足し算: 10
引き算: 6
掛け算: 16
割り算: 4.0
```

## このコードの読み方

`number1 = 8` は、`8` に `number1` という名前を付けます。あとで値を使うための名前を **変数** と呼びます。`number2` も同じ書き方です。今回は4つの計算を見比べるため、割り切れる `8` と `2` を選んでいます。

数字や変数の間に `+`、`-`、`*`、`/` を書くと、それぞれ足し算・引き算・掛け算・割り算になります。Pythonの `/` は、この例でも整数の `4` ではなく小数を扱う数値の `4.0` を作ります。割る数字を `0` にするとエラーで終了します。

`print(...)` は、`()` の中で指定した値をターミナルに表示します。カンマで区切った内容の間には空白が入ります。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

1つ目の数字を `8` から `10` に変えてください。`number2` は `2` のままにしてください。

VS Codeで `calculate_numbers.py` を開き、**3行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
number1 =
```

[`calculate_numbers.py` の2〜3行](./calculate_numbers.py#L2-L3)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`calculate_numbers.py` の 2〜3行](./calculate_numbers.py#L2-L3)。

```python
# number1 に8を入れる
number1 = 8
```

変更後：

変更する場所：[`calculate_numbers.py` の 3行](./calculate_numbers.py#L3-L3)。

```python
# number1 に10を入れる
number1 = 10
```

## 保存してもう一度実行する

VS Codeで `calculate_numbers.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python calculate_numbers.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 calculate_numbers.py
```

同じターミナルに次の結果が表示されます。

```text
足し算: 12
引き算: 8
掛け算: 20
割り算: 5.0
```
