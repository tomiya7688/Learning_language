# 点数によって表示するメッセージを変えたい

このプログラムは、入力した点数が80以上なら「よくできました」、60以上80未満なら「合格です」、60未満なら「もう一度挑戦しましょう」と表示します。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# score は「点数」という意味
# score に「点数を入力してください: 」と表示して入力された内容を整数にして入れる
score = int(input("点数を入力してください: "))

# score が80以上なら、次の行を実行する
if score >= 80:
    # 「よくできました」と表示する
    print("よくできました")
# score が80未満で60以上なら、次の行を実行する
elif score >= 60:
    # 「合格です」と表示する
    print("合格です")
# score が60未満なら、次の行を実行する
else:
    # 「もう一度挑戦しましょう」と表示する
    print("もう一度挑戦しましょう")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `judge_score.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

judge は「判定する」、score は「点数」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./judge_score.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`judge_score.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python judge_score.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 judge_score.py
```

## 実行結果

案内が表示されたら、同じターミナルで **75** と入力し、Enter キーを押してください。`75` が自分で入力する部分です。

```text
点数を入力してください: 75
合格です
```

## このコードの読み方

Pythonでは、文字の並びを値として扱うとき、その値を **文字列** と呼びます。コードの中では `"こんにちは"` のように引用符で囲んで書いてください。

`input(...)` はターミナルでの入力を待ちます。Enter キーで確定した内容を文字列として受け取り、Pythonは `int(...)` で整数（小数点のない数）に変換します。`score = ...` は、その整数に `score` という名前を付けます。あとで値を使うための名前を **変数** と呼びます。整数に変換できない入力はエラーで終了します。

`>=` は「左側が右側以上」を確認します。`if 条件:` の行で条件を確認し、当てはまったときだけ、その下の右にずらした行を実行します。

`elif` は同じ組の `if` の後ろに書き、前の条件に当てはまらなかった場合に別の条件を確認します。`else:` はその組の最後に書き、どの条件にも当てはまらなかった場合の処理を置きます。このプログラムは上から順に確認して、1つのメッセージだけを表示します。80と60は、この例で評価を分ける境目です。

行の先頭の空白で処理のまとまりを示す書き方を **インデント** と呼びます。`print(...)` の前には半角の空白を4つ入れます。`if`、`elif`、`else` の行末の `:` も必要です。

`print(...)` は指定した内容をターミナルに表示します。`input`、`int`、`print` のように名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

一番上の評価の境目を80から90に変えてください。10行目の直上のコメントも「score が90未満で60以上なら、次の行を実行する」に変え、コードと説明を合わせてください。

VS Codeで `judge_score.py` を開き、**6行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
if score >= 80:
```

対象の行と、その直上の処理コメントを、次のように置き換えてください。

変更前：

```python
# score が80以上なら、次の行を実行する
if score >= 80:
```

変更後：

```python
# score が90以上なら、次の行を実行する
if score >= 90:
```

## 保存してもう一度実行する

VS Codeで `judge_score.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python judge_score.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 judge_score.py
```

同じターミナルで **85** と入力し、Enter キーを押してください。変更前なら「よくできました」ですが、変更後は「合格です」と表示されます。

```text
点数を入力してください: 85
合格です
```
