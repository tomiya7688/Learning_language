# ファイルに保存したメモを読みたい

メモをファイルへ保存できても、自分のプログラムがその内容を読めなければ、毎回手で写すことになります。

> **「保存したメモを、そのままプログラムで読みたい！」**

この例は、ファイルからメモを読み、ターミナルへ表示します。このページでメモのファイルも用意するため、先に保存の教材を読む必要はありません。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`read_memo.py` の 1〜9行](./read_memo.py#L1-L9)。

```python
# file は「ファイル」という意味
# purpose_memo.txt をUTF-8で読み込み用に開き、file という名前で使う
with open("purpose_memo.txt", "r", encoding="utf-8") as file:
    # text は「文章」という意味
    # text に file が表すファイルの内容をすべて読み込んで入れる
    text = file.read()

# text を表示し、表示のあとに改行を追加しない
print(text, end="")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `read_memo.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

read は「読む」、memo は「メモ」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./read_memo.py)

## 読み込むメモを用意する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次の1行を書き、その行の最後で Enter キーを押して改行してください。

```text
こんにちは
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、`read_memo.py` と同じ練習用フォルダに `purpose_memo.txt` という名前で保存してください。文字コードはUTF-8にしてください。VS Codeの右下にUTF-8以外が表示されている場合は、その表示をクリックして「エンコード付きで保存」を選び、UTF-8を選んで保存してください。

purpose は「目的」、memo は「メモ」という意味です。 `.txt` は文章を保存するファイルの末尾に使っています。

[読み込むメモのサンプルを開く](./purpose_memo.txt)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`read_memo.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python read_memo.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 read_memo.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
こんにちは
```

## このコードの読み方

`open("purpose_memo.txt", "r", encoding="utf-8")` は、練習用フォルダにある指定したファイルを読み込み用に開きます。`"r"` は読み込み、`encoding="utf-8"` は保存した日本語の読み方を指定しています。`as file` は、開いたファイルを `file` という名前で使う指定です。

`file.read()` はファイルの内容をすべて読み、`text = ...` でその内容に `text` という名前を付けます。あとで値を使うための名前を **変数** と呼びます。読み込んだ文字の並びは **文字列** と呼ばれる値です。

`with ...:` の下に右へずらして書いた処理が終わると、ファイルは自動的に閉じられます。行頭の空白で処理のまとまりを示す書き方を **インデント** と呼びます。読み込む行の前には半角の空白を4つ入れます。

`print(text, end="")` は内容をターミナルに表示し、追加の改行を付けません。ファイル内にすでにある改行はそのまま表示されます。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

ファイルが見つからない場合は、エクスプローラーやFinderなどで `read_memo.py` と `purpose_memo.txt` が同じフォルダにあることを確認し、そのフォルダへ `cd` してから実行してください。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

読み込んだ内容の前に「メモ:」を表示するコードに変更してください。

VS Codeで `read_memo.py` を開き、**9行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
print(text
```

[`read_memo.py` の8〜9行](./read_memo.py#L8-L9)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`read_memo.py` の 8〜9行](./read_memo.py#L8-L9)。

```python
# text を表示し、表示のあとに改行を追加しない
print(text, end="")
```

変更後：

変更する場所：[`read_memo.py` の 9行](./read_memo.py#L9-L9)。

```python
# 「メモ:」と text を表示し、表示のあとに改行を追加しない
print("メモ:", text, end="")
```

## 保存してもう一度実行する

VS Codeで `read_memo.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python read_memo.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 read_memo.py
```

同じターミナルに次の結果が表示されます。

```text
メモ: こんにちは
```
