# 数字以外を入力したときに、案内を表示したい

整数にできる入力なら2倍にして表示します。「ねこ」のように数字以外を入力したら、案内を表示して終了します。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備します。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開きます（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# 下の処理を試し、整数に変換できない場合は except の処理へ進む
try:
    # number は「数字」という意味
    # number に「数字を入力してください: 」と表示して入力された内容を整数にして入れる
    number = int(input("数字を入力してください: "))
# 入力を整数に変換できなかった場合、下の行を実行する
except ValueError:
    # 「数字を入力してください」と表示する
    print("数字を入力してください")
# 入力を整数に変換できた場合、下の行を実行する
else:
    # number に2を掛けた値を表示する
    print(number * 2)
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `safe_number.py` という名前で保存します。ファイル名の最後は `.py` にします。

safe は「安全な」、number は「数字」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./safe_number.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

### 保存先フォルダのパスをコピーする

`safe_number.py` を保存したフォルダの場所を、次の操作でコピーします。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックします。表示されたフォルダのパス全体を選び、Ctrl + C を押します。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーします。ファイルではなくフォルダを選びます。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーします。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力します。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けます。入力し終えたら Enter キーを押します。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しません。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python safe_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 safe_number.py
```

## 実行結果

案内が表示されたら、同じターミナルで **ねこ** と入力し、Enter キーを押します。案内の後ろの `ねこ` が自分で入力する部分です。

```text
数字を入力してください: ねこ
数字を入力してください
```

## このコードの読み方

`input(...)` はターミナルで入力を待ち、Enter キーで確定した内容を文字列（文字の並びを扱う値）として受け取ります。`int(...)` は整数（小数点のない数）へ変換します。変換できないと `ValueError` という問題が発生します。このような実行中の問題を **例外** と呼びます。

`try:` の下に試す処理を書き、`except ValueError:` の下に、その例外が起きた場合の処理を書きます。`else:` は同じ組の最後に書き、例外が起きなかった場合の処理を置きます。今回は「ねこ」なら案内を表示し、`6` なら `12` を表示します。再入力を待つ処理はありません。

`number = ...` は変換した整数に名前を付けます。あとで値を使うための名前を **変数** と呼びます。`*` は掛け算、`print(...)` は指定した内容をターミナルに表示します。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

行頭の空白で処理のまとまりを示す書き方を **インデント** と呼びます。`try`、`except`、`else` の下は半角の空白4つで書きます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

入力ミスの案内を変えます。行頭の空白4つも残してください。

VS Codeで `safe_number.py` を開き、**9行目**を探します。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押します。検索欄に次の文字を入力して、対象の行を探します。

```text
print("数字を入力してください")
```

対象の行と、その直上の処理コメントを、次のように置き換えます。

変更前：

```python
    # 「数字を入力してください」と表示する
    print("数字を入力してください")
```

変更後：

```python
    # 「整数で入力してください」と表示する
    print("整数で入力してください")
```

## 保存してもう一度実行する

VS Codeで `safe_number.py` を保存します。Windows / Linuxは Ctrl + S、macOSは Command + S を押します。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力します。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選びます。

保存先フォルダへ移動済みなら、次の実行コマンドへ進みます。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押します。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python safe_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力します。
2. Enter キーを押します。

```text
python3 safe_number.py
```

同じターミナルで **ねこ** と入力し、Enter キーを押します。

```text
数字を入力してください: ねこ
整数で入力してください
```
