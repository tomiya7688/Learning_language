# 名前と点数の組をファイルへ保存して読みたい

名前と点数を保存して、あとから点数だけを使いたいとします。「たろう、80」と並べるだけでは、どの値が何の項目なのかを順番で覚える必要があります。

> **「『名前』『点数』の項目名も一緒にファイルへ残したい！」**

この例は、名前がたろう・点数が80という情報を、項目名と値の組で記録するJSONという形式のファイルへ保存し、読み直して表示します。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

この例は練習用の `purpose_student.json` を作り、同じ名前のファイルがあれば中身を書き直します。自分のメモなどと分けるため、新しい練習用フォルダを作り、その中へサンプルを保存して実行してください。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`save_read_json.py` の 1〜21行](./save_read_json.py#L1-L21)。

```python
# JSONを読み書きするための json の処理を使えるようにする
import json

# student は「生徒」という意味
# student に名前が「たろう」、点数が80の情報を入れる
student = {"名前": "たろう", "点数": 80}

# file は「ファイル」という意味
# purpose_student.json をUTF-8で書き込み用に開き、file という名前で使う
with open("purpose_student.json", "w", encoding="utf-8") as file:
    # student を日本語をそのまま残し空白2つで段をそろえたJSONとして file へ書き込む
    json.dump(student, file, ensure_ascii=False, indent=2)

# purpose_student.json をUTF-8で読み込み用に開き、file という名前で使う
with open("purpose_student.json", "r", encoding="utf-8") as file:
    # loaded_student は「読み込んだ生徒」という意味
    # loaded_student に file からJSONを読み込んで入れる
    loaded_student = json.load(file)

# loaded_student の「名前」と「点数」を表示する
print(loaded_student["名前"], loaded_student["点数"])
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `save_read_json.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

save は「保存する」、read は「読む」、JSONは名前付きのデータを保存するファイルの書き方の名前です。`.py` はPythonのコードを書いたファイルの末尾に付けます。保存先の `purpose_student.json` は、この例で使う生徒の情報のファイル名です。purpose は「目的」、student は「生徒」という意味です。

[サンプルファイルを開く](./save_read_json.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`save_read_json.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python save_read_json.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 save_read_json.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
たろう 80
```

練習用フォルダの `purpose_student.json` をVS Codeで開くと、次の内容になっています。

```json
{
  "名前": "たろう",
  "点数": 80
}
```

## このコードの読み方

`{"名前": "たろう", "点数": 80}` のように、項目と値を組にしてまとめるものをPythonでは **辞書** と呼びます。`student` のように値を使うための名前を **変数** と呼びます。引用符で囲んだ値は **文字列**（文字の並び）、`80` は数値です。

このような情報をファイルへ保存する書き方の1つが **JSON** です。`import json` は、Pythonに最初から用意されている読み書きの処理を使えるようにします。追加のインストールは必要ありません。

`open(..., "w", ...)` はファイルを新しく書き込み、同じ名前のファイルがあれば中身を書き直します。`"r"` は読み込み、`encoding="utf-8"` は日本語の記録方法です。`with ... as file:` の下でファイルを使い、処理が終わると自動的に閉じます。

`json.dump(student, file, ...)` は、情報をJSONとしてファイルに書きます。`ensure_ascii=False` は日本語をそのまま書き、`indent=2` はファイル内の段を空白2つでそろえる指定です。`json.load(file)` はJSONを読み込み、ここではPythonの辞書として `loaded_student` に入れます。

このコードは、`loaded_student["名前"]` のように項目を指定して値を取り出す処理です。`print(...)` はターミナルに表示します。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。コードの行頭の空白で処理のまとまりを示す書き方を **インデント** と呼び、`with` の中には空白4つを入れてください。保存先JSONの空白2つとは別の指定です。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

保存する名前と点数を、さくら・95点へ変えてください。`loaded_student =` の行は変更しないでください。

VS Codeで `save_read_json.py` を開き、**6行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
student =
```

[`save_read_json.py` の5〜6行](./save_read_json.py#L5-L6)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`save_read_json.py` の 5〜6行](./save_read_json.py#L5-L6)。

```python
# student に名前が「たろう」、点数が80の情報を入れる
student = {"名前": "たろう", "点数": 80}
```

変更後：

変更する場所：[`save_read_json.py` の 6行](./save_read_json.py#L6-L6)。

```python
# student に名前が「さくら」、点数が95の情報を入れる
student = {"名前": "さくら", "点数": 95}
```

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python save_read_json.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text

```

同じターミナルに次の結果が表示されます。

```text
さくら 95
```
