# 1-5. 仮想環境 venv

1つのアプリで使う追加の機能を更新したら、別のアプリが動かなくなった、といったことがあります。アプリごとに別のバージョンが必要な場合、同じ場所で管理すると困ります。

> **「こっちを直したら、あっちが動かない！アプリごとに分けたい！」**

追加した機能を作業用フォルダごとに分けるために、Pythonの **仮想環境** を使えます。このページでは作り方と使い始める操作を扱います。完成ゲームとブラウザアプリは、各ページの起動手順で仮想環境を作り、その中へ必要な機能を追加します。

## 作成

作業用フォルダのパス（場所を表す文字列）をコピーしてください。Windowsはエクスプローラーでフォルダを開き、上部のアドレス欄をクリックしてCtrl + Cを押してください。macOSはFinderでフォルダを選び、Option + Command + Cを押してください。Linuxは「ファイル」でフォルダを開き、Ctrl + Lで場所欄を出してCtrl + Cを押してください。下の `cd` の引用符の中へ、WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

Windows:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 同じターミナルに `cd "このプログラムの作業用フォルダのパス"` と入力し、Enter キーを押してください。引用符の中は、自分の作業用フォルダの場所に置き換えてください。
3. 次のコマンドを、そのターミナルに入力してください。
4. Enter キーを押してください。

```powershell
python -m venv .venv
```

macOS / Linux:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 同じターミナルに `cd "このプログラムの作業用フォルダのパス"` と入力し、Enter キーを押してください。引用符の中は、自分の作業用フォルダの場所に置き換えてください。
3. 次のコマンドを、そのターミナルに入力してください。
4. Enter キーを押してください。

```bash
python3 -m venv .venv
```

## 有効化（任意）

有効化は、そのターミナルで `python` と入力したときに、作業用フォルダの仮想環境を使う設定です。完成ゲームとブラウザアプリの起動ページでは、`.venv` 内のPythonの場所をコマンドへ直接書くため、有効化の操作は必須ではありません。

WindowsのPowerShellでは、下の `Activate.ps1` を実行してください。スクリプトを実行できないというエラーが出た場合も、`.venv` 内のPythonを直接指定できます。VS Codeの **表示（View）→ ターミナル（Terminal）** で作業用フォルダへ移動済みのターミナルを開き、`.\.venv\Scripts\python.exe --version` と入力してEnterキーを押してください。仮想環境のPythonのバージョンが表示されます。完成品の起動は各起動ページの `.venv` を指定したコマンドを使ってください。[Python公式の仮想環境の使い方](https://docs.python.org/3/library/venv.html#how-venvs-work)

Windows:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS / Linux:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```bash
source .venv/bin/activate
```

有効になると、ターミナルの先頭に次のような表示が出ることがあります。

```text
(.venv)
```

## 有効化を終了する

仮想環境を有効化した場合は、次の操作で元のPythonを使う設定へ戻してください。`.venv` のPythonを直接指定していた場合は、この操作は不要です。

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
deactivate
```

完成ゲームとブラウザアプリを選んだ場合は、それぞれの保存・起動ページに、仮想環境へ必要な機能を追加するコマンドがあります。[完成品を選ぶ目次](../../目次.md)へ戻り、動かしたい完成品を選んでください。
