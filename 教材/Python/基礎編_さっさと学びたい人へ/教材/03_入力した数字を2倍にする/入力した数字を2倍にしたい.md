# 入力した数字を2倍にしたい

1個の値段から、2個分の金額を計算したいとします。「120」と表示するだけでは、2個分の240は出ません。

> **「入力した数字を使って、計算した答えが欲しい！」**

この例は、入力した数字を2倍にして表示します。試すときは、小数点のない数字を入力してください。120なら240、80なら160が表示されます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`double_number.py` の 1〜6行](./double_number.py#L1-L6)。

```python
# number は「数字」という意味
# number に「数字を入力してください: 」と表示して入力された内容を整数にして入れる
number = int(input("数字を入力してください: "))

# number に2を掛けた値を表示する
print(number * 2)
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `double_number.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

double は「2倍にする」、number は「数字」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./double_number.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`double_number.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python double_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 double_number.py
```

## 実行結果

案内が表示されたら、同じターミナルで **6** と入力し、Enter キーを押してください。`6` が自分で入力する部分で、`12` がプログラムの表示です。

```text
数字を入力してください: 6
12
```

## このコードの読み方

Pythonでは、文字の並びを値として扱うとき、その値を **文字列** と呼びます。コードの中では `"こんにちは"` のように引用符で囲んで書いてください。

`input(...)` はターミナルでの入力を待ち、Enter キーで確定した内容を文字列として受け取ります。そのため、入力した `6` を計算に使うには数値に変換してください。

`int(...)` は、ここでは入力された文字列を **整数**（小数点のない数）に変換します。`number = ...` で、その整数に `number` という名前を付けます。あとで内容を使うための名前を **変数** と呼びます。

`number * 2` の `*` は掛け算です。`print(...)` は `()` の中で指定した値をターミナルに表示します。`int`、`input`、`print` のように名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

この例には入力ミスからやり直す処理はありません。整数に変換できない内容を入力すると、エラーで終了します。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

小数点のある数字も計算したい場合は、`int` を `float` に変えてください。`float(...)` は、ここでは入力された文字列を小数を扱える数値に変換します。小数点には半角の `.` を使ってください。

VS Codeで `double_number.py` を開き、**3行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
int(input(
```

[`double_number.py` の2〜3行](./double_number.py#L2-L3)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`double_number.py` の 2〜3行](./double_number.py#L2-L3)。

```python
# number に「数字を入力してください: 」と表示して入力された内容を整数にして入れる
number = int(input("数字を入力してください: "))
```

変更後：

変更する場所：[`double_number.py` の 3行](./double_number.py#L3-L3)。

```python
# number に「数字を入力してください: 」と表示して入力された内容を小数を扱える数値にして入れる
number = float(input("数字を入力してください: "))
```

## 保存してもう一度実行する

VS Codeで `double_number.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python double_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 double_number.py
```

同じターミナルで **2.5** と入力し、Enter キーを押してください。

```text
数字を入力してください: 2.5
5.0
```
