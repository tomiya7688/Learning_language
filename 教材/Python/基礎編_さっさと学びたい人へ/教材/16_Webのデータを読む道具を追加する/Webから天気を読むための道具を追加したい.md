# Webから天気を読むための道具を追加したい

自分のプログラムで天気のデータを使いたいとします。インターネットからデータを受け取る処理を全部自分で書くのは大変です。

> **「天気を調べたいだけ！データを読む道具を使いたい！」**

このページでは、Webからデータを読むRequestsという道具を追加し、Pythonから使えることを確かめてください。気温と湿度を表示するサンプルは、天気を取得するページで扱います。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`check_requests.py` の 1〜6行](./check_requests.py#L1-L6)。

```python
# requests は「要求」という意味
# 追加した Requests の処理を requests という名前で使えるようにする
import requests

# 「天気を読むための道具を使えます」と表示する
print("天気を読むための道具を使えます")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `check_requests.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

check は「確認する」、requests は「要求」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./check_requests.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`check_requests.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Webのデータを読む道具を追加する

練習用フォルダの `.venv` に専用のPython実行環境を作り、Requestsを追加してください。使うのはこのフォルダのPythonです。実行するPythonの場所をコマンドに書いてください。インストールにはインターネット接続が必要です。

### Windows

まず専用の実行環境を作ってください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python -m venv .venv
```

続けて、作った環境のPythonへRequestsを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe -m pip install requests
```

追加が終わったら、保存したファイルを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe check_requests.py
```

### macOS / Linux

まず専用の実行環境を作ってください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 -m venv .venv
```

続けて、作った環境のPythonへRequestsを追加してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python -m pip install requests
```

追加が終わったら、保存したファイルを実行してください。

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python check_requests.py
```

`-m venv` を指定したコマンドは専用の環境を作り、`-m pip install requests` を指定したコマンドはその環境へRequestsを追加します。作成や追加に失敗した場合は表示されたエラーを確認し、プログラムの実行へ進む前に、ページ上部の準備手順でPythonを確認してください。

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
天気を読むための道具を使えます
```

## このコードの読み方

`requests` はPython本体とは別に配布されている道具です。このように追加する機能の集まりを **外部ライブラリ** と呼びます。`pip` は、そのライブラリをインストールするための操作に使います。

このページでは、練習用フォルダの `.venv` にPythonの実行環境を作り、そこへRequestsを追加してください。このように専用の実行環境を用意することを **仮想環境** と呼びます。`.venv` のPythonでインストールし、同じPythonでプログラムを動かしてください。

`import requests` が成功すると、その次の表示へ進みます。`print(...)` は指定した内容をターミナルに表示します。引用符で囲んで書く文字の並びを **文字列** と呼びます。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

この確認コードでは、天気の取得までは行いません。ページ末尾のリンクから、追加したRequestsで気温と湿度を取得するコードへ進めます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

読み込みに成功したときのメッセージを変えてください。

VS Codeで `check_requests.py` を開き、**6行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
print(
```

[`check_requests.py` の5〜6行](./check_requests.py#L5-L6)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`check_requests.py` の 5〜6行](./check_requests.py#L5-L6)。

```python
# 「天気を読むための道具を使えます」と表示する
print("天気を読むための道具を使えます")
```

変更後：

変更する場所：[`check_requests.py` の 6行](./check_requests.py#L6-L6)。

```python
# 「Requestsを読み込めました」と表示する
print("Requestsを読み込めました")
```

## 保存してもう一度実行する

VS Codeで `check_requests.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.\.venv\Scripts\python.exe check_requests.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、次のコマンドを入力してください。
2. Enter キーを押してください。

```text
.venv/bin/python check_requests.py
```

同じターミナルに次の結果が表示されます。

```text
Requestsを読み込めました
```
