# 公開中の電卓を保存して動かす

> **「自分で使える電卓にしたい！まずこのコードを動かしたい！」**

数字ボタン・小数点ボタン・計算ボタンをクリックして、小数も含む四則演算の答えを出す電卓です。Tk9のコードを保存して動かし、そのあとコードの説明へ進めます。

![公開中の電卓の画面構成](./assets/calculator.svg)

公開サンプルをもとにした画面構成図です。色や文字の形はパソコンによって変わります。

関数電卓を目指すルートの途中までを公開しています。現在は四則演算ができます。0〜9の数字と小数点は、電卓画面のボタンをクリックして入力してください。sin/cosは未公開です。

PythonとVS Codeをまだ使えない場合は、先に準備してください。準備後は、このページへ戻ってください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## 完成コードを保存する

1. 練習用の新しいフォルダを作ってください。Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderで **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。ここでは `calculator_practice` としてください。`calculator` は「電卓」、`practice` は「練習」という意味です。各章で起動するファイル名は `app.py` にそろえます。
2. 次の一覧から保存するファイルを選び、そのリンクを開いてください。GitHubのファイル画面で **Raw** を開くと、選んだファイルのコードだけが表示されます。
3. Windows / Linuxは Ctrl + A、Ctrl + C、macOSは Command + A、Command + C を押して、開いたファイルのコード全体をコピーしてください。
4. VS Codeで新しいファイルを開き（Windows / Linuxは Ctrl + N、macOSは Command + N）、コード全体を貼り付けてください（Windows / Linuxは Ctrl + V、macOSは Command + V）。
5. Windows / Linuxは Ctrl + S、macOSは Command + S を押し、`calculator_practice` フォルダへ一覧と同じファイル名で保存してください。末尾の `.py` まで入力してください。もう一方のファイルも、手順2〜5で同じフォルダへ保存してください。

| 保存するファイル | 内容 |
| --- | --- |
| [`calculator.py`](../../../基礎編_ゆっくり学びたい人へ/教材/Tk09_小数点を置く/calculator.py) | 電卓の画面、入力した式、計算処理をまとめた `CalculatorApp` の定義です。電卓の機能を変更するファイルです。 |
| [`app.py`](../../../基礎編_ゆっくり学びたい人へ/教材/Tk09_小数点を置く/app.py) | 同じフォルダの `calculator.py` から電卓の定義を読み込み、電卓を起動します。ターミナルで実行するファイルです。 |

`calculator_practice` フォルダに `calculator.py` と `app.py` の両方があることを確認してください。`app.py` だけを保存すると、読み込む電卓の定義が見つからず起動できません。

## 保存したフォルダへ移動する

これからは、保存した `app.py` を動かしてください。まず、そのファイルが入ったフォルダの場所をコピーしてください。場所を表す文字列を「パス」と呼びます。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックしてください。フォルダのパス全体を Ctrl + C でコピーしてください。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の入力欄を出し、Ctrl + C でパスをコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。ターミナルは、文字で操作を入力する場所です。そのターミナルに次のコマンドを入力してください。引用符の中を、エクスプローラーのアドレス欄、Finderのフォルダ選択、Linuxのフォルダの場所欄でコピーした `calculator_practice` フォルダのパスに置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力後にEnterキーを押すと、ターミナルの現在のフォルダが `calculator_practice` に変わります。

```text
cd "コピーしたcalculator_practiceフォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。コードを書いた欄には入力しないでください。`PS C:\Users\...>` など、すでに表示されている文字も入力しないでください。

## 電卓を起動する

このサンプルは、Tkinter（ティーケーインター）という画面を作る道具を使います。

### Windows

VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、`cd` で `calculator_practice` へ移動したターミナルを表示してください。そのターミナルに次のコマンドを入力し、Enterキーを押してください。「小数点を置く」というタイトルの画面に、数字の入力欄、計算ボタン、0〜9・C・小数点のボタンが表示されます。

```text
python app.py
```

### macOS / Linux

VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、`cd` で `calculator_practice` へ移動したターミナルを表示してください。そのターミナルに次のコマンドを入力し、Enterキーを押してください。「小数点を置く」というタイトルの画面に、数字の入力欄、計算ボタン、0〜9・C・小数点のボタンが表示されます。

```text
python3 app.py
```

`No module named tkinter` と表示された場合は、使っているPythonにTkinterが入っていません。Pythonのインストール元やOSの案内に従ってTkinterを追加してから、同じコマンドで実行してください。

## 1.5 + 2.5 を計算する

小数点ボタンの「.」は、Pythonで小数を書く記号に合わせています。電卓画面の「.」ボタンを数字より先に押すと `0.` が入り、2個目の点を押しても追加されません。

足し算・引き算・答えを出すボタンは、電卓で使う記号の「+」「-」「=」に合わせています。掛け算と割り算のボタンには、Pythonで計算式を書くときの記号「*」「/」を使います。

1. 電卓画面の「C」ボタンで入力と式を消し、電卓画面の「1」「.」「5」の各ボタンを順に押してください。「数字」の入力欄に `1.5`、式の欄に `計算式:`、結果の欄に `答え:` と表示されます。
2. 電卓画面の「+」ボタンをクリックしてください。式の欄に `計算式: 1.5 +` と表示され、入力欄が空になります。
3. 電卓画面の「2」「.」「5」の各ボタンを順に押してください。数字の入力欄に `2.5` と表示され、式の欄は `計算式: 1.5 +` のままです。
4. 電卓画面の「=」ボタンを押してください。式の欄に `計算式: 1.5 + 2.5 = 4.0`、結果の欄に `答え: 4.0` と表示され、入力欄にも答えの `4.0` が入ります。`.0` は小数部分が0であることを表します。

「-」は引き算、「*」は掛け算、「/」は割り算のボタンです。正常な計算の答えの `4.0` が入力欄にある状態で、電卓画面の計算記号ボタンを押すと、その答えを使って計算を続けられます。新しい計算を始める場合は、電卓画面の数字ボタンか小数点ボタンを押してください。前の答えと式が消え、数字ボタンなら押した数字、小数点ボタンなら `0.` が入力欄へ入ります。

「C」はClear（消去）の頭文字です。入力や式を最初からやり直すためのボタンです。途中の入力を間違えた場合に電卓画面の「C」ボタンを押すと、入力欄と保存した式が消え、式の欄は `計算式:`、結果の欄は `答え:` に戻ります。

0で割る式は「0では割れません」と表示されます。0で割った後には答えがなく、入力欄には割る数の `0` が残ります。その後に電卓画面の数字ボタンをクリックすると、残った `0` と前の式を消して、その数字から新しい入力を始めます。電卓画面の計算記号ボタンを押した場合は、残る `0` を新しい計算の最初の数字として使います。キーボードで `1.2.3` など数値へ変換できない文字列を入力して計算ボタンを押すと、結果の欄に「数字を入力してください（例: 1.5）」と表示されます。入力欄の文字列と保存済みの式は残るため、入力欄をクリックし、Ctrl + A（macOSはCommand + A）で全体を選んで数字へ書き換え、電卓画面の計算ボタンを押し直してください。キーボードで新しい計算を始める場合は、最初に電卓画面の「C」ボタンを押してください。

`float`（小数も扱える数値）の計算では、たとえば `0.1 + 0.2` が `0.30000000000000004` と表示される場合があります。この電卓は答えを丸めずに表示します。

終了するときは、電卓の画面を閉じてください。
