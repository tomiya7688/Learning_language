# 公開中の電卓を保存して動かす

> **「自分で使える電卓にしたい！まずこのコードを動かしたい！」**

入力欄へ数字を打ち込み、計算ボタンを押して答えを出す電卓です。完成したTk7のコードを保存して動かし、そのあとコードの説明へ進めます。

![公開中の電卓の画面構成](./assets/calculator.svg)

公開サンプルをもとにした画面構成図です。色や文字の形はパソコンによって変わります。

関数電卓を目指すルートの途中までを公開しています。現在は四則演算ができます。数字はキーボードで入力してください。数字ボタン・小数点ボタン・sin/cosは未公開です。

PythonとVS Codeをまだ使えない場合は、先に準備してください。準備後は、このページへ戻ってください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## 完成コードを保存する

1. 練習用の新しいフォルダを作ってください。Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderで **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。ここでは `calculator_practice` としてください。`calculator` は「電卓」、`practice` は「練習」という意味です。各章で起動するファイル名は `app.py` にそろえます。
2. 下の完成コードへのリンクを開いてください。GitHubのファイル画面で **Raw** を開くと、コードだけが表示されます。
3. Windows / Linuxは Ctrl + A、Ctrl + C、macOSは Command + A、Command + C を押して、コード全体をコピーしてください。
4. VS Codeで新しいファイルを開き（Windows / Linuxは Ctrl + N、macOSは Command + N）、コード全体を貼り付けてください（Windows / Linuxは Ctrl + V、macOSは Command + V）。
5. Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `app.py` という名前で保存してください。末尾の `.py` まで入力してください。

[完成コードを開く：app.py](../../../基礎編_ゆっくり学びたい人へ/教材/Tk07_割り算を用意する/app.py)

このサンプルは、保存したPythonファイル1つで動きます。

## 保存したフォルダへ移動する

これからは、保存した `app.py` を動かしてください。まず、そのファイルが入ったフォルダの場所をコピーしてください。場所を表す文字列を「パス」と呼びます。

- Windows：エクスプローラーで練習用フォルダを開き、上部のアドレス欄をクリックしてください。フォルダのパス全体を Ctrl + C でコピーしてください。
- macOS：Finderで練習用フォルダを選択し、Option + Command + C でパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」の例）：練習用フォルダを開き、Ctrl + L で場所の入力欄を出し、Ctrl + C でパスをコピーしてください。

1. VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。ターミナルは、文字で操作を入力する場所です。
2. 次の形で入力してください。引用符の中を、上の操作でコピーしたフォルダのパスに置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。
3. Enter キーを押してください。

```text
cd "コピーした練習用フォルダのパス"
```

`cd` は、ターミナルで使うフォルダを変える操作です。コードを書いた欄には入力しないでください。`PS C:\Users\...>` など、すでに表示されている文字も入力しないでください。

## 電卓を起動する

このサンプルは、Tkinter（ティーケーインター）という画面を作る道具を使います。

### Windows

1. VS Codeの **表示（View）→ ターミナル（Terminal）** でターミナルを開いてください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
python app.py
```

### macOS / Linux

1. VS Codeの **表示（View）→ ターミナル（Terminal）** でターミナルを開いてください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
python3 app.py
```

実行すると「割り算を用意する」というタイトルの画面が開きます。`No module named tkinter` と表示された場合は、使っているPythonにTkinterが入っていません。Pythonのインストール元やOSの案内に従ってTkinterを追加してから、同じコマンドで実行してください。

## 10 + 2 を計算する

1. 「数字」の下の入力欄をクリックして、キーボードで `10` と入力してください。Enterは押さず、画面の「+」ボタンをクリックしてください。
2. 入力欄が空になるので、`2` と入力してください。
3. 「=」ボタンをクリックしてください。
4. 電卓が、計算式に `10.0 + 2.0 = 12.0`、答えに `答え: 12.0` と表示します。`.0` は小数部分が0であることを表しています。

「-」は引き算、「*」は掛け算、「/」は割り算のボタンです。同じ手順で演算ボタンを変えると、別の計算を試せます。

数字以外の文字（例：こんにちは）は入力しないでください。この公開サンプルには、その入力ミスを案内する処理は入っていません。

終了するときは、電卓の画面を閉じてください。
