# 完成したブラウザアプリのコードを読む

> **「入力した名前が画面に出た！見出しや質問を自分で変えたい！」**

このアプリは、ブラウザの入力欄で受け取った名前を使って挨拶を表示します。まだ起動していない場合は、同じコースの[ブラウザアプリを保存して動かす手順](../ブラウザアプリを動かす.md)でコードの保存と起動を行ってください。コードを読むときも、このフォルダの `streamlit_greeting.py` を使います。greetingは「挨拶」という意味です。

## 見出し・入力欄・挨拶の順に読む

元ファイル：[`streamlit_greeting.py` 全体](./streamlit_greeting.py)。

```python
# streamlitを、このプログラムで st という名前で使えるようにする
import streamlit as st

# ブラウザ画面に「名前を入力してみよう」というタイトルを表示する
st.title("名前を入力してみよう")

# 「名前」と表示した入力欄をブラウザ画面に置き、入力された文字列を name に入れる
name = st.text_input("名前")

# name が空の文字列でなければ、次の処理を実行する
if name:
    # ブラウザ画面に「こんにちは」と name の値を表示する
    st.write("こんにちは", name)
```

Streamlitは、Pythonからブラウザに見出しや入力欄を置くために追加した道具です。[2行目](./streamlit_greeting.py#L2)は、Streamlitを、このファイル内では `st` という短い名前で使えるようにします。

[5行目](./streamlit_greeting.py#L5)の `st.title` は、括弧の中で指定した文字列を画面の見出しにします。文字列は、文字をひとまとまりの値として扱ったものです。このコードの文字列は、前後を `"` で囲んでいます。

[8行目](./streamlit_greeting.py#L8)の `st.text_input` は、「名前」という案内を付けた入力欄を置きます。入力欄に入った文字列は `name`（名前）という変数で使えます。変数は値を名前で参照する仕組みです。後の行で入力された名前を表示するため、その文字列に `name` という名前を付けています。

[11〜13行目](./streamlit_greeting.py#L11-L13)は、`name` が空の文字列でない場合だけ、`st.write` で挨拶を表示します。空欄なら挨拶は表示されず、入力欄に `たろう` を入力してEnterキーを押すと、入力欄の下に `こんにちは たろう` が表示されます。

## 見出しを変えて起動し直す

見出しに使う文字列だけを変える練習です。挨拶の処理と名前の入力欄は、そのまま残します。

1. VS Codeの **表示（View）→ ターミナル（Terminal）** で、このアプリを起動したターミナルを開き、Ctrl + Cを押してください。Streamlitの実行が終わり、コマンドを入力できる状態に戻ります。
2. VS Codeで、練習用フォルダの `streamlit_greeting.py` を開いてください。Windows / LinuxはCtrl + F、macOSはCommand + Fで検索欄を開き、`st.title` を検索してください。見出しを置く行を見つけられます。
3. [元の4〜5行目](./streamlit_greeting.py#L4-L5)のコメントとコードを、次の練習用コードへ置き換えてください。Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。見出しの指定が「ようこそ」に変わります。

```python
# ブラウザ画面に「ようこそ」というタイトルを表示する
st.title("ようこそ")
```

4. VS Codeの **表示（View）→ ターミナル（Terminal）** で、練習用フォルダへ移動済みのターミナルを開いてください。Windowsなら `.\.venv\Scripts\python.exe -m streamlit run streamlit_greeting.py`、macOS / Linuxなら `.venv/bin/python -m streamlit run streamlit_greeting.py` を入力し、Enterキーを押してください。ブラウザで開いたアプリの見出しが「ようこそ」になります。自動でブラウザが開かない場合は、ターミナルの `Local URL:` の後ろのアドレスをブラウザのアドレス欄へ貼り付けてEnterキーを押してください。

名前の入力欄の案内を変える場合は、[元の7〜8行目](./streamlit_greeting.py#L7-L8)の `st.text_input("名前")` にある文字列と、その直前のコメントを変更してください。入力された文字列を `name` で使い、後の行で挨拶を表示する流れは変わりません。
