# 5. 完成した関数電卓の数字・小数点・Cボタンを読む

> **「1、.、5を押すと1.5になるけど、どの行が文字を増やしてるの？」**

[3章](./03_入力欄とボタンを読む.md)で数字や小数点のボタンへ処理を登録しました。その処理の**中身**を、`calculator.py`の159〜220行から、配布版のPythonコードをそのまま載せて読みます。

## 159〜176行：前の答えを置き換える準備

数字や小数点を押したとき、前の計算結果の表示を残すか消すかを決めます。

実ファイルのPythonコード：[ `calculator.py` の159〜176行](./src/calculator.py#L159-L176)

```python
    # 次の数字入力のために前の値を消す prepare_input を宣言する
    def prepare_input(self):
        # self.replace_input が False なら、次の処理を実行する
        if not self.replace_input:
            # prepare_input の処理をここで終える
            return
        # self.calculation_parts に式が残っていれば、次の処理を実行する
        if self.calculation_parts:
            # self.number_entry の先頭から末尾までの文字列を削除する
            self.number_entry.delete(0, tkinter.END)
            # self.expression_label に、保存した式を表示用に変換した文字列を表示する
            self.expression_label.config(text="計算式: " + self.format_expression())
            # self.replace_input に False を入れる
            self.replace_input = False
        # self.calculation_parts に式が残っていなければ、次の処理を実行する
        else:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()
```

**コードに登場する順に、1行ずつ確認します。**

- **160行目：`def prepare_input(self):`** — `prepare_input`は「次の入力を準備する」という意味のメソッドです。電卓の数字・小数点を押したとき、前に表示した答えを消すか調べます。

- **162行目：`if not self.replace_input:`** — `not`は「〜ではない」。右側の`self.replace_input`（次の入力で置き換えるか）が`False`なら、この`if`は成り立ち、164行目へ進みます。

- **164行目：`return`** — `return`で`prepare_input`の処理だけ終えます。置き換え不要なので入力欄の文字は消しません。後に呼び出した数字追加処理へ戻ります。

- **166行目：`if self.calculation_parts:`** — `self.calculation_parts`は式の部品の一覧です。右側のリストが空ではない場合だけ168〜172行目を実行します。真偽値を直接書かなくても、空でないリストは条件に合います。

- **168行目：`self.number_entry.delete(0, tkinter.END)`** — `delete(0, tkinter.END)`は、この電卓の入力欄`self.number_entry`の先頭0から末尾`END`までを削除します。式の部品の一覧はここでは消しません。

- **170行目：`self.expression_label.config(text="計算式: " + self.format_expression())`** — 右側の`"計算式: " + self.format_expression()`は、見出しと保存済みの式を表示用に変えた文字列をつなぎます。`config(text=...)`で式の表示欄の文字を更新します。

- **172行目：`self.replace_input = False`** — `self.replace_input`へ`False`（もう置き換える必要がない）を入れます。

- **174行目：`else:`** — `else`は166行目の`if`と対になり、途中の式が**空**の場合に176行目へ進みます。

- **176行目：`self.clear()`** — `self.clear()`は、この電卓の入力欄・式・答えの表示を初期化するメソッドを実行します。先ほどの計算結果を消し、新しく数字を入力できるようにします。

## 178〜186行：数字の文字を追加する

押された数字ボタンの文字列を、入力欄の末尾へ追加します。

実ファイルのPythonコード：[ `calculator.py` の178〜186行](./src/calculator.py#L178-L186)

```python
    # 入力欄へ数字を追加する append_digit を宣言する
    def append_digit(self, digit):
        # digit（追加する数字）には、押された数字ボタンの文字列が入る
        # 次の数字入力のために前の値を消す self.prepare_input を呼び出す
        self.prepare_input()
        # self.number_entry の末尾へ digit を挿入する
        self.number_entry.insert(tkinter.END, digit)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
```

**コードに登場する順に、1行ずつ確認します。**

- **179行目：`def append_digit(self, digit):`** — `append_digit`は「数字を末尾へ追加する」。`digit`は「押された数字」を表す引数で、数字ボタンの登録時に決めた`"1"`などの**文字列**が渡されます。

- **182行目：`self.prepare_input()`** — `self.prepare_input()`を呼び出し、前の答えを置き換える必要があれば先に入力欄を消します。

- **184行目：`self.number_entry.insert(tkinter.END, digit)`** — `self.number_entry.insert(tkinter.END, digit)`は、入力欄の**末尾**に文字列`digit`を挿入します。入力欄に`"1"`があって`"2"`を追加すれば、文字列`"12"`になります。

- **186行目：`self.result_label.config(text="答え:")`** — `self.result_label.config(text="答え:")`は、以前の計算結果を表示していた欄を、見出しだけの「答え:」へ戻します。

## 188〜207行：小数点を追加する

小数点の重複や、空欄から入力した場合を判断します。

実ファイルのPythonコード：[ `calculator.py` の188〜207行](./src/calculator.py#L188-L207)

```python
    # 入力欄へ小数点を追加する append_decimal_point を宣言する
    def append_decimal_point(self):
        # 次の数字入力のために前の値を消す self.prepare_input を呼び出す
        self.prepare_input()
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()
        # number_text に小数点が含まれていれば、次の処理を実行する
        if "." in number_text:
            # self.result_label の表示を「小数点は1つの数字に1個だけ入力できます」に変える
            self.result_label.config(text="小数点は1つの数字に1個だけ入力できます")
            # append_decimal_point の処理をここで終える
            return
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.number_entry の末尾へ「0」を挿入する
            self.number_entry.insert(tkinter.END, "0")
        # self.number_entry の末尾へ「.」を挿入する
        self.number_entry.insert(tkinter.END, ".")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
```

**コードに登場する順に、1行ずつ確認します。**

- **189行目：`def append_decimal_point(self):`** — `append_decimal_point`は「小数点を追加する」という処理です。ボタンの文字`"."`を押したとき呼ばれます。

- **191行目：`self.prepare_input()`** — `self.prepare_input()`で前の答えを置き換える場合の準備をします。

- **193行目：`number_text = self.number_entry.get()`** — 右側の`self.number_entry.get()`は現在の入力欄の文字を取得します。その文字列を左側の`number_text`（入力文字列）へ入れます。

- **195行目：`if "." in number_text:`** — 右側の`"." in number_text`は、入力文字列の中に小数点`"."`が含まれるかを調べます。`in`は「含まれている」です。

- **197行目：`self.result_label.config(text="小数点は1つの数字に1個だけ入力できます")`** — すでに小数点が含まれる場合、`config(text=...)`で結果欄へ「小数点は1つの数字に1個だけ入力できます」と表示します。

- **199行目：`return`** — `return`で小数点の追加処理を終え、205行目の`insert`へは進みません。2個目の小数点は追加されません。

- **201行目：`if number_text == "":`** — 右側の`number_text == ""`は、入力文字列が空かを調べます。`""`は文字が1つもない「空文字列」です。

- **203行目：`self.number_entry.insert(tkinter.END, "0")`** — 入力欄が空なら、まず末尾へ文字列の`"0"`を追加します。小数点が先頭になるのを避け、`0.`から入力できるようにします。

- **205行目：`self.number_entry.insert(tkinter.END, ".")`** — `insert(tkinter.END, ".")`で、小数点の文字列を入力欄の末尾へ追加します。前の`0`があれば`0.`、`1`があれば`1.`となります。

- **207行目：`self.result_label.config(text="答え:")`** — `config(text="答え:")`で以前の結果メッセージを見出し「答え:」へ戻します。

## 209〜220行：Cで入力と計算式を消す

入力・式の部品・画面の表示を初めの状態へ戻します。

実ファイルのPythonコード：[ `calculator.py` の209〜220行](./src/calculator.py#L209-L220)

```python
    # 入力・計算式・結果表示を空にする clear を宣言する
    def clear(self):
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.expression_label の表示を「計算式:」に変える
        self.expression_label.config(text="計算式:")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False
```

**コードに登場する順に、1行ずつ確認します。**

- **210行目：`def clear(self):`** — `clear`は「消す・空にする」という意味のメソッドです。「C」ボタンを押すと呼ばれます。

- **212行目：`self.calculation_parts.clear()`** — `self.calculation_parts.clear()`は、この電卓が保存した計算式の**部品の一覧**を空にします。表示文字とは別の値です。

- **214行目：`self.number_entry.delete(0, tkinter.END)`** — `self.number_entry.delete(0, tkinter.END)`は、入力欄の先頭から末尾までの文字を消します。文字列の変更通知で、保存した答えも無効になります。

- **216行目：`self.expression_label.config(text="計算式:")`** — 式を表示する`self.expression_label`の`text`を、最初の見出し`"計算式:"`へ戻します。

- **218行目：`self.result_label.config(text="答え:")`** — 答えを表示する`self.result_label`の`text`を、最初の見出し`"答え:"`へ戻します。

- **220行目：`self.replace_input = False`** — `self.replace_input`へ右側の`False`（次の数字は前の答えの置き換えとして扱わない）を保存し、通常の入力に戻します。


## 変更せずに確かめる：小数点を2回押す

1. 起動中の電卓で「C」「1」「.」「.」の順に押してください。
2. 入力欄は `1.` のまま、結果の欄に「小数点は1つの数字に1個だけ入力できます」と表示されることを確認してください。
3. `calculator_practice/src/calculator.py` の `def append_decimal_point(self):` を探し、`if "." in number_text:` と `return` がその結果につながることを確かめてください。
