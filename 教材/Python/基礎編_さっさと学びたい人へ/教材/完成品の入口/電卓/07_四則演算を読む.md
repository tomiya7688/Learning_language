# 7. 完成した関数電卓の四則演算を読む

> **「2 + 3 × 4は、どうして20ではなく14になるの？」**

[6章](./06_入力から計算記号を読む.md)では数値と記号を`self.calculation_parts`（計算式の部品の一覧）に保存しました。ここでは`calculator.py`の301〜396行を、**完成したコードの実行される行ごとに**読んでいきます。

最初に電卓で「C」「2」「+」「3」「*」「4」「=」を順番に押してください。`答え: 14`と表示されるのは、掛け算を先に計算して`2 + 12`にするからです。

## 301〜311行：最後の数字を式へ入れる

「=」を押したとき、入力欄にある最後の数字まで読み取ります。

実ファイルのPythonコード：[ `calculator.py` の301〜311行](./src/calculator.py#L301-L311)

```python
    # 計算式に最後の数字を追加し、掛け算と割り算を先に計算して答えを表示する calculate を宣言する
    def calculate(self):
        # number（読み取った数値）に、空欄の案内「最後の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("最後の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)
```

**元ファイルの行番号に沿って**、右側の式が何を求め、左側へ何が保存されるかを追います。

- **302行目：`def calculate(self):`** — `calculate`は「計算する」という意味。「=」を押した後、式を読み取って結果を表示するメソッドです。

- **304行目：`number = self.read_number("最後の数字を入力してください")`** — 右側の`self.read_number(...)`が入力欄の最後の数値を読み取り、結果を左側の`number`（数値）へ入れます。丸括弧の文字列は空欄だった場合の案内です。

- **306行目：`if number is None:`** — `number is None`は数値を読み取れなかったかどうかです。`None`は「数値がない状態」で、数値の0とは違います。

- **308行目：`return`** — `return`で計算処理を終えます。数字が読めないときは式を増やしません。

- **311行目：`self.calculation_parts.append(number)`** — 右側の`number`を`self.calculation_parts`（式の部品の一覧）の末尾へ追加し、最後の数値までそろえます。

## 313〜354行：掛け算と割り算を先に処理する

式を左から読みます。掛け算と割り算はその場で計算し、足し算と引き算は別の一覧へ残します。

実ファイルのPythonコード：[ `calculator.py` の313〜354行](./src/calculator.py#L313-L354)

```python
        # 掛け算と割り算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」ではなく「/」なら、次の処理を実行する
            elif operator == "/":
                # number が0なら、次の処理を実行する
                if number == 0:
                    # self.result_label の表示を「0では割れません」に変える
                    self.result_label.config(text="0では割れません")
                    # self.calculation_parts の要素をすべて削除する
                    self.calculation_parts.clear()
                    # self.answer_value に、答えがないことを表す None を入れる
                    self.answer_value = None
                    # self.replace_input に True を入れる
                    self.replace_input = True
                    # calculate の処理をここで終える
                    return

                # addition_and_subtraction_parts の末尾の要素に、その値を number で割った値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] / number
                )
            # operator が「*」でも「/」でもなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)
```

**元ファイルの行番号に沿って**、右側の式が何を求め、左側へ何が保存されるかを追います。

- **315行目：`addition_and_subtraction_parts = [self.calculation_parts[0]]`** — 左側の`addition_and_subtraction_parts`は「足し算・引き算のために残す部品」という意味です。右側の`[self.calculation_parts[0]]`は、元の一覧の**先頭の数値だけ**を入れた新しいリストです。

- **318行目：`for index in range(1, len(self.calculation_parts), 2):`** — `range(1, len(self.calculation_parts), 2)`は、記号がある番号1、3、5…を作ります。1は開始、`len(...)`は一覧の長さ、2は増やす間隔です。`index`は「位置を示す番号」です。

- **320行目：`operator = self.calculation_parts[index]`** — 右側の`self.calculation_parts[index]`から記号を取り出して、左側の`operator`（演算子）へ入れます。

- **322行目：`number = self.calculation_parts[index + 1]`** — 右側の`self.calculation_parts[index + 1]`から、記号の**次**の数値を取り出し、左側の`number`へ入れます。

- **325行目：`if operator == "*":`** — 右側の`operator == "*"`は記号が掛け算か調べます。`==`は「等しいか調べる」という意味です。

- **327行目：`addition_and_subtraction_parts[-1] = (`** — 左側の`addition_and_subtraction_parts[-1]`は、新しい一覧の**末尾の数値**です。`-1`は末尾の番号。右側で求めた積をそこへ上書きする代入の始まりです。

- **328行目：`addition_and_subtraction_parts[-1] * number`** — 右側の`addition_and_subtraction_parts[-1] * number`は、末尾の数値と今の数値を掛ける計算です。3と4なら12になります。

- **329行目：`)`** — `)`で327行目からの式を閉じ、計算した12を一覧の末尾へ上書きします。元の式`self.calculation_parts`はここでは変更しません。

- **331行目：`elif operator == "/":`** — `elif`は「直前の条件に合わず、こちらに合うなら」という意味です。記号が割り算`/`なら次へ進みます。

- **333行目：`if number == 0:`** — 右側の`number == 0`で割る数が0かを調べます。0なら割り算を行わず案内を表示します。

- **335行目：`self.result_label.config(text="0では割れません")`** — 右側の文字列`"0では割れません"`を、結果表示の`text=`へ渡します。

- **337行目：`self.calculation_parts.clear()`** — 保存済みの式の一覧を空にします。入力欄の文字を消す処理ではありません。

- **339行目：`self.answer_value = None`** — 左側の`self.answer_value`に右側の`None`（答えなし）を入れます。

- **341行目：`self.replace_input = True`** — 左側の`self.replace_input`に右側の`True`（次の入力で置き換える）を入れます。

- **343行目：`return`** — `return`で割り算の計算を中断します。ウィンドウ全体を閉じる命令ではありません。

- **346行目：`addition_and_subtraction_parts[-1] = (`** — 新しい一覧の末尾へ、割り算の結果を上書きする代入の始まりです。

- **347行目：`addition_and_subtraction_parts[-1] / number`** — 右側の`addition_and_subtraction_parts[-1] / number`で、末尾の数値を`number`で割ります。

- **348行目：`)`** — `)`で式を閉じ、計算した商を新しい一覧の末尾へ入れます。

- **350行目：`else:`** — `else`は掛け算でも割り算でもない場合です。足し算と引き算の記号を後の計算へ残します。

- **352行目：`addition_and_subtraction_parts.append(operator)`** — 右側の`operator`（`"+"`か`"-"`）を新しい一覧の末尾へ追加します。

- **354行目：`addition_and_subtraction_parts.append(number)`** — 右側の`number`（記号の次の数値）を新しい一覧の末尾へ追加します。まだ足し算・引き算をしていません。

## 356〜374行：残った足し算と引き算を計算する

先に計算した掛け算・割り算の結果を使い、足し算・引き算を左から行います。

実ファイルのPythonコード：[ `calculator.py` の356〜374行](./src/calculator.py#L356-L374)

```python
        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number
```

**元ファイルの行番号に沿って**、右側の式が何を求め、左側へ何が保存されるかを追います。

- **358行目：`answer = addition_and_subtraction_parts[0]`** — 右側の`addition_and_subtraction_parts[0]`で一覧の最初の数値を読み、左側の`answer`（答え）へ入れます。

- **361行目：`for index in range(1, len(addition_and_subtraction_parts), 2):`** — 残された記号の番号1、3、5…を繰り返し、足し算と引き算だけを処理します。

- **363行目：`operator = addition_and_subtraction_parts[index]`** — 右側の一覧の番号`index`から記号を取り出し、`operator`へ入れます。

- **365行目：`number = addition_and_subtraction_parts[index + 1]`** — 右側の一覧の番号`index + 1`から次の数値を取り出し、`number`へ入れます。

- **368行目：`if operator == "+":`** — 記号が足し算の`"+"`なら、下の足し算へ進みます。

- **370行目：`answer = answer + number`** — 右側の`answer + number`を計算し、左側の`answer`に**新しい答えを上書き**します。2+12なら14です。

- **372行目：`else:`** — `else`は足し算ではない場合、つまり残りの引き算`-`の処理へ進む部分です。

- **374行目：`answer = answer - number`** — 右側の`answer - number`を計算し、左側の`answer`へ上書きします。

## 376〜396行：式と答えを画面へ出す

大きすぎる計算を確認してから、式と答えを表示します。

実ファイルのPythonコード：[ `calculator.py` の376〜396行](./src/calculator.py#L376-L396)

```python
        # answer が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(answer):
            # self.result_label の表示を「計算結果が大きすぎます。Cで消してやり直してください」に変える
            self.result_label.config(text="計算結果が大きすぎます。Cで消してやり直してください")
            # self.calculation_parts の要素をすべて削除する
            self.calculation_parts.clear()
            # self.answer_value に、答えがないことを表す None を入れる
            self.answer_value = None
            # self.replace_input に True を入れる
            self.replace_input = True
            # calculate の処理をここで終える
            return

        # self.expression_label に、表示用の式と表示用の答えをつないだ文字列を表示する
        self.expression_label.config(
            text="計算式: " + self.format_expression() + " = " + self.format_number(answer)
        )
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # answer を指定して、答えを表示して保存する self.show_answer を呼び出す
        self.show_answer(answer)
```

**元ファイルの行番号に沿って**、右側の式が何を求め、左側へ何が保存されるかを追います。

- **377行目：`if not math.isfinite(answer):`** — `math.isfinite(answer)`は答えが有限の数値か調べます。`not`は結果を反転し、無限大などなら案内を表示します。

- **379行目：`self.result_label.config(text="計算結果が大きすぎます。Cで消してやり直してください")`** — 計算結果が大きすぎる場合の案内文を、結果の表示欄へ設定します。

- **381行目：`self.calculation_parts.clear()`** — 途中の式の一覧を空にします。

- **383行目：`self.answer_value = None`** — 保存済みの答えへ`None`（答えなし）を入れます。

- **385行目：`self.replace_input = True`** — 次の数字ボタンでは入力を置き換えるよう、`True`にします。

- **387行目：`return`** — `return`で処理を終了します。以下の通常の結果表示へは進みません。

- **390行目：`self.expression_label.config(`** — `self.expression_label.config(`は、式の表示欄の文字列を更新する処理を開始します。

- **391行目：`text="計算式: " + self.format_expression() + " = " + self.format_number(answer)`** — 右側の`"計算式: "`、`self.format_expression()`で作った式の表示、`" = "`、`self.format_number(answer)`で作った答えの表示を連結します。2+3*4なら`"計算式: 2 + 3 * 4 = 14"`です。

- **392行目：`)`** — `)`で式の表示を更新する呼び出しを閉じます。

- **394行目：`self.calculation_parts.clear()`** — 計算が終わったため、保存していた式の部品の一覧を空にします。

- **396行目：`self.show_answer(answer)`** — `self.show_answer(answer)`は、答えの数値を渡して結果欄と入力欄を更新し、表示前の数値も保存するメソッドを実行します。


## 「2 + 3 * 4」で途中の一覧を追う

| 読んだ時点 | 元の式の一覧 | 足し算・引き算用に残す一覧 |
| --- | --- | --- |
| 「=」を押した直後 | `[2.0, "+", 3.0, "*", 4.0]` | まだない |
| 315行目の後 | 同じ | `[2.0]` |
| 記号「+」の後 | 同じ | `[2.0, "+", 3.0]` |
| 記号「*」の後 | 同じ | `[2.0, "+", 12.0]` |
| 370行目の後 | 同じ | `[2.0, "+", 12.0]`、答えは14 |
| 394行目の後 | `[]` | この計算中に使った一覧 |

`addition_and_subtraction_parts`は別に作った一覧なので、掛け算の結果12に置き換えても、元の`self.calculation_parts`はそのままです。最後の394行目で元の一覧を空にします。
