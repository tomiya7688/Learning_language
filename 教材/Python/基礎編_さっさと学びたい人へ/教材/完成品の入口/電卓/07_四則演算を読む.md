# 7. 「=」で四則演算する順番を読む

> **「2 + 3 × 4 は、順番に計算すると20になるのでは？」**

[6章](./06_入力から計算記号を読む.md)では、数字と記号を `self.calculation_parts`（計算式の部品の一覧）へ保存しました。`calculator.py` の301〜396行で、その式を計算します。

## 最初に完成電卓で試す

電卓の「C」「2」「+」「3」「*」「4」「=」を順に押してください。答えの欄には `答え: 14` と表示されます。

掛け算と割り算を、足し算と引き算より**先に計算する**ため、`2 + (3 × 4) = 14` になります。コードを上から読んで、この順番を確かめましょう。

## 301〜311行：最後の数字を式へ加える

[`calculate` の301〜311行](./src/calculator.py#L301-L311)の `calculate` は「計算する」という意味です。「=」ボタンに登録されていた処理です。

`self.read_number("最後の数字を入力してください")` が、入力欄の最後の数字を読み取ります。数字がなければ `None`（読み取れなかった）を返すので、`if number is None: return` で計算を終えます。

数字を読めたら `self.calculation_parts.append(number)` が、その数字を式の一覧の末尾へ追加します。

「2」「+」「3」「*」「4」「=」なら、計算直前に保存しているのは次の一覧です。

```text
[2.0, "+", 3.0, "*", 4.0]
```

## 313〜354行：掛け算と割り算を先に処理する

[`calculate` の313〜354行](./src/calculator.py#L313-L354)を順に追ってください。

`addition_and_subtraction_parts` は「足し算と引き算の部品」です。最初に `[self.calculation_parts[0]]` として、式の先頭の数値を入れた一覧を作ります。`[0]` は一覧の0番目、つまり最初の要素です。

`for index in range(1, len(self.calculation_parts), 2):` は、`index`（一覧の番号）を1、3、5…と2ずつ増やして、計算記号の位置を読みます。`len(...)` は一覧の要素数です。`operator` に記号、`number` にその次の数値を入れます。

- `operator == "*"` なら、残している数値へ次の数値を掛けます。`addition_and_subtraction_parts[-1]` は、残している一覧の**一番最後の要素**です。`-1` は末尾を表す番号です。
- `operator == "/"` なら、次の数値で割ります。ただし0で割ることはできないので、`if number == 0:` のときは「0では割れません」と表示して計算を終えます。
- それ以外（`+` または `-`）なら、記号と次の数値を一旦残します。まだ足し算や引き算はしません。

2 + 3 × 4 の例では、一覧は次のように変化します。

| 読んだ計算記号 | 足し算・引き算用に残る一覧 |
| --- | --- |
| 開始時 | `[2.0]` |
| `+` を読んだ後 | `[2.0, "+", 3.0]` |
| `*` を読んだ後 | `[2.0, "+", 12.0]` |

`3.0` と `4.0` を掛けた結果12を、末尾の3と置き換えています。**式の元の一覧とは別に、計算用の一覧を作っています。**

## 356〜374行：残った足し算と引き算を処理する

[`calculate` の356〜374行](./src/calculator.py#L356-L374)では、`answer`（答え）に、残った一覧の最初の数値を入れます。

もう一度 `for index in range(...)` で記号と数値を順に取り出し、`+` なら `answer = answer + number`、そうでなければ `answer = answer - number` で答えを更新します。

先ほどの例は `[2.0, "+", 12.0]` なので、`answer` は最初2、足し算をして14になります。

## 376〜396行：答えを確認して表示する

[`calculate` の376〜396行](./src/calculator.py#L376-L396)では、`math.isfinite(answer)` で答えが有限の数値か確認します。極端に大きい計算で使えない数値になった場合は案内を表示し、`return` で計算を止めます。

使える答えなら、式の欄に `計算式: 2 + 3 * 4 = 14` を表示し、`self.calculation_parts.clear()` で途中の式を空にします。

最後の `self.show_answer(answer)` が、[4章で読んだ答えの表示](./04_答えと式の表示を読む.md)を行い、入力欄・答え欄へ14を表示し、次の計算で使う元の数値も保存します。

## 0で割ったときの案内を変更する

1. 電卓を閉じてから `calculator_practice/src/calculator.py` を開き、Ctrl + F（macOSはCommand + F）で `"0では割れません"` を検索してください。[334〜335行](./src/calculator.py#L334-L335)です。
2. この表示文を練習用として `"0で割る計算はできません"` に変更してください。直前のコメントに書いた案内も同じ文に変更します。
3. 保存後、Windowsなら `python src/app.py`、macOS / Linuxなら `python3 src/app.py` で起動してください。
4. 「C」「8」「/」「0」「=」を順に押してください。結果の欄に変更した文が表示されれば成功です。これは `number == 0` が成り立った結果です。
5. 電卓を閉じ、元の「0では割れません」とコメントへ戻して保存してください。
