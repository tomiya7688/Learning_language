# 4. 計算式と答えを画面へ表示する

> **「答えが0.333333333333なのに、次の計算では何を使ってるの？」**

`calculator.py` の110〜157行では、**表示するための文字列**と**次の計算に使う数値**を分けています。先に電卓の「C」「1」「/」「3」「=」を順に押すと、答えの欄と入力欄に `0.333333333333` が表示されることを確認してください。

## 110〜117行：`format_number` で数字を読みやすくする

[`calculator.py` の110〜117行](./src/calculator.py#L110-L117)の `format_number`（数値の表示を整える）は、引数 `number`（表示する数値）を受け取ります。引数とは、関数を呼び出すときに指定する値のことです。

`if number == 0:` が成り立つ場合は、`return "0"` で文字列の0を返して、この関数を終えます。`return` は「値を呼び出した場所へ返す」という意味です。

0でなければ `format(number, ".12g")` を使います。これは`number`の有効数字を**最大12桁の文字列**へ変える指定です。`number`の数値自体を変更しません。

```text
計算に使う数値: 0.3333333333333333
画面で見せる文字列: "0.333333333333"
```

有効数字は最初の0以外の数字から数えた桁です。`".12g"` にしても、計算の誤差がなくなるわけではありません。

## 119〜134行：式を文字でつなぐ

[`format_expression` の119〜134行](./src/calculator.py#L119-L134)の `expression` は「式」という意味です。

1. `parts_text = []` で、表示する式の部品を入れる空の一覧を作ります。`parts` は「部品」、`text` は「文字」です。
2. `for part in self.calculation_parts:` は、保存済みの式から部品を1つずつ取り出します。
3. `isinstance(part, str)` は、`part` が文字列か調べます。`str` は「文字列」の型です。計算記号の `"+"` や `"/"` なら、そのまま表示用の一覧へ追加します。
4. 数値なら、`self.format_number(part)` で表示用の文字列にしてから追加します。
5. `" ".join(parts_text)` は、部品と部品の間に半角の空白を入れてつなぎ、出来上がった式を返します。

たとえば `self.calculation_parts` が `[2.0, "+", 3.0]` なら、画面用の文字列は `"2 + 3"` になります。

## 136〜142行：手入力したら前の答えを忘れる

[`forget_answer` の136〜142行](./src/calculator.py#L136-L142)の `forget` は「忘れる」という意味です。

入力欄へ新しい文字を書き込んだ通知を受けたときに、`self.answer_value`（表示前の答え）へ `None`（保存した答えなし）を入れ、`self.replace_input`（次の入力を置き換えるか）へ `False`（置き換えない）を入れます。

`variable_name`・`index`・`operation` はTkinterから渡される変更情報で、この関数では使いません。[3章の `trace_add("write", self.forget_answer)`](./src/calculator.py#L40-L47)がこの処理を登録していました。

画面の `0.333333333333` を自分で書き直したなら、**入力した文字列を次の計算に使う**ために、前の計算結果を無効にします。

## 144〜157行：画面を書き換えた後、元の数値を保存する

[`show_answer` の144〜157行](./src/calculator.py#L144-L157)の `show` は「表示する」、`answer` は「答え」です。

1. `answer_text = self.format_number(answer)` で表示用の文字列を作ります。
2. `self.result_label.config(...)` で結果の欄を `答え: 0.333333333333` のように書き換えます。
3. `self.number_entry.delete(0, tkinter.END)` で入力欄の先頭から末尾までを消します。`0` は先頭、`tkinter.END` は末尾です。
4. `self.number_entry.insert(0, answer_text)` で表示用の答えを入力欄の先頭へ入れます。
5. **その後で** `self.answer_value = answer` として、丸める前の数値を保存します。さらに `self.replace_input = True` にして、次の数字ボタンを押したとき入力を置き換える準備をします。

手順3・4の `delete` や `insert` でも文字列の書き込み通知が起き、`forget_answer` が呼ばれます。その**後**に元の数値を保存する順番だからこそ、次の計算へ表示前の数値を渡せます。

## 表示する桁数を変えてみる

1. 電卓を閉じて `calculator_practice/src/calculator.py` を開いてください。
2. `format(number, ".12g")` を検索し、[116〜117行](./src/calculator.py#L116-L117)のコメントとコードを、練習用として次のように変更してください。

```python
# number を有効数字6桁の表示へ変換した文字列を返す
return format(number, ".6g")
```

3. 保存して、Windowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` で再実行してください。
4. 「C」「1」「/」「3」「=」の順に押すと、答えの欄に `答え: 0.333333` と表示されます。変更前の `0.333333333333` と比べてください。
5. ウィンドウを閉じ、`".12g"` とコメントの「12桁」に戻して保存してください。計算用の元の数値を変える練習ではありません。
