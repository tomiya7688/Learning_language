# 4. 完成した関数電卓の式と答えの表示を読む

> **「答えは0.333333333333だけど、次の計算にはどの数字を使うの？」**

[3章](./03_入力欄とボタンを読む.md)で入力欄・式・答えの表示場所を作りました。ここでは`calculator.py`の110〜157行を**完成コードそのままの順番**で読みます。表示する文字列と、計算を続ける数値の区別を確かめてください。

## 110〜117行：数字を表示用の文字列へ変える

数値を画面へ出す前に、長い小数を読みやすく整えます。

完成版のPythonコード：[ `calculator.py` の110〜117行](./src/calculator.py#L110-L117)

```python
    # 数値を表示用の文字列にする format_number を宣言する
    def format_number(self, number):
        # number（表示する数値）が0なら、次の処理を実行する
        if number == 0:
            # 文字列の「0」を返す
            return "0"
        # number を有効数字12桁の表示へ変換した文字列を返す
        return format(number, ".12g")
```

以下は**実ファイルの行番号ごと**の説明です。

- **111行目：`def format_number(self, number):`** — `def`で`format_number`（数値の表示を整える）を宣言します。`number`は受け取った数値を入れる名前です。この関数は数値を変更せず、画面へ出す文字列を返します。

- **113行目：`if number == 0:`** — `if`は「もし」、`==`は左右が同じかです。`number`が数値の0かどうか調べ、そうなら字下げした115行目を実行します。

- **115行目：`return "0"`** — `return`は「値を呼び出し元へ返す」。右側の`"0"`は数字の0ではなく**文字列**です。この処理を終え、117行目には進みません。

- **117行目：`return format(number, ".12g")`** — 右側の`format(number, ".12g")`は、受け取った数値`number`を表示用文字列に変えます。`format`は書式を整えるPythonの関数、`".12g"`は有効数字を最大12桁にする指定です。**元の数値を上書きせず**変換後の文字列だけ返します。

## 119〜134行：計算式の部品を文字列でつなぐ

計算式の部品が数値か記号かを調べ、画面へ出す文字列へ変えます。

完成版のPythonコード：[ `calculator.py` の119〜134行](./src/calculator.py#L119-L134)

```python
    # 保存済みの式を表示用の文字列にする format_expression を宣言する
    def format_expression(self):
        # parts_text（表示する式の部品）に空のリストを入れる
        parts_text = []
        # part（式の部品）に self.calculation_parts の値を順に入れて繰り返す
        for part in self.calculation_parts:
            # part が文字列なら、次の処理を実行する
            if isinstance(part, str):
                # parts_text の末尾に part を追加する
                parts_text.append(part)
            # part が文字列でなければ、次の処理を実行する
            else:
                # parts_text の末尾に part を表示用の文字列にした値を追加する
                parts_text.append(self.format_number(part))
        # parts_text の文字列を空白でつないだ文字列を返す
        return " ".join(parts_text)
```

以下は**実ファイルの行番号ごと**の説明です。

- **120行目：`def format_expression(self):`** — `format_expression`は「式の表示を整える」という意味のメソッドです。字下げした122行目からを、呼び出されたときに実行します。

- **122行目：`parts_text = []`** — 左側の`parts_text`（式を文字で表す部品の一覧）へ、右側の`[]`（空のリスト）を入れます。計算式の数字と記号を後で文字列にして並べます。

- **124行目：`for part in self.calculation_parts:`** — `for`は「順番に繰り返す」。右側の`self.calculation_parts`は電卓が保存している式の部品の一覧です。1個ずつ左の`part`（部品）へ入れて、字下げした部分を実行します。

- **126行目：`if isinstance(part, str):`** — 右側の`isinstance(part, str)`は、部品`part`が`str`（文字列の型）か調べます。`"+"`や`"/"`などの記号ならTrueなので128行目へ進みます。

- **128行目：`parts_text.append(part)`** — `parts_text.append(part)`は、元の記号の文字列を表示用の一覧`parts_text`の末尾へ追加します。`append`は「後ろへ追加する」です。

- **130行目：`else:`** — `else`は「それ以外」です。`part`が文字列ではない数値などの場合だけ132行目へ進みます。

- **132行目：`parts_text.append(self.format_number(part))`** — 右側の`self.format_number(part)`が数値を文字列に変え、それを`parts_text.append(...)`が表示用一覧の末尾へ追加します。**元の計算式の数値は変えません**。

- **134行目：`return " ".join(parts_text)`** — 右側の`" ".join(parts_text)`は`parts_text`内の文字列を、半角空白`" "`を挟んでつなぎます。たとえば`["2", "+", "3"]`なら`"2 + 3"`となり、その文字列を返します。

## 136〜142行：入力が書き換わったら保存済みの答えを忘れる

利用者が入力欄を変更したら、以前の答えを次の計算へ使わないようにします。

完成版のPythonコード：[ `calculator.py` の136〜142行](./src/calculator.py#L136-L142)

```python
    # 入力欄へ書き込まれた時に答えを忘れる forget_answer を宣言する
    def forget_answer(self, variable_name, index, operation):
        # variable_name（変数名）・index（添字）・operation（操作の種類）には、Tkinterが指定した変更情報が入る
        # self.answer_value に、保存した答えがないことを表す None を入れる
        self.answer_value = None
        # self.replace_input に False を入れる
        self.replace_input = False
```

以下は**実ファイルの行番号ごと**の説明です。

- **137行目：`def forget_answer(self, variable_name, index, operation):`** — `forget_answer`は「保存した答えを忘れる」。`trace_add`による入力文字の書き込み通知で呼ばれます。`variable_name`（変数名）、`index`（添字）、`operation`（操作の種類）はTkinterから渡される値で、この関数では読みません。

- **140行目：`self.answer_value = None`** — 左側の`self.answer_value`（表示前の答え）へ、右側の`None`（答えが保存されていない状態）を入れます。**数値の0ではありません**。

- **142行目：`self.replace_input = False`** — 左側の`self.replace_input`（次の数字で入力欄を置き換えるか）へ、右側の`False`（置き換えない）を入れます。自分で文字を入力した場合に、前の答えを使わないようにします。

## 144〜157行：答えを表示してから、元の数値を保存する

表示用に丸めた文字列とは別に、計算結果の数値も保持します。

完成版のPythonコード：[ `calculator.py` の144〜157行](./src/calculator.py#L144-L157)

```python
    # 答えを表示し、次の計算用の数値を保存する show_answer を宣言する
    def show_answer(self, answer):
        # answer_text（答えの表示文字列）に answer を表示用に変換した文字列を入れる
        answer_text = self.format_number(answer)
        # self.result_label の表示を「答え: 」と answer_text をつないだ文字列に変える
        self.result_label.config(text="答え: " + answer_text)
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer_text を挿入する
        self.number_entry.insert(0, answer_text)
        # self.answer_value に、表示する前の数値 answer を入れる
        self.answer_value = answer
        # self.replace_input に True を入れる
        self.replace_input = True
```

以下は**実ファイルの行番号ごと**の説明です。

- **145行目：`def show_answer(self, answer):`** — `show_answer`は「答えを表示する」というメソッドです。`answer`は計算で求めた元の数値です。ここから入力欄と結果欄を更新します。

- **147行目：`answer_text = self.format_number(answer)`** — 右側の`self.format_number(answer)`が数値`answer`を表示用の文字列に変え、その結果を左側の`answer_text`（答えの表示文字列）へ入れます。

- **149行目：`self.result_label.config(text="答え: " + answer_text)`** — `self.result_label`（答えの表示欄）の`config`（設定変更）へ`text=`で表示文を渡します。右側の`"答え: " + answer_text`が見出しと数値文字列をつないで、例では`"答え: 0.333333333333"`を表示します。

- **151行目：`self.number_entry.delete(0, tkinter.END)`** — `self.number_entry`（入力欄）の`delete(0, tkinter.END)`は先頭0から最後までの文字を削除します。`tkinter.END`は入力欄の最後を表します。書き込みの通知も発生します。

- **153行目：`self.number_entry.insert(0, answer_text)`** — `self.number_entry.insert(0, answer_text)`は入力欄の先頭0へ表示用の文字列`answer_text`を挿入します。挿入の通知により`forget_answer`が呼ばれ、いったん保存済みの答えが無効になります。

- **155行目：`self.answer_value = answer`** — 左側の`self.answer_value`へ右側の`answer`（丸める前の計算結果）を入れます。**入力欄を書き換えた後に保存**するので、`forget_answer`の通知でこの値を消されずに済みます。

- **157行目：`self.replace_input = True`** — `self.replace_input`へ右側の`True`（次の数字入力で置き換える）を入れます。計算直後に「7」を押すと、前の答えの文字列に7を足さず、新しい数字7として始められます。


## 実際の表示と計算の違い

電卓で「C」「1」「/」「3」「=」を順に押すと、答えの欄は`答え: 0.333333333333`になります。`format_number`が表示を12桁へ整えた一方、`self.answer_value`には丸める前の数値が保存されています。次の計算でその数値を読み出す処理は[6章の`read_number`](./06_入力から計算記号を読む.md)で確認します。

## 変更して確かめる：表示する桁数を変える

1. 電卓を閉じて `calculator_practice/src/calculator.py` を開いてください。
2. `format(number, ".12g")` を検索し、[116〜117行](./src/calculator.py#L116-L117)のコメントとコードを、練習用として次のように変更してください。

```python
        # number を有効数字6桁の表示へ変換した文字列を返す
        return format(number, ".6g")
```

3. 保存して、Windowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` で再実行してください。
4. 「C」「1」「/」「3」「=」の順に押すと、答えの欄に `答え: 0.333333` と表示されます。変更前の `0.333333333333` と比べてください。
5. ウィンドウを閉じ、`".12g"` とコメントの「12桁」に戻して保存してください。計算用の元の数値を変える練習ではありません。
