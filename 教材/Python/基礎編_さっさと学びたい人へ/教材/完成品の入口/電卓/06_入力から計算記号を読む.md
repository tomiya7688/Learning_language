# 6. 入力を数値へ変えて、計算記号を保存する

> **「『2』『+』を押したとき、足し算する前の2はどこへ行くの？」**

`calculator.py` の222〜299行では、入力欄の文字列を計算に使える数字へ変え、途中の数字と記号を一覧へ保存します。

## 222〜254行：`read_number` で数値を読み取る

[`read_number` の222〜254行](./src/calculator.py#L222-L254)の `read` は「読み取る」、`number` は「数値」です。`empty_message` は「入力欄が空のときに表示する案内」という意味の引数です。

このメソッドは次の順番で調べます。

1. `number_text = self.number_entry.get().strip()`：入力欄の文字列を読み、前後の空白を取り除きます。`strip()` は「前後を取り除く」です。
2. `if number_text == "":`：空欄なら、指定された `empty_message` を答えの欄へ表示し、`None`（数値を読めなかった）を返します。
3. `if self.answer_value is not None:`：表示前の答えを保存していれば、入力欄の表示文字列より先に、その数値を返します。`is not None` は「Noneではない」の意味です。
4. `float(number_text)`：文字列の `"2.5"` を小数も扱える数値の `2.5` に変換します。`float` は、小数を含む数値を扱う型の名前です。
5. `except ValueError:`：`"あいうえお"` など数値に変えられない文字なら、案内を表示して `None` を返します。`try` は実行して問題が起きるか確認する部分、`except` は特定の問題が起きた場合の部分です。
6. `math.isfinite(number)`：数値が無限大でも「数値ではない値」でもないか調べます。`not` が付いているため、使えない値なら案内を表示して `None` を返します。
7. どの確認にも引っかからなければ、最後の `return number` で読み取った数値を返します。

ここで返す `None` は **0と違います**。0は計算できる数値ですが、`None` は「数値を読み取れず、計算へ進めない」という合図です。

## 256〜279行：`add_operator` で数字と記号を式へ加える

[`add_operator` の256〜279行](./src/calculator.py#L256-L279)の `add` は「追加する」、`operator` は「演算子（計算の記号）」という意味です。

入力欄に文字列の `"2"` を入れて「+」を押した場合を追います。

1. `self.read_number("次の数字を入力してください")` が、`"2"` を数値の `2.0` に変換します。
2. `if number is None: return` は、数値を読めなかった場合だけ、式を変更せず処理を終えます。
3. `self.calculation_parts.append(number)` は、数値の `2.0` を式の部品の一覧へ追加します。`append` は「一覧の末尾へ加える」です。
4. `self.calculation_parts.append(operator)` は、文字列の `"+"` をその後ろへ追加します。
5. `self.expression_label.config(...)` で、式の表示を「計算式: 2 +」へ変えます。
6. `self.number_entry.delete(...)` で入力欄を空にします。次の数字「3」を入れるためです。結果表示も「答え:」に戻します。

この時点で `self.calculation_parts` は `[2.0, "+"]` です。`[]` は一覧（リスト）を表し、`2.0` は数値、`"+"` は文字列です。**まだ足し算は行っていません。**

## 281〜299行：「+」「-」「*」「/」は同じ処理を使う

[`select_addition` から `select_division` まで](./src/calculator.py#L281-L299)を続けて読んでください。

`addition` は「足し算」、`subtraction` は「引き算」、`multiplication` は「掛け算」、`division` は「割り算」です。各メソッドはそれぞれの記号を `self.add_operator(...)` へ渡すだけです。

| 押すボタン | 実際に呼び出す処理 |
| --- | --- |
| `+` | `self.add_operator("+")` |
| `-` | `self.add_operator("-")` |
| `*` | `self.add_operator("*")` |
| `/` | `self.add_operator("/")` |

もし4種類のボタンそれぞれに数字を読む処理と式へ追加する処理を重複して書いたら、空欄の確認を変更するとき4か所直す必要があります。ここでは**共通の処理を1か所**にして、記号だけを変えています。

## 空欄の案内を変えてみる

1. 電卓を閉じ、`calculator_practice/src/calculator.py` を開いてください。
2. Ctrl + F（macOSはCommand + F）で `self.read_number("次の数字を入力してください")` を検索してください。[259〜260行](./src/calculator.py#L259-L260)にあります。
3. 練習用として、`"次の数字を入力してください"` を `"数字を入れてから計算記号を押してください"` に変えてください。直前のコメントにある案内も同じ文へ変えてください。
4. 保存して、Windowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` を実行してください。
5. まだ数字を入力せず「+」を押すと、答えの欄に変更した案内が表示されます。これは `number is None` で式の追加をやめるためです。
6. ウィンドウを閉じて元の案内とコメントに戻し、保存してください。
