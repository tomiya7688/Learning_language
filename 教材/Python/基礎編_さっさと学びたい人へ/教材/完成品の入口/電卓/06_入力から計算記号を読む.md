# 6. 完成した関数電卓の数字と計算記号の保存を読む

> **「2を入力して+を押したら、数字の2はどこへ行ったの？」**

[5章](./05_数字と小数点を読む.md)で数字を入力欄へ追加しました。その数字はまだ文字列です。`calculator.py`の222〜299行を**1行ずつ**読み、実際の数値へ変換して計算式へ追加するところを確認します。

## 222〜254行：入力欄の文字列を数値へ変える

入力欄は文字列を持っています。計算する前に、その文字列が数値として使えるかを調べます。

実ファイルのPythonコード：[ `calculator.py` の222〜254行](./src/calculator.py#L222-L254)

```python
    # 入力欄を数値へ変換し、使えない入力を結果の欄で知らせる read_number を宣言する
    def read_number(self, empty_message):
        # empty_message（空欄の案内）には、入力欄が空の場合に表示する文字列が入る
        # number_text（入力文字列）に self.number_entry の文字列から前後の空白を取り除いた文字列を入れる
        number_text = self.number_entry.get().strip()
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を empty_message に変える
            self.result_label.config(text=empty_message)
            # 数値を読み取れなかったことを表す None を返す
            return None
        # self.answer_value に答えの数値が保存されていれば、次の処理を実行する
        if self.answer_value is not None:
            # 表示する前の答え self.answer_value を返す
            return self.answer_value
        # 次の数値変換で ValueError が起きるかを確認する
        try:
            # number（読み取った数値）に number_text を float で数値に変換した値を入れる
            number = float(number_text)
        # 数値へ変換できず ValueError が起きた場合は、次の処理を実行する
        except ValueError:
            # self.result_label の表示を「数字を入力してください（例: 1.5）」に変える
            self.result_label.config(text="数字を入力してください（例: 1.5）")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # number が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(number):
            # self.result_label の表示を「有限の数字を入力してください」に変える
            self.result_label.config(text="有限の数字を入力してください")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 読み取った数値 number を返す
        return number
```

**元ファイルの行番号順**に、式の左右・条件・呼び出す処理を読みます。

- **223行目：`def read_number(self, empty_message):`** — `def read_number(self, empty_message):`は「入力した数値を読む」というメソッドの宣言です。`empty_message`は空欄のときに表示する案内文で、呼び出す側が決めて渡します。

- **226行目：`number_text = self.number_entry.get().strip()`** — 右側の`self.number_entry.get()`で入力欄から文字列を読み、続く`strip()`で**前後の空白**を取り除きます。左側の`number_text`（入力文字列）へ入れます。

- **228行目：`if number_text == "":`** — 右側の`number_text == ""`は、入力文字列が空文字列`""`か調べます。空欄なら次の行へ、空でなければ234行目へ進みます。

- **230行目：`self.result_label.config(text=empty_message)`** — `self.result_label.config(text=empty_message)`は結果の欄を、引数として受け取った`empty_message`の文に変えます。`text=`は表示文字を指定する名前です。

- **232行目：`return None`** — `return None`は、このメソッドを終えて「数値を読み取れなかった」という`None`を呼び出し元へ返します。**数値の0ではありません**。

- **234行目：`if self.answer_value is not None:`** — `self.answer_value is not None`は、表示前の答えが保存されているか調べます。`is not None`は「Noneではない」。前の答えがある場合は次へ進みます。

- **236行目：`return self.answer_value`** — 右側の`self.answer_value`は、画面表示用に桁を短くする前の答えです。その数値を直接返すので、表示された文字列に丸め直してから計算しません。

- **238行目：`try:`** — `try:`は、次の数値変換を試す範囲の始まりです。数値へ変換できない場合は242行目の`except`へ進みます。

- **240行目：`number = float(number_text)`** — 右側の`float(number_text)`は入力文字列を小数も扱える数値の型`float`へ変えます。たとえば`"2"`から数値の`2.0`を作り、左側の`number`（読み取った数値）へ入れます。

- **242行目：`except ValueError:`** — `except ValueError:`は、240行目で数値へ変換できず`ValueError`（値の変換失敗）が起きた場合だけ、下の処理を実行します。

- **244行目：`self.result_label.config(text="数字を入力してください（例: 1.5）")`** — 右側の文字列`"数字を入力してください（例: 1.5）"`を`text=`へ渡し、結果の欄に表示します。

- **246行目：`return None`** — `return None`で変換失敗を呼び出し元へ伝え、ここで数値を読む処理を終えます。

- **248行目：`if not math.isfinite(number):`** — 右側の`math.isfinite(number)`は`number`が有限の数値か調べます。`not`は判定を反転するので、無限大や数値でない値なら次の案内へ進みます。

- **250行目：`self.result_label.config(text="有限の数字を入力してください")`** — 結果欄へ`"有限の数字を入力してください"`と表示します。これは非常に大きい入力や`nan`などが計算へ入るのを防ぐためです。

- **252行目：`return None`** — `return None`で「扱えない数値」という結果を呼び出し元へ返します。

- **254行目：`return number`** — どのエラー条件にも当てはまらなければ、左から準備してきた`number`の数値を`return number`で返します。

## 256〜279行：計算式の一覧に数値と記号を保存する

数字の入力欄を消す前に、計算途中の数値と記号を一覧へ移します。

実ファイルのPythonコード：[ `calculator.py` の256〜279行](./src/calculator.py#L256-L279)

```python
    # 入力された数字と operator を計算式に追加する add_operator を宣言する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number（読み取った数値）に、空欄の案内「次の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("次の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # self.expression_label に、保存した式を表示用に変換した文字列を表示する
        self.expression_label.config(text="計算式: " + self.format_expression())

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False
```

**元ファイルの行番号順**に、式の左右・条件・呼び出す処理を読みます。

- **257行目：`def add_operator(self, operator):`** — `add_operator`（計算記号を式へ加える）メソッドの宣言です。`operator`（演算子）は、押された計算記号の文字列`"+"`・`"-"`・`"*"`・`"/"`を受け取る名前です。

- **260行目：`number = self.read_number("次の数字を入力してください")`** — 右側の`self.read_number("次の数字を入力してください")`で入力欄を読み取ります。丸括弧の文字列は、空欄だった場合に表示する案内です。返った数値または`None`を左側の`number`へ入れます。

- **262行目：`if number is None:`** — 右側の`number is None`は入力の読み取りが失敗した場合に成り立ちます。数値の0とは異なり、`None`なら次の`return`へ進みます。

- **264行目：`return`** — `return`で記号追加の処理だけを終了します。まだ式の一覧は変更しません。

- **267行目：`self.calculation_parts.append(number)`** — `self.calculation_parts`は、この電卓が保存する計算式の部品の一覧です。右側の`number`（読み取った数値）を`append`（末尾へ追加）します。

- **269行目：`self.calculation_parts.append(operator)`** — 右側の`operator`（`"+"`などの記号の文字列）を同じ一覧の末尾へ追加します。数値と記号を順番に保存します。

- **272行目：`self.expression_label.config(text="計算式: " + self.format_expression())`** — `self.format_expression()`が保存した式を表示用文字列に変換します。右側で`"計算式: "`をその文字列につなぎ、`config(text=...)`で式の表示欄へ出します。

- **275行目：`self.number_entry.delete(0, tkinter.END)`** — `self.number_entry.delete(0, tkinter.END)`で入力欄を先頭0から末尾まで消します。次の数値を入力するためで、式の一覧`self.calculation_parts`は消しません。

- **277行目：`self.result_label.config(text="答え:")`** — 答えの表示欄の文字を`"答え:"`という見出しだけに戻します。

- **279行目：`self.replace_input = False`** — `self.replace_input`へ右側の`False`を入れます。新しい数字を通常どおり入力する状態に戻します。

## 281〜299行：4種類の計算記号で同じ処理を呼ぶ

4つのボタンが渡す記号だけを変え、式へ保存する処理は共有します。

実ファイルのPythonコード：[ `calculator.py` の281〜299行](./src/calculator.py#L281-L299)

```python
    # 入力された数字と「+」を計算式に追加する select_addition を宣言する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を宣言する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 入力された数字と「*」を計算式に追加する select_multiplication を宣言する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")

    # 入力された数字と「/」を計算式に追加する select_division を宣言する
    def select_division(self):
        # 「/」を指定して self.add_operator を呼び出す
        self.add_operator("/")
```

**元ファイルの行番号順**に、式の左右・条件・呼び出す処理を読みます。

- **282行目：`def select_addition(self):`** — `select_addition`は「足し算を選ぶ」という処理の宣言です。

- **284行目：`self.add_operator("+")`** — 右側の文字列`"+"`を引数にして`self.add_operator("+")`を呼び出します。数字と記号を保存する共通処理を使います。

- **287行目：`def select_subtraction(self):`** — `select_subtraction`は「引き算を選ぶ」という処理の宣言です。

- **289行目：`self.add_operator("-")`** — 文字列`"-"`を渡して共通の`add_operator`を呼び出します。

- **292行目：`def select_multiplication(self):`** — `select_multiplication`は「掛け算を選ぶ」という処理の宣言です。

- **294行目：`self.add_operator("*")`** — 文字列`"*"`を渡して共通の`add_operator`を呼び出します。`*`は掛け算の記号です。

- **297行目：`def select_division(self):`** — `select_division`は「割り算を選ぶ」という処理の宣言です。

- **299行目：`self.add_operator("/")`** — 文字列`"/"`を渡して共通の`add_operator`を呼び出します。`/`は割り算の記号です。


## 「2 + 3」の式がどう残るか

電卓の「C」「2」「+」を順に押してください。`self.calculation_parts`（計算式の部品の一覧）には、数値と記号を順番に並べた`[2.0, "+"]`が残ります。入力欄は空になるため、次に「3」を入れられます。**この時点ではまだ足し算はしません。**「=」の計算は[7章](./07_四則演算を読む.md)で読みます。

## 変更して確かめる：空欄の案内を変える

1. 電卓を閉じ、`calculator_practice/src/calculator.py` を開いてください。
2. Ctrl + F（macOSはCommand + F）で `self.read_number("次の数字を入力してください")` を検索してください。[259〜260行](./src/calculator.py#L259-L260)にあります。
3. 練習用として、`"次の数字を入力してください"` を `"数字を入れてから計算記号を押してください"` に変えてください。直前のコメントにある案内も同じ文へ変えてください。
4. 保存して、Windowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` を実行してください。
5. まだ数字を入力せず「+」を押すと、答えの欄に変更した案内が表示されます。これは `number is None` で式の追加をやめるためです。
6. ウィンドウを閉じて元の案内とコメントに戻し、保存してください。
