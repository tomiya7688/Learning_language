## 32〜57行：入力欄と結果欄を作る

入力する場所・式の表示・答えの表示を、ウィンドウへ上から順に追加します。

完成版のPythonコード：[ `calculator.py` の32〜57行](./src/calculator.py#L32-L57)

```python
    # 入力欄・式・答えを配置する create_display を宣言する
    def create_display(self):
        # self.number_label（数字の案内）に self.window 内の「数字（sin・cosは角度を度で入力）」というラベルを入れる
        self.number_label = tkinter.Label(
            self.window, text="数字（sin・cosは角度を度で入力）"
        )
        # self.number_label を self.window 内に配置し、上下に6ピクセルずつ間を空ける
        self.number_label.pack(pady=6)
        # self.input_text（入力欄の文字列）に self.window で使う、文字列を保持する変数を入れる
        self.input_text = tkinter.StringVar(master=self.window)
        # self.input_text へ書き込まれた時の処理として self.forget_answer を登録する
        self.input_text.trace_add("write", self.forget_answer)
        # self.number_entry（数字の入力欄）に、文字列を self.input_text とつなぐ1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window, textvariable=self.input_text)
        # self.number_entry を横へ広げ、左右に16ピクセルずつ間を空ける
        self.number_entry.pack(fill="x", padx=16)
        # self.expression_label（計算式の表示）に「計算式:」を表示し、380ピクセルで折り返すラベルを入れる
        self.expression_label = tkinter.Label(
            self.window, text="計算式:", wraplength=380
        )
        # self.expression_label を横へ広げ、上下に6ピクセルずつ間を空ける
        self.expression_label.pack(fill="x", pady=6)
        # self.result_label（答えの表示）に「答え:」を表示し、380ピクセルで折り返すラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:", wraplength=380)
        # self.result_label を横へ広げ、上下に6ピクセルずつ間を空ける
        self.result_label.pack(fill="x", pady=6)
```

以下では、**実際のコードの行番号順**に読みます。各行で`=`の右側の指定と、その結果どこが変わるかも確認してください。

- **35行目：`self.number_label = tkinter.Label(`** — 左側の`self.number_label`は「この電卓の数字の案内」という保存先。右側の`tkinter.Label(`は、画面へ文字を表示する**ラベル**を作り始める呼び出しです。丸括弧が閉じる37行目までが同じ1つの式です。

- **36行目：`self.window, text="数字（sin・cosは角度を度で入力）"`** — 右辺の1つ目`self.window`は案内を載せるウィンドウで、`text=`は案内へ表示する文字列を指定します。ここでは「数字（sin・cosは角度を度で入力）」がラベルの文字になります。

- **37行目：`)`** — `)`で、35行目からの`tkinter.Label(...)`に渡す値の指定を閉じます。作られたラベルは35行目の左側`self.number_label`に入ります。

- **39行目：`self.number_label.pack(pady=6)`** — 右側の`pady=6`はラベルの**上下**に6ピクセルの間を空ける指定です。`pack()`はウィンドウ内へラベルを並べて配置します。ピクセルは画面の距離を数える単位です。

- **41行目：`self.input_text = tkinter.StringVar(master=self.window)`** — 左側の`self.input_text`は「入力欄が持つ文字列」です。右側の`tkinter.StringVar(master=self.window)`はTkinterが文字列を保持・通知するための変数を作り、`master`で所属するウィンドウ`self.window`を指定します。

- **43行目：`self.input_text.trace_add("write", self.forget_answer)`** — `trace_add`は「変化を知らせる処理を登録する」。右側の`"write"`は文字列が書き換えられた時という意味で、`self.forget_answer`は呼び出してほしい処理そのもの。**`() `を付けずに登録し、今は実行しません**。書き換えが起きた後に動きます。

- **47行目：`self.number_entry.pack(fill="x", padx=16)`** — `pack(fill="x", padx=16)`で入力欄を配置します。`fill="x"`は横方向に広げる指定、`padx=16`は左右の間隔を16ピクセルにする指定です。

- **49行目：`self.expression_label = tkinter.Label(`** — 左側の`self.expression_label`は「計算式の表示欄」。右側の`tkinter.Label(`で新しいラベルを作り始めます。

- **50行目：`self.window, text="計算式:", wraplength=380`** — `self.window`は置くウィンドウ、`text="計算式:"`は最初に表示する文字列、`wraplength=380`は文章を幅380ピクセルで折り返す指定です。

- **51行目：`)`** — `)`でラベルの作成を終え、49行目の`self.expression_label`に入れます。

- **53行目：`self.expression_label.pack(fill="x", pady=6)`** — `pack(fill="x", pady=6)`は式の欄を横へ広げ、上下に6ピクセルの間隔を付けて配置します。

- **55行目：`self.result_label = tkinter.Label(self.window, text="答え:", wraplength=380)`** — 左の`self.result_label`は「答えを表示する欄」。右側の`tkinter.Label`はラベル作成、`self.window`は置き先、`text="答え:"`は最初の文字、`wraplength=380`は表示が長いときの折り返し幅です。

## 59〜72行：ボタンが入る枠と行・列を用意する

まずボタンの外側の枠を作り、4列・5行が同じ幅と高さで広がる設定をします。

完成版のPythonコード：[ `calculator.py` の59〜72行](./src/calculator.py#L59-L72)

```python
    # 数字と計算記号のボタンを配置する create_buttons を宣言する
    def create_buttons(self):
        # self.buttons_frame（ボタンの枠）に self.window 内の部品をまとめる枠を入れる
        self.buttons_frame = tkinter.Frame(self.window)
        # self.buttons_frame を縦横へ広げ、左右と上下に12ピクセルずつ間を空ける
        self.buttons_frame.pack(fill="both", expand=True, padx=12, pady=12)
        # column（列番号）に0から3までの番号を入れ、次の処理を繰り返す
        for column in range(4):
            # self.buttons_frame の column 列へ、余った幅を同じ割合で配分する
            self.buttons_frame.columnconfigure(column, weight=1, uniform="buttons")
        # row（行番号）に0から4までの番号を入れ、次の処理を繰り返す
        for row in range(5):
            # self.buttons_frame の row 行へ、余った高さを同じ割合で配分する
            self.buttons_frame.rowconfigure(row, weight=1)
```

以下では、**実際のコードの行番号順**に読みます。各行で`=`の右側の指定と、その結果どこが変わるかも確認してください。

- **60行目：`def create_buttons(self):`** — `create_buttons`（ボタンを作る）というメソッドを宣言します。前章の`self.create_buttons()`が呼んだときに、61行目以降の処理を実行します。

- **62行目：`self.buttons_frame = tkinter.Frame(self.window)`** — 左側の`self.buttons_frame`は「ボタンを入れる枠」。右側の`tkinter.Frame(self.window)`はウィンドウ内へ配置できる**枠**を新しく作ります。枠の中へ複数のボタンを並べます。

- **64行目：`self.buttons_frame.pack(fill="both", expand=True, padx=12, pady=12)`** — `pack`でその枠を配置。`fill="both"`は縦と横の両方へ広げ、`expand=True`は余った空間も使い、`padx=12`は左右12、`pady=12`は上下12ピクセルの間を空ける指定です。

- **66行目：`for column in range(4):`** — `for`は「順番に繰り返す」。`range(4)`が0・1・2・3を作り、`column`（列番号）へ1個ずつ入れて下の68行目を4回実行します。

- **68行目：`self.buttons_frame.columnconfigure(column, weight=1, uniform="buttons")`** — 右側の`column`が今設定する列番号、`weight=1`が余った横幅を配分する重み、`uniform="buttons"`は`buttons`という同じグループの列を同じ比率の幅にする指定です。各列を均等に広げます。

- **70行目：`for row in range(5):`** — `range(5)`で0・1・2・3・4の5つの番号を作り、`row`（行番号）へ順に入れて72行目を5回実行します。

- **72行目：`self.buttons_frame.rowconfigure(row, weight=1)`** — `rowconfigure(row, weight=1)`は今の行番号`row`の高さへ余った領域を同じ重みで配分する指定です。

## 73〜83行：数字ボタンの位置を決める

数字と行・列の組を一覧へ保存してから、1個ずつボタンを作ります。

完成版のPythonコード：[ `calculator.py` の73〜83行](./src/calculator.py#L73-L83)

```python
        # digit_positions（数字と配置位置）に、数字の文字列・行番号・列番号の組を並べたリストを入れる
        digit_positions = [
            ("7", 1, 0), ("8", 1, 1), ("9", 1, 2),
            ("4", 2, 0), ("5", 2, 1), ("6", 2, 2),
            ("1", 3, 0), ("2", 3, 1), ("3", 3, 2),
```

以下では、**実際のコードの行番号順**に読みます。各行で`=`の右側の指定と、その結果どこが変わるかも確認してください。

- **74行目：`digit_positions = [`** — 左側の`digit_positions`は「数字と置き場所の一覧」。右側の`[`から、数字文字列・行番号・列番号をまとめた組を並べた**リスト**を作り始めます。`positions`は「位置」です。

- **75行目：`("7", 1, 0), ("8", 1, 1), ("9", 1, 2),`** — `("7", 1, 0)`は文字7を1行目の0列目へ置く組です。同じ行で8・9の位置も指定します。**行・列とも0から数えます**。

- **76行目：`("4", 2, 0), ("5", 2, 1), ("6", 2, 2),`** — 4・5・6をそれぞれ2行目の0・1・2列へ置く組です。

- **77行目：`("1", 3, 0), ("2", 3, 1), ("3", 3, 2),`** — 1・2・3をそれぞれ3行目の0・1・2列へ置く組です。

- **79行目：`]`** — `]`で74行目から並べた数字の一覧を閉じ、`digit_positions`へ保存します。この時点ではまだ実際のボタンを置いていません。

## 99〜108行：ボタン1個を実際に配置する

繰り返しから呼ばれた`create_button`がボタンを作り、行・列へ置きます。

完成版のPythonコード：[ `calculator.py` の99〜108行](./src/calculator.py#L99-L108)

```python
    # 指定した文字と処理のボタンを配置する create_button を宣言する
    def create_button(self, text, row, column, command, column_span=1):
        # column_span（使う列数）には、ボタンを広げる列の数が入り、省略した場合は1になる
        # button（ボタン）に text を表示し、押すと command を実行するボタンを入れる
        button = tkinter.Button(self.buttons_frame, text=text, command=command)
        # button を row 行・column 列から column_span 列分へ広げ、周囲に4ピクセルずつ間を空ける
        button.grid(
            row=row, column=column, columnspan=column_span,
            sticky="nsew", padx=4, pady=4
        )
```

以下では、**実際のコードの行番号順**に読みます。各行で`=`の右側の指定と、その結果どこが変わるかも確認してください。

- **100行目：`def create_button(self, text, row, column, command, column_span=1):`** — `create_button`（ボタンを作る）メソッドの宣言です。受け取る値は`text`（文字）、`row`（行）、`column`（列）、`command`（操作時の処理）、`column_span`（横に使う列数）。最後を省略すると`=1`によって1列になります。

- **103行目：`button = tkinter.Button(self.buttons_frame, text=text, command=command)`** — 左側の`button`は「ボタン」。右側の`tkinter.Button(...)`がボタンを作ります。`self.buttons_frame`は置く枠、`text=text`は表示文字、`command=command`は押された後に呼ぶ処理です。ここではまだその処理を呼び出しません。

- **105行目：`button.grid(`** — `button.grid(`は枠内でボタンを行・列の**マス目**へ配置する呼び出しの始まりです。引数指定は108行目まで続きます。

- **106行目：`row=row, column=column, columnspan=column_span,`** — `row=row`は行番号、`column=column`は列番号、`columnspan=column_span`は横に何列をまたぐかという指定です。

- **107行目：`sticky="nsew", padx=4, pady=4`** — `sticky="nsew"`は北・南・東・西、つまり上下左右へボタンを広げます。`padx=4`は左右、`pady=4`は上下に4ピクセルずつ間を空けます。

- **108行目：`)`** — `)`で105行目からの配置を閉じます。これで1個のボタンが指定した位置に置かれます。
