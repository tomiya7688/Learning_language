# 3. 入力欄と数字・計算ボタンを読む

> **「数字のボタンがきれいに並んでるけど、どこで場所を決めてるの？」**

[2章](./02_電卓の準備を読む.md)で `self.create_display()` と `self.create_buttons()` を呼び出しました。その**中身が出てくる順番**に、`calculator.py` の32〜108行を読みます。電卓は先ほど保存した完成品をそのまま使います。

## 32〜57行：上から入力欄、式、答えを置く

[`create_display` の32〜57行](./src/calculator.py#L32-L57)で、ウィンドウに次の順番で部品を置いています。

1. **案内**：`self.number_label`（数字の案内）に「数字（sin・cosは角度を度で入力）」という文字列を持つ `tkinter.Label`（文字を表示する部品）を入れます。`self.number_label.pack(pady=6)` が上下に6ピクセルの間隔を空けて表示位置を決めます。
2. **入力の文字列**：`self.input_text`（入力欄の文字列）に `tkinter.StringVar(master=self.window)` を入れます。これは入力された文字をウィンドウと結び付けて持つためのものです。
3. **入力欄**：`self.number_entry`（数字の入力欄）に `tkinter.Entry`（一行の入力欄）を入れます。`textvariable=self.input_text` と指定するため、入力欄に書いた文字と `self.input_text` が対応します。
4. **計算式**：`self.expression_label`（式の表示）に最初は `計算式:` と出す `tkinter.Label` を入れます。
5. **答え**：`self.result_label`（答えの表示）に最初は `答え:` と出す `tkinter.Label` を入れます。

`Label` は「札・表示する文字」、`Entry` は「入力欄」、`pack` は「並べて配置する」、`fill="x"` は「横へ広げる」、`padx=16` は「左右の間を16ピクセル空ける」という意味です。式と答えの `wraplength=380` は、長い表示を幅380ピクセルで折り返すために使います。

[`calculator.py` の40〜47行](./src/calculator.py#L40-L47)には、次の指定もあります。

- `self.input_text.trace_add("write", self.forget_answer)`：`write` は「書き込み」です。入力欄の文字が書き換えられたら `forget_answer`（保存していた答えを忘れる）を**あとで呼び出すよう登録**します。
- `self.forget_answer` の後ろに `()` が**付いていない**のは登録だけを行うためです。ここで実行するのではありません。後の[4章](./04_答えと式の表示を読む.md)で、この通知が計算にどう影響するかを確認します。

## 59〜72行：ボタンの入る枠を用意する

[`create_buttons` の59〜72行](./src/calculator.py#L59-L72)では、`self.buttons_frame`（ボタンの枠）に `tkinter.Frame` で作った入れ物を保存し、`pack` で広げて配置します。

`for column in range(4):` は「`column`（列番号）を0、1、2、3と変えて4回繰り返す」という意味です。`columnconfigure` は各列の幅を調整します。`uniform="buttons"` なので、同じ種類のボタン列を同じ割合で広げます。`for row in range(5):` は `row`（行番号）を0〜4にして、`rowconfigure` で5行の高さを調整します。

## 73〜97行：何のボタンをどこへ置くか決める

[`calculator.py` の73〜83行](./src/calculator.py#L73-L83)の `digit_positions` は「数字と配置位置」の一覧です。

```text
("7", 1, 0) は「文字7を、1行目の0列目へ置く」
("0", 4, 0) は「文字0を、4行目の0列目へ置く」
```

行も列も0から数えます。`("7", 1, 0)` のように複数の値を括弧でまとめたものを「組（タプル）」と呼びます。`for digit, row, column in digit_positions:` は、一覧の組を1つずつ取り出して、文字・行番号・列番号へ入れます。

`partial(self.append_digit, digit)` は、`append_digit`（数字を追加する）に、押されたとき渡す数字を**先に指定した処理**を作ります。ここでも `self.append_digit(...)` をまだ実行しません。電卓画面で7を押した後に、登録した処理が実行されます。

[`calculator.py` の84〜97行](./src/calculator.py#L84-L97)の `operation_positions`（操作ボタンの位置）は、文字・行・列・実行する処理をまとめた一覧です。

| 実際の組 | ボタンを押したときの仕事 |
| --- | --- |
| `("sin", 0, 0, partial(...))` | 角度のsinを計算する |
| `("cos", 0, 1, partial(...))` | 角度のcosを計算する |
| `("C", 0, 2, self.clear)` | 入力や式を消す |
| `("+", 3, 3, self.select_addition)` | 足し算の記号を選ぶ |
| `("=", 4, 2, self.calculate)` | 式を計算する |

`2 if text == "=" else 1` は「`text` が `"="` なら列を2つ使い、それ以外は1つ使う」という指定です。`if` は「もし」、`else` は「それ以外」、`==` は「等しいか調べる」です。

## 99〜108行：ボタンを実際に配置する

[`create_button` の99〜108行](./src/calculator.py#L99-L108)は、一つのボタンを作って配置する処理です。

`text`（表示文字）、`row`（行番号）、`column`（列番号）、`command`（押したときの処理）、`column_span`（横に何列使うか）を受け取ります。

`tkinter.Button(self.buttons_frame, text=text, command=command)` がボタンを作り、`button.grid(...)` が指定した行・列へ置きます。`columnspan` は使う列数、`sticky="nsew"` は上下左右に広げる指定、`padx=4` と `pady=4` は周囲の間隔です。

## 案内の文字を変更してみる

1. 電卓を閉じてから、VS Codeで `calculator_practice/src/calculator.py` を開いてください。
2. Ctrl + F（macOSはCommand + F）で `text="数字（sin・cosは角度を度で入力）"` を探してください。[35〜37行](./src/calculator.py#L35-L37)が見つかります。
3. 文字だけを `"数字を入力（sin・cosは角度を度で入力）"` に変えて、保存してください。`text=` や括弧は残してください。これは練習用の変更です。
4. Windowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` をターミナルから実行し、入力欄の上の案内が変わったことを確認してください。
5. 電卓を閉じて元の文字へ戻し、保存してください。次の章も完成版のコードを使って読みます。
