# 2. 完成した関数電卓の準備を読む

> **「電卓を作るとき、画面の大きさや最初の数字はどこで決まるの？」**

[1章](./01_起動の流れを読む.md)では、`app.py` の `CalculatorApp()` で電卓を1個作りました。この章から`calculator.py`を**1行目から順番に**読みます。どのコードも、保存済みの完成版からの抜粋です。

## 1〜6行：3つの道具を読み込む

実際のPythonコード：[ `calculator.py` の1〜6行](./src/calculator.py#L1-L6)

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
# math を、このプログラムで使えるようにする
import math
# functools から、処理に指定する値を先に固定する partial を読み込む
from functools import partial
```

- **1行目**：`#` から後ろはコメントです。2行目が何をするかを説明し、実行はされません。
- **2行目 `import tkinter`**：`import` は「読み込んで使えるようにする」、`tkinter`（ティーケーインター）はPythonでウィンドウ・文字・ボタンを作る道具の名前です。`tkinter.Tk()` で画面を作るときに使います。**読み込むだけでは、画面はまだ開きません。**
- **3行目**：次の`math`についてのコメントです。
- **4行目 `import math`**：`math` は「数学」という意味です。`math.radians`（角度の単位変換）や`math.sin`、`math.cos`などを後で使えるようにします。この行では計算しません。
- **5行目**：次の`partial`についてのコメントです。
- **6行目 `from functools import partial`**：`functools` は「関数のための道具集」、`partial` は「一部をあらかじめ決めるもの」という意味です。`functools`から`partial`という機能を読み込み、後でボタンへ「7を追加する処理」などを登録するために使います。まだ数字ボタンは作りません。

## 9〜18行：電卓のクラスと、最初の値

実際のPythonコード：[ `calculator.py` の9〜18行](./src/calculator.py#L9-L18)

```python
# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを宣言する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を宣言する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
        # self.replace_input（次の数字ボタンか小数点ボタンで入力を置き換えるか）に False を入れる
        self.replace_input = False
        # self.answer_value（表示する前の答え）に、答えがないことを表す None を入れる
        self.answer_value = None
```

- **9行目**：`CalculatorApp`（電卓アプリ）へ電卓の情報と処理をまとめる理由を記したコメントです。
- **10行目 `class CalculatorApp:`**：`class`は「クラスを宣言する」という書き方です。`CalculatorApp`は、`Calculator`（電卓）と`App`（アプリ）をつなげた名前です。`:`の下で字下げした行に、このクラスが持つ処理を書きます。ここではまだ電卓の画面を作りません。
- **11行目**：次に宣言する`__init__`についてのコメントです。
- **12行目 `def __init__(self):`**：`def`は処理へ名前を付ける関数の宣言です。`__init__`は電卓を作るときに準備する処理、`self`は「今作っている電卓自身」を表します。`app.py`の`CalculatorApp()`を実行すると、この中身が始まります。
- **13行目**：`self.calculation_parts`が「計算式の部品を入れる一覧」であることを示すコメントです。
- **14行目 `self.calculation_parts = []`**：左側の`self.calculation_parts`は「この電卓の計算式の部品」、`=`は右側の値を入れる記号です。**右側の`[]`**は、まだ中身のない**リスト（一覧）**です。計算記号や数字を入力する前なので空から始めます。
- **15行目**：`self.replace_input`は「次の数字ボタンで前の答えを置き換えるか」という意味だと説明するコメントです。
- **16行目 `self.replace_input = False`**：右側の`False`（フォールス）は「いいえ／成り立たない」という意味です。左側に`False`を保存して、電卓を作った直後は数字を置き換える必要がないことを表します。`True`（トゥルー）は反対に「はい／成り立つ」です。
- **17行目**：`self.answer_value`が「画面に表示する前の答え」という意味だと説明するコメントです。
- **18行目 `self.answer_value = None`**：右側の`None`（ノン）は、この電卓で「まだ答えを保存していない」という状態です。左側へ`None`を入れます。**数値の0を入れたのではありません。** 0を答えとして計算した場合と、まだ答えがない場合を区別するためです。

`calculation` は「計算」、`parts` は「部品」、`replace` は「置き換える」、`input` は「入力」、`answer` は「答え」、`value` は「値」です。変数名の日本語訳だけで終わらず、**右側の値が何を表し、左側のどこに入るか**を確認してください。

## 19〜30行：ウィンドウを作り、初めの大きさを決める

実際のPythonコード：[ `calculator.py` の19〜30行](./src/calculator.py#L19-L30)

```python
        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「関数電卓」にする
        self.window.title("関数電卓")
        # self.window の大きさを横420、縦520にする
        self.window.geometry("420x520")
        # self.window の最小の大きさを横420、縦520にする
        self.window.minsize(420, 520)
        # 入力欄・式・答えを配置する self.create_display を呼び出す
        self.create_display()
        # 数字と計算記号のボタンを配置する self.create_buttons を呼び出す
        self.create_buttons()
```

- **19行目**：`self.window`は「この電卓が持つウィンドウ」という意味だと説明しています。
- **20行目 `self.window = tkinter.Tk()`**：右側の`tkinter.Tk()`は、Tkinterの画面（ウィンドウ）を1つ作ります。`Tk`はTkinterの画面を作るためのクラスです。**作られたウィンドウを左側の`self.window`へ入れます。** ここではまだボタンは置いていません。
- **21行目**：次に画面の題名を設定することを示すコメントです。
- **22行目 `self.window.title("関数電卓")`**：`title`は「題名」です。右側の丸括弧へ指定した文字列`"関数電卓"`を、`self.window`のタイトルバーに使います。`" "`は文字列を囲む記号で、画面には表示されません。
- **23行目**：ウィンドウの初めの大きさについてのコメントです。
- **24行目 `self.window.geometry("420x520")`**：`geometry`（ジオメトリー）は「寸法・形」という意味です。右側の文字列`"420x520"`は幅420ピクセル、高さ520ピクセルを指定します。ピクセルは画面の大きさを数える単位です。
- **25行目**：ウィンドウの最小寸法についてのコメントです。
- **26行目 `self.window.minsize(420, 520)`**：`minsize`は「最小の大きさ」という意味です。丸括弧の**1つ目の420は最小幅、2つ目の520は最小高さ**です。`geometry`の初期の寸法と違い、これより小さく縮められないようにする指定です。
- **27行目**：入力欄と表示欄を用意する次の処理を説明するコメントです。
- **28行目 `self.create_display()`**：`create`は「作る」、`display`は「表示」です。この電卓の`create_display`を呼び出し、入力欄・計算式・答えの欄を**実際に作ります**。中身は[3章で32〜57行](./03_入力欄とボタンを読む.md)を読みます。
- **29行目**：数字や計算記号のボタンを用意する次の処理を説明するコメントです。
- **30行目 `self.create_buttons()`**：`buttons`は「ボタン」です。この電卓の`create_buttons`を呼び出し、数字・計算記号・C・sin・cosなどのボタンを実際に作ります。中身は[3章で59〜108行](./03_入力欄とボタンを読む.md)に続きます。

**20行目でウィンドウを作る → 22〜26行目で外見の基準を決める → 28・30行目で入力欄とボタンを用意する**順番です。`app.py`の`CalculatorApp()`から始まった準備が、ここで進んでいます。

## ウィンドウの題名を変更して確かめる

1. 起動中の電卓を閉じて、VS Codeで`calculator_practice/src/calculator.py`を開いてください。
2. Windows / LinuxはCtrl + F、macOSはCommand + Fで`self.window.title("関数電卓")`を探してください。[22行](./src/calculator.py#L22-L22)です。
3. **22行目と21行目のコメント**を、次の2行へ置き換えてください。これらは変更後の練習用コードで、配布版とは異なります。

```python
        # self.window のタイトルを「わたしの関数電卓」にする
        self.window.title("わたしの関数電卓")
```

4. ファイルを保存してから、練習用フォルダのターミナルでWindowsは`python src/app.py`、macOS / Linuxは`python3 src/app.py`を入力し、Enterキーを押してください。
5. ウィンドウ上部の題名が「わたしの関数電卓」になったら成功です。閉じてから元の「関数電卓」へ戻し、コメントも戻して保存してください。
