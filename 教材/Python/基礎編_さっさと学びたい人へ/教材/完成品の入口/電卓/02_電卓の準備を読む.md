# 2. 電卓の準備とウィンドウを読む

> **「電卓のボタンを押す前に、何が用意されているの？」**

[1章](./01_起動の流れを読む.md)では、`app.py` の `CalculatorApp()` が電卓を作ると分かりました。ここからは同じ完成品の `calculator.py` を**先頭から順番に**読みます。

## 1〜6行：使う道具を読み込む

[`calculator.py` の1〜6行](./src/calculator.py#L1-L6)では、次の道具を読み込んでいます。

- `import tkinter`：`tkinter`（ティーケーインター）は、ウィンドウやボタンを作る道具です。後で `tkinter.Tk()` や `tkinter.Button(...)` を使います。
- `import math`：`math` は「数学」という意味です。`math.sin(...)`、`math.cos(...)` といった角度の計算に使います。
- `from functools import partial`：`partial` は「一部分をあらかじめ決める」という意味です。後で「7のボタンを押したら文字列の7を追加する」といった処理をボタンへ登録します。

これらは、電卓を**作る前に使えるようにする準備**です。`import` を書いた時点ではウィンドウは開きません。

## 9〜18行：電卓1個の持ち物を決める

[`calculator.py` の9〜18行](./src/calculator.py#L9-L18)で `class CalculatorApp:` と書きます。`class` は、同じ対象に関係する情報と操作をまとめる**クラスの宣言**です。電卓の画面、入力、計算、表示を1つの `CalculatorApp` にまとめます。

`def __init__(self):` の `__init__` は、`CalculatorApp()` で電卓を作るときに実行される、**最初の準備処理**です。`self` は「この電卓自身」を指します。

| 実際の行 | 日本語の意味 | 作ったときに入る値 |
| --- | --- | --- |
| `self.calculation_parts = []` | 計算式の部品の一覧 | `[]`：まだ何もない一覧 |
| `self.replace_input = False` | 次の入力で前の数字を置き換えるか | `False`：「いいえ」 |
| `self.answer_value = None` | 表示前の答えの数値 | `None`：「答えがまだない」 |

`calculation` は「計算」、`parts` は「部品」、`replace` は「置き換える」、`input` は「入力」、`answer` は「答え」、`value` は「値」という意味です。

`False` と `True` はPythonで条件の成り立ち方を表す値です。`False` は「いいえ／成り立たない」、`True` は「はい／成り立つ」です。`None` は「この電卓ではまだ答えを保存していない」状態で、数値の0とは違います。

初めから計算式や答えを入れておくと、電卓がまだ操作されていないのに古い値があるように見えます。そこで空の一覧、`False`、`None` から始めます。

## 19〜30行：実際のウィンドウを作る

[`calculator.py` の19〜30行](./src/calculator.py#L19-L30)を順に見てください。

1. `self.window = tkinter.Tk()`：`window` は「ウィンドウ」という意味です。`tkinter.Tk()` で画面を1つ作り、`self.window` に入れます。
2. `self.window.title("関数電卓")`：ウィンドウ上部の題名を「関数電卓」にします。
3. `self.window.geometry("420x520")`：初めの幅を420、高さを520に指定します。単位は画面上の点を数える「ピクセル」です。
4. `self.window.minsize(420, 520)`：ウィンドウを縮められる最小の幅・高さを420×520にします。
5. `self.create_display()`：`display` は「表示」です。入力欄・式・答えを表示する部品を作ります。
6. `self.create_buttons()`：`buttons` は「ボタン」です。数字や計算記号のボタンを並べます。

`create_display` と `create_buttons` はこの後の部分に宣言した**メソッド**です。メソッドはクラスの中にある関数を指します。まだ中身を読んでいなくても、ここでは「どんな準備を呼んでいるか」を確かめてください。次の章で中身を続けて読みます。

## ウィンドウの題名を変えてみる

1. 開いている関数電卓のウィンドウを閉じ、VS Codeで `calculator_practice/src/calculator.py` を開いてください。
2. Windows / LinuxならCtrl + F、macOSならCommand + Fで `self.window.title("関数電卓")` を検索してください。[22行](./src/calculator.py#L22-L22)が見つかります。
3. 題名だけ変えるので、次のように書き換えてください。これは**練習用の変更**で、公開ソースの抜粋ではありません。

```python
        # self.window のタイトルを「わたしの関数電卓」にする
        self.window.title("わたしの関数電卓")
```

4. 元のコメントも変更し、Windows / LinuxならCtrl + S、macOSならCommand + Sで保存してください。VS Codeのターミナルを開き、練習用フォルダからWindowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` を入力してEnterキーを押してください。
5. ウィンドウ上部の題名が「わたしの関数電卓」になれば、変更した行を確認できています。電卓を閉じ、もう一度元の題名「関数電卓」に戻して保存してください。
