# 9. 完成した関数電卓を改造する

> **「コードの各行が分かった！今度は自分で機能を変えてみたい！」**

[1〜8章の目次](./電卓のコードを読む.md)で、`app.py`の先頭から`calculator.py`の最後まで、実際のコードを1行ずつ読みました。ここでは、**今まで使った完成品をそのまま変更**し、どの操作が変わるか確かめます。

## 変更前の電卓を残す

1. 起動中の電卓を閉じて、ターミナルが入力待ちへ戻っていることを確かめてください。
2. 練習用フォルダの`src/calculator.py`をコピーし、同じ`src`へ`calculator_before.py`という名前でも保存してください。`before`は「変更前」という意味です。
3. `app.py`は`from calculator import CalculatorApp`と書いているため、**起動時に読むのは`calculator.py`です**。`calculator_before.py`は変更前の保存用で、自動では読み込まれません。

## 改造1：「C」のボタンを「クリア」と表示する

「C」は入力や計算式を消すボタンです。ボタンの**表示する文字**だけ変更して、呼び出す処理は変えないようにします。

### 変更前の完成コード

元ファイル：[ `calculator.py` の84〜93行](./src/calculator.py#L84-L93)

```python
        # operation_positions（計算ボタンと配置位置）に、表示文字列・行・列・押した時の処理の組を入れる
        operation_positions = [
            ("sin", 0, 0, partial(self.apply_trigonometry, "sin")),
            ("cos", 0, 1, partial(self.apply_trigonometry, "cos")),
            ("C", 0, 2, self.clear), ("/", 0, 3, self.select_division),
            ("*", 1, 3, self.select_multiplication),
            ("-", 2, 3, self.select_subtraction),
            ("+", 3, 3, self.select_addition),
            (".", 4, 1, self.append_decimal_point), ("=", 4, 2, self.calculate),
        ]
```

**88行目**の`("C", 0, 2, self.clear)`は、一組に4つの値を入れています。`"C"`はボタンの表示文字、`0`は0行目、`2`は2列目、`self.clear`は押されたときに使う「消す」処理です。**`self.clear`に`()`が付いていないのは、作成時には実行せず、クリックされた後に呼び出すため**です。

### 表示文字だけを変更する

1. VS Codeで`calculator_practice/src/calculator.py`を開き、Ctrl + F（macOSはCommand + F）で`("C", 0, 2, self.clear)`を検索してください。
2. 88行目の`"C"`を`"クリア"`へ変更してください。82〜97行目は[3章](./03_入力欄とボタンを読む.md)で読んだボタンの一覧です。**この1組だけ**変更します。

変更後の練習用コード：

```python
            ("クリア", 0, 2, self.clear), ("/", 0, 3, self.select_division),
```

この行の右側の`"/"`（割り算ボタン）や位置の数値はそのままにしてください。元の`self.clear`も残すので、消す処理には変更がありません。

3. 保存し、練習用フォルダのターミナルでWindowsは`python src/app.py`、macOS / Linuxは`python3 src/app.py`を入力してEnterキーを押してください。
4. 「C」ボタンの代わりに「クリア」と表示されることを確認してください。「1」「2」「クリア」と押したとき、入力欄が空になれば、表示文字だけが変わって処理は変わっていないと分かります。

## 改造2：Escキーでも入力・式・答えを消す

ボタンをクリックしなくても、キーボードのEscキーを押すことで`self.clear()`を実行できるようにします。この処理は元からあるので、**Escキーが押されたときに呼び出す設定**を追加します。

### 新しい行を追加する場所

起動している電卓を閉じ、VS Codeの`calculator.py`で`self.create_buttons()`を検索してください。元ファイルの[25〜30行](./src/calculator.py#L25-L30)が次の部分です。

```python
        # self.window の最小の大きさを横420、縦520にする
        self.window.minsize(420, 520)
        # 入力欄・式・答えを配置する self.create_display を呼び出す
        self.create_display()
        # 数字と計算記号のボタンを配置する self.create_buttons を呼び出す
        self.create_buttons()

```

`self.create_buttons()`の**すぐ下**へ、次の2行を追加してください。先頭の空白8個は`self.create_buttons()`と同じにしてください。追加した後の練習用コードです。

```python
        # Escキーが押されたら、電卓の入力・式・答えの表示を消す
        self.window.bind("<Escape>", lambda event: self.clear())
```

追加した2行について、1行ずつ説明します。

- **コメント行**：Escキーを押したときの動作を日本語で説明しています。`#`から始まるため実行されません。
- **`self.window.bind(...)`の行**：`self.window`（この電卓のウィンドウ）の`bind`（操作と処理を結び付ける）へ、2つの値を渡しています。**1つ目の`"<Escape>"`**はEscキーを押す操作を表す文字列、**2つ目の`lambda event: self.clear()`**は、その操作を受け取ってから実行する処理です。`lambda`は、短い処理へ名前を付けずに書くPythonの構文です。
- **`event`**は「起きた操作の知らせ」という意味です。今回は受け取りますが、その内容を調べる必要がないので使いません。Escキーが押されたとき、`self.clear()`の`()`によって電卓の消去処理を実行します。

`bind`は呼び出す処理を**登録**します。この行へたどり着いた直後に入力欄を消すわけではありません。後でEscキーが押されたときに、`lambda`の中身が動きます。

### 保存して操作を確認する

1. `calculator.py`を保存し、練習用フォルダのターミナルからWindowsは`python src/app.py`、macOS / Linuxは`python3 src/app.py`で電卓を起動してください。
2. 数字ボタンで`123`を入力してください。
3. **入力欄をクリックしてからEscキーを押してください。** 入力欄が空になり、式の欄が`計算式:`、答えの欄が`答え:`へ戻れば成功です。
4. 数字を入力し、今度は「クリア」ボタンをクリックしてください。Escキーと同じ`self.clear()`の処理によって入力が消えます。

## 変更を戻すか、自分の電卓として残す

変更を残して使っても構いません。元に戻す場合は、電卓を閉じ、`calculator_before.py`のコード全体を`calculator.py`へ書き戻して保存してください。起動用の`app.py`は変更していません。

次は「どのボタンの表示を変えたいか」「入力を間違えたとき何を表示したいか」など、改造したい動作を決めて、その処理を担当する行を探してみましょう。初めて見つけた名前があれば、その行の**左側の保存先**と**右側で実際に使う値や処理**から確認してください。
