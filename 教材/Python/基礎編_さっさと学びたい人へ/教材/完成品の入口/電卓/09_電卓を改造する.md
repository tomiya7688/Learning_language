# 9. 完成した関数電卓を自分で改造する

> **「コードの仕組みは追えた。今度は自分の電卓にしたい！」**

[1〜8章](./電卓のコードを読む.md)で、`app.py` の先頭から `calculator.py` の最後まで読みました。ここでは**完成品のコードを変更し、実際のウィンドウで確かめる**練習をします。すでに完成したアプリをもう一度作り直す必要はありません。

## 変更前のファイルを残しておく

1. 電卓のウィンドウが開いていたら閉じてください。ターミナルが入力待ちに戻っていることを確認してください。
2. 練習用フォルダの `src/calculator.py` をコピーし、同じフォルダに `calculator_before.py` という名前でも保存してください。`before` は「変更前」という意味です。
3. 起動するのは引き続き `src/app.py` です。`app.py` は `calculator.py` を読み込むので、`calculator_before.py` の方は読み込まれません。

## 改造1：Cのボタンを「クリア」にする

まず見た目だけ変えます。

1. VS Codeで `calculator_practice/src/calculator.py` を開き、Ctrl + F（macOSはCommand + F）で `("C", 0, 2, self.clear)` を検索してください。[`calculator.py` の84〜93行](./src/calculator.py#L84-L93)にあります。
2. この組を次のように変えてください。変更するのは`表示する文字列`だけです。

```python
            ("クリア", 0, 2, self.clear)
```

3. 保存し、練習用フォルダのターミナルでWindowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` を入力してEnterキーを押してください。
4. 「C」だったボタンが「クリア」になっていることを確認してください。数字を入力してから「クリア」を押すと、前と同じく入力欄が空になります。これは呼び出す `self.clear` を変更していないためです。

## 改造2：Escキーでも入力を消す

今度は**新しい操作**を1つ増やします。キーボードのEscキーを押したら、「クリア」を押したときと同じ動作をさせましょう。

1. 電卓を閉じ、`calculator.py` の `self.create_buttons()` を検索してください。[`calculator.py` の27〜30行](./src/calculator.py#L27-L30)の `__init__` 内にあります。
2. その行の**次**に、次の2行を同じ字下げ（先頭に空白8個）で追加してください。

```python
        # Escキーを押したら、電卓の入力欄と式と答えの表示を消す
        self.window.bind("<Escape>", lambda event: self.clear())
```

`bind` は「操作と処理を結び付ける」、`"<Escape>"` は「Escキーを押す」という知らせです。`lambda event: self.clear()` は、キーの操作を表す `event`（知らせ）が来たら、`self.clear()` を呼び出す小さな処理です。`lambda` は、名前を付けずに短い処理を書くPythonの書き方です。ここでは入力欄やウィンドウへEscを押した知らせが届いたときに使います。

`bind` を書いた時点で `clear()` を**実行するわけではありません**。Escキーを押した後に呼び出します。

3. 保存して、同じ実行コマンドで電卓を起動してください。
4. 数字ボタンで `123` を入力し、**入力欄をクリックした状態でEscキー**を押してください。入力欄が空になり、式と答えの表示が初期状態へ戻れば成功です。
5. クリアボタンでも同じ結果になるか確認してください。画面上のボタンを押す操作とキーボード操作が、どちらも `self.clear()` に届いています。

この変更を残しても構いません。元の状態へ戻したい場合は、追加した2行を削除するか、保存した `calculator_before.py` の内容で `calculator.py` を置き換えて保存してください。

## 次に自分で考える変更

たとえば「ボタンを押したときの案内を変える」「小数点を2回押したときの文を変える」「ウィンドウの題名を変える」といった変更は、すでに読んだコードのどこを直せばよいか探せます。

新しい動きを追加するときは、**何をしたいか → どのファイルと関数が担当するか → 値・表示・操作を変更 → 保存して実行 → 実際の結果を確認**という順番で進めてください。

これで完成コードを実行し、最初から最後まで読み、実際に改造する一連の学習が終わります。
