# 1. 完成した関数電卓の起動を読む

> **「電卓が動くのは分かったけど、どの行が最初に動くの？」**

[関数電卓を保存して動かす](../電卓を動かす.md)ページの手順で、`src/app.py` と `src/calculator.py` を保存して起動してから読んでください。この章では、保存済みの**完成コードを変更せず**、上から1行ずつ追います。

## この章で読むファイル

`app` は「アプリ」という意味です。**App Store（アプリストア）の「App」と同じ英語**です。`app.py` はアプリを起動するPythonファイルです。一方、`calculator` は「電卓」という意味で、`calculator.py` には電卓の画面や計算の仕組みが書かれています。

`CalculatorApp` は、`Calculator`（電卓）と `App`（アプリ）をつなげた名前です。**「電卓アプリ」という意味**で、電卓の情報と操作をまとめたクラスの名前です。クラスは、同じ種類のものを作るために、情報と操作をひとまとめにした設計です。

これから出てくるPythonコードは、[完成版の `app.py`](./src/app.py) と同じです。まず1〜2行、次に5〜10行、最後に13〜15行を読みます。

## 1〜2行：電卓アプリの宣言を読み込む

元ファイル：[ `app.py` の1〜2行](./src/app.py#L1-L2)

次は**実際のPythonコード**です。

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp
```

**1行目**の `#` で始まる文章はコードの説明用の「コメント」です。Pythonはコメントの内容を実行しません。

**2行目**の `from calculator import CalculatorApp` は、次の順に読みます。`from` は「〜から」、`calculator` はファイル名 `calculator.py` の `.py` を外した部分、`import` は「読み込んで使えるようにする」です。したがって「`calculator.py` から、`CalculatorApp` という名前を読み込む」という意味です。

Pythonは`calculator.py`に書かれたクラスなどの宣言を読み込み、`app.py`からその名前を使えるようにします。**この行だけでは電卓を新しく作っていません。** 後で `CalculatorApp()` と書いたときに、電卓の準備が始まります。

## 5〜10行：`main` という関数を宣言する

元ファイル：[ `app.py` の5〜10行](./src/app.py#L5-L10)

```python
# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()
```

**5行目**の `#` はコメントです。`main` は「主な」という意味で、アプリを起動するときの処理に付けた名前です。

**6行目**の `def main():` の `def` は「関数を宣言する」という書き方です。`main` は関数名、`()` は今回受け取る値がないこと、`:` は次の字下げした範囲が関数の中身であることを示します。**6行目で関数を使えるようにしますが、8行目と10行目はまだ実行しません。**

**7行目**のコメントは次の代入を説明しています。

**8行目**の `app = CalculatorApp()` は、左右を分けて読みます。`app` は「アプリ」という意味の変数名、`=` は右側で作った値を左側の変数へ入れる記号です。**右側の `CalculatorApp()`** は、先ほど読み込んだ「電卓アプリ」というクラスから電卓を新しく1個作ります。そのとき[ `calculator.py` の `__init__`](./src/calculator.py#L11-L30) が呼ばれ、電卓の情報、ウィンドウ、入力欄、ボタンが準備されます。その**作られた電卓**を `app` という変数に入れます。ここで完成するのは操作できる画面の準備で、まだ画面の操作待ちは始めていません。

**9行目**は次の処理についてのコメントです。

**10行目**の `app.run()` は、8行目で作った電卓 `app` に対して、`run`（実行する）という処理を**呼び出します**。右端の `()` は呼び出すための括弧です。[ `calculator.py` の `run`](./src/calculator.py#L436-L439) がウィンドウを表示して、ボタンやキーボードの操作を待ちます。

## 13〜15行：関数を実際に呼び出す

元ファイル：[ `app.py` の13〜15行](./src/app.py#L13-L15)

```python
# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

**13行目**は「このファイルを直接実行した場合だけ次を動かす」というコメントです。

**14行目**の `if __name__ == "__main__":` の `if` は「もし」、`==` は左右の値が等しいか調べる記号です。`__name__` はPythonが今のファイルへ付ける名前で、`"__main__"` は「このファイルが直接実行されたときの名前」という文字列です。`python src/app.py` と入力して直接起動した場合は左右が等しいため、字下げした15行目へ進みます。ほかのPythonファイルが`app.py`を読み込むだけなら、通常は左右が異なるので15行目を実行しません。

**15行目**の `main()` は、6行目で宣言した`main`関数を**呼び出して実行**します。`main`と名前だけを書くと、Pythonはその関数を指す値として扱い、**関数の中身を実行する操作にはなりません**。後ろに`()`を付けて`main()`と書くことで初めて、8行目の電卓作成、10行目の操作待ちへ進みます。

## 上から読んだ順と、実行した順を比べる

`app.py` を直接起動したときの順番は次の通りです。

1. **2行目**：`CalculatorApp` を使えるようにします。
2. **6行目**：`main` 関数を宣言します。まだ電卓は作りません。
3. **14〜15行目**：直接実行か確認し、`main()` を呼び出します。
4. **8行目**：`CalculatorApp()` で電卓1個を作り、その準備処理が進みます。
5. **10行目**：`app.run()` でウィンドウが操作を待ちます。

**ファイルに書いてある順番と、関数の中身が実行される順番は異なります。** 先に関数を宣言して、後から呼び出すためです。

## 実際に確かめる

1. VS Codeで練習用フォルダの`src/app.py`を開き、2・6・8・10・14・15行目を順に探してください。
2. 起動中の電卓があれば閉じ、ターミナルが入力待ちに戻ったことを確認してください。
3. 練習用フォルダのターミナルで、Windowsは`python src/app.py`、macOS / Linuxは`python3 src/app.py`を入力してEnterキーを押してください。
4. `CalculatorApp()`の準備が行われ、`app.run()`によって「関数電卓」というウィンドウが表示されることを確かめてください。

今回はコードを変えません。次の章では、電卓を作る`CalculatorApp()`の中身を、`calculator.py`の先頭から1行ずつ読みます。
