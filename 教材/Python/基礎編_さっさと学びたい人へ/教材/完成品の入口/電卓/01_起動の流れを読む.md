# 1. 完成した電卓はどこから動き始める？

> **「電卓は動いた。でも、どの行から始まってるの？」**

まず[完成した関数電卓を保存して動かす](../電卓を動かす.md)ページで、`calculator.py` と `app.py` を同じ `src` フォルダに保存し、電卓を起動してください。ここでは、実際に動かした**完成版のコードを先頭から**読みます。新しい電卓を作り直す章ではありません。

## `app.py` を上から読む

`app` は「アプリ」という意味です。このファイルは、電卓のウィンドウを準備する処理を呼び出し、操作できる状態にする**起動用のファイル**です。画面のボタンや四則演算の中身は、同じフォルダの `calculator.py`（電卓）にあります。

[完成版の `app.py` 1〜15行](./src/app.py#L1-L15)：

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp


# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

### 1〜2行：別のファイルの電卓を使えるようにする

`from calculator import CalculatorApp` の `from` は「〜から」、`import` は「読み込んで使う」という意味です。Pythonは、同じ `src` の `calculator.py` から、`CalculatorApp`（電卓アプリ）という**クラス**の宣言を読み込みます。クラスは、電卓1個分の情報と操作をまとめた設計です。これで `app.py` から `CalculatorApp()` を書けるようになります。

`CalculatorApp` という名前を読み込んだだけでは電卓のウィンドウはまだ作られません。[`calculator.py` のクラス宣言](./src/calculator.py#L9-L12)と、後に使う処理の違いに注目してください。

### 5〜10行：電卓を作って動かす

[`app.py` の5〜10行](./src/app.py#L5-L10)の `def main():` は、`main`（主な処理）という名前の**関数を宣言**します。関数は、後から名前と `()` を書いて実行できる処理のまとまりです。宣言しただけでは、字下げした中身はまだ動きません。

`app = CalculatorApp()` の `app` は「アプリ」という意味の**変数名**です。`=` は右側で作った値を左の名前へ入れます。`CalculatorApp()` を実行すると、新しい電卓が1個作られ、`app` に入ります。

次の `app.run()` は、`app` に入っている電卓の `run()`（実行する）を呼び出します。[`calculator.py` の436〜439行](./src/calculator.py#L436-L439)で `self.window.mainloop()` が呼ばれ、電卓の画面が操作を待つようになります。`self.window` は、**その電卓自身が持つウィンドウ**です。

### 13〜15行：`main()` を実行する場所

`if` は「もし」という意味で、条件に合ったときだけ下の字下げした行を実行します。`__name__` はPythonが実行方法に応じて付ける名前です。`app.py` を直接起動すると `"__main__"` になるため、`==`（左右が等しいか調べる）が成り立ち、`main()` が呼ばれます。

`main` とだけ書いても実行にはなりません。**`main()` と丸括弧を付けて初めて呼び出します。** 別のPythonファイルが `app.py` を読み込むだけなら、この `if` が成り立たず、勝手に電卓は起動しません。

## 実際の動きと行を対応させる

1. VS Codeで練習用フォルダの `src/app.py` を開いてください。
2. `from calculator import CalculatorApp` を見つけ、次に `def main():`、`app = CalculatorApp()`、`app.run()`、`main()` を順に探してください。
3. 電卓のウィンドウがまだ開いていたら閉じてください。起動したターミナルが入力待ちへ戻ったことを確認してください。
4. VS Codeのターミナルで、練習用フォルダからWindowsは `python src/app.py`、macOS / Linuxは `python3 src/app.py` を入力してEnterキーを押してください。再び関数電卓が開きます。

コードを変更せず、**読む順番と呼び出される順番**を比べる練習です。`app.py` の上から読む順番は「読み込み → 関数宣言 → 条件確認 → `main()` の実行」です。`main()` が動き始めると、今度は関数の中の「電卓の作成 → `run()`」へ進みます。
