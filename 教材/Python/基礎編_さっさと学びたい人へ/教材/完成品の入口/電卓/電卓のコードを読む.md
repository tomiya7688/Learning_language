# 完成した電卓のコードを読む

> **「ボタンを押すと計算できた！入力した数字は、どこで式や答えに変わるの？」**

この電卓は、数字と計算記号をボタンで入力し、四則演算とsin・cosの答えを表示するアプリです。まだ起動していない場合は、同じコースの[電卓を保存して動かす手順](../電卓を動かす.md)で、`app.py` と `calculator.py` を練習用フォルダ内の同じ `src` へ保存して起動してください。このページでは、保存した完成コードの処理を追います。


## Pythonファイルの保存場所

この章のPythonファイルは、練習用フォルダ内の `src` へ保存してください。

起動時に用意した練習用フォルダを使ってください。新しい練習用フォルダは作らず、保存済みのコードと変更をそのまま使ってください。

練習用フォルダの中で、Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderの **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。フォルダ名を `src` と入力してEnterキーを押すと、練習用フォルダの中に `src` ができます。すでに `src` がある場合はそのフォルダを使い、保存済みのコードは必要な変更だけを行ってください。

VS Codeで開くフォルダと、ターミナルの `cd` で移動するフォルダは、`src` の一つ上の練習用フォルダです。保存先を選ぶときは `src` を開き、起動するときは練習用フォルダから `src/app.py` を指定してください。実行手順のコマンドは、この練習用フォルダから入力してください。


## 起動から画面を開くまで

電卓の起動と、入力や計算の処理を同じファイルへ詰め込むと、どこから動き始めるか見つけにくくなります。起動する処理は `app.py`（アプリ）、画面と計算の処理は `calculator.py`（電卓）へ分けています。起動時の処理を `main`（中心の処理）という名前の関数にまとめています。関数は、名前を指定して実行できるように処理をまとめたものです。

元ファイル：[`app.py` 全体](./src/app.py)。

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp


# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

`from calculator import CalculatorApp` は、同じフォルダの `calculator.py` に定義した電卓を、このファイルで使えるようにする行です。読者が `app.py` を実行すると、最後の `if` に続く `main()` が実行され、電卓を作る処理が始まります。別のファイルから `app.py` を読み込んだ場合は、最後の `main()` は実行されません。

電卓の入力、計算途中の式、答え、画面を別々に管理すると、どの入力をどの答えとして表示するか対応を追いにくくなります。同じ電卓の情報と操作を `CalculatorApp`（電卓アプリ）というクラスへまとめています。クラスは、同じ対象に関する情報と操作をまとめて定義する仕組みです。クラスの中に定義した関数をメソッドと呼び、各メソッドの `self` は操作対象の電卓を表します。

[`calculator.py` の10〜30行](./src/calculator.py#L10-L30)の `__init__` は、電卓を作るときの準備を行います。画面の場所を変える処理と、ボタンを押したときの計算を混ぜないため、表示欄の準備は `create_display`、ボタンの準備は `create_buttons` へ分けています。[`calculator.py` の436〜439行](./src/calculator.py#L436-L439)の `run` は、用意した画面を表示し、閉じるまで利用者の操作を待ちます。

## ボタンと押したときの処理をつなぐ

同じ形のボタンを一つずつ作ると、ボタンの見た目を変更するときに何か所も直す必要があります。[`calculator.py` の99〜108行](./src/calculator.py#L99-L108)の `create_button` は、ボタンの文字、行と列、押したときの処理を指定して、一つのボタンを作ります。ボタンの行と列は0から数えます。`command`（押したときの処理）には、そのボタンをクリックした後に実行するメソッドを指定します。

[`calculator.py` の59〜97行](./src/calculator.py#L59-L97)の `create_buttons` は、数字ボタンに `append_digit`（数字を追加する）、計算記号に記号ごとの処理、`=` に `calculate`（計算する）を登録します。`partial` は、押された数字などを先に指定して処理を用意する道具です。たとえば7のボタンには、`append_digit` へ文字列の `"7"` を指定した処理を登録します。

## 2 + 3 が答えになるまで

起動中の電卓で、画面の「C」「2」「+」「3」「=」ボタンを順にクリックしてください。電卓は、式の欄へ `計算式: 2 + 3 = 5`、答えの欄へ `答え: 5`、数字の入力欄へ `5` を表示します。

1. 「2」をクリックすると、[`append_digit`（178〜186行）](./src/calculator.py#L178-L186)が文字列の `"2"` を入力欄の末尾へ追加します。入力欄にあるのは文字列なので、計算前に数値へ変える必要があります。
2. 「+」をクリックすると、[`select_addition`（281〜284行）](./src/calculator.py#L281-L284)が足し算の記号を `add_operator` へ指定します。[`add_operator`（256〜279行）](./src/calculator.py#L256-L279)は、入力欄から読んだ数値2と記号 `"+"` を `self.calculation_parts`（計算式の部品）へ保存し、次の数字を入力できるよう入力欄を空にします。
3. 「3」をクリックすると、[`append_digit`（178〜186行）](./src/calculator.py#L178-L186)が入力欄へ文字列の `"3"` を追加します。先に保存した2と+は、`self.calculation_parts` に残っています。
4. 「=」をクリックすると、[`calculate`（301〜396行）](./src/calculator.py#L301-L396)が最後の数値3を式へ追加し、答え5を求めます。掛け算と割り算がある式では、その二つを先に計算し、残った足し算と引き算を左から計算します。
5. 計算後、[`show_answer`（144〜157行）](./src/calculator.py#L144-L157)が答えを表示し、次の計算で使う元の数値を `self.answer_value`（表示する前の答え）へ保存します。

数字を読んで使えるか確認する処理は、四則演算とsin・cosのどちらでも必要です。二か所で違う入力確認をしないよう、[`read_number`（222〜254行）](./src/calculator.py#L222-L254)へまとめています。`read_number` は、保存した答えがない場合に入力欄の文字列を `float`（小数も扱える数値）へ変換し、保存した答えがある場合は保存済みの数値を返します。空欄、数字に変換できない入力、無限大などは結果の欄へ案内し、`None` を返します。`None` は、この処理では数値を読み取れなかった状態です。計算側は `None` を受け取った場合、式へ追加する前に処理を終えます。数値の0は、読み取れなかった状態と区別して使います。

## 答えの表示と、次の計算に使う数値

長い小数をそのまま表示すると、入力欄と答えの欄が読みにくくなります。[`format_number`（110〜117行）](./src/calculator.py#L110-L117)は、表示する数値を有効数字が最大12桁の文字列へ変換します。有効数字は最初に現れる0以外の数字から数えた桁です。表示の変換は計算する数値を書き換えません。入力中の文字列にも、この変換は適用しません。

たとえば1/3の表示は `0.333333333333` ですが、[`show_answer`（144〜157行）](./src/calculator.py#L144-L157)は表示前の数値を保存します。次に計算記号やsin・cosをクリックすると、[`read_number`（233〜235行）](./src/calculator.py#L233-L235)は保存した数値を返します。`read_number` が表示された文字列を変換せず、保存した数値を直接返すのは、画面に出ていない桁も次の計算で使うためです。

利用者が入力を直した後も前の答えを使うと、変更した数字が計算に反映されません。[`create_display`（40〜47行）](./src/calculator.py#L40-L47)は、入力欄の文字列へ書き込まれたときに [`forget_answer`（136〜142行）](./src/calculator.py#L136-L142)を実行するよう登録します。手入力や貼り付けでは保存した答えが消え、次の計算は書き換えた数字を使います。答えをプログラムが表示するときも同じ通知が来るため、`show_answer` は入力欄を書き換えた後に元の数値を保存します。

## sin・cosと入力の消去

sin・cosは、角度から高さや横の長さの割合を求める計算です。電卓の入力欄には度で角度を指定します。[`apply_trigonometry`（398〜434行）](./src/calculator.py#L398-L434)は、入力された度の角度を、計算の道具が使うラジアンという角度の単位へ変換してからsinかcosを求めます。度を変換せずに使うと、別の角度として計算されます。四則演算の途中でsin・cosを使った場合も、保存済みの式を残し、角度から求めた数値を次の計算で使えます。

[`clear`（209〜220行）](./src/calculator.py#L209-L220)は、入力欄、保存済みの式、式と答えの表示を消します。数字ボタンで前の答えを置き換える処理は、[`prepare_input`（159〜176行）](./src/calculator.py#L159-L176)が担当します。保存済みの式がある場合は入力欄だけを空にし、式がない場合は前の計算全体を消します。手入力で書き換える操作とは処理が異なります。

0で割るときや、途中の式へsin・cosを使うときの画面操作と表示は、同じコースの[電卓を動かすページ](../電卓を動かす.md)にあります。コードを開く場合は、[このフォルダの `calculator.py` 全体](./src/calculator.py)を使ってください。
