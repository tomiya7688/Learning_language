# 長くなったコードを別のPythonファイルに分けて使いたい

挨拶も計算も1つのファイルへ書き足していると、挨拶を変えるだけなのに、長いコードからその場所を探すことになります。

> **「挨拶を直したいだけ！関係ある処理を別のファイルに分けたい！」**

この例は、挨拶を作る処理を別のPythonファイルへまとめ、使う側のファイルから読み込みます。挨拶を変えるときに開くファイルが分かりやすくなります。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## 使われる側のファイルを書く

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をコピーしてください。

```python
# make_greeting は「挨拶を作る」、name は「名前」という意味
# make_greeting という名前で、name を受け取り、下の処理を行う関数を定義する
def make_greeting(name):
    # 「こんにちは 」と name をつないだ文字列を返す
    return "こんにちは " + name
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `greeting_tools.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

greeting は「挨拶」、tools は「道具」という意味です。

[使われる側のサンプルファイルを開く](./greeting_tools.py)

## 実行する側のファイルを書く

VS Codeで再び新しいテキストファイルを開き（Windows / Linuxは Ctrl + N、macOSは Command + N）、次のコード全体をコピーしてください。

```python
# greeting_tools は「挨拶の道具」という意味
# greeting_tools.py にある処理を greeting_tools という名前で使えるようにする
import greeting_tools

# greeting_tools の make_greeting に「たろう」を指定して作った挨拶を表示する
print(greeting_tools.make_greeting("たろう"))
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `use_greeting.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。 先ほどの `greeting_tools.py` と同じフォルダへ保存してください。

use は「使う」、greeting は「挨拶」という意味です。

[実行する側のサンプルファイルを開く](./use_greeting.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`use_greeting.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python use_greeting.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 use_greeting.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
こんにちは たろう
```

## このコードの読み方

`def make_greeting(name):` は、挨拶を作る処理を `make_greeting` という名前で呼び出せるようにします。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。処理を書くときは、下の行の先頭に半角の空白4つを入れてください。行頭の空白でまとまりを示す書き方を **インデント** と呼びます。

`name` は呼び出す側で指定した名前を使うための名前で、このような名前を **変数** と呼びます。引用符で囲んで書く文字の並びを **文字列** と呼びます。文字列同士の `+` は文字列をつなぎ、`return` はその結果を呼び出した側へ返します。

`import greeting_tools` は、同じフォルダの `greeting_tools.py` のコードを読み込み、その中の処理を使えるようにします。`import` の後ろに名前を書くときは、`.py` を付けないでください。このように読み込んで使うPythonファイルを **モジュール** と呼びます。

`greeting_tools.make_greeting("たろう")` は、ファイルの名前と処理の名前を `.` でつないで指定しています。返された「こんにちは たろう」を `print(...)` がターミナルへ表示します。2つのファイルを同じフォルダへ保存してください。実行するファイルは `use_greeting.py` です。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

別のファイルにまとめた挨拶を変えてください。行頭の空白4つも残してください。

VS Codeで `greeting_tools.py` を開き、**5行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
return "こんにちは "
```

対象の行と、その直上の処理コメントを、次のように置き換えてください。

変更前：

```python
    # 「こんにちは 」と name をつないだ文字列を返す
    return "こんにちは " + name
```

変更後：

```python
    # 「おはよう 」と name をつないだ文字列を返す
    return "おはよう " + name
```

## 保存してもう一度実行する

VS Codeで変更した `greeting_tools.py` を保存してください。実行するファイルは `use_greeting.py` です。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python use_greeting.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 use_greeting.py
```

同じターミナルに次の結果が表示されます。

```text
おはよう たろう
```
