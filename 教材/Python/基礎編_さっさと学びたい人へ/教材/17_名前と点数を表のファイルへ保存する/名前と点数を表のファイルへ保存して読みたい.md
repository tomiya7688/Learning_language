# 名前と点数を表のファイルへ保存して読みたい

名前と点数を保存したあと、表計算ソフトで開いたり、自分のプログラムで点数を計算したりしたいとします。文章のままでは、どこが名前でどこが点数かを読み取る決まりがありません。

> **「名前の列と点数の列がある表として残したい！」**

この例は、たろうの80点を、2列のあるCSVという形式のファイルへ保存し、読み直します。CSVは、表の各行を記録する形式です。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../環境構築/環境構築ガイド.md)

この例は練習用の `purpose_scores.csv` を作り、同じ名前のファイルがあれば中身を書き直します。自分のメモなどと分けるため、新しい練習用フォルダを作り、その中へサンプルを保存して実行してください。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`save_read_csv.py` の 1〜26行](./save_read_csv.py#L1-L26)。

```python
# CSVを読み書きするための csv の処理を使えるようにする
import csv

# rows は「複数の行」という意味
# rows に見出しの行と、たろうの80点を表す行をまとめた一覧を入れる
rows = [["名前", "点数"], ["たろう", 80]]

# file は「ファイル」という意味
# purpose_scores.csv をUTF-8で書き込み用に開き、file という名前で使う
with open("purpose_scores.csv", "w", encoding="utf-8", newline="") as file:
    # writer は「書き込むもの」という意味
    # writer に file へCSVの行を書くためのものを入れる
    writer = csv.writer(file)
    # writer を使い、rows の各行を file へ書き込む
    writer.writerows(rows)

# purpose_scores.csv をUTF-8で読み込み用に開き、file という名前で使う
with open("purpose_scores.csv", "r", encoding="utf-8", newline="") as file:
    # reader は「読み込むもの」という意味
    # reader に file からCSVの行を読むためのものを入れる
    reader = csv.reader(file)
    # row は「1行」という意味
    # row に reader から読んだ行を1つずつ入れ、下の行を実行する
    for row in reader:
        # row の1列目と2列目を表示する
        print(row[0], row[1])
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `save_read_csv.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

save は「保存する」、read は「読む」、CSVは表のデータを保存するファイルの書き方の名前です。`.py` はPythonのコードを書いたファイルの末尾に付けます。保存先の `purpose_scores.csv` は、この例で使う点数のファイル名です。purpose は「目的」、scores は「複数の点数」という意味です。

[サンプルファイルを開く](./save_read_csv.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`save_read_csv.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python save_read_csv.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 save_read_csv.py
```

## このコードの読み方

表の1行をカンマで区切って記録する書き方を **CSV** と呼びます。`import csv` は、Pythonに最初から用意されている読み書きの処理を使えるようにします。追加のインストールは必要ありません。

`rows` の `[]` は一覧を作る書き方で、このような一覧を **リスト** と呼びます。今回は1行分のリストを2つ、その外側のリストに入れています。`rows` のように値を使うための名前を **変数** と呼びます。引用符で囲んだ値は **文字列**（文字の並び）、`80` は数値です。

`open(..., "w", ...)` はファイルを新しく書き込み、同じ名前のファイルがあれば中身を書き直します。`"r"` は読み込みです。`encoding="utf-8"` は日本語の記録方法、`newline=""` はCSVの機能で改行を扱うための指定です。`with ... as file:` の下でファイルを使い、処理が終わると自動的に閉じます。

このプログラムは `csv.writer(file)` で行を書くためのものを作り、`writer.writerows(rows)` で一覧の各行を書きます。`csv.reader(file)` で行を読むためのものを作り、`for row in reader:` で1行ずつ使います。`row[0]` が1列目、`row[1]` が2列目です。位置を表す番号は0から始まります。読み込んだ点数の `80` も文字列になるので、計算に使う場合は `int(row[1])` で整数へ変換してください。

`print(...)` は値をターミナルに表示します。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。行頭の空白でまとまりを示す書き方を **インデント** と呼び、`with` の中は空白4つ、さらに `for` の中は8つです。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

保存する名前と点数を、さくら・95点へ変えてください。

VS Codeで `save_read_csv.py` を開き、**6行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
rows =
```

[`save_read_csv.py` の5〜6行](./save_read_csv.py#L5-L6)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`save_read_csv.py` の 5〜6行](./save_read_csv.py#L5-L6)。

```python
# rows に見出しの行と、たろうの80点を表す行をまとめた一覧を入れる
rows = [["名前", "点数"], ["たろう", 80]]
```

変更後：

変更する場所：[`save_read_csv.py` の 6行](./save_read_csv.py#L6-L6)。

```python
# rows に見出しの行と、さくらの95点を表す行をまとめた一覧を入れる
rows = [["名前", "点数"], ["さくら", 95]]
```
