# 好きなメッセージを画面に表示したい

プログラムを動かしても、画面に何も出なければ、動いたのか分かりません。

> **「動いたなら、何か表示して！」**

この例は、ターミナルに「おはよう世界！」と表示します。同じ書き方で、入力を促す案内や計算の答えも表示できます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# 「おはよう世界！」と表示する
print("おはよう世界！")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `show_message.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

show は「表示する」、message は「メッセージ」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./show_message.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`show_message.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python show_message.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 show_message.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
おはよう世界！
```

## このコードの読み方

`print(...)` は、`()` の中で指定した内容をターミナルに表示します。この1行は「おはよう世界！という文字を画面に表示する」という意味です。

`"おはよう世界！"` のように、引用符で囲んで書いた文字の並びを **文字列** と呼びます。引用符自体は表示されません。`print` と `()` はそのままにして、引用符の中を変えると表示内容を変えられます。

このように、名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。ここでは、表示する処理の名前が `print` です。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

引用符の中を「Pythonの勉強を始めます」に変えてください。

VS Codeで `show_message.py` を開き、**2行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
print(
```

対象の行と、その直上の処理コメントを、次のように置き換えてください。

変更前：

```python
# 「おはよう世界！」と表示する
print("おはよう世界！")
```

変更後：

```python
# 「Pythonの勉強を始めます」と表示する
print("Pythonの勉強を始めます")
```

## 保存してもう一度実行する

VS Codeで `show_message.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python show_message.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 show_message.py
```

同じターミナルに次の結果が表示されます。

```text
Pythonの勉強を始めます
```
