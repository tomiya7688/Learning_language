# 1人分の名前と点数をまとめて扱いたい

「たろう、80」と情報を並べておくだけでは、名前と点数のどちらを使うにも、並び順を覚えておく必要があります。

> **「番号じゃなくて、名前や点数を指定して取り出したい！」**

このプログラムは、たろうの名前と80という点数を、項目名と組にして1人分の情報へまとめます。項目名を指定して、それぞれの値を表示します。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`show_student.py` の 1〜6行](./show_student.py#L1-L6)。

```python
# student は「生徒」という意味
# student に名前が「たろう」、点数が80の情報を入れる
student = {"名前": "たろう", "点数": 80}

# student の「名前」と「点数」を表示する
print(student["名前"], student["点数"])
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `show_student.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

show は「表示する」、student は「生徒」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./show_student.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`show_student.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python show_student.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 show_student.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
たろう 80
```

## このコードの読み方

`{"名前": "たろう", "点数": 80}` のように、項目と値を `:` で組にして `{}` の中へ並べるものを **辞書** と呼びます。ここでは項目が「名前」と「点数」、対応する値が「たろう」と `80` です。

`student = ...` は、その情報に `student` という名前を付けます。あとで値を使うための名前を **変数** と呼びます。`student["点数"]` は、その情報の「点数」という項目に対応する値を取り出す指定です。

引用符で囲んで書く文字の並びを **文字列** と呼びます。名前は文字列、点数の `80` は計算に使える数値として書いています。辞書にない項目名を指定するとエラーで終了します。

`print(...)` は指定した値をターミナルに表示します。カンマで区切った内容の間には空白が入ります。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

名前と点数を、さくら・95点へ変えてください。

VS Codeで `show_student.py` を開き、**3行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
student =
```

[`show_student.py` の2〜3行](./show_student.py#L2-L3)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`show_student.py` の 2〜3行](./show_student.py#L2-L3)。

```python
# student に名前が「たろう」、点数が80の情報を入れる
student = {"名前": "たろう", "点数": 80}
```

変更後：

変更する場所：[`show_student.py` の 3行](./show_student.py#L3-L3)。

```python
# student に名前が「さくら」、点数が95の情報を入れる
student = {"名前": "さくら", "点数": 95}
```

## 保存してもう一度実行する

VS Codeで `show_student.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python show_student.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 show_student.py
```

同じターミナルに次の結果が表示されます。

```text
さくら 95
```
