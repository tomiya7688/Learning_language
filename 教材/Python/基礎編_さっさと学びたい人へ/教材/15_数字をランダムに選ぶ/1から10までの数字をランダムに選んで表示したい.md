# 1から10までの数字をランダムに選んで表示したい

このプログラムは、1から10までの整数を1つ選び、表示します。くじやサイコロのように、候補の中から数字を選ぶときに使えます。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

保存するフォルダを1つ選び、このページではその場所を「練習用フォルダ」と呼びます。

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

```python
# random は「無作為の」という意味
# Pythonに用意されている random の処理を使えるようにする
import random

# number は「数字」という意味
# number に1から10までの整数からランダムに選んだ値を入れる
number = random.randint(1, 10)
# 「出た数字:」と number を表示する
print("出た数字:", number)
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、練習用フォルダに `choose_number.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

choose は「選ぶ」、number は「数字」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./choose_number.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`choose_number.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python choose_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 choose_number.py
```

## 実行結果

次は表示例です。実際には1から10までのいずれかが表示されます。同じ数字が続けて出ることもあります。

```text
出た数字: 4
```

## このコードの読み方

`import random` は、Pythonに最初から用意されている `random` というまとまりを使えるようにします。このような機能の集まりを **標準ライブラリ** と呼びます。追加のインストールは必要ありません。

`random.randint(1, 10)` は、1と10を含む範囲から整数を1つ選びます。`number = ...` は、その値に `number` という名前を付けます。あとで値を使うための名前を **変数** と呼びます。

`print(...)` は指定した内容をターミナルに表示します。引用符で囲んで書く文字の並びを **文字列** と呼びます。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。ここでは `randint` が数字を選ぶ処理の名前で、`random.` を付けて指定しています。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

サイコロの目と同じ1から6までの範囲に変えてください。

VS Codeで `choose_number.py` を開き、**7行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
random.randint(
```

対象の行と、その直上の処理コメントを、次のように置き換えてください。

変更前：

```python
# number に1から10までの整数からランダムに選んだ値を入れる
number = random.randint(1, 10)
```

変更後：

```python
# number に1から6までの整数からランダムに選んだ値を入れる
number = random.randint(1, 6)
```

## 保存してもう一度実行する

VS Codeで `choose_number.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python choose_number.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 choose_number.py
```

次も表示例です。1から6までのいずれかが表示され、7以上は表示されなくなります。

```text
出た数字: 3
```
