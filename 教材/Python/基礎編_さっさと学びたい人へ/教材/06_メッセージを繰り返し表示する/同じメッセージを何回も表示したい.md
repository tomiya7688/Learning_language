# 同じメッセージを何回も表示したい

「こんにちは」を3回表示するために、同じコードを3行書いたとします。10回に変えたいとき、さらに7行書き足すのは手間です。

> **「同じ行を増やすんじゃなくて、回数だけ変えたい！」**

この例は、表示する処理を1つにして、繰り返す回数を決めます。最初は3回表示するコードです。

PythonとVS Codeをまだ使える状態にしていない場合は、先に準備してください。

[進む：Pythonを書いて動かす準備をする](../../../基礎編_ゆっくり学びたい人へ/教材/01_環境構築/環境構築ガイド.md)

## コードを書く・保存する

VS Codeで新しいテキストファイルを開いてください（Windows / Linuxは Ctrl + N、macOSは Command + N）。次のコード全体をそのファイルへコピーしてください。

このコードの元ファイル：[`repeat_message.py` の 1〜5行](./repeat_message.py#L1-L5)。

```python
# count は「何回目かを数える値」という意味
# count に0、1、2を順に入れ、そのたびに下の行を実行する
for count in range(3):
    # 「こんにちは」と表示する
    print("こんにちは")
```

Windows / Linuxは Ctrl + S、macOSは Command + S を押し、自分で選んだフォルダに `repeat_message.py` という名前で保存してください。ファイル名の最後は `.py` にしてください。

repeat は「繰り返す」、message は「メッセージ」という意味です。 `.py` はPythonのコードを書いたファイルの末尾に付けます。

[サンプルファイルを開く](./repeat_message.py)

## 保存したファイルを実行する

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

### 保存先フォルダのパスをコピーする

`repeat_message.py` を保存したフォルダの場所を、次の操作でコピーしてください。

- Windows：エクスプローラーで保存先フォルダを開き、上部のアドレス欄をクリックしてください。表示されたフォルダのパス全体を選び、Ctrl + C を押してください。
- macOS：Finderで保存先フォルダを選択し、Option + Command + C を押して、そのフォルダのパスをコピーしてください。ファイルではなくフォルダを選んでください。
- Linux（GNOMEの「ファイル」を使う場合）：保存先フォルダを開き、Ctrl + L で場所の入力欄を表示して、フォルダのパスを Ctrl + C でコピーしてください。

### ターミナルを保存先フォルダへ移動する

VS Codeのターミナルを開き、次の形で入力してください。引用符の中は、上の操作でコピーした**フォルダのパス**に置き換えてください。Windowsは Ctrl + V、macOSは Command + V、Linuxは Ctrl + Shift + V で貼り付けてください。入力し終えたら Enter キーを押してください。

```text
cd "コピーした保存先フォルダのパス"
```

`cd` は、ターミナルで現在使っているフォルダを変える操作です。`PS C:\Users\...>` など、すでに表示されている文字は入力しないでください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python repeat_message.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 repeat_message.py
```

## 実行結果

実行すると、同じターミナルに次の結果が表示されます。

```text
こんにちは
こんにちは
こんにちは
```

## このコードの読み方

`for count in range(3):` は、`count` に `0`、`1`、`2` を順に対応させ、そのたびに下の右にずらした処理を実行します。`range(3)` は0から始まり、3の手前までの整数を順に使う指定です。この例の `3` は、3回表示するための指定です。

`count` は、その回の値を使うための名前です。このような名前を **変数** と呼びます。この例の表示内容には `count` を使わないため、毎回同じメッセージになります。

行頭の空白で、どの処理を繰り返すかを示します。この書き方を **インデント** と呼びます。表示の行には半角の空白を4つ入れてください。`for` の行末の `:` も必要です。

`print(...)` は、`()` の中で指定した内容をターミナルに表示します。引用符で囲んで書いた文字の並びを **文字列** と呼びます。名前の後ろに `()` を付けて呼び出す処理を **関数** と呼びます。

コードの `#` から行末までに書いた説明を **コメント** と呼びます。コメントは実行されません。

## どこを変えるか

表示する回数を3回から5回に変えてください。

VS Codeで `repeat_message.py` を開き、**3行目**を探してください。行番号は、最初のコードをコメントと空行も含めてそのまま保存した場合の番号です。

Windows / Linuxは Ctrl + F、macOSは Command + F を押してください。検索欄に次の文字を入力して、対象の行を探してください。

```text
range(3)
```

[`repeat_message.py` の2〜3行](./repeat_message.py#L2-L3)のコードを、次の内容に置き換えてください。

変更前：

このコードの元ファイル：[`repeat_message.py` の 2〜3行](./repeat_message.py#L2-L3)。

```python
# count に0、1、2を順に入れ、そのたびに下の行を実行する
for count in range(3):
```

変更後：

変更する場所：[`repeat_message.py` の 3行](./repeat_message.py#L3-L3)。

```python
# count に0、1、2、3、4を順に入れ、そのたびに下の行を実行する
for count in range(5):
```

## 保存してもう一度実行する

VS Codeで `repeat_message.py` を保存してください。Windows / Linuxは Ctrl + S、macOSは Command + S を押してください。

最初の実行と同じターミナルを使えます。

コマンドは、コードを書いた欄ではなく、VS Codeのターミナルへ入力してください。ターミナルは、文字で操作を入力し、プログラムの結果を見る場所です。表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んでください。

保存先フォルダへ移動済みなら、次の実行コマンドへ進んでください。別のフォルダに移動した場合は、最初の実行の手順でコピーした保存先フォルダのパスを使い、ターミナルへ `cd "コピーした保存先フォルダのパス"` と入力して Enter キーを押してください。

### Windows

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python repeat_message.py
```

### macOS / Linux

1. VS Codeのターミナルを開き、下のコマンドを入力してください。
2. Enter キーを押してください。

```text
python3 repeat_message.py
```

同じターミナルに次の結果が表示されます。

```text
こんにちは
こんにちは
こんにちは
こんにちは
こんにちは
```
