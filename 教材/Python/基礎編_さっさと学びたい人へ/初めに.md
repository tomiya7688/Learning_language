# 基礎編：さっさと学びたい人へ

> **「説明だけ読んでいても、何が作れるのかイメージが湧かない！」**

電卓・シューティングゲーム・ブラウザアプリから、作りたいものを選んでください。公開中のサンプルを先に動かして、そのコードを読んだり変更したりしてみてください。

## ここから始める

[進む：画面と機能を見て、作りたい完成品を選ぶ](./目次.md)

目次の上に3つのルートを並べています。

- **関数電卓**：数字・小数点・計算記号が一つの盤面に並び、四則演算と、角度から高さや横の長さの割合を求めるsin・cosの計算ができる電卓です。小数の答えは有効数字を最大12桁まで残して表示します。有効数字は、最初に現れる0以外の数字から数えた桁です。
- **シューティングゲーム**：宇宙船を動かして弾を撃ち、敵とボスを倒す完成ゲームを動かせます。タイトル・ゲームオーバー・クリアの画面もあります。
- **ブラウザアプリ**：ブラウザで名前を入力し、その名前で挨拶する完成サンプルを動かせます。

PythonとVS Codeをまだ使えない場合は、先に準備してください。準備後は、目次で選んだ完成品へ進んでください。

[進む：Pythonを書いて動かす準備をする](./教材/環境構築/環境構築ガイド.md)

作る途中で表示・計算・ファイルの読み書きなどが必要になったら、目次の下にある「やりたい処理から探す」を使えます。
