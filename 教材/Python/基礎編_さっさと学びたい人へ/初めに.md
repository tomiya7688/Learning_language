# 基礎編：さっさと学びたい人へ

> **「文法の勉強からじゃなくて、完成したものを動かして中身を知りたい！」**

このコースでは、**最初から完成しているプログラム**を選びます。実際に保存して動かし、完成コードを先頭から読んで、出てきたPythonの書き方をその場で覚えます。コードや数字を変更する練習も、選んだ完成品の中で行います。

## ここから始める

[進む：完成品を見て選ぶ](./目次.md)

- **関数電卓**：四則演算・小数点・sin・cosが使える電卓を動かし、`app.py` から `calculator.py` の最後まで全9章で読みます。
- **シューティングゲーム**：宇宙船を動かし、敵とボスを倒す完成ゲームです。完成コードを先頭から読む教材は継続して制作中です。
- **ブラウザアプリ**：Streamlitで作った完成アプリを動かし、ブラウザの入力欄と表示の仕組みを読みます。
- **Webから天気を取得する**：RequestsとWeb APIで気温・湿度を取得し、JSONを読んでターミナルへ表示するプログラムです。

PythonとVS Codeをまだ使えない場合は、[このコースの準備手順](./教材/環境構築/環境構築ガイド.md)を読んでください。準備が済んだら、選んだ完成品へ戻ってください。

**「ゆっくり学びたい人へ」を先に終える必要はありません。** 完成コードを読んで新しい言葉や書き方に出会ったら、その完成品のページで説明します。
