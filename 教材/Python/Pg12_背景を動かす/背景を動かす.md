# Pg12. pygame「背景を動かす」

Pg11で、ボス戦まで遊べるようになりました。

でも画面を見てみると、

> **「ずっと真っ暗な宇宙空間、進んでる感じせんやん！！！」**

プレイヤーも敵も動いています。

でも背景がずっと同じなので、画面全体としては止まって見えます。

今回は、星を下へ流して、

> **前へ進んでいるように見える背景**

を作ります。

ゲームのルールは変えません。

**見た目だけ変えます。**

---

## Pg12-1. 今回作るもの

[scrolling_background.py](./scrolling_background.py) を開いてください。

`scrolling` は「流れる」「スクロールする」という意味です。

今回は、

```text
星をいくつか置く
↓
毎フレーム下へ動かす
↓
画面下へ出る
↓
上へ戻す
↓
また下へ流れる
```

という背景を作ります。

---

## Pg12-2. 星の場所を用意する

まず、

```python
background_stars = [
    [40, 30],
    [120, 90],
    [210, 40],
    ...
]
```

とします。

1個の星は、

```python
[x座標, y座標]
```

です。

たとえば、

```python
[40, 30]
```

なら、

```text
x座標 40
y座標 30
```

の場所にある星です。

変数名も `background_stars` として、

> **背景に使う星の一覧**

だと分かるようにしています。

---

## Pg12-3. 背景の速さを決める

```python
background_speed = 2
```

を用意します。

これは、

> **1フレームで星を何px動かすか**

です。

---

## Pg12-4. 毎フレーム下へ動かす

ゲームループの中で、

```python
for background_star in background_stars:
    background_star[1] = background_star[1] + background_speed
```

とします。

`background_star[1]` はy座標です。

yを増やすので、星は下へ動きます。

---

## Pg12-5. そのままだと全部いなくなる

星をずっと下へ動かすだけだと、

```text
下へ進む
↓
画面の外へ出る
↓
戻ってこない
↓
そのうち星が全部消える
```

となります。

> **「背景なくなったんだけど！！！」**

なので、画面下まで来た星を上へ戻します。

---

## Pg12-6. 下へ出たら上へ戻す

```python
if background_star[1] > 480:
    background_star[1] = 0
```

とします。

画面の高さは480です。

なので、

> **y座標が480を超えたら画面の下へ出た**

と判断できます。

そこでy座標を0へ戻します。

```text
下へ流れる
↓
画面下へ消える
↓
画面上へ戻る
↓
また下へ流れる
```

これを繰り返すので、背景がずっと流れ続けます。

---

## Pg12-7. 星を描く

背景を塗ったあとに、

```python
for background_star in background_stars:
    pygame.draw.circle(
        screen,
        (180, 180, 220),
        (background_star[0], background_star[1]),
        2
    )
```

で星を描きます。

今回は半径2pxの小さい丸です。

まだ画像素材は使いません。

---

## Pg12-8. 背景は先に描く

描画順も大事です。

```text
背景色
↓
星
↓
プレイヤー
↓
弾
↓
敵
↓
ボス
```

の順に描きます。

もし星を最後に描くと、プレイヤーや敵の上に星が乗ってしまいます。

> **背景なんだから後ろにいろ！！！**

ということで、背景は先に描きます。

---

## Pg12-9. プレイヤーを前へ動かしているわけではない

今回、プレイヤーを上へ移動させ続けているわけではありません。

動かしているのは背景の星です。

でも星が下へ流れると、

> **自分が前へ進んでいるように見える**

ようになります。

シューティングゲームでは、こういう見せ方をよく使えます。

---

## Pg12-10. ゲームルールは何も変えていない

今回追加したのは、

- 星の座標
- 星の速度
- 星を動かす処理
- 星を描く処理

だけです。

敵のHPも、

ボスのHPも、

弾の当たり判定も変えていません。

それでも見た目はかなり変わります。

> **ゲームっぽさは、ルールだけで決まるわけではありません。**

---

## Pg12-11. ここまでで覚えること

1. 背景用の座標もリストで持てる
2. y座標を増やすと下へ動く
3. 画面下へ出たら上へ戻せばループできる
4. 毎フレーム動かすとスクロールして見える
5. 背景はプレイヤーや敵より先に描く
6. ゲームルールを変えなくても見た目を大きく変えられる
