# Pg12. pygame「背景を動かす」

Pg11で、ボス戦まで遊べるようになりました。

でも画面を見てみると、

> **「ずっと真っ暗な宇宙空間、進んでる感じせんやん！！！」**

プレイヤーも敵も動いています。

でも背景がずっと同じなので、画面全体としては止まって見えます。

今回は、星を下へ流して、

> **前へ進んでいるように見える背景**

を作ります。

ゲームのルールは変えません。

**見た目だけ変えます。**

---

## Pg12-1. 今回作るもの

[scrolling_background.py](./scrolling_background.py) を開いてください。

`scrolling` は「流れる」「スクロールする」という意味です。

今回は、

```text
星をいくつか置く
↓
毎フレーム下へ動かす
↓
画面下へ出る
↓
上へ戻す
↓
また下へ流れる
```

という背景を作ります。

---

## Pg12-2. 星の場所を用意する

まず、

```python
background_stars = [
    [40, 30],
    [120, 90],
    [210, 40],
    ...
]
```

とします。

1個の星は、

```python
[x座標, y座標]
```

です。

たとえば、

```python
[40, 30]
```

なら、

```text
x座標 40
y座標 30
```

の場所にある星です。

変数名も `background_stars` として、

> **背景に使う星の一覧**

だと分かるようにしています。

---

## Pg12-3. 背景の速さを決める

```python
background_speed = 2
```

を用意します。

これは、

> **1フレームで星を何px動かすか**

です。

---

## Pg12-4. 毎フレーム下へ動かす

ゲームループの中で、

```python
for background_star in background_stars:
    background_star[1] = background_star[1] + background_speed
```

とします。

`background_star[1]` はy座標です。

yを増やすので、星は下へ動きます。

---

## Pg12-5. そのままだと全部いなくなる

星をずっと下へ動かすだけだと、

```text
下へ進む
↓
画面の外へ出る
↓
戻ってこない
↓
そのうち星が全部消える
```

となります。

> **「背景なくなったんだけど！！！」**

なので、画面下まで来た星を上へ戻します。

---

## Pg12-6. 下へ出たら上へ戻す

```python
if background_star[1] > 480:
    background_star[1] = 0
```

とします。

画面の高さは480です。

なので、

> **y座標が480を超えたら画面の下へ出た**

と判断できます。

そこでy座標を0へ戻します。

```text
下へ流れる
↓
画面下へ消える
↓
画面上へ戻る
↓
また下へ流れる
```

これを繰り返すので、背景がずっと流れ続けます。

---

## Pg12-7. 星を描く

背景色を塗ったあとに、星を丸として描きます。

```python
for background_star in background_stars:
    pygame.draw.circle(
        screen,
        (180, 180, 220),
        (background_star[0], background_star[1]),
        2
    )
```

`pygame.draw.circle()` は丸を描く関数です。

左から順に、

```text
screen
→ どの画面へ描くか

(180, 180, 220)
→ 何色で描くか

(background_star[0], background_star[1])
→ 丸の中心をどこにするか

2
→ 半径を何ピクセルにするか
```

を渡しています。

### `screen`

`screen` は、ゲームを描いている640×480の画面です。

星もプレイヤーも敵も、同じ `screen` へ順番に描いています。

### `(180, 180, 220)`

これは星の色です。順番は **赤・緑・青** です。

```text
赤 = 180
緑 = 180
青 = 220
```

それぞれ0〜255の整数で、青が少し強いので明るい青みのある色になります。

この180・180・220は**色の強さ**で、座標ではありません。

### `(background_star[0], background_star[1])`

`background_stars` は背景に使う星の一覧で、`background_star` はその中から今描いている星1個です。

1個の星は `[x座標, y座標]` で持っているので、

```text
background_star[0]
→ 横の位置

background_star[1]
→ 縦の位置
```

です。

`draw.circle()` では、この2つを**丸の中心**として使います。

四角形の `draw.rect()` で使った左上位置とは違います。

### 最後の `2`

最後の `2` は丸の**半径**です。

半径は、丸の中心から端までの距離です。

```text
中心 ●── 2ピクセル ──端
```

なので今回は半径2ピクセルの小さい星を描きます。

`2` は直径ではなく、左上の位置でもありません。

### 星の色を変えてみる

`scrolling_background.py` の **280行目** を変更します。

VS Codeで **Ctrl + F**、macOSでは **Command + F** を押して、

```text
(180, 180, 220),
```

を検索してください。

変更前:

```python
(180, 180, 220),
```

変更後:

```python
(255, 255, 255),
```

保存して再実行し、星が白くなれば成功です。

確認したら `(180, 180, 220)` に戻しておいてください。

### 星を少し大きくしてみる

半径は **282行目** です。

Ctrl + F、macOSではCommand + Fで、

```text
pygame.draw.circle(
```

を検索すると、星を描く処理を見つけられます。

その中の最後の `2` を変更します。

変更前:

```python
2
```

変更後:

```python
4
```

保存して再実行し、星の半径が2ピクセルから4ピクセルへ大きくなれば成功です。

確認したら `2` に戻しておいてください。

この章の完成形では、元の色と半径2ピクセルを使います。

まだ画像素材は使いません。

---

## Pg12-8. 背景は先に描く

描画順も大事です。

```text
背景色
↓
星
↓
プレイヤー
↓
弾
↓
敵
↓
ボス
```

の順に描きます。

もし星を最後に描くと、プレイヤーや敵の上に星が乗ってしまいます。

> **背景なんだから後ろにいろ！！！**

ということで、背景は先に描きます。

---

## Pg12-9. プレイヤーを前へ動かしているわけではない

今回、プレイヤーを上へ移動させ続けているわけではありません。

動かしているのは背景の星です。

でも星が下へ流れると、

> **自分が前へ進んでいるように見える**

ようになります。

シューティングゲームでは、こういう見せ方をよく使えます。

---

## Pg12-10. ゲームルールは何も変えていない

今回追加したのは、

- 星の座標
- 星の速度
- 星を動かす処理
- 星を描く処理

だけです。

敵のHPも、

ボスのHPも、

弾の当たり判定も変えていません。

それでも見た目はかなり変わります。

> **ゲームっぽさは、ルールだけで決まるわけではありません。**

---

## Pg12-11. ここまでで覚えること

1. 背景用の座標もリストで持てる
2. y座標を増やすと下へ動く
3. 画面下へ出たら上へ戻せばループできる
4. 毎フレーム動かすとスクロールして見える
5. 背景はプレイヤーや敵より先に描く
6. ゲームルールを変えなくても見た目を大きく変えられる
