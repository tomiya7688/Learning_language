# Pg18. pygame「ゲームオーバー画面を作る」

Pg17までで、クリア画面とBACKボタンまで作りました。

でも負けたときはまだ、

> **「HP 0になった瞬間ゲーム閉じるんかい！！！」**

です。

今回は、プレイヤーのHPが0になったら

> **GAME OVER**

と分かる専用画面へ切り替えます。

---

## Pg18-1. 今回使うもの

[game_over_screen.py](./game_over_screen.py) を開いてください。

今回の中心はこれです。

```text
HPが0になる
↓
game_state を game_over にする
↓
ゲームオーバー画面を表示する
```

新しい考え方を大量に増やす章ではありません。

Pg16でやったクリア画面と、

> **条件が違うだけで、ほぼ同じことをやります。**

---

## Pg18-2. 今まではHPが0になったら終了していた

Pg17までは、

```python
if player_hp <= 0:
    running = False
```

でした。

つまり、

```text
HP 0
↓
ゲームループ終了
↓
ウィンドウ終了
```

です。

ゲームとしてはちょっと雑です。

> **「負けたのは分かったけど、せめて負けたって言ってくれ！」**

なので、今回は終了させません。

---

## Pg18-3. game_overという状態に切り替える

こうします。

```python
if player_hp <= 0:
    game_state = "game_over"
```

これで、

```text
HP 0
↓
game_state = "game_over"
```

になります。

Pg16の、

```python
game_state = "clear"
```

と同じ考え方です。

違うのは、

> **何が起きたらその状態になるか**

だけです。

---

## Pg18-4. クリアとゲームオーバーを並べて見る

クリアは、

```python
if boss_active and boss_hp <= 0:
    game_state = "clear"
```

ゲームオーバーは、

```python
if player_hp <= 0:
    game_state = "game_over"
```

です。

つまり、

```text
ボスHPが0 → clear
自分のHPが0 → game_over
```

です。

> **条件が違うだけで、画面を変える仕組みは同じ。**

ここが今回いちばん大事です。

---

## Pg18-5. 同時に起きたらどうする？

コードでは、

```python
if player_hp <= 0:
    game_state = "game_over"
elif boss_active and boss_hp <= 0:
    game_state = "clear"
```

としています。

`elif` にしているので、

同じフレームで両方の条件が成立しても、先に判定した方だけを使います。

今回は、

> **プレイヤーHPが0ならゲームオーバー**

を先にしています。

複雑な勝敗判定ルールにはまだ入りません。

---

## Pg18-6. ゲームオーバー中はゲームを止める

ゲームオーバーになったのに、

- 敵が動く
- 弾が飛ぶ
- 背景が流れる
- ボスが撃つ

を続けたら変です。

> **「負けた後ろでまだ戦争続いてるんだけど！！！」**

なので、

```python
if game_state == "game_over":
    ...
    continue
```

とします。

`continue` で、その周回の残りを飛ばします。

これでゲームオーバー中は、

> **専用画面だけを表示する**

状態になります。

---

## Pg18-7. GAME OVERを描く

まず背景を塗ります。

```python
screen.fill((28, 8, 12))
```

その上に、

```python
game_over_text = clear_font.render(
    "GAME OVER",
    True,
    (255, 90, 90)
)
```

で文字を作ります。

そして、

```python
game_over_text_rect = game_over_text.get_rect(
    center=(320, 220)
)
```

で中央へ置きます。

---

## Pg18-8. Pg16と比べる

Pg16のクリア画面は、

```python
if game_state == "clear":
    # クリア画面を描く
    ...
    continue
```

Pg18のゲームオーバー画面は、

```python
if game_state == "game_over":
    # ゲームオーバー画面を描く
    ...
    continue
```

です。

かなり似ています。

> **画面が増えたからって、毎回まったく新しい仕組みを覚えるわけじゃない。**

状態を変えて、

その状態に合う画面を描くだけです。

---

## Pg18-9. 今はまだ再開できない

GAME OVER は出るようになりました。

でも今は、

> **「で、もう一回やるには閉じて起動し直すん？」**

状態です。

ここではまだ直しません。

次のPg19で、

> **もう一度遊ぶ**

ための再開ボタンを作ります。

そのときは、画面を戻すだけではなく、

- HP
- 敵
- 弾
- ボス
- 各タイマー

なども初期状態へ戻す必要があります。
