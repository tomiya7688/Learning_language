# 2. Hello World

この章では、Python で最初のプログラムを作成して実行します。

最初の目標は、画面に次の文字を表示することです。

```text
Hello, World!
```

---

## 2-1. サンプルコード

`hello_world.py` を開いてください。

```python
# print() は、文字や数字などを画面に表示するための関数です。
# "Hello, World!" は表示したい文字列です。
print("Hello, World!")
```

実際のファイル:

- [hello_world.py](./hello_world.py)

---

## 2-2. 実行する

ターミナルで、このファイルがあるディレクトリへ移動します。

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

次のように表示されれば成功です。

```text
Hello, World!
```

---

## 2-3. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

```python
print("Hello, World!")
```

### `print`

`print` は、値を画面に表示するために Python が用意している **関数** です。

関数については後の章で詳しく説明します。

今は、

> `print` を使うと、画面に何かを表示できる

と覚えておけば十分です。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、`print` に渡したい値を書きます。

今回渡しているのは、

```python
"Hello, World!"
```

です。

### `"Hello, World!"`

`"Hello, World!"` は **文字列** です。

Python では、文字を値として扱いたいときに、基本的には `"` または `'` で囲みます。

たとえば、次の2つはどちらも文字列です。

```python
"Hello"
'Hello'
```

この教材では、特に理由がない限り `"` を使います。

---

## 2-4. コメント

サンプルコードの先頭には、次のような行があります。

```python
# print() は、文字や数字などを画面に表示するための関数です。
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

```python
# この行は実行されません。
print("Hello, World!")
```

と書いても、表示されるのは次の1行だけです。

```text
Hello, World!
```

このリポジトリでは、サンプルコードを初めて読む人でも処理を追いやすいようにコメントを付けています。

## 2-5. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

```

実行結果:

```

---

## 2-6. よくある間違い

### 引用符を付け忘れる

次のコードは正しくありません。

```python
print(Hello, World!)
```

`Hello, World!` を文字として扱いたいので、引用符で囲む必要があります。

正しくは、

```python
print("Hello, World!")
```

です。

### 丸括弧を閉じ忘れる

次のコードも正しくありません。

```python
print("Hello, World!"
```

開いた `(` に対応する `)` が必要です。

### 全角の記号を使う

日本語入力のまま、次のような全角記号を入力するとエラーになることがあります。

```text
print（"Hello, World!"）
```

プログラムの記号は基本的に半角で入力します。

正しくは、

```python
print("Hello, World!")
```

です。
