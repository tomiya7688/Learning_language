# Pg14. pygame「同梱キャラクター素材へ差し替える」

Pg13で背景は画像になりました。

でも、

> **「背景だけちゃんとしてるのに自機と敵まだ図形なん？？？」**

となります。

今回は、

- プレイヤー
- 通常敵
- ボス

を同梱PNGへ差し替えます。

弾は図形のままです。

そして大事なのは、

> **見た目を変えても、移動・攻撃・当たり判定の仕組みはそのまま使える**

ということです。

---

## Pg14-1. 今回使うもの

[character_sprites.py](./character_sprites.py) を開いてください。

同梱素材は、

- [player_ship.png](./assets/player_ship.png)
- [enemy_ship.png](./assets/enemy_ship.png)
- [boss_ship.png](./assets/boss_ship.png)
- [space_background.png](./assets/space_background.png)

です。

すべてこの教材用に作成したオリジナル素材です。

---

## Pg14-2. 透明PNGを読み込む

キャラクター画像は背景が透明です。

なので、

```python
player_image = pygame.image.load(
    str(assets_path / "player_ship.png")
).convert_alpha()
```

のように読み込みます。

Pg13の背景では `convert()` を使いました。

今回は透明部分があるので、

> **透明情報も残すために `convert_alpha()`**

を使います。

---

## Pg14-3. 3種類の画像を読み込む

```python
player_image = pygame.image.load(
    str(assets_path / "player_ship.png")
).convert_alpha()

enemy_image = pygame.image.load(
    str(assets_path / "enemy_ship.png")
).convert_alpha()

boss_image = pygame.image.load(
    str(assets_path / "boss_ship.png")
).convert_alpha()
```

これで、

- 自機
- 通常敵
- ボス

の画像をpygameで使えるようになります。

---

## Pg14-4. 座標は今までと同じ

プレイヤー座標は今まで通り、

```python
player_x
player_y
```

です。

敵も、

```python
enemy.x
enemy.y
```

のままです。

ボスも、

```python
boss_x
boss_y
```

のままです。

> **画像にしたから座標の考え方まで変わるわけではありません。**

---

## Pg14-5. 画像の中心を座標へ合わせる

プレイヤーは、

```python
player_image_rect = player_image.get_rect(
    center=(player_x, player_y)
)
```

とします。

`get_rect()` で画像と同じ大きさのRectを作り、

```python
center=(player_x, player_y)
```

で画像の中心を今までの座標へ合わせます。

---

## Pg14-6. blit()で描く

```python
screen.blit(
    player_image,
    player_image_rect
)
```

で自機画像を描きます。

通常敵も、

```python
enemy_image_rect = enemy_image.get_rect(
    center=(enemy.x, enemy.y)
)

screen.blit(
    enemy_image,
    enemy_image_rect
)
```

です。

ボスも同じです。

---

## Pg14-7. 当たり判定も画像サイズと揃える

今までのプレイヤー当たり判定は40×40でした。

今回のプレイヤー画像も40×40です。

なので、

```python
player_rect = player_image.get_rect(
    center=(player_x, player_y)
)
```

とすれば、

> **見た目と当たり判定を同じサイズにできる**

ようになります。

敵画像は40×30、ボス画像は120×60です。

これも今までの当たり判定サイズと揃えています。

---

## Pg14-8. 見た目だけ変えてゲームはそのまま

変えたのは主に描画部分です。

```text
今まで
pygame.draw.polygon()
pygame.draw.rect()

Pg14
pygame.image.load()
get_rect()
blit()
```

でも、

- プレイヤー移動
- 弾発射
- 敵の移動
- 敵ごとの発射タイマー
- ボス出現
- ボス攻撃
- HP
- ゲームクリア

はそのままです。

> **素材を変えることと、ゲームロジックを変えることは別です。**

---

## Pg14-9. 弾はまだ図形でいい

今回は、

- プレイヤー
- 敵
- ボス

だけ画像にしています。

弾は `pygame.draw.rect()` のままです。

全部を画像にしないとゲームが完成しないわけではありません。

必要なところだけ素材へ差し替えればOKです。

## Pg14-11. pygame基礎編の完成

ここまでで、

```text
画面を出す
↓
プレイヤーを出す
↓
動かす
↓
弾を撃つ
↓
敵を出す
↓
敵が撃つ
↓
敵を増やす
↓
敵ごとに発射タイミングを分ける
↓
ボスを出す
↓
ボスも撃つ
↓
強すぎるので調整する
↓
背景を動かす
↓
背景画像を使う
↓
キャラクター画像を使う
```

まで来ました。

> **ちゃんと1本のシューティングゲームになりました。**
