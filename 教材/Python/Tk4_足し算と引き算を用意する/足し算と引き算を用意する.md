# Tk4. 足し算と引き算を用意する

Tk3で、2つの数字を足せるようになりました。

でも、

> **「足し算しかできんやん！電卓名乗るな！！！」**

となります。

今回は、

```text
[ + ]
[ - ]
[ = ]
```

の3つのボタンを用意して、

> **どの計算をするか選んでから、=で計算する**

ようにします。

---

## Tk4-1. 今回作るもの

[add_subtract_calculator.py](./add_subtract_calculator.py) を開いてください。

今回は、

```text
1つ目の数字を入力
↓
2つ目の数字を入力
↓
+ か - を選ぶ
↓
= を押す
↓
答えを表示
```

という流れにします。

---

## Tk4-2. 何が新しいの？

Tk3では、

```python
answer = number1 + number2
```

と、計算方法が最初から決まっていました。

Tk4では、

```text
+
か
-
```

をあとから選びます。

つまり今度は、

> **「今どの計算を選んでいるか」を覚えておく必要があります。**

---

## Tk4-3. 選んだ演算子を覚える

最初に、

```python
selected_operator = "+"
```

とします。

`operator` は「演算子」という意味です。

今回なら、

```text
+
-
```

のことです。

`selected_operator` は、

> **今選ばれている演算子**

を覚える変数です。

最初は `+` にしておきます。

---

## Tk4-4. + ボタンを押したら + を覚える

```python
def select_addition():
    global selected_operator

    selected_operator = "+"
    operator_label.config(text="選択中: +")
```

とします。

`+` ボタンを押したら、

```python
selected_operator = "+"
```

にします。

画面の表示も、

```text
選択中: +
```

へ変えます。

---

## Tk4-5. - ボタンも同じ

```python
def select_subtraction():
    global selected_operator

    selected_operator = "-"
    operator_label.config(text="選択中: -")
```

です。

今度は、

```python
selected_operator = "-"
```

とします。

これで、

> **最後に押した方の演算子を覚えている**

状態になります。

---

## Tk4-6. なんで変数が必要なの？

もし演算子を覚えていなかったら、

```text
+ を押す
↓
数字を読む
↓
= を押す
↓
……で、さっき何押したっけ？
```

となります。

> **「覚えとけよ！！！」**

ということで、

```python
selected_operator
```

に覚えさせます。

GUIでは、

- どのモードを選んだか
- どのボタンを押したか
- 今何を選択しているか

のような、

> **今の状態**

を変数に持つことがよくあります。

---

## Tk4-7. = を押したときに計算する

`=` ボタンは、

```python
equals_button = tkinter.Button(
    window,
    text="=",
    command=calculate
)
```

です。

つまり、

> **= が押されたら calculate() を実行する**

という意味です。

---

## Tk4-8. 選ばれた演算子を見る

`calculate()` の中では、

```python
if selected_operator == "+":
    answer = number1 + number2
else:
    answer = number1 - number2
```

とします。

`+` が選ばれていれば足し算。

それ以外、今回は `-` しかないので引き算です。

---

## Tk4-9. ボタンごとに役割が違う

今回の3つのボタンは、

```text
+
→ 足し算を選ぶ

-
→ 引き算を選ぶ

=
→ 実際に計算する
```

という別々の役割があります。

> **ボタンを押した瞬間に全部計算する必要はありません。**

まず状態だけ変えるボタンも作れます。

---

## Tk4-10. global は何？

```python
global selected_operator
```

と書いています。

これは、

> **関数の外にある selected_operator を、この関数の中で書き換えます**

という意味です。

今回は、

```python
selected_operator = "+"
```

や、

```python
selected_operator = "-"
```

と書き換えたいので使っています。

今は、

> **関数の外の変数を書き換えるときに必要**

くらいで十分です。

大きなプログラムでは状態の持ち方を整理する方法もありますが、今はそこまで進みません。

---

## Tk4-11. 実際に試す

たとえば、

```text
1つ目: 10
2つ目: 3
```

とします。

`+` を押してから `=` を押すと、

```text
答え: 13.0
```

です。

`-` を押してから `=` を押すと、

```text
答え: 7.0
```

になります。

---

## Tk4-12. Tk3から何が増えた？

Tk3では、

```text
入力
↓
計算
↓
表示
```

でした。

Tk4では、

```text
入力
↓
計算方法を選ぶ
↓
その選択を覚える
↓
=
↓
計算
↓
表示
```

になりました。

> **アプリが少しずつ「状態を持つ」ようになってきました。**

---

## Tk4-13. ここまでで覚えること

1. GUIのボタンで演算子を選べる
2. `selected_operator` に今の選択を覚えられる
3. ボタンは「状態を変えるだけ」の役割にもできる
4. `=` ボタンで最後に計算を確定できる
5. 条件分岐で選ばれた演算子に応じて処理を変えられる
6. GUIでは「今どういう状態か」を変数で持つことがある

---

## Tk4-14. 次は2つだけじゃ足りない

今は、

```text
12 + 8
```

や、

```text
12 - 8
```

のように、

> **数字2個だけ**

です。

でも普通の電卓なら、

```text
1 + 2 - 3 + 4
```

みたいに続けて計算したくなります。

> **「毎回2個で終わるんかい！！！」**

次のTk5では、複数の数字と演算子をつないで計算できる形へ進めます。
