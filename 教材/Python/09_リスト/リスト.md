# 9. リスト

この章では、**複数の値をひとまとめにして扱う方法**を学びます。

今回作るのは、複数の点数をまとめて保存し、順番に表示して、合計や件数を確認する小さなプログラムです。

---

## 9-1. 今回作るもの

最初に3つの点数をまとめて保存します。

```python
scores = [80, 90, 70]
```

あとから点数を追加して、

```python
scores.append(100)
```

すべての点数を順番に表示します。

```text
80
90
70
100
```

さらに、

```text
件数: 4
合計: 340
```

も表示します。

---

## 9-2. なぜリストが必要なの？

3人分くらいなら、

```python
score1 = 80
score2 = 90
score3 = 70
```

でも何とかなります。

では、100人分ならどうでしょうか。

```python
score1 = 80
score2 = 90
score3 = 70
# ...
score99 = 85
score100 = 92
```

となります。

しかも101人目が増えたら、また変数を追加します。

> 「変数、何個作ればいいんだよ！」

となってきます。

そこで使うのが **リスト** です。

リストを使えば、

```python
scores = [80, 90, 70]
```

のように、複数の値を1つの変数にまとめられます。

---

## 9-3. サンプルコード

[score_list.py](./score_list.py) を開いてください。

`score` は「点数」、`list` は「一覧」という意味です。

```python
scores = [80, 90, 70]

scores.append(100)

print("最初の点数:", scores[0])
print("件数:", len(scores))

total = 0

for score in scores:
    print(score)
    total = total + score

print("合計:", total)
```

---

## 9-4. リストを作る

リストは、`[ ]` を使って作ります。

```python
scores = [80, 90, 70]
```

この場合、

```text
80
90
70
```

という3つの値を、`scores` という1つの変数へまとめています。

---

## 9-5. リストの中の1つ1つを「要素」と呼ぶ

リストの中に入っている値を **要素** と呼びます。

```python
scores = [80, 90, 70]
```

なら、

- `80`
- `90`
- `70`

がそれぞれ要素です。

今は、

> リスト = 複数の値を並べて入れる箱

くらいに考えておけば十分です。

---

## 9-6. 番号で値を取り出す

リストの中の値は、番号を使って取り出せます。

```python
print(scores[0])
```

実行結果:

```text
80
```

ここで注意するのは、最初の要素が `0` 番だということです。

```text
scores = [80, 90, 70]
          ↑   ↑   ↑
          0   1   2
```

この番号を **添字（インデックス）** と呼びます。

---

## 9-7. なぜ0から始まるの？

Pythonでは、リストの最初の要素を `0` 番として扱います。

最初は少し違和感があるかもしれません。

```python
scores[0]
```

は「1番目の値」です。

```python
scores[1]
```

は「2番目の値」です。

今は、

> Pythonの番号は0から始まることが多い

と覚えておけば十分です。

---

## 9-8. `append()` で追加する

リストの最後へ新しい値を追加するときは、`append()` を使います。

```python
scores.append(100)
```

もともと、

```python
[80, 90, 70]
```

だったリストが、

```python
[80, 90, 70, 100]
```

になります。

`append` は「付け加える」という意味です。

---

## 9-9. またドットが出てきた

Tkinterでも見た、

```text
A.B
```

という形がここでも出てきます。

```python
scores.append(100)
```

は、

> `scores` というリストが持っている `append` を使う

という意味です。

つまり、

```text
scores . append(100)
   ↑        ↑
リスト    追加する機能
```

です。

---

## 9-10. `len()` で個数を調べる

リストに何個の要素が入っているか調べるには、`len()` を使います。

```python
print(len(scores))
```

`scores` が、

```python
[80, 90, 70, 100]
```

なら、

```text
4
```

と表示されます。

`len` は length（長さ）から来ています。

---

## 9-11. `for` と組み合わせる

リストは `for` ととても相性が良いです。

```python
for score in scores:
    print(score)
```

と書くと、リストの要素を1つずつ取り出せます。

流れは、

```text
80 → score
90 → score
70 → score
100 → score
```

です。

そのたびに、

```python
print(score)
```

が実行されます。

---

## 9-12. リストがあると繰り返しが便利になる

リストがなければ、

```python
print(score1)
print(score2)
print(score3)
```

のように1つずつ書くことになります。

リストなら、

```python
for score in scores:
    print(score)
```

だけです。

データが3個でも100個でも、基本的な書き方は変わりません。

---

## 9-13. 合計を作る

今回のサンプルでは、

```python
total = 0

for score in scores:
    total = total + score
```

としています。

最初は、

```text
total = 0
```

です。

そこへ順番に、

```text
0 + 80 = 80
80 + 90 = 170
170 + 70 = 240
240 + 100 = 340
```

と足していきます。

最後に、

```text
340
```

が残ります。

---

## 9-14. 自分で値を変えてみる

たとえば、

```python
scores = [100, 50, 75]
```

に変えてみてください。

また、

```python
scores.append(60)
scores.append(95)
```

のように複数追加しても構いません。

`len()` の結果や合計が変わることを確認してみましょう。

---

## 9-15. 文字列も入れられる

リストには数字だけでなく、文字列も入れられます。

```python
names = ["たろう", "さくら", "けん"]
```

そして、

```python
for name in names:
    print(name)
```

と順番に表示できます。

---

## 9-16. GUIでもリストを使う

GUIでもリストはよく使います。

たとえば、

- 商品一覧
- ファイル一覧
- 選択肢の一覧
- ボタンの一覧
- 入力された履歴

などです。

つまりリストは、

> 同じ種類のデータを複数まとめて扱いたい

ときの基本になります。
