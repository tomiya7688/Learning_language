# Pg1. pygame「最初のゲーム画面」

この章では、**pygameでウィンドウを表示して、閉じる操作を受け取るところ**まで進みます。

今回作るのは、何も描かれていないゲーム画面です。

この章の本質はこれです。

> **「画面出しただけで終わるな！閉じるボタン押したかちゃんと見とけ！」**

ゲームでは、画面を出したあともずっと、

- キーが押されたか
- マウスが動いたか
- 閉じるボタンが押されたか
- 次の画面をどう描くか

を確認し続けます。

---

## Pg1-1. pygameって何？

pygameは、Pythonで2Dゲームや自由な描画をしやすくする外部ライブラリです。

tkinterのようにボタンや入力欄を並べるより、

> **自分で画面へ描いて、自分で入力を処理する**

方向に向いています。

---

## Pg1-2. 今回作るもの

[first_game_window.py](./first_game_window.py) を開いてください。

`first` は「最初の」、`game` は「ゲーム」、`window` は「ウィンドウ」という意味です。

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("最初のpygame")

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

pygame.quit()
```

実行すると、640×480のウィンドウが表示されます。

右上の閉じるボタンを押すと終了します。

## Pg1-3. まずpygameを入れる

pygameは標準ライブラリではないので、最初にインストールします。

Windows:

```text
python -m pip install pygame
```

macOS / Linux:

```text
python3 -m pip install pygame
```

これはPythonコードではなく、**ターミナルへ入力するコマンド**です。


## Pg1-6. ウィンドウを作る

```python
screen = pygame.display.set_mode((640, 480))
```

で画面を作ります。

```text
640
→ 横幅

480
→ 高さ
```

です。

`screen` には、これから描画するための画面が入ります。

## Pg1-7. タイトルを付ける

```python
pygame.display.set_caption("最初のpygame")
```

で、ウィンドウ上部のタイトルを設定できます。

---

## Pg1-8. なぜwhileが必要なの？

ここがpygameらしいところです。

```python
running = True

while running:
```

と書いて、画面が開いている間ずっと処理を繰り返します。

> **「一回見て終わりじゃゲームにならんやろ！」**

ゲームでは、画面が開いている間ずっと入力や状態を確認する必要があります。

この繰り返しを、よく **ゲームループ** と呼びます。

---

## Pg1-9. イベントを見る

```python
for event in pygame.event.get():
```

で、その時に起きた操作を順番に確認します。

たとえば、

- ウィンドウを閉じた
- キーを押した
- マウスを動かした
- マウスボタンを押した

などです。

---

## Pg1-10. 閉じるボタンを押したら

```python
if event.type == pygame.QUIT:
    running = False
```

は、

> 閉じる操作が来たら、ゲームループを終わらせる

という意味です。

`running` が `False` になると、

```python
while running:
```

の繰り返しが終わります。

---

## Pg1-11. 最後にpygameを終了する

```python
pygame.quit()
```

でpygameを終了します。

流れをまとめると、

```text
pygameを準備
↓
画面を作る
↓
ゲームループ開始
↓
イベントを見る
↓
閉じる操作が来たらループ終了
↓
pygame終了
```

です。

## Pg1-13. ウィンドウが固まるとき

イベント処理をしないまま長い処理を続けると、OSから「応答していない」ように見えることがあります。

pygameではゲームループの中で、

```python
pygame.event.get()
```

を使ってイベントを処理していくのが重要です。

---

## Pg1-14. tkinterとの違い

tkinterでは、

- Label
- Entry
- Button

のような部品を置いてGUIを作りました。

pygameは少し違います。

```text
tkinter
→ GUI部品を置く

pygame
→ 画面へ自分で描く
   入力も自分で処理する
```

という違いがあります。

そのため、ゲームや自由な描画に向いています。

---

## Pg1-15. 次にできること

ここまででは、まだ何も描いていません。

この先は、

- 背景色を変える

といった方向へ進めます。

まずは、

> **画面を出して、ループしながらイベントを見る**

というpygameの基本形が分かれば十分です。
