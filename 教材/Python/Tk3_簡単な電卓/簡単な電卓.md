# Tk3. 簡単な電卓

この章では、これまで学んだGUI部品とPythonの計算を組み合わせて、**2つの数字を足し算する電卓**を作ります。

今回の目標は、

> 入力する  
> ↓  
> ボタンを押す  
> ↓  
> 計算する  
> ↓  
> 結果を画面に表示する

という流れを完成させることです。

---

## Tk3-1. 今回作るもの

画面には、

- 1つ目の数字を入れる入力欄
- 2つ目の数字を入れる入力欄
- 「計算する」ボタン
- 答えを表示する場所

を作ります。

たとえば、

```text
1つ目: 12
2つ目: 8
```

と入力してボタンを押すと、

```text
答え: 20
```

と表示されます。

---

## Tk3-2. なぜこの章を作るの？

Tk1ではウィンドウを出しました。

Tk2では入力欄とボタンを置きました。

でも、部品を置くだけではアプリとしてできることはまだ少ないです。

たとえば電卓の見た目だけ作って、

```text
[ 12 ]
[  8 ]
[ 計算する ]
```

まで表示できても、ボタンを押して何も起きなかったら、

> 「それ電卓じゃなくて電卓の写真じゃん」

となってしまいます。

そこでこの章では、GUIの部品とPythonの計算処理をつなげます。

**見た目 + 入力 + 計算 + 結果表示**がそろうと、ようやく「使える小さなアプリ」になります。

---

## Tk3-3. サンプルコード

[simple_calculator.py](./simple_calculator.py) を開いてください。

`simple` は「簡単な」、`calculator` は「電卓」という意味です。

```python
import tkinter


def calculate():
    number1_text = number1_entry.get()
    number2_text = number2_entry.get()

    if number1_text == "" or number2_text == "":
        result_label.config(text="数字を2つ入力してください")
        return

    number1 = float(number1_text)
    number2 = float(number2_text)

    answer = number1 + number2

    result_label.config(text=f"答え: {answer}")


window = tkinter.Tk()
window.title("簡単な電卓")
window.geometry("400x260")

number1_label = tkinter.Label(window, text="1つ目の数字")
number1_label.pack()

number1_entry = tkinter.Entry(window)
number1_entry.pack()

number2_label = tkinter.Label(window, text="2つ目の数字")
number2_label.pack()

number2_entry = tkinter.Entry(window)
number2_entry.pack()

calculate_button = tkinter.Button(
    window,
    text="計算する",
    command=calculate
)
calculate_button.pack()

result_label = tkinter.Label(window, text="答え:")
result_label.pack()

window.mainloop()
```

---

## Tk3-4. Entryから取り出した値は文字

Tk2で使った `.get()` を今回も使います。

```python
number1_text = number1_entry.get()
number2_text = number2_entry.get()
```

ここで大切なのは、Entryから取り出した内容は**文字列**だということです。

たとえば画面に、

```text
12
```

と入力しても、Pythonでは最初、

```text
"12"
```

という文字として受け取ります。

---

## Tk3-5. 文字のまま足すとどうなる？

もし、

```python
answer = number1_text + number2_text
```

と書いて、

```text
12
8
```

を入力すると、結果は、

```text
128
```

になります。

足し算のつもりなのに、文字がつながってしまいます。

そこで、

```python
number1 = float(number1_text)
number2 = float(number2_text)
```

と書いて、計算できる数値へ変換します。

4章「数値と計算」で学んだ内容が、ここでそのまま使われています。

---

## Tk3-6. なぜ `float()` を使うの？

今回は `int()` ではなく `float()` を使っています。

`int()` なら整数だけを扱えます。

```text
10
25
100
```

一方、`float()` なら、

```text
10.5
3.14
0.5
```

のような小数も扱えます。

電卓らしく少し広く数字を扱えるように、今回は `float()` を使います。

---

## Tk3-7. 入力が空なら計算しない

次の部分を見てください。

```python
if number1_text == "" or number2_text == "":
    result_label.config(text="数字を2つ入力してください")
    return
```

入力欄が空の場合は、計算せず、

```text
数字を2つ入力してください
```

と表示します。

ここでは5章で学んだ**条件分岐**を使っています。

`or` は、

> どちらか一方でも条件に当てはまれば

という意味です。

---

## Tk3-8. `return` で途中で関数を終える

入力が空だった場合は、

```python
return
```

で関数をそこで終わらせています。

もしここで止めなければ、そのあと、

```python
float("")
```

を実行しようとしてエラーになります。

今回は、

> 入力が足りないなら、その先の計算へ進まない

ために `return` を使っています。

---

## Tk3-9. 実際に計算する

入力を数値へ変換したら、

```python
answer = number1 + number2
```

で足し算します。

ここは普通のPythonの計算と同じです。

GUIだから特別な計算方法になるわけではありません。

**GUIは入力と表示の方法が変わるだけで、計算そのものは今まで学んだPythonを使います。**

---

## Tk3-10. 計算結果を画面へ表示する

計算した結果は、

```python
result_label.config(text=f"答え: {answer}")
```

でLabelへ表示します。

Tk2で使った `config()` と同じです。

流れをまとめると、

```text
Entryから文字を取る
        ↓
float()で数値へ変換
        ↓
足し算する
        ↓
Labelを書き換える
```

となります。

---

## Tk3-11. ボタンを押したら計算する

ボタンは、

```python
calculate_button = tkinter.Button(
    window,
    text="計算する",
    command=calculate
)
```

と作っています。

`command=calculate` によって、

> 「計算する」ボタンが押されたら `calculate` 関数を実行する

という関係になります。

Tk2で学んだイベント駆動が、そのまま使われています。

---

## Tk3-12. ここまでの章が全部つながっている

この電卓には、これまで学んだ内容がいくつも入っています。

- 3章: 変数
- 4章: 数値変換と計算
- 5章: 条件分岐
- 7章: 関数
- Tk1: ウィンドウ
- Tk2: Label / Entry / Button / イベント

つまり、新しい文法を大量に覚えたのではありません。

**今まで覚えたものを組み合わせたら、電卓になった**ということです。

プログラムは、このように小さな知識を組み合わせて大きな機能を作っていきます。

## Tk3-13. 実行してみる

Windows:

```text
python simple_calculator.py
```

または、

```text
py simple_calculator.py
```

macOS / Linux:

```text
python3 simple_calculator.py
```

次のように試してください。

```text
12
8
```

結果:

```text
答え: 20.0
```

`float()` を使っているため、整数を入力しても `.0` が付くことがあります。

これは間違いではありません。

---

## Tk3-14. 掛け算へ変えてみる

次の部分を、

```python
answer = number1 + number2
```

から、

```python
answer = number1 * number2
```

へ変えると掛け算になります。

同じように、

```python
answer = number1 - number2
```

なら引き算、

```python
answer = number1 / number2
```

なら割り算です。

---

## Tk3-15. 四則演算ボタンを作るなら？

さらに発展させるなら、

```text
[ + ] [ - ] [ × ] [ ÷ ]
```

のように、計算ごとにボタンを分けることもできます。

その場合は、

- 足し算用の関数
- 引き算用の関数
- 掛け算用の関数
- 割り算用の関数

を作る方法もあります。

今は、まず1つのボタンで足し算ができれば十分です。

---

## Tk3-16. 数字以外を入れるとどうなる？

今のサンプルに、

```text
abc
```

のような文字を入力すると、`float()` で数値へ変換できないためエラーになります。

これは今の段階では問題ありません。

このような入力ミスを安全に処理する方法は、後の**例外処理**で学びます。

## Tk3-17. ここまでで覚えること

この章では、次のことが分かれば十分です。

1. Entryから取り出した値は最初は文字列
2. `float()` で計算できる数値へ変換できる
3. 条件分岐で入力不足を確認できる
4. 関数の中で計算処理を書ける
5. Buttonから関数を呼び出せる
6. `config()` で計算結果を画面へ表示できる
7. GUIでも、今まで学んだPythonの文法をそのまま組み合わせられる
8. `+`、`-`、`*`、`/` に変えれば他の四則演算へ発展できる

これで、tkinter基礎編として**入力 → 操作 → 処理 → 結果表示**まで一通り体験できました。
