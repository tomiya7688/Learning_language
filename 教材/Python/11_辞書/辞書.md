# 11. 辞書

この章では、**名前と値をセットにして管理する方法**を学びます。

今回作るのは、1人分のプロフィールを辞書にまとめて、名前や点数を取り出したり、あとから情報を追加・更新したりする小さなプログラムです。

---

## 11-1. 今回作るもの

最初に、1人分のデータをまとめます。

```python
student = {
    "name": "たろう",
    "score": 80
}
```

そして、

```python
print(student["name"])
print(student["score"])
```

と書くと、

```text
たろう
80
```

と表示できます。

さらに、

```python
student["class"] = "A"
student["score"] = 90
```

のように、あとから追加や更新もできます。

---

## 11-2. なぜ辞書が必要なの？

10章のリストでは、番号で値を取り出しました。

たとえば、

```python
student = ["たろう", 80, "A"]
```

とした場合、

```python
student[0]
student[1]
student[2]
```

で値を取り出せます。

でも、しばらくしてこのコードを見たとき、

> **「え、番号？しらんしらん、たろうだってたろう」**

となることがあります。

番号だけでは、その値が何を意味しているのか分かりにくいのです。

そこで使うのが **辞書** です。

```python
student = {
    "name": "たろう",
    "score": 80,
    "class": "A"
}
```

なら、

```python
student["name"]
student["score"]
student["class"]
```

のように、**意味のある名前で値を取り出せます。**

---

## 11-3. サンプルコード

[student_dictionary.py](./student_dictionary.py) を開いてください。

`student` は「生徒」、`dictionary` は「辞書」という意味です。

```python
student = {
    "name": "たろう",
    "score": 80
}

print("名前:", student["name"])
print("点数:", student["score"])

# 新しい情報を追加します。
student["class"] = "A"

# 既存の情報を更新します。
student["score"] = 90

print("更新後の点数:", student["score"])

# キーと値を順番に表示します。
for key, value in student.items():
    print(key, ":", value)
```

---

## 11-4. 辞書を作る

辞書は `{ }` を使って作ります。

```python
student = {
    "name": "たろう",
    "score": 80
}
```

この中では、

```text
"name"  → "たろう"
"score" → 80
```

というように、名前と値をセットにしています。

---

## 11-5. 辞書はそのまま日本語で読んでいい

たとえば、

```python
{
    "name": "たろう",
    "score": 80
}
```

を見たら、

> **「名前はたろうで、点数は80ね」**

くらいに読めば大丈夫です。

```text
"name": "たろう"
→ 名前はたろう

"score": 80
→ 点数は80
```

つまり辞書は、

> **項目名と、その中身をセットで並べている**

だけです。

記号を1文字ずつ難しく考えるより、まずは文章として読んだ方が分かりやすいです。

---

## 11-6. キーと値

辞書では、

```python
"name": "たろう"
```

の左側を **キー**、右側を **値** と呼びます。

```text
"name" : "たろう"
  ↑         ↑
キー       値
```

です。

`"score": 80` なら、

- キー: `"score"`
- 値: `80`

です。

---

## 11-7. キーを使って値を取り出す

辞書の値は、キーを指定して取り出します。

```python
print(student["name"])
```

実行結果:

```text
たろう
```

同じように、

```python
print(student["score"])
```

なら、

```text
80
```

と表示されます。

---

## 11-8. リストとの違い

リストは番号で取り出します。

```python
scores[0]
```

辞書は名前で取り出します。

```python
student["name"]
```

大まかには、

```text
リスト
→ 順番で管理したい

辞書
→ 名前を付けて管理したい
```

という使い分けです。

---

## 11-9. 新しい情報を追加する

辞書へ新しい情報を追加するには、

```python
student["class"] = "A"
```

と書きます。

これで、

```python
{
    "name": "たろう",
    "score": 80,
    "class": "A"
}
```

になります。

---

## 11-10. 既存の値を更新する

すでにあるキーへ新しい値を入れると、値を更新できます。

```python
student["score"] = 90
```

もともと `80` だった点数が `90` に変わります。

つまり、

```text
まだ無いキーに代入 → 追加
すでにあるキーに代入 → 更新
```

です。

---

## 11-11. キーが存在しないとどうなる？

たとえば、

```python
print(student["age"])
```

のように、存在しないキーを指定するとエラーになります。

今の段階では、

> 辞書は、存在するキーを指定して使う

と覚えておけば十分です。

後の例外処理や、より安全な取り出し方を学ぶと、このあたりも扱いやすくなります。

---

## 11-12. `for` と組み合わせる

辞書も `for` と組み合わせられます。

今回のサンプルでは、

```python
for key, value in student.items():
    print(key, ":", value)
```

としています。

実行結果は、

```text
name : たろう
score : 90
class : A
```

のようになります。

---

## 11-13. `.items()` とは

```python
student.items()
```

は、辞書の**キーと値をセットで取り出す**ために使います。

イメージは、

```text
"name"  と "たろう"
"score" と 90
"class" と "A"
```

です。

そして、

```python
for key, value in student.items():
```

で、それぞれを `key` と `value` に入れています。

---

## 11-14. またドットが出てきた

9章の `scores.append()` と同じように、

```python
student.items()
```

も、

> `student` が持っている `items` を使う

という意味です。

```text
student . items()
   ↑        ↑
 辞書     キーと値を取り出す機能
```

です。

---

## 11-15. 辞書の中にリストを入れることもできる

辞書の値には、数字や文字だけでなく、リストも入れられます。

```python
student = {
    "name": "たろう",
    "scores": [80, 90, 70]
}
```

この場合、

```python
print(student["scores"])
```

で、

```text
[80, 90, 70]
```

を取り出せます。

---

## 11-16. リストの中に辞書を入れることもできる

逆に、リストの中へ辞書を入れることもできます。

```python
students = [
    {"name": "たろう", "score": 80},
    {"name": "さくら", "score": 90}
]
```

この形は、複数人のデータを扱うときによく使われます。

```python
for student in students:
    print(student["name"], student["score"])
```

と書けば、

```text
たろう 80
さくら 90
```

と表示できます。

---

## 11-17. JSONにつながる形

辞書は、あとで扱う **JSON** ととてもよく似た形をしています。

たとえば、

```python
{
    "name": "たろう",
    "score": 80
}
```

という形は、JSONでもよく出てきます。

そのため、辞書を理解しておくと、Web APIや設定ファイルを扱うときにも役立ちます。

今は、

> 辞書は、名前付きのデータをまとめる基本

と覚えておけば十分です。

---

## 11-18. GUIでも辞書を使う

GUIでも辞書は使えます。

たとえば、

- ユーザー名と設定
- 商品名と価格
- ボタン名と処理
- 項目名と入力値

などをまとめたいときです。

リストが「順番のある複数データ」に向いているのに対して、辞書は「名前の付いたデータ」に向いています。

---

たとえば、

```python
student = {

```
