# Pg7. pygame「敵を増やす」

Pg6では、敵も撃ち返してくるようになりました。

でも最初に3体置いて、それを倒したら終わりです。

> **「3体置いただけじゃステージ感ないな！」**

今回は、時間が経つと敵が順番に増えていくようにします。

難しいステージ管理はまだやりません。

本質は、

> **一定時間ごとに敵を1体追加する**

だけです。

---

## Pg7-1. 今回作るもの

[enemy_waves.py](./enemy_waves.py) を開いてください。

`wave` は、ゲームでは「敵がまとまって出てくる一波」のような意味で使われます。

今回は、

```text
少し待つ
↓
敵が出る
↓
また少し待つ
↓
次の敵が出る
↓
何体か続けて出る
```

という簡単なウェーブを作ります。

---

## Pg7-2. 最初から全部置かない

Pg6では、最初から全部の敵を置いていました。

Pg7では、

```python
enemies = []
```

から始めます。

敵はあとから追加します。

---

## Pg7-3. 出現位置を先に決める

```python
spawn_positions_x = [
    120,
    320,
    520,
    220,
    420,
    100,
    540
]
```

と、敵を出したいx座標を並べておきます。

変数名も `spawn_positions_x` として、

> **「これはx座標の一覧です」**

と名前だけで分かるようにします。

`spawn_positions` だけでは、x座標なのか `[x, y]` の組なのか分かりません。

教材では短さより、読んだ瞬間に意味が分かる名前を優先します。

今は、

> **「次はどこから出す？」を順番に並べたもの**

くらいで構いません。

---

## Pg7-4. 何体目まで出したか覚える

```python
spawn_index = 0
```

を用意します。

これは、

> spawn_positions_xの何番目まで使ったか

を覚えるための数字です。

---

## Pg7-5. 出現タイマー

```python
spawn_interval = 90
spawn_timer = 0
```

とします。

ゲームループの中で、

```python
spawn_timer = spawn_timer + 1
```

と数えます。

90フレームたったら、新しい敵を出します。

60FPSなら約1.5秒ごとです。

---

## Pg7-6. 時間が来たら敵を追加

```python
if spawn_timer >= spawn_interval:
    if spawn_index < len(spawn_positions_x):
        enemies.append([
            spawn_positions_x[spawn_index],
            -20
        ])

        spawn_index = spawn_index + 1
        spawn_timer = 0
```

これで、時間が来るたびに敵が1体ずつ追加されます。

yを `-20` にしているので、画面の少し上から入ってきます。

---

## Pg7-7. `len()` は何？

```python
len(spawn_positions_x)
```

は、

> spawn_positions_xに何個入っている？

を調べます。

今回なら7個です。

```python
if spawn_index < len(spawn_positions_x):
```

としておけば、用意した出現位置を全部使い切ったあとに、存在しない次の番号を読もうとしません。

---

## Pg7-8. 敵が増えるだけでゲームっぽくなる

仕組みはかなり単純です。

```text
タイマーを進める
↓
時間が来た
↓
敵を1体追加
↓
次の位置へ進む
↓
また待つ
```

だけです。

でも、最初から全部並んでいるより、

> **敵が順番に現れる**

だけでかなりステージっぽくなります。

---

## Pg7-9. 敵弾も今いる敵だけが撃つ

Pg6と同じように、

```python
for enemy in enemies:
    enemy_bullets.append([
        enemy[0],
        enemy[1] + 20
    ])
```

としています。

つまり、

> **その時点で画面にいる敵だけが撃つ**

ことになります。

---

## Pg7-10. いきなり敵を出しすぎない

たとえば、

```python
spawn_interval = 10
```

にすると、一気に敵が出てきます。

> **「増やせとは言ったけど一斉に来いとは言ってない！」**

今回は `90` にして、順番に処理できるくらいの間隔にします。

---

## Pg7-11. 敵が下まで行ったら消す

```python
enemies = [
    enemy
    for enemy in enemies
    if enemy[1] < 520
]
```

これで、倒されずに画面下へ抜けた敵も消します。

---

## Pg7-12. これが最小のウェーブ

本格的なゲームでは、

- 第1波
- 第2波
- 敵の種類
- 同時出現数
- 出現パターン

などを管理することがあります。

でも最初から全部やる必要はありません。

今回は、

> **出現位置を順番に使って、一定時間ごとに敵を追加する**

だけです。

これでも十分ウェーブの入口になります。

---

## Pg7-13. 出現順を変えてみる

```python
spawn_positions_x = [
    100,
    540,
    200,
    440,
    320
]
```

のように変えると、左右から交互っぽく出せます。

---

## Pg7-14. まだ終わりではない

敵が順番に出てくるようになりました。

でも全部倒したあと、

> **「で、最後どうなるん？」**

となります。

次のPg8では、一定数の敵を倒したあとにボスを出します。

---

## Pg7-15. ここまでで覚えること

1. 最初から全部置かず、あとから敵を追加できる
2. `spawn_positions_x` に出現位置をまとめられる
3. `spawn_index` で何番目まで使ったか覚えられる
4. `spawn_timer` で出現間隔を作れる
5. `len()` でリストの個数を調べられる
6. 一定時間ごとに敵を追加するだけでも簡単なウェーブになる
7. 出現間隔もゲームバランスの一部
