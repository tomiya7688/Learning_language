# Tk1. tkinter入門 - 最初のウィンドウ

この章では、Pythonで**最初のGUIウィンドウを表示する**ところまで進みます。

ここから読み始めても進められるように、必要なことはこの章の中でも短く説明します。

今回の目標はひとつです。

> **Pythonを実行して、自分で作ったウィンドウを画面に出す**

まずはこれができれば十分です。

---

## Tk1-1. 今回作るもの

次のような、空のウィンドウを表示します。

タイトルには、

```text
はじめてのGUI
```

と表示します。

サイズは、

```text
400 × 300
```

にします。

まだボタンや入力欄はありません。

最初は、**画面が出ることそのもの**を確認します。

---

## Tk1-2. tkinterとは？

**tkinter** は、Pythonでウィンドウやボタンなどを作るための標準ライブラリです。

標準ライブラリとは、

> Pythonをインストールしたときから使える機能

のことです。

そのため、通常は追加で何かをインストールしなくても使えます。

この章では、まずtkinterを使って、

- ウィンドウを作る
- タイトルを付ける
- サイズを決める
- 画面を表示したままにする

ところまで進みます。

---

## Tk1-3. なぜGUIを使うの？

これまでのプログラムでは、ターミナルに文字を表示してきました。

もちろん、文字だけでもプログラムは動きます。

でも、使う人からすると、

> 「覚えらんねえよ！ 何ができるか見えるようにしろよ！」

となることがあります。

たとえば、文字だけの画面で、

```text
1: 開く
2: 保存
3: 設定
4: 終了
```

と表示されていたら、

> 「保存って2番だっけ？ 設定は3番だっけ？」

と毎回覚えて操作しなければなりません。

GUIなら、

- 「開く」ボタン
- 「保存」ボタン
- 「設定」ボタン

のように、**何ができるのかを画面に見せる**ことができます。

つまりGUIは、

> 利用者に操作を覚えさせるのではなく、  
> 何ができるかを画面から分かるようにする

ための仕組みでもあります。

この章ではまず、GUIの土台になるウィンドウを表示します。

---

## Tk1-4. サンプルコード

[first_window.py](./first_window.py) を開いてください。

`first` は「最初の」、`window` は「ウィンドウ」という意味です。

```python
import tkinter

# tkinterのウィンドウを作ります。
window = tkinter.Tk()

# ウィンドウのタイトルを設定します。
window.title("はじめてのGUI")

# ウィンドウの大きさを設定します。
window.geometry("400x300")

# ウィンドウを表示し続けます。
window.mainloop()
```

---

## Tk1-5. 実行してみる

VS Codeで `first_window.py` を開きます。

ターミナルを開いて、ファイルのある場所で次のように実行します。

Windows:

```text
python first_window.py
```

環境によっては、

```text
py first_window.py
```

でも実行できます。

macOS / Linux:

```text
python3 first_window.py
```

実行すると、新しいウィンドウが表示されます。

タイトルが、

```text
はじめてのGUI
```

になっていれば成功です。

---

## Tk1-6. `import tkinter` とは

最初の行を見てみましょう。

```python
import tkinter
```

`import` は、

> Pythonに用意されている別の機能を、このプログラムで使えるようにする

ための書き方です。

今回は `tkinter` を使いたいので、

```python
import tkinter
```

と書いています。

今は、

> GUIを使う準備をしている

くらいの理解で十分です。

`import` については、基礎文法ルートでも後ほど詳しく扱います。

---

## Tk1-7. `tkinter.Tk()` でウィンドウを作る

次の行では、ウィンドウを作っています。

```python
window = tkinter.Tk()
```

`tkinter.Tk()` を実行すると、GUIの元になるウィンドウが作られます。

そして、そのウィンドウを `window` という変数へ保存しています。

イメージは、

```text
tkinterで作ったウィンドウ
        ↓
      window
```

です。

---

## Tk1-8. 変数を知らなくても大丈夫

ここから読み始めた人向けに、変数も短く確認します。

```python
window = tkinter.Tk()
```

の `window` が変数です。

変数は、

> 値や作ったものに名前を付けて、あとから使うための仕組み

です。

今回は、作ったウィンドウに `window` という名前を付けています。

そのあと、

```python
window.title(...)
window.geometry(...)
window.mainloop()
```

のように、同じウィンドウに対して設定を追加していきます。

---

## Tk1-9. タイトルを付ける

```python
window.title("はじめてのGUI")
```

では、ウィンドウ上部のタイトルを設定しています。

`title` は「タイトル」という意味です。

文字を変えれば、好きなタイトルにできます。

```python
window.title("かんたんツール")
```

のように変更しても構いません。

---

## Tk1-10. サイズを決める

```python
window.geometry("400x300")
```

では、ウィンドウのサイズを指定しています。

```text
400x300
```

は、

```text
横400 × 縦300
```

という意味です。

ここで使っている `x` は掛け算記号ではなく、サイズを区切るために使っています。

たとえば、

```python
window.geometry("600x400")
```

なら、少し大きなウィンドウになります。

---

## Tk1-11. `mainloop()` は何をしている？

最後の行です。

```python
window.mainloop()
```

これは、GUIでとても大切な処理です。

ウィンドウを表示したあと、Pythonは、

- マウスが動いた
- ボタンが押された
- ウィンドウが閉じられた

といった操作を待ち続ける必要があります。

`mainloop()` は、そのための処理です。

もしこれがなければ、プログラムがすぐ終わってしまい、ウィンドウを操作できません。

今は、

> GUIを表示したままにして、操作を待つ処理

と覚えておけば十分です。

---

## Tk1-12. 関数を知らなくても大丈夫

この章には、

```python
tkinter.Tk()
window.title(...)
window.geometry(...)
window.mainloop()
```

のように、`()` が付いた書き方がいくつも出てきます。

これは、処理を実行するための**関数やメソッドの呼び出し**です。

まだ関数を詳しく知らなくても、

> `()` を付けて、その処理を実行している

くらいに考えてください。

基礎文法ルートの関数の章を読んでいる人は、その知識をここでも使っています。

---

## Tk1-13. 自分で変えてみる

タイトルとサイズを変えてみましょう。

```python
import tkinter

window = tkinter.Tk()

window.title("わたしのアプリ")
window.geometry("500x200")

window.mainloop()
```

実行すると、タイトルとサイズが変わります。

この時点ではまだ中身が空でも問題ありません。

**自分のコードでウィンドウが出た**ことが、この章の一番大きな成果です。

---

## Tk1-14. ウィンドウが出ないとき

まず、ターミナルにエラーメッセージが出ていないか確認してください。

よくある確認ポイントは次のとおりです。

- `first_window.py` を保存しているか
- ターミナルで正しいファイル名を入力しているか
- Pythonが正しくインストールされているか
- `import tkinter` のつづりが合っているか

Linuxでは、環境によってtkinterが別パッケージになっていて、追加インストールが必要な場合があります。

その場合は、利用しているLinuxディストリビューションのPython tkinterパッケージを確認してください。

Windowsや一般的なPython公式インストーラーでは、通常tkinterを利用できます。
