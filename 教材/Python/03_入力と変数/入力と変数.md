# 3. 入力と変数

この章では、利用者が入力した内容を受け取り、
その内容をあとで使う方法を学びます。

今回作るのは、**名前を入力すると、その名前で挨拶してくれるプログラム**です。

---

## 3-1. 今回作るもの

実行すると、まず名前を聞かれます。

```text
名前を入力してください: たろう
```

そのあと、入力した名前を使って挨拶します。

```text
こんにちは たろう
```

前の章では、あらかじめ決めた文字を表示するだけでした。

今回は、

> 利用者が入力する  
> ↓  
> 入力した内容を覚えておく  
> ↓  
> その内容を使う

という流れを作ります。

### なぜ入力と変数が必要なの？

もしプログラムが利用者の入力を受け取れなかったら、いつも同じことしかできません。

たとえば、名前を聞くプログラムなのに、

```text
名前を入力してください: さくら
こんにちは たろう
```

と表示されたら、少し困ります。

せっかく「さくら」と入力したのに、プログラムがその内容を使えていません。

> **「いや誰やねん、たろう！」**

となります。

入力した値を覚えて使えないなら、入力欄を置いた意味がありません。

そこで、

- `input()` で利用者の入力を受け取る
- 受け取った内容を変数に保存する
- 保存した値をあとで使う

という仕組みが必要になります。

入力と変数を使うことで、**利用者によって動きが変わるプログラム**を作れるようになります。

---

## 3-2. サンプルコード

[greeting.py](./greeting.py) を開いてください。

`greeting` は英語で「挨拶」という意味です。

```python
# input() で、利用者がキーボードから入力した文字を受け取ります。
# 受け取った文字を name という変数に保存します。
name = input("名前を入力してください: ")

# 保存した name の内容を使って挨拶します。
print("こんにちは", name)
```

---

## 3-3. `input()` とは

`input()` は、利用者から文字を入力してもらうための関数です。

```python
input("名前を入力してください: ")
```

実行すると、

```text
名前を入力してください:
```

と表示され、入力待ちになります。

文字を入力して Enter キーを押すと、
その文字を Python が受け取ります。

---

## 3-4. 変数とは

次の部分を見てください。

```python
name = input("名前を入力してください: ")
```

ここで `name` は **変数** です。

変数は、値に名前を付けて、
あとから使えるようにしておくための仕組みです。

今回なら、

```text
たろう
```

と入力した場合、

```text
name → "たろう"
```

というイメージです。

---

## 3-5. `=` は何をしている？

Python の

```python
name = ...
```

に出てくる `=` は、
数学の「左右が等しい」という意味だけではありません。

ここでは、

> 右側で得られた値を、左側の変数に入れる

という意味です。

```python
name = "たろう"
```

なら、

> `"たろう"` という文字列を `name` に入れる

と考えると分かりやすいです。

---

## 3-6. 保存した値を使う

```python
print("こんにちは", name)
```

では、先ほど保存した `name` を使っています。

たとえば `name` に `"たろう"` が入っていれば、

```text
こんにちは たろう
```

と表示されます。

つまり変数を使うと、

> 一度得た値を、あとで別の処理に使える

ようになります。

---

## 3-7. 自分で変えてみる

質問を変えてみましょう。

```python
food = input("好きな食べ物を入力してください: ")
print("好きな食べ物は", food, "ですね")
```

入力例:

```text
好きな食べ物を入力してください: カレー
```

実行結果:

```text
好きな食べ物は カレー ですね
```

変数名も `name` で固定ではありません。

内容に合わせて、

```text
name
food
age
color
```

のように名前を付けられます。

---

## 3-8. ここまでで覚えること

この章では、次のことが分かれば十分です。

1. `input()` で利用者の入力を受け取れる
2. 変数は値に名前を付けて覚えておくために使う
3. `=` で右側の値を左側の変数へ入れられる
4. 保存した変数はあとから使える

次は、入力した数字を使って計算する方法へ進めます。
