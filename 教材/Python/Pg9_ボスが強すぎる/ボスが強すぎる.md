# Pg9. pygame「ボスが強すぎる」

Pg8では、最後にボスが出るところまで作りました。

ここからは、あえて一度やらかします。

> **「いやデカすぎ！！！避ける場所ないやん！！！」**

今回は、ボスの弾を異常に大きくして、ほぼ避けられない状態にします。

直しません。

まず遊んで、

> **「これゲームとしてダメだな」**

を自分で確認します。

---

## Pg9-1. 今回作るもの

[unfair_boss.py](./unfair_boss.py) を開いてください。

`unfair` は「不公平な」「理不尽な」という意味です。

ボスが出るまではPg8とほぼ同じです。

違うのは、ボスが巨大な弾を撃ってくることです。

---

## Pg9-2. 問題の数字

今回の主犯はこれです。

```python
boss_bullet_width = 360
boss_bullet_height = 260
```

画面は640×480です。

その中で弾1発が、

```text
横 360
縦 260
```

あります。

> **そりゃ避ける場所なくなるわ。**

---

## Pg9-3. 速度は普通

```python
boss_bullet_speed = 4
boss_fire_interval = 120
```

にしています。

つまり、

- 異常に速いわけではない
- 異常な連射でもない
- **ただ弾がデカすぎる**

という状態です。

原因を1つに絞ります。

---

## Pg9-4. ボス弾を作る

ボスが出ている間、

```python
boss_fire_timer = boss_fire_timer + 1
```

と数えます。

時間が来たら、

```python
boss_bullets.append([
    boss_x,
    boss_y + 40
])
```

で弾を追加します。

---

## Pg9-5. 巨大弾を描く

```python
pygame.draw.rect(
    screen,
    (255, 80, 80),
    (
        boss_bullet[0] - boss_bullet_width // 2,
        boss_bullet[1],
        boss_bullet_width,
        boss_bullet_height
    )
)
```

です。

`// 2` は半分にするために使っています。

弾の中心がボスのx座標に合うよう、横幅の半分だけ左へずらしています。

---

## Pg9-6. 当たり判定も同じ大きさ

今回は、

```python
boss_bullet_rect = pygame.Rect(
    boss_bullet[0] - boss_bullet_width // 2,
    boss_bullet[1],
    boss_bullet_width,
    boss_bullet_height
)
```

として、見た目と同じ巨大Rectで判定します。

だから本当に避けにくいです。

---

## Pg9-7. 実装としては正しい

このコードは、

- 起動する
- 弾が出る
- 弾が動く
- 当たり判定もある
- HPも減る

ので、プログラムとしては動いています。

でも、

> **「動く」と「遊べる」は別です。**

これが今回の本題です。

---

## Pg9-8. 数字を変えただけでクソゲーになる

Pg8までのゲームロジックを大きく壊していません。

それでも、

```python
boss_bullet_width = 360
boss_bullet_height = 260
```

にしただけで、ゲーム性はかなり壊れます。

つまり、

> **パラメータもゲームの一部**

です。

---

## Pg9-9. この章では直さない

ここで普通サイズへ直したくなるかもしれません。

でも今回はまだ直しません。

まずは、

1. 実際に遊ぶ
2. 避けられない
3. 何が原因か見る
4. 弾がデカすぎると気付く

という順番を体験します。

---

## Pg9-10. CIも「失敗状態」を守る

普通なら、巨大すぎる弾はCIで止めたいところです。

でもPg9だけは逆です。

Pg9のCIでは、

> **ちゃんと弾がデカすぎること**

を確認します。

つまり、うっかり普通サイズへ直してしまうとCIが落ちます。

教材として、

> **意図的な失敗例を失敗例のまま保存する**

ためです。

---

## Pg9-11. 次で直す

次のPg10では、

> **「いやこれ避けられんわ。直そ」**

というところから始めます。

まず巨大弾を小さくします。

それでも難しければ、

- 弾速
- 発射間隔
- ボスHP

などを少しずつ調整します。

---

## Pg9-12. ここまでで覚えること

1. パラメータだけでもゲーム性は大きく変わる
2. 動くコードでも、遊べないゲームになることがある
3. 弾サイズと当たり判定サイズはゲームバランスに直結する
4. 問題の原因を1つに絞ると、何が悪いか分かりやすい
5. ゲーム開発では実装後に実際に遊ぶことが重要
6. 意図的な失敗例も教材として価値がある
