# 基礎編：ゆっくり学びたい人へ

小さなプログラムを作りながら、Pythonを順に学んで見ましょう。

## 最初に読むページ

**[ここから始める：0. Pythonとは？](./教材/00_Pythonとは/Pythonとは.md)**

0章から8章まで順に進めます。コードの書き方と実行手順を読み、保存して動かし、結果を確認しながら学びます。

9章で、次に進むルートを選びます。

- 基本文法を続ける
- 電卓を作る
- ブラウザのツールを作る
- ゲームを作る

各ルートの学習順は、目次で確認できます。

## 作るものから選びたい場合
