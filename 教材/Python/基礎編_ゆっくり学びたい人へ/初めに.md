# 基礎編：ゆっくり学びたい人へ

小さなプログラムを作りながら、Pythonを順に学んで見ましょう。コードの書き方と実行手順を読み、保存して動かし、結果を確認しながら進めます。

最初から始める場合は、[0. Pythonとは？](./教材/00_Pythonとは/Pythonとは.md)へ進んでください。

Pythonの導入から始める場合は、[1. 環境構築](./教材/01_環境構築/環境構築ガイド.md)を開いてください。

電卓・ブラウザのツール・ゲームを作りたい場合は、[作りたいものから選ぶ](./教材/09_進みたい方を選ぼう/進みたい方を選ぼう.md)でルートを選べます。各ルートでは、そこで使う変数・関数・操作も説明します。
