# Pg9. pygame「ボスを出す」

Pg8では、敵が順番に出てきて、それぞれ攻撃するようになりました。でも通常の敵が全部いなくなると、次に戦う相手がいません。

> **「雑魚全部いなくなった。で、終わり？？？」**

最後に大きな敵と戦って締めくくりたいところです。この章のゲームは、通常の敵を倒したあとに、HPの多い大きなボスが登場します。

## 起動してから1回の更新が終わるまで

`main.py` を実行すると、PythonはPygameを準備して `Game.run()` を始めます。`Game.run()` は、ウィンドウを閉じる操作を確認し、戦闘中の自機・敵・弾の状態を更新して、描いた画面を表示します。画面更新の速さは `self.clock.tick(settings.FPS)` で1秒あたり最大 `settings.FPS` 回に抑えます。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

`main.py` を直接実行すると、Pythonは `main()` を動かし、`game.py` の `Game` がゲーム画面を開きます。別のPythonファイルから `main.py` を読み込んだだけでは、`main()` は動かず、ウィンドウも開きません。読者がウィンドウの閉じるボタンを押すと、`Game.handle_events()` は `pygame.event.get()` から閉じる操作の知らせ `pygame.QUIT` を受け取り、`self.running` を `False` にします。`Game.run()` はその値を見て画面更新の繰り返しを終え、`main.py` に戻ります。

`main.py` の `try:` の下にはゲームの起動と実行を書きます。Pythonはその処理が正常に終わった場合も途中でエラーが起きた場合も、`finally:` の下にある `pygame.quit()` を実行してPygameを終了します。エラーが起きた場合は、Pygameを終了してからPythonがエラーを表示します。

### 起動用の `main.py`

このコードの元ファイル：[`main.py` の 1〜24行](./main.py#L1-L24)。

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # Pythonは try: の処理が終わったときもエラーで中断したときも、finally: の下の pygame.quit() を実行する
    try:
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygameを終了する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

## ボスにも `Boss` という型を用意する

通常の敵にクラスを使いながら、ボスの位置とHPだけを別々の変数へ散らすと、どこまでがボスの処理か分からなくなります。ボスが初めて出るこの章で `Boss` を作ります。

`Boss` は位置の `rect`、体力の `hp`、ダメージを受ける `take_damage()`、描く `draw()` を持ちます。中心は `(320, 90)`、大きさは120×80、体力は20です。位置と体力はボス自身が持ちます。

`Battle.boss` は最初 `None` です。`None` は「ここにボスがまだない」ことを表す値です。全ての敵を出し終え、通常の敵の一覧が空になったとき、`Boss()` を1つ作ってここへ入れます。`boss_active` と位置とHPを別々に同期する必要はありません。

ボスが現れるときは、自機の弾の一覧を空にします。出現前に撃った弾をボスへ持ち越しません。通常の敵もボスも、弾との重なりを調べて命中した弾を処理します。この同じ種類の処理を `collisions.py` に置き、ボス用の `hit_boss`（ボスに命中）ではボスのHPを1減らします。HPが0なら `GAME CLEAR!` をターミナルに表示して終了します。

## 設定値の場所と意味

`settings.py` は、ゲーム内容を調整する数値をまとめた Python ファイルです。`PLAYER_SPEED = 5` は、自機を押した矢印の方向へ画面更新1回あたり5ピクセル動かします。縦横の矢印キーを同時に押すと、両方向へそれぞれ5ピクセル動きます。`player.py` は `settings.PLAYER_SPEED` を使って自機を動かします。`game.py` は `settings.WIDTH` と `settings.HEIGHT` で画面の幅と高さを決め、`settings.FPS` で1秒あたりの画面更新回数の上限を決めます。

画面を1回更新するとは、ゲーム内の位置や状態を進めて、画面を書き直すことです。画面の位置・幅・高さはピクセル（画面上の点1つ）で表します。速さは1回の画面更新で動くピクセル数、敵の出現間隔や弾の発射間隔は次の動作までの画面更新回数です。間隔の数値は秒ではありません。`FPS = 60` は1秒間に画面を更新する回数の上限を60回にします。画面が毎秒60回更新されているときは、60回が約1秒、90回が約1.5秒、120回が約2秒です。更新が毎秒60回より少ない場合は、間隔にかかる時間が長くなります。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | ゲーム画面の横幅（ピクセル） | `640` |
| `HEIGHT` | ゲーム画面の縦幅（ピクセル） | `480` |
| `FPS` | ゲーム画面を1秒間に更新する回数の上限（回/秒） | `60` |
| `PLAYER_X` | 自機の最初の中心位置。画面左端からの距離（ピクセル） | `320` |
| `PLAYER_Y` | 自機の最初の中心位置。画面上端からの距離（ピクセル） | `400` |
| `PLAYER_SPEED` | 押した矢印の方向へ1回の画面更新で進む距離。縦横同時に押すと両方向へ進みます（ピクセル/回） | `5` |
| `BULLET_SPEED` | 自機の弾が画面を1回更新する間に上へ動く距離（ピクセル/回） | `8` |
| `ENEMY_SPEED` | 通常の敵が画面を1回更新する間に下へ動く距離（ピクセル/回） | `1` |
| `PLAYER_HP` | 自機がゲーム開始時に持つ体力の値 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾が画面を1回更新する間に下へ動く距離（ピクセル/回） | `4` |
| `SPAWN_POSITIONS_X` | 敵を出す順に並べた横位置。各値は画面左端から敵の中心までの距離（ピクセル） | `(120, 320, 520, 220, 420, 100, 540)` |
| `SPAWN_INTERVAL` | 次の敵が出現するまでの画面更新回数。90回なら約1.5秒（FPS=60の場合） | `90` |
| `ENEMY_FIRE_INTERVALS` | 出現順の敵ごとに、次の弾を撃つまでの画面更新回数を並べた一覧 | `(60, 90, 120, 75, 105, 80, 110)` |
| `BOSS_X` | ボスの中心位置。画面左端からの距離（ピクセル） | `320` |
| `BOSS_Y` | ボスの中心位置。画面上端からの距離（ピクセル） | `90` |
| `BOSS_HP` | ボスが登場したときに持つ体力の値 | `20` |

自機の中心(320, 400)は画面の中央より下、ボスの中心(320, 90)は上側です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。機体の `rect` は位置と大きさを一緒に持ち、移動・描画・命中に同じ長方形を使います。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `boss.py` の `Boss`

[`boss.py` の6〜27行](./boss.py#L6-L27)にある `Boss` の定義を、下のコードに置き換えてください。

`BOSS_X = 320` と `BOSS_Y = 90` は、640×480ピクセルの画面でボスの中心を左から320、上から90ピクセルの位置に置きます。`BOSS_HP = 20` は、ボスが登場したときの体力を20にします。

このコードの元ファイル：[`boss.py` の 6〜27行](./boss.py#L6-L27)。

```python
# Boss という型を定義する
class Boss:
    # __init__ の処理を定義する
    def __init__(self):
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, 120, 80) を入れる
        self.rect = pygame.Rect(0, 0, 120, 80)
        # self.rect.center に (settings.BOSS_X, settings.BOSS_Y) を入れる
        self.rect.center = (settings.BOSS_X, settings.BOSS_Y)
        # hp はhit points（体力）。攻撃1回で1減り、0で倒されます。
        # self.hp に settings.BOSS_HP を入れる
        self.hp = settings.BOSS_HP

    # take_damage の処理を定義する
    def take_damage(self):
        # self.hp から 1 を引く
        self.hp -= 1

    # draw の処理を定義する
    def draw(self, screen):
        # pygame.draw.rect(screen, (180, 80, 255), self.rect) を実行する
        pygame.draw.rect(screen, (180, 80, 255), self.rect)
```

### `battle.py` の `Battle.update_boss`

通常の敵を出す処理とボスの出現条件を `Battle.update()` に全部書くと、通常の敵を出す流れが追いにくくなります。この章では、敵を出し終えた後にボスを作り、ボスが出た後の命中も確認する処理を `Battle.update_boss()` にまとめ、戦闘の更新から呼びます。

[`battle.py` の149〜163行](./battle.py#L149-L163)にある `Battle.update_boss` の定義を、下のコードに置き換えてください。

`SPAWN_POSITIONS_X` は左端からの距離（ピクセル）で敵の中心位置を表す一覧で、この章では7個です。7か所すべてへ敵を出し終わり、画面上に通常の敵がいなくなったとき、`Battle.update_boss()` がボスを作ります。

このコードの元ファイル：[`battle.py` の 149〜163行](./battle.py#L149-L163)。

```python
# update_boss の処理を定義する
def update_boss(self):
    # self.boss is None が成り立つなら
    if self.boss is None:
        # self.spawn_index >= len(settings.SPAWN_POSITIONS_X) and (not self.enemies) が成り立つなら
        if self.spawn_index >= len(settings.SPAWN_POSITIONS_X) and not self.enemies:
            # boss はボス。通常の敵が全ていなくなった後に登場します。
            # self.boss に Boss() を入れる
            self.boss = Boss()

            # self.bullets.clear() を実行する
            self.bullets.clear()
        # この処理を終える
        return
    # hit_boss(self.bullets, self.boss) を実行する
    hit_boss(self.bullets, self.boss)
```

## 保存先へ移動して `main.py` を実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の `main.py` を保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。


`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

```text

```

### macOS / Linux
