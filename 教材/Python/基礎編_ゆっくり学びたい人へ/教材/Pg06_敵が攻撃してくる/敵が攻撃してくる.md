## 起動してから1回の更新が終わるまで

`enemy_fire.py` の `main()` がpygameを初期化し、`Game()` を作って `run()` を呼びます。`Game` は画面と時計を持ち、入力・更新・描画を順に呼びます。`Battle` は1回の戦闘の自機・敵・弾を管理します。移動と描画は各機体や弾自身のメソッド（クラス内の関数）へ任せます。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

入口の最後の `if __name__ == "__main__":` は、直接実行したときだけmain()を呼ぶ条件です。補助ファイルを読み込んだだけではゲームを起動しません。`finally` のpygame.quit()はエラーが起きた場合も終了時の片付けを行います。

### 入口のコード

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # game はゲーム全体。起動・繰り返し・画面切り替えを担当します。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# __name__ == '__main__' が成り立つなら
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 敵の発射と、自機が受けるダメージを分ける

`Enemy.shoot()` は敵の下辺から下向きの弾を作ります。自機の弾と同じ `Bullet` を使い、速さを `4`、大きさを8×16、色をピンクに指定します。弾の移動と描画を書き直す必要はありません。

`Battle.fire_timer` は前回の発射からの更新回数です。この章では全ての敵が同時に撃ちます。`ENEMY_FIRE_INTERVAL = 90` は90回更新したら発射する指定で、60回/秒なら約1.5秒です。発射したら数える値を0へ戻します。

`enemy_bullets` は敵の弾の一覧です。`hit_player`（自機に命中）は、自機と重なった弾を削除し、`Player.take_damage()`（ダメージを受ける）を呼びます。`hp` は体力で、3から始まり、命中1回で1減ります。0以下ならターミナルに `GAME OVER` が表示され、ゲームが終了します。

`pygame.font.Font(None, 36)` はpygame同梱の標準フォントを36ピクセルの大きさで用意する指定です。`None` はフォントファイルを自分で指定しないという意味です。ここでは英数字の `HP: 3` を表示します。この標準フォントで日本語表示ができるとは限りません。`render` は文字を描いた画像を作り、`blit` はその画像を画面へ置きます。

## 設定値の場所と意味

`settings.py` の値はこの章の初期設定です。位置と大きさの単位はピクセル、速さは1回の更新で動くピクセル数、間隔は更新回数です。最大60回/秒の場合、90回は約1.5秒、120回は約2秒です。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | 画面の幅 | `640` |
| `HEIGHT` | 画面の高さ | `480` |
| `FPS` | 1秒あたりの更新回数の上限 | `60` |
| `PLAYER_X` | 自機の最初の中心の横位置 | `320` |
| `PLAYER_Y` | 自機の最初の中心の縦位置 | `400` |
| `PLAYER_SPEED` | 自機の移動の速さ | `5` |
| `BULLET_SPEED` | 自機の弾の速さ（発射時に負にして上へ動かす） | `8` |
| `ENEMY_SPEED` | 通常の敵の移動の速さ | `1` |
| `PLAYER_HP` | 自機の最初の体力 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾の速さ | `4` |
| `ENEMY_FIRE_INTERVAL` | 全ての敵に共通する発射間隔 | `90` |

自機の中心(320, 400)は画面の中央より下です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `collisions.py` の `hit_player`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# hit_player の処理を定義する
def hit_player(bullets, player):
    # bullets[:] から bullet を1つずつ取り出して繰り返す
    for bullet in bullets[:]:
        # bullet.rect.colliderect(player.rect) が成り立つなら
        if bullet.rect.colliderect(player.rect):
            # bullets.remove(bullet) を実行する
            bullets.remove(bullet)
            # player.take_damage() を実行する
            player.take_damage()
```

## 保存先へ移動して、入口ファイルを実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の入口ファイルを保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe enemy_fire.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text

```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。
