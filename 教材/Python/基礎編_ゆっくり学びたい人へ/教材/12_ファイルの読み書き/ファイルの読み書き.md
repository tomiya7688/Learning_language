# 12. ファイルの読み書き

メモをプログラムの中だけで持っていると、終了したあとには残りません。明日また読み返したいのに、内容を最初から用意し直すのは困ります。

> **「昨日のメモどこ行った！閉じても残しておきたい！」**

この章のプログラムは、文章をパソコンのファイルへ書き込み、そのファイルから読み直します。ファイルへ保存した文章は、プログラムを終了したあとも読み返せます。

---

## 12-1. 今回作るもの

今回のプログラムは、まず次の文字列をファイルへ保存します。

```text
こんにちは
Pythonを勉強中です
```

保存したあと、そのファイルをもう一度開いて内容を読み込みます。

実行すると、

```text
保存しました
読み込んだ内容:
こんにちは
Pythonを勉強中です
```

のように表示されます。

---

## 12-2. なぜファイルが必要なの？

ここまでの変数、リスト、辞書はとても便利です。

でも、プログラムを終了すると、その中に入っていたデータは消えます。

たとえば、

```python
name = "たろう"
```

この代入で、`name` の値をファイルへ保存したわけではありません。終了後に同じコードを実行すると、コードに書いた「たろう」をもう一度設定します。実行中に入力したメモや変更した値を次回も使うには、ファイルなどへ記録しておく必要があります。

> **「一々入力すんのだるすぎるわ！そんくらい覚えとけ！」**

となります。

そこで使うのが **ファイル** です。

ファイルへ書き込めば、プログラムが終了してもデータを残せます。

---

## 12-3. 保存するファイルを決める

[file_io.py](./file_io.py) を開いてください。

`file` は「ファイル」、`io` は Input / Output、つまり「入力と出力」という意味です。

まず、保存先のファイル名を決めてください。

保存先のファイル名は `message.txt` にしてください。次のコードは、その名前を `file_name` に対応させる処理です。

```python
# 保存先のファイル名を file_name に保存します。
file_name = "message.txt"

# ファイルへ文字を書き込みます。
with open(file_name, "w", encoding="utf-8") as file:
    file.write("こんにちは\n")
    file.write("Pythonを勉強中です\n")

print("保存しました")

# 保存した内容を読み込みます。
with open(file_name, "r", encoding="utf-8") as file:
    # 読み込んだ文字を text に保存します。
    text = file.read()

print("読み込んだ内容:")
print(text)
```

---

## 12-4. `open()` でファイルを開く

ファイルを扱うときは、`open()` を使ってください。

```python
open(file_name, "w", encoding="utf-8")
```

ここでは、

- どのファイルを使うか
- 書き込みか読み込みか
- 文字コードは何か

を指定しています。

---

## 12-5. `"w"` は書き込み

```python
with open(file_name, "w", encoding="utf-8") as file:
```

の `"w"` は write、つまり「書き込み」です。

このモードでファイルを開くと、そのファイルへ文字を書けます。

ただし、同じ名前のファイルがすでにある場合は、内容が上書きされます。

`"w"` は書き込みモードです。同じ名前のファイルがある場合、既存の内容を上書きします。

---

## 12-6. `.write()` で文字を書く

ファイルへ文字を書くには、`.write()` を使ってください。

```python
file.write("こんにちは\n")
```

これで、

```text
こんにちは
```

という文字がファイルへ保存されます。

---

## 12-7. `\n` は改行

```python
"こんにちは\n"
```

の `\n` は改行を表します。

```python
file.write("こんにちは\n")
file.write("Pythonを勉強中です\n")
```

と書くと、ファイルの中は、

```text
こんにちは
Pythonを勉強中です
```

のように2行になります。

---

## 12-8. なぜ `with` を使うの？

メモを書くコードを作るたびに、ファイルを開く処理と、使い終わって閉じる処理を両方書くと、閉じるほうを忘れてしまうことがあります。

> **「使い終わったら閉じるところまで、まとめて任せたい！」**

`with` を使うと、ファイルを使う範囲を決め、その範囲を抜けたときに閉じる処理をPythonに任せられます。

```python
with open(file_name, "w", encoding="utf-8") as file:
    file.write("こんにちは\n")
```

このブロックを抜けると、ファイルは自動で閉じられます。

つまり、

> 開く → 使う → 閉じる

を安全にまとめやすくするのが `with` です。

---

## 12-9. `as file` とは

```python
with open(file_name, "w", encoding="utf-8") as file:
```

では、開いたファイルをこのブロックの中で使う名前も必要です。

ここでは短く `file` にしてください。

`as file` は、

> 開いたファイルを `file` という名前で使う

という意味です。

そのため、その中で、

```python
file.write(...)
```

と書けます。

---

## 12-10. `"r"` は読み込み

保存したファイルを読むときは、`"r"` を使ってください。

```python
with open(file_name, "r", encoding="utf-8") as file:
```

`r` は read、つまり「読み込み」です。

---

## 12-11. `.read()` で内容を全部読む

```python
text = file.read()
```

とすると、ファイルの内容をまとめて読み込めます。

読み込んだ文字列を `text` に保存して、

```python
print(text)
```

で表示できます。

---

## 12-12. UTF-8とは

今回、

```python
encoding="utf-8"
```

と書いています。

これは、文字をどのルールで保存・読み込みするかを指定しています。

文字コードが合っていないと、日本語が文字化けすることがあります。

この教材では、基本的に **UTF-8** を使います。

`encoding="utf-8"` を指定すると、UTF-8で文字を読み書きできます。教材のサンプルにも、この指定があります。

---

## 12-13. 相対パスとは

今回のファイル名は、

```python
file_name = "message.txt"
```

です。

フォルダ名を書いていません。

このように、今いる場所を基準にした指定を **相対パス** と呼びます。

今回のプログラムを、

```text
12_ファイルの読み書き/
├─ file_io.py
└─ message.txt
```

のような形で使うイメージです。

---

## 12-14. 「今いる場所」が大事

相対パスは、**どこからPythonを実行したか**によって意味が変わります。

ここで初学者がよく混乱します。

たとえば `file_io.py` が、

```text
C:\study\Python\12_ファイルの読み書き
```

にあるなら、そのフォルダへ移動してから実行すると分かりやすいです。

Windowsなら、

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 例のフォルダのパスを自分の保存先に置き換え、次のコマンドを上から1行ずつ、そのターミナルに入力してください。
3. 1行入力するたびに Enter キーを押してください。

```text
cd "C:\study\Python\12_ファイルの読み書き"
python file_io.py
```

次のコードは、その指定を使った例です。

macOS / Linuxなら、

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 例のフォルダのパスを自分の保存先に置き換え、次のコマンドを上から1行ずつ、そのターミナルに入力してください。
3. 1行入力するたびに Enter キーを押してください。

```text
cd "/home/user/study/Python/12_ファイルの読み書き"
python3 file_io.py
```

次のコードは、その指定を使った例です。

## 12-15. パスが分からないとき

Windowsでは、次の手順で `file_io.py` を保存したフォルダの場所をコピーし、ターミナルでそのフォルダへ移動してください。

1. エクスプローラーで、保存した `file_io.py` が入っているフォルダを開いてください。
2. 上部のアドレス欄をクリックし、表示されたフォルダのパス全体を選んで **Ctrl + C** を押してください。アドレス欄を選べないときは、**Alt + D** を押すと選べます。
3. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
4. 次のコマンドを、そのターミナルに入力してください。「コピーしたパス」の部分は、手順2でエクスプローラーのアドレス欄からコピーした文字列に置き換えてください。**Ctrl + V** で貼り付け、前後の `"` は残してください。
5. Enter キーを押してください。

```text
cd "コピーしたパス"
```

`cd` は、ターミナルで作業するフォルダを移動するためのコマンドです。

## 12-19. 上書きしたくない場合は？

`"w"` は、同名ファイルがあると内容を上書きします。

あとから追記したい場合は `"a"` を使う方法もあります。

```python
with open("message.txt", "a", encoding="utf-8") as file:
    file.write("追加の文章です\n")
```

`a` は append、つまり「追記」です。

`"w"` は書き込み用、`"r"` は読み込み用、`"a"` は追記用にファイルを開きます。

---

## 12-20. ファイルが存在しないとどうなる？

`"r"` で存在しないファイルを開こうとすると、エラーになります。

たとえば、

```python
open("not_found.txt", "r", encoding="utf-8")
```

で、そのファイルが無ければプログラムは止まります。

このような問題を安全に扱う方法は、次の**例外処理**で学びます。
