# 4. 数値と計算

3章では、`input(...)` で受け取った名前や好きな食べ物を変数に入れ、`print(...)` で表示しました。次は、`input(...)` で受け取った値を変数に入れる書き方を使って、買い物の合計を計算したいところです。

たとえば、10円のお菓子と20円のお菓子を買う場合を考えてみてください。3章と同じように、入力した値段を表示するだけでは、合計は自分で計算することになります。入力した2つの値段をプログラムで足して、合計を表示するようにしたいですね。

> **「数字を並べるだけじゃなくて、足した答えが欲しい！」**

この章では、入力した2つの数字を足し算するプログラムを作ります。10と20を入力し、合計の30を表示することを目指します。

## 4-1. 2つの入力を足してみる

3章で作った名前を尋ねるプログラムと、好きな食べ物を尋ねるプログラムには、それぞれ `input(...)` が1か所ありました。どちらも、入力を1つ受け取るためです。今回は2つの値段を受け取るので、`input(...)` を2回書きます。

2つの入力をあとで足せるように、それぞれ別の変数で使えるようにします。変数名には、英語で「1つ目の数」を意味する `number1` と、「2つ目の数」を意味する `number2` を使います。3章で名前に使った `name`、食べ物に使った `food` と同じように、受け取るものに合わせて名前を決めます。

受け取った値を足すには、`number1 + number2` と書きます。答えもあとで表示したいので、英語で「答え」を意味する `answer` という変数へ入れます。

VS Codeの **ファイル → 新しいテキストファイル** を選び、次の作成途中のコード全体を書いてください。

```python
# number1 は「1つ目の数」という意味の変数
# number1 に「1つ目の数字を入力してください: 」と表示して入力された文字列を入れる
number1 = input("1つ目の数字を入力してください: ")
# number2 は「2つ目の数」という意味の変数
# number2 に「2つ目の数字を入力してください: 」と表示して入力された文字列を入れる
number2 = input("2つ目の数字を入力してください: ")
# 作り方と10・20を入力した場合の表示は、同じフォルダの「数値と計算.md」を参照
# answer は「答え」という意味の変数
# answer に number1 と number2 を足した値を入れる
answer = number1 + number2

# 「答えは」と answer の値と「です」を、間に空白を入れてターミナルに表示する
print("答えは", answer, "です")
```

**ファイル → 名前を付けて保存** を選び、第3章で使った学習用フォルダへ `simple_addition.py` として保存してください。`simple_addition` は英語で「簡単な足し算」という意味です。第3章の `greeting.py` は残してください。

## 4-2. 10と20を入力すると、どうなる？

保存した `simple_addition.py` を実行し、10と20を入力して、答えを確認してください。

1. エクスプローラー（Windows）、Finder（macOS）、ファイル管理アプリ（Linux）で、`simple_addition.py` を保存した学習用フォルダを開いてください。
2. フォルダの場所を表す文字列を「パス」といいます。次の方法で、`simple_addition.py` を保存した学習用フォルダのパスをコピーしてください。
   - Windows：開いたフォルダの上部のアドレス欄をクリックし、Ctrl + Cを押してください。
   - macOS：Finderで学習用フォルダを選び、Option + Command + Cを押してください。
   - Linux（GNOMEの「ファイル」）：学習用フォルダを開き、Ctrl + L、Ctrl + Cの順に押してください。
3. VS Codeの **表示 → ターミナル** を選んでください。画面下に開くターミナルは、実行するコマンドを入力する欄です。
4. 開いたターミナルに `cd "コピーした学習用フォルダのパス"` と入力してください。引用符の中は、手順2でコピーしたパスに置き換えてください。WindowsではCtrl + V、macOSではCommand + V、LinuxではCtrl + Shift + Vで貼り付け、Enterキーを押してください。`cd` は、ターミナルで作業するフォルダを変えるコマンドです。
5. 保存先へ移動した同じターミナルに、Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力し、Enterキーを押してください。

コマンドはPythonのコードを書く編集欄へ入力しないでください。ターミナルに既に表示されている `PS C:\...>` や `$` などの文字も入力しないでください。

`1つ目の数字を入力してください:` が表示されたら、同じターミナルに `10` と入力してEnterキーを押してください。`2つ目の数字を入力してください:` が表示されたら、`20` と入力してEnterキーを押してください。入力するのは数字だけです。案内の文字、`円`、引用符は入力しないでください。

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
答えは 1020 です
```

プログラムが表示した答えは、求めたかった30ではなく、1020になってしまいました。

> **「10円と20円を足して、なんで1020円になるんだよ！」**

## 4-3. 文字列の足し算と、数値の足し算

`input(...)` は、数字を入力した場合も、入力内容を文字列として受け取ります。`10` と入力すると、数値の10ではなく、文字列 `"10"` を受け取ります。2つ目の入力も、文字列 `"20"` です。

文字列同士の `+` は、文字列をつなげます。文字列 `"10"` の後ろに `"20"` をつなげたので、結果は文字列 `"1020"` になりました。

求めたいのは、金額の10と20を足した30です。数値の足し算にするには、入力された文字列を数値へ変える必要があります。

次の表は違いを説明するための例で、ファイルに追加するコードではありません。

| コードに書く値 | `+` の動き | 結果 |
| --- | --- | --- |
| `"10" + "20"` | 文字列をつなげる | 文字列 `"1020"` |
| `10 + 20` | 数値を足す | 数値 `30` |

コードの中では、文字列は `"10"` のように引用符で囲み、数値は `10` のように引用符を付けずに書きます。ターミナルに入力するときに引用符を省いても、`input(...)` が受け取る値は文字列です。

## 4-4. 数値に変えてから足す

10や20のように、小数部分を持たない数を **整数** といいます。整数の書かれた文字列を整数へ変えるには、`int(...)` を使います。`int("10")` は整数の10、`int("20")` は整数の20になります。

数値の足し算にするために、`simple_addition.py` へ文字列を整数に変える行を加えます。VS Codeで `simple_addition.py` を開き、`# answer は「答え」という意味の変数` のコメントを探してください。そのコメントの直前へ、次の4行と空行を追加してください。

[`simple_addition.py` の8〜11行](./simple_addition.py#L8-L11)

```python
# number1 の文字列を、小数部分を持たない数（整数）に変換し、number1 に入れ直す
number1 = int(number1)
# number2 の文字列を整数に変換し、number2 に入れ直す
number2 = int(number2)
```

`number1 = int(number1)` では、Pythonはまず右側の `int(number1)` で、入力された文字列 `"10"` を整数の10へ変えます。次に、左側の `number1` へ整数の10を入れ直します。Pythonは `number2` にも、文字列 `"20"` から変換した整数の20を入れ直します。

`=` は「左右が等しい」という意味ではなく、右側の値を左側の名前へ代入する記号なので、同じ変数へ値を入れ直すこともできます。変換後の `number1 + number2` は、整数の10と20の足し算になります。

追加後の完成コード全体は、次のとおりです。

[`simple_addition.py` の1〜18行](./simple_addition.py#L1-L18)

```python
# number1 は「1つ目の数」という意味の変数
# number1 に「1つ目の数字を入力してください: 」と表示して入力された文字列を入れる
number1 = input("1つ目の数字を入力してください: ")
# number2 は「2つ目の数」という意味の変数
# number2 に「2つ目の数字を入力してください: 」と表示して入力された文字列を入れる
number2 = input("2つ目の数字を入力してください: ")
# 作り方と10・20を入力した場合の表示は、同じフォルダの「数値と計算.md」を参照
# number1 の文字列を、小数部分を持たない数（整数）に変換し、number1 に入れ直す
number1 = int(number1)
# number2 の文字列を整数に変換し、number2 に入れ直す
number2 = int(number2)

# answer は「答え」という意味の変数
# answer に number1 と number2 を足した値を入れる
answer = number1 + number2

# 「答えは」と answer の値と「です」を、間に空白を入れてターミナルに表示する
print("答えは", answer, "です")
```

1. VS Codeで `simple_addition.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. 同じターミナルに、Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力し、Enterキーを押してください。

`1つ目の数字を入力してください:` に `10`、`2つ目の数字を入力してください:` に `20` と入力し、それぞれEnterキーを押してください。

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
答えは 30 です
```

入力する数字は変えずに、文字列を整数へ変える行を追加したことで、合計の30を表示できました。Pythonは上から、入力を受け取る → 整数へ変える → 足した答えを `answer` へ入れる → 答えを表示する、という順で実行します。

## 4-5. 掛け算に変えてみる

`simple_addition.py` を変更して、1個10円のお菓子を20個買う金額も計算してみてください。値段同士の足し算ではなく、1個の値段に個数を掛ける計算です。

VS Codeで `simple_addition.py` を開き、`answer = number1 + number2` を探してください。[完成コードの14〜15行](./simple_addition.py#L14-L15)に当たるコメントと計算の2行を、次の練習用コードへ置き換えてください。

```python
# answer に number1 と number2 を掛けた値を入れる
answer = number1 * number2
```

Pythonで掛け算を書く記号は `*` です。`answer` の行だけを変えたので、数字を尋ねる案内と答えの表示は、足し算のプログラムと同じです。

1. VS Codeで `simple_addition.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. 同じターミナルに、Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力し、Enterキーを押してください。

1つ目の数字の案内が出たら、1個の値段の `10` を入力してEnterキーを押してください。2つ目の数字の案内が出たら、個数の `20` を入力してEnterキーを押してください。

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
答えは 200 です
```

10円を20個分なので、答えは200です。掛け算へ変えたコードは残したまま次の章へ進めます。第5章では別のプログラムを作ります。

## 4-6. 小数や数字以外を入力する場合

この章の `int(...)` を使うプログラムでは、金額や個数の案内へ `10` や `20` のように整数を入力してください。`10円`、`abc`、小数の `12.5` を入力すると、文字列を整数へ変えられず、ターミナルに `ValueError` というエラー名を表示してプログラムが終了します。

入力し直すには、VS Codeの **表示 → ターミナル** で保存先へ移動した同じターミナルを表示してください。Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力してEnterキーを押し、数字の案内が出てから整数を入力してEnterキーを押してください。

小数を計算したい場合は、文字列を小数の計算に使える数値へ変える `float(...)` を使います。説明用の例として、`float("12.5")` なら数値の12.5になります。この章の練習用ファイルへ追記するコードではありません。

## 4-7. 今回の内容

- `input(...)` は、数字も文字列として受け取ります。
- 文字列同士の `+` は、文字列をつなげます。
- 入力された文字列を `int(...)` で整数へ変えると、数値の計算に使えます。
- 数値同士の `+` は足し算、`*` は掛け算です。
- 計算した値にも名前を付け、あとの行で表示できます。

### ほかの計算記号を調べたいとき

数値の計算には、次の記号も使えます。必要な計算を書くときに参照してください。表の式は説明用で、ファイルへ追加するコードではありません。

| 記号 | 計算の意味 | 説明用の式と結果 |
| --- | --- | --- |
| `-` | 引き算 | `20 - 10` → `10` |
| `/` | 割り算 | `20 / 10` → `2.0` |
| `//` | 割った結果を小さい方の整数へ切り下げる | `10 // 3` → `3`、`-10 // 3` → `-4` |
| `%` | 整数同士なら、割り算の余り | `10 % 3` → `1` |
| `**` | 累乗。同じ数を指定した回数掛ける計算 | `2 ** 3` → `8`（2 × 2 × 2） |

`//` は小数部分を取り除く操作とは異なります。`-10 / 3` は約−3.33なので、小さい方の整数へ切り下げると−4です。数値の計算規則は[Python公式資料](https://docs.python.org/ja/3/reference/expressions.html#binary-arithmetic-operations)で確認できます。
