# 4. 数値と計算

この章の題材は、利用者が入力した数字を使って計算するプログラムです。

今回作るのは、**2つの数字を入力して足し算するプログラム**です。

---

## 4-1. 今回作るもの

実行例:

```text
1つ目の数字を入力してください: 12
2つ目の数字を入力してください: 8
答えは 20 です
```

前の章では入力した文字をそのまま使いました。

このプログラムは、入力した2つの数字を使って、足した結果を表示します。

---

## 4-2. 入力した数字をそのまま表示する

まず、`10` と入力したときに、どんな値を受け取るか見てください。

1. VS Code の **ファイル → 新しいテキストファイル** を選び、次の Python コードを書いてください。
2. **名前を付けて保存** で、自分の学習用フォルダに `calculation_trial.py` として保存してください。
3. `calculation_trial.py` を保存したフォルダの場所をコピーしてください。この場所を表す文字列を「パス」と呼びます。

   - Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして Ctrl + C を押してください。
   - macOS：Finderでそのフォルダを選び、Option + Command + C を押してください。
   - Linux（GNOMEの「ファイル」）：そのフォルダを開き、Ctrl + L、Ctrl + C の順に押してください。

4. VS Code の **表示（View）→ ターミナル（Terminal）** を選び、ターミナルを開いてください。
5. `cd "コピーしたフォルダのパス"` と入力してください。引用符の中は、3でコピーしたパスに置き換えてください。
6. Enter キーを押してください。
7. 4で開いた同じターミナルに、Windows では `python calculation_trial.py`、macOS / Linux では `python3 calculation_trial.py` と入力してください。
8. Enter キーを押してください。

保存先の調べ方や `cd` の操作は、[第2章の実行手順](../02_最初のプログラム/最初のプログラム.md#run-hello-world)でも確認できます。

```python
# 入力された文字列を number に保存します。
number = input("数字を入力してください: ")

# number に保存した文字列を表示します。
print(number)
```

`数字を入力してください:` と表示されたら、ターミナルへ `10` を入力して Enter を押してください。

表示例:

```text
数字を入力してください: 10
10
```

このとき `input()` が返す値は、数値の `10` ではなく、`"10"` という **文字列** です。数字を入力しても、`input()` は入力内容を文字列として返します。

コードで文字列を書くときは、`"10"` のように引用符で囲みます。`print()` の表示にはその引用符が付かないため、画面の `10` だけでは文字列か数値かを見分けられません。

4-3〜4-5では、例を試すたびに次の操作をしてください。

1. VS Code で `calculation_trial.py` を開き、内容全体を、試したい例のコードへ置き換えてください。
2. Windows / Linux では **Ctrl + S**、macOS では **Command + S** を押して保存してください。
3. VS Code の **表示（View）→ ターミナル（Terminal）** を選び、4-2で保存先へ移動したターミナルを開いてください。
4. Windows では `python calculation_trial.py`、macOS / Linux では `python3 calculation_trial.py` と入力してください。
5. Enter キーを押してください。

入力待ちの案内が表示されたら、その例に書かれた数字を入力してください。数字を1つ入力するたびに、Enter キーを押してください。

## 4-3. まず、文字列同士で足してみる

2つの入力を、そのまま `+` で足してみます。

```python
# 1つ目の入力を文字列のまま number1 に保存します。
number1 = input("1つ目の数字を入力してください: ")

# 2つ目の入力を文字列のまま number2 に保存します。
number2 = input("2つ目の数字を入力してください: ")

# number1 と number2 の文字列をつなげ、その結果を answer に保存します。
answer = number1 + number2

# answer に保存した文字列を表示します。
print("答えは", answer, "です")
```

実行して、1つ目に `10`、2つ目に `20` を入力してください。

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
答えは 1020 です
```

`number1` には `"10"`、`number2` には `"20"` が入っています。文字列同士の `+` は文字をつなげるので、`"10"` の後ろに `"20"` が続いて `"1020"` になります。

入力を使わずに同じことを書いても、結果は同じです。

```python
# 文字列 "10" と "20" をつなげて answer に保存します。
answer = "10" + "20"

# answer に保存した文字列を表示します。
print(answer)
```

表示結果:

```text
1020
```

## 4-4. 10 と 20 を足して 30 にする

今回の題材は、入力した2つの数字を足すプログラムです。2と3を入力すると、足した結果の **5** を表示するプログラムです。

コードに数値を直接書く場合は、引用符を付けずに書いてください。

```python
# 整数の 10 と 20 を足して answer に保存します。
answer = 10 + 20

# answer に保存した計算結果を表示します。
print(answer)
```

表示結果:

```text
30
```

見た目が似ていても、コードでは次の違いがあります。

| コードに書いた値 | 種類 | `+` の働き |
| --- | --- | --- |
| `"10"` と `"20"` | 文字列 | 文字をつなげて `"1020"` にする |
| `10` と `20` | 整数 | 足し算して `30` にする |

ただし、利用者が入力した数字に合わせて計算したいので、コードに `10 + 20` と固定して書く方法では対応できません。

このプログラムは、入力から受け取った文字列を数値へ変換してから足します。今回は整数を使うため、`int()` で変換するコードです。

`int("10")` は文字列 `"10"` を整数の `10` に変換します。`int("20")` も同じように整数の `20` に変換します。

```python
# 文字列 "10" と "20" をそれぞれ整数に変換し、足した結果を answer に保存します。
answer = int("10") + int("20")

# answer に保存した計算結果を表示します。
print(answer)
```

表示結果:

```text
30
```

## 4-5. 入力した数字で足し算する

このコードで、プログラムは引用符で囲んで直接書いた文字列の代わりに、`input()` の結果を `int()` へ渡します。

次のコードを `calculation_trial.py` に書いて保存し、実行してください。同じ内容の完成サンプルは [simple_addition.py](./simple_addition.py) にあります。`simple` は「簡単な」、`addition` は「足し算」という意味です。

```python
# 1つ目の入力を受け取り、int() で整数に変換して number1 に保存します。
number1 = int(input("1つ目の数字を入力してください: "))

# 2つ目の入力も整数に変換して number2 に保存します。
number2 = int(input("2つ目の数字を入力してください: "))

# number1 と number2 を足し、その結果を answer に保存します。
answer = number1 + number2

# answer に保存した計算結果を表示します。
print("答えは", answer, "です")
```

Pythonは `int(input(...))` の内側の `input(...)` から先に処理して入力を受け取ります。次に、その文字列を外側の `int(...)` で整数へ変換します。

1つ目に `10`、2つ目に `20` を入力した場合:

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
答えは 30 です
```

整数へ変換した値を `number1` と `number2` に保存しているので、`number1 + number2` が数値の足し算になります。

---

## 4-6. 計算結果も変数に入れられる

足した結果は、このあと表示するために残しておきたいので、`answer` に保存してください。

```python
# number1 と number2 を足し、その結果を answer に保存します。
answer = number1 + number2
```

これで、`number1 + number2` の計算結果が `answer` に入ります。

たとえば、

```text
number1 → 12
number2 → 8
```

なら、

```text
answer → 20
```

となります。

変数には、利用者が入力した値だけでなく、
**計算した結果も保存できます。**

## 4-7. よく使う計算記号

Pythonでは、次のような記号で計算できます。

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `+` | 足し算 | `10 + 3` |
| `-` | 引き算 | `10 - 3` |
| `*` | 掛け算 | `10 * 3` |
| `/` | 割り算 | `10 / 3` |
| `//` | 割り算の結果を小さい方の整数へ切り下げる | `10 // 3` |
| `%` | 余り | `10 % 3` |
| `**` | 累乗 | `2 ** 3` |

`+`、`-`、`*`、`/` は、それぞれ足し算・引き算・掛け算・割り算に使います。

整数同士で `//` を使うと、割り算の結果を小さい方の整数へ切り下げます。

| 計算 | 結果 |
| --- | --- |
| `10 // 3` | `3` |
| `-10 // 3` | `-4` |

`-10 / 3` は約 `-3.33` です。そこから小さい方の整数へ切り下げると `-4` になります。小数部分を単に取り除いた `-3` とは異なります。

この動作は、[Python公式資料の算術演算の説明](https://docs.python.org/ja/3/reference/expressions.html#binary-arithmetic-operations)でも確認できます。

## 4-8. 小数を扱いたいとき

`int()` は整数へ変換します。

小数を扱いたい場合は `float()` を使ってください。

```python
# 入力された文字列を float() で数値に変換し、price に保存します。
price = float(input("値段を入力してください: "))
```

たとえば、

```text
12.5
```

のような値を入力できます。

---

## 4-9. 数字以外を入力するとどうなる？

次のプログラムで、

```python
# 入力された文字列を int() で整数に変換し、number に保存します。
number = int(input("数字を入力してください: "))
```

としたときに、

```text
abc
```

のような数字ではない文字を入力すると、エラーになります。

`int()` に渡す文字列には、整数として読める数字を書いてください。`abc` など数字以外の文字を渡すと、変換時にエラーになります。

## 4-10. 自分で変えてみる

足し算を掛け算に変えてみてください。

```python
# 1つ目の入力を受け取り、int() で整数に変換して number1 に保存します。
number1 = int(input("1つ目の数字を入力してください: "))

# 2つ目の入力も整数に変換して number2 に保存します。
number2 = int(input("2つ目の数字を入力してください: "))

# number1 と number2 を掛け、その結果を answer に保存します。
answer = number1 * number2

# answer に保存した計算結果を表示します。
print("答えは", answer, "です")
```

さらに `-` や `/` に変えて、結果がどうなるか試してみてください。
