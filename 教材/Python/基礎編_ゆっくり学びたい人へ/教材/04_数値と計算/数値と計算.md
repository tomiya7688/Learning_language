# 4. 数値と計算

120円のパンと80円の飲み物なら、合計は200円です。合計をコードへ直接書いて表示するだけでは、買う物や値段が変わるたびに、合計を自分で計算してコードを書き直すことになります。

> **「金額を入れたら、合計はパソコンに計算してほしい！」**

この章では、2つの金額を入力すると、合計金額を表示するプログラムを作ってください。前の章で使った入力に、足し算を加えます。

## 4-1. 合計金額を出すプログラムを保存する

VS Codeの **ファイル → 新しいテキストファイル** を選び、次のコード全体を書いてください。コード中の `int(...)` は、入力された数字の文字列を、120のように小数部分を持たない数（整数）へ変えるために使っています。入力から計算までの仕組みは、実行結果を見たあとで順に説明します。

[`simple_addition.py` の1〜14行](./simple_addition.py#L1-L14)

```python
# 1つ目の入力を文字列として受け取り、first_text という名前を付ける
first_text = input("1つ目の金額を入力してください: ")
# 2つ目の入力を文字列として受け取り、second_text という名前を付ける
second_text = input("2つ目の金額を入力してください: ")

# 入力された文字列を整数に変換し、計算に使う名前を付ける
first_price = int(first_text)
second_price = int(second_text)

# 2つの金額を足し、合計に total という名前を付ける
total = first_price + second_price

# ターミナルに合計金額を表示する
print("合計は", total, "円です")
```

**ファイル → 名前を付けて保存** を選び、第3章で使った学習用フォルダへ `simple_addition.py` という名前で保存してください。第3章の `greeting.py` は残してください。`simple_addition` は英語で「簡単な足し算」という意味です。

## 4-2. 120円と80円を入力してみる

1. エクスプローラー（Windows）、Finder（macOS）、ファイル管理アプリ（Linux）で、`simple_addition.py` を保存した学習用フォルダを開いてください。
2. 保存先の場所を表す文字列を「パス」といいます。次の方法で、学習用フォルダのパスをコピーしてください。
   - Windows：開いたフォルダの上部のアドレス欄をクリックし、Ctrl + Cを押してください。
   - macOS：Finderで学習用フォルダを選び、Option + Command + Cを押してください。
   - Linux（GNOMEの「ファイル」）：学習用フォルダを開き、Ctrl + L、Ctrl + Cの順に押してください。
3. VS Codeの **表示 → ターミナル** を選んでください。ターミナルは、実行するコマンドを入力する欄です。
4. 開いたターミナルに `cd "コピーした学習用フォルダのパス"` と入力してください。引用符の中を、手順2でコピーしたパスに置き換え、Enterキーを押してください。`cd` は、ターミナルで作業するフォルダを変えるコマンドです。
5. 保存先へ移動した同じターミナルに、Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力し、Enterキーを押してください。

コマンドはコードを書く編集欄へ入力しないでください。ターミナルに最初から表示されている `PS C:\...>` や `$` などの文字も入力しないでください。

`1つ目の金額を入力してください:` が表示されたら、同じターミナルに `120` と入力してEnterキーを押してください。続いて `2つ目の金額を入力してください:` が表示されたら、`80` と入力してEnterキーを押してください。`円` や引用符は入力しないでください。

```text
1つ目の金額を入力してください: 120
2つ目の金額を入力してください: 80
合計は 200 円です
```

合計を表示すると、プログラムは終了します。別の金額を計算するには、プログラムをもう一度起動します。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力してEnterキーを押してください。1つ目の案内に `150`、2つ目の案内に `100` と入力し、それぞれEnterキーを押してください。

```text
1つ目の金額を入力してください: 150
2つ目の金額を入力してください: 100
合計は 250 円です
```

コードの計算式を書き直さずに、入力した金額の合計を出せました。ここからの説明では、最初に試した `120` と `80` の場合を使います。

起動するコマンドで `can't open file` と表示された場合は、`simple_addition.py` の保存先とファイル名を確認し、この節の手順1からやり直してください。

## 4-3. 入力した数字を、計算に使う数値にする

### 入力された時点では、金額も文字列

[`simple_addition.py` の1〜4行](./simple_addition.py#L1-L4)

```python
# 1つ目の入力を文字列として受け取り、first_text という名前を付ける
first_text = input("1つ目の金額を入力してください: ")
# 2つ目の入力を文字列として受け取り、second_text という名前を付ける
second_text = input("2つ目の金額を入力してください: ")
```

`first` は「1つ目」、`second` は「2つ目」、`text` は「文字列」という意味で名前に使っています。`120` と入力すると `first_text` で文字列 `"120"` を使え、`80` と入力すると `second_text` で文字列 `"80"` を使えます。

第3章では、入力された名前を文字列のまま挨拶に使いました。`input(...)` は、数字を入力した場合も入力内容を文字列として受け取ります。

文字列同士の `+` は足し算ではなく、文字列をつなげる操作です。文字列 `"120"` と `"80"` を `+` でつなげると、文字列 `"12080"` になります。合計の200を計算するには、文字列を数値へ変える必要があります。

| 説明用の式 | Pythonが行う操作 | 結果 |
| --- | --- | --- |
| `"120" + "80"` | 文字列をつなげる | 文字列 `"12080"` |
| `120 + 80` | 数値を足す | 数値 `200` |

この表の式は違いを説明するための例です。`simple_addition.py` に追加するコードではありません。コードの中では、引用符の有無で文字列と数値を書き分けます。

### `int(...)` で、文字列を整数に変える

[`simple_addition.py` の6〜8行](./simple_addition.py#L6-L8)

```python
# 入力された文字列を整数に変換し、計算に使う名前を付ける
first_price = int(first_text)
second_price = int(second_text)
```

整数は、120や80のように小数部分を持たない数です。`int(first_text)` は、`first_text` で使える文字列 `"120"` を、整数の `120` へ変換します。変換した整数は、`first_price` であとから使えるようにしています。`price` は英語で「値段」という意味です。

同じように、`int(second_text)` は文字列 `"80"` を整数の `80` へ変換します。Pythonは変換した整数を、`second_price` で使えるようにします。文字列を受け取る行と整数へ変える行を分けて、入力から計算までの順序をコードでも追えるようにしています。

## 4-4. 2つの金額を足して表示する

[`simple_addition.py` の10〜14行](./simple_addition.py#L10-L14)

```python
# 2つの金額を足し、合計に total という名前を付ける
total = first_price + second_price

# ターミナルに合計金額を表示する
print("合計は", total, "円です")
```

`first_price + second_price` は、整数の `120` と `80` を足す式です。Pythonは足し算した結果の `200` を、`total` で使えるようにします。`total` は英語で「合計」という意味です。

`print("合計は", total, "円です")` は、文字列 `"合計は"`、計算結果の `200`、文字列 `"円です"` を、間に空白を入れてターミナルへ表示します。

```text
合計は 200 円です
```

変数は、入力内容だけでなく、計算結果をあとで表示するためにも使えます。このプログラムは、金額を尋ねる → 入力内容を整数に変える → 合計を計算する → 合計を表示する、という順に動きます。

## 4-5. 足し算を引き算に変える

500円を持っていて、120円のパンを買うと、残りはいくらでしょうか。入力と計算の流れを使って、残りの金額を計算してみてください。

VS Codeで `simple_addition.py` を開き、[元の1〜14行](./simple_addition.py#L1-L14)に当たる内容全体を次の練習用コードへ置き換えてください。質問と結果の表示も、合計ではなく残金を求める内容へ変えています。

```python
# 入力された所持金を、整数に変える前の文字列として受け取る
money_text = input("持っている金額を入力してください: ")
# 入力された代金を、整数に変える前の文字列として受け取る
price_text = input("買う物の金額を入力してください: ")

# 入力された文字列を整数に変換する
money = int(money_text)
price = int(price_text)

# 所持金から代金を引き、残りの金額を求める
remaining = money - price

# ターミナルに残りの金額を表示する
print("残りは", remaining, "円です")
```

`money` は「お金」、`remaining` は「残り」という意味で名前に使っています。`money - price` の `-` が引き算の記号です。

1. VS Codeで `simple_addition.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力し、Enterキーを押してください。

`持っている金額を入力してください:` と表示されたら `500` と入力してEnterキーを押してください。`買う物の金額を入力してください:` と表示されたら `120` と入力してEnterキーを押してください。

```text
持っている金額を入力してください: 500
買う物の金額を入力してください: 120
残りは 380 円です
```

残金を求める変更は、残したまま次の章へ進めます。第5章では別のプログラムを作ってください。

## 4-6. 数字を入力するときの注意

金額を尋ねる案内が出たターミナルには、`120` のように整数を入力してください。`120円` や `abc`、小数の `12.5` を入力すると、このプログラムは変換できず、ターミナルに `ValueError` というエラー名を表示して終了します。

入力をやり直すときは、VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。Windowsでは `python simple_addition.py`、macOS / Linuxでは `python3 simple_addition.py` と入力してEnterキーを押し、金額の案内が出てから整数を入力してEnterキーを押してください。

小数を計算するプログラムでは、`float(...)` で、入力された文字列を小数の計算に使える数値へ変えます。たとえば `float("12.5")` は数値の `12.5` になります。この章の円単位の計算では `int(...)` を使っています。

## 4-7. 今回の内容

- `input(...)` で受け取った入力内容は、数字でも文字列です。
- `int(...)` で整数の書かれた文字列を整数へ変えると、数値の計算に使えます。
- 数値同士の `+` は足し算、`-` は引き算です。文字列同士の `+` は文字列をつなげます。
- 計算結果にも名前を付け、あとの行で表示できます。

### ほかの計算記号を調べたいとき

数値の計算には、次の記号も使えます。必要な計算を書くときに参照してください。

| 記号 | 計算の意味 | 説明用の式と結果 |
| --- | --- | --- |
| `*` | 掛け算 | `120 * 2` → `240` |
| `/` | 割り算 | `120 / 2` → `60.0` |
| `//` | 割った結果を小さい方の整数へ切り下げる | `10 // 3` → `3`、`-10 // 3` → `-4` |
| `%` | 整数同士なら、割り算の余り | `10 % 3` → `1` |
| `**` | 累乗。同じ数を指定した回数掛ける計算 | `2 ** 3` → `8`（2 × 2 × 2） |

`//` は小数部分を取り除く操作とは異なります。`-10 / 3` は約−3.33なので、小さい方の整数へ切り下げると−4です。数値の計算規則は[Python公式資料](https://docs.python.org/ja/3/reference/expressions.html#binary-arithmetic-operations)で確認できます。表の式は説明用で、練習用ファイルへ追加するコードではありません。
