# 6. 繰り返し

同じ案内を3回表示するなら、表示するコードを3行書くこともできます。ところが「100回にして」となったら、同じ行を100行に増やすのは大変です。

> **「回数を変えたいだけなのに、何行も書き足すの？？？」**

この章では、利用者が決めた回数だけ「1回目です」「2回目です」のようなメッセージを表示するプログラムを作ります。Pythonは同じ処理を繰り返すため、コードに表示処理を書くのは1回だけです。表示回数を3回から100回へ変えるときは、利用者が入力する数を変えてください。

---

## 6-1. 今回作るもの

プログラムを実行すると、Pythonは「何回表示しますか:」と案内します。利用者は、案内の後ろに回数を入力してEnterキーを押してください。

```text
何回表示しますか: 3
```

たとえば、利用者が `3` を入力してEnterキーを押すと、Pythonは次の3行を表示します。

```text
1回目です
2回目です
3回目です
```

同じ文章を3回だけ表示するなら、次のように同じ `print()` を3回書けます。

```python
print("メッセージ")
print("メッセージ")
print("メッセージ")
```

しかし、10回、100回、1000回と増えていくと大変です。

そこで使うのが **繰り返し** です。

### なぜ繰り返しが必要なの？

3回くらいなら、同じ `print()` を3行書いても何とかなります。

では、

```text
「こんにちは」を1000回表示してください
```

と言われたらどうでしょうか。

繰り返しを使わない場合、

```python
print("こんにちは")
print("こんにちは")
print("こんにちは")
# このあとも延々と続く……
```

と、同じ処理を1000回書くことになります。

書くのも大変ですが、途中で「やっぱり2000回にして」と言われたらさらに大変です。

> **「1000回も書けんわ！そもそも今何個目？？？」**

となります。

繰り返しを使うと、**同じ処理をコードに1回だけ書き、必要な回数だけPythonに実行させられます**。

要するに、

> **同じ処理を何回も素直に書いたら日が暮れるから、1つにまとめて回している**

だけです。

---

## 6-2. 表示する回数を決めて繰り返す

[repeat_message.py](./repeat_message.py) を開いてください。

`repeat_message.py` の `repeat` は「繰り返す」、`message` は「メッセージ」という意味です。このファイル名は「メッセージを繰り返す」という内容を表しています。

`input()` は、プログラムの実行中に利用者の入力を受け取るPythonの書き方です。`int()` は、数字の文字を整数に変換するPythonの書き方です。

Pythonは、利用者が入力した回数を `int()` で整数に変換し、変数 `count` に保存します。英語の `count` は「回数」という意味です。

`for` は、並んだ値を1つずつ取り出しながら、字下げした処理を繰り返すPythonの書き方です。

`range(count)` は、0から `count - 1` までの整数を順番に用意します。Pythonは、その整数を変数 `i` に1つずつ入れます。

`f"..."` は、文字列の前に `f` を付ける書き方です。`{}` の中に変数や計算を書くと、Pythonはその値を文字列に入れます。次のコードでは、Pythonが `{i + 1}` を計算して「回目です」とつなげます。

```python
# Pythonは、利用者が入力した表示回数を整数に変換し、変数 count に保存します。
count = int(input("何回表示しますか: "))

# range(count) は、0から count - 1 までの整数を for 文へ順番に渡します。
for i in range(count):
    # Pythonは、i + 1 を計算して、表示番号を1回目から始めます。
    print(f"{i + 1}回目です")
```

---

## 6-3. `for` とは

`for` は、並んだ値を1つずつ取り出しながら、字下げした処理を繰り返すPythonの書き方です。

次のコードでは、

```python
for i in range(count):
    print(f"{i + 1}回目です")
```

Pythonは、`range(count)` が返す `count` 個の整数を順番に使います。そのため、字下げした `print()` を `count` 回実行します。

---

## 6-4. `range()` とは

`range()` は、`for` が順番に使う連続した整数を用意します。

たとえば、

```python
range(3)
```

では、

```text
0
1
2
```

という3つの値を順番に使えます。`range(3)` は、0から始めて3になる前に止まるため、3個の値を用意します。

---

## 6-5. `i` は毎回変わる

次のコードでは、

```python
for i in range(3):
    print(i)
```

実行結果は、

```text
0
1
2
```

になります。

`i` は、`range(3)` が返す整数を繰り返すたびに1つずつ受け取る変数です。Pythonは、1回目に `0`、2回目に `1`、3回目に `2` を `i` に入れます。

このコードでは、変数名を短く `i` にしています。`i` は繰り返しでよく使われる名前ですが、Pythonがこの名前を要求しているわけではありません。

`number` は英語で「数字」を意味します。変数名を `number` に変えても、同じように動きます。たとえば、

```python
for number in range(3):
    print(number)
```


---

## 6-6. なぜ `i + 1` と書くの？

今回のサンプルでは、

```python
print(f"{i + 1}回目です")
```

と書いています。

`range(count)` で最初に入る値は `0` です。

Pythonが `i` の値をそのまま表示すると、

```text
0回目です
1回目です
2回目です
```

となってしまいます。

表示する回数は1回から数えるため、Pythonは表示するときに `i + 1` を計算します。`i` が `0` のとき、Pythonは `1回目です` と表示します。

---

## 6-7. `f"..."` とは

`print(f"{i + 1}回目です")` では、計算結果を文字列に入れるため、引用符の前に `f` を付けています。

```python
print(f"{i + 1}回目です")
```

引用符の前に `f` を付ける書き方を **f文字列** と呼びます。

f文字列では、`{}` の中に変数や計算を書くと、Pythonがその値を文字列へ入れます。

変数 `name` は名前を保存するための変数で、この例では文字列 `Python` を保存しています。英語の `name` は「名前」という意味です。

たとえば、

```python
name = "Python"
print(f"{name}を勉強します")
```

と書くと、

```text
Pythonを勉強します
```

と表示されます。

---

## 6-8. 繰り返す処理はインデントする

`for` の行の次に繰り返す処理を書くときは、`for` の行より右へ字下げしてください。

```python
for i in range(3):
    print(i)
```

Pythonは、`for` の行より右へ字下げされた `print(i)` を繰り返します。

次のコードを実行すると、`for` の中で繰り返す行が字下げされていないため、Pythonはエラーを表示します。

```python
for i in range(3):
print(i)
```

この教材では、インデントには **半角スペース4個** を基本として使います。

---

## 6-9. `:` を忘れない

`for` の行の最後にも `:` が必要です。

```python
for i in range(3):
```

`for` の行末から `:` を抜くと、次のようになります。

```python
for i in range(3)
    print(i)
```

このコードを実行すると、Pythonはエラーを表示します。

---

## 6-10. 繰り返しの外に処理を書く

次のコードで、`for` の内側と外側にある処理の違いを確認します。

```python
for i in range(3):
    print(i)

print("終わりました")
```

Pythonは、字下げされた `print(i)` を3回実行します。

```python
print("終わりました")
```

この `print("終わりました")` の行は、`for` の外に書かれています。Pythonは、3回の繰り返しを終えたあとにこの行を1回だけ実行します。実行結果は次のとおりです。

```text
0
1
2
終わりました
```

## 6-11. 自分で変えてみる

`repeat_message.py` のコードを次のように書き換えると、利用者が入力した回数だけ応援メッセージを表示できます。

```python
count = int(input("何回応援しますか: "))

for i in range(count):
    print(f"{i + 1}回目: がんばれ！")
```

利用者に回数を入力してもらわず、コードに回数を書くこともできます。次のコードでは、Pythonが「こんにちは」を5回表示します。

```python
for i in range(5):
    print("こんにちは")
```

---

## 6-12. `while` という繰り返しもある

Pythonには `for` のほかに `while` という繰り返しもあります。

`while` は、条件が成り立つ間、字下げした処理を繰り返すPythonの書き方です。条件が成り立たなくなると、Pythonは繰り返しを終えます。

ゲームでは、次のような処理に `while` を使います。

- ゲームの処理は、プレイヤーのHPが0になるまで続きます。
- プログラムは、正しい入力があるまで利用者から入力を受け取ります。

`while` の条件がいつまでも成り立つと、Pythonは繰り返しを終えません。

この章では、まず `for` と `range()` を使った繰り返しを中心に扱います。

---

## 6-13. 今回の内容

この章で扱った内容をまとめます。

1. `for` で同じ処理を繰り返せる
2. `range()` で繰り返す回数を作れる
3. `range(3)` では `0`、`1`、`2` が順番に使われる
4. 繰り返しのたびに変数の値が変わる
5. 繰り返す処理はインデントする
6. `for` の行末には `:` が必要
7. `while` という別の繰り返し方法もある
