# 6. 繰り返し

5章では、入力した点数を `score` に入れ、点数に合うメッセージを1つ選んで表示しました。次は、同じメッセージを何回も表示したい場面を考えてください。これまでの `print()` だけで3回表示するなら、同じ行を3回書くことになります。

**これまでの書き方を使った説明用の例**です。

```python
# 「メッセージ」とターミナルに表示する処理を3回書く
print("メッセージ")
print("メッセージ")
print("メッセージ")
```

この例は3回なので書けます。ところが「100回にして」となったら、同じ行を100行に増やすことになり、大変です。

> **「回数を変えたいだけなのに、何行も書き足すの？？？」**

この章では、利用者が決めた回数だけ「1回目です」「2回目です」のようなメッセージを表示するプログラムを作ります。回数を受け取る部分は、5章で点数を受け取った `int(input(...))` と同じ書き方です。回数だけ表示を繰り返すために、表示するコードは1回だけ書きます。表示回数を3回から100回へ変えるときは、プログラムを実行したあとに入力する数を変えてください。

---

## 6-1. 今回作るもの

次は、完成したプログラムの実行例です。プログラムが「何回表示しますか:」と尋ね、利用者が `3` と入力して Enter キーを押すと、プログラムは次の3行を表示します。ファイルの作成と実行は6-2で行うので、ここでは入力しないでください。

```text
何回表示しますか: 3
1回目です
2回目です
3回目です
```

この例の `3` は利用者が入力する数字で、それ以外の文章はプログラムが表示するものです。

冒頭の例のように、同じ `print()` を3回書くことはできます。しかし、10回、100回、1000回と増えていくと大変です。

そこで使うのが **繰り返し** です。同じ処理を決めた回数だけ実行する書き方を、繰り返しと呼びます。

### なぜ繰り返しが必要なの？

3回くらいなら、同じ `print()` を3行書いても何とかなります。

では、

```text
「こんにちは」を1000回表示してください
```

と言われたらどうでしょうか。

繰り返しを使わない場合、

```python
# 「こんにちは」とターミナルに表示する処理を、1000回になるまで書き続ける
print("こんにちは")
print("こんにちは")
print("こんにちは")
# このあとも延々と続く……
```

と、同じ処理を1000回書くことになります。

書くのも大変ですが、途中で「やっぱり2000回にして」と言われたらさらに大変です。

> **「1000回も書けんわ！そもそも今何個目？？？」**

となります。

繰り返しを使うと、**同じ処理をコードに1回だけ書き、決めた回数だけPythonに実行させられます**。

要するに、

> **同じ処理を何回も素直に書いたら日が暮れるから、1つにまとめて回している**

だけです。

## 6-2. 表示する回数を決めて繰り返す

VS Codeの **ファイル → 新しいテキストファイル** を選び、下のコード全体を書いてください。保存する名前は `repeat_message.py` にします。

`repeat_message.py` の `repeat` は「繰り返す」、`message` は「メッセージ」という意味です。このファイル名は「メッセージを繰り返す」という内容を表しています。

コードを書く前に、使う書き方を確認します。

- 回数の受け取り：5章と同じ `int(input(...))` で、入力された文字列を整数に変えます。英語で「回数」を意味する `count` という変数に入れます。
- 繰り返し：`for` は、`range(count)` が用意する整数を1つずつ取り出し、字下げした処理を取り出した回数だけ実行するPythonの書き方です。行末には `:` を付けます。
- 整数の受け取り先：`range(count)` は、0から `count - 1` までの整数を順番に用意します。`for i in range(count):` と書くと、Pythonは用意された整数を1つずつ変数 `i` に入れます。
- 表示：`f"..."` は、文字列の前に `f` を付ける書き方です。`{}` の中に変数や計算を書くと、Pythonはその結果を文字列に入れます。`{i + 1}` と書くと、Pythonは `i` に1を足した結果を「回目です」の前に入れます。

このコードの元ファイル：[`repeat_message.py` の 1〜9行](./repeat_message.py#L1-L9)。

```python
# count は「回数」という意味の変数
# count に「何回表示しますか: 」と表示して入力された文字列を整数にして入れる
count = int(input("何回表示しますか: "))

# i は、繰り返しのたびに整数を1つ受け取る変数
# range(count) が用意する0からcount - 1までの整数を、i に1つずつ入れて繰り返す
for i in range(count):
    # i + 1 を計算して、「1回目です」のように表示する
    print(f"{i + 1}回目です")
```

## 6-3. `for` とは

`for` は、`range(count)` が用意した整数を1つずつ取り出し、取り出すたびに字下げした処理を実行するPythonの書き方です。`for` の行末には `:` を付け、繰り返す処理は次の行から半角スペース4個で字下げして書きます。

次のコードでは、`range(count)` が用意する `count` 個の整数を、`for` が1つずつ `i` に入れます。

このコードの元ファイル：[`repeat_message.py` の 7〜9行](./repeat_message.py#L7-L9)。

```python
# range(count) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(count):
    # i + 1 を計算して、「1回目です」のように表示する
    print(f"{i + 1}回目です")
```

整数を `i` に入れるたびに、Pythonは字下げした `print()` を1回実行します。整数は `count` 個あるため、`print()` が実行される回数は `count` 回です。

---

## 6-4. `range()` とは

`range()` は、`for` が1つずつ取り出す連続した整数を用意します。`()` の中に回数を指定すると、0から始めて、その回数の1つ前までの整数を用意します。

たとえば、次の `range(3)` は、`for` が取り出す整数を用意する書き方です。

```python
# 0から2までの3つの整数を用意する
range(3)
```

`for` は、この `range(3)` から次の3つの値を順番に取り出せます。

```text
0
1
2
```

`range(3)` は、0から始めて3になる前に止まるため、3個の値を用意します。

---

## 6-5. `i` は毎回変わる

次のコードでは、`range(3)` が用意する整数を `i` に入れて、`print(i)` で表示します。これは `i` の値の変化を確かめる説明用の例で、`repeat_message.py` に追加するコードではありません。

```python
# range(3) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(3):
    # i の値をターミナルに表示する
    print(i)
```

このコードを実行すると、ターミナルに次の3行が表示されます。

```text
0
1
2
```

`i` は、`range(3)` が用意する整数を繰り返すたびに1つずつ受け取る変数です。Pythonは、1回目に `0`、2回目に `1`、3回目に `2` を `i` に入れます。

このコードでは、変数名を短く `i` にしています。`i` は繰り返しでよく使われる名前ですが、Pythonがこの名前を要求しているわけではありません。

`number` は英語で「数字」を意味します。次のように変数名を `number` に変えても、同じ3行を表示します。

```python
# range(3) が用意する整数を、number に1つずつ入れて繰り返す
for number in range(3):
    # number の値をターミナルに表示する
    print(number)
```

```text
0
1
2
```

## 6-6. なぜ `i + 1` と書くの？

今回の `repeat_message.py` では、

このコードの元ファイル：[`repeat_message.py` の 9行](./repeat_message.py#L9-L9)。

```python
# i + 1 を計算して、「1回目です」のように表示する
print(f"{i + 1}回目です")
```

と書いています。

`range(count)` で最初に入る値は `0` です。

`{i + 1}` ではなく `{i}` と書いて、Pythonが `i` の値をそのまま表示すると、`count` が3のとき次のようになります。

```text
0回目です
1回目です
2回目です
```

表示する回数は1回から数えるため、`{i + 1}` と書いて、Pythonに `i` に1を足した結果を表示させます。`i` が `0` のとき、Pythonは `1回目です` と表示します。

## 6-7. `f"..."` とは

`print(f"{i + 1}回目です")` では、計算結果を文字列に入れるため、引用符の前に `f` を付けています。

このコードの元ファイル：[`repeat_message.py` の 9行](./repeat_message.py#L9-L9)。

```python
# i + 1 を計算して、「1回目です」のように表示する
print(f"{i + 1}回目です")
```

引用符の前に `f` を付ける書き方を **f文字列** と呼びます。

f文字列では、`{}` の中に変数や計算を書くと、Pythonがその結果を文字列へ入れます。

次は、f文字列の働きを確かめる説明用の例で、`repeat_message.py` に追加するコードではありません。変数 `name` は名前を保存するための変数で、この例では文字列 `Python` を保存しています。英語の `name` は「名前」という意味です。

```python
# name に文字列 Python を入れる
name = "Python"
# name の中身を {} の位置に入れて、ターミナルに表示する
print(f"{name}を勉強します")
```

このコードを実行すると、ターミナルに次の1行が表示されます。

```text
Pythonを勉強します
```

## 6-8. 繰り返す処理はインデントする

`for` の行の次に繰り返す処理を書くときは、`for` の行より右へ字下げしてください。この行頭の空白による字下げを **インデント** と呼びます。Pythonは、インデントされた行を、`for` の繰り返す処理として扱います。

```python
# range(3) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(3):
    # i の値をターミナルに表示する
    print(i)
```

Pythonは、`for` の行より右へ字下げされた `print(i)` を繰り返します。

次のコードを実行すると、`for` の中で繰り返す行が字下げされていないため、Pythonは `IndentationError` というエラーを表示します。これは動かない例で、ファイルに書くコードではありません。

```python
# range(3) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(3):
# i の値をターミナルに表示する
print(i)
```

エラーを表示したときは、`for` の次の行の先頭に半角スペース4個を入れてください。

この教材では、インデントには **半角スペース4個** を基本として使います。

---

## 6-9. `:` を忘れない

`for` の行の最後にも `:` が必要です。

```python
# range(3) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(3):
```

`for` の行末から `:` を抜くと、次のようになります。

```python
# 行末に : がないため、Pythonがエラーを表示する
for i in range(3)
    print(i)
```

このコードを実行すると、Pythonは `SyntaxError` というエラーを表示します。エラーを表示したときは、`for` の行末に `:` を書き足してください。

## 6-10. 繰り返しの外に処理を書く

次のコードで、`for` の内側と外側にある処理の違いを確認します。これは違いを確かめる説明用の例で、`repeat_message.py` に追加するコードではありません。

```python
# range(3) が用意する整数を、i に1つずつ入れて繰り返す
for i in range(3):
    # 字下げされているので、繰り返すたびに i の値を表示する
    print(i)

# 字下げされていないので、繰り返しが終わったあとに1回だけ表示する
print("終わりました")
```

Pythonは、字下げされた `print(i)` を3回実行します。

```python
print("終わりました")
```

この `print("終わりました")` の行は、`for` の外に書かれています。Pythonは、3回の繰り返しを終えたあとにこの行を1回だけ実行します。実行結果は次のとおりです。

```text
0
1
2
終わりました
```

## 6-12. 繰り返しは何に使える？

決めた回数だけ表示する書き方は、次のような場面でも使えます。

- 同じ表示を何回も出す：「こんにちは」を5回、1000回と表示する。
- 一覧のデータを順番に処理する：10人分の点数を1人ずつ取り出して、5章の条件分岐で合格かどうかを調べる。
- 同じ部品を決めた数だけ並べる：ゲームで同じ形の敵を5体並べる。

どの場面でも、同じ処理を書くのは1回だけです。回数が変わっても、書き換えるのは回数だけです。

## 6-13. `while` という繰り返しもある

Pythonには `for` のほかに `while` という繰り返しもあります。

`while` は、条件が成り立つ間、字下げした処理を繰り返すPythonの書き方です。条件が成り立たなくなると、Pythonは繰り返しを終えます。

ゲームでは、次のような処理に `while` を使います。

- ゲームの処理は、プレイヤーのHPが0になるまで続きます。
- プログラムは、正しい入力があるまで利用者から入力を受け取ります。

`while` の条件がいつまでも成り立つと、Pythonは繰り返しを終えません。

この章で作った `repeat_message.py` は、`for` と `range()` を使って回数を決めて繰り返しました。`while` は、回数が決まっていない繰り返しに使います。
