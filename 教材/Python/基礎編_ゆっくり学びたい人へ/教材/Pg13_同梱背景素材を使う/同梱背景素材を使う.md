# Pg13. pygame「同梱背景素材を使う」

Pg12では、丸い星をコードで描き、下へ流れる背景にしました。背景を宇宙の絵に替えたいところです。

> **「ずっと丸だけってのも寂しいな！！！」**

この章では、同梱の背景画像を読み込み、同じ画像を2枚並べて下へ流してください。背景の動きと画像の読み込みを、それぞれのファイルで扱います。

## 起動してから1回の更新が終わるまで

`bundled_background.py` の `main()` がpygameを初期化し、`Game()` を作って `run()` を呼びます。`Game` は画面と時計を持ち、入力・更新・描画を順に呼びます。`Battle` は1回の戦闘の自機・敵・弾を管理します。移動と描画は各機体や弾自身のメソッド（クラス内の関数）へ任せます。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

入口の最後の `if __name__ == "__main__":` は、直接実行したときだけmain()を呼ぶ条件です。補助ファイルを読み込んだだけではゲームを起動しません。`finally` のpygame.quit()はエラーが起きた場合も終了時の片付けを行います。

### 入口のコード

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # game はゲーム全体。起動・繰り返し・画面切り替えを担当します。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# __name__ == '__main__' が成り立つなら
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 画像を読む処理を `resources.py` に置く

背景画像を読む指定を戦闘の更新に混ぜず、`resources.py`（素材の読み込み）へ置きます。`load_image` は画像を読み込んで返す関数です。

`Path(__file__).parent` は、この `resources.py` が入っているフォルダです。その下の `assets`（素材）から `space_background.png` を読みます。ターミナルをどこから開いても、画像の場所はこのファイルから決まります。

`pygame.image.load` で画像を読み、`convert_alpha()` で透明部分も扱える形式へ変換します。この処理はゲーム画面を作った後に呼びます。`size`（大きさ）を指定したときは `pygame.transform.scale` でその大きさへ変えます。背景には幅640、高さ480を指定します。

`Background` は同じ画像をy=0とy=-480へ2枚描き、1回の更新で2ピクセル下へ動かします。片方の上端が480に達したら、もう片方の480ピクセル上へ戻します。2枚が接しているため、画面に隙間が空きません。

## 設定値の場所と意味

`settings.py` の値はこの章の初期設定です。位置と大きさの単位はピクセル、速さは1回の更新で動くピクセル数、間隔は更新回数です。最大60回/秒の場合、90回は約1.5秒、120回は約2秒です。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | 画面の幅 | `640` |
| `HEIGHT` | 画面の高さ | `480` |
| `FPS` | 1秒あたりの更新回数の上限 | `60` |
| `PLAYER_X` | 自機の最初の中心の横位置 | `320` |
| `PLAYER_Y` | 自機の最初の中心の縦位置 | `400` |
| `PLAYER_SPEED` | 自機の移動の速さ | `5` |
| `BULLET_SPEED` | 自機の弾の速さ（発射時に負にして上へ動かす） | `8` |
| `ENEMY_SPEED` | 通常の敵の移動の速さ | `1` |
| `PLAYER_HP` | 自機の最初の体力 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾の速さ | `4` |
| `SPAWN_POSITIONS_X` | 出現順に並べた敵の横位置 | `(120, 320, 520, 220, 420, 100, 540)` |
| `SPAWN_INTERVAL` | 敵の出現間隔 | `90` |
| `ENEMY_FIRE_INTERVALS` | 出現順に並べた敵ごとの発射間隔 | `(60, 90, 120, 75, 105, 80, 110)` |
| `BOSS_X` | ボスの中心の横位置 | `320` |
| `BOSS_Y` | ボスの中心の縦位置 | `90` |
| `BOSS_HP` | ボスの最初の体力 | `50` |
| `BOSS_BULLET_SPEED` | ボスの弾の速さ | `4` |
| `BOSS_FIRE_INTERVAL` | ボスの発射間隔 | `120` |
| `BOSS_BULLET_WIDTH` | ボスの弾の幅 | `48` |
| `BOSS_BULLET_HEIGHT` | ボスの弾の高さ | `48` |
| `BACKGROUND_SPEED` | 背景が下へ流れる速さ | `2` |

自機の中心(320, 400)は画面の中央より下、ボスの中心(320, 90)は上側です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。機体の `rect` は位置と大きさを一緒に持ち、移動・描画・命中に同じ長方形を使います。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `resources.py` の `load_image`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# load_image の処理を定義する
def load_image(name, size=None):
    # path は画像ファイルの場所です。
    # path に Path(__file__).parent / 'assets' / name を入れる
    path = Path(__file__).parent / "assets" / name
    # image は画像。画面へ描く内容を持ちます。
    # image に pygame.image.load(str(path)).convert_alpha() を入れる
    image = pygame.image.load(str(path)).convert_alpha()
    # size is not None が成り立つなら
    if size is not None:
        # image は画像。画面へ描く内容を持ちます。
        # image に pygame.transform.scale(image, size) を入れる
        image = pygame.transform.scale(image, size)
    # image を返す
    return image
```

### `background.py` の `Background`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# Background という型を定義する
class Background:
    # __init__ の処理を定義する
    def __init__(self):
        # image は画像。画面へ描く内容を持ちます。
        # self.image に load_image('space_background.png', (settings.WIDTH, settings.HEIGHT)) を入れる
        self.image = load_image("space_background.png", (settings.WIDTH, settings.HEIGHT))
        # y1 は1枚目の背景の上端の位置です。
        # self.y1 に 0 を入れる
        self.y1 = 0
        # y2 は2枚目の背景の上端の位置です。
        # self.y2 に -settings.HEIGHT を入れる
        self.y2 = -settings.HEIGHT

    # update の処理を定義する
    def update(self):
        # self.y1 に settings.BACKGROUND_SPEED を足す
        self.y1 += settings.BACKGROUND_SPEED
        # self.y2 に settings.BACKGROUND_SPEED を足す
        self.y2 += settings.BACKGROUND_SPEED
        # self.y1 >= settings.HEIGHT が成り立つなら
        if self.y1 >= settings.HEIGHT:
            # y1 は1枚目の背景の上端の位置です。
            # self.y1 に self.y2 - settings.HEIGHT を入れる
            self.y1 = self.y2 - settings.HEIGHT
        # self.y2 >= settings.HEIGHT が成り立つなら
        if self.y2 >= settings.HEIGHT:
            # y2 は2枚目の背景の上端の位置です。
            # self.y2 に self.y1 - settings.HEIGHT を入れる
            self.y2 = self.y1 - settings.HEIGHT

    # draw の処理を定義する
    def draw(self, screen):
        # screen.blit(self.image, (0, self.y1)) を実行する
        screen.blit(self.image, (0, self.y1))
        # screen.blit(self.image, (0, self.y2)) を実行する
        screen.blit(self.image, (0, self.y2))
```

## 実行したときの画面と操作

同梱の背景画像が下へ流れます。

キー操作はゲームのウィンドウをクリックしてから行ってください。

Spaceキーは押して離すたびに1発出ます。矢印キーは押している間、移動します。

## 保存先へ移動して、入口ファイルを実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の入口ファイルを保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe bundled_background.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python bundled_background.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。

## 1か所変えて比べる

VS Codeで `settings.py` を開き、Windows / LinuxはCtrl + F、macOSはCommand + Fで `BACKGROUND_SPEED = 2` を検索してください。背景の速さを2から1へ変更してください。Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。

再実行は、VS Codeの **表示 → ターミナル** で先ほどのターミナルを開いてください。Windowsは `.\.venv\Scripts\python.exe bundled_background.py`、macOS / Linuxは `.venv/bin/python bundled_background.py` を入力してEnterキーを押してください。変更前と比べてください。閉じる前のウィンドウがあれば、先に閉じてください。
