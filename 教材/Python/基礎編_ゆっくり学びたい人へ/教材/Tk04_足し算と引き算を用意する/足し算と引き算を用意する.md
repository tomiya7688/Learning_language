# Tk4. 足し算と引き算を用意する

Tk3で2つの数字を足せるようになりました。でも、買い物のあとに残る金額を調べたくても、引き算を選べません。

> **「足し算しかできんやん！電卓名乗るな！！！」**

この章では足し算と引き算を選ぶボタンを用意してください。計算を選んでから=ボタンを押すと、選んだ計算の答えが表示されます。

ボタンは、次の3つです。

```text
[ + ]
[ - ]
[ = ]
```

---

## Tk4-1. 今回作るもの

[app.py](./app.py) を開いてください。

このコードの元ファイル：[`app.py` の 1〜131行](./app.py#L1-L131)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# selected_operator に「+」を入れる
selected_operator = "+"


# 足し算を選び、選択中の表示を更新する select_addition を定義する
def select_addition():
    # 関数の外にある selected_operator を、この関数内の代入先として指定する
    global selected_operator

    # selected_operator に「+」を入れる
    selected_operator = "+"
    # operator_label の表示を「選択中: +」に変える
    operator_label.config(text="選択中: +")


# 引き算を選び、選択中の表示を更新する select_subtraction を定義する
def select_subtraction():
    # 関数の外にある selected_operator を、この関数内の代入先として指定する
    global selected_operator

    # selected_operator に「-」を入れる
    selected_operator = "-"
    # operator_label の表示を「選択中: -」に変える
    operator_label.config(text="選択中: -")


# 入力された2つの数字を選択中の演算子で計算し、答えを表示する calculate を定義する
def calculate():
    # number1_text に number1_entry に入力された文字列を入れる
    number1_text = number1_entry.get()
    # number2_text に number2_entry に入力された文字列を入れる
    number2_text = number2_entry.get()

    # number1_text または number2_text が空の文字列なら、次の処理を実行する
    if number1_text == "" or number2_text == "":
        # result_label の表示を「数字を2つ入力してください」に変える
        result_label.config(text="数字を2つ入力してください")
        # calculate の処理をここで終える
        return

    # number1 に number1_text を float で数値に変換した値を入れる
    number1 = float(number1_text)
    # number2 に number2_text を float で数値に変換した値を入れる
    number2 = float(number2_text)

    # selected_operator が「+」なら、次の処理を実行する
    if selected_operator == "+":
        # answer に number1 と number2 を足した値を入れる
        answer = number1 + number2
    # selected_operator が「+」でなければ、次の処理を実行する
    else:
        # answer に number1 から number2 を引いた値を入れる
        answer = number1 - number2

    # result_label の表示を「答え: 」と answer の値を含む文字列に変える
    result_label.config(text=f"答え: {answer}")


# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()
# window のタイトルを「足し算と引き算を用意する」にする
window.title("足し算と引き算を用意する")
# window の大きさを横400、縦340にする
window.geometry("400x340")

# number1_label に window 内で「1つ目の数字」と表示するラベルを入れる
number1_label = tkinter.Label(window, text="1つ目の数字")
# number1_label を window 内に配置する
number1_label.pack()

# number1_entry に window 内の1行の入力欄を入れる
number1_entry = tkinter.Entry(window)
# number1_entry を window 内に配置する
number1_entry.pack()

# number2_label に window 内で「2つ目の数字」と表示するラベルを入れる
number2_label = tkinter.Label(window, text="2つ目の数字")
# number2_label を window 内に配置する
number2_label.pack()

# number2_entry に window 内の1行の入力欄を入れる
number2_entry = tkinter.Entry(window)
# number2_entry を window 内に配置する
number2_entry.pack()

# operator_label に window 内で「選択中: +」と表示するラベルを入れる
operator_label = tkinter.Label(window, text="選択中: +")
# operator_label を window 内に配置する
operator_label.pack()

# 足し算
# addition_button に window 内で「+」と表示し、押すと select_addition を呼ぶボタンを入れる
addition_button = tkinter.Button(
    window,
    text="+",
    command=select_addition
)
# addition_button を window 内に配置する
addition_button.pack()

# 引き算
# subtraction_button に window 内で「-」と表示し、押すと select_subtraction を呼ぶボタンを入れる
subtraction_button = tkinter.Button(
    window,
    text="-",
    command=select_subtraction
)
# subtraction_button を window 内に配置する
subtraction_button.pack()

# 計算する
# equals_button に window 内で「=」と表示し、押すと calculate を呼ぶボタンを入れる
equals_button = tkinter.Button(
    window,
    text="=",
    command=calculate
)
# equals_button を window 内に配置する
equals_button.pack()

# result_label に window 内で「答え:」と表示するラベルを入れる
result_label = tkinter.Label(window, text="答え:")
# result_label を window 内に配置する
result_label.pack()

# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

今回は、

```text
1つ目の数字を入力
↓
2つ目の数字を入力
↓
+ か - を選ぶ
↓
= を押す
↓
答えを表示
```

これが、この電卓の操作の順番です。

## Tk4-2. 何が新しいの？

Tk3では、

このコードの元ファイル：[`app.py` の 53〜53行](./app.py#L53-L53)。

```python
# answer に number1 と number2 を足した値を入れる
answer = number1 + number2
```

と、計算方法が最初から決まっていました。

Tk4では、

```text
+
か
-
```

これが、あとから演算子を選ぶ操作です。

つまり今度は、

> **「今どの計算を選んでいるか」を覚えておく必要があります。**

---

## Tk4-3. 選んだ演算子を覚える

今選んでいる演算子を、`=` を押すまで覚えておく場所が必要です。

名前は `selected_operator` にしてください。

最初は足し算を選んだ状態から始めるので、`+` を入れておきます。

このコードの元ファイル：[`app.py` の 5〜6行](./app.py#L5-L6)。

```python
# selected_operator に「+」を入れる
selected_operator = "+"
```

`operator` は「演算子」という意味です。

今回なら、

```text
+
-
```

のことです。

`selected_operator` は、

> **今選ばれている演算子**

を覚える変数です。

最初は `+` にしておきます。

---

## Tk4-4. + ボタンを押したら + を覚える

「+」ボタンを押したときだけ選択中の演算子と画面表示を変えたいので、その操作を `select_addition()` にまとめます。ボタンはこの関数を呼び出します。

次のコードは、足し算を選ぶ処理をまとめた関数の定義です。

名前は `select_addition` にしてください。

このコードの元ファイル：[`app.py` の 9〜17行](./app.py#L9-L17)。

```python
# 足し算を選び、選択中の表示を更新する select_addition を定義する
def select_addition():
    # 関数の外にある selected_operator を、この関数内の代入先として指定する
    global selected_operator

    # selected_operator に「+」を入れる
    selected_operator = "+"
    # operator_label の表示を「選択中: +」に変える
    operator_label.config(text="選択中: +")
```

このコードは、この指定を使っています。

`+` ボタンを押したら、

このコードの元ファイル：[`app.py` の 5〜6行](./app.py#L5-L6)。

```python
# selected_operator に「+」を入れる
selected_operator = "+"
```

この値に変更してください。

画面の表示も、

```text
選択中: +
```

へ変えてください。

## Tk4-5. - ボタンも同じ

「-」ボタンにも、押したときに選択中の演算子と画面表示を変える処理が必要です。足し算側と同じ動きを使いながら、設定する記号だけを「-」にする関数を作ります。

次のコードは、引き算を選ぶ処理です。足し算を選ぶ処理と同じ形です。

名前は `select_subtraction` にしてください。

このコードの元ファイル：[`app.py` の 20〜28行](./app.py#L20-L28)。

```python
# 引き算を選び、選択中の表示を更新する select_subtraction を定義する
def select_subtraction():
    # 関数の外にある selected_operator を、この関数内の代入先として指定する
    global selected_operator

    # selected_operator に「-」を入れる
    selected_operator = "-"
    # operator_label の表示を「選択中: -」に変える
    operator_label.config(text="選択中: -")
```

です。

今度は、

このコードの元ファイル：[`app.py` の 26〜26行](./app.py#L26-L26)。

```python
# selected_operator に「-」を入れる
selected_operator = "-"
```

このコードは、この指定を使っています。

これで、

> **最後に押した方の演算子を覚えている**

状態になります。

## Tk4-6. なんで変数が必要なの？

もし演算子を覚えていなかったら、

```text
+ を押す
↓
数字を読む
↓
= を押す
↓
……で、さっき何押したっけ？
```

となります。

> **「覚えとけよ！！！」**

ということで、

```python
selected_operator
```

に覚えさせます。

GUIでは、

- どのモードを選んだか
- どのボタンを押したか
- 今何を選択しているか

のような、

> **今の状態**

を変数に持つことがよくあります。

## Tk4-7. = を押したときに計算する

次のコードは、計算を確定する `=` ボタンを作る処理です。

名前は `equals_button` にしてください。

このコードの元ファイル：[`app.py` の 115〜121行](./app.py#L115-L121)。

```python
# 計算する
# equals_button に window 内で「=」と表示し、押すと calculate を呼ぶボタンを入れる
equals_button = tkinter.Button(
    window,
    text="=",
    command=calculate
)
```

です。

つまり、

> **= が押されたら calculate() を実行する**

という意味です。

## Tk4-8. 選ばれた演算子を見る

`calculate()` の中では、

このコードの元ファイル：[`app.py` の 51〜57行](./app.py#L51-L57)。

```python
# selected_operator が「+」なら、次の処理を実行する
if selected_operator == "+":
    # answer に number1 と number2 を足した値を入れる
    answer = number1 + number2
# selected_operator が「+」でなければ、次の処理を実行する
else:
    # answer に number1 から number2 を引いた値を入れる
    answer = number1 - number2
```

このコードは、この指定を使っています。

`+` が選ばれていれば足し算。

それ以外、今回は `-` しかないので引き算です。

## Tk4-9. ボタンごとに役割が違う

今回の3つのボタンは、

```text
+
→ 足し算を選ぶ

-
→ 引き算を選ぶ

=
→ 実際に計算する
```

という別々の役割があります。

> **ボタンを押した瞬間に全部計算する必要はありません。**

まず状態だけ変えるボタンも作れます。

---

## Tk4-10. global は何？

このコードの元ファイル：[`app.py` の 12〜12行](./app.py#L12-L12)。

```python
# 関数の外にある selected_operator を、この関数内の代入先として指定する
global selected_operator
```

と書いています。

これは、

> **関数の外にある selected_operator を、この関数の中で書き換えます**

という意味です。

今回は、

このコードの元ファイル：[`app.py` の 5〜6行](./app.py#L5-L6)。

```python
# selected_operator に「+」を入れる
selected_operator = "+"
```

や、

このコードの元ファイル：[`app.py` の 26〜26行](./app.py#L26-L26)。

```python
# selected_operator に「-」を入れる
selected_operator = "-"
```

と書き換えたいので使っています。

`global selected_operator` と書くと、関数の中から関数外の `selected_operator` を更新できます。

## Tk4-11. 実際に試す

VS Codeで、この章の [`app.py`](./app.py) を開き、Ctrl + S（macOSではCommand + S）で保存してください。前に起動したTkinterのウィンドウが残っている場合は、そのウィンドウの閉じるボタンを押してください。前の実行を終えた場合は、VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、実行に使ったターミナルで `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。

1. Windowsでは、エクスプローラーでこの章の `app.py` が入ったフォルダを開いてください。上部のアドレスバーをクリックし、表示されたフォルダのパスをCtrl + Cでコピーしてください。macOS / Linuxでは、VS Codeのエクスプローラーでこの章のフォルダを右クリックし、**パスのコピー（Copy Path）** を選んでください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでターミナルを開き、次のコマンドを入力してください。引用符の中へ、手順1でコピーしたフォルダのパスを貼り付けてください。

   ```text
   cd "ここにコピーしたフォルダのパスを貼り付ける"
   ```

3. Enterキーを押してください。ターミナルの現在のフォルダが、この章の `app.py` のあるフォルダに変わります。
4. Windowsでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python app.py
   ```

   `python` が見つからないというメッセージが出た場合は、同じターミナルに `py app.py` と入力し、Enterキーを押してください。

   macOS / Linuxでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python3 app.py
   ```

ウィンドウが開いている間、Tkinterは操作を待ち続けるため、このターミナルには次のコマンドを入力できません。変更後にもう一度起動する場合は、先にウィンドウを閉じてください。

ウィンドウ上部のタイトルが「足し算と引き算を用意する」になり、数字の入力欄と計算用のボタンが表示されたことを確認してください。

ウィンドウの「1つ目の数字」に `10`、「2つ目の数字」に `3` を入力してください。`+` ボタンを押してから `=` ボタンを押すと、結果の欄に次の文字が表示されます。

```text

```

入力欄の `10` と `3` はそのままで、`-` ボタンを押してから `=` ボタンを押してください。結果の欄が次の表示に変わります。

```text
答え: 7.0
```

## Tk4-12. Tk3から何が増えた？

Tk3では、

```text
入力
↓
計算
↓
表示
```

でした。

Tk4では、

```text
入力
↓
計算方法を選ぶ
↓
その選択を覚える
↓
=
↓
計算
↓
表示
```

になりました。

> **アプリが少しずつ「状態を持つ」ようになってきました。**

---

## Tk4-13. ここまでで覚えること

1. GUIのボタンで演算子を選べる
2. `selected_operator` に今の選択を覚えられる
3. ボタンは「状態を変えるだけ」の役割にもできる
4. `=` ボタンで最後に計算を確定できる
5. 条件分岐で選ばれた演算子に応じて処理を変えられる
6. GUIでは「今どういう状態か」を変数で持つことがある
