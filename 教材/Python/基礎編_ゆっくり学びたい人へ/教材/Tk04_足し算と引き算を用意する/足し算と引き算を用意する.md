# Tk4. 足し算と引き算を用意する

買い物に使った合計金額は足し算で求められますが、財布に残る金額を求めるには引き算が必要です。Tk3の電卓は、計算方法を変えるたびにPythonファイルの計算式を書き換える必要がありました。

> **「足し算しかできんやん！電卓名乗るな！！！」**

この章の電卓では、利用者が画面のボタンで足し算と引き算を選べます。入力欄の数字を変えずに、合計と差の両方を調べられる電卓です。

計算方法を選ぶボタンには、算数や電卓で使う記号に合わせて `+` と `-` を使います。答えを出すボタンにも、電卓で計算結果を出すときに使う `=` を使います。


## Pythonファイルの保存場所

この章のPythonファイルは、練習用フォルダ内の `src` へ保存してください。

この章のコードを保存する練習用フォルダを1つ選んでください。まだない場合は、保存したい場所で、Windowsはエクスプローラーの **新規作成 → フォルダー**、macOSはFinderの **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は右クリックの **新しいフォルダー** を選び、練習用フォルダを作ってください。

練習用フォルダの中で、Windowsはエクスプローラーの空いている場所を右クリックして **新規作成 → フォルダー**、macOSはFinderの **ファイル → 新規フォルダ**、Linux（GNOMEの「ファイル」）は空いている場所を右クリックして **新しいフォルダー** を選んでください。フォルダ名を `src` と入力してEnterキーを押すと、練習用フォルダの中に `src` ができます。すでに `src` がある場合はそのフォルダを使い、保存済みのコードは必要な変更だけを行ってください。

VS Codeで開くフォルダと、ターミナルの `cd` で移動するフォルダは、`src` の一つ上の練習用フォルダです。保存先を選ぶときは `src` を開き、起動するときは練習用フォルダから `src/app.py` を指定してください。実行手順のコマンドは、この練習用フォルダから入力してください。


## Tk4-1. 計算方法を選んでから答えを出す

利用者は2つの入力欄に数字を入力し、`+` または `-` ボタンを押して計算方法を選び、最後に `=` ボタンを押してください。

- `+` ボタンを押すと、電卓は足し算を選び、「選択中: +」と表示します。
- `-` ボタンを押すと、電卓は引き算を選び、「選択中: -」と表示します。
- `=` ボタンを押すと、電卓は選択中の計算方法で2つの数字を計算し、結果の欄へ答えを表示します。

`+` と `-` のボタンは計算方法を選ぶためのボタンです。どちらを押しても、`=` を押すまでは結果の欄は変わりません。

## Tk4-2. 選択状態と操作を同じ電卓にまとめる

利用者が `-` を選んでから `=` を押すまで、電卓は「引き算が選ばれている」という情報を覚えておく必要があります。選択中の計算方法のように、操作によって変わる情報を「状態」と呼びます。

選択状態、入力欄、結果表示、計算処理は、すべて同じ電卓に関する情報と操作です。選択状態だけを電卓の外へ置くと、どの電卓の選択なのかが変数から分かりません。画面の部品と操作をまとめた `CalculatorApp` というクラスに、選択状態も持たせます。クラスは、同じ対象に関する情報と操作をまとめて定義する仕組みです。

`CalculatorApp()` で実際に使う電卓を1つ作ると、その電卓の状態と画面の部品が用意されます。クラスから作った個々の電卓を「インスタンス」と呼びます。クラス内の `self` は、操作の対象になっている電卓のインスタンスを指します。`self.selected_operator` は、その電卓が選んでいる計算記号を覚える変数です。`+` や `-` のような計算記号を「演算子」と呼びます。

`+` を押したときだけ足し算を選び、`-` を押したときだけ引き算を選ぶ必要があるため、ボタンごとの処理を `select_addition` と `select_subtraction` に分けます。クラス内で定義した関数を「メソッド」と呼びます。両方のメソッドが同じ電卓の `self.selected_operator` を書き換え、画面の選択表示も更新します。

`=` の処理は、計算方法を選ぶ処理とは別のタイミングで実行するため、`calculate` に分けます。`calculate` は同じ電卓の入力欄と選択状態を読み、同じ電卓の結果の欄へ答えを表示します。

画面を用意する処理と、ボタン操作を待つ処理も実行するタイミングが違います。`__init__` は電卓を作ったときに初期状態と画面の部品を用意し、`run` は起動時にウィンドウを表示して利用者の操作を待ち続けます。

電卓の機能は `calculator.py` にまとめます。起動時に電卓を作って操作待ちを始める処理は、`app.py` の `main` にまとめます。計算方法を増やすときも、起動処理へ計算式を書き足さず、`calculator.py` を変更できます。

### calculator.py：電卓の画面と操作

元ファイル：[`calculator.py` 全体](./src/calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 電卓の入力欄・選択中の計算方法・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.selected_operator（選択中の演算子）に足し算を表す「+」を入れる
        self.selected_operator = "+"

        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「足し算と引き算を用意する」にする
        self.window.title("足し算と引き算を用意する")
        # self.window の大きさを横400、縦340にする
        self.window.geometry("400x340")

        # self.number1_label（1つ目の数字の案内）に self.window 内で「1つ目の数字」と表示するラベルを入れる
        self.number1_label = tkinter.Label(self.window, text="1つ目の数字")
        # self.number1_label を self.window 内に配置する
        self.number1_label.pack()

        # self.number1_entry（1つ目の数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number1_entry = tkinter.Entry(self.window)
        # self.number1_entry を self.window 内に配置する
        self.number1_entry.pack()

        # self.number2_label（2つ目の数字の案内）に self.window 内で「2つ目の数字」と表示するラベルを入れる
        self.number2_label = tkinter.Label(self.window, text="2つ目の数字")
        # self.number2_label を self.window 内に配置する
        self.number2_label.pack()

        # self.number2_entry（2つ目の数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number2_entry = tkinter.Entry(self.window)
        # self.number2_entry を self.window 内に配置する
        self.number2_entry.pack()

        # self.operator_label（選択中の演算子の表示）に self.window 内で「選択中: +」と表示するラベルを入れる
        self.operator_label = tkinter.Label(self.window, text="選択中: +")
        # self.operator_label を self.window 内に配置する
        self.operator_label.pack()

        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()

        # self.equals_button（計算を行うボタン）に self.window 内で「=」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.equals_button = tkinter.Button(
            self.window,
            text="=",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.equals_button を self.window 内に配置する
        self.equals_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

    # 足し算を選び、選択中の表示を更新する select_addition を定義する
    def select_addition(self):
        # self.selected_operator に足し算を表す「+」を入れる
        self.selected_operator = "+"
        # self.operator_label の表示を「選択中: +」に変える
        self.operator_label.config(text="選択中: +")

    # 引き算を選び、選択中の表示を更新する select_subtraction を定義する
    def select_subtraction(self):
        # self.selected_operator に引き算を表す「-」を入れる
        self.selected_operator = "-"
        # self.operator_label の表示を「選択中: -」に変える
        self.operator_label.config(text="選択中: -")

    # 入力された2つの数字を選択中の演算子で計算し、答えを表示する calculate を定義する
    def calculate(self):
        # number1_text（1つ目の入力文字列）に self.number1_entry に入力された文字列を入れる
        number1_text = self.number1_entry.get()
        # number2_text（2つ目の入力文字列）に self.number2_entry に入力された文字列を入れる
        number2_text = self.number2_entry.get()

        # number1_text または number2_text が空の文字列なら、次の処理を実行する
        if number1_text == "" or number2_text == "":
            # self.result_label の表示を「数字を2つ入力してください」に変える
            self.result_label.config(text="数字を2つ入力してください")
            # calculate の処理をここで終える
            return

        # number1（1つ目の数値）に number1_text を float で数値に変換した値を入れる
        number1 = float(number1_text)
        # number2（2つ目の数値）に number2_text を float で数値に変換した値を入れる
        number2 = float(number2_text)

        # self.selected_operator が「+」なら、次の処理を実行する
        if self.selected_operator == "+":
            # answer（答え）に number1 と number2 を足した値を入れる
            answer = number1 + number2
        # self.selected_operator が「+」でなければ、次の処理を実行する
        else:
            # answer に number1 から number2 を引いた値を入れる
            answer = number1 - number2

        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

## Tk4-7. = ボタンで入力した数字を計算する

Tkinterは `=` ボタンが押されると、そのボタンに登録した `self.calculate` を実行します。`calculate` は「計算する」という意味です。

`CalculatorApp.calculate` は、`self.number1_entry` と `self.number2_entry` から入力内容を読み取ります。`Entry` は1行の入力欄を作る部品で、`get()` は入力欄にある文字列を読み取る操作です。

元ファイル：[`calculator.py` の93〜110行](./src/calculator.py#L93-L110)。

```python
    # 入力された2つの数字を選択中の演算子で計算し、答えを表示する calculate を定義する
    def calculate(self):
        # number1_text（1つ目の入力文字列）に self.number1_entry に入力された文字列を入れる
        number1_text = self.number1_entry.get()
        # number2_text（2つ目の入力文字列）に self.number2_entry に入力された文字列を入れる
        number2_text = self.number2_entry.get()

        # number1_text または number2_text が空の文字列なら、次の処理を実行する
        if number1_text == "" or number2_text == "":
            # self.result_label の表示を「数字を2つ入力してください」に変える
            self.result_label.config(text="数字を2つ入力してください")
            # calculate の処理をここで終える
            return

        # number1（1つ目の数値）に number1_text を float で数値に変換した値を入れる
        number1 = float(number1_text)
        # number2（2つ目の数値）に number2_text を float で数値に変換した値を入れる
        number2 = float(number2_text)
```

どちらかの入力欄が空なら、`calculate` は「数字を2つ入力してください」と結果の欄へ表示し、`return` で計算処理を終えます。両方に入力がある場合は、`float` が入力文字列を小数を扱える数値へ変換します。

空欄の確認は、数字以外の文字を確認する処理ではありません。たとえば入力欄に `abc` と入力して `=` を押すと、`float` が数値へ変換できず、`ValueError` というエラーが起きます。Tkinterは、ボタンから実行した処理のエラーを起動に使ったターミナルへ表示し、結果の欄には直前の表示が残ります。この章のコードには、数字以外の入力を画面で案内する処理は入っていません。

## Tk4-8. 保存した計算方法に合わせて答えを出す

`CalculatorApp.calculate` は `self.selected_operator` を読み、`"+"` が保存されていれば足し算を行います。`"+"` でなければ `else` の引き算を行います。この電卓が選択状態へ保存する記号は `"+"` と `"-"` の2つだけです。

元ファイル：[`calculator.py` の112〜122行](./src/calculator.py#L112-L122)。

```python
        # self.selected_operator が「+」なら、次の処理を実行する
        if self.selected_operator == "+":
            # answer（答え）に number1 と number2 を足した値を入れる
            answer = number1 + number2
        # self.selected_operator が「+」でなければ、次の処理を実行する
        else:
            # answer に number1 から number2 を引いた値を入れる
            answer = number1 - number2

        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")
```

`answer` は「答え」という意味の変数です。`calculate` は計算した値を `answer` へ入れ、`self.result_label.config(...)` で結果の欄へ表示します。文字列の先頭の `f` は、文字列内の `{answer}` を変数の値に置き換える記述です。

## Tk4-9. 選択と計算のタイミングを分ける

利用者が `-` ボタンを押すと、`select_subtraction` が `self.selected_operator` を `"-"` へ変えます。その後、利用者が `=` ボタンを押すと、`calculate` が `self.selected_operator` を読み取って引き算を行います。

選択処理が終わっても、`self.selected_operator` は電卓の情報として残っています。選択処理の中だけで使う一時的な変数へ記号を入れても、後から実行する `calculate` が選択した記号を読み取れません。選択と計算で同じ情報を使うため、電卓のインスタンスに記号を持たせています。

`+` ボタンを押す処理も、`-` ボタンを押す処理も、`=` ボタンを押す処理も、同じ `CalculatorApp` のメソッドです。各メソッドの `self` を通じて、同じ電卓の選択状態と画面を使います。

## Tk4-10. app.py が電卓を作って操作待ちを始める

`app.py` の `from calculator import CalculatorApp` は、同じフォルダの `calculator.py` から電卓の定義を読み込む記述です。`calculator` と書く部分には、ファイル名の `.py` を付けません。

`calculator.py` を読み込むだけでは、ウィンドウは開きません。クラス内に定義した処理は、読み込んだ時点では実行されません。

`app.py` を直接実行すると、末尾の `if __name__ == "__main__":` の条件に当てはまり、Pythonが `main()` を実行します。`main` 内の `CalculatorApp()` が電卓を作り、`__init__` が初期状態と画面を用意します。続く `app.run()` が `self.window.mainloop()` を実行してウィンドウを表示し、ボタン操作を待ち続けます。

別のファイルから `app.py` を読み込んだ場合は、末尾の条件に当てはまらないため `main()` は実行されません。機能を定義するファイルと起動するファイルを分けても、ターミナルで実行するファイルは `app.py` のままです。

## Tk4-11. 実際に試す

VS Codeで、この章の [`app.py`](./src/app.py) と [`calculator.py`](./src/calculator.py) をそれぞれ開き、Ctrl + S（macOSではCommand + S）で両方を保存してください。前に起動したTkinterのウィンドウが残っている場合は、そのウィンドウの閉じるボタンを押してください。前の実行を終えた場合は、VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、実行に使ったターミナルで `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。

1. Windowsでは、エクスプローラーでこの章の `src` が入っている練習用フォルダを開いてください。`app.py` が入った `src` 自体ではなく、その一つ上を選んでください。上部のアドレスバーをクリックし、表示されたフォルダのパスをCtrl + Cでコピーしてください。macOS / Linuxでは、VS Codeのエクスプローラーでこの章の `src` が入っている練習用フォルダを右クリックし、**パスのコピー（Copy Path）** を選んでください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでターミナルを開き、次のコマンドを入力してください。引用符の中へ、手順1でコピーしたフォルダのパスを貼り付けてください。

   ```text
   cd "ここにコピーしたフォルダのパスを貼り付ける"
   ```

3. Enterキーを押してください。ターミナルの現在のフォルダが、この章の `app.py` のあるフォルダに変わります。
4. Windowsでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python src/app.py
   ```

   `python` が見つからないというメッセージが出た場合は、同じターミナルに `py src/app.py` と入力し、Enterキーを押してください。

   macOS / Linuxでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python3 src/app.py
   ```

ウィンドウが開いている間、Tkinterは操作を待ち続けるため、このターミナルには次のコマンドを入力できません。変更後にもう一度起動する場合は、先にウィンドウを閉じてください。

```text

```


足し算と引き算を続けて試す操作では、ファイルを書き換えたり、電卓を再起動したりする必要はありません。`+` と `-` のボタンが、開いている電卓の選択状態を変えます。

空欄の案内を試す場合は、電卓の「1つ目の数字」の入力欄から `10` を削除し、`=` ボタンを押してください。結果の欄に「数字を2つ入力してください」と表示されます。「1つ目の数字」へ `10` を入力し直し、`+` ボタン、`=` ボタンの順に押すと、結果の欄に `答え: 13.0` と表示されます。

## Tk4-12. Tk3との違い

Tk3で配布している電卓の `CalculatorApp.calculate` は、次の式で足し算を行います。

元ファイル：[`Tk3のcalculator.py` の70〜71行](../Tk03_簡単な電卓/src/calculator.py#L70-L71)。

```python
        # answer（答え）に number1 と number2 を足した値を入れる
        answer = number1 + number2
```

Tk3で計算方法を変えるには、`calculator.py` の計算式を書き換え、ウィンドウを閉じてファイルを保存し、`app.py` を再実行する必要がありました。Tk4では、開いている電卓のボタンで計算方法を変えられます。

Tk3とTk4は、どちらも電卓の機能を `calculator.py` の `CalculatorApp` にまとめ、`app.py` から起動します。Tk4では、電卓の情報に `self.selected_operator` を加え、その記号を選ぶ2つのメソッドとボタンを加えています。

## Tk4-13. 今回の内容

- `CalculatorApp` は、電卓の入力欄、選択中の計算方法、結果表示、ボタン処理をまとめます。
- `self.selected_operator` は、対象の電卓で選ばれている計算記号を保存します。最初は足し算の `"+"` です。
- `select_addition` と `select_subtraction` は、選択状態と画面の選択表示を一緒に更新します。
- `calculate` は、2つの入力欄と選択状態を読み、選んだ計算の答えを結果の欄へ表示します。
- 機能を定義するファイルは `calculator.py`、ターミナルで実行するファイルは `app.py` です。
