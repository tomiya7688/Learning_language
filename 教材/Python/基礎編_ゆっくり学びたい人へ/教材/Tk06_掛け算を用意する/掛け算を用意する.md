# Tk6. 掛け算を用意する

同じ価格の品物を3個買うとき、価格を3回足す代わりに掛け算で合計を求めたいところです。

> **「掛け算ないん？？？」**

この章の電卓には、掛け算を入力できる `*` ボタンがあります。`1 + 2 * 3` では掛け算を先に行い、答えの `7.0` を表示する電卓です。

掛け算のボタンには、Pythonで掛け算を表す記号 `*` を使います。足し算・引き算・答えを出すボタンも、電卓で使う記号の `+`、`-`、`=` に合わせます。

## Tk6-1. 計算順と画面の操作を揃える

足し算と引き算を左から計算する方法へ掛け算を加えると、`1 + 2 * 3` を `(1 + 2) * 3` と扱い、答えが9になってしまいます。算数の計算順に合わせて7を求めるため、掛け算を先に計算し、残った足し算と引き算を後から計算します。

利用者は「数字」の入力欄へ数字を1つずつ入力し、次に使う計算記号のボタンを押してください。計算記号のボタンは、入力中の数字と記号を保存して入力欄を空にします。最後の数字を入力して `=` を押すと、電卓は保存した式を計算します。

## Tk6-2. 同じ電卓の状態と操作に機能を加える

Tk5と同じ `CalculatorApp` に、入力欄、計算途中の式、表示、ボタン処理をまとめます。クラスは、同じ対象の情報と操作をまとめて定義する仕組みです。クラスから作った個々の電卓を「インスタンス」と呼び、クラス内の `self` は操作対象の電卓を指します。

入力済みの数字と計算記号は、対象の電卓の `self.calculation_parts` に保存します。複数の値を順に保存する一覧を「リスト」と呼びます。式の追加と計算が同じリストを使うため、機能を増やしても式を電卓の外へ移す必要はありません。

数字と計算記号を保存し、表示を更新し、入力欄を空にする処理は、計算記号を追加する各ボタンで共通です。同じ処理をボタンごとに書き直さず、`add_operator` を使います。`+`、`-`、`*`、`/` のような計算記号を「演算子」と呼び、追加する記号を `operator` で指定します。

`*` を押したときだけ記号を追加する処理を登録できるよう、`select_multiplication` を用意します。`select_multiplication` は同じ電卓の `add_operator` に `"*"` を指定します。クラス内の関数を「メソッド」と呼びます。式を計算する `calculate` は、`=` が押されたときに実行します。

画面を用意する `__init__` は電卓を作ったときに実行され、`run` は起動時にウィンドウを表示してボタン操作を待ち続けます。機能を変更するファイルは `calculator.py`、起動するファイルは `app.py` です。`app.py` の `main` は電卓を作って操作待ちを始める処理だけを担当します。

## Tk6-3. 2つのファイルを保存する

画面には、Pythonでウィンドウや入力欄、ボタンを作るための道具「Tkinter」を使います。Tk6用の新しいフォルダを作り、[`calculator.py`](./calculator.py) と [`app.py`](./app.py) の両方を同じフォルダへ保存してください。前の章のファイルを残すため、Tk5用のフォルダとは分けてください。

自分でコードを書く場合は、VS Codeで新しいファイルを2つ作り、次の全体コードをそれぞれ書いてください。電卓の定義を `calculator.py`、起動処理を `app.py` として、同じTk6用のフォルダへ保存してください。

### calculator.py：電卓の画面と計算

元ファイル：[`calculator.py` 全体](./calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []

        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「掛け算を用意する」にする
        self.window.title("掛け算を用意する")
        # self.window の大きさを横420、縦360にする
        self.window.geometry("420x360")

        # self.number_label（数字の案内）に self.window 内で「数字」と表示するラベルを入れる
        self.number_label = tkinter.Label(self.window, text="数字")
        # self.number_label を self.window 内に配置する
        self.number_label.pack()

        # self.number_entry（数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window)
        # self.number_entry を self.window 内に配置する
        self.number_entry.pack()

        # self.expression_label（計算式の表示）に self.window 内で「計算式:」と表示するラベルを入れる
        self.expression_label = tkinter.Label(self.window, text="計算式:")
        # self.expression_label を self.window 内に配置する
        self.expression_label.pack()

        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()

        # self.multiplication_button（掛け算ボタン）に self.window 内で「*」と表示し、押すと self.select_multiplication を呼ぶボタンを入れる
        self.multiplication_button = tkinter.Button(
            self.window,
            text="*",
            # ボタンを押したときに呼ぶ処理として self.select_multiplication を登録する
            command=self.select_multiplication,
        )
        # self.multiplication_button を self.window 内に配置する
        self.multiplication_button.pack()

        # self.equals_button（計算を行うボタン）に self.window 内で「=」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.equals_button = tkinter.Button(
            self.window,
            text="=",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.equals_button を self.window 内に配置する
        self.equals_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「次の数字を入力してください」に変える
            self.result_label.config(text="次の数字を入力してください")
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 入力された数字と「*」を計算式に追加する select_multiplication を定義する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")

    # 計算式に最後の数字を追加し、掛け算を先に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「最後の数字を入力してください」に変える
            self.result_label.config(text="最後の数字を入力してください")
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))

        # 掛け算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」でなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)

        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものと「 = 」と answer の値を付けた文字列に変える
        self.expression_label.config(
            text=(
                "計算式: "
                + " ".join(str(part) for part in self.calculation_parts)
                + f" = {answer}"
            )
        )
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer を文字列にした値を挿入する
        self.number_entry.insert(0, str(answer))

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

### app.py：電卓を起動する

`app.py` のコードは前の章と同じです。比較する起動処理は、[`Tk5のapp.py` の1〜15行](../Tk05_複数の数字を計算できる/app.py#L1-L15)と、[`Tk6のapp.py` の1〜15行](./app.py#L1-L15)です。`from calculator import CalculatorApp` は、同じフォルダの `calculator.py` から電卓の定義を読み込みます。`calculator` と書く部分には、ファイル名の `.py` を付けません。

元ファイル：[`app.py` 全体](./app.py)。

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp


# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

`app.py` を直接実行すると、末尾の `if __name__ == "__main__":` の条件に当てはまり、Pythonが `main()` を実行します。`CalculatorApp()` が電卓を作り、`app.run()` がウィンドウを表示して操作待ちを始めます。別のファイルから `app.py` を読み込んだだけの場合は、`main()` は実行されません。

## Tk6-5. ボタンを使って計算する

新しく開いた電卓で、次の順に `1 + 2 * 3` を入力してください。

1. 「数字」の入力欄へ `1` を入力し、`+` ボタンを押してください。式の欄は `計算式: 1.0 +` に変わり、入力欄が空になります。
2. 同じ「数字」の入力欄へ `2` を入力し、`*` ボタンを押してください。式の欄は `計算式: 1.0 + 2.0 *` に変わり、入力欄が空になります。
3. 同じ「数字」の入力欄へ `3` を入力し、`=` ボタンを押してください。式の欄に `計算式: 1.0 + 2.0 * 3.0 = 7.0`、結果の欄に `答え: 7.0` と表示され、入力欄にも答えの `7.0` が入ります。

別の式を試す場合は、入力欄の `7.0` をすべて削除してから `10` を入力し、`-` ボタンを押してください。空になった入力欄へ `2` を入力して `*` を押し、再び空になった入力欄へ `3` を入力して `=` を押すと、式の欄は `計算式: 10.0 - 2.0 * 3.0 = 4.0`、結果の欄は `答え: 4.0` に変わり、入力欄にも `4.0` が入ります。

## Tk6-6. 計算記号を共通の追加処理へ指定する

元ファイル：[`Tk6のcalculator.py` の118〜121行](./calculator.py#L118-L121)。

```python
    # 入力された数字と「*」を計算式に追加する select_multiplication を定義する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")
```

`CalculatorApp.select_multiplication` は、同じ電卓の `add_operator` に `"*"` を指定して実行します。画面のボタンに登録する処理も、その電卓のメソッドです。

元ファイル：[`Tk6のcalculator.py` の54〜62行](./calculator.py#L54-L62)。

```python
        # self.multiplication_button（掛け算ボタン）に self.window 内で「*」と表示し、押すと self.select_multiplication を呼ぶボタンを入れる
        self.multiplication_button = tkinter.Button(
            self.window,
            text="*",
            # ボタンを押したときに呼ぶ処理として self.select_multiplication を登録する
            command=self.select_multiplication,
        )
        # self.multiplication_button を self.window 内に配置する
        self.multiplication_button.pack()
```

`command` には、ボタンを押したときに実行するメソッドの名前を指定します。末尾の `()` を付けると、Pythonはボタンを作る途中で処理を実行してしまい、押したときの処理を登録できません。

`add_operator` は入力欄の文字列を `get()` で読み、`float` で数値に変換してから、リストの `append` で数値と計算記号を末尾へ追加します。入力欄が空なら、電卓は「次の数字を入力してください」と表示し、追加処理を終えます。

保存した式の表示では、`str(part) for part in self.calculation_parts` が各値を `part` として取り出し、`str` で文字列に変えます。`" ".join(...)` が文字列を空白でつなぎます。`delete(0, tkinter.END)` は、入力欄の先頭から末尾までの文字を削除し、次の数字を入力できるようにする操作です。

## Tk6-7. 前の章の構成を引き継ぐ

Tk5とTk6は、計算途中の式を `CalculatorApp.__init__` で作るインスタンスのリストに保存します。比較する両方の定義は次のとおりです。

元ファイル：[`Tk5のcalculator.py` の9〜10行](../Tk05_複数の数字を計算できる/calculator.py#L9-L10)。

```python
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
```

元ファイル：[`Tk6のcalculator.py` の9〜10行](./calculator.py#L9-L10)。

```python
        # self.calculation_parts（計算式の部品）に空のリストを入れる

```

Tk6のボタン処理と計算処理も、Tk5と同じ `CalculatorApp` の中にあります。起動ファイル `app.py` へ計算機能を加えず、`calculator.py` のボタンと `calculate` を変更する構成です。

## Tk6-8. 優先する計算を先に行う

元ファイル：[`Tk6のcalculator.py` の138〜160行](./calculator.py#L138-L160)。

```python
        # 掛け算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」でなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)
```

`addition_and_subtraction_parts` は「足し算と引き算の部品」という意味です。電卓は、この作業用リストの先頭に元の式の最初の数字を入れます。リストの位置は0から数えるため、`self.calculation_parts[0]` が先頭の数字です。

`range(1, len(self.calculation_parts), 2)` は、1から始め、元のリストの個数未満までの番号を2ずつ増やします。`for` は、その番号を `index` に入れて続く字下げの処理を繰り返します。位置1、3、5には計算記号があり、その次の位置 `index + 1` には数値があります。

`addition_and_subtraction_parts[-1]` は、作業用リストの末尾の値です。掛け算を見つけた場合、電卓は末尾の値に次の数値を掛け、末尾の値を答えに置き換えます。足し算と引き算を見つけた場合は、記号と次の数字を作業用リストへそのまま残します。

たとえば `1 + 2 * 3` の元のリストは `[1.0, "+", 2.0, "*", 3.0]` です。掛け算を処理すると、作業用リストには `[1.0, "+", 6.0]` が残ります。

## Tk6-9. 残った足し算・引き算を計算する

元ファイル：[`Tk6のcalculator.py` の162〜180行](./calculator.py#L162-L180)。

```python
        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number
```

電卓は作業用リストの先頭の数値を途中の答え `answer` に入れます。残った計算記号を順に取り出し、`"+"` なら次の数値を足し、それ以外の `"-"` なら次の数値を引きます。優先する計算は処理済みなので、作業用リストには足し算と引き算だけが残っています。

`calculate` は、元の式と答えを式の欄へ表示し、結果の欄へも答えを表示します。文字列内の `{answer}` を答えの値に置き換えるため、先頭に `f` を付けた文字列を使います。計算後は元のリストを `clear()` で空にし、入力欄へ答えを入れます。入力欄の答えを残して計算記号を押せば、その答えから続けて計算できます。

## Tk6-10. 入力できる内容と今回の内容


`=` を押したときに入力欄が空なら、電卓は結果の欄へ「最後の数字を入力してください」と表示して計算を止めます。入力済みの式はリストに残るため、利用者が最後の数字を入力して `=` を押すと、その式を計算できます。

数字以外の入力を案内する処理は入っていません。たとえば `abc` の入力に対して計算記号や `=` を押すと、`float` が数値へ変換できず、`ValueError` というエラーが起きます。Tkinterはエラーを起動に使ったターミナルへ表示します。式と結果の表示、保存済みのリストは変わりません。入力欄の `abc` をすべて削除して数字を入力し直すと、電卓は入力の追加や計算を続けられます。

- `CalculatorApp` は、電卓の画面・計算途中の式・ボタン処理・計算処理をまとめます。
- `self.calculation_parts` は、対象の電卓が入力した数字と計算記号を順に保存します。
- `calculate` は、優先する計算を先に処理し、残った足し算と引き算を後から計算します。
- 機能を変更するファイルは `calculator.py`、ターミナルで実行するファイルは `app.py` です。
