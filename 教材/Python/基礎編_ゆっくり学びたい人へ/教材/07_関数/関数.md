# 7. 関数

たろう・さくら・けんへの挨拶を、それぞれ別の場所に書いたとします。「こんにちは」を「ようこそ」へ変えるたびに、3か所とも直す必要があります。1か所忘れると、そこだけ古い挨拶のままです。

> **「同じ挨拶なのに、全部探して直すの？？？」**

挨拶を作る部分は1か所にまとめて、名前を変えて使いたいところです。この章では、その処理に名前を付けて、必要な場所から使うプログラムを書いてください。

## 7-1. `print()` や `input()` も名前で使っていた

前章の [`greet_name.py` の1〜6行](../03_入力と変数/greeting.py#L1-L6)をもとに、コメントをこのページ向けに言い換えた振り返り用の例です。

```python
# name は「名前」という意味
# 入力の案内を表示し、入力された文字列を name に代入する
name = input("名前を入力してください: ")
# 「こんにちは」と name の文字列を表示する
print("こんにちは", name)
```

`input(...)` は、案内を表示して入力を受け取ります。`print(...)` は、括弧の中で指定した内容を表示します。どちらも、名前のあとに丸括弧 `()` を付けて使っていました。

このように、名前を使って実行できる処理のまとまりを **関数** と呼びます。名前のあとに `()` を書いて、その処理を実行することを **呼び出す** といいます。

`print` と `input` は Python が用意した関数です。自分でも、処理に名前を付けて呼び出せるようにできます。

## 7-2. 挨拶文を作る処理に名前を付ける

自分で関数を定義するときは、`def` を使ってください。**定義する**とは、その名前で使える処理を決めることです。

挨拶文を作る関数の名前を `make_greeting` にしてください。`make` は「作る」、`greeting` は「挨拶」という意味です。

次のコードは、この章のサンプルの冒頭です。

このコードの元ファイル：[`greeting_function.py` の 1〜5行](./greeting_function.py#L1-L5)。

```python
# make_greeting は「挨拶を作る」、name は「名前」という意味
# name で名前を受け取り、挨拶文を返す関数を定義する
def make_greeting(name):
    # name を組み込んだ挨拶の文字列を、呼び出した場所へ返す
    return f"こんにちは {name}"
```

`def make_greeting(name):` は、名前を `name` で受け取る関数を定義しています。字下げした行が、その関数の処理です。

`f"こんにちは {name}"` は、`{name}` の部分に `name` の値を組み込む書き方です。`name` が `"たろう"` なら、`"こんにちは たろう"` という文字列になります。

`return` は、作った値を関数を呼び出した場所へ返す文です。この関数は挨拶文を作って返します。表示する処理は、呼び出した側に置いてください。

**関数を定義した時点では、字下げした処理は実行されません。** Python は、関数の名前をあとで使えるようにして、定義の次へ進みます。字下げした処理を実行するのは、その関数を呼び出したときです。

## 7-3. サンプルを保存する

[greeting_function.py](./greeting_function.py) は「挨拶の関数.py」という意味のファイル名です。2人分の挨拶文を同じ関数で作り、順に表示するサンプルです。

1. VS Code を開き、上部メニューの **ファイル → 新しいテキストファイル** を選んでください。
2. 次のコードをすべて入力するか、コピーして貼り付けてください。
3. **ファイル → 名前を付けて保存** を選んでください。
4. 保存するフォルダを選び、ファイル名を `greeting_function.py` にして保存してください。サンプルファイルをダウンロードして使う場合も、この名前と保存先を確認してください。

このコードの元ファイル：[`greeting_function.py` の 1〜27行](./greeting_function.py#L1-L27)。

```python
# make_greeting は「挨拶を作る」、name は「名前」という意味
# name で名前を受け取り、挨拶文を返す関数を定義する
def make_greeting(name):
    # name を組み込んだ挨拶の文字列を、呼び出した場所へ返す
    return f"こんにちは {name}"


# main は「主な」という意味。このプログラム全体の流れをまとめる
# 2人分の挨拶文を作り、順に表示する関数を定義する
def main():
    # message1 は「1人目の挨拶文」という意味
    # "たろう" で make_greeting を呼び出し、戻った文字列を message1 に代入する
    message1 = make_greeting("たろう")
    # message2 は「2人目の挨拶文」という意味
    # "さくら" で make_greeting を呼び出し、戻った文字列を message2 に代入する
    message2 = make_greeting("さくら")

    # message1 の文字列を画面に表示する
    print(message1)
    # message2 の文字列を画面に表示する
    print(message2)


# このファイルを直接実行した場合かどうかを調べる
if __name__ == "__main__":
    # プログラム全体の流れをまとめた main を呼び出す
    main()
```

## 7-5. 「上から実行する」と関数の定義の関係

Python はファイルの一番上から進みます。ただし、`def` の行で行うのは **関数の定義** です。そこで関数の本体まで実行するわけではありません。

このサンプルでは、次の順番で処理が進みます。

| 順番 | Python が進む場所 | 起きること |
| --- | --- | --- |
| 1 | `def make_greeting(name):` | `make_greeting` を定義する。本体の `return` はまだ実行しない |
| 2 | `def main():` | `main` を定義する。本体の代入や表示はまだ実行しない |
| 3 | ファイル末尾の `if __name__ == "__main__":` | このファイルを直接実行した場合だけ、次の行へ進む |
| 4 | `if` の次の行にある `main()` | `main` の本体を実行する |
| 5 | `message1 = make_greeting("たろう")` | `make_greeting` を呼び出す。`name` は `"たろう"` になり、本体の `return` で挨拶文が返る。その値を `message1` に代入する |
| 6 | `message2 = make_greeting("さくら")` | 同じ関数を、今度は `"さくら"` で呼び出す。返った挨拶文を `message2` に代入する |
| 7 | `print(message1)`、`print(message2)` | 2つの挨拶文を順に表示する |
| 8 | `main` の本体の終わり | `main()` を呼び出した場所へ戻り、ファイルの末尾まで進んで終了する |

**上に書いてある関数でも、その本体が動くのは呼び出したときです。** 呼び出した関数の処理が終わると、Python は呼び出した場所へ戻り、その続きへ進みます。

## 7-6. 引数と戻り値を対応させる

**引数**は、関数を呼び出すときに指定する値です。サンプルのこの行では、`"たろう"` が引数です。

このコードの元ファイル：[`greeting_function.py` の 13〜13行](./greeting_function.py#L13-L13)。

```python
# message1 は「1人目の挨拶文」という意味
# "たろう" で make_greeting を呼び出し、戻った文字列を message1 に代入する
message1 = make_greeting("たろう")
```

定義側の `def make_greeting(name):` では、受け取る値に `name` という名前を付けています。この呼び出しでは、`name` の値が `"たろう"` になります。

関数から呼び出した場所へ返った値を **戻り値** といいます。今回の戻り値は `"こんにちは たろう"` です。

```text
make_greeting("たろう") を呼び出す
          ↓
関数の中で name が "たろう" になる
          ↓
return で "こんにちは たろう" を返す
          ↓
呼び出した場所へ戻り、message1 に代入する
```

`return` は、その関数の処理をそこで終えて呼び出した場所へ戻ります。プログラム全体を終える文ではありません。サンプルでは、そのあと `message2` の代入へ進みます。

## 7-7. `main()` も自分で定義した関数

`main` は「主な」という意味の名前です。このサンプルでは、プログラム全体の流れをまとめる関数の名前として使っています。`main` という名前にしただけで、自動的に実行されるわけではありません。

次はサンプル末尾の抜粋です。

このコードの元ファイル：[`greeting_function.py` の 24〜27行](./greeting_function.py#L24-L27)。

```python
# このファイルを直接実行した場合かどうかを調べる
if __name__ == "__main__":
    # プログラム全体の流れをまとめた main() を実行する
    main()
```

`__name__` は、Python が実行・読み込みの方法に応じて設定する名前です。`python greeting_function.py` のようにファイルを直接実行した場合、その値は文字列 `"__main__"` になります。

`==` は、左右の値が同じか調べる書き方でした。この例では、左右の値がどちらも `"__main__"` です。そのため、Pythonは次の行にある `main()` を実行し、ここで初めて `main` の本体へ進みます。

別のファイルから `greeting_function.py` を読み込むと、`__name__` は通常 `"greeting_function"` になります。`"greeting_function"` は `"__main__"` と違うため、Pythonは次の行にある `main()` を実行しません。別のプログラムが `make_greeting()` を使ったとき、2人分の挨拶まで表示されるのを防げます。

`make_greeting` は挨拶文を作る担当、`main` は呼び出す順番と表示を決める担当です。処理を増やすときも、この役割を分けて書いてください。

## 7-8. `def` の形と処理の範囲

関数を定義するときは、次の順で書いてください。

1. `def` と、そのあとに空白を書いてください。
2. 関数名を書いてください。
3. 丸括弧 `()` を書いてください。受け取る値がある場合は、括弧の中にその値の名前を書いてください。
4. 行の最後に `:` を書いてください。
5. 次の行から、関数の本体を半角スペース4個で字下げして書いてください。この字下げを **インデント** と呼びます。

`main` のように受け取る値がない関数でも、`def main():` の `()` は必要です。

関数の本体は、字下げを戻すところまで続きます。関数の中の `if` や繰り返しの処理は、さらに字下げしてください。`return` は関数の本体の中に書いてください。

次は書き方を比べる例です。動かない例をサンプルへ貼り付けないでください。

**❌ `:` がないため動かない例**：

```python
# 挨拶文を返す関数の定義。行末の : が欠けている
def make_greeting(name)
    # name を組み込んだ挨拶文を返す
    return f"こんにちは {name}"
```

**⭕ `:` と本体の字下げがある例**：

このコードの元ファイル：[`greeting_function.py` の 1〜5行](./greeting_function.py#L1-L5)。

```python
# make_greeting は「挨拶を作る」、name は「名前」という意味
# name で名前を受け取り、挨拶文を返す関数を定義する
def make_greeting(name):
    # name を組み込んだ挨拶の文字列を、呼び出した場所へ返す
    return f"こんにちは {name}"
```

本体を字下げしなかった場合も、どこが関数の処理かを Python に伝えられず、実行前に問題を示すメッセージが表示されます。

## 7-9. `print()` と `return` の役割は違う

サンプルの `make_greeting` は、文字列を **返す** 関数です。呼び出しただけでは、挨拶は表示されません。`main` の `print(message1)` が、その文字列を **表示する** 処理です。

| 書き方 | このサンプルでの役割 |
| --- | --- |
| `return f"こんにちは {name}"` | 挨拶文を呼び出した場所へ返す |
| `message1 = make_greeting("たろう")` | 戻り値の挨拶文を `message1` に代入する |
| `print(message1)` | `message1` の文字列を画面に表示する |

返した文字列は、表示するほか、あとでファイルへ保存する処理でも使えます。表示と文字列を作る処理が分かれているので、文字列を使う場所を呼び出した側で決められます。

`print(...)` が表示した文字列を、そのまま戻り値として返すわけではありません。`print` の戻り値は `None` です。`None` は、ここでは挨拶文のような結果の値がないことを表します。

## 7-10. 複数の引数を指定する

次は、2つの数字を足す関数の説明用の例です。挨拶サンプルへ追加する必要はありません。

```python
# add_numbers は「数字を足す」という意味
# number1 と number2 は「1つ目の数字」と「2つ目の数字」という意味
# 2つの値を受け取り、その合計を返す関数を定義する
def add_numbers(number1, number2):
    # number1 と number2 の合計を、呼び出した場所へ返す
    return number1 + number2


# answer は「答え」という意味
# 10と20で add_numbers を呼び出し、戻った合計を answer に代入する
answer = add_numbers(10, 20)
# answer の値を画面に表示する
print(answer)
```

引数はカンマ `,` で区切って指定してください。この例では、順番に `10` が `number1`、`20` が `number2` の値になります。関数が返した `30` を `answer` に代入し、`print` で表示します。実行すると、ターミナルには次の結果が表示されます。

```text
30
```

## 7-11. 繰り返しと関数を使う場面

`for` や `while` は、その場所で処理を繰り返すための書き方です。関数は、処理に名前を付けて、必要な場所から呼び出すためのものです。

今回の `make_greeting` は、`main` の2か所から、違う名前で呼び出しています。関数の本体を直すと、どちらの呼び出しにも変更が反映されます。

関数の中に繰り返しを書き、何回も行う処理をまとめることもできます。関数と繰り返しは、どちらか一方を選ぶものではありません。

## 7-12. 挨拶を変更してみる

たろうとさくらの両方に、「ようこそ」と表示するように変更してください。

1. VS Code で、保存した `greeting_function.py` を開いてください。
2. **5行目**の `return` を探してください。Ctrl + F（macOS は Command + F）を押し、検索欄に `return f"こんにちは {name}"` と入力しても探せます。
3. [`greeting_function.py` の4〜5行](./greeting_function.py#L4-L5)の2行を、下の変更後の例へ置き換えてください。

変更前：

このコードの元ファイル：[`greeting_function.py` の 4〜5行](./greeting_function.py#L4-L5)。


変更後：

変更する場所：[`greeting_function.py` の5行](./greeting_function.py#L5-L5)。

```python
    # name を組み込んだ挨拶の文字列を、呼び出した場所へ返す
    return f"ようこそ {name}さん"
```

4. Ctrl + S（macOS は Command + S）を押して保存してください。
5. VS Code の **表示 → ターミナル** を選び、7-4で保存先へ移動した同じターミナルを表示してください。


変更したのは関数の本体の1か所ですが、両方の挨拶が変わります。呼び出す側の `"たろう"` と `"さくら"` を直す必要はありません。

## 7-13. 今回の内容

- `print` と `input` も、名前のあとに `()` を付けて呼び出す関数。
- `def` は関数を定義する文。本体は、呼び出したときに実行される。
- 引数は呼び出すときに指定する値。戻り値は関数から呼び出した場所へ返る値。
- `return` は関数を終えて戻る文。`print` は画面へ表示する関数。
- `main` も自分で定義した関数。名前を付けただけでは実行されない。
- ファイル末尾の条件と `main()` で、直接実行したときの入口を示す。
- 関数の本体を1か所直すと、その関数を使う場所すべてに変更が反映される。

書き方の詳しい説明は、[Python公式：関数を定義する](https://docs.python.org/ja/3/tutorial/controlflow.html#defining-functions)と[Python公式：`__main__`](https://docs.python.org/ja/3/library/__main__.html)でも確認できます。
