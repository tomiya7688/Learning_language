# 10. リスト

3人の点数が80点・90点・70点だったとします。点数を1人ずつ別の変数に入れて足していると、人数が増えるたびに、変数も足し算のコードも増えてしまいます。

> **「100人分を全部別々に書くの？1人増えたら、また書き直し？」**

点数を一覧にして、人数が変わっても同じ計算で合計を出したいところです。この章のプログラムは、点数の一覧へ100点を追加し、4件・合計340点を表示します。複数の値を順に並べた一覧を **リスト** と呼びます。

---

## 10-1. 今回作るもの

複数の点数を1つずつ別の変数に入れるのではなく、まとめて持てるようにしてください。

点数の一覧なので、名前は `scores` にしてください。

このコードの元ファイル：[`score_list.py` の 2〜2行](./score_list.py#L2-L2)。

```python
scores = [80, 90, 70]
```

次のコードは、点数のリストへ100点を追加する処理です。

このコードの元ファイル：[`score_list.py` の 5〜5行](./score_list.py#L5-L5)。

```python
scores.append(100)
```

このプログラムは、そのあと、点数を1つずつ表示しながら合計も計算します。

```text
80
90
70
100
件数: 4
合計: 340
```

---

## 10-2. なぜリストが必要なの？

3人分くらいなら、

```python
score1 = 80
score2 = 90
score3 = 70
```

でも何とかなります。

では、100人分ならどうでしょうか。

```python
score1 = 80
score2 = 90
score3 = 70
# ...
score99 = 85
score100 = 92
```

となります。

しかも101人目が増えたら、また変数を追加する必要があります。

> **「何個書けばええんや！！！100個だっつってんだろ！」**

となってきます。

そこで使うのが **リスト** です。

リストを使えば、

このコードの元ファイル：[`score_list.py` の 2〜2行](./score_list.py#L2-L2)。

```python
scores = [80, 90, 70]
```

のように、複数の値を1つの変数にまとめられます。

ここでも本質は同じです。

> **同じ種類の変数を何十個も素直に書いたら日が暮れるから、1つにまとめている**

だけです。

---

## 10-3. 点数の一覧を作る

[score_list.py](./score_list.py) を開いてください。

`score` は「点数」、`list` は「一覧」という意味です。

このプログラムは、まず3つの点数をまとめるので、`scores` というリストを作ります。

このコードの元ファイル：[`score_list.py` の 1〜21行](./score_list.py#L1-L21)。

```python
# 3つの点数を scores というリストにまとめます。
scores = [80, 90, 70]

# 新しい点数を追加します。
scores.append(100)

# 最初の要素を表示します。
print("最初の点数:", scores[0])

# 要素の数を表示します。
print("件数:", len(scores))

# 合計を保存する total を0から始めます。
total = 0

# リストの点数を1つずつ取り出します。
for score in scores:
    print(score)
    total = total + score

print("合計:", total)
```

## 10-4. リストを作る

リストは、`[ ]` を使って作ってください。

このコードの元ファイル：[`score_list.py` の 2〜2行](./score_list.py#L2-L2)。

```python
scores = [80, 90, 70]
```

この場合、

```text
80
90
70
```

という3つの値を、`scores` という1つの変数へまとめています。

---

## 10-5. リストの中の1つ1つを「要素」と呼ぶ

リストの中に入っている値を **要素** と呼びます。

このコードの元ファイル：[`score_list.py` の 2〜2行](./score_list.py#L2-L2)。

```python
scores = [80, 90, 70]
```

なら、

- `80`
- `90`
- `70`

がそれぞれ要素です。

リストは、複数の値を順番に並べて保存するデータです。中に入っている値を要素と呼びます。

---

## 10-6. 番号で値を取り出す

リストの中の値は、番号を使って取り出せます。

```python
print(scores[0])
```

実行結果:

```text
80
```

ここで注意するのは、最初の要素が `0` 番だということです。

```text
scores = [80, 90, 70]
          ↑   ↑   ↑
          0   1   2
```

この番号を **添字（インデックス）** と呼びます。

---

## 10-7. なぜ0から始まるの？

Pythonでは、リストの最初の要素を `0` 番として扱います。

最初は少し違和感があるかもしれません。

```python
scores[0]
```

は「1番目の値」です。

```python
scores[1]
```

は「2番目の値」です。

リストの添字は `0` から始まります。そのため `scores[1]` は2番目の値を表します。

---

## 10-8. `append()` で追加する

リストの最後へ新しい値を追加するときは、`append()` を使ってください。

このコードの元ファイル：[`score_list.py` の 5〜5行](./score_list.py#L5-L5)。

```python
scores.append(100)
```

もともと、

```python
[80, 90, 70]
```

だったリストが、

```python
[80, 90, 70, 100]
```

になります。

`append` は「付け加える」という意味です。

---

## 10-9. またドットが出てきた

ここでも、

```text
A.B
```

という形が出てきます。

このコードの元ファイル：[`score_list.py` の 5〜5行](./score_list.py#L5-L5)。

```python
scores.append(100)
```

は、

> `scores` というリストが持っている `append` を使う

という意味です。

つまり、

```text
scores . append(100)
   ↑        ↑
リスト    追加する機能
```

です。

---

## 10-10. `len()` で個数を調べる

リストに何個の要素が入っているか調べるには、`len()` を使ってください。

```python
print(len(scores))
```

`scores` が、

```python
[80, 90, 70, 100]
```

なら、

```text
4
```

と表示されます。

`len` は length（長さ）から来ています。

---

## 10-11. `for` と組み合わせる

リストは `for` ととても相性が良いです。

このコードの元ファイル：[`score_list.py` の 17〜18行](./score_list.py#L17-L18)。

```python
for score in scores:
    print(score)
```

と書くと、リストの要素を1つずつ取り出せます。

流れは、

```text
80 → score
90 → score
70 → score
100 → score
```

です。

そのたびに、

このコードの元ファイル：[`score_list.py` の 18〜18行](./score_list.py#L18-L18)。

```python
print(score)
```

が実行されます。

---

## 10-12. リストがあると繰り返しが便利になる

リストがなければ、

```python
print(score1)
print(score2)
print(score3)
```

のように1つずつ書くことになります。

リストなら、

このコードの元ファイル：[`score_list.py` の 17〜18行](./score_list.py#L17-L18)。

```python
for score in scores:
    print(score)
```

だけです。

データが3個でも100個でも、基本的な書き方は変わりません。

---

## 10-13. 合計を作る

合計を作るには、足した結果を保存する場所が必要です。

名前は `total` にして、最初はまだ何も足していないので `0` から始めてください。

```python
total = 0

for score in scores:
    total = total + score
```

最初は、

このコードの元ファイル：[`score_list.py` の14行](./score_list.py#L14-L14)。

```text
total = 0
```

です。

そこへ順番に、

```text
0 + 80 = 80
80 + 90 = 170
170 + 70 = 240
240 + 100 = 340
```

と足していきます。

最後に、

```text
340
```

が残ります。

---

## 10-14. 自分で値を変えてみる

たとえば、

```python
scores = [100, 50, 75]
```

に変えてみてください。

また、

```python
scores.append(60)
scores.append(95)
```

のように複数追加しても構いません。

`len()` の結果や合計が変わることを確認してください。

---

## 10-15. 文字列も入れられる

リストには数字だけでなく、文字列も入れられます。

```python
names = ["たろう", "さくら", "けん"]
```

そして、

```python
for name in names:
    print(name)
```

と順番に表示できます。
