# 3. 入力と変数

前の章では、`print("Hello World!")` で、コードに書いた文字列を表示しました。挨拶の名前まで `print("こんにちは たろう")` のようにコードへ固定してしまうと、使う人がさくらに変わっても「こんにちは たろう」と表示されてしまいます。

> **「名前を変えるだけなのに、毎回コードを書き直すの？」**

使う人が自分の名前を入力できれば、挨拶のコードを書き直さずに済みます。この章では、入力した名前で挨拶するプログラムを作ります。

## 3-1. 名前を尋ねるプログラムを保存する

VS Codeの **ファイル → 新しいテキストファイル** を選び、次のコード全体を書いてください。コードの仕組みは、実際に名前を入力したあとで説明します。

[`greeting.py` の1〜5行](./greeting.py#L1-L5)

```python
# キーボードで入力された名前を、name という名前であとから使えるようにする
name = input("名前を入力してください: ")

# 入力された名前を使って、ターミナルに挨拶を表示する
print("こんにちは", name)
```

**ファイル → 名前を付けて保存** を選び、第2章で使った学習用フォルダへ `greeting.py` という名前で保存してください。`hello_world.py` は残してください。`greeting` は英語で「挨拶」という意味で、`.py` はPythonのファイル名の末尾に付ける部分です。

## 3-2. 起動して、自分の名前を入力する

1. エクスプローラー（Windows）、Finder（macOS）、ファイル管理アプリ（Linux）で、`greeting.py` を保存した学習用フォルダを開いてください。
2. 保存先の場所を表す文字列を「パス」といいます。次の方法で、学習用フォルダのパスをコピーしてください。
   - Windows：開いたフォルダの上部のアドレス欄をクリックし、Ctrl + Cを押してください。
   - macOS：Finderで学習用フォルダを選び、Option + Command + Cを押してください。
   - Linux（GNOMEの「ファイル」）：学習用フォルダを開き、Ctrl + L、Ctrl + Cの順に押してください。
3. VS Codeの **表示 → ターミナル** を選んでください。ターミナルは、実行するコマンドを入力する欄です。
4. 開いたターミナルに `cd "コピーした学習用フォルダのパス"` と入力してください。引用符の中を、手順2でコピーしたパスに置き換え、Enterキーを押してください。`cd` は、ターミナルで作業するフォルダを変えるコマンドです。
5. 保存先へ移動した同じターミナルに、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

コマンドはコードを書く編集欄へ入力しないでください。ターミナルに最初から表示されている `PS C:\...>` や `$` などの文字も入力しないでください。

プログラムが起動すると、ターミナルに次の案内が表示され、名前の入力を待ちます。

```text
名前を入力してください:
```

案内が出ているターミナルをクリックし、案内の後ろに `たろう` と入力してEnterキーを押してください。`名前を入力してください:` はプログラムが表示する案内なので、入力するのは `たろう` だけです。

ターミナルには、入力した名前と挨拶が次のように残ります。

```text
名前を入力してください: たろう
こんにちは たろう
```

挨拶を表示すると、プログラムは終了します。続けて別の名前を入力するには、プログラムをもう一度起動します。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力してEnterキーを押してください。`名前を入力してください:` が出たら `さくら` と入力し、Enterキーを押してください。

```text
名前を入力してください: さくら
こんにちは さくら
```

コードの `print` の行を書き直さなくても、入力した名前に合わせて挨拶が変わりました。

起動するコマンドで `can't open file` と表示された場合は、`greeting.py` の保存先とファイル名を確認し、この節の手順1からやり直してください。第2章の[保存先への移動と実行の手順](../02_最初のプログラム/最初のプログラム.md#run-hello-world)にも、フォルダの場所を確認する説明があります。

## 3-3. 入力した名前を、次の行で使う仕組み

### `input(...)` が名前の入力を待つ

[`greeting.py` の1〜2行](./greeting.py#L1-L2)

```python
# キーボードで入力された名前を、name という名前であとから使えるようにする
name = input("名前を入力してください: ")
```

`input("名前を入力してください: ")` を実行すると、Pythonは括弧の中の案内をターミナルへ表示し、入力を待ちます。利用者が名前を入力してEnterキーを押すと、Pythonは入力内容を文字列として受け取ります。

`たろう` と入力した場合に受け取る値は、文字列 `"たろう"` です。コードの中で文字列を書くときは引用符で囲みますが、名前を尋ねられたターミナルでは引用符を付けずに入力してください。

### `name` は、受け取った名前をあとで使うための名前

挨拶を表示する行でも入力内容を使いたいので、受け取った文字列に `name` という名前を付けています。**値をあとから使うために付ける名前を、変数といいます。** `name` は英語で「名前」という意味です。

`name = input("名前を入力してください: ")` では、Pythonがまず `=` の右側の `input(...)` を実行します。入力内容を受け取ると、Pythonは入力された文字列を、左側の `name` で使えるようにします。値を名前で使えるようにする操作を **代入** といいます。

`たろう` と入力したあとは、`name` と書くと文字列 `"たろう"` を使えます。別の起動で `さくら` と入力したあとは、`name` と書くと文字列 `"さくら"` を使えます。

### `print(...)` が、入力された名前で挨拶を表示する

[`greeting.py` の4〜5行](./greeting.py#L4-L5)

```python
# 入力された名前を使って、ターミナルに挨拶を表示する
print("こんにちは", name)
```

`print("こんにちは", name)` は、文字列 `"こんにちは"` と、`name` で使える入力内容を、間に空白を入れてターミナルへ表示します。`name` を引用符で囲まないのは、`name` という文字列ではなく、入力された名前を使うためです。

| `たろう` と入力した場合の書き方 | 表示される内容 |
| --- | --- |
| `print("こんにちは", name)` | `こんにちは たろう` |
| `print("こんにちは", "name")` | `こんにちは name` |

表の2行目は、引用符による違いを説明するための例です。`greeting.py` に追加するコードではありません。

このプログラムでは、入力内容を名前で使えるようにしているだけで、入力内容をパソコンのファイルへ保存してはいません。プログラムを起動し直すと、再び名前の入力を待ちます。

## 3-4. 好きな食べ物を尋ねるように変える

名前で挨拶する代わりに、入力した好きな食べ物を表示してみてください。`food` は英語で「食べ物」という意味です。受け取る内容に合わせて、変数名も `name` から `food` に変えます。

VS Codeで `greeting.py` を開き、[元の1〜5行](./greeting.py#L1-L5)に当たる内容全体を次の練習用コードへ置き換えてください。

```python
# 入力された食べ物を、food という名前であとから使えるようにする
food = input("好きな食べ物を入力してください: ")

# 入力された食べ物をターミナルに表示する
print("好きな食べ物は", food, "ですね")
```

1. VS Codeで `greeting.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

`好きな食べ物を入力してください:` が出たら、同じターミナルに `カレー` と入力してEnterキーを押してください。

```text
好きな食べ物を入力してください: カレー
好きな食べ物は カレー ですね
```

質問の文字列と、入力内容に付ける名前を変えることで、同じ流れを別の質問にも使えます。食べ物を尋ねる変更は、残したまま次の章へ進めます。次の章では、別のファイルを作ってください。

## 3-5. 今回の内容

- `input(...)` は案内を表示し、利用者が入力してEnterキーを押すまで待ちます。
- 変数は、値をあとから使うために付ける名前です。
- `=` は、右側の値を左側の名前で使えるようにするための記号です。
- `print("こんにちは", name)` は、文字列 `"こんにちは"` と、`name` で使える入力内容を表示します。
