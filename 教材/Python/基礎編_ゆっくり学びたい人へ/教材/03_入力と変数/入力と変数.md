# 3. 入力と変数

2章では、`print()` の括弧の中に書く文字列を変えると、表示する文章も変わることを試しました。同じ書き方で、名前を入れた挨拶も表示できます。

次は、2章の書き方を使った説明用の例です。

```python
# 「こんにちは たろう」という文字列を画面に表示する
print("こんにちは たろう")
```

このコードを動かすと、ターミナルに次の挨拶が表示されます。

```text
こんにちは たろう
```

コードに名前を直接書いているため、さくらが使っても表示は「こんにちは たろう」のままです。「こんにちは さくら」と表示するには、コードの「たろう」を「さくら」に書き換える必要があります。

> **「私、たろうじゃないんだけど！名前くらい変えさせて！」**

使う人が変わるたびに、コードの名前を書き換えるのは手間です。使う人がキーボードから名前を入力し、その名前で挨拶を表示するようにしたいですね。この章では、入力した名前で挨拶するプログラムを作ります。

## 3-1. 入力した名前を覚えておく

まずは、プログラムで名前を尋ねて、入力された内容を受け取ります。`input("名前を入力してください: ")` と書くと、Pythonは括弧の中の案内をターミナルへ表示し、利用者が入力してEnterキーを押すまで待ちます。

受け取った名前は、あとで挨拶にも使いたいので、名前を付けて覚えておきます。**値に付ける名前を、変数といいます。** 今回は、人の名前を受け取るので、変数名には英語で「名前」を意味する `name` を使います。

VS Codeの **ファイル → 新しいテキストファイル** を選び、次の3行を書いてください。ここでは名前を受け取るところまでを作ります。

[`greeting.py` の1〜3行](./greeting.py#L1-L3)

```python
# name は「名前」という意味の変数（実行中に使う値へ付ける名前）
# name に「名前を入力してください: 」と表示して入力された文字列を入れる
name = input("名前を入力してください: ")
```

`=` の右側に、覚えておきたい値を求めるコードを書き、左側に、その値に付ける名前を書きます。この行では、Pythonが右側の `input(...)` で入力内容を受け取ってから、左側の `name` で使えるようにします。この操作を **代入** といいます。

**ファイル → 名前を付けて保存** を選び、第2章で使った学習用フォルダへ `greeting.py` として保存してください。`greeting` は英語で「挨拶」という意味です。第2章で作った `hello_world.py` は残してください。

## 3-2. 名前を入力してみる

保存した `greeting.py` を実行して、名前を入力できるか確かめてください。

1. エクスプローラー（Windows）、Finder（macOS）、ファイル管理アプリ（Linux）で、`greeting.py` を保存した学習用フォルダを開いてください。
2. フォルダの場所を表す文字列を「パス」といいます。次の方法で、`greeting.py` を保存した学習用フォルダのパスをコピーしてください。
   - Windows：開いたフォルダの上部のアドレス欄をクリックし、Ctrl + Cを押してください。
   - macOS：Finderで学習用フォルダを選び、Option + Command + Cを押してください。
   - Linux（GNOMEの「ファイル」）：学習用フォルダを開き、Ctrl + L、Ctrl + Cの順に押してください。
3. VS Codeの **表示 → ターミナル** を選んでください。画面下に開くターミナルは、実行するコマンドを入力する欄です。
4. 開いたターミナルに `cd "コピーした学習用フォルダのパス"` と入力してください。引用符の中は、手順2でコピーしたパスに置き換えてください。WindowsではCtrl + V、macOSではCommand + V、LinuxではCtrl + Shift + Vで貼り付け、Enterキーを押してください。`cd` は、ターミナルで作業するフォルダを変えるコマンドです。
5. 保存先へ移動した同じターミナルに、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

コマンドはPythonのコードを書く編集欄へ入力しないでください。ターミナルに既に表示されている `PS C:\...>` や `$` などの文字も入力しないでください。

起動したプログラムが、ターミナルへ次の案内を表示します。

```text
名前を入力してください:
```

案内が表示されているターミナルをクリックし、`名前を入力してください:` の後ろに `さくら` と入力して、Enterキーを押してください。入力するのは `さくら` だけです。案内の文字や引用符は入力しないでください。

```text
名前を入力してください: さくら
```

今のコードには挨拶を表示する行がないので、入力を受け取るとプログラムは終了します。入力した文字列 `"さくら"` には `name` という名前が付きましたが、表示する行をまだ書いていません。

起動コマンドに対して `can't open file` と表示された場合は、`greeting.py` の保存先とファイル名を確認し、この節の手順1からやり直してください。パスの確認方法は、第2章の[保存したファイルを実行する手順](../02_最初のプログラム/最初のプログラム.md#run-hello-world)でも説明しています。

## 3-3. 入力した名前で挨拶する

入力した名前で挨拶するには、`greeting.py` に表示する行が必要です。VS Codeで `greeting.py` を開き、`name = input("名前を入力してください: ")` の下に、説明ページの案内を含めて次の3行を追加してください。

[`greeting.py` の4〜6行](./greeting.py#L4-L6)

```python
# 入力内容をファイルへは保存しない。作り方は同じフォルダの「入力と変数.md」を参照
# 「こんにちは」と name の値を、間に空白を入れてターミナルに表示する
print("こんにちは", name)
```

`print("こんにちは", name)` と書くと、Pythonは文字列 `"こんにちは"` と、`name` の値を、間に空白を入れて表示します。表示したいものが複数あるときは、括弧の中でカンマ `,` を使って区切ります。

保存するコード全体は、次の6行です。`input` で名前を受け取り、次の `print` でその名前をもう1回使っています。

[`greeting.py` の1〜6行](./greeting.py#L1-L6)

```python
# name は「名前」という意味の変数（実行中に使う値へ付ける名前）
# name に「名前を入力してください: 」と表示して入力された文字列を入れる
name = input("名前を入力してください: ")
# 入力内容をファイルへは保存しない。作り方は同じフォルダの「入力と変数.md」を参照
# 「こんにちは」と name の値を、間に空白を入れてターミナルに表示する
print("こんにちは", name)
```

1. VS Codeで `greeting.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. 同じターミナルに、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

`名前を入力してください:` が表示されたら、同じターミナルに `さくら` と入力してEnterキーを押してください。

```text
名前を入力してください: さくら
こんにちは さくら
```

入力された名前で挨拶を表示できました。次は `greeting.py` を起動し直して別の名前を入力し、挨拶が変わるか確かめてください。VS Codeの **表示 → ターミナル** で同じターミナルを表示し、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力してEnterキーを押してください。名前の案内が出たら、`たろう` と入力してEnterキーを押してください。

```text
名前を入力してください: たろう
こんにちは たろう
```

挨拶のコードを書き直さなくても、入力する名前を変えると挨拶も変わります。変数を使うと、**一度受け取った値を、あとでもう1回使えます。** 入力内容はファイルへ保存していないので、プログラムを起動し直すたびに名前の入力を待ちます。

## 3-4. 引用符と `=` の書き方を確かめる

### `name` と `"name"` は違う

入力された名前を表示するには、変数名の `name` を引用符で囲まずに書きます。`"name"` と囲むと、入力内容ではなく `name` という文字列になります。

次の表は、`さくら` と入力した場合の違いを示す説明用の例です。ファイルに追加するコードではありません。

| 書き方 | 表示される内容 |
| --- | --- |
| `print("こんにちは", name)` | `こんにちは さくら` |
| `print("こんにちは", "name")` | `こんにちは name` |

### `=` は、等しいかを調べる記号ではない

Pythonの `=` は、数学の「左右が等しい」という意味ではありません。右側の値を左側の名前へ代入するための記号です。値が同じかを調べる場合は、`=` を2つ並べた `==` を使います。

次の表も書き方を比べる説明用の例で、ファイルへ追加するコードではありません。

| 書き方 | Pythonが行うこと |
| --- | --- |
| `name = "たろう"` | 文字列 `"たろう"` を、`name` という名前で使えるようにする |
| `name == "たろう"` | `name` の値が文字列 `"たろう"` と同じかを調べる。同じなら `True`（条件に合う）、違えば `False`（条件に合わない）になる。`name` の値は変えない |

## 3-5. 好きな食べ物を尋ねてみる

質問を「好きな食べ物」に変えてみてください。受け取るのは食べ物なので、変数名には英語で「食べ物」を意味する `food` を使います。

VS Codeで `greeting.py` を開き、[元の1〜6行](./greeting.py#L1-L6)に当たる内容全体を、次の練習用コードへ置き換えてください。

```python
# food は「食べ物」という意味の変数
# food に「好きな食べ物を入力してください: 」と表示して入力された文字列を入れる
food = input("好きな食べ物を入力してください: ")

# 「好きな食べ物は」と food の値と「ですね」を、間に空白を入れてターミナルに表示する
print("好きな食べ物は", food, "ですね")
```

1. VS Codeで `greeting.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. 同じターミナルに、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

`好きな食べ物を入力してください:` が表示されたら、同じターミナルに `カレー` と入力してEnterキーを押してください。

```text
好きな食べ物を入力してください: カレー
好きな食べ物は カレー ですね
```

質問の案内と、入力内容に付ける名前、表示する文章を変えると、別の質問にも使えます。食べ物を尋ねる変更は残したまま次の章へ進めます。第4章では、別のファイルを作ります。

## 3-6. 今回の内容

- `input(...)` は、括弧の中の案内を表示して入力を待ち、利用者がEnterキーを押すと入力内容を文字列として受け取ります。
- 変数は、値に付ける名前です。入力した値を、あとの行でもう1回使えます。
- `=` は代入、`==` は値が同じかを調べる比較に使います。
- 変数名を引用符で囲まずに書くと、その名前の値を使えます。引用符で囲むと、そのままの文字列になります。
