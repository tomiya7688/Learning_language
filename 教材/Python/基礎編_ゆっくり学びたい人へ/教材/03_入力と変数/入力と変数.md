# 3. 入力と変数

2章では、`print()` の丸括弧 `()` に書いた文字列を変えると、表示される文章が変わりました。同じ `print()` を使って、まずは名前を含む文章を表示してみましょう。

VS Codeで、2章の `hello_world.py` を保存した学習用フォルダを使います。**`hello_world.py` は書き換えず、新しく `greeting.py` を作ってください。** `greeting` は英語で「挨拶」、`.py` はPythonのファイルに付ける拡張子です。

1. VS Codeの **ファイル → 新しいテキストファイル** を選んでください。
2. 開いた編集欄へ、次の2行を書いてください。これは**最初の練習用コード**です。配布している `greeting.py` は章の終わりの完成形なので、この段階ではコピーしません。

```python
# 「こんにちは たろう」という文字列をターミナルに表示する
print("こんにちは たろう")
```

3. VS Codeの **ファイル → 名前を付けて保存** を選び、2章で使った学習用フォルダへ `greeting.py` という名前で保存してください。`hello_world.py` と同じフォルダに別のファイルができればOKです。
4. VS Codeの **表示 → ターミナル** でターミナルを開いてください。2章で学習用フォルダへ移動したターミナルが残っていれば、そのまま使えます。別のフォルダを表示している場合は、`greeting.py` を保存したフォルダへ `cd` で移動してください。移動の方法は[2章の実行手順](../02_最初のプログラム/最初のプログラム.md#run-hello-world)で確認できます。
5. ターミナルに、使っているOSのコマンドを入力し、Enterキーを押してください。

Windows：

```powershell
python greeting.py
```

macOS / Linux：

```bash
python3 greeting.py
```

ターミナルには、次の文字が表示されます。

```text
こんにちは たろう
```

しかし、あなたはこう思ったかもしれません。

> **「私、たろうじゃないんだけど！名前くらい変えさせて！」**

今の `greeting.py` は、誰が使っても「こんにちは たろう」と表示します。使う人が変わるたびに、VS Codeで `"たろう"` を書き直すのは面倒です。**使う人に名前を入力してもらい、その名前を表示できるようにしていきましょう。**

## 3-1. 入力した名前を覚えておく

まずは、`greeting.py` が使う人へ名前を尋ねるように変えましょう。

`input("名前を入力してください: ")` は、ターミナルへ `名前を入力してください:` と表示し、キーボードから文字を入力してEnterキーを押すまで待ちます。Enterキーを押すと、入力された文字を`input()`が受け取ります。

受け取った名前を、後で表示するときにも使いたいので、その値に名前を付けて覚えておきます。名前に名前、紛らわしいですね。**値に付ける名前を「変数」といいます。** 利用者が入力する名前には、英語で「名前」を意味する `name` という変数名を付けましょう。

VS Codeで先ほど保存した `greeting.py` を開いてください。最初に書いた2行を、次の3行に**置き換えて**ください。`print("こんにちは たろう")` は残しません。

完成版で対応する部分：[`greeting.py` の1〜3行](./greeting.py#L1-L3)。

```python
# name は「名前」という意味の変数（実行中に使う値へ付ける名前）
# name に「名前を入力してください: 」と表示して入力された文字列を入れる
name = input("名前を入力してください: ")
```

`=` は、**右側で受け取った値を左側の名前に入れる**ための記号です。この行では、`input()` がキーボードから受け取った文字列を、変数 `name` に入れます。この操作を「代入」といいます。

Windows / LinuxならCtrl + S、macOSならCommand + Sで `greeting.py` の変更を保存してください。保存したら、同じファイルを次の節で実行しましょう。

## 3-2. 名前を入力してみる

VS Codeの **表示 → ターミナル** で、先ほど `greeting.py` を実行したターミナルを開いてください。学習用フォルダへ移動した状態で、Windowsなら `python greeting.py`、macOS / Linuxなら `python3 greeting.py` を入力してEnterキーを押してください。

ターミナルに次の案内が表示され、入力を待ちます。

```text
名前を入力してください:
```

この案内が表示されているターミナルへ、試しに `さくら` と入力してEnterキーを押してください。案内の「名前を入力してください:」は自分で入力しません。

```text
名前を入力してください: さくら
```

ここで実行は終わります。せっかく名前を入力したのに、まだ挨拶は表示されません。**今の `greeting.py` は名前を受け取る3行だけで、`print()` で表示する行がないからです。**

もし `can't open file` と表示されたら、`greeting.py` の保存場所とターミナルで開いているフォルダを確認してください。[2章のフォルダ移動手順](../02_最初のプログラム/最初のプログラム.md#run-hello-world)も参照できます。

## 3-3. 入力した名前で挨拶する

さて、入力した名前を使ってみましょう。`こんにちは さくら` と表示するには、`greeting.py` に `print()` の行を追加します。

VS Codeで `greeting.py` を開き、`name = input("名前を入力してください: ")` の**下**に次の3行を追加してください。最初の3行は消しません。

追加する3行の元ファイル：[`greeting.py` の4〜6行](./greeting.py#L4-L6)。

```python
# 入力内容をファイルへは保存しない。作り方は同じフォルダの「入力と変数.md」を参照
# 「こんにちは」と name の値を、間に空白を入れてターミナルに表示する
print("こんにちは", name)
```

`print("こんにちは", name)` は、文字列 `"こんにちは"` と、変数 `name` に入れた名前を、間に空白を入れて表示します。`"こんにちは"` と `name` を並べる間には、カンマ `,` が必要です。カンマを省くと正しく実行できません。

`greeting.py` の全体は、次の6行になります。すでに書いた3行と追加した3行がつながっているか、確認してください。

6行の完成版の元ファイル：[`greeting.py` の1〜6行](./greeting.py#L1-L6)。

```python
# name は「名前」という意味の変数（実行中に使う値へ付ける名前）
# name に「名前を入力してください: 」と表示して入力された文字列を入れる
name = input("名前を入力してください: ")
# 入力内容をファイルへは保存しない。作り方は同じフォルダの「入力と変数.md」を参照
# 「こんにちは」と name の値を、間に空白を入れてターミナルに表示する
print("こんにちは", name)
```

では、あなたの名前や好きな名前を入力してみましょう。

1. VS Codeで `greeting.py` を保存してください。Windows / LinuxならCtrl + S、macOSならCommand + Sです。
2. VS Codeの **表示 → ターミナル** で、先ほど使ったターミナルを開いてください。
3. Windowsなら `python greeting.py`、macOS / Linuxなら `python3 greeting.py` を入力し、Enterキーを押してください。
4. `名前を入力してください:` と表示されたら、`さくら` と入力してEnterキーを押してください。

```text
名前を入力してください: さくら
こんにちは さくら
```

**「こんにちは さくら」と表示されたら成功です。** `greeting.py` は終了していますので、同じターミナルで起動し直して別の名前を入れてみましょう。たとえば `たろう` と入力すれば、次のように変わります。

```text
名前を入力してください: たろう
こんにちは たろう
```

最初の `print("こんにちは たろう")` はコードを書き換えなければ名前が変わりませんでした。今は**同じ `greeting.py` のまま、入力した名前に合わせて表示を変えられます。** 変数 `name` に受け取った値を、後の `print()` でも使っているからです。


## 3-4. 引用符と `=` の書き方を確かめる

### `name` と `"name"` は違う

入力された名前を表示するには、変数名の `name` を引用符で囲まずに書きます。`"name"` と囲むと、入力内容ではなく `name` という文字列になります。

次の表は、`さくら` と入力した場合の違いを示す説明用の例です。ファイルに追加するコードではありません。

| 書き方 | 表示される内容 |
| --- | --- |
| `print("こんにちは", name)` | `こんにちは さくら` |
| `print("こんにちは", "name")` | `こんにちは name` |

### `=` は、等しいかを調べる記号ではない

Pythonの `=` は、数学の「左右が等しい」という意味ではありません。右側の値を左側の名前へ代入するための記号です。値が同じかを調べる場合は、`=` を2つ並べた `==` を使います。

次の表も書き方を比べる説明用の例で、ファイルへ追加するコードではありません。

| 書き方 | Pythonが行うこと |
| --- | --- |
| `name = "たろう"` | 文字列 `"たろう"` を、`name` という名前で使えるようにする |
| `name == "たろう"` | `name` の値が文字列 `"たろう"` と同じかを調べる。同じなら `True`（条件に合う）、違えば `False`（条件に合わない）になる。`name` の値は変えない |

## 3-5. 好きな食べ物を尋ねてみる

質問を「好きな食べ物」に変えてみてください。受け取るのは食べ物なので、変数名には英語で「食べ物」を意味する `food` を使います。

VS Codeで `greeting.py` を開き、[元の1〜6行](./greeting.py#L1-L6)に当たる内容全体を、次の練習用コードへ置き換えてください。

```python
# food は「食べ物」という意味の変数
# food に「好きな食べ物を入力してください: 」と表示して入力された文字列を入れる
food = input("好きな食べ物を入力してください: ")

# 「好きな食べ物は」と food の値と「ですね」を、間に空白を入れてターミナルに表示する
print("好きな食べ物は", food, "ですね")
```

1. VS Codeで `greeting.py` を開き、Windows / LinuxではCtrl + S、macOSではCommand + Sを押して保存してください。
2. VS Codeの **表示 → ターミナル** を選び、この章で保存先へ移動したターミナルを表示してください。
3. 同じターミナルに、Windowsでは `python greeting.py`、macOS / Linuxでは `python3 greeting.py` と入力し、Enterキーを押してください。

`好きな食べ物を入力してください:` が表示されたら、同じターミナルに `カレー` と入力してEnterキーを押してください。

```text
好きな食べ物を入力してください: カレー
好きな食べ物は カレー ですね
```

質問の案内と、入力内容に付ける名前、表示する文章を変えると、別の質問にも使えます。食べ物を尋ねる変更は残したまま次の章へ進めます。第4章では、別のファイルを作ります。

## 3-6. 今回の内容

- `input(...)` は、括弧の中の案内を表示して入力を待ち、利用者がEnterキーを押すと入力内容を文字列として受け取ります。
- 変数は、値に付ける名前です。入力した値を、あとの行でもう1回使えます。
- `=` は代入、`==` は値が同じかを調べる比較に使います。
- 変数名を引用符で囲まずに書くと、その名前の値を使えます。引用符で囲むと、そのままの文字列になります。

次の4章では、名前や食べ物の代わりに値段を入力し、2つの値段を足して合計を表示するプログラムを作ります。
