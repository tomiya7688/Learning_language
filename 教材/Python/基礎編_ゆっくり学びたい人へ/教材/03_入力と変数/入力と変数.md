# 3. 入力と変数

この章では、利用者が入力した内容を受け取り、
その内容をあとで使う方法を学びます。

今回作るのは、**名前を入力すると、その名前で挨拶するプログラム**です。

---

## 3-1. 今回作るもの

プログラムを実行したターミナルで、次のように進みます。

**1. プログラムが表示する案内**

```text
名前を入力してください:
```

**2. 自分で入力する名前**

VS Code のターミナルが表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んで開きます。このプログラムを実行したのと同じターミナルで、案内の後ろに `たろう` と入力し、Enter キーを押します。

```text
たろう
```

入力するのは名前だけです。`名前を入力してください:` はプログラムが表示する案内なので、自分では入力しません。名前は Python のコードを書く欄ではなく、ターミナルへ入力します。

**3. Enter キーを押したあとに、プログラムが表示する挨拶**

```text
こんにちは たろう
```

前の章では、あらかじめ決めた文字を表示するだけでした。

今回は、

> 利用者が入力する  
> ↓  
> 入力した内容を覚えておく  
> ↓  
> その内容を使う

という流れを作ります。

### 入力した名前をあとで使う

入力した名前で挨拶するには、受け取った入力内容を、挨拶を表示する行でも使う必要があります。

そのために、入力した値に `name` という名前を付けます。値をあとから使うために付ける名前を **変数** といいます。

たとえば `たろう` と入力した場合、`name` を使うと、入力した文字列 `"たろう"` を使えます。`さくら` と入力した場合は、同じ `name` で文字列 `"さくら"` を使えます。

このプログラムでは、入力した名前を `name` という変数で使えるようにし、挨拶を表示するときに使います。

---

## 3-2. 名前を受け取って保存する

[greeting.py](./greeting.py) を開いてください。

`greeting` は英語で「挨拶」という意味です。

ここでは、入力された名前を `name` という変数であとから使えるようにします。`name` は英語で「名前」という意味です。

```python
# input() で、利用者がキーボードから入力した文字を受け取ります。
# 受け取った文字を name という変数に保存します。
name = input("名前を入力してください: ")

# 保存した name の内容を使って挨拶します。
print("こんにちは", name)
```

---

## 3-3. `input()` とは

`input()` は、括弧の中で指定した案内を表示し、利用者が入力して Enter キーを押すまで待ちます。そのあと、入力された内容を文字列として受け取ります。

```python
# input() で、利用者がキーボードから入力した文字を受け取ります。
input("名前を入力してください: ")
```

実行すると、

```text
名前を入力してください:
```

と表示され、入力待ちになります。

このプログラムを実行したターミナルで、案内の後ろに名前を入力して Enter キーを押すと、その入力内容を Python が受け取ります。`名前を入力してください:` は入力しません。

---

## 3-4. 変数とは

次の部分を見てください。

```python
name = input("名前を入力してください: ")
```

ここで `name` は **変数** です。

変数は、値をあとから使うために付ける名前です。この例では、入力した文字列に `name` という名前を付けています。

今回なら、

```text
たろう
```

と入力した場合、

```text
name → "たろう"
```

というイメージです。

---

## 3-5. `=` は何をしている？

Python の `=` は、右側の値を左側の名前に **代入する** ときに使います。

```python
# "たろう" を name に代入する
name = "たろう"
```

なら、

> `"たろう"` という文字列を `name` という名前で使えるようにする

という意味です。`=` は、数学の「左右が等しい」という意味ではありません。

「同じ値かどうか」を調べるときは、`=` を2つ並べた **`==`** を使います。

```python
# "たろう" を name に代入する
name = "たろう"
# name の値が "たろう" と同じかどうかを調べ、結果を表示する
print(name == "たろう")
# name の値が "さくら" と同じかどうかを調べ、結果を表示する
print(name == "さくら")
```

実行結果:

```text
True
False
```

`True` は「同じ」、`False` は「同じではない」という、この比較の結果です。
`==` は比較するだけで、`name` の値を書き換えません。

- **`=`**: 値を代入する
- **`==`**: 値が同じかどうかを比較する

---

## 3-6. 保存した値を使う

```python
print("こんにちは", name)
```

では、先ほど保存した `name` を使っています。

たとえば `name` に `"たろう"` が入っていれば、

```text
こんにちは たろう
```

と表示されます。

つまり変数を使うと、

> 一度得た値を、あとで別の処理に使える

ようになります。

---

## 3-7. 自分で変えてみる

質問を変えてみましょう。

```python
food = input("好きな食べ物を入力してください: ")
print("好きな食べ物は", food, "ですね")
```

プログラムがターミナルに表示する案内:

```text
好きな食べ物を入力してください:
```

自分で入力する内容:

```text
カレー
```

このプログラムを実行したのと同じターミナルで、案内の後ろに `カレー` と入力し、Enter キーを押します。`好きな食べ物を入力してください:` はプログラムが表示するので、入力しません。

Enter キーを押したあとに、プログラムが表示する結果:

```text
好きな食べ物は カレー ですね
```

今度は好きな食べ物を覚えたいので、変数名を `food` にしましょう。

同じように、保存する内容に合わせて、

```text
name
food
age
color
```

のように名前を決められます。

---

## 3-8. ここまでで覚えること

この章で扱った内容をまとめます。

1. `input()` で利用者の入力を受け取れる
2. 変数は値に名前を付けて覚えておくために使う
3. `=` で右側の値を左側の変数へ入れられる
4. 保存した変数はあとから使える
