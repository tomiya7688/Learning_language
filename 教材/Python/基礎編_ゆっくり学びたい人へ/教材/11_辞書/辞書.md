# 11. 辞書

1人分の情報を「たろう、80、A」と並べておいて、あとから点数を変更したくなったとします。番号だけで取り出すと、「名前は何番？点数は何番？」と並び順を思い出す必要があります。

> **「何番目かじゃなくて、『点数』を指定したい！」**

この章では、名前や点数を項目名と組にして扱います。プログラムは1人分の情報から点数を取り出し、80点を90点へ変更します。項目名を指定して値を使えるまとまりを **辞書** と呼びます。

---

## 11-1. 今回作るもの

1人分の「名前」と「点数」を、別々の変数ではなく1つにまとめてください。

生徒の情報なので、名前は `student` にしてください。

このコードの元ファイル：[`student_dictionary.py` の 2〜5行](./student_dictionary.py#L2-L5)。

```python
student = {
    "name": "たろう",
    "score": 80
}
```

ここから名前や点数を取り出せます。

```python
print(student["name"])
print(student["score"])
```

さらに、クラス情報を追加したり、点数を更新したりしてみます。

このコードの元ファイル：[`student_dictionary.py` の 11〜14行](./student_dictionary.py#L11-L14)。

```python
student["class"] = "A"
student["score"] = 90
```

---

## 11-2. なぜ辞書が必要なの？

10章のリストでは、番号で値を取り出しました。

たとえば、

```python
student = ["たろう", 80, "A"]
```

とした場合、

```python
student[0]
student[1]
student[2]
```

で値を取り出せます。

でも、しばらくしてこのコードを見たとき、

> **「え、番号？しらんしらん、たろうだってたろう」**

となることがあります。

番号だけでは、その値が何を意味しているのか分かりにくいのです。

そこで使うのが **辞書** です。

```python
student = {
    "name": "たろう",
    "score": 80,
    "class": "A"
}
```

なら、

```python
student["name"]
student["score"]
student["class"]
```

のように、**意味のある名前で値を取り出せます。**

---

## 11-3. 生徒の辞書を作る

[student_dictionary.py](./student_dictionary.py) を開いてください。

`student` は「生徒」、`dictionary` は「辞書」という意味です。

次のコードは、名前と点数をまとめる `student` を作る処理です。

このコードの元ファイル：[`student_dictionary.py` の 1〜20行](./student_dictionary.py#L1-L20)。

```python
# 生徒1人分の名前と点数を student にまとめます。
student = {
    "name": "たろう",
    "score": 80
}

print("名前:", student["name"])
print("点数:", student["score"])

# 新しい情報を追加します。
student["class"] = "A"

# 既存の情報を更新します。
student["score"] = 90

print("更新後の点数:", student["score"])

# キーを key、対応する値を value に入れながら順番に表示します。
for key, value in student.items():
    print(key, ":", value)
```

---

## 11-4. 辞書を作る

辞書は `{ }` を使って作ってください。

このコードの元ファイル：[`student_dictionary.py` の 2〜5行](./student_dictionary.py#L2-L5)。

```python
student = {
    "name": "たろう",
    "score": 80
}
```

この中では、

```text
"name"  → "たろう"
"score" → 80
```

というように、名前と値をセットにしています。

---

## 11-5. 辞書はそのまま日本語で読んでいい

たとえば、

```python
{
    "name": "たろう",
    "score": 80
}
```

では、キー `"name"` に値 `"たろう"`、キー `"score"` に値 `80` が対応しています。

```text
"name": "たろう"
→ 名前はたろう

"score": 80
→ 点数は80
```

つまり辞書は、

> **項目名と、その中身をセットで並べている**

だけです。

記号を1文字ずつ難しく考えるより、まずは文章として読んだ方が分かりやすいです。

---

## 11-6. キーと値

辞書では、

```python
"name": "たろう"
```

の左側を **キー**、右側を **値** と呼びます。

```text
"name" : "たろう"
  ↑         ↑
キー       値
```

です。

`"score": 80` なら、

- キー: `"score"`
- 値: `80`

です。

---

## 11-7. キーを使って値を取り出す

辞書の値を取り出すときは、キーを指定してください。

```python
print(student["name"])
```

実行結果:

```text
たろう
```

同じように、

```python
print(student["score"])
```

なら、

```text
80
```

と表示されます。

---

## 11-8. リストとの違い

リストの値を取り出すときは、番号を指定してください。

```python
scores[0]
```

辞書の値を取り出すときは、キーを指定してください。

```python
student["name"]
```

大まかには、

```text
リスト
→ 順番で管理したい

辞書
→ 名前を付けて管理したい
```

という使い分けです。

---

## 11-9. 新しい情報を追加する

辞書へ新しい情報を追加するには、

このコードの元ファイル：[`student_dictionary.py` の 11〜11行](./student_dictionary.py#L11-L11)。

```python
student["class"] = "A"
```

と書いてください。

これで、

```python
{
    "name": "たろう",
    "score": 80,
    "class": "A"
}
```

になります。

---

## 11-10. 既存の値を更新する

すでにあるキーへ新しい値を入れると、値を更新できます。

このコードの元ファイル：[`student_dictionary.py` の 14〜14行](./student_dictionary.py#L14-L14)。

```python
student["score"] = 90
```

もともと `80` だった点数が `90` に変わります。

つまり、

```text
まだ無いキーに代入 → 追加
すでにあるキーに代入 → 更新
```

です。

---

## 11-11. キーが存在しないとどうなる？

たとえば、

```python
print(student["age"])
```

のように、存在しないキーを指定するとエラーになります。

辞書にないキーを指定すると、存在しないキーを参照したことを示す `KeyError` が発生します。キーがあるか確認するか、`.get()` を使うと、キーがない場合も処理できます。

---

## 11-12. `for` と組み合わせる

辞書も `for` と組み合わせられます。

キーと値を順番に表示したいので、`.items()` から2つずつ受け取ってください。

キーは `key`、対応する値は `value` に入れます。

このコードの元ファイル：[`student_dictionary.py` の 19〜20行](./student_dictionary.py#L19-L20)。

```python
for key, value in student.items():
    print(key, ":", value)
```

実行結果は、

```text
name : たろう
score : 90
class : A
```

のようになります。

---

## 11-13. `.items()` とは

```python
student.items()
```

これは、辞書の**キーと値を組にして取り出す**ための書き方です。

イメージは、

```text
"name"  と "たろう"
"score" と 90
"class" と "A"
```

です。

そして、

このコードの元ファイル：[`student_dictionary.py` の 19〜19行](./student_dictionary.py#L19-L19)。

```python
for key, value in student.items():
```

で、取り出したキーを `key`、値を `value` に入れます。

---

## 11-14. またドットが出てきた

9章の `scores.append()` と同じように、

```python
student.items()
```

も、

> `student` が持っている `items` を使う

という意味です。

```text
student . items()
   ↑        ↑
 辞書     キーと値を取り出す機能
```

です。

---

## 11-15. 辞書の中にリストを入れることもできる

辞書の値には、数字や文字だけでなく、リストも入れられます。

```python
student = {
    "name": "たろう",
    "scores": [80, 90, 70]
}
```

この場合、

```python
print(student["scores"])
```

で、

```text
[80, 90, 70]
```

を取り出せます。

---

## 11-16. リストの中に辞書を入れることもできる

逆に、リストの中へ辞書を入れることもできます。

```python
students = [
    {"name": "たろう", "score": 80},
    {"name": "さくら", "score": 90}
]
```

この形は、複数人のデータを扱うときによく使われます。

```python
for student in students:
    print(student["name"], student["score"])
```

と書けば、

```text
たろう 80
さくら 90
```

と表示できます。

---

## 11-17. JSONにつながる形

辞書は、あとで扱う **JSON** ととてもよく似た形をしています。

たとえば、

```python
{
    "name": "たろう",
    "score": 80
}
```

という形は、JSONでもよく出てきます。

そのため、辞書を理解しておくと、Web APIや設定ファイルを扱うときにも役立ちます。

辞書は、名前（キー）と値を組み合わせてデータをまとめます。JSONやWeb APIのデータでも、この形がよく使われます。

---

## 11-18. 自分で変えてみる

たとえば、

```python
student = {
    "name": "さくら",
    "score": 95
}
```

に変えてみてください。

さらに、

```python
student["age"] = 18
```

を追加してみても構いません。

`for` で表示したときに、新しい情報も出てくることを確認してください。

---

## 11-19. ここまでで覚えること

この章で扱った内容をまとめます。

1. 辞書はキーと値をセットで管理できる
2. `{ }` で辞書を作る
3. `student["name"]` のようにキーで値を取り出せる
4. 新しいキーへ代入すると情報を追加できる
5. 既存のキーへ代入すると値を更新できる
