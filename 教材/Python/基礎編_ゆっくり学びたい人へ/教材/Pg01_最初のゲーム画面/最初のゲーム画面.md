# Pg1. pygame「最初のゲーム画面」

自機を動かして遊ぶシューティングゲームには、文字の答えを表示する場所とは別に、自機や敵を描く画面が必要です。その画面を出せても、閉じるボタンに反応しなければ、遊び終わったときに困ります。

> **「画面出しただけで終わるな！閉じるボタン押したかちゃんと見とけ！」**

この章では、ゲーム用の画面を開き、閉じるボタンで終了できるところまで作ってみてください。パソコン上に開くアプリの画面の枠を **ウィンドウ** と呼びます。自機や敵は次の章から加えるため、最初は空の画面です。

---

## Pg1-1. pygameって何？

pygameは、Pythonでゲーム画面を作るために使える機能です。

画面に図形や画像を描いたり、キーボードやマウスの操作を受け取ったりできます。

Pythonに後から追加して使う機能のまとまりを、**外部ライブラリ**といいます。
pygameは、その外部ライブラリの1つです。

---

## Pg1-2. 今回作るもの

[first_game_window.py](./first_game_window.py) を開いてください。

`first` は「最初の」、`game` は「ゲーム」、`window` は「ウィンドウ」という意味です。

```python
# pygame をインポートする
import pygame

# pygame を初期化する
pygame.init()

# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
# pygame画面のタイトルに「最初のpygame」をセットする
pygame.display.set_caption("最初のpygame")

# running に True を入れる
running = True

# running が True の間、繰り返す
while running:
    # pygameで起きたイベントを1つずつ event に入れて繰り返す
    for event in pygame.event.get():
        # event.type が pygame.QUIT なら
        if event.type == pygame.QUIT:
            # running に False を入れる
            running = False

# pygame を終了する
pygame.quit()
```

実行すると、640×480のウィンドウが表示されます。

ウィンドウ右上の閉じるボタンを押すと、ゲームのプログラムが終了します。

## Pg1-3. まずpygameを入れる

pygameはPythonにもともと入っている機能ではないので、最初にインストールしてください。

Windows:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。


macOS / Linux:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。

これはPythonコードではなく、**ターミナルへ入力するコマンド**です。

## Pg1-8. なぜwhileが必要なの？

ここがpygameらしいところです。

```python
# running に True を入れる
running = True

# running が True の間、繰り返す
while running:
```

この `while running:` のコードで、プログラムは画面が開いている間、処理を繰り返します。

> **「一回見て終わりじゃゲームにならんやろ！」**

ゲームでは、画面が開いている間ずっと入力や状態を確認する必要があります。

この繰り返しを、よく **ゲームループ** と呼びます。

---

## Pg1-9. イベントを見る

```python
# pygameで起きたイベントを1つずつ event に入れて繰り返す
for event in pygame.event.get():
```

この `for` の処理で、プログラムはその時に起きた操作を順番に確認します。

たとえば、

- ウィンドウを閉じた
- キーを押した
- マウスを動かした
- マウスボタンを押した

などです。

---

## Pg1-10. 閉じるボタンを押したら

```python
# event.type が pygame.QUIT なら
if event.type == pygame.QUIT:
    # running に False を入れる
    running = False
```

は、

> 閉じる操作が来たら、ゲームループを終わらせる

という意味です。

`running` が `False` になると、

```python
# running が True の間、繰り返す
while running:
```

の繰り返しが終わります。

---

## Pg1-11. 最後にpygameを終了する

```python
# pygame を終了する
pygame.quit()
```

このコードで、プログラムはpygameを終了します。

流れをまとめると、

```text
pygameを準備
↓
画面を作る
↓
ゲームループ開始
↓
イベントを見る
↓
閉じる操作が来たらループ終了
↓
pygame終了
```

です。

## Pg1-13. ウィンドウが固まるとき

イベント処理をしないまま長い処理を続けると、OSから「応答していない」ように見えることがあります。

pygameではゲームループの中で、

```python
# pygameで起きたイベントを一覧として取得する
pygame.event.get()
```

を使ってイベントを処理していくのが重要です。
