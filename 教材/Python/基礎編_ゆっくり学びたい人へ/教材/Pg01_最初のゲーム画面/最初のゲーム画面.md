# Pg1. pygame「最初のゲーム画面」

自機を動かして遊ぶシューティングゲームには、文字の答えを表示する場所とは別に、自機や敵を描く画面が必要です。その画面を出せても、閉じるボタンに反応しなければ、遊び終わったときに困ります。

> **「画面出しただけで終わるな！閉じるボタン押したかちゃんと見とけ！」**

この章では、ゲーム用の画面を開き、閉じるボタンで終了できるところまで作ってみてください。パソコン上に開くアプリの画面の枠を **ウィンドウ** と呼びます。自機や敵は次の章から加えるため、最初は空の画面です。

## 起動から終了までを `main()` にまとめる

`def main():` は、起動時の処理に `main`（メイン）という名前を付けています。`main()` の `()` は、この名前の処理を呼び出す指定です。字下げされた行がその処理に含まれます。

画面を作る処理は `main()` の中にあります。`if __name__ == "__main__":` は、このファイルを直接実行したときにだけ `main()` を呼ぶ条件です。別ファイルから読み込んだだけではウィンドウを開きません。

`pygame.init()` はpygameを使う準備、`pygame.quit()` は終了時の片付けです。`try` の中でエラーが起きても、`finally` の中の片付けは行われます。

`screen` は描画先、`clock` は時計、`running` は実行を続けるかを表します。`running` が `False` になると繰り返しを終えます。ウィンドウを閉じる操作は `pygame.QUIT` というイベント（操作や変化を知らせる情報）で届きます。

`pygame.display.set_mode((640, 480))` の数値は幅640、高さ480ピクセルです。左上が `(0, 0)` で、右へ進むほどx、下へ進むほどyが増えます。`fill((10, 10, 30))` は赤・緑・青の強さを0〜255で指定した暗い青で塗る処理です。

`pygame.display.flip()` は描いた内容を表示へ反映します。`clock.tick(60)` は更新を最大60回/秒に調整します。時計は移動距離そのものを決めません。

## この章のコード全体

```python
# pygame を読み込む
import pygame

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # screen は画面。pygameが用意した描画先です。
        # screen に pygame.display.set_mode((640, 480)) を入れる
        screen = pygame.display.set_mode((640, 480))
        # pygame.display.set_caption('最初のゲーム画面') を実行する
        pygame.display.set_caption('最初のゲーム画面')

        # clock は時計。画面更新を最大60回/秒に調整します。
        # clock に pygame.time.Clock() を入れる
        clock = pygame.time.Clock()

        # running は実行中かどうか。Falseで繰り返しを終えます。
        # running に True を入れる
        running = True
        # running が成り立つ間、繰り返す
        while running:
            # pygame.event.get() から event を1つずつ取り出して繰り返す
            for event in pygame.event.get():
                # event.type == pygame.QUIT が成り立つなら
                if event.type == pygame.QUIT:
                    # running は実行中かどうか。Falseで繰り返しを終えます。
                    # running に False を入れる
                    running = False
            # not running が成り立つなら
            if not running:
                # この繰り返しを終える
                break

            # screen.fill((10, 10, 30)) を実行する
            screen.fill((10, 10, 30))

            # pygame.display.flip() を実行する
            pygame.display.flip()
            # clock.tick(60) を実行する
            clock.tick(60)
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# __name__ == '__main__' が成り立つなら
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 実行したときの画面と操作

暗い青のウィンドウが開きます。閉じる操作で終了します。

## 保存先へ移動して、入口ファイルを実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の入口ファイルを保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe first_game_window.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python first_game_window.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。

## 1か所変えて比べる

VS Codeで `first_game_window.py` を開き、Windows / LinuxはCtrl + F、macOSはCommand + Fで `pygame.display.set_caption` を検索してください。引用符の中のタイトル文字を「私のゲーム」へ変更してください。Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。

再実行は、VS Codeの **表示 → ターミナル** で先ほどのターミナルを開いてください。Windowsは `.\.venv\Scripts\python.exe first_game_window.py`、macOS / Linuxは `.venv/bin/python first_game_window.py` を入力してEnterキーを押してください。変更前と比べてください。閉じる前のウィンドウがあれば、先に閉じてください。
