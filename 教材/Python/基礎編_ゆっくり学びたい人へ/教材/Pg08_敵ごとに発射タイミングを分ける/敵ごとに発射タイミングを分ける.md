# Pg8. pygame「敵ごとに発射タイミングを分ける」

Pg7で、敵が順番に増えるようになりました。でも弾を撃つタイミングは全員同じです。

> **「全員同時に撃ってくる。つまんない！！！」**

敵がそれぞれ違うタイミングで攻撃すれば、避ける場所やタイミングも変わります。この章の題材は、敵ごとに弾を撃つタイミングが異なるゲームです。

## 起動してから1回の更新が終わるまで

`enemy_fire_timing.py` の `main()` がpygameを初期化し、`Game()` を作って `run()` を呼びます。`Game` は画面と時計を持ち、入力・更新・描画を順に呼びます。`Battle` は1回の戦闘の自機・敵・弾を管理します。移動と描画は各機体や弾自身のメソッド（クラス内の関数）へ任せます。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

入口の最後の `if __name__ == "__main__":` は、直接実行したときだけmain()を呼ぶ条件です。補助ファイルを読み込んだだけではゲームを起動しません。`finally` のpygame.quit()はエラーが起きた場合も終了時の片付けを行います。

### 入口のコード

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # game はゲーム全体。起動・繰り返し・画面切り替えを担当します。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# __name__ == '__main__' が成り立つなら
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 既存の `Enemy` に、敵ごとの発射間隔を追加する

Pg5から使っている `Enemy` に `fire_interval`（発射間隔）と `fire_timer`（発射までの更新回数）を追加します。全ての敵が1つの時計を使う構成から、各敵が自分の回数を数える構成へ変更します。

`ENEMY_FIRE_INTERVALS` は60、90、120、75、105、80、110です。出現順と同じ番号の間隔を指定します。60回/秒の場合、最初の敵は約1秒、次は約1.5秒、3機目は約2秒ごとに撃ちます。

`ready_to_fire` は「発射する時か」を返す処理です。各敵が自分の `fire_timer` を増やし、自分の `fire_interval` に達したときだけ0へ戻して `True` を返します。敵が出た時刻が違っても、別の敵の値を上書きしません。

## 設定値の場所と意味

`settings.py` の値はこの章の初期設定です。位置と大きさの単位はピクセル、速さは1回の更新で動くピクセル数、間隔は更新回数です。最大60回/秒の場合、90回は約1.5秒、120回は約2秒です。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | 画面の幅 | `640` |
| `HEIGHT` | 画面の高さ | `480` |
| `FPS` | 1秒あたりの更新回数の上限 | `60` |
| `PLAYER_X` | 自機の最初の中心の横位置 | `320` |
| `PLAYER_Y` | 自機の最初の中心の縦位置 | `400` |
| `PLAYER_SPEED` | 自機の移動の速さ | `5` |
| `BULLET_SPEED` | 自機の弾の速さ（発射時に負にして上へ動かす） | `8` |
| `ENEMY_SPEED` | 通常の敵の移動の速さ | `1` |
| `PLAYER_HP` | 自機の最初の体力 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾の速さ | `4` |
| `SPAWN_POSITIONS_X` | 出現順に並べた敵の横位置 | `(120, 320, 520, 220, 420, 100, 540)` |
| `SPAWN_INTERVAL` | 敵の出現間隔 | `90` |
| `ENEMY_FIRE_INTERVALS` | 出現順に並べた敵ごとの発射間隔 | `(60, 90, 120, 75, 105, 80, 110)` |

自機の中心(320, 400)は画面の中央より下です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `enemy.py` の `Enemy.ready_to_fire`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# ready_to_fire の処理を定義する
def ready_to_fire(self):
    # self.fire_timer に 1 を足す
    self.fire_timer += 1
    # self.fire_timer >= self.fire_interval が成り立つなら
    if self.fire_timer >= self.fire_interval:
        # fire_timer は前回の発射から何回更新したかを数える値です。
        # self.fire_timer に 0 を入れる
        self.fire_timer = 0
        # True を返す
        return True
    # False を返す
    return False
```

### `battle.py` の `Battle.spawn_enemy`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# spawn_enemy の処理を定義する
def spawn_enemy(self):
    # self.spawn_index >= len(settings.SPAWN_POSITIONS_X) が成り立つなら
    if self.spawn_index >= len(settings.SPAWN_POSITIONS_X):
        # この処理を終える
        return
    # self.spawn_timer に 1 を足す
    self.spawn_timer += 1
    # self.spawn_timer >= settings.SPAWN_INTERVAL が成り立つなら
    if self.spawn_timer >= settings.SPAWN_INTERVAL:
        # x は横位置。画面の左から右へ増えます。
        # x に settings.SPAWN_POSITIONS_X[self.spawn_index] を入れる
        x = settings.SPAWN_POSITIONS_X[self.spawn_index]

        # fire_interval は発射の間隔。単位は更新回数です。
        # fire_interval に settings.ENEMY_FIRE_INTERVALS[self.spawn_index] を入れる
        fire_interval = settings.ENEMY_FIRE_INTERVALS[self.spawn_index]
        # self.enemies.append(Enemy(x, -20, fire_interval)) を実行する
        self.enemies.append(Enemy(x, -20, fire_interval))

        # self.spawn_index に 1 を足す
        self.spawn_index += 1
        # spawn_timer は前回の敵の出現からの更新回数です。
        # self.spawn_timer に 0 を入れる
        self.spawn_timer = 0
```

## 保存先へ移動して、入口ファイルを実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の入口ファイルを保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text

```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。
