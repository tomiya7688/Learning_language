# Tk11. 小数の答えを読みやすくする

> **「0.1 + 0.2なのに、答えが0.30000000000000004！0.3と読める表示にしたい！」**

この章の電卓は、小数の答えの表示を整えた関数電卓です。たとえば `0.1 + 0.2` の結果の欄は `答え: 0.3`、数字の入力欄は `0.3` になります。四則演算とsin・cos、数字・小数点・Cのボタンを使えます。

## Tk11-2. 表示する桁と、計算に使う数値を分ける

Pythonの `float` は、小数も扱える数値です。floatは二進数（0と1を使う表し方）で数値を保持します。0.1などの小数はfloatでぴったり表せないため、近い数で保持されます。足し算の答えにも小さな違いが残り、数値をそのまま表示すると余分な桁が見える場合があります。[Python公式の小数計算の説明](https://docs.python.org/3/tutorial/floatingpoint.html)

この章では、floatの数値を画面へ出す時に、有効数字を最大12桁まで残す文字列へ変換します。不要な末尾の0は表示しないため、表示が12桁より短くなる場合もあります。有効数字は、最初に現れる0以外の数字から数えた桁です。0.00125なら、1・2・5の3桁です。`format(number, ".12g")` は、数値 `number` を有効数字12桁で表示する文字列へ変換します。12桁を使うと、1/3などの小数も途中の桁を確認でき、末尾の長い桁を短くできます。表示の桁数は、計算結果の正確さを保証する数ではありません。[Python公式のg形式と精度の指定](https://docs.python.org/3/library/string.html#format-specification-mini-language)

数値を保持する方法を変えて計算する場合は、計算の仕組み自体の変更になります。この章は、floatの計算を続け、画面へ出す文字列を整える方法です。計算した元の数値は書き換えません。たとえば `0.1 + 0.2` の数値は `0.30000000000000004` のまま保存し、画面には `0.3` を表示します。

式の欄だけ元の長い数値が残ると、入力欄や答えの欄と違う数に見えます。電卓が式と答えの欄へ表示する数値と、計算後に入力欄へ戻す答えは、同じ表示用の変換を通します。利用者が入力中の文字列は変換せず、入力した桁をそのまま残します。たとえば入力欄へ `0.123456789012345` と入力すると、計算前は15桁の小数が残ります。式に表示する数値も丸めた文字列なので、画面にある数字を別の電卓へ入力し直すと、丸める前の値を使った結果と違う場合があります。

## Tk11-3. なぜ答えの数値を覚えておくのか

1/3の答えは、画面では `0.333333333333` になります。表示の文字列だけを次の計算へ使うと、短くした数値に置き換わります。プログラムは、丸める前の答えを `self.answer_value`（表示する前の答え）へ保存し、計算記号やsin・cosを押した時は保存した数値を使います。`read_number`（数値を読み取る）は、保存した答えがあれば数値を返し、保存した答えがなければ入力欄の文字列をfloatへ変換します。`None` は、この電卓では保存した答えがない状態を表す値で、数値の0とは区別します。

しかし、利用者が入力欄を別の数字へ書き換えたのに保存した答えを使うと、入力した数字が計算へ反映されません。入力欄の文字列を `self.input_text`（入力欄の文字列）という `StringVar`（Tkinterが文字列を保持する変数）とつなぎます。`master=self.window` は、この電卓のウィンドウで使う変数として作る指定です。`trace_add("write", self.forget_answer)` は、文字列へ書き込まれた時に実行する処理を登録する指定です。`write` は「書き込み」を表します。手入力や貼り付けのたびに、`forget_answer`（答えを忘れる）が保存した答えをNoneへ戻します。次の計算には書き換えた入力を使います。[Python公式の入力欄と変数の連携](https://docs.python.org/3/library/tkinter.html#coupling-widget-variables)、[Tcl公式の変更通知](https://www.tcl-lang.org/man/tcl8.6/TclCmd/trace.htm)

入力欄に表示された答えと同じ文字列を利用者が入力し直した場合も、表示前の保存した答えは消えます。たとえば表示中の `0.333333333333` を削除して同じ文字列を入力した場合、電卓は1/3の元の数値を使わず、入力し直した小数を使います。入力した数字へ数字ボタンで続きを追加する場合も、その入力を残します。

四則演算とsin・cosの両方が、答えを表示して次の計算用に保存します。二つの処理へ同じ表示と保存を書くと、修正時に片方を直し忘れる恐れがあります。答えの表示と保存を `show_answer`（答えを表示する）へまとめます。入力欄へ表示を書き込む時にも `forget_answer` が実行されるため、`show_answer` は入力欄を書き換えた後に、丸める前の答えを保存します。

式の欄や答えの欄で同じ数値を違う書式にしないため、数値の表示は `format_number`（数値の表示を整える）、保存済みの数値と記号を空白でつなぐ表示は `format_expression`（式の表示を整える）へまとめます。0と-0.0はどちらも `0` と表示し、不要な末尾の `.0` も表示しません。

入力欄、保存した答え、式、表示を更新する処理は同じ電卓に関する情報と操作です。入力を読む処理と表示を更新する処理を別々の場所へ置くと、どの電卓の数値をどの表示へ戻すかが分かりにくくなります。`CalculatorApp`（電卓アプリ）というクラスへ情報と操作をまとめ、各処理が同じ `self`（操作対象の電卓）を使う構成にします。クラスは、同じ対象の情報と操作をまとめて定義する仕組みです。クラス内に定義した関数をメソッドと呼びます。

画面の準備は `__init__`（作成時の準備処理）、表示欄の作成は `create_display`、ボタンの配置は `create_buttons`、一つのボタンの作成は `create_button` が担当します。表示欄とボタンの場所を変えるコードが混ざらないよう、準備の場所を分けています。各ボタンで違うのは文字・位置・押した時の処理なので、共通の作成処理へそれぞれを指定します。

数字や小数点を押した時だけ入力を追加するため、数字の追加は `append_digit`、小数点の追加は `append_decimal_point` に分けます。前の答えを消す判定は `prepare_input` が担当します。`prepare_input` は、前の答えを置き換える必要があり、保存済みの式がある場合には入力中の値だけを消します。前の答えを置き換える必要があり、保存済みの式がない場合には前の計算全体を消します。計算記号の保存は `add_operator`、四則演算は `calculate`、sin・cosは `apply_trigonometry`、入力と式の消去は `clear` が担当します。

準備した後に操作を待つ処理は `run`（実行する）へ分けています。`app.py` の `main`（起動時の中心の処理）は電卓を作って `run` を実行する処理です。電卓の機能を変更するファイルは `calculator.py`（電卓）、起動するファイルは `app.py`（アプリ）のままです。

### calculator.py：計算する数値と表示用の文字列を分ける

元ファイル：[`calculator.py` 全体](./src/calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
# math を、このプログラムで使えるようにする
import math
# functools から、処理に指定する値を先に固定する partial を読み込む
from functools import partial


# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
        # self.replace_input（次の数字ボタンか小数点ボタンで入力を置き換えるか）に False を入れる
        self.replace_input = False
        # self.answer_value（表示する前の答え）に、答えがないことを表す None を入れる
        self.answer_value = None
        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「関数電卓」にする
        self.window.title("関数電卓")
        # self.window の大きさを横420、縦520にする
        self.window.geometry("420x520")
        # self.window の最小の大きさを横420、縦520にする
        self.window.minsize(420, 520)
        # 入力欄・式・答えを配置する self.create_display を呼び出す
        self.create_display()
        # 数字と計算記号のボタンを配置する self.create_buttons を呼び出す
        self.create_buttons()

    # 入力欄・式・答えを配置する create_display を定義する
    def create_display(self):
        # self.number_label（数字の案内）に self.window 内の「数字（sin・cosは角度を度で入力）」というラベルを入れる
        self.number_label = tkinter.Label(
            self.window, text="数字（sin・cosは角度を度で入力）"
        )
        # self.number_label を self.window 内に配置し、上下に6ピクセルずつ間を空ける
        self.number_label.pack(pady=6)
        # self.input_text（入力欄の文字列）に self.window で使う、文字列を保持する変数を入れる
        self.input_text = tkinter.StringVar(master=self.window)
        # self.input_text へ書き込まれた時の処理として self.forget_answer を登録する
        self.input_text.trace_add("write", self.forget_answer)
        # self.number_entry（数字の入力欄）に、文字列を self.input_text とつなぐ1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window, textvariable=self.input_text)
        # self.number_entry を横へ広げ、左右に16ピクセルずつ間を空ける
        self.number_entry.pack(fill="x", padx=16)
        # self.expression_label（計算式の表示）に「計算式:」を表示し、380ピクセルで折り返すラベルを入れる
        self.expression_label = tkinter.Label(
            self.window, text="計算式:", wraplength=380
        )
        # self.expression_label を横へ広げ、上下に6ピクセルずつ間を空ける
        self.expression_label.pack(fill="x", pady=6)
        # self.result_label（答えの表示）に「答え:」を表示し、380ピクセルで折り返すラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:", wraplength=380)
        # self.result_label を横へ広げ、上下に6ピクセルずつ間を空ける
        self.result_label.pack(fill="x", pady=6)

    # 数字と計算記号のボタンを配置する create_buttons を定義する
    def create_buttons(self):
        # self.buttons_frame（ボタンの枠）に self.window 内の部品をまとめる枠を入れる
        self.buttons_frame = tkinter.Frame(self.window)
        # self.buttons_frame を縦横へ広げ、左右と上下に12ピクセルずつ間を空ける
        self.buttons_frame.pack(fill="both", expand=True, padx=12, pady=12)
        # column（列番号）に0から3までの番号を入れ、次の処理を繰り返す
        for column in range(4):
            # self.buttons_frame の column 列へ、余った幅を同じ割合で配分する
            self.buttons_frame.columnconfigure(column, weight=1, uniform="buttons")
        # row（行番号）に0から4までの番号を入れ、次の処理を繰り返す
        for row in range(5):
            # self.buttons_frame の row 行へ、余った高さを同じ割合で配分する
            self.buttons_frame.rowconfigure(row, weight=1)
        # digit_positions（数字と配置位置）に、数字の文字列・行番号・列番号の組を並べたリストを入れる
        digit_positions = [
            ("7", 1, 0), ("8", 1, 1), ("9", 1, 2),
            ("4", 2, 0), ("5", 2, 1), ("6", 2, 2),
            ("1", 3, 0), ("2", 3, 1), ("3", 3, 2),
            ("0", 4, 0),
        ]
        # digit（数字）・row（行）・column（列）に digit_positions の各組の値を入れ、次の処理を繰り返す
        for digit, row, column in digit_positions:
            # digit を指定した self.append_digit の処理を、指定した行と列のボタンへ登録する
            self.create_button(digit, row, column, partial(self.append_digit, digit))
        # operation_positions（計算ボタンと配置位置）に、表示文字列・行・列・押した時の処理の組を入れる
        operation_positions = [
            ("sin", 0, 0, partial(self.apply_trigonometry, "sin")),
            ("cos", 0, 1, partial(self.apply_trigonometry, "cos")),
            ("C", 0, 2, self.clear), ("/", 0, 3, self.select_division),
            ("*", 1, 3, self.select_multiplication),
            ("-", 2, 3, self.select_subtraction),
            ("+", 3, 3, self.select_addition),
            (".", 4, 1, self.append_decimal_point), ("=", 4, 2, self.calculate),
        ]
        # text（表示文字列）・row・column・command（押した時の処理）に各組の値を入れて繰り返す
        for text, row, column, command in operation_positions:
            # 「=」なら2列分、それ以外なら1列分の幅を指定して self.create_button を呼び出す
            self.create_button(text, row, column, command, 2 if text == "=" else 1)

    # 指定した文字と処理のボタンを配置する create_button を定義する
    def create_button(self, text, row, column, command, column_span=1):
        # column_span（使う列数）には、ボタンを広げる列の数が入り、省略した場合は1になる
        # button（ボタン）に text を表示し、押すと command を実行するボタンを入れる
        button = tkinter.Button(self.buttons_frame, text=text, command=command)
        # button を row 行・column 列から column_span 列分へ広げ、周囲に4ピクセルずつ間を空ける
        button.grid(
            row=row, column=column, columnspan=column_span,
            sticky="nsew", padx=4, pady=4
        )

    # 数値を表示用の文字列にする format_number を定義する
    def format_number(self, number):
        # number（表示する数値）が0なら、次の処理を実行する
        if number == 0:
            # 文字列の「0」を返す
            return "0"
        # number を有効数字12桁の表示へ変換した文字列を返す
        return format(number, ".12g")

    # 保存済みの式を表示用の文字列にする format_expression を定義する
    def format_expression(self):
        # parts_text（表示する式の部品）に空のリストを入れる
        parts_text = []
        # part（式の部品）に self.calculation_parts の値を順に入れて繰り返す
        for part in self.calculation_parts:
            # part が文字列なら、次の処理を実行する
            if isinstance(part, str):
                # parts_text の末尾に part を追加する
                parts_text.append(part)
            # part が文字列でなければ、次の処理を実行する
            else:
                # parts_text の末尾に part を表示用の文字列にした値を追加する
                parts_text.append(self.format_number(part))
        # parts_text の文字列を空白でつないだ文字列を返す
        return " ".join(parts_text)

    # 入力欄へ書き込まれた時に答えを忘れる forget_answer を定義する
    def forget_answer(self, variable_name, index, operation):
        # variable_name（変数名）・index（添字）・operation（操作の種類）には、Tkinterが指定した変更情報が入る
        # self.answer_value に、保存した答えがないことを表す None を入れる
        self.answer_value = None
        # self.replace_input に False を入れる
        self.replace_input = False

    # 答えを表示し、次の計算用の数値を保存する show_answer を定義する
    def show_answer(self, answer):
        # answer_text（答えの表示文字列）に answer を表示用に変換した文字列を入れる
        answer_text = self.format_number(answer)
        # self.result_label の表示を「答え: 」と answer_text をつないだ文字列に変える
        self.result_label.config(text="答え: " + answer_text)
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer_text を挿入する
        self.number_entry.insert(0, answer_text)
        # self.answer_value に、表示する前の数値 answer を入れる
        self.answer_value = answer
        # self.replace_input に True を入れる
        self.replace_input = True

    # 次の数字入力のために前の値を消す prepare_input を定義する
    def prepare_input(self):
        # self.replace_input が False なら、次の処理を実行する
        if not self.replace_input:
            # prepare_input の処理をここで終える
            return
        # self.calculation_parts に式が残っていれば、次の処理を実行する
        if self.calculation_parts:
            # self.number_entry の先頭から末尾までの文字列を削除する
            self.number_entry.delete(0, tkinter.END)
            # self.expression_label に、保存した式を表示用に変換した文字列を表示する
            self.expression_label.config(text="計算式: " + self.format_expression())
            # self.replace_input に False を入れる
            self.replace_input = False
        # self.calculation_parts に式が残っていなければ、次の処理を実行する
        else:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()

    # 入力欄へ数字を追加する append_digit を定義する
    def append_digit(self, digit):
        # digit（追加する数字）には、押された数字ボタンの文字列が入る
        # 次の数字入力のために前の値を消す self.prepare_input を呼び出す
        self.prepare_input()
        # self.number_entry の末尾へ digit を挿入する
        self.number_entry.insert(tkinter.END, digit)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力欄へ小数点を追加する append_decimal_point を定義する
    def append_decimal_point(self):
        # 次の数字入力のために前の値を消す self.prepare_input を呼び出す
        self.prepare_input()
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()
        # number_text に小数点が含まれていれば、次の処理を実行する
        if "." in number_text:
            # self.result_label の表示を「小数点は1つの数字に1個だけ入力できます」に変える
            self.result_label.config(text="小数点は1つの数字に1個だけ入力できます")
            # append_decimal_point の処理をここで終える
            return
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.number_entry の末尾へ「0」を挿入する
            self.number_entry.insert(tkinter.END, "0")
        # self.number_entry の末尾へ「.」を挿入する
        self.number_entry.insert(tkinter.END, ".")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力・計算式・結果表示を空にする clear を定義する
    def clear(self):
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.expression_label の表示を「計算式:」に変える
        self.expression_label.config(text="計算式:")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力欄を数値へ変換し、使えない入力を結果の欄で知らせる read_number を定義する
    def read_number(self, empty_message):
        # empty_message（空欄の案内）には、入力欄が空の場合に表示する文字列が入る
        # number_text（入力文字列）に self.number_entry の文字列から前後の空白を取り除いた文字列を入れる
        number_text = self.number_entry.get().strip()
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を empty_message に変える
            self.result_label.config(text=empty_message)
            # 数値を読み取れなかったことを表す None を返す
            return None
        # self.answer_value に答えの数値が保存されていれば、次の処理を実行する
        if self.answer_value is not None:
            # 表示する前の答え self.answer_value を返す
            return self.answer_value
        # 次の数値変換で ValueError が起きるかを確認する
        try:
            # number（読み取った数値）に number_text を float で数値に変換した値を入れる
            number = float(number_text)
        # 数値へ変換できず ValueError が起きた場合は、次の処理を実行する
        except ValueError:
            # self.result_label の表示を「数字を入力してください（例: 1.5）」に変える
            self.result_label.config(text="数字を入力してください（例: 1.5）")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # number が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(number):
            # self.result_label の表示を「有限の数字を入力してください」に変える
            self.result_label.config(text="有限の数字を入力してください")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 読み取った数値 number を返す
        return number

    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number（読み取った数値）に、空欄の案内「次の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("次の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # self.expression_label に、保存した式を表示用に変換した文字列を表示する
        self.expression_label.config(text="計算式: " + self.format_expression())

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 入力された数字と「*」を計算式に追加する select_multiplication を定義する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")

    # 入力された数字と「/」を計算式に追加する select_division を定義する
    def select_division(self):
        # 「/」を指定して self.add_operator を呼び出す
        self.add_operator("/")

    # 計算式に最後の数字を追加し、掛け算と割り算を先に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number（読み取った数値）に、空欄の案内「最後の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("最後の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)

        # 掛け算と割り算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」ではなく「/」なら、次の処理を実行する
            elif operator == "/":
                # number が0なら、次の処理を実行する
                if number == 0:
                    # self.result_label の表示を「0では割れません」に変える
                    self.result_label.config(text="0では割れません")
                    # self.calculation_parts の要素をすべて削除する
                    self.calculation_parts.clear()
                    # self.answer_value に、答えがないことを表す None を入れる
                    self.answer_value = None
                    # self.replace_input に True を入れる
                    self.replace_input = True
                    # calculate の処理をここで終える
                    return

                # addition_and_subtraction_parts の末尾の要素に、その値を number で割った値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] / number
                )
            # operator が「*」でも「/」でもなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)

        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number

        # answer が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(answer):
            # self.result_label の表示を「計算結果が大きすぎます。Cで消してやり直してください」に変える
            self.result_label.config(text="計算結果が大きすぎます。Cで消してやり直してください")
            # self.calculation_parts の要素をすべて削除する
            self.calculation_parts.clear()
            # self.answer_value に、答えがないことを表す None を入れる
            self.answer_value = None
            # self.replace_input に True を入れる
            self.replace_input = True
            # calculate の処理をここで終える
            return

        # self.expression_label に、表示用の式と表示用の答えをつないだ文字列を表示する
        self.expression_label.config(
            text="計算式: " + self.format_expression() + " = " + self.format_number(answer)
        )
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # answer を指定して、答えを表示して保存する self.show_answer を呼び出す
        self.show_answer(answer)

    # 入力欄の角度からsinかcosを求める apply_trigonometry を定義する
    def apply_trigonometry(self, function_name):
        # function_name（計算名）には、ボタンが指定した「sin」か「cos」が入る
        # angle_degrees（度の角度）に、空欄の案内を指定して self.read_number が返す値を入れる
        angle_degrees = self.read_number("角度を度で入力してください（例: 30）")
        # angle_degrees が None なら、次の処理を実行する
        if angle_degrees is None:
            # apply_trigonometry の処理をここで終える
            return
        # angle_radians（ラジアンの角度）に、angle_degrees をラジアンへ変換した値を入れる
        angle_radians = math.radians(angle_degrees)
        # function_name が「sin」なら、次の処理を実行する
        if function_name == "sin":
            # answer（答え）に angle_radians のsinを求めた値を入れる
            answer = math.sin(angle_radians)
        # function_name が「sin」でなければ、次の処理を実行する
        else:
            # answer に angle_radians のcosを求めた値を入れる
            answer = math.cos(angle_radians)
        # operation_text（角度の計算表示）に計算名・表示用の度の角度・度の記号を含む文字列を入れる
        operation_text = f"{function_name}({self.format_number(angle_degrees)}°)"
        # self.calculation_parts に式が残っていれば、次の処理を実行する
        if self.calculation_parts:
            # self.expression_label に、保存した式と operation_text を表示する
            self.expression_label.config(
                text="計算式: "
                + self.format_expression()
                + " " + operation_text
            )
        # self.calculation_parts に式が残っていなければ、次の処理を実行する
        else:
            # self.expression_label に、operation_text と表示用の答えを表示する
            self.expression_label.config(
                text="計算式: " + operation_text + " = " + self.format_number(answer)
            )
        # answer を指定して、答えを表示して保存する self.show_answer を呼び出す
        self.show_answer(answer)

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

## Tk11-6. 表示が整った答えを使う

「+」「-」「=」は電卓で使う記号、「*」「/」はPythonで掛け算・割り算を書く記号です。「.」はPythonの小数点、「C」はClear（消去）の頭文字で、入力と式を最初からやり直すボタンです。

1. 電卓画面の「C」「0」「.」「1」「+」「0」「.」「2」「=」の各ボタンを順に押してください。式の欄は `計算式: 0.1 + 0.2 = 0.3`、結果の欄は `答え: 0.3`、入力欄は `0.3` になります。計算用には表示前の `0.30000000000000004` が保存されます。
2. 入力欄に答えの `0.3` がある状態で、電卓画面の「*」「1」「0」「=」の各ボタンを順に押してください。式の欄は `計算式: 0.3 * 10 = 3`、結果の欄は `答え: 3`、入力欄は `3` になります。最初の数値には保存した `0.30000000000000004` を使い、式の欄には表示用の `0.3` を使います。
3. 電卓画面の「C」「2」「+」「3」「=」の各ボタンを順に押してください。式の欄は `計算式: 2 + 3 = 5`、結果の欄は `答え: 5`、入力欄は `5` になります。整数の答えには末尾の `.0` を表示しません。
4. 電卓画面の「C」「1」「/」「8」「=」の各ボタンを順に押してください。式の欄は `計算式: 1 / 8 = 0.125`、結果の欄は `答え: 0.125`、入力欄は `0.125` になります。計算する数値も0.125です。

### 保存した答えから続ける場合

1. 電卓画面の「C」「1」「/」「3」「=」の各ボタンを順に押してください。式の欄は `計算式: 1 / 3 = 0.333333333333`、結果の欄は `答え: 0.333333333333`、入力欄は `0.333333333333` になります。表示前の数値は約 `0.3333333333333333` で、電卓はその数値を保存します。
2. 入力欄を書き換えず、電卓画面の「*」「3」「=」の各ボタンを順に押してください。式の欄は `計算式: 0.333333333333 * 3 = 1`、結果の欄は `答え: 1`、入力欄は `1` になります。短くした表示の文字列ではなく、保存した1/3の数値を使います。

### 表示された小数を手で入力し直す場合

1. 電卓画面の「C」「1」「/」「3」「=」の各ボタンを順に押してください。入力欄は `0.333333333333`、式の欄は `計算式: 1 / 3 = 0.333333333333`、結果の欄は `答え: 0.333333333333` になります。
2. 電卓画面の入力欄で、`0.333333333333` の先頭から末尾までマウスの左ボタンを押したまま動かして全体を選択し、Windows / LinuxはBackspaceキー、macOSはDeleteキーで削除してください。空になった入力欄へキーボードで `0.333333333333` と入力してください。入力欄の見た目は同じですが、保存した1/3の数値は破棄され、次の計算には入力した小数を使います。式と答えの欄は、次の計算まで直前の表示が残ります。
3. 電卓画面の「*」「3」「=」の各ボタンを順に押してください。式の欄は `計算式: 0.333333333333 * 3 = 0.999999999999`、結果の欄は `答え: 0.999999999999`、入力欄は `0.999999999999` になります。

利用者が入力欄へ手入力や貼り付けで書き込むと、表示前の保存した答えは破棄され、次の計算には書き込んだ文字列から変換した数値を使います。電卓が計算後に入力欄へ答えを書く場合も保存値はいったん破棄されますが、`show_answer`（答えを表示する処理）が書き込み後に元の答えを保存し直すため、続ける計算には丸める前の数値を使えます。キーボードで別の計算を最初から始める場合は、先に電卓画面の「C」ボタンを押してください。計算途中の数字だけを直す場合は、Cで保存済みの式を消さず、入力欄の文字列だけをマウスで全体選択して削除し、数字を入力し直してください。

## Tk11-7. sinとcosの答えも同じ書式にする

sin（サイン）とcos（コサイン）は、角度から数値を求める計算です。たとえば斜めの棒を地面から30度傾けた場合、sinは棒の長さに対する高さの割合、cosは棒の長さに対する横の長さの割合です。ボタン名は数学や関数電卓で使う名前に合わせています。電卓画面の数字の入力欄へ角度の数字だけを入れ、高さの割合なら「sin」ボタン、横の長さの割合なら「cos」ボタンを押してください。30度なら30を入力し、°は入力しないでください。

Pythonのmath（数学の計算をまとめた標準の道具）のsinとcosは、ラジアンという角度の単位を使います。ラジアンは、円周のうち角度に対応する部分の長さを半径で割った数で角度を表す単位です。この電卓は入力する角度の単位を度にそろえ、math.radiansでラジアンへ変換してから計算します。

1. 電卓画面の「C」「3」「0」「sin」の各ボタンを順に押してください。式の欄は `計算式: sin(30°) = 0.5`、結果の欄は `答え: 0.5`、入力欄は `0.5` になります。計算用には、約 `0.49999999999999994` という表示前の数値を保存します。
2. 入力欄を書き換えず、電卓画面の「*」「1」「0」「=」の各ボタンを順に押してください。式の欄は `計算式: 0.5 * 10 = 5`、結果の欄は `答え: 5`、入力欄は `5` になります。保存したsinの数値に10を掛けた、約5の答えを表示しています。
3. 電卓画面の「C」「0」「cos」の各ボタンを順に押してください。式の欄は `計算式: cos(0°) = 1`、結果の欄は `答え: 1`、入力欄は `1` になります。計算する数値も1.0です。

### 途中のsinから直接答えを出す場合

1. 電卓画面の「C」「2」「+」「0」「sin」の各ボタンを順に押してください。式の欄は `計算式: 2 + sin(0°)`、結果の欄は `答え: 0`、入力欄は `0` になります。保存済みの式は `2 +` で、保存した答えの数値はsinだけの0です。
2. 電卓画面の「=」ボタンを押してください。電卓は保存したsinの数値0を式の最後の数字に使い、式の欄は `計算式: 2 + 0 = 2`、結果の欄は `答え: 2`、入力欄は `2` になります。sinという表示は、足し算に使った数値の0へ変わります。

### 途中のsinから計算記号を続ける場合

1. 電卓画面の「C」「2」「+」「0」「sin」の各ボタンを順に押してください。式の欄は `計算式: 2 + sin(0°)`、結果の欄は `答え: 0`、入力欄は `0` になります。0はsinだけの答えで、2を足す計算はまだ終わっていません。
2. 電卓画面の「*」ボタンを押してください。保存済みの式へsinの値と掛け算の記号を追加し、式の欄は `計算式: 2 + 0 *`、入力欄は空、結果の欄は `答え:` になります。
3. 電卓画面の「3」「=」の各ボタンを順に押してください。掛け算を先に計算し、式の欄は `計算式: 2 + 0 * 3 = 2`、結果の欄は `答え: 2`、入力欄は `2` になります。

sinの後に入力をやり直す場合は、電卓画面の「C」「2」「+」「0」「sin」「3」の各ボタンを順に押してください。sinの値だけを消して3を入力するので、式の欄は `計算式: 2 +`、入力欄は `3`、結果の欄は `答え:` になります。電卓画面の「=」ボタンを押すと、式の欄は `計算式: 2 + 3 = 5`、結果の欄は `答え: 5`、入力欄は `5` になります。

sinの後に小数点から入力をやり直す場合は、電卓画面の「C」「2」「+」「0」「sin」「.」の各ボタンを順に押してください。保存済みの式は残り、式の欄は `計算式: 2 +`、入力欄は `0.`、結果の欄は `答え:` になります。電卓画面の「5」「=」の各ボタンを順に押すと、式の欄は `計算式: 2 + 0.5 = 2.5`、結果の欄は `答え: 2.5`、入力欄は `2.5` になります。

sin・cosボタンは、押すたびに入力欄の数値を度の角度として計算します。保存した答えがある場合は、その数値を角度として使います。たとえばcosの答え1の直後にsinを押すと、1度のsinを求めます。別の角度の計算を始める場合は、先に電卓画面の「C」ボタンを押してください。

## Tk11-8. 表示の限界を確認する

大きい数や小さい数は、桁を省く指数表示になる場合があります。たとえば `1e+12` は1に10の12乗を掛けた数、`1e-06` は1に10の-6乗を掛けた数です。後者は0.000001です。eの後の数は、10を何回掛けるかを表す指数で、負の場合は10で割ります。

電卓画面の「C」「9」「0」「cos」の各ボタンを順に押してください。式の欄は `計算式: cos(90°) = 6.12323399574e-17`、結果の欄は `答え: 6.12323399574e-17`、入力欄は `6.12323399574e-17` など、0に近い数値の指数表示になります。この数値は0にとても近いですが、電卓は0へ置き換えません。数学でのcos90度は0でも、floatで近似した角度から計算すると小さな値が残ります。環境により末尾の桁が違う場合があります。[Python公式の三角関数](https://docs.python.org/3/library/math.html#trigonometric-functions)

この章の表示の改善は、計算の誤差をなくす処理ではありません。12桁より後の違いが画面で見えなくなる場合もあります。必要な桁数や数値の保持方法は、作るものに合わせて決めてください。

## Tk11-9. 入力ミスを直して続ける

1. 電卓画面の「C」「0」「.」「1」「+」の各ボタンを順に押してください。式の欄は `計算式: 0.1 +`、入力欄は空、結果の欄は `答え:` になります。
2. 電卓画面の入力欄をクリックして、キーボードで `1.2.3` と入力し、電卓画面の「=」ボタンを押してください。結果の欄には「数字を入力してください（例: 1.5）」と表示されます。式の欄は `計算式: 0.1 +`、入力欄は `1.2.3` のままです。
3. 電卓画面の入力欄で `1.2.3` 全体をマウスで選択し、Windows / LinuxはBackspaceキー、macOSはDeleteキーで削除してください。空になった入力欄へキーボードで `0.2` と入力し、電卓画面の「=」ボタンを押してください。式の欄は `計算式: 0.1 + 0.2 = 0.3`、結果の欄は `答え: 0.3`、入力欄は `0.3` になります。

電卓画面の「C」「1」「/」「0」「=」の各ボタンを順に押してください。結果の欄は「0では割れません」、式の欄は `計算式: 1 /`、入力欄は `0` になります。保存済みの式と答えの数値は破棄されます。入力欄の0は割る数として入力した数字で、答えではありません。電卓画面の数字ボタンか小数点ボタンを押すと、前の式を消して新しい入力になります。電卓画面の計算記号ボタンを押すと、残った0を最初の数字として新しい式を作ります。

### 0で割った後に残る入力を使う場合

0で割った直後に残る入力欄の0は、新しいsin・cos・=の計算にも使えます。0除算後は、式の欄が `計算式: 1 /`、結果の欄が「0では割れません」、入力欄が `0` です。保存した式と答えはありません。

- 電卓画面の「C」「1」「/」「0」「=」「3」の各ボタンを順に押してください。入力欄は `3`、式の欄は `計算式:`、結果の欄は `答え:` になり、3から新しい入力を始めます。
- 電卓画面の「C」「1」「/」「0」「=」「.」の各ボタンを順に押してください。入力欄は `0.`、式の欄は `計算式:`、結果の欄は `答え:` になり、小数点から新しい入力を始めます。
- 電卓画面の「C」「1」「/」「0」「=」「+」の各ボタンを順に押してください。電卓は残る0を新しい式へ保存し、式の欄は `計算式: 0 +`、入力欄は空、結果の欄は `答え:` になります。
- 電卓画面の「C」「1」「/」「0」「=」「C」の各ボタンを順に押してください。入力欄は空、式の欄は `計算式:`、結果の欄は `答え:` になり、入力と計算を最初からやり直せます。
- 電卓画面の「C」「1」「/」「0」「=」「sin」の各ボタンを順に押してください。電卓は残る入力の0を0度として計算し、式の欄は `計算式: sin(0°) = 0`、結果の欄は `答え: 0`、入力欄は `0` になります。sinの数値0は新しい答えとして保存されます。
- 電卓画面の「C」「1」「/」「0」「=」「cos」の各ボタンを順に押してください。電卓は残る入力の0を0度として計算し、式の欄は `計算式: cos(0°) = 1`、結果の欄は `答え: 1`、入力欄は `1` になります。cosの数値1は新しい答えとして保存されます。
- 電卓画面の「C」「1」「/」「0」「=」「=」の各ボタンを順に押してください。電卓は残る入力の0を新しい式の数値に使い、式の欄は `計算式: 0 = 0`、結果の欄は `答え: 0`、入力欄は `0` になります。この数値0は新しい答えとして保存されます。

`inf`（無限大）や `nan`（数値を表さない値）、空欄は計算に使いません。計算結果が大きすぎて有限の数値にならない場合は、「計算結果が大きすぎます。Cで消してやり直してください」と案内し、保存済みの式と答えを破棄します。電卓画面の「C」ボタンを押してから、新しい数字を入力してください。

## Tk11-10. 変更した処理を読む

### format_number：画面へ出す数値の書式

元ファイル：[`calculator.py` の110〜117行](./src/calculator.py#L110-L117)。

```python
    # 数値を表示用の文字列にする format_number を定義する
    def format_number(self, number):
        # number（表示する数値）が0なら、次の処理を実行する
        if number == 0:
            # 文字列の「0」を返す
            return "0"
        # number を有効数字12桁の表示へ変換した文字列を返す
        return format(number, ".12g")
```

`.12g` は、最初に現れる0以外の数字から数え、最大12桁まで残して表示する指定です。g形式は必要に応じて指数表示を使い、不要な末尾の0や小数点を省きます。このメソッドが返すのは表示用の文字列で、数値 `number` の中身は変わりません。

### show_answer：入力欄へ書いてから、計算用の答えを保存する

元ファイル：[`calculator.py` の144〜157行](./src/calculator.py#L144-L157)。

```python
    # 答えを表示し、次の計算用の数値を保存する show_answer を定義する
    def show_answer(self, answer):
        # answer_text（答えの表示文字列）に answer を表示用に変換した文字列を入れる
        answer_text = self.format_number(answer)
        # self.result_label の表示を「答え: 」と answer_text をつないだ文字列に変える
        self.result_label.config(text="答え: " + answer_text)
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer_text を挿入する
        self.number_entry.insert(0, answer_text)
        # self.answer_value に、表示する前の数値 answer を入れる
        self.answer_value = answer
        # self.replace_input に True を入れる
        self.replace_input = True
```

`number_entry.delete` と `number_entry.insert` が入力欄を書き換える時、Tkinterは `forget_answer` を実行します。`show_answer` は書き換えが終わってから `self.answer_value` を保存するので、次の計算へ表示前の数値を使えます。

### forget_answer：手入力の後は入力した数値を使う

元ファイル：[`calculator.py` の136〜142行](./src/calculator.py#L136-L142)。

```python
    # 入力欄へ書き込まれた時に答えを忘れる forget_answer を定義する
    def forget_answer(self, variable_name, index, operation):
        # variable_name（変数名）・index（添字）・operation（操作の種類）には、Tkinterが指定した変更情報が入る
        # self.answer_value に、保存した答えがないことを表す None を入れる
        self.answer_value = None
        # self.replace_input に False を入れる
        self.replace_input = False
```

Tkinterは、変更した変数の名前・変数内の位置を表す添字・操作の種類の3つを指定して `forget_answer` を実行します。この電卓のStringVarは一つの文字列を保持するため、添字の情報は空の文字列です。操作の種類は、書き込みを表す `write` です。メソッドが実行時に受け取る情報を引数と呼びます。`forget_answer` の3つの引数は、Tkinterが指定する変更情報を受け取るためにあります。この電卓の処理は変更情報の中身を使わず、保存した答えを破棄します。`self.replace_input` もFalseへ戻すので、利用者が書き換えた数字へ数字ボタンで続きを追加できます。

### read_number：答えが残っている時だけ元の数値を返す

元ファイル：[`calculator.py` の222〜254行](./src/calculator.py#L222-L254)。

```python
    # 入力欄を数値へ変換し、使えない入力を結果の欄で知らせる read_number を定義する
    def read_number(self, empty_message):
        # empty_message（空欄の案内）には、入力欄が空の場合に表示する文字列が入る
        # number_text（入力文字列）に self.number_entry の文字列から前後の空白を取り除いた文字列を入れる
        number_text = self.number_entry.get().strip()
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を empty_message に変える
            self.result_label.config(text=empty_message)
            # 数値を読み取れなかったことを表す None を返す
            return None
        # self.answer_value に答えの数値が保存されていれば、次の処理を実行する
        if self.answer_value is not None:
            # 表示する前の答え self.answer_value を返す
            return self.answer_value
        # 次の数値変換で ValueError が起きるかを確認する
        try:
            # number（読み取った数値）に number_text を float で数値に変換した値を入れる
            number = float(number_text)
        # 数値へ変換できず ValueError が起きた場合は、次の処理を実行する
        except ValueError:
            # self.result_label の表示を「数字を入力してください（例: 1.5）」に変える
            self.result_label.config(text="数字を入力してください（例: 1.5）")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # number が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(number):
            # self.result_label の表示を「有限の数字を入力してください」に変える
            self.result_label.config(text="有限の数字を入力してください")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 読み取った数値 number を返す
        return number
```

Tk10との比較には、[Tk10の `read_number`（169〜197行）](../Tk10_sinとcosを追加する/src/calculator.py#L169-L197)と、[Tk11の `read_number`（222〜254行）](./src/calculator.py#L222-L254)を使ってください。Tk10は入力欄の文字列を毎回floatへ変換し、Tk11は入力欄への書き込みがない間だけ保存した答えを返します。通常の入力の確認は続けて行います。

## Tk11-11. 今回の内容

- 電卓が式と答えの欄へ表示する数値と、計算後に入力欄へ戻す答えを、有効数字を最大12桁まで残す同じ書式へ変換します。入力中の文字列は変換しません。
- 表示前の答えは数値として保存し、入力欄を書き換えないまま続ける計算へ使います。
- 利用者の手入力・貼り付けでは、保存した答えを破棄して書き換えた入力を使います。電卓が答えを入力欄へ表示する時は、書き込み通知の後に元の数値を保存し直します。
- 表示の桁を短くしても、floatの近似や計算の誤差はなくなりません。
- 起動ファイルは `app.py`、電卓を変更するファイルは `calculator.py` です。

電卓を終了する時は、ウィンドウを閉じてください。`calculator.py` を変更して再実行する時は、起動中の電卓を閉じ、ターミナルが文字を入力できる状態へ戻ったことを確認してください。VS Codeで変更したファイルを保存し（Windows / LinuxはCtrl + S、macOSはCommand + S）、**表示（View）→ ターミナル（Terminal）** でTk11のフォルダへ移動済みのターミナルを開いてください。Windowsなら `python src/app.py`、macOS / Linuxなら `python3 src/app.py` と入力してEnterキーを押してください。保存した機能コードで関数電卓が起動します。
