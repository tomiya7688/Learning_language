# Tk3. 簡単な電卓

買い物の金額が12と8のとき、2つの数字を入力して合計を確かめられる電卓を作りたいとします。画面に入力欄とボタンがあるだけでは、ボタンを押しても合計は出ません。

> **「数字を入れて『計算する』を押したら、答えが出てほしい！」**

この章の電卓は、2つの入力欄から数字を読み取り、足した答えを画面に表示するアプリです。12と8を入力して「計算する」ボタンを押すと、結果の欄に `答え: 20.0` と表示されます。

## Tk3-1. 今回作るもの

電卓の画面には、1つ目と2つ目の数字を入力する欄、「計算する」ボタン、答えを表示する欄があります。次の図は、12と8を入力してボタンを押した後の画面の構成です。

```text
1つ目の数字
[ 12 ]          ← 利用者が入力する欄
2つ目の数字
[  8 ]          ← 利用者が入力する欄
[計算する]      ← 利用者が押すボタン
答え: 20.0      ← プログラムが表示する結果
```

## Tk3-2. 電卓の部品と計算をまとめる理由

Tk2の `GreetingApp` は、名前の入力欄と、その入力欄を使う挨拶の処理をまとめたクラスでした。クラスは、同じ対象に関する情報と操作を一つにまとめるために使えます。

電卓でも、2つの入力欄、答えを表示する欄、計算ボタン、入力された数字を計算する処理は、一つの電卓に関するものです。部品をファイルの先頭へ置き、計算処理を別の場所へ書くと、どの電卓の入力欄を読み、どの表示欄へ答えを書くのか追いづらくなります。電卓の部品と計算処理を `CalculatorApp`（電卓アプリ）クラスへまとめます。`CalculatorApp` は、この章の電卓を表す新しいクラスで、Tk2の `GreetingApp` とは別の定義です。

`CalculatorApp.__init__` は、ウィンドウと入力欄、ボタン、結果表示欄を作る処理です。画面を作っている途中で計算を始めると、利用者が数字を入力する前の空の入力欄を読んでしまいます。数字を入力してからボタンを押したときだけ計算できるように、入力の読み取りから答えの表示までを `calculate()`（計算する処理）へ分けます。

Tkinterの `mainloop()` は、ウィンドウを閉じるまで利用者の操作を待ち続ける処理です。画面を作る `__init__` 内で操作待ちを始めると、ウィンドウを閉じるまで `CalculatorApp()` の次の行へ進めません。画面の準備を終えてから操作待ちを始められるように、`mainloop()` は `run()`（アプリを動かす処理）へ分けます。

電卓の画面と計算を起動処理と同じファイルへ足し続けると、起動する数行が長いコードの中に埋もれます。電卓の部品と処理は `calculator.py` に置き、起動する入口は `app.py` に分けます。`calculator` は「電卓」、`app` は「アプリ」を表す名前です。計算を変えるときは `calculator.py` を編集し、起動するときは `app.py` を実行してください。

起動処理をファイルの先頭へ直接書くと、別のファイルから `import`（ファイルの定義を読み込む記述）で読み込んだときも画面が開きます。電卓を使いたいときだけ起動できるように、画面を準備して `run()` を実行する順番を `main()`（起動処理）へまとめます。`app.py` の末尾で、直接実行された場合だけ `main()` を実行する形にします。

## Tk3-3. 保存する2つのファイルと全文コード

Tk3用のフォルダを作り、その中へ次の2つのファイルを保存してください。Tk1・Tk2の `app.py` と混ざらないように、章ごとに別のフォルダを使ってください。

| 保存するファイル | 担当すること |
| --- | --- |
| [`app.py`](./app.py) | 電卓を準備して起動する入口です。実行するファイルは、この `app.py` です。 |
| [`calculator.py`](./calculator.py) | 電卓の画面の部品・計算・操作待ちをまとめた `CalculatorApp` の定義があります。数字の計算を変えるときは、このファイルを編集してください。 |

2つのファイルの置き方は次の通りです。

```text
Tk3用のフォルダ/
├─ app.py
└─ calculator.py
```

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、作ったTk3用のフォルダを開いてください。VS Codeの **ファイル（File）→ 新しいテキストファイル（New Text File）** でファイルを作り、各全文コードを入力してから **名前を付けて保存（Save As）** で、それぞれ表に示したファイル名へ保存してください。保存後に `app.py.txt` や `calculator.py.txt` と表示された場合は、名前を付けて保存し直し、ファイル名を `app.py` または `calculator.py` にしてください。

画面の入力欄には `Entry`、文字を表示する欄には `Label`、押して処理を始める部品には `Button` を使います。`calculator.py` の `import tkinter` は、ウィンドウや画面の部品を作るTkinterを、このファイルから使えるようにする記述です。各部品の `pack()` は、部品をウィンドウの中へ上から順に並べます。`tkinter.Tk()` はウィンドウを作り、`geometry("400x260")` は横400ピクセル・縦260ピクセルの大きさを指定します。

### 電卓を定義する calculator.py

次の全文を `calculator.py` に保存してください。

元ファイル：[`calculator.py` 全体（1〜79行）](./calculator.py#L1-L79)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 電卓の入力欄・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「簡単な電卓」にする
        self.window.title("簡単な電卓")
        # self.window の大きさを横400、縦260にする
        self.window.geometry("400x260")

        # self.number1_label（1つ目の数字の案内）に self.window 内で「1つ目の数字」と表示するラベルを入れる
        self.number1_label = tkinter.Label(self.window, text="1つ目の数字")
        # self.number1_label を self.window 内に配置する
        self.number1_label.pack()

        # self.number1_entry（1つ目の数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number1_entry = tkinter.Entry(self.window)
        # self.number1_entry を self.window 内に配置する
        self.number1_entry.pack()

        # self.number2_label（2つ目の数字の案内）に self.window 内で「2つ目の数字」と表示するラベルを入れる
        self.number2_label = tkinter.Label(self.window, text="2つ目の数字")
        # self.number2_label を self.window 内に配置する
        self.number2_label.pack()

        # self.number2_entry（2つ目の数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number2_entry = tkinter.Entry(self.window)
        # self.number2_entry を self.window 内に配置する
        self.number2_entry.pack()

        # self.calculate_button（計算ボタン）に self.window 内で「計算する」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.calculate_button = tkinter.Button(
            self.window,
            text="計算する",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.calculate_button を self.window 内に配置する
        self.calculate_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

    # 入力された2つの数字を足して答えを表示する calculate を定義する
    def calculate(self):
        # number1_text（1つ目の入力文字列）に self.number1_entry に入力された文字列を入れる
        number1_text = self.number1_entry.get()
        # number2_text（2つ目の入力文字列）に self.number2_entry に入力された文字列を入れる
        number2_text = self.number2_entry.get()

        # number1_text または number2_text が空の文字列なら、次の処理を実行する
        if number1_text == "" or number2_text == "":
            # self.result_label の表示を「数字を2つ入力してください」に変える
            self.result_label.config(text="数字を2つ入力してください")
            # calculate の処理をここで終える
            return

        # number1（1つ目の数値）に number1_text を float で数値に変換した値を入れる
        number1 = float(number1_text)
        # number2（2つ目の数値）に number2_text を float で数値に変換した値を入れる
        number2 = float(number2_text)

        # answer（答え）に number1 と number2 を足した値を入れる
        answer = number1 + number2

        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

### 電卓を起動する app.py

次の全文を `calculator.py` と同じフォルダの `app.py` に保存してください。

元ファイル：[`app.py` 全体（1〜15行）](./app.py#L1-L15)。

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp


# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

## Tk3-4. 入力欄から読み取った内容は文字列

`self.number1_entry` は1つ目の数字の入力欄、`self.number2_entry` は2つ目の数字の入力欄です。`self` は、この処理を実行している電卓自身を表します。`self.number1_entry.get()` は、その電卓の1つ目の入力欄から文字列を読み取ります。

元ファイル：[`calculator.py` の53〜56行](./calculator.py#L53-L56)。

```python
        # number1_text（1つ目の入力文字列）に self.number1_entry に入力された文字列を入れる
        number1_text = self.number1_entry.get()
        # number2_text（2つ目の入力文字列）に self.number2_entry に入力された文字列を入れる
        number2_text = self.number2_entry.get()
```

`12` と `8` を入力した場合、`number1_text` には文字列 `"12"`、`number2_text` には文字列 `"8"` が入ります。`_text` は、まだ数値へ変換していない入力文字列だと分かるように付けた名前です。

## Tk3-5. 文字列の足し算では金額を足せない

次のコードは、文字列と数値の違いを示す説明用の例です。電卓のファイルへ貼り付けるコードではありません。

```python
# 文字列「12」と文字列「8」をつなげた結果を表示する
print("12" + "8")
```

この説明用の例では `128` と表示されます。文字列どうしの `+` は文字をつなげるため、買い物の合計20にはなりません。合計を求めるには、入力欄から読み取った文字列を数値へ変換する必要があります。

## Tk3-6. 小数も計算するために float() を使う

`float(number1_text)` は、入力文字列を小数も扱える数値へ変換します。たとえば、入力文字列 `"10.5"` を数値 `10.5` に変換できます。`int("10.5")` は小数点を含む文字列を整数へ変換できないため、この電卓では `float()` を使います。

元ファイル：[`calculator.py` の65〜68行](./calculator.py#L65-L68)。

```python
        # number1（1つ目の数値）に number1_text を float で数値に変換した値を入れる
        number1 = float(number1_text)
        # number2（2つ目の数値）に number2_text を float で数値に変換した値を入れる
        number2 = float(number2_text)
```

変換した1つ目の数値は `number1`、2つ目の数値は `number2` に入ります。入力欄へ `12` と `8` を入力した場合も、`float()` は `12.0` と `8.0` に変換するため、合計は `20.0` になります。

## Tk3-7. 入力欄が空なら案内を表示する

片方の金額をまだ入力していないのに計算ボタンを押すと、空の文字列を数値へ変換することになります。`float("")` は変換できないため、先に入力欄が空かどうかを確かめます。

元ファイル：[`calculator.py` の58〜63行](./calculator.py#L58-L63)。

```python
        # number1_text または number2_text が空の文字列なら、次の処理を実行する
        if number1_text == "" or number2_text == "":
            # self.result_label の表示を「数字を2つ入力してください」に変える
            self.result_label.config(text="数字を2つ入力してください")
            # calculate の処理をここで終える
            return
```

`number1_text == ""` は、1つ目の入力文字列が空かどうかを比べます。`number2_text == ""` は、2つ目の入力文字列が空かどうかを比べます。`or` で2つの条件をつなぐと、片方でも空の場合に `if` の内側が実行されます。

どちらかの入力欄が空の場合、プログラムは結果の欄に `数字を2つ入力してください` と表示します。利用者は、空だった欄に数字を入力して、もう一度「計算する」ボタンを押すと計算できます。

## Tk3-8. return で今回の計算だけを終える

空の入力欄を見つけて案内を表示した後は、数値変換へ進む必要がありません。`return` は、実行中の `calculate()` の処理をその位置で終える記述です。

元ファイル：[`calculator.py` の62〜63行](./calculator.py#L62-L63)。

```python
            # calculate の処理をここで終える
            return
```

この `return` はウィンドウを閉じる操作ではありません。`calculate()` が終わると、Tkinterは次の入力やボタン操作を待ちます。入力を補ってボタンを押すと、Tkinterが `calculate()` を最初から実行します。

## Tk3-9. 2つの数値を足す

`number1` と `number2` は、入力文字列を `float()` で変換した数値です。数値どうしを `+` で足し、変数 `answer`（答え）に計算結果を入れます。

元ファイル：[`calculator.py` の70〜71行](./calculator.py#L70-L71)。

```python
        # answer（答え）に number1 と number2 を足した値を入れる
        answer = number1 + number2
```

`number1` が `12.0`、`number2` が `8.0` の場合、`answer` は `20.0` になります。

## Tk3-10. 結果の欄に答えを表示する

`self.result_label` は、この電卓の答えを表示する `Label` です。`config(text=...)` は、すでに画面にある表示欄の文字を変更します。

元ファイル：[`calculator.py` の73〜74行](./calculator.py#L73-L74)。

```python
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")
```

`f"答え: {answer}"` は、`answer` の値を文字列の `{answer}` の位置へ入れる書き方です。`answer` が `20.0` の場合、結果の欄には `答え: 20.0` と表示されます。

## Tk3-11. 計算ボタンへ処理を登録する

入力している途中に計算が始まらないように、利用者が「計算する」ボタンを押したときだけ `calculate()` を実行します。ボタンの名前も、押すと計算が始まることが分かる「計算する」にしています。

元ファイル：[`calculator.py` の36〜44行](./calculator.py#L36-L44)。

```python
        # self.calculate_button（計算ボタン）に self.window 内で「計算する」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.calculate_button = tkinter.Button(
            self.window,
            text="計算する",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.calculate_button を self.window 内に配置する
        self.calculate_button.pack()
```

`command=self.calculate` は、この電卓の計算処理をボタンへ登録する指定です。登録するときは `self.calculate` の後ろに `()` を付けません。`command=self.calculate()` と書くと、画面を準備している時点で計算を実行してしまいます。

利用者がボタンを押すと、Tkinterが登録された `self.calculate` を実行します。計算処理は、この電卓の入力欄から文字列を読み取り、数値へ変換して足し、結果の欄を更新します。

## Tk3-12. main() から電卓を起動する

`app.py` の `from calculator import CalculatorApp` は、同じフォルダの `calculator.py` から `CalculatorApp` の定義を読み込む記述です。`calculator` と書く部分には、ファイル名の `.py` を付けません。

`calculator.py` には、クラスの定義と `import tkinter` が書かれています。クラスを定義するだけでは `__init__` の中の処理は実行されず、ウィンドウも作られません。

`app.py` を直接実行すると、末尾の `if __name__ == "__main__":` の条件に当てはまり、Pythonが `main()` を実行します。`main()` の `CalculatorApp()` が画面を作り、続く `app.run()` がTkinterの操作待ちを始めます。別のファイルから `app.py` を読み込んだ場合は、この条件に当てはまらないため `main()` は実行されません。

## Tk3-14. 計算する式を変えてみる

掛け算を試す場合は、`calculator.py` の `CalculatorApp.calculate` にある `answer = number1 + number2` を検索してください。VS CodeでCtrl + F（macOSではCommand + F）を押すと、ファイル内を検索できます。

次のコードは、足し算を掛け算へ変えた例です。`calculator.py` の70〜71行を、説明コメントも含めて次の2行へ置き換えてください。行の先頭の8個のスペースも残してください。

置き換える元の範囲：[`calculator.py` の70〜71行](./calculator.py#L70-L71)。

```python
        # answer（答え）に number1 と number2 を掛けた値を入れる
        answer = number1 * number2
```

変更した電卓を、次の手順で再実行してください。実行に使うターミナルの現在のフォルダは、Tk3-13「電卓を実行して足し算を試す」で移動したTk3用のフォルダのままです。

1. 起動中のアプリのウィンドウで、閉じるボタンを押してください。Tkinterが操作を待つ処理を終了し、実行に使ったターミナルでコマンドを入力できるようになります。
2. VS Codeで変更した `calculator.py` をCtrl + S（macOSではCommand + S）で保存してください。
3. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んで、直前の実行に使ったターミナルを開いてください。ターミナルに `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。
4. Windowsでは、同じターミナルに `python app.py` と入力し、Enterキーを押してください。直前に `py app.py` で起動した場合は、今回も `py app.py` と入力してEnterキーを押してください。macOS / Linuxでは、同じターミナルに `python3 app.py` と入力し、Enterキーを押してください。

編集したファイルは `calculator.py` ですが、起動するファイルは `app.py` のままです。`app.py` が変更後の `CalculatorApp` を読み込んで起動します。

ウィンドウの「1つ目の数字」に `10`、「2つ目の数字」に `3` を入力し、「計算する」ボタンを押してください。結果の欄に `答え: 30.0` と表示されます。

引き算を試す場合は、`calculator.py` の `CalculatorApp.calculate` 内の70〜71行を、コメントも含めて次の変更後の例へ置き換えてください。

置き換える元の範囲：[`calculator.py` の70〜71行](./calculator.py#L70-L71)。

```python
        # answer（答え）に number1 から number2 を引いた値を入れる
        answer = number1 - number2
```

Tk3-14「計算する式を変えてみる」の4つの再実行手順でウィンドウを閉じ、`calculator.py` を保存し、ターミナルで `app.py` を再実行してください。2つの入力欄に `10` と `3` を入力して「計算する」ボタンを押すと、結果の欄に `答え: 7.0` と表示されます。

割り算を試す場合も、`calculator.py` の `CalculatorApp.calculate` 内の70〜71行を、コメントも含めて次の変更後の例へ置き換えてください。

置き換える元の範囲：[`calculator.py` の70〜71行](./calculator.py#L70-L71)。

```python
        # answer（答え）に number1 を number2 で割った値を入れる
        answer = number1 / number2
```

Tk3-14「計算する式を変えてみる」の4つの再実行手順でウィンドウを閉じ、`calculator.py` を保存し、ターミナルで `app.py` を再実行してください。2つの入力欄に `10` と `2` を入力して「計算する」ボタンを押すと、結果の欄に `答え: 5.0` と表示されます。2つ目には0以外の数字を入力してください。この変更例には、0で割る計算を止める処理はありません。

## Tk3-15. 計算を選ぶボタンへ進む

Tk3の「計算する」ボタンは、`CalculatorApp.calculate` に書かれた計算式を一つ実行します。別の計算をするたびにファイルを書き換えるのは手間なので、次のTk4では画面のボタンで足し算と引き算を選ぶ電卓を扱います。

## Tk3-16. 数字以外を入力した場合

1つ目の入力欄へ `abc`、2つ目へ `8` を入力して「計算する」ボタンを押すと、`float("abc")` が文字列を数値へ変換できず、`ValueError` というエラーが起きます。Tkinterは、ボタンから実行した計算処理のエラーを、起動に使ったターミナルへ表示します。結果の欄には、直前の表示が残ります。

この電卓の空欄確認は、数字以外の文字を確認する処理ではありません。空欄の案内が出る場合と、数値へ変換できない場合を区別してください。1つ目の入力欄を `12` に書き換え、もう一度「計算する」ボタンを押すと `答え: 20.0` と表示されます。

数値への変換に失敗したときの処理の書き方は、[13章「例外処理」](../13_例外処理/例外処理.md)で扱っています。`try` と `except` は、失敗する可能性がある処理と、失敗したときに行う処理を書き分ける記述です。Tk3の配布コードには、このエラーへの対応は入っていません。

## Tk3-17. 今回の内容

- `CalculatorApp` は、電卓の画面の部品と、その部品を使う計算処理をまとめます。
- `self.number1_entry` と `self.number2_entry` は、この電卓の入力欄です。`get()` で読み取った内容は文字列です。
- `calculate()` は、空欄を確認し、入力文字列を `float()` で数値へ変換して、答えを `self.result_label` へ表示します。
- `calculator.py` は電卓の定義、`app.py` は電卓を起動する入口です。計算式を変えるファイルと、実行するファイルを区別してください。
- 再実行する場合は、起動中のウィンドウを閉じ、変更したファイルを保存し、ターミナルで `app.py` を実行してください。
