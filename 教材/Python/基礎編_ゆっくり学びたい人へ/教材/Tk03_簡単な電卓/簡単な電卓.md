# Tk3. 簡単な電卓

Tk2で、入力欄とボタンのある画面ができました。次は、買い物の合計などを確かめるために、2つの数字を入れて足した答えが出る電卓にしたいところです。

> **「数字を入れて『計算する』を押したら、答えが出てほしい！」**

この章の題材は、2つの数字を足す電卓です。12と8を入力してボタンを押すと、画面に「答え: 20.0」と表示されます。数字を変えれば、別の足し算もできます。

---

## Tk3-1. 今回作るもの

画面には、

- 1つ目の数字を入れる入力欄
- 2つ目の数字を入れる入力欄
- 「計算する」ボタン
- 答えを表示する場所

このコードは、上に示した内容を作る処理です。

たとえば、

```text
1つ目: 12
2つ目: 8
```

と入力してボタンを押すと、

```text
答え: 20
```

と表示されます。

---

## Tk3-2. なぜこの章を作るの？

Tk1では、

> **「文字ばっかでつまらん！！！」**

からウィンドウを出しました。

Tk2では、名前を入力してボタンを押すと、挨拶が出る画面を作りました。次は、入力した数字を計算して答えを出したいところです。

入力欄と「計算する」ボタンを置くだけでは、足し算の答えは出ません。

たとえば、

```text
[ 12 ]
[  8 ]
[ 計算する ]
```

まで表示できても、ボタンを押して何も起きなかったら、

> **「それ電卓じゃなくて電卓の写真じゃん！！！」**

となります。

そこでこの章では、GUIの部品とPythonの計算処理をつなげます。

**見た目 + 入力 + 計算 + 結果表示**がそろうと、ようやく「使える小さなアプリ」になります。

---

## Tk3-3. 入力と計算をつなぐ

[simple_calculator.py](./simple_calculator.py) を開いてください。

`simple` は「簡単な」、`calculator` は「電卓」という意味です。

このプログラムは、まず、2つの入力欄から文字を取り出します。

1つ目は `number1_text`、2つ目は `number2_text` にしてください。

Pythonは数値へ変換した値を、それぞれ `number1` と `number2` に保存します。

足した結果は `answer` に入れ、最後に `result_label` を書き換えます。

このコードの元ファイル：[`simple_calculator.py` の 1〜74行](./simple_calculator.py#L1-L74)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 入力された2つの数字を足して答えを表示する calculate を定義する
def calculate():
    # number1_text に number1_entry に入力された文字列を入れる
    number1_text = number1_entry.get()
    # number2_text に number2_entry に入力された文字列を入れる
    number2_text = number2_entry.get()

    # number1_text または number2_text が空の文字列なら、次の処理を実行する
    if number1_text == "" or number2_text == "":
        # result_label の表示を「数字を2つ入力してください」に変える
        result_label.config(text="数字を2つ入力してください")
        # calculate の処理をここで終える
        return

    # number1 に number1_text を float で数値に変換した値を入れる
    number1 = float(number1_text)
    # number2 に number2_text を float で数値に変換した値を入れる
    number2 = float(number2_text)

    # answer に number1 と number2 を足した値を入れる
    answer = number1 + number2

    # result_label の表示を「答え: 」と answer の値を含む文字列に変える
    result_label.config(text=f"答え: {answer}")


# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()
# window のタイトルを「簡単な電卓」にする
window.title("簡単な電卓")
# window の大きさを横400、縦260にする
window.geometry("400x260")

# number1_label に window 内で「1つ目の数字」と表示するラベルを入れる
number1_label = tkinter.Label(window, text="1つ目の数字")
# number1_label を window 内に配置する
number1_label.pack()

# number1_entry に window 内の1行の入力欄を入れる
number1_entry = tkinter.Entry(window)
# number1_entry を window 内に配置する
number1_entry.pack()

# number2_label に window 内で「2つ目の数字」と表示するラベルを入れる
number2_label = tkinter.Label(window, text="2つ目の数字")
# number2_label を window 内に配置する
number2_label.pack()

# number2_entry に window 内の1行の入力欄を入れる
number2_entry = tkinter.Entry(window)
# number2_entry を window 内に配置する
number2_entry.pack()

# 計算する
# calculate_button に window 内で「計算する」と表示し、押すと calculate を呼ぶボタンを入れる
calculate_button = tkinter.Button(
    window,
    text="計算する",
    command=calculate
)
# calculate_button を window 内に配置する
calculate_button.pack()

# result_label に window 内で「答え:」と表示するラベルを入れる
result_label = tkinter.Label(window, text="答え:")
# result_label を window 内に配置する
result_label.pack()

# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

## Tk3-4. Entryから取り出した値は文字

このプログラムは、Tk2で使った `.get()` を今回も使います。

入力欄から取り出した直後は文字列なので、名前にも `_text` を付けて区別してください。

このコードの元ファイル：[`simple_calculator.py` の 8〜10行](./simple_calculator.py#L8-L10)。

```python
# number1_text に number1_entry に入力された文字列を入れる
number1_text = number1_entry.get()
# number2_text に number2_entry に入力された文字列を入れる
number2_text = number2_entry.get()
```

ここで大切なのは、Entryから取り出した内容は**文字列**だということです。

たとえば画面に、

```text
12
```

と入力しても、Pythonでは最初、

```text
"12"
```

という文字として受け取ります。

## Tk3-5. 文字のまま足すとどうなる？

もし、

```python
# answer に number1_text と number2_text の文字列をつなげた値を入れる
answer = number1_text + number2_text
```

と書いて、

```text
12
8
```

を入力すると、結果は、

```text
128
```

になります。

足し算のつもりなのに、文字がつながってしまいます。

このプログラムは、計算用の数値へ変換します。

変換後は `number1` と `number2` に入れてください。

このコードの元ファイル：[`simple_calculator.py` の 20〜22行](./simple_calculator.py#L20-L22)。

```python
# number1 に number1_text を float で数値に変換した値を入れる
number1 = float(number1_text)
# number2 に number2_text を float で数値に変換した値を入れる
number2 = float(number2_text)
```

これで計算できる数値になります。

4章「数値と計算」で学んだ内容が、ここでそのまま使われています。

---

## Tk3-6. なぜ `float()` を使うの？

今回は `int()` ではなく `float()` を使っています。

`int()` なら整数だけを扱えます。

```text
10
25
100
```

一方、`float()` なら、

```text
10.5
3.14
0.5
```

のような小数も扱えます。

小数も計算できるように、このプログラムは `float()` を使います。

## Tk3-7. 入力が空なら計算しない

次の部分を見てください。

このコードの元ファイル：[`simple_calculator.py` の 13〜17行](./simple_calculator.py#L13-L17)。

```python
# number1_text または number2_text が空の文字列なら、次の処理を実行する
if number1_text == "" or number2_text == "":
    # result_label の表示を「数字を2つ入力してください」に変える
    result_label.config(text="数字を2つ入力してください")

    return
```

入力欄が空の場合は、計算せず、

```text
数字を2つ入力してください
```

これが、プログラムの表示する内容です。

ここでは5章で学んだ**条件分岐**を使っています。

`or` は、

> どちらか一方でも条件に当てはまれば

という意味です。

## Tk3-8. `return` で途中で関数を終える

入力が空だった場合は、

このコードの元ファイル：[`simple_calculator.py` の 17〜17行](./simple_calculator.py#L17-L17)。

```python
# calculate の処理をここで終える
return
```

で関数をそこで終わらせています。

もしここで止めなければ、そのあと、

```python
# 空の文字列を float で数値に変換する（エラーになる）
float("")
```

を実行しようとしてエラーになります。

今回は、

> 入力が足りないなら、その先の計算へ進まない

ために `return` を使っています。

## Tk3-9. 実際に計算する

入力を数値へ変換したら、足し算した結果を保存する場所が必要です。

名前は `answer` にしてください。

このコードの元ファイル：[`simple_calculator.py` の 25〜25行](./simple_calculator.py#L25-L25)。

```python
# answer に number1 と number2 を足した値を入れる
answer = number1 + number2
```

これで足し算の結果が `answer` に入ります。

ここは普通のPythonの計算と同じです。

GUIだから特別な計算方法になるわけではありません。

**GUIは入力と表示の方法が変わります。計算に使うのは、今まで学んだPythonの書き方です。**

## Tk3-10. 計算結果を画面へ表示する

計算結果を表示する場所も必要なので、結果用Labelは `result_label` にしておきます。

計算したら、

このコードの元ファイル：[`simple_calculator.py` の 28〜28行](./simple_calculator.py#L28-L28)。

```python
# result_label の表示を「答え: 」と answer の値を含む文字列に変える
result_label.config(text=f"答え: {answer}")
```

でそのLabelを書き換えます。

Tk2で使った `config()` と同じです。

流れをまとめると、

```text
Entryから文字を取る
        ↓
float()で数値へ変換
        ↓
足し算する
        ↓
Labelを書き換える
```

となります。

## Tk3-14. 掛け算へ変えてみる

次の部分を、

このコードの元ファイル：[`simple_calculator.py` の 25〜25行](./simple_calculator.py#L25-L25)。

```python
# answer に number1 と number2 を足した値を入れる
answer = number1 + number2
```

から、

```python
# answer に number1 と number2 を掛けた値を入れる
answer = number1 * number2
```

へ変えると掛け算になります。

同じように、

```python
# answer に number1 から number2 を引いた値を入れる
answer = number1 - number2
```

なら引き算、

```python
# answer に number1 を number2 で割った値を入れる
answer = number1 / number2
```

なら割り算です。
