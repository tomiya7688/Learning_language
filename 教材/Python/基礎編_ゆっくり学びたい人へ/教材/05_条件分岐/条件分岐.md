# 5. 条件分岐

4章では、入力した値を `int(...)` で整数に変え、計算した答えを `print(...)` で表示しました。次は、受け取った値によって、表示する文章を変えたいところです。

たとえば、テストの点数を入力すると、点数に合ったメッセージを表示するプログラムを考えてみてください。点数を受け取る部分は4章と同じ書き方で作れます。英語で「点数」を意味する `score` という変数を使うと、次のようになります。

**これまでの書き方を使った説明用の例**です。

```python
# score に「点数を入力してください: 」と表示して入力された文字列を入れる
score = input("点数を入力してください: ")
# score の文字列を整数へ変えて、score に入れ直す
score = int(score)
# 「合格です」とターミナルに表示する
print("合格です")
```

この例では、入力した点数を `score` へ入れていますが、表示する文章を選ぶためには使っていません。30と入力しても82と入力しても、次の行で「合格です」と表示します。

> **「点数違うのに、全員合格なの？？？」**

点数を受け取るだけでなく、基準に合うかを調べ、表示する文章を選ぶ処理が必要です。この章では、入力した点数によって表示するメッセージが変わるプログラムを作ります。

---

## 5-1. 今回作るもの

このプログラムでは、80点以上なら「とても良い結果です」、60点以上80点未満なら「合格です」、60点未満なら「もう一度挑戦しましょう」と表示する基準にします。

次は、完成後の動きを示す実行例です。プログラムが名前ではなく点数を尋ね、利用者が82と入力すると、対応するメッセージを表示します。保存して動かす手順は5-2で説明します。

```text
点数を入力してください: 82
とても良い結果です
```

この例の「82」は利用者が入力する数字で、それ以外の文章はプログラムが表示するものです。

「点数が80点以上か」のように、値が基準に合うかを調べるものを **条件** といいます。条件に応じて実行する処理を分ける書き方が **条件分岐** です。点数の入力・整数への変換・表示には4章と同じ書き方を使い、今回はメッセージを選ぶための条件分岐を加えます。

### 別の例：アンケートの回答に合う文章を表示する

プログラムは、何も条件を付けなければ上から順番に処理します。

ここからは、アンケートを使った説明用の例です。

たとえばアンケートで、

```text
性別を選んでください: 男性
```

と答えたとします。

ところが、条件分岐を使わずに、

```python
# 「あなたは男性です」と表示する
print("あなたは男性です")
# 「あなたは女性です」と表示する
print("あなたは女性です")
```

と書いてあれば、

```text
あなたは男性です
あなたは女性です
```

と両方表示されてしまいます。

プログラムは「これは今は表示しないほうがいいかな」と自分で判断してはくれません。男性と回答した利用者に女性向けの文も表示されたら、利用者はこう言いたくなります。

> **「男だって言ってんだろ！」**

利用者の回答に合う文だけを表示するには、入力に応じて条件ごとに処理を分ける必要があります。

> この条件ならこの処理
>
> 別の条件なら別の処理

条件ごとに実行する処理を分ける書き方を **条件分岐** と呼びます。

## 5-2. 点数を受け取って判定する

VS Codeの **ファイル → 新しいテキストファイル** を選び、下のコード全体を書いてください。保存する名前は `score_check.py` にします。

`score_check.py` は「点数を判定する」という意味のファイル名です。`score` は「点数」、`check` は「確認する・判定する」という意味です。

入力された点数をあとでメッセージの選択に使うため、英語で「点数」を意味する `score` という変数（値に付ける名前）へ入れます。

4章では、`input(...)` で受け取った文字列を、次の行の `int(...)` で整数へ変えました。ここでは `int(input(...))` とまとめて書きます。Pythonは内側の `input(...)` で文字列を受け取り、外側の `int(...)` で整数へ変えてから、`score` に入れます。

`>=` は、左側の値が右側の値以上かを調べる記号です。次のコードは、入力された点数を80点以上、60点以上80点未満、60点未満の3つに分けて判定します。

`if` は最初の条件、`elif` は前の条件が成り立たなかった場合に調べる次の条件、`else` はどの条件にも当てはまらない場合の処理を指定します。それぞれの行末には `:` を付けます。条件に合ったときの処理は次の行から書き、行頭に半角スペース4個を入れて右へずらしてください。この行頭の空白による字下げを **インデント** と呼び、実行する処理の範囲を示します。

このコードの元ファイル：[`score_check.py` の 1〜18行](./score_check.py#L1-L18)。

```python
# score は「点数」という意味の変数
# score に「点数を入力してください: 」と表示して入力された文字列を整数にして入れる
score = int(input("点数を入力してください: "))

# score が80以上なら、字下げした処理を実行する
if score >= 80:
    # 「とても良い結果です」とターミナルに表示する
    print("とても良い結果です")

# score が80未満で60以上なら、字下げした処理を実行する
elif score >= 60:
    # 「合格です」とターミナルに表示する
    print("合格です")

# score が80以上でも60以上でもない場合、字下げした処理を実行する
else:
    # 「もう一度挑戦しましょう」とターミナルに表示する
    print("もう一度挑戦しましょう")
```

## 5-3. `if` とは

`if` は、条件が成り立つ場合だけ、字下げした処理を実行するPythonの書き方です。`if` の後ろに条件を書き、行末に `:` を付けます。実行する処理は次の行に書き、行頭に半角スペース4個を入れて右へずらしてください。この行頭の空白による字下げを **インデント** と呼びます。

`score` は、この章のプログラムが入力から受け取った点数を保存する変数です。

たとえば、次のコードは `score` が80以上の場合に「とても良い結果です」と表示します。

このコードの元ファイル：[`score_check.py` の 5〜8行](./score_check.py#L5-L8)。

```python
# score が80以上なら、字下げした処理を実行する
if score >= 80:
    # 「とても良い結果です」とターミナルに表示する
    print("とても良い結果です")
```

---

## 5-4. `>=` は何を表している？

次は、[`score_check.py` の6行](./score_check.py#L6-L6)の条件の式だけを取り出した説明用の例です。

```python
score >= 80
```

`score >= 80` の `>=` は、`score` に保存した点数が80以上かを調べる記号です。

よく使う比較記号は次のとおりです。

| 記号 | 意味 |
| --- | --- |
| `==` | 等しい |
| `!=` | 等しくない |
| `>` | より大きい |
| `<` | より小さい |
| `>=` | 以上 |
| `<=` | 以下 |

---

## 5-5. `=` と `==` は違う

Pythonでは、`=` と `==` は見た目が似ていますが、役割が違います。次の2つは書き方を比べる説明用の例で、ファイルに追加するコードではありません。

```python
# score に整数の80を入れる
score = 80
```

`score = 80` の `=` は、右側の80を左側の変数 `score` に保存する記号です。

一方、

```python
# score の値が80と等しいかを調べる
score == 80
```

`score == 80` の `==` は、変数 `score` に保存された値が80と等しいかを調べる記号です。

つまり、

```text
=   → 値を入れる
==  → 同じか調べる
```

です。

---

## 5-6. `elif` とは

`elif` は、それまでの条件に当てはまらない場合に、次の条件を調べるための書き方です。同じ条件分岐の `if` の処理の後ろに続けて書き、`if` と同じ位置から書き始めます。`elif` の後ろに条件と `:` を書き、その条件に合ったときの処理を、次の行から半角スペース4個で字下げしてください。別の条件を増やす場合は、`elif` を続けて追加できます。

このコードの元ファイル：[`score_check.py` の 10〜13行](./score_check.py#L10-L13)。

```python
# score が80未満で60以上なら、字下げした処理を実行する
elif score >= 60:
    # 「合格です」とターミナルに表示する
    print("合格です")
```

`elif score >= 60:` は、先の `if score >= 80:` が成り立たなかった場合に、80点未満の点数が60点以上かどうかを調べます。

---

## 5-7. `else` とは

`else` の中の処理は、同じ条件分岐にある `if score >= 80:` と `elif score >= 60:` のどちらも成り立たない場合に実行されます。`else:` は同じ条件分岐の最後に、`if` と同じ位置から書きます。`else` の後ろに条件は書かず、次の行から行う処理を半角スペース4個で字下げしてください。

このコードの元ファイル：[`score_check.py` の 15〜18行](./score_check.py#L15-L18)。

```python
# score が80以上でも60以上でもない場合、字下げした処理を実行する
else:
    # 「もう一度挑戦しましょう」とターミナルに表示する
    print("もう一度挑戦しましょう")
```

この条件分岐では、`else` の処理は `score` が60点未満の場合に実行されます。

---

## 5-8. 条件は上から順番に確認される

次のコードでは、

このコードの元ファイル：[`score_check.py` の 5〜18行](./score_check.py#L5-L18)。

```python
# score が80以上なら、字下げした処理を実行する
if score >= 80:
    # 「とても良い結果です」とターミナルに表示する
    print("とても良い結果です")

# score が80未満で60以上なら、字下げした処理を実行する
elif score >= 60:
    # 「合格です」とターミナルに表示する
    print("合格です")

# score が80以上でも60以上でもない場合、字下げした処理を実行する
else:
    # 「もう一度挑戦しましょう」とターミナルに表示する
    print("もう一度挑戦しましょう")
```

条件は上から順番に確認されます。

次は、[`score_check.py` の6行](./score_check.py#L6-L6)から条件の式だけを取り出した説明用の例です。たとえば、入力した点数 `score` が90の場合、

```python
score >= 80
```

は成り立ちます。この点数判定の条件分岐では、`score >= 80` が成り立つと、「とても良い結果です」と表示し、後ろの `elif` と `else` の処理は実行しません。

## 5-9. インデントとは

行の先頭に半角スペースを入れて右へずらすことを **インデント** と呼びます。次のコードでは、`print(...)` の前にある半角スペース4個がインデントです。Pythonはその位置で、`if` の条件に合ったときに実行する処理を判断します。

このコードの元ファイル：[`score_check.py` の 5〜8行](./score_check.py#L5-L8)。

```python
# score が80以上なら、字下げした処理を実行する
if score >= 80:
    # 「とても良い結果です」とターミナルに表示する
    print("とても良い結果です")
```

次のコードを実行すると、条件に合ったときの処理が字下げされていないため、Pythonはエラーを表示します。

このコードの元ファイル：[`score_check.py` の 5〜8行](./score_check.py#L5-L8)。次は、元の例から行頭の空白を取り除いた、動かない例です。

```python
# score が80以上なら、字下げした処理を実行する
if score >= 80:
# 「とても良い結果です」とターミナルに表示する
print("とても良い結果です")
```

この教材では、インデントには **半角スペース4個** を基本として使います。

VS Codeでは Enter キーを押したときに、
必要なインデントを自動で入れてくれることがあります。

## 5-10. `:` を忘れない

`if`、`elif`、`else` の行の最後には `:` を書いてください。

このコードの元ファイル：[`score_check.py` の 6〜6行](./score_check.py#L6-L6)。

```python
if score >= 80:
```

このコードの元ファイル：[`score_check.py` の 11〜11行](./score_check.py#L11-L11)。

```python
elif score >= 60:
```

このコードの元ファイル：[`score_check.py` の 16〜16行](./score_check.py#L16-L16)。

```python
else:
```

`if`、`elif`、`else` の行から `:` を抜いて実行すると、Pythonはエラーを表示します。

## 5-11. 自分で変えてみる

次は、80点以上・60点以上という基準を、それぞれ90点以上・70点以上へ変えてみてください。

VS Codeで `score_check.py` を開き、[5〜18行の条件分岐](./score_check.py#L5-L18)を、コメントも含めて次のコードへ置き換えてください。入力を受け取る1〜3行は残してください。

```python
# score が90以上なら、字下げした処理を実行する
if score >= 90:
    # 「最高評価です」とターミナルに表示する

# score が90未満で70以上なら、字下げした処理を実行する
elif score >= 70:
    # 「合格です」とターミナルに表示する

# score が90以上でも70以上でもない場合、字下げした処理を実行する

    print("再挑戦です")
```

2. VS Codeの **表示 → ターミナル** を選び、5-2で学習用フォルダへ移動したターミナルを表示してください。そのターミナルを閉じてしまった場合は、[5-2の保存して点数を入力する手順](#保存して点数を入力する)で、保存先のパスの確認と `cd` からやり直してください。
