# 5. 条件分岐

点数を入力する判定プログラムで、30点でも82点でも同じ「合格です」と出たら、判定になりません。

> **「点数違うのに、全員合格なの？？？」**

条件は、「点数が80点以上か」のように、値が決めた基準に合うかを調べるものです。この点数判定プログラムは、入力した点数を条件と比べ、点数に合った結果だけを表示します。

---

## 5-1. 今回作るもの

プログラムを実行すると、点数を尋ねる案内が表示されます。案内の後ろに点数を入力し、Enterキーを押してください。

```text
点数を入力してください: 82
```

入力した点数によって、表示される結果が変わります。

例:

```text
とても良い結果です
```

別の点数なら、

```text
合格です
```

または、

```text
もう一度挑戦しましょう
```

これまでのプログラムは、基本的に上から順番に同じ処理を実行していました。

この点数判定プログラムは、点数を条件と比べ、条件に合った結果だけを表示します。

> 条件を確認する
> ↓
> 条件に合う結果だけを表示する

### なぜ条件分岐が必要なの？

プログラムは、何も条件を付けなければ上から順番に処理します。

たとえばアンケートで、

```text
性別を選んでください: 男性
```

と答えたとします。

ところが、条件分岐を使わずに、

```python
print("あなたは男性です")
print("あなたは女性です")
```

と書いてあれば、

```text
あなたは男性です
あなたは女性です
```

と両方表示されてしまいます。

プログラムは「これは今は表示しないほうがいいかな」と自分で判断してはくれません。男性と回答した利用者に女性向けの文も表示されたら、利用者はこう言いたくなります。

> **「男だって言ってんだろ！」**

利用者の回答に合う文だけを表示するには、入力に応じて条件ごとに処理を分ける必要があります。

> この条件ならこの処理
>
> 別の条件なら別の処理

条件ごとに実行する処理を分ける書き方を **条件分岐** と呼びます。

---

## 5-2. 点数を受け取って判定する

[score_check.py](./score_check.py) を開いてください。

`score_check.py` は「点数を判定する」という意味のファイル名です。`score` は「点数」、`check` は「確認する・判定する」という意味です。

このプログラムは、入力された点数をあとで判定に使うため、`score` という変数（値につける名前）に保存します。

Pythonは入力を文字列として受け取るため、`int()` で整数へ変換してから `score` に保存します。

`>=` は、左側の値が右側の値以上かを調べる記号です。次のコードは、入力された点数を80点以上、60点以上80点未満、60点未満の3つに分けて判定します。

`if` は最初の条件、`elif` は前の条件が成り立たなかった場合に調べる次の条件、`else` はどの条件にも当てはまらない場合の処理を指定します。

```python
# 入力を受け取り、int() で整数に変換して score に保存します。
score = int(input("点数を入力してください: "))

# 80点以上なら、この処理を実行します。
if score >= 80:
    print("とても良い結果です")

# 60点以上80点未満なら、この処理を実行します。
elif score >= 60:
    print("合格です")

# それ以外の場合は、この処理を実行します。
else:
    print("もう一度挑戦しましょう")
```

---

## 5-3. `if` とは

`if` は、条件が成り立つ場合だけ、字下げした処理を実行するPythonの書き方です。

`score` は、この章のプログラムが入力から受け取った点数を保存する変数です。

たとえば、次のコードは `score` が80以上の場合に「とても良い結果です」と表示します。

```python
if score >= 80:
    print("とても良い結果です")
```

---

## 5-4. `>=` は何を表している？

```python
score >= 80
```

`score >= 80` の `>=` は、`score` に保存した点数が80以上かを調べる記号です。

よく使う比較記号は次のとおりです。

| 記号 | 意味 |
| --- | --- |
| `==` | 等しい |
| `!=` | 等しくない |
| `>` | より大きい |
| `<` | より小さい |
| `>=` | 以上 |
| `<=` | 以下 |

---

## 5-5. `=` と `==` は違う

Pythonでは、`=` と `==` は見た目が似ていますが、役割が違います。

```python
score = 80
```

`score = 80` の `=` は、右側の80を左側の変数 `score` に保存する記号です。

一方、

```python
score == 80
```

`score == 80` の `==` は、変数 `score` に保存された値が80と等しいかを調べる記号です。

つまり、

```text
=   → 値を入れる
==  → 同じか調べる
```

です。

---

## 5-6. `elif` とは

`elif` は、それまでの条件に当てはまらない場合に、次の条件を調べるための書き方です。

```python
elif score >= 60:
    print("合格です")
```

`elif score >= 60:` は、先の `if score >= 80:` が成り立たなかった場合に、80点未満の点数が60点以上かどうかを調べます。

---

## 5-7. `else` とは

`else` の中の処理は、同じ条件分岐にある `if score >= 80:` と `elif score >= 60:` のどちらも成り立たない場合に実行されます。

```python
else:
    print("もう一度挑戦しましょう")
```

この条件分岐では、`else` の処理は `score` が60点未満の場合に実行されます。

---

## 5-8. 条件は上から順番に確認される

次のコードでは、

```python
if score >= 80:
    print("とても良い結果です")
elif score >= 60:
    print("合格です")
else:
    print("もう一度挑戦しましょう")
```

条件は上から順番に確認されます。

たとえば、入力した点数 `score` が90の場合、

```python
score >= 80
```

は成り立ちます。この点数判定の条件分岐では、`score >= 80` が成り立つと、「とても良い結果です」と表示し、後ろの `elif` と `else` の処理は実行しません。

---

## 5-9. インデントとは

`if` の条件に合ったときに実行する行は、`if` の行より右へ字下げします。この字下げを **インデント** と呼び、Pythonはその位置で `if` に属する処理を判断します。

```python
if score >= 80:
    print("とても良い結果です")
```

次のコードを実行すると、条件に合ったときの処理が字下げされていないため、Pythonはエラーを表示します。

```python
if score >= 80:
print("とても良い結果です")
```

この教材では、インデントには **半角スペース4個** を基本として使います。

VS Codeでは Enter キーを押したときに、
必要なインデントを自動で入れてくれることがあります。

---

## 5-10. `:` を忘れない

`if`、`elif`、`else` の行の最後には `:` を書いてください。

```python
if score >= 80:
```

```python
elif score >= 60:
```

```python
else:
```

`if`、`elif`、`else` の行から `:` を抜いて実行すると、Pythonはエラーを表示します。

---

## 5-11. 自分で変えてみる

判定する点数を変えてみてください。

たとえば、

```python
if score >= 90:
    print("最高評価です")
elif score >= 70:
    print("合格です")
else:
    print("再挑戦です")
```

のようにできます。

また、点数以外にも、

- 年齢
- 金額
- 気温
- ゲームの得点
- 在庫数

など、数値によって処理を変えたい場面で同じ考え方を使えます。

---

## 5-12. 今回の内容

この章で扱った内容をまとめます。

1. `if` で条件に合うときだけ処理できる
2. `elif` で別の条件を追加できる
3. `else` でそれ以外を扱える
4. `==`、`>=`、`<=` などで値を比較できる
5. `=` と `==` は意味が違う
6. Pythonではインデントが重要
7. `if`、`elif`、`else` の行末には `:` が必要
