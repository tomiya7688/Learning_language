# Tk1. tkinter入門 - 最初のウィンドウ

電卓で数字を入力し、「計算する」ボタンを押して使いたいとします。ターミナルは文字を入力して実行する場所なので、数字を入れる欄やボタンを置けません。

> **「数字を入れて、ボタンを押して使う電卓にしたい！」**

そのために、数字の入力欄やボタンを置く画面が必要です。パソコン上に開く画面の枠を **ウィンドウ** と呼びます。画面に入力欄やボタンを置いて操作する仕組みは **GUI** と呼ばれます。この章では、部品を置く前の空のウィンドウを表示します。

---

## Tk1-1. 今回作るもの

このプログラムは、タイトルが「はじめてのGUI」、横400ピクセル・縦300ピクセルの空のウィンドウを表示します。タイトルには、画面上部に表示する名前を指定してください。

```text
はじめてのGUI
```

ウィンドウには、まだボタンや入力欄はありません。まず、空のウィンドウが表示されることを確認してください。

---

## Tk1-2. tkinterとは？

**tkinter** は、Pythonでウィンドウやボタンなどを作るための標準ライブラリです。

標準ライブラリとは、

> Pythonをインストールしたときから使える機能

のことです。

そのため、通常は追加で何かをインストールしなくても使えます。

この章では、tkinterを使って、

- ウィンドウを作る
- タイトルを付ける
- サイズを決める
- 画面を表示したままにする

ところまで進みます。

---

## Tk1-3. なぜGUIを使うの？

これまでのプログラムでは、ターミナルに文字を表示してきました。

ターミナルでも計算や文字表示はできます。ただし、数字を入力するたびに決まった形式で文字を打つ必要があります。使う人は、

> **「文字ばっかでつまらん！！！」**

と感じることがあります。

ずっと、

```text
1: 開く
2: 保存
3: 設定
4: 終了
```

のような画面だけでは、

- 何ができるのか一目で分かりにくい
- 見た目がずっと文字だけ
- 「ちょっと触ってみよう」となりにくい

という困りごとがあります。

GUIなら、

- 「開く」ボタン
- 「保存」ボタン
- 「設定」ボタン

のように、**できることを画面に見せられます。**

この章では、まずウィンドウを表示します。次の章では、ウィンドウに入力欄とボタンを置き、電卓へ近づけます。

---

## Tk1-4. サンプルコード

[app.py](./app.py) を開いてください。

`app.py` は、この章のアプリを起動する入口です。Tk01からTk07までは章ごとに別のフォルダへ保存するため、どの章も起動ファイル名を `app.py` に揃えています。

次の章で入力欄やボタンを加えると、ウィンドウの設定、画面の部品、部品を操作する処理が必要になります。それらがファイル内の別々の場所にあると、どの部品をどの処理が使うのか追いづらくなります。そこで、この章ではウィンドウと設定を `App` クラスにまとめます。Tk02では、同じまとめ方で入力欄・ボタン・挨拶の処理を持つ `GreetingApp` クラスを定義します。`GreetingApp` は挨拶用の画面を表す名前で、この章の `App` とは別のクラスです。

`App.__init__` は、ウィンドウを作ってタイトルと大きさを設定する処理です。画面の準備中に操作待ちの `mainloop()` を始めると、ウィンドウを閉じるまで `__init__` の実行が終わらず、`App()` の次の行へ進めません。準備を終えてから操作待ちを始められるように、`mainloop()` を実行する処理は `run()` に分けます。

ファイルの先頭へ起動処理を直接書くと、別のファイルから `import` で読み込んだときもウィンドウが開きます。必要なときだけ起動できるように、`App()` で画面を準備して `app.run()` で操作を待つ順番を `main()` にまとめます。ファイル末尾の `if __name__ == "__main__":` は、`app.py` を直接実行した場合だけ `main()` を実行するための記述です。

このコードの元ファイル：[`app.py` 全体（1〜32行）](./app.py#L1-L32)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# ウィンドウと設定をまとめる App クラスを定義する
class App:
    # App の初期設定を行う __init__ を定義する
    def __init__(self):
        # self.window に tkinter.Tk() で作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「はじめてのGUI」にする
        self.window.title("はじめてのGUI")
        # self.window の大きさを横400、縦300にする
        self.window.geometry("400x300")

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()


# アプリの起動処理を main にまとめる
def main():
    # app に App() で作ったアプリを入れる
    app = App()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

## Tk1-5. 実行してみる

VS Codeで、この章の [`app.py`](./app.py) を開き、Ctrl + S（macOSではCommand + S）で保存してください。前に起動したTkinterのウィンドウが残っている場合は、そのウィンドウの閉じるボタンを押してください。前の実行を終えた場合は、VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、実行に使ったターミナルで `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。

1. Windowsでは、エクスプローラーでこの章の `app.py` が入ったフォルダを開いてください。上部のアドレスバーをクリックし、表示されたフォルダのパスをCtrl + Cでコピーしてください。macOS / Linuxでは、VS Codeのエクスプローラーでこの章のフォルダを右クリックし、**パスのコピー（Copy Path）** を選んでください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでターミナルを開き、次のコマンドを入力してください。引用符の中へ、手順1でコピーしたフォルダのパスを貼り付けてください。

   ```text
   cd "ここにコピーしたフォルダのパスを貼り付ける"
   ```

3. Enterキーを押してください。ターミナルの現在のフォルダが、この章の `app.py` のあるフォルダに変わります。
4. Windowsでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python app.py
   ```

   `python` が見つからないというメッセージが出た場合は、同じターミナルに `py app.py` と入力し、Enterキーを押してください。

   macOS / Linuxでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python3 app.py
   ```

ウィンドウが開いている間、Tkinterは操作を待ち続けるため、このターミナルには次のコマンドを入力できません。変更後にもう一度起動する場合は、先にウィンドウを閉じてください。

ウィンドウが開いたら、タイトルが「はじめてのGUI」になっていることを確認してください。

## Tk1-6. `import tkinter` とは

`app.py` の2行目で `tkinter` を読み込みます。

このコードの元ファイル：[`app.py` の1〜2行](./app.py#L1-L2)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
```

`import tkinter` を書くと、このファイルから `tkinter.Tk()` などの機能を使えます。`tkinter` には、ウィンドウ、ボタン、入力欄などを作る機能があります。

## Tk1-7. `App` クラスに画面をまとめる

ウィンドウにはタイトルや大きさを設定し、最後に表示する処理が必要です。これらは同じウィンドウを扱う処理なので、`App` クラスの中へまとめます。

このコードの元ファイル：[`app.py` の5〜14行](./app.py#L5-L14)。

```python
# ウィンドウと設定をまとめる App クラスを定義する
class App:
    # App の初期設定を行う __init__ を定義する
    def __init__(self):
        # self.window に tkinter.Tk() で作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「はじめてのGUI」にする
        self.window.title("はじめてのGUI")
        # self.window の大きさを横400、縦300にする
        self.window.geometry("400x300")
```

`App` は、この章のアプリを表すクラスです。`tkinter.Tk()` は、画面に表示するウィンドウを作ります。`self.window` は、作ったウィンドウをこのアプリに保存する名前です。

`self` は、作成中の `App` そのものを指します。`self.window` と書くと、「このアプリのウィンドウ」を表します。`__init__` は `App()` を実行したときに、ウィンドウを作るメソッドです。

`tkinter.Tk` も `App` もクラスですが、ここでの役割は別です。`tkinter.Tk()` は実際のウィンドウを作り、`App()` はウィンドウやアプリの処理をまとめたものを作ります。

## Tk1-8. タイトルを付ける

`App.__init__` の中で、`self.window.title()` にタイトルの文字列を指定します。

```python
# self.window のタイトルを「はじめてのGUI」にする
self.window.title("はじめてのGUI")
```

`title()` は、ウィンドウ上部に表示する文字を設定します。括弧の中の文字列がタイトルになります。

## Tk1-9. サイズを決める

`App.__init__` の中で、`self.window.geometry()` に横幅と高さを指定します。

このコードの元ファイル：[`app.py` の13〜14行](./app.py#L13-L14)。

```python
# self.window の大きさを横400、縦300にする
self.window.geometry("400x300")
```

`"400x300"` は、横幅400ピクセル・高さ300ピクセルを表します。ここでの `x` は、横幅と高さを区切る文字です。

## Tk1-10. `run()` でウィンドウを表示する

タイトルとサイズを決めただけでは、利用者が操作できる画面になりません。`run()` を呼び出して、ウィンドウを表示したまま利用者の操作を待ちます。

このコードの元ファイル：[`app.py` の16〜19行](./app.py#L16-L19)。

```python
    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

`mainloop()` は、マウスやボタンの操作、ウィンドウを閉じる操作を待つ処理です。ウィンドウを閉じると `mainloop()` が終わり、プログラムも続きの処理へ進みます。

---

## Tk1-11. `main()` からアプリを起動する

起動処理を `main()` にまとめます。`main()` は `App()` でアプリを作り、`app.run()` でそのウィンドウを表示します。

このコードの元ファイル：[`app.py` の22〜27行](./app.py#L22-L27)。

```python
# アプリの起動処理を main にまとめる
def main():
    # app に App() で作ったアプリを入れる
    app = App()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()
```

ファイルの最後にある `if __name__ == "__main__":` は、`app.py` を直接実行したときに `main()` を呼び出します。別のPythonファイルが `app.py` を読み込んだだけなら、この `if` の中は実行されないため、ウィンドウは開きません。

このファイルを直接実行すると、Pythonは `__name__` に `"__main__"` を設定します。そのため、次の `main()` が実行され、ウィンドウが表示されます。

## Tk1-12. 自分でタイトルと大きさを変える

4. Windowsでは、同じターミナルに `python app.py` と入力し、Enterキーを押してください。直前に `py app.py` で起動した場合は、今回も `py app.py` と入力してEnterキーを押してください。macOS / Linuxでは、同じターミナルに `python3 app.py` と入力し、Enterキーを押してください。

ウィンドウ上部に「わたしのアプリ」と表示され、横幅500ピクセル・高さ200ピクセルになれば変更できています。

## Tk1-13. ウィンドウが出ないとき

まず、ターミナルにエラーメッセージが出ていないか確認してください。

よくある確認ポイントは次のとおりです。

- `app.py` を保存しているか
- ターミナルで正しいファイル名を入力しているか
- Pythonが正しくインストールされているか
- `import tkinter` のつづりが合っているか

Linuxでは、環境によってtkinterが別パッケージになっていて、追加インストールが必要な場合があります。

その場合は、利用しているLinuxディストリビューションのPython tkinterパッケージを確認してください。

Windowsや一般的なPython公式インストーラーでは、通常tkinterを利用できます。
