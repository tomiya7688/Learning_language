# Tk1. tkinter入門 - 最初のウィンドウ

電卓で数字を入れる欄や「計算する」ボタンを押して操作したいとします。文字を入力するターミナルだけでは、その欄やボタンを置く画面がありません。

> **「数字を入れて、ボタンを押して使う電卓にしたい！」**

そのために、まずアプリの画面を用意してください。パソコン上に開く画面の枠を **ウィンドウ** と呼びます。この章では、電卓の部品を置く前の、空のウィンドウを表示します。

---

## Tk1-1. 今回作るもの

今回のプログラムは、次のような空のウィンドウを表示します。

ウィンドウのタイトルは、次の文字列を指定してください。

今回は、

```text
はじめてのGUI
```

この値に変更してください。

ウィンドウのサイズは、

```text
横400 × 縦300
```

で作ってください。

まだボタンや入力欄はありません。

最初は、**画面が出ることそのもの**を確認してください。

---

## Tk1-2. tkinterとは？

**tkinter** は、Pythonでウィンドウやボタンなどを作るための標準ライブラリです。

標準ライブラリとは、

> Pythonをインストールしたときから使える機能

のことです。

そのため、通常は追加で何かをインストールしなくても使えます。

この章では、まずtkinterを使って、

- ウィンドウを作る
- タイトルを付ける
- サイズを決める
- 画面を表示したままにする

ところまで進みます。

---

## Tk1-3. なぜGUIを使うの？

これまでのプログラムでは、ターミナルに文字を表示してきました。

もちろん、それでもプログラムは動きます。

でも使う人からすると、

> **「文字ばっかでつまらん！！！」**

となります。

ずっと、

```text
1: 開く
2: 保存
3: 設定
4: 終了
```

のような画面だけでは、

- 何ができるのか一目で分かりにくい
- 見た目がずっと文字だけ
- 「ちょっと触ってみよう」となりにくい

という問題があります。

GUIなら、

- 「開く」ボタン
- 「保存」ボタン
- 「設定」ボタン

のように、**できることを画面に見せられます。**

> **文字だけだったプログラムを、見て触れる画面にする。**

まずはそこからです。

この章の題材は、アプリの画面（ウィンドウ）を表示するコードです。

---

## Tk1-4. サンプルコード

[first_window.py](./first_window.py) を開いてください。

`first` は「最初の」、`window` は「ウィンドウ」という意味です。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter

# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()

# window のタイトルを「はじめてのGUI」にする
window.title("はじめてのGUI")

# window の大きさを横400、縦300にする
window.geometry("400x300")

# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

## Tk1-6. `import tkinter` とは

最初の行を見てください。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
```

tkinterには、GUIに関係するいろいろな機能がまとまっています。

たとえば、

```text
tkinter
├─ ウィンドウを作る機能
├─ ボタンを作る機能
├─ 入力欄を作る機能
└─ GUIを動かすための機能
```

のようなイメージです。

`import tkinter` は、

> **tkinterという機能のまとまりを、このプログラムで使えるようにする**

という意味です。

`import tkinter` は、Tkinterの機能をこのファイルから使えるようにします。

## Tk1-7. `tkinter.Tk()` でウィンドウを作る

次のコードは、ウィンドウを1つ作る処理です。

```python
# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()
```

この行では、`tkinter.Tk()` で作ったウィンドウを、変数 `window` に保存しています。

変数は、値や作ったものに名前を付けて、あとから使うためのものです。ここで `window` に保存しておくと、同じウィンドウへタイトルやサイズを設定できます。

> **これ、8章でやった `Student()` と同じやつです。**

8章では、

```python
# Studentクラスから作ったオブジェクトを student に入れる
student = Student()
```

と書いて、`Student` クラスから実際に使うものを1つ作りました。

tkinterでも同じです。

`tkinter.Tk` は、**tkinterの中にあるクラス**です。

```python
# tkinterのTkクラスからウィンドウを1つ作る
tkinter.Tk()
```

と書くと、その `Tk` クラスからウィンドウを1つ作れます。
クラス名の後ろに `()` を付けて、そのクラスから使うオブジェクトを作っています。

つまり、

```python
# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()
```

は、

> **tkinterの中にある `Tk` クラスからウィンドウを1つ作って、`window` に入れる**

という意味です。

並べると、

```text
student = Student()
          ↓
Studentクラスから student を作る

window = tkinter.Tk()
         ↓
Tkクラスから window を作る
```

です。

そして、作った `window` にはウィンドウ用のメソッドがあります。メソッドは、オブジェクトに結び付いた処理です。

関数は、名前の後ろに `()` を付けて呼び出す処理です。メソッドは、オブジェクトに結び付いた関数で、`オブジェクト.メソッド()` の形で呼び出すものです。

たとえば、

```python
# window のタイトルを指定する（... は値の省略を表す）
window.title(...)
# window の大きさを指定する（... は値の省略を表す）
window.geometry(...)
# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

です。

8章で、

```python
# student の show_result を呼び出す
student.show_result()
```

のように書いたのと同じく、`window` の後ろに `.` を付けて、そのウィンドウのメソッドを呼び出すコードです。

`()` の中には、処理で使う値を指定してください。たとえば `window.title("はじめてのGUI")` は、タイトルの文字列を `title()` メソッドへ渡すコードです。

> **`.` を使って、そのオブジェクトが持っているものを使う**

という考え方です。

## Tk1-8. タイトルを付ける

次のコードは、ウィンドウのタイトルを指定する処理です。

最初の画面なので、`"はじめてのGUI"` にしてください。

```python
# window のタイトルを「はじめてのGUI」にする
window.title("はじめてのGUI")
```

これで、ウィンドウ上部のタイトルを設定できます。

`title()` は `window` のメソッドです。括弧の中の文字列を、タイトルとして渡しています。

`title` は「タイトル」という意味です。

文字を変えれば、好きなタイトルにできます。

```python
# window のタイトルを「かんたんツール」にする
window.title("かんたんツール")
```

のように変更しても構いません。

## Tk1-9. サイズを決める

次のコードは、ウィンドウの大きさを指定する処理です。

まずは横400、縦300で作ってください。

```python
# window の大きさを横400、縦300にする
window.geometry("400x300")
```

これでウィンドウのサイズを指定できます。

`geometry()` も `window` のメソッドです。`"400x300"` を渡して、横と縦のサイズを指定しています。

```text
400x300
```

は、

```text
横400 × 縦300
```

という意味です。

ここで使っている `x` は掛け算記号ではなく、サイズを区切るために使っています。

たとえば、

```python
# window の大きさを横600、縦400にする
window.geometry("600x400")
```

なら、少し大きなウィンドウになります。

---

## Tk1-10. `mainloop()` は何をしている？

最後の行です。

```python
# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

これは、GUIでとても大切な処理です。

`mainloop()` は `window` のメソッドです。`window.mainloop()` と呼び出すと、ウィンドウを表示して操作を待ち続けます。

ウィンドウを表示したあと、Pythonは、

- マウスが動いた
- ボタンが押された
- ウィンドウが閉じられた

といった操作を待ち続ける必要があります。

`mainloop()` は、そのための処理です。

もしこれがなければ、プログラムがすぐ終わってしまい、ウィンドウを操作できません。

## Tk1-11. 自分で変えてみる

タイトルとサイズを変えてみてください。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter

# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()

# window のタイトルを「わたしのアプリ」にする
window.title("わたしのアプリ")
# window の大きさを横500、縦200にする
window.geometry("500x200")

# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

実行すると、タイトルとサイズが変わります。

この時点ではまだ中身が空でも問題ありません。

**自分のコードでウィンドウが出た**ことが、この章の一番大きな成果です。

## Tk1-12. ウィンドウが出ないとき

まず、ターミナルにエラーメッセージが出ていないか確認してください。

よくある確認ポイントは次のとおりです。

- `first_window.py` を保存しているか
- ターミナルで正しいファイル名を入力しているか
- Pythonが正しくインストールされているか
- `import tkinter` のつづりが合っているか

Linuxでは、環境によってtkinterが別パッケージになっていて、追加インストールが必要な場合があります。

その場合は、利用しているLinuxディストリビューションのPython tkinterパッケージを確認してください。

Windowsや一般的なPython公式インストーラーでは、通常tkinterを利用できます。
