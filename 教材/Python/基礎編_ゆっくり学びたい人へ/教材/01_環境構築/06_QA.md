# 1-6. 環境構築 Q&A

環境構築で止まったときに確認するページです。

## Q. `python --version` で見つからない

Windowsでは次も試してください。

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```powershell
py --version
```

macOS / Linux:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```bash
python3 --version
```

インストール前からVS Codeを開いていた場合は、次の手順で開き直してから確認します。

1. VS Code上部の **ファイル（File）→ 終了（Exit）** を選びます。macOSでは **Code → Quit Visual Studio Code** を選びます。
2. Windowsではスタートボタンをクリックし、検索欄に `Visual Studio Code` と入力して、検索結果のアプリを開きます。macOSではFinderの **アプリケーション（Applications）** フォルダから、LinuxではOSのアプリ一覧から **Visual Studio Code** を開きます。
3. 上部の **ターミナル（Terminal）→ 新しいターミナル（New Terminal）** を選びます。
4. Windowsでは `py --version`、macOS / Linuxでは `python3 --version` を、画面下に開いたターミナルへ入力します。
5. Enterキーを押し、Pythonのバージョンが表示されるか確認します。

それでも見つからない場合は [PATH・パス・ディレクトリ](./04_PATHとパス.md) を確認してください。

---

## Q. `python` と `python3` は何が違う？

どちらも Python を起動するコマンドとして使われます。

この教材では基本的に、

- Windows: `python`
- macOS / Linux: `python3`

を使います。

---

## Q. `hello_world.py` が見つからない

現在のフォルダに本当にファイルがあるか確認してください。

Windows:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```powershell
dir
```

macOS / Linux:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```bash
ls
```

一覧に無ければ、保存場所と現在地が違います。

## Q. `hello_world.py.txt` になっている

Windows では拡張子が非表示になっている場合があります。

ファイル名が実際に

```text
hello_world.py
```

で終わっているか確認してください。

---

## Q. `can't open file` と表示される

Python 自体は起動できていますが、指定したファイルを見つけられていません。

現在地とファイルの場所を確認してください。

---

## Q. `SyntaxError` と表示された

Python は動いていますが、コードに文法上の問題があります。

よくある例:

- `"` の閉じ忘れ
- `)` の閉じ忘れ
- 全角記号を使った

エラーに表示された行番号も確認してください。

---

## Q. `>>>` が表示された

`python` だけを実行すると Python の対話モードに入ります。

終了:

VS Code の **表示（View）→ ターミナル（Terminal）** を選び、`>>>` が表示されているターミナルを開きます。そこへ次の1行を入力し、Enter キーを押します。

```python
exit()
```

ファイルを実行したい場合は、

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 同じターミナルに `cd "ファイルを保存したフォルダのパス"` と入力し、Enter キーを押します。引用符の中は、自分の保存先に置き換えてください。
3. 次のコマンドを、そのターミナルに入力します。
4. Enter キーを押します。

```powershell
python hello_world.py
```

のようにファイル名まで入力します。

## Q. VS Code で実行すると別の Python が使われる

複数の Python がインストールされている可能性があります。

1. VS Codeを開き、Windows / Linuxでは **Ctrl + Shift + P**、macOSでは **Command + Shift + P** を押します。
2. 画面上部に入力欄と操作の一覧が表示されます。この画面が **コマンドパレット** です。
3. 入力欄に `Python: Select Interpreter` と入力し、一覧に表示された同じ名前の項目を選びます。
4. 表示されたPythonの一覧から、自分がインストールしたPython 3を選びます。

項目が出ない場合は、VS Code左側の四角が並んだ **拡張機能（Extensions）** アイコンをクリックし、検索欄に `Python` と入力します。MicrosoftのPython拡張機能を選び、**インストール（Install）** を押してから、上の操作を試してください。

選ぶPythonはVS Codeの実行機能に使われます。[VS Codeの公式説明](https://code.visualstudio.com/docs/python/environments#select-an-environment)でも確認できます。

---

## Q. VS Code は絶対必要？

Python 自体は VS Code がなくても使えます。

この教材では、Python のコードを書くためのアプリに VS Code を使い、画面や操作の説明を揃えています。
