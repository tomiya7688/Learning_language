## VS Code が使う Python を確認する

複数の Python が入っている場合、VS Code が別の Python を選んでいることがあります。

1. VS Code を起動してください
2. Windows / Linux では **Ctrl + Shift + P**、macOS では **Command + Shift + P** を押してください
3. 画面上部に入力欄と操作の一覧が表示される。この画面を **コマンドパレット** と呼ぶ
4. 入力欄に `Python: Select Interpreter` と入力し、一覧に表示された同じ名前の項目を選んでください
5. 表示された Python の一覧から、自分がインストールした Python 3 を選んでください

`Select Interpreter` は、コードを実行する Python を選ぶという意味です。

項目が表示されない場合は、[1-1. Visual Studio Code をインストールする](./01_Visual_Studio_Codeの導入.md) の「Python 拡張機能を入れる」を確認してください。

ここで選ぶのは VS Code の実行機能が使う Python です。ターミナルへ入力する `python` や `python3` が見つからない場合は、[環境構築 Q&A](./06_QA.md) を確認してください。

環境構築ができたら次へ進みます。
