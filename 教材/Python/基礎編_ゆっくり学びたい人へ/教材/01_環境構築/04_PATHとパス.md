# 1-4. PATH・パス・ディレクトリ

環境構築で特につまずきやすいのが **PATH** と **パス** です。

## ターミナルとは

この章では、`python`、`where python`、`cd` などの **コマンド** の入力方法を説明します。

これらを入力する場所が **ターミナル** です。

ターミナルは、文字を入力してコンピュータへ操作を指示するための画面です。

VS Code を使っている場合は、画面上部のメニューから、

```text
ターミナル → 新しいターミナル
```

を選ぶと、画面下側にターミナルを開けます。

Windows では、次のような表示になることがあります。

```text
PS C:\Users\sample>
```

この `PS C:\Users\sample>` の部分は自分で入力するものではありません。

Python の場所を調べる例:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
where python
```

フォルダへ移動する例:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドのフォルダのパスや名前を、自分の保存先に置き換え、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
cd "C:\Users\sample\Documents"
```

これらのコマンドを入力すると、Python の場所を調べたり、作業するフォルダを変えたりできます。

### Python のコードを書く場所とは別

たとえば、

```python
print("Hello")
```

は **Python のコード** なので、通常は `.py` ファイルへ書いてください。

`python hello_world.py` や `cd "フォルダのパス"` は **コマンド** なので、ターミナルへ入力してください。入力する操作は、それぞれの実行手順で説明します。

最初はこの2つを混同しやすいので、

> Python のコード → `.py` ファイル  
> コマンド → ターミナル

と分けて考えてください。

ターミナルについてさらに詳しく知りたい場合は、共通教材の
[ターミナル・シェル・コマンド](../../../../コンピュータ基礎/04_ターミナル・シェル・コマンド/ターミナル・シェル・コマンド.md)
も参照できます。

## PATH とは

PATH は、`python` や `code` のようなコマンドを入力したときに、
OS が実行ファイルを探す場所の一覧です。

たとえば Python が次にあるとします。

```text
C:\Users\ユーザー名\AppData\Local\Programs\Python\Python314\python.exe
```

PATH に追加するのは通常 `python.exe` 自体ではなく、その入っているフォルダです。

```text
C:\Users\ユーザー名\AppData\Local\Programs\Python\Python314\
```

さらに `pip` などを使うため、次のような `Scripts` フォルダも関係します。

```text
C:\Users\ユーザー名\AppData\Local\Programs\Python\Python314\Scripts\
```

要するに、

> PATH には、実行したいプログラムが入っているフォルダまでを書く

と覚えてください。

## Python の場所を確認する

Windows:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```powershell
where python
```

macOS / Linux:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```bash
which python3
```

## PATH を変えたのに反映されない

PATH を変更したあと、すでに開いていたターミナルには反映されないことがあります。

VS Codeを使っている場合は、アプリごと開き直してください。

1. VS Code上部の **ファイル（File）→ 終了（Exit）** を選んでください。macOSでは **Code → Quit Visual Studio Code** を選んでください。
2. Windowsではスタートボタンをクリックし、検索欄に `Visual Studio Code` と入力して、検索結果のアプリを開いてください。macOSではFinderの **アプリケーション（Applications）** フォルダから、LinuxではOSのアプリ一覧から **Visual Studio Code** を開いてください。
3. 上部の **ターミナル（Terminal）→ 新しいターミナル（New Terminal）** を選んでください。
4. Windowsでは `python --version`、macOS / Linuxでは `python3 --version` を、画面下に開いたターミナルへ入力してください。
5. Enterキーを押し、Pythonのバージョンが表示されるか確認してください。

## パスとは

**パス** はファイルやフォルダの場所を表します。

Windows:

```text
C:\Users\sample\Documents\hello_world.py
```

macOS / Linux:

```text
/home/sample/hello_world.py
```

PATH 環境変数と普通の「パス」は別のものです。

## カレントディレクトリ

ターミナルが現在基準にしているフォルダを **カレントディレクトリ** と呼びます。

現在地を確認:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
pwd
```

中身を見る:

Windows:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```powershell
dir
```

macOS / Linux:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```bash
ls
```

移動:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドのフォルダのパスや名前を、自分の保存先に置き換え、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
cd フォルダ名
```

1つ上へ戻る:

1. VS Code のターミナルを開いてください。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選んでください。前の操作から続ける場合は、同じターミナルを使ってください。
2. 次のコマンドを、そのターミナルに入力してください。
3. Enter キーを押してください。

```text
cd ..
```

## 絶対パスと相対パス

絶対パスは、場所を先頭から全部書いたものです。

```text
C:\Users\sample\Documents\Python\hello_world.py
```

相対パスは、現在地を基準にした書き方です。

現在のフォルダに `hello_world.py` があるなら、

```text
hello_world.py
```

だけで指定できます。

`python hello_world.py` でファイルが見つからない場合は、
Pythonではなく **今いるフォルダが違う** 可能性も確認してください。

---

## ユーザー環境変数とシステム環境変数

Windows の PATH には主に、

- ユーザー環境変数
- システム環境変数

があります。

個人で Python を学ぶだけなら、通常は **ユーザー環境変数の PATH** で十分です。

システム環境変数は PC 全体へ影響するため、
意味が分からない状態で無理に変更する必要はありません。
