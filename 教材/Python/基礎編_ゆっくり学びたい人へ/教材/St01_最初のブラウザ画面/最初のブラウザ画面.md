# St1. Streamlitで最初のWeb画面を作る

この章では、**Pythonだけで、Webページを見るときに使うブラウザ（Google ChromeやSafariなど）へ入力欄と文字を表示します。**

今回作るのは、名前を入力すると、

```text
こんにちは たろう
```

とブラウザに表示する小さなアプリです。

この章の本質はこれです。

> **「ブラウザ画面作るのにHTMLもCSSもJavaScriptも今から全部やるん？？？今日はPythonやりに来たんやけど！」**

まずはPythonだけで画面を出してみます。

---

## St1-1. Streamlitって何？

Streamlitは、Pythonに後から追加して使う機能の集まりです。これを使うと、Pythonコードからブラウザ画面を作れます。

このような追加の機能の集まりを「外部ライブラリ」と呼びます。

たとえば、

- 文字を表示する
- 入力欄を置く
- ボタンを置く
- 表を表示する
- グラフを表示する

といったことができます。

HTMLやJavaScriptを書かずに、Python中心で画面を作れます。

---

## St1-2. 今回作るもの

[streamlit_greeting.py](./streamlit_greeting.py) を開いてください。

`streamlit` はライブラリ名、`greeting` は「挨拶」という意味です。

まずタイトルを1つ出して、その下に名前の入力欄を置きましょう。

入力された名前はあとで挨拶に使うので、`name` に保存します。

最後に、`name` に文字が入っているときだけ挨拶を表示します。

```python
import streamlit as st

st.title("名前を入力してみよう")

name = st.text_input("名前")

if name:
    st.write("こんにちは", name)
```

ブラウザに、

- タイトル
- 名前の入力欄

が表示されます。

名前を入力すると、その名前を使って挨拶します。

---

## St1-3. まずStreamlitを入れる

Pythonには、追加でインストールしなくても最初から使える機能の集まりもあります。これを「標準ライブラリ」と呼びます。

StreamlitはPythonに後から追加して使う機能なので、最初にインストールします。

ターミナルを開いてください。

`pip` は、Streamlitのような追加の機能の集まりをPythonにインストールするときに使います。

Windows:

```text
python -m pip install streamlit
```

macOS / Linux:

```text
python3 -m pip install streamlit
```

> **「コードに書くん？ターミナルに書くん？」**
>
> これは**ターミナル**へ入力します。

---

## St1-4. `import streamlit as st`

最初の行です。

```python
import streamlit as st
```

これは、

> Streamlitという機能のまとまりを使えるようにする

という意味です。

さらに、

```text
as st
```

によって、このファイルの中では `streamlit` を短く `st` と書いています。

そのため、

```python
st.title(...)
st.text_input(...)
st.write(...)
```

のように使えます。

---

## St1-5. `st.title()`

```python
st.title("名前を入力してみよう")
```

は、ブラウザ画面へ大きめのタイトルを表示します。

```text
st
↓
Streamlitのまとまり

title
↓
タイトルを表示する機能
```

です。

---

## St1-6. 入力欄を置く

次に、名前を入力する欄を置きます。

入力された文字はあとで挨拶に使うので、保存先は `name` にしましょう。

```python
name = st.text_input("名前")
```

`st.text_input()` が返した入力内容が `name` に入ります。

つまり、

```text
ブラウザで入力する
      ↓
st.text_input()
      ↓
name
```

です。

基本文法の変数と同じ考え方です。

---

## St1-7. 入力されたら表示する

```python
if name:
    st.write("こんにちは", name)
```

`name` に文字が入っているときだけ、挨拶を表示します。

```python
st.write(...)
```

は、ブラウザ画面へ文字や値を表示するために使えます。

---

## St1-8. 実行方法が普通のPythonと少し違う

普通のPythonファイルなら、

```text
python sample.py
```

のように実行してきました。

Streamlitでは、ターミナルで、

Windows:

```text
python -m streamlit run streamlit_greeting.py
```

macOS / Linux:

```text
python3 -m streamlit run streamlit_greeting.py
```

と実行します。

Streamlit公式では、

```text
streamlit run streamlit_greeting.py
```

でも実行できます。

この教材では、どのPythonでStreamlitを動かしているか分かりやすいように `python -m streamlit` を基本にします。

---

## St1-9. ブラウザが開く

実行すると、Streamlitがローカルでサーバーを起動し、ブラウザで画面を開きます。

自動で開かない場合は、ターミナルに表示されたローカルURLをブラウザで開いてください。

通常は、

```text
http://localhost:8501
```

のようなアドレスです。

> **「Webアプリなのにネットへ公開されたん？」**

今の段階では違います。

この画面は自分のPC上で動いています。

---

## St1-10. 画面を止める

Streamlitを止めたいときは、実行中のターミナルで、

```text
Ctrl + C
```

を押します。

ブラウザのタブを閉じるだけでは、ターミナル側のStreamlitが動き続けていることがあります。

---

## St1-11. コードを変えると画面も変わる

Streamlitを起動したままPythonファイルを編集して保存すると、変更を検出して画面を更新できます。

たとえば、

```python
st.title("自己紹介アプリ")
```

に変えて保存してみてください。

ブラウザ側でも表示が変わります。

---

## St1-12. 普通のPythonと何が違う？

今までのPythonは、

```text
コードを実行
↓
ターミナルへ表示
```

が中心でした。

Streamlitでは、

```text
コードを実行
↓
ブラウザ画面を作る
↓
入力欄などを操作する
```

という流れになります。

ただし、中身はPythonです。

変数や `if` など、ここまでの知識がそのまま使えます。

---

## St1-13. Streamlitは操作すると上からもう一度動く

Streamlitでは、入力欄などを操作すると、基本的にPythonスクリプトが上から再実行されます。

たとえば名前を入力すると、

```python
name = st.text_input("名前")
```

で現在の入力値を受け取り、

```python
if name:
```

がもう一度判断されます。

このサンプルでは、入力欄で変更を確定するとスクリプトが上から再実行されます。`st.text_input()` が現在の入力値を返し、`if name:` の判断結果に応じて表示内容が更新されます。

---

## St1-14. 自分で変えてみる

入力欄をもう1つ増やしてみましょう。

```python
import streamlit as st

st.title("自己紹介アプリ")

name = st.text_input("名前")

# 好きな食べ物もあとで使うので food に保存します。
food = st.text_input("好きな食べ物")

if name and food:
    st.write(name, "さんは", food, "が好きです")
```

これだけでも、ブラウザ上で操作できる小さなツールになります。

---

## St1-15. うまく起動しないとき

### `No module named streamlit`

Streamlitが、そのPython環境へ入っていない可能性があります。

Windows:

```text
python -m pip install streamlit
```

macOS / Linux:

```text
python3 -m pip install streamlit
```

を確認してください。

### ファイルが見つからない

ターミナルが `streamlit_greeting.py` のあるフォルダにいるか確認してください。

### 何か変なStreamlitが起動した

複数のPythonが入っている場合があります。

この教材では、

```text
python -m streamlit run streamlit_greeting.py
```

の形を使うと、使うPythonを揃えやすくなります。

## St1-17. ここまでで覚えること

1. StreamlitはPythonからブラウザ画面を作れる外部ライブラリ
2. `pip` でStreamlitをインストールする
3. `import streamlit as st` でStreamlitを使える
4. `st.title()` でタイトルを表示できる
5. `st.text_input()` で入力欄を置ける
6. 入力値を普通のPython変数として受け取れる
7. `st.write()` でブラウザへ表示できる
8. `python -m streamlit run ファイル名.py` で起動できる
9. 終了するときはターミナルで `Ctrl + C`
10. Streamlitでは操作時にスクリプトが上から再実行される
