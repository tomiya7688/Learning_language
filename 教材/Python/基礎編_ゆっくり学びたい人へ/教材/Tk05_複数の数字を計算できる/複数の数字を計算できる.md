# Tk5. 複数の数字を計算できる

3つ以上の品物の合計を調べたいとき、2つの数字しか入力できない電卓では、途中の答えを次の計算へ入力し直す手間がかかります。

> **「毎回2個で終わるんかい！！！」**

この章の電卓は、1つの入力欄へ数字を順に入力し、足し算と引き算を続けられる電卓です。たとえば `1 + 2 - 3 + 4` の数字と計算記号を順に入力すると、画面に計算式と答えが表示されます。

ボタンの記号は、算数や電卓で使う足し算の `+`、引き算の `-`、答えを出す `=` に合わせます。利用者は、入力欄に計算式全体を書くのではなく、数字を1つ入力するたびに計算記号のボタンを押してください。

## Tk5-1. 入力欄を増やさずに数字を順に保存する

数字ごとに入力欄を増やすと、3つの品物には3つ、4つの品物には4つの欄が必要になります。Tk5では入力欄を1つにして、利用者が入力した数字を計算記号と一緒に保存します。数字を保存した後に入力欄を空にすれば、利用者は同じ欄へ次の数字を入力できます。

`+` と `-` のボタンは、入力中の数字と押した計算記号を保存するボタンです。`=` ボタンは、最後の数字を保存し、覚えている式を計算するボタンです。

Tk4の `+` と `-` は計算方法を選ぶだけのボタンでした。Tk5の `+` と `-` は、数字を1つ確定してから次の計算記号を追加します。計算記号を押す前に、数字を入力してください。空の入力欄で計算記号を押しても、直前の記号を変更する機能はありません。

## Tk5-2. 計算途中の式と操作を同じ電卓へ持たせる

利用者が数字と計算記号を入力してから `=` を押すまで、電卓は入力済みの式を覚えておく必要があります。数字と計算記号を入力した順に保存する一覧を、`self.calculation_parts` として電卓へ持たせます。`calculation_parts` は「計算式の部品」という意味です。複数の値を順に保存するPythonの一覧を「リスト」と呼びます。

入力欄、計算途中の式、結果表示、式を計算する操作は、すべて同じ電卓に関する情報と操作です。式だけを電卓の外に置くと、どの電卓が入力した式なのかが分かりません。Tk4と同じ `CalculatorApp` というクラスに、式と画面の部品、式を操作する処理をまとめます。クラスは、同じ対象に関する情報と操作をまとめて定義する仕組みです。

`CalculatorApp()` で実際に使う電卓を作ると、計算途中の式と画面の部品がその電卓に用意されます。クラスから作った個々の電卓を「インスタンス」と呼びます。クラス内の `self` は、操作の対象になっている電卓のインスタンスを指します。`self.calculation_parts` は、対象の電卓が入力を覚えておくためのリストです。

`+` と `-` は、どちらも数字と計算記号を保存し、式の表示を更新し、入力欄を空にする操作です。同じ処理を2か所に書くと、入力欄の扱いを変えるときに両方を直す必要があります。共通の処理を `add_operator` にまとめ、追加する計算記号を `operator` で指定します。`+` や `-` の計算記号を「演算子」と呼びます。`operator` は「演算子」という意味です。

各ボタンから実行する処理は、Tk4と同じ名前の `select_addition` と `select_subtraction` に分けます。`select_addition` は足し算の記号 `"+"`、`select_subtraction` は引き算の記号 `"-"` を指定して `add_operator` を実行します。クラス内で定義した関数を「メソッド」と呼びます。

`=` を押すまで答えを出さないため、式を計算する処理は `calculate` に分けます。`add_operator` が同じ電卓のリストへ入力を保存し、後で実行する `calculate` がそのリストを読み取ります。

画面を作る処理と利用者の操作を待つ処理も、実行するタイミングが違います。`__init__` は電卓を作ったときに空のリストと画面を用意し、`run` は起動時にウィンドウを表示して操作を待ち続けます。

機能を変更する場所と起動する場所を分けるため、電卓の定義は `calculator.py`、電卓を作って操作待ちを始める処理は `app.py` の `main` に置きます。Tk4から起動方法を変える必要はありません。

### calculator.py：入力・保存・計算の処理

元ファイル：[`calculator.py` 全体](./calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []

        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「複数の数字を計算できる」にする
        self.window.title("複数の数字を計算できる")
        # self.window の大きさを横420、縦320にする
        self.window.geometry("420x320")

        # self.number_label（数字の案内）に self.window 内で「数字」と表示するラベルを入れる
        self.number_label = tkinter.Label(self.window, text="数字")
        # self.number_label を self.window 内に配置する
        self.number_label.pack()

        # self.number_entry（数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window)
        # self.number_entry を self.window 内に配置する
        self.number_entry.pack()

        # self.expression_label（計算式の表示）に self.window 内で「計算式:」と表示するラベルを入れる
        self.expression_label = tkinter.Label(self.window, text="計算式:")
        # self.expression_label を self.window 内に配置する
        self.expression_label.pack()

        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()

        # self.equals_button（計算を行うボタン）に self.window 内で「=」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.equals_button = tkinter.Button(
            self.window,
            text="=",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.equals_button を self.window 内に配置する
        self.equals_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した「+」または「-」が入る
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「次の数字を入力してください」に変える
            self.result_label.config(text="次の数字を入力してください")
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 計算式に最後の数字を追加し、順に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「最後の数字を入力してください」に変える
            self.result_label.config(text="最後の数字を入力してください")
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))

        # answer（答え）に self.calculation_parts の先頭の値を入れる
        answer = self.calculation_parts[0]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものと「 = 」と answer の値を付けた文字列に変える
        self.expression_label.config(
            text=(
                "計算式: "
                + " ".join(str(part) for part in self.calculation_parts)
                + f" = {answer}"
            )
        )
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer を文字列にした値を挿入する
        self.number_entry.insert(0, str(answer))

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

### app.py：電卓を起動する

`app.py` のコードはTk4と同じです。`from calculator import CalculatorApp` は、同じフォルダの `calculator.py` から電卓の定義を読み込みます。`calculator` と書く部分には、ファイル名の `.py` を付けません。

元ファイル：[`app.py` 全体](./app.py)。

```python
# 同じフォルダの calculator.py から電卓の CalculatorApp を読み込む
from calculator import CalculatorApp


# 電卓の起動処理を main にまとめる
def main():
    # app（アプリ）に CalculatorApp() で作った電卓を入れる
    app = CalculatorApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

`app.py` を直接実行すると、末尾の `if __name__ == "__main__":` の条件に当てはまり、Pythonが `main()` を実行します。`main` 内の `CalculatorApp()` が電卓を作り、`app.run()` がウィンドウを表示して操作待ちを始めます。別のファイルから `app.py` を読み込んだ場合は、この条件に当てはまらず `main()` は実行されません。

## Tk5-6. リストへ数字と計算記号を追加する

`CalculatorApp.__init__` は `self.calculation_parts` を空のリスト `[]` で用意します。まだ数字も計算記号も入力されていない状態です。

元ファイル：[`calculator.py` の9〜10行](./calculator.py#L9-L10)。

```python
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
```

`CalculatorApp.add_operator` は、`self.number_entry.get()` で入力欄の文字列を読み取ります。Tkinterは、Pythonでウィンドウや入力欄、ボタンを作るための道具です。`Entry` はTkinterの1行の入力欄で、`get()` は入力内容を読み取る操作です。

元ファイル：[`calculator.py` の69〜85行](./calculator.py#L69-L85)。

```python
    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した「+」または「-」が入る
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「次の数字を入力してください」に変える
            self.result_label.config(text="次の数字を入力してください")
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)
```

入力欄が空なら、`add_operator` は結果の欄へ「次の数字を入力してください」と表示し、`return` で処理を終えます。空欄の場合は、リストへ数字も計算記号も追加しません。

入力欄に数字があれば、`float` が入力文字列を小数を扱える数値へ変換します。リストの `append(...)` は、括弧の中で指定した値をリストの末尾へ追加する操作です。`add_operator` は数値を追加し、その後で `operator` の計算記号を追加します。

たとえば入力欄の `1` に対して `+` を押すと、`self.calculation_parts` の内容は `[1.0, "+"]` になります。続けて入力欄の `2` に対して `-` を押すと、同じリストの内容は `[1.0, "+", 2.0, "-"]` になります。数字と計算記号の順序が、利用者の入力順に揃います。

## Tk5-7. + と - のボタンから共通の追加処理を使う

`+` ボタンには `self.select_addition`、`-` ボタンには `self.select_subtraction` が、押したときの処理として登録されています。Tkinterはボタンが押されると、登録されたメソッドを実行します。

元ファイル：[`calculator.py` の34〜52行](./calculator.py#L34-L52)。

```python
        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()
```

`command` にはメソッドの名前を指定します。たとえば足し算のボタンには `command=self.select_addition` と指定してください。`self.select_addition()` と指定すると、Pythonがボタンを作る途中で処理を実行してしまい、押したときの処理を登録できません。

`select_addition` は `"+"` を指定して同じ電卓の `add_operator` を実行し、`select_subtraction` は `"-"` を指定して同じ処理を実行します。

元ファイル：[`calculator.py` の98〜106行](./calculator.py#L98-L106)。

```python
    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")
```

両方のボタンが使う保存・表示・入力欄の削除は、`CalculatorApp.add_operator` に1か所だけ書かれています。掛け算のボタンを加える章でも、ボタンから追加する計算記号を指定して、同じ追加処理を使えます。

## Tk5-8. 保存した式を表示し、次の数字を入力できるようにする

`CalculatorApp.add_operator` は、保存済みの式を `self.expression_label` に表示し、`self.number_entry` を空にします。前の数字を保存してから入力欄を空にするため、数字を消しても計算途中の式は失われません。

元ファイル：[`calculator.py` の87〜96行](./calculator.py#L87-L96)。

```python
        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
```

`str(part) for part in self.calculation_parts` は、リストの各値を `part` として順に取り出し、`str` で表示用の文字列に変える記述です。`" ".join(...)` は、用意した文字列を空白でつなぎます。たとえば `[1.0, "+", 2.0, "-"]` から、式の表示用に `1.0 + 2.0 -` という文字列を作ります。

入力欄の `delete(0, tkinter.END)` は、先頭の位置0から末尾までの文字列を削除する操作です。`add_operator` は入力欄を空にし、結果の欄を「答え:」へ戻します。利用者は同じ欄へ次の数字を入力できます。

## Tk5-9. = を押したときに最後の数字を追加する

`=` ボタンを押すと、Tkinterはボタンに登録された `self.calculate` を実行します。`CalculatorApp.calculate` は、入力欄に残っている最後の数字を `self.calculation_parts` へ追加します。

元ファイル：[`calculator.py` の108〜124行](./calculator.py#L108-L124)。

```python
    # 計算式に最後の数字を追加し、順に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「最後の数字を入力してください」に変える
            self.result_label.config(text="最後の数字を入力してください")
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))

        # answer（答え）に self.calculation_parts の先頭の値を入れる
        answer = self.calculation_parts[0]
```

入力欄が空なら、`calculate` は結果の欄へ「最後の数字を入力してください」と表示し、`return` で計算を止めます。保存済みの数字と計算記号はリストに残るため、利用者が最後の数字を入力して `=` を押すと、同じ式を計算できます。

`1 + 2 - 3 + 4` の入力では、`=` を押す前のリストは `[1.0, "+", 2.0, "-", 3.0, "+"]` です。`calculate` が最後の `4.0` を追加すると、リストは `[1.0, "+", 2.0, "-", 3.0, "+", 4.0]` になります。

`self.calculation_parts[0]` は、リストの先頭の値を取り出す記述です。Pythonのリストの位置は0から数えます。`calculate` は先頭の数値を途中の答え `answer` へ入れ、残りの数字を順に計算します。

## Tk5-10. 計算記号と次の数字を2つずつ取り出す

`CalculatorApp.calculate` は、リスト内の計算記号とその次の数字を組にして取り出します。

元ファイル：[`calculator.py` の126〜131行](./calculator.py#L126-L131)。

```python
        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]
```

`len(self.calculation_parts)` は、リストにある値の個数を求めます。`range(1, len(self.calculation_parts), 2)` は、1から始め、リストの個数未満までの番号を2ずつ増やして用意します。`for` は、用意した番号を `index` へ順に入れ、続く字下げされた処理を繰り返します。

リストが `[1.0, "+", 2.0, "-", 3.0, "+", 4.0]` なら、`index` は1、3、5の順に変わります。各番号の位置には計算記号があり、`index + 1` の位置には次の数値があります。

| `index` の値 | `operator` へ入る計算記号 | `number` へ入る次の数値 |
| --- | --- | --- |
| 1 | リストの位置1にある `"+"` | リストの位置2にある `2.0` |
| 3 | リストの位置3にある `"-"` | リストの位置4にある `3.0` |
| 5 | リストの位置5にある `"+"` | リストの位置6にある `4.0` |

## Tk5-11. 足し算と引き算を入力順に計算する

`CalculatorApp.calculate` は、`operator` が `"+"` なら `answer` に次の数値を足し、`"+"` でなければ次の数値を引きます。この章のボタンが保存する計算記号は `"+"` と `"-"` の2つだけです。

元ファイル：[`calculator.py` の133〜140行](./calculator.py#L133-L140)。

```python
            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number
```

`1 + 2 - 3 + 4` の計算では、最初の `answer` は `1.0` です。`calculate` が `2.0` を足すと `3.0`、次の `3.0` を引くと `0.0`、最後の `4.0` を足すと `4.0` になります。

この電卓は、数字と計算記号を一覧から取り出し、足し算と引き算を左から順に行います。計算式全体を入力欄へ書いて解析する機能や、掛け算・割り算を計算する機能は入っていません。

## Tk5-12. 計算した式を表示し、次の計算に答えを使う

`CalculatorApp.calculate` は、保存した式と答えを `self.expression_label` に表示し、`self.result_label` にも答えを表示します。文字列の先頭の `f` は、文字列内の `{answer}` を変数の値に置き換える記述です。

元ファイル：[`calculator.py` の142〜159行](./calculator.py#L142-L159)。

```python
        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものと「 = 」と answer の値を付けた文字列に変える
        self.expression_label.config(
            text=(
                "計算式: "
                + " ".join(str(part) for part in self.calculation_parts)
                + f" = {answer}"
            )
        )
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer を文字列にした値を挿入する
        self.number_entry.insert(0, str(answer))
```

計算済みの数字を次の式へ混ぜないため、`calculate` は `self.calculation_parts.clear()` でリストの内容を空にします。続いて入力欄の文字を削除し、`insert(0, str(answer))` で答えの文字列を先頭へ入れます。

答えの `4.0` が入力欄にあるときに `+` を押すと、`add_operator` は新しいリストへ `4.0` と `"+"` を保存します。利用者は `4.0` を入力し直さず、次の数字を入力できます。

別の数字から新しい式を始める場合は、答えが残っている入力欄の文字をすべて削除してから、最初の数字を入力してください。たとえば答えの `10.0` が残る欄へ `2` を続けて入力すると `10.02` になるため、数字を追加する操作と、数字を置き換える操作を区別してください。

## Tk5-13. 空欄と数字以外の入力を区別する

入力欄が空の状態で `+` または `-` を押すと、電卓は結果の欄へ「次の数字を入力してください」と表示します。入力欄が空の状態で `=` を押すと、電卓は結果の欄へ「最後の数字を入力してください」と表示します。どちらの処理も、保存済みの式は変更しません。

数字以外の入力を確認する処理は、この章のコードにはありません。たとえば入力欄へ `abc` を入力して `+` や `=` を押すと、`float` が入力文字列を数値へ変換できず、`ValueError` というエラーが起きます。Tkinterは、ボタンから実行した処理のエラーを起動に使ったターミナルへ表示します。式と結果の欄には、直前の表示が残ります。

`abc` の変換でエラーが起きた場合、計算途中のリストは変更されていません。利用者は入力欄の `abc` をすべて削除して数字を入力し、同じボタンを押してください。電卓は、残っていた式への追加または計算を行います。

## Tk5-14. Tk4と同じ起動方法で機能を増やす

Tk4とTk5は、どちらも `calculator.py` の `CalculatorApp` に電卓の状態と操作をまとめ、`app.py` から起動します。Tk4が1つの選択記号を覚えるのに対し、Tk5は入力済みの数字と計算記号をリストに保存します。

Tk5の `add_operator` は、計算記号を指定して使う共通処理です。掛け算のボタンを追加するときも、`app.py` に計算処理を書き足す必要はありません。電卓のボタンと計算処理を定義する `calculator.py` を変更する構成です。

## Tk5-15. 今回の内容

- `CalculatorApp` は、電卓の入力欄、計算途中の式、式と答えの表示、入力と計算の処理をまとめます。
- `self.calculation_parts` は、対象の電卓が入力した数字と計算記号を順に保存するリストです。
- `select_addition` と `select_subtraction` は、保存する記号を指定して同じ電卓の `add_operator` を実行します。
- `calculate` は、最後の数字を追加し、保存した式を計算して表示した後、リストを空にして入力欄へ答えを入れます。
- 機能を定義するファイルは `calculator.py`、ターミナルで実行するファイルは `app.py` です。
