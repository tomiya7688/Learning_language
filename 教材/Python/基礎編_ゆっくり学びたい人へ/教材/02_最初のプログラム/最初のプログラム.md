# 2. 最初のプログラム

> **「いきなり長く書いて動かなかったら困る！まず1行だけ動かしたい！」**

Pythonを入れたあと、長いプログラムを書いてから動かそうとした時、動かなかったら、準備が足りないのか、書いたコードが違うのかを探すのが大変です。なのでまずは1行だけ動かして、準備したPythonで結果を表示できるか確かめましょう。

この章では、画面に次の文字列を表示するプログラムを書いて、保存・実行を試してください。

```text
Hello World!
```

---

## 2-1. なぜ Hello World! を表示するの？

hello worldと表示するのには、特別な理由はありません。「こんにちは」でも、自分の名前でもいいのです。

昔のあるプログラミング教材で、最初に動かす例として「Hello World」を表示するプログラムが使われ、その例が世界に広まりました。由来は [プリンストン大学の紹介](https://engineering.princeton.edu/news/2021/12/17/part-fourteen-hello-world) で詳しく説明されています。

つまり

> **とりまなんか表示しとけ！おはよう世界！**

ということです。
昔からそれがよく使われてきたため、慣例的に「Hello World」が使われているのです。

次は実際にこの1行を書いて、ファイルを保存して実行してください。

このコードの元ファイル：[`hello_world.py` の 2〜2行](./hello_world.py#L2-L2)。

```python
print("Hello World!")
```

この1行を実行することで、次のことを確認できます。

- ファイルを保存できたか
- Pythonが動くか
- ファイルを実行できるか
- 結果が画面に出るか

最初を短いプログラムにするのは、**動くかもわからんのにいっぱい書いても仕方ない**からです。

この章の手順に沿って、コードを書く → 実行する → 結果を見る、という流れを試してください。

---

## 2-2. 最初のコードを書く

まずは、画面へ「Hello World!」と表示する1行を書いてみてください。

このコードの元ファイル：[`hello_world.py` の 1〜2行](./hello_world.py#L1-L2)。

```python
# Hello World! という文字列を画面に表示する
print("Hello World!")
```

このコードを用意する方法は2つあります。

### 方法A: 自分で書く

1. VS Code を起動してください
2. **ファイル（File）→ 新しいテキストファイル（New Text File）** を選んでください (またはCTRL + Nキーを同時押し)
3. 表示された何も書かれていない欄(エディタといいます)に、上の Python コード(print("Hello World!"))を書いてください
4. **ファイル（File）→ 名前を付けて保存（Save As）** を選んでください ( またはctrl + Sを同時押し)
5. 自分が分かる保存先を選んでください。決め兼ねている人は「ドキュメント」の中に「Python学習」というフォルダを作り、そのフォルダを選んでください
6. ファイル名を `hello_world.py` にしてください
7. **保存（Save）** を押してください

`hello` は「こんにちは」、`world` は「世界」という意味です。`.py` は、Python のコードを保存するファイルに付ける目印です。ファイル名の末尾に付く `.py` のような部分を **拡張子** と呼びます。

保存したフォルダの場所は覚えておいてください。次の実行手順で、その場所を入力してもらいます。

保存後にコードを書き換えたときは、Windows / Linux では **Ctrl + Sキーを同時押し**、macOS では **Command + Sキーを同時押し** で再び保存してください。

### 方法B: サンプルファイルを使う

この教材には、同じ内容のサンプルファイルも用意しています。

- [hello_world.py](./hello_world.py)

リンクを開いて、ファイルを自分のPCへ保存して使うこともできます。

保存したファイル名が、

```text
hello_world.py
```

になっていることを確認してください。

Windowsでは設定によって拡張子(ファイル名の最後についている "."の後ろの部分のことです)が見えず、

```text
hello_world.py.txt
```

になってしまうことがあります。

その場合は`.txt`の部分を削除し、 `.py` ファイルとして保存し直してください。

この方法でも、`hello_world.py` を保存したフォルダの場所を忘れないようにしてください。

## 2-3. 保存した `hello_world.py` を動かしてみる

`hello_world.py` を保存できたら、中に書いたコードを動かしてみてください。画面に `Hello World!` が表示されるかを確認してください。

保存したファイルの中のコードをPythonで動かすことを、ここでは **Pythonファイルを実行する** といいます。

自分で書いた場合も、サンプルファイルを保存した場合も、動かすのは `hello_world.py` です。次の手順で、Pythonを使ってこのファイルの中のコードを実行してください。

### 1. `hello_world.py` を保存したフォルダを確認する

2-2で `hello_world.py` を保存したフォルダを開いてください。Windowsではエクスプローラー、macOSではFinderで開きます。次の手順では、Windowsでこのフォルダの場所をコピーします。

### 2. 保存したフォルダのパスをコピーする

Windowsでは、手順1で開いたエクスプローラーの画面上部のアドレス欄をクリックしてください。次の例のように、フォルダの場所を表す文字列が表示されます。この文字列を **パス** といいます。

```text
C:\Users\sample\Documents\Python学習
```

アドレス欄(エクスプローラーの更新ボタンの左)の文字列全体を選び、**Ctrl + C** を押してコピーしてください。アドレス欄を選べないときは、エクスプローラーで **Alt + D** を押すと選べます。コピーしたパスは、手順4の `cd` コマンドへ貼り付けます。

補足 コピーするのは `hello_world.py` 自体ではなく、**hello_world.py が入っているフォルダのパス**です。

macOS / Linuxでは、手順4で自分の保存先のパスを入力します。macOSでFinderからパスを入力する方法も、手順4に載せています。

### 3. VS Code でターミナルを開く

VS Code を起動し、上部メニューの **ターミナル（Terminal）→ 新しいターミナル（New Terminal）** を選んでください。

画面下側に、文字を入力できる場所が表示されます。この入力画面を **ターミナル** と呼び、そこへ入力する操作の指示を **コマンド** と呼びます。

ここからのコマンドは、Python のコードを書いた欄ではなく、このターミナルへ入力してください。1行入力するたびに Enter キーを押してください。

`PS C:\Users\sample>` など、すでに表示されている文字は入力しないようにしてください

### 4. `cd` で保存したフォルダへ移動する

ここから手順6までは、手順3で開いた同じターミナルを使ってください。ターミナルが隠れた場合は、VS Codeの **表示（View）→ ターミナル（Terminal）** で再び表示できます。

`cd` は、ターミナルで現在いるフォルダを変更するコマンドです。

Windows の例:

手順3で開いたVS Codeのターミナルへ、次のコマンドを入力してください。引用符の中の `C:\Users\sample\Documents\Python学習` は、**手順2でエクスプローラーのアドレス欄からコピーしたパス**を **Ctrl + V** で貼り付けて置き換え、前後の `"` は残してください。入力後に **Enter** キーを押してください。

```powershell
cd "C:\Users\sample\Documents\Python学習"
```

フォルダ名に空白が含まれていても動くように、
パス全体を `"` で囲んでおくと安全です。

macOS の例:

手順3で開いたVS Codeのターミナルへ、次のコマンドのフォルダ部分を自分の保存先に置き換えて入力し、**Enter** キーを押してください。

```bash
cd "/Users/sample/Documents/Python学習"
```

macOSでは、パスを手で入力する代わりにFinderから入力する方法もあります。Finderで `hello_world.py` を保存したフォルダの1つ上を開き、保存先フォルダが見える状態にしてください。VS Codeのターミナルに `cd `（`cd` と半角スペース）と入力し、その後ろへFinderの保存先フォルダをドラッグしてください。フォルダのパスが入力されたら **Enter** キーを押してください。

Linux の例:

手順3で開いたVS Codeのターミナルへ、次のコマンドのフォルダ部分を自分の保存先に置き換えて入力し、**Enter** キーを押してください。

```bash
cd "/home/sample/Documents/Python学習"
```

どの OS でも、例のパスを自分の保存先に置き換えてください。

### 5. ファイルがあるか確認する

保存した `hello_world.py` があるか、ファイル一覧を表示して確認しましょう。

Windows:

1. VS Codeのターミナルが表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んで開いてください。手順4でフォルダを移動したターミナルを使います。
2. 次の `dir` をターミナルへ入力してください。

```powershell
dir
```

3. **Enter** キーを押してください。

macOS / Linux:

1. VS Codeのターミナルが表示されていなければ、**表示（View）→ ターミナル（Terminal）** を選んで開いてください。手順4でフォルダを移動したターミナルを使います。
2. 次の `ls` をターミナルへ入力してください。

```bash
ls
```

3. **Enter** キーを押してください。

表示されたファイル一覧の中に、

```text
hello_world.py
```

があればOKです。見つからない場合は手順4へ戻り、`hello_world.py` を保存したフォルダへ移動したか確認してください。

### 6. Python で `hello_world.py` を動かす

ファイル名を確認したターミナルへ、次のコマンドを入力し、**Enter** キーを押してください。このコマンドで、Pythonが `hello_world.py` の中に書かれたコードを動かします。

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

ターミナルに次の文字が表示されたら、保存した `hello_world.py` のコードを動かせています。

```text
Hello World!
```

## 2-4. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

Pythonでは、`"` や `'` で囲んだ文字を **文字列** と呼びます。文字をひとまとまりの値として扱うときに使います。`"あ"` は1文字の文字列、`"おはよう"` は4文字の文字列です。1文字でも、文字列として扱います。

このコードの元ファイル：[`hello_world.py` の 1〜2行](./hello_world.py#L1-L2)。

```python
# Hello World! という文字列を画面に表示する
print("Hello World!")
```

### `print`

`print()` は、括弧の中で指定した値を画面に表示します。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、画面に表示したい値を書きます。

今回表示したい値は、

```python
"Hello World!"
```

です。

### `"Hello World!"`

`"Hello World!"` は、`Hello World!` という内容の文字列です。

Python のコードで文字列を書くときは、内容を `"` または `'` で囲みます。前後の引用符は、文字列の始まりと終わりを示すための記号です。この例で `print()` を実行すると、引用符は表示されず、中身の `Hello World!` が表示されます。

たとえば、次の2つは引用符の種類が違いますが、どちらも `おはよう` という同じ内容の文字列です。

```python
"おはよう"
'おはよう'
```

この教材では、特に理由がない限り `"` を使います。

## 2-5. コメント

サンプルコードの先頭には、次のような行があります。

このコードの元ファイル：[`hello_world.py` の 1〜1行](./hello_world.py#L1-L1)。

```python
# Hello World! という文字列を画面に表示する
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

このコードの元ファイル：[`hello_world.py` の 2〜2行](./hello_world.py#L2-L2)。

```python
# この行は実行されません。
print("Hello World!")
```

と書いても、表示されるのは次の1行だけです。

```text
Hello World!
```

## 2-6. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

変更する場所：[`hello_world.py` の2行](./hello_world.py#L2-L2)。

```python
print("おはようPython！")
```

書き換えたコードを保存して、もう一度動かしてください。

1. VS Codeで、書き換えた `hello_world.py` を開いてください。Windows / Linuxでは **Ctrl + S**、macOSでは **Command + S** を押して保存してください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでください。2-3で `hello_world.py` を動かしたときのターミナルを使ってください。そのターミナルを閉じた場合は、[2-3の手順](#2-3-保存した-hello_worldpy-を動かしてみる)に沿って保存先のフォルダへ移動してください。
3. 使っているOSに合わせて、次のコマンドをターミナルへ入力してください。入力後に **Enter** キーを押してください。

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

ターミナルに、次の文字が表示されます。

```text
おはようPython！
```

自分の好きな文字に変更して実行してみてください。

たとえば、

変更する場所：[`hello_world.py` の2行](./hello_world.py#L2-L2)。

```python
print("Pythonの勉強を始めます")
```

として、次の手順で保存して実行してください。

1. VS Codeで、書き換えた `hello_world.py` を開いてください。Windows / Linuxでは **Ctrl + S**、macOSでは **Command + S** を押して保存してください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでください。2-3で `hello_world.py` を動かしたときのターミナルを使ってください。そのターミナルを閉じた場合は、[2-3の手順](#2-3-保存した-hello_worldpy-を動かしてみる)に沿って保存先のフォルダへ移動してください。
3. 使っているOSに合わせて、次のコマンドをターミナルへ入力してください。入力後に **Enter** キーを押してください。

Windows:

```powershell
python hello_world.py
```

macOS / Linux:

```bash
python3 hello_world.py
```

ターミナルに、

```text
Pythonの勉強を始めます
```

と表示されます。

## 2-7. よくある間違い

### 引用符を付け忘れる

`Hello World!` は文字列なので、引用符で囲む必要があります。

❌

```python
print(Hello World!)
```

⭕️

このコードの元ファイル：[`hello_world.py` の 2〜2行](./hello_world.py#L2-L2)。

```python
print("Hello World!")
```

### 丸括弧を閉じ忘れる

開いた `(` に対応する `)` が必要です。

❌

```python
print("Hello World!"
```

⭕️

このコードの元ファイル：[`hello_world.py` の 2〜2行](./hello_world.py#L2-L2)。

```python
print("Hello World!")
```

### 全角の記号を使う

この例の丸括弧は、半角の `(` と `)` で入力してください。

❌

```text
print（"Hello World!"）
```

⭕️

このコードの元ファイル：[`hello_world.py` の 2〜2行](./hello_world.py#L2-L2)。

```python
print("Hello World!")
```
