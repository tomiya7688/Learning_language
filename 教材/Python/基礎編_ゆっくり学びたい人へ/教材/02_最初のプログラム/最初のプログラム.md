# 2. 最初のプログラム

この章では、画面に次の文字を表示するプログラムを書いて、動かします。

```text
Hello World!
```

---

## 2-1. なぜ Hello World! を表示するの？

hello worldと表示するのには、特別な理由はありません。「こんにちは」でも、自分の名前でもいいのです。

昔のプログラミング教材で、最初に動かす例として「Hello World」を表示するプログラムが使われ、その例が広まりました。由来は [プリンストン大学の紹介](https://engineering.princeton.edu/news/2021/12/17/part-fourteen-hello-world) で詳しく説明されています。

つまり

> **とりまなんか表示しとけ！おはよう世界！**

ということです。
昔からそれがよく使われてきたため、慣例的に「Hello World」が使われているのです。

次は実際にこの1行を書いて、ファイルを保存して実行します。

```python
print("Hello World!")
```

この1行を実行することで、次のことを確認できます。

- ファイルを保存できたか
- Pythonが動くか
- ファイルを実行できるか
- 結果が画面に出るか

なぜ最初、短いプログラムにするかというと、動くかもわからんのにいっぱい書いても仕方ないから　です。

この章では、書く → 実行する → 結果を見る という流れを確認します。

---

## 2-2. 最初のコードを書く

では、画面へ「Hello World!」と表示する1行を書いてみましょう。

```python
# Hello World! という文字列を画面に表示する
print("Hello World!")
```

このコードを用意する方法は2つあります。

### 方法A: 自分で書く

1. VS Code を起動する
2. **ファイル（File）→ 新しいテキストファイル（New Text File）** を選ぶ (またはCTRL + Nキーを同時押し)
3. 表示された白紙の欄(エディタといいます)に、上の Python コード(print("Hello World!"))を書く
4. **ファイル（File）→ 名前を付けて保存（Save As）** を選ぶ ( またはctrl + Sを同時押し)
5. 自分が分かる保存先を選ぶ。たとえば「ドキュメント」の中に「Python学習」というフォルダを作り、そのフォルダを選ぶ
6. ファイル名を `hello_world.py` にする
7. **保存（Save）** を押す

`hello` は「こんにちは」、`world` は「世界」という意味です。`.py` は、Python のコードを保存するファイルに付ける拡張子です。

保存したフォルダの場所を覚えておいてください。次の実行手順で使います。

保存後にコードを書き換えたときは、Windows / Linux では **Ctrl + Sキーを同時押し**、macOS では **Command + Sキーを同時押し** で再び保存します。

### 方法B: サンプルファイルを使う

この教材には、同じ内容のサンプルファイルも用意しています。

- [hello_world.py](./hello_world.py)

リンクを開き、ファイルを自分のPCへ保存して使っても構いません。

保存したファイル名が、

```text
hello_world.py
```

になっていることを確認してください。

Windowsでは設定によって拡張子(ファイル名の最後についている "."の後ろの部分のことです)が見えず、

```text
hello_world.py.txt
```

になってしまうことがあります。

その場合は `.py` ファイルとして保存し直してください。

## 2-3. 保存した `hello_world.py` を動かしてみる

`hello_world.py` を保存できたら、中に書いたコードを動かしてみましょう。画面に `Hello World!` が表示されるかを試します。

保存したファイルの中のコードをPythonで動かすことを、ここでは **実行する** といいます。

自分で書いた場合も、サンプルファイルを保存した場合も、動かすのは `hello_world.py` です。次の手順で、Pythonを使ってこのファイルの中のコードを動かします。

### 1. `hello_world.py` を保存したフォルダを確認する

まず、先ほど保存した `hello_world.py` が入っているフォルダを確認します。

たとえば Windows で、

```text
C:\Users\sample\Documents\Python学習
```

というフォルダに保存したとします。

この **ファイルが入っているフォルダの場所** は、このあとPythonに `hello_world.py` の場所を伝えるために使います。

### 2. 保存したフォルダのパスをコピーする

Windows では、エクスプローラーで `hello_world.py` が入っているフォルダを開きます。

画面上部のアドレス欄をクリックすると、

```text
C:\Users\sample\Documents\Python学習
```

のように、フォルダの場所を表す文字列が表示されます。この文字列を **パス** といいます。

アドレス欄の文字列全体を選び、**Ctrl + C** を押してコピーします。アドレス欄を選べないときは、エクスプローラーで **Alt + D** を押すと選べます。

このあと使う「コピーしたパス」は、**エクスプローラーで `hello_world.py` の保存先を開き、上部のアドレス欄からコピーした文字列**を指します。

> コピーするのは `hello_world.py` 自体ではなく、**hello_world.py が入っているフォルダのパス**です。

macOS では Finder で保存したフォルダを確認します。

必要ならフォルダをターミナルへドラッグすると、
そのフォルダのパスを入力できます。

### 3. VS Code でターミナルを開く

VS Code を起動し、上部メニューの **ターミナル（Terminal）→ 新しいターミナル（New Terminal）** を選びます。

画面下側に、文字を入力できる場所が表示されます。この入力画面を **ターミナル** と呼び、そこへ入力する操作の指示を **コマンド** と呼びます。

ここからのコマンドは、Python のコードを書いた欄ではなく、このターミナルへ入力します。1行入力するたびに Enter キーを押してください。

`PS C:\Users\sample>` など、すでに表示されている文字は入力しません。

### 4. `cd` で保存したフォルダへ移動する

`cd` は、ターミナルで現在いるフォルダを変更するコマンドです。

Windows の例:

1. エクスプローラーで、保存した `hello_world.py` が入っているフォルダを開きます。
2. 上部のアドレス欄をクリックし、表示されたフォルダのパス全体を選んで **Ctrl + C** を押します。
3. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
4. 次のコマンドを、そのターミナルに入力します。引用符の中の `C:\Users\sample\Documents\Python学習` は、手順2でエクスプローラーのアドレス欄からコピーしたパスに置き換えます。**Ctrl + V** で貼り付け、前後の `"` は残してください。
5. Enter キーを押します。

```powershell
cd "C:\Users\sample\Documents\Python学習"
```

フォルダ名に空白が含まれていても動くように、
パス全体を `"` で囲んでおくと安全です。

macOS の例:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドのフォルダのパスや名前を、自分の保存先に置き換え、そのターミナルに入力します。
3. Enter キーを押します。

```bash
cd "/Users/sample/Documents/Python学習"
```

Linux の例:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドのフォルダのパスや名前を、自分の保存先に置き換え、そのターミナルに入力します。
3. Enter キーを押します。

```bash
cd "/home/sample/Documents/Python学習"
```

どの OS でも、例のパスを自分の保存先に置き換えてください。

### 5. ファイルがあるか確認する

移動できたら、`hello_world.py` があるか確認します。

Windows:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```powershell
dir
```

macOS / Linux:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```bash
ls
```

一覧の中に、

```text
hello_world.py
```

があれば、正しいフォルダに移動できています。

### 6. Python で `hello_world.py` を動かす

次のコマンドをターミナルに入力し、Enter キーを押します。このコマンドで、Pythonが `hello_world.py` の中に書かれたコードを動かします。

Windows:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```powershell
python hello_world.py
```

macOS / Linux:

1. VS Code のターミナルを開きます。表示されていなければ **表示（View）→ ターミナル（Terminal）** を選びます。前の操作から続ける場合は、同じターミナルを使います。
2. 次のコマンドを、そのターミナルに入力します。
3. Enter キーを押します。

```bash
python3 hello_world.py
```

ターミナルに次の文字が表示されたら、保存した `hello_world.py` のコードを動かせています。

```text
Hello World!
```

ここまでの流れは、

1. 自分で書く、またはサンプルを保存する
2. `hello_world.py` の保存場所を確認する
3. Windowsでは、エクスプローラーで保存先のフォルダを開き、上部のアドレス欄からフォルダのパスをコピーする
4. VS Codeでターミナルを開く
5. `cd` でそのフォルダへ移動する
6. `dir` / `ls` でファイルを確認する
7. Pythonで実行する

となります。

## 2-4. コードを分解してみる

書いたコードは1行だけですが、いくつかの要素があります。

文字の並びをひとまとまりの値として扱うものを **文字列** といいます。`"あ"` は1文字の文字列、`"おはよう"` は4文字の文字列です。1文字でも、文字列として扱います。

```python
# Hello World! という文字列を画面に表示する
print("Hello World!")
```

### `print`

`print()` は、括弧の中で指定した値を画面に表示します。この例では、`Hello World!` という文字列を表示します。

### `()`

`print` の後ろには丸括弧 `()` があります。

丸括弧の中に、画面に表示したい値を書いて指定します。

今回指定している値は、

```python
"Hello World!"
```

です。

### `"Hello World!"`

`"Hello World!"` は、`Hello World!` という内容の文字列です。

Python のコードで文字列を書くときは、内容を `"` または `'` で囲みます。前後の引用符は、文字列の始まりと終わりを示すための記号です。この例で `print()` を実行すると、引用符は表示されず、中身の `Hello World!` が表示されます。

たとえば、次の2つは引用符の種類が違いますが、どちらも `おはよう` という同じ内容の文字列です。

```python
"おはよう"
'おはよう'
```

この教材では、特に理由がない限り `"` を使います。

---

## 2-5. コメント

サンプルコードの先頭には、次のような行があります。

```python
# Hello World! という文字列を画面に表示する
```

Python では、`#` から行の終わりまでが **コメント** になります。

コメントはプログラムの説明を書くためのもので、Python は実行しません。

たとえば、

```python
# この行は実行されません。
print("Hello World!")
```

と書いても、表示されるのは次の1行だけです。

```text
Hello World!
```

## 2-6. 少し変更してみる

文字列の中身を変更すると、表示される内容も変わります。

```python
print("おはようPython！")
```

実行結果:

```text
おはようPython！
```

自分の好きな文字に変更して実行してみてください。

たとえば、

```python
print("Pythonの勉強を始めます")
```

として実行してみると、

```text
Pythonの勉強を始めます
```

と表示されます。

## 2-7. よくある間違い

### 引用符を付け忘れる

`Hello World!` は文字列なので、引用符で囲む必要があります。

❌

```python
print(Hello World!)
```

⭕️

```python
print("Hello World!")
```

### 丸括弧を閉じ忘れる

開いた `(` に対応する `)` が必要です。

❌

```python
print("Hello World!"
```

⭕️

```python
print("Hello World!")
```

### 全角の記号を使う

この例の丸括弧は、半角の `(` と `)` で入力します。

❌

```text
print（"Hello World!"）
```

⭕️

```python
print("Hello World!")
```
