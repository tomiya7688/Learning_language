# 9. 進みたい方を選ぼう

> **「基本の書き方は試せたけど、次は何を作ればいい？」**

作りたいものが決まっている場合は、次の3つから選んでください。選んだページを開き、作りながら必要な書き方を学んでください。先にPythonの基本的な書き方を練習したい場合は、[「もっと基礎を固めてからにしたい」](#もっと基礎を固めてからにしたい)へ進んでください。
