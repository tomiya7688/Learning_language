# Tk9. 小数点を置く

> **「1.5を計算したいのに、小数点のボタンがない！間違って点を2個押しても直せる電卓にしたい！」**

この章の電卓は、数字ボタンと小数点ボタンをクリックして、`1.5 + 2.5` など小数を含む四則演算ができる電卓です。電卓画面の「1」「.」「5」「+」「2」「.」「5」「=」の各ボタンを順に押すと、結果の欄に `答え: 4.0` が表示されます。

小数点のボタンには、Pythonで小数を書くときの記号「.」を使います。数字ボタンの最下段を「C・0・.」の並びにして、0の隣へ小数点を置きます。CはClear（消去）の頭文字で、入力と保存済みの式を最初からやり直すボタンです。

## Tk9-1. 入力する時と、計算する時の両方で困り事を防ぐ

小数点を数字と同じように末尾へ追加するだけでは、電卓画面の「.」ボタンを2回押したときに `1.2.3` のような入力ができます。小数点を追加する前に、入力中の数字へ小数点が既に入っているか調べる処理が必要です。

小数点を押した時だけ判定するため、`append_decimal_point`（小数点を追加する）という処理に分けます。クラス内で定義した関数を「メソッド」と呼びます。入力欄が空なら、`append_decimal_point` は `0.` を入れます。たとえば電卓画面の「.」「5」の各ボタンだけで `0.5` を入力できます。

小数点ボタンで二重入力を防いでも、利用者はキーボードで `1.2.3` と入力できます。計算記号や「=」のボタンを押した時にも、入力欄の文字列を数値に変換できるか調べる必要があります。

計算記号を保存する処理と答えを出す処理へ同じ確認を書けば、入力ミスの案内を変える時に2か所を直すことになります。数値への変換と入力ミスの案内は `read_number`（数値を読み取る）へまとめます。`read_number` は、数値へ変換できた場合にその数値を返し、変換できない場合に画面へ案内を表示して `None` を返します。`None` は、この処理では「使える数値が得られなかった」と区別するための値です。数値の0とは別です。

入力を直して計算を続けたい時に、前に入力した `1.5 +` まで消えると、最初から入力し直すことになります。`read_number` が使える数値を返すまで、計算式のリスト（数値と計算記号を順に保存する一覧）へ入力を追加しません。入力ミスを案内した時も、既に保存した式と入力欄を残し、利用者が入力だけを直せるようにします。

## Tk9-2. どの電卓の入力を調べるかをそろえる

入力欄、保存済みの式、小数点を追加する操作、数値を読み取る操作は、同じ電卓に関する情報と操作です。入力欄を読む処理と案内を表示する処理を別々の場所へ置くと、どの電卓の入力を調べ、どの電卓へ案内を表示するかを対応させにくくなります。`CalculatorApp`（電卓アプリ）というクラスへまとめ、各メソッドが同じ電卓の入力欄と結果の欄を使う構成にします。クラスは、同じ対象の情報と操作をまとめて定義する仕組みです。

`CalculatorApp()` で作る個々の電卓を「インスタンス」と呼びます。クラス内の `self` は、操作対象の電卓を表します。`self.number_entry` は数字の入力欄、`self.calculation_parts` は入力済みの式のリスト、`self.replace_input` は次の数字ボタンや小数点ボタンで入力を置き換えるかを覚える情報です。`True` なら前の計算を消して新しく入力し、`False` なら入力中の数字へ追加します。

電卓の準備は、電卓を作った時に実行する `__init__` が担当します。数字・C・小数点のボタンを並べる処理は、画面を作る時だけ実行する `create_digit_buttons`（数字ボタンを作る）にまとめます。数字ボタンごとに同じ追加処理を用意せず、`append_digit`（数字を追加する）へ押した数字を指定します。 `partial` は、押す前にボタンの数字を指定しておき、押した時にその数字で処理を実行するための道具です。`from functools import partial` は、Pythonに同梱された `functools` という道具のファイルから `partial` を読み込みます。たとえば「7」のボタンは `"7"` を指定した処理を登録し、ボタンを押した時に `append_digit` を実行します。

電卓画面の計算記号ボタンは、数字と記号を保存する `add_operator`（演算子を追加する）を使います。演算子は「+」「-」「*」「/」など計算の種類を表す記号です。電卓画面の「=」ボタンを押した時だけ答えを出すため、計算する処理は `calculate`（計算する）に分けます。`clear`（消す）は、電卓画面の「C」ボタンと、答えの後に数字や小数点で新しく入力する操作の両方から使う消去処理です。

画面を準備する処理と、画面を表示して操作を待つ処理は実行するタイミングが違うため、操作待ちは `run`（実行する）へ分けます。`app.py` の `main` は電卓を作って `run` を実行する起動処理です。`app` は「アプリ」、`main` は起動時に実行する中心の処理を表す名前です。機能を変更するファイルは `calculator.py`（電卓）、起動するファイルは `app.py` のままです。

### calculator.py：小数点の入力と計算

元ファイル：[`calculator.py` 全体](./calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
# math を、このプログラムで使えるようにする
import math
# functools から、処理に指定する値を先に固定する partial を読み込む
from functools import partial


# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
        # self.replace_input（次の数字ボタンか小数点ボタンで入力を置き換えるか）に False を入れる
        self.replace_input = False

        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「小数点を置く」にする
        self.window.title("小数点を置く")
        # self.window の大きさを横420、縦600にする
        self.window.geometry("420x600")

        # self.number_label（数字の案内）に self.window 内で「数字」と表示するラベルを入れる
        self.number_label = tkinter.Label(self.window, text="数字")
        # self.number_label を self.window 内に配置する
        self.number_label.pack()

        # self.number_entry（数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window)
        # self.number_entry を self.window 内に配置する
        self.number_entry.pack()

        # self.expression_label（計算式の表示）に self.window 内で「計算式:」と表示するラベルを入れる
        self.expression_label = tkinter.Label(self.window, text="計算式:")
        # self.expression_label を self.window 内に配置する
        self.expression_label.pack()

        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()

        # self.multiplication_button（掛け算ボタン）に self.window 内で「*」と表示し、押すと self.select_multiplication を呼ぶボタンを入れる
        self.multiplication_button = tkinter.Button(
            self.window,
            text="*",
            # ボタンを押したときに呼ぶ処理として self.select_multiplication を登録する
            command=self.select_multiplication,
        )
        # self.multiplication_button を self.window 内に配置する
        self.multiplication_button.pack()

        # self.division_button（割り算ボタン）に self.window 内で「/」と表示し、押すと self.select_division を呼ぶボタンを入れる
        self.division_button = tkinter.Button(
            self.window,
            text="/",
            # ボタンを押したときに呼ぶ処理として self.select_division を登録する
            command=self.select_division,
        )
        # self.division_button を self.window 内に配置する
        self.division_button.pack()

        # self.equals_button（計算を行うボタン）に self.window 内で「=」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.equals_button = tkinter.Button(
            self.window,
            text="=",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.equals_button を self.window 内に配置する
        self.equals_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

        # 数字ボタン・消去ボタン・小数点ボタンを作って配置する self.create_digit_buttons を呼び出す
        self.create_digit_buttons()

    # 数字ボタン・消去ボタン・小数点ボタンを配置する create_digit_buttons を定義する
    def create_digit_buttons(self):
        # self.digits_frame（数字ボタンの枠）に self.window 内の部品をまとめる枠を入れる
        self.digits_frame = tkinter.Frame(self.window)
        # self.digits_frame を self.window 内に配置する
        self.digits_frame.pack()
        # digit_positions（数字と配置位置）に、数字の文字列・行番号・列番号の組を並べたリストを入れる
        digit_positions = [
            ("7", 0, 0), ("8", 0, 1), ("9", 0, 2),
            ("4", 1, 0), ("5", 1, 1), ("6", 1, 2),
            ("1", 2, 0), ("2", 2, 1), ("3", 2, 2),
            ("0", 3, 1),
        ]
        # digit（数字）・row（行）・column（列）に digit_positions の各組の値を入れ、次の処理を繰り返す
        for digit, row, column in digit_positions:
            # button（数字ボタン）に、digit を表示し、押すと self.append_digit に digit を指定して実行するボタンを入れる
            button = tkinter.Button(
                self.digits_frame,
                text=digit,
                width=4,
                # digit を指定した self.append_digit の処理を、ボタンを押したときの処理として登録する
                command=partial(self.append_digit, digit),
            )
            # button を row 行・column 列へ配置し、左右と上下に4ピクセルずつ間を空ける
            button.grid(row=row, column=column, padx=4, pady=4)
        # self.clear_button（消去ボタン）に、Cを表示し、押すと self.clear を実行するボタンを入れる
        self.clear_button = tkinter.Button(
            self.digits_frame, text="C", width=4, command=self.clear
        )
        # self.clear_button を3行・0列へ配置し、左右と上下に4ピクセルずつ間を空ける
        self.clear_button.grid(row=3, column=0, padx=4, pady=4)
        # self.decimal_button（小数点ボタン）に、点を表示し、押すと self.append_decimal_point を実行するボタンを入れる
        self.decimal_button = tkinter.Button(
            self.digits_frame, text=".", width=4, command=self.append_decimal_point
        )
        # self.decimal_button を3行・2列へ配置し、左右と上下に4ピクセルずつ間を空ける
        self.decimal_button.grid(row=3, column=2, padx=4, pady=4)

    # 入力欄へ数字を追加する append_digit を定義する
    def append_digit(self, digit):
        # digit（追加する数字）には、押された数字ボタンの文字列が入る
        # self.replace_input が True なら、次の処理を実行する
        if self.replace_input:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()
        # self.number_entry の末尾へ digit を挿入する
        self.number_entry.insert(tkinter.END, digit)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力欄へ小数点を追加する append_decimal_point を定義する
    def append_decimal_point(self):
        # self.replace_input が True なら、次の処理を実行する
        if self.replace_input:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()
        # number_text に小数点が含まれていれば、次の処理を実行する
        if "." in number_text:
            # self.result_label の表示を「小数点は1つの数字に1個だけ入力できます」に変える
            self.result_label.config(text="小数点は1つの数字に1個だけ入力できます")
            # append_decimal_point の処理をここで終える
            return
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.number_entry の末尾へ「0」を挿入する
            self.number_entry.insert(tkinter.END, "0")
        # self.number_entry の末尾へ「.」を挿入する
        self.number_entry.insert(tkinter.END, ".")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")

    # 入力・計算式・結果表示を空にする clear を定義する
    def clear(self):
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.expression_label の表示を「計算式:」に変える
        self.expression_label.config(text="計算式:")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力欄を数値へ変換し、使えない入力を結果の欄で知らせる read_number を定義する
    def read_number(self, empty_message):
        # empty_message（空欄の案内）には、入力欄が空の場合に表示する文字列が入る
        # number_text（入力文字列）に self.number_entry の文字列から前後の空白を取り除いた文字列を入れる
        number_text = self.number_entry.get().strip()
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を empty_message に変える
            self.result_label.config(text=empty_message)
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 次の数値変換で ValueError が起きるかを確認する
        try:
            # number（読み取った数値）に number_text を float で数値に変換した値を入れる
            number = float(number_text)
        # 数値へ変換できず ValueError が起きた場合は、次の処理を実行する
        except ValueError:
            # self.result_label の表示を「数字を入力してください（例: 1.5）」に変える
            self.result_label.config(text="数字を入力してください（例: 1.5）")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # number が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(number):
            # self.result_label の表示を「有限の数字を入力してください」に変える
            self.result_label.config(text="有限の数字を入力してください")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 読み取った数値 number を返す
        return number

    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number（読み取った数値）に、空欄の案内「次の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("次の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 入力された数字と「*」を計算式に追加する select_multiplication を定義する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")

    # 入力された数字と「/」を計算式に追加する select_division を定義する
    def select_division(self):
        # 「/」を指定して self.add_operator を呼び出す
        self.add_operator("/")

    # 計算式に最後の数字を追加し、掛け算と割り算を先に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number（読み取った数値）に、空欄の案内「最後の数字を入力してください」を指定して self.read_number が返す値を入れる
        number = self.read_number("最後の数字を入力してください")
        # number が None なら、次の処理を実行する
        if number is None:
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number を追加する
        self.calculation_parts.append(number)

        # 掛け算と割り算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」ではなく「/」なら、次の処理を実行する
            elif operator == "/":
                # number が0なら、次の処理を実行する
                if number == 0:
                    # self.result_label の表示を「0では割れません」に変える
                    self.result_label.config(text="0では割れません")
                    # self.calculation_parts の要素をすべて削除する
                    self.calculation_parts.clear()
                    # self.replace_input に True を入れる
                    self.replace_input = True
                    # calculate の処理をここで終える
                    return

                # addition_and_subtraction_parts の末尾の要素に、その値を number で割った値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] / number
                )
            # operator が「*」でも「/」でもなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)

        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number

        # answer が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(answer):
            # self.result_label の表示を「計算結果が大きすぎます。Cで消してやり直してください」に変える
            self.result_label.config(text="計算結果が大きすぎます。Cで消してやり直してください")
            # self.calculation_parts の要素をすべて削除する
            self.calculation_parts.clear()
            # self.replace_input に True を入れる
            self.replace_input = True
            # calculate の処理をここで終える
            return

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものと「 = 」と answer の値を付けた文字列に変える
        self.expression_label.config(
            text=(
                "計算式: "
                + " ".join(str(part) for part in self.calculation_parts)
                + f" = {answer}"
            )
        )
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer を文字列にした値を挿入する
        self.number_entry.insert(0, str(answer))
        # self.replace_input に True を入れる
        self.replace_input = True

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

## Tk9-7. キーボードで入力した数字も調べる

元ファイル：[`calculator.py` の184〜212行](./calculator.py#L184-L212)。

```python
    # 入力欄を数値へ変換し、使えない入力を結果の欄で知らせる read_number を定義する
    def read_number(self, empty_message):
        # empty_message（空欄の案内）には、入力欄が空の場合に表示する文字列が入る
        # number_text（入力文字列）に self.number_entry の文字列から前後の空白を取り除いた文字列を入れる
        number_text = self.number_entry.get().strip()
        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を empty_message に変える
            self.result_label.config(text=empty_message)
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 次の数値変換で ValueError が起きるかを確認する
        try:
            # number（読み取った数値）に number_text を float で数値に変換した値を入れる
            number = float(number_text)
        # 数値へ変換できず ValueError が起きた場合は、次の処理を実行する
        except ValueError:
            # self.result_label の表示を「数字を入力してください（例: 1.5）」に変える
            self.result_label.config(text="数字を入力してください（例: 1.5）")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # number が無限大でも非数でもない数値でなければ、次の処理を実行する
        if not math.isfinite(number):
            # self.result_label の表示を「有限の数字を入力してください」に変える
            self.result_label.config(text="有限の数字を入力してください")
            # 数値を読み取れなかったことを表す None を返す
            return None
        # 読み取った数値 number を返す
        return number
```

`get().strip()` は、入力欄の文字列を読み、前後の空白を取り除きます。空欄なら、`read_number` は呼び出す側が指定した案内を結果の欄へ表示し、数値がないことを表す `None` を返します。

`float(number_text)` は、`"1.5"` などの数字の文字列を、小数も扱える数値へ変換します。文字列は表示や入力に使う文字の並び、数値は足し算などの計算に使う値です。`"1.2.3"` や `"abc"` は数値へ変換できないため、Pythonは `ValueError` という、値が合わないことを知らせるエラーを起こします。

`try` の下では `float` による変換を行います。変換で `ValueError` が起きた時だけ `except ValueError` の下を実行し、電卓の結果の欄へ「数字を入力してください（例: 1.5）」と表示して `None` を返します。変換できた時は `except` の下を通らず、数値の確認へ進みます。`None` は0とは違うため、0を入力した場合も計算へ進めます。

`float` は `inf`（無限大）や `nan`（計算できる数値ではない特別な値）という文字列も受け付けます。普通の電卓の答えとして扱わないため、`math.isfinite(number)` で無限大でも `nan` でもない数値かを調べます。`not` は判定を反対にする記述なので、無限大や `nan` なら結果の欄に「有限の数字を入力してください」と表示して計算へ進めません。`import math` は、Pythonに同梱された計算用の道具を読み込む記述です。追加インストールは必要ありません。仕様は [Python公式のfloatの説明](https://docs.python.org/3/library/functions.html#float)と [math.isfiniteの説明](https://docs.python.org/3/library/math.html#math.isfinite)で確認できます。

```python
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False
```

`number = self.read_number("次の数字を入力してください")` は、入力欄が空の場合の案内を指定して、同じ電卓の入力を数値へ変換します。`number is None` は、使える数値を受け取れなかったかを調べます。使える数値がない場合は `return` で処理を終え、式のリストを変更しません。使える数値がある場合は、`append`（末尾へ追加する操作）で数値と計算記号を式のリストへ保存します。

答えを出す [`calculator.py` の262〜365行](./calculator.py#L262-L365)も、最初に `read_number("最後の数字を入力してください")` を実行します。小数も整数も `float` の数値として保存しているため、数字ボタンから入力した `1` は計算式の欄で `1.0` と表示されます。掛け算と割り算を先に計算し、残った足し算と引き算を左から計算する順序は共通です。

### 0で割る入力と、大きすぎる計算の後

電卓画面の「C」ボタンを押し、電卓画面の「1」「.」「5」「/」「0」「=」の各ボタンを順に押してください。結果の欄に「0では割れません」と表示されます。式の欄は `計算式: 1.5 /`、入力欄は `0` のままですが、保存した式は空になります。

0で割る入力の後、電卓画面の「.」ボタンを押してください。前の表示と入力が消え、入力欄は `0.`、式の欄は `計算式:`、結果の欄は `答え:` に変わります。電卓画面の「5」「=」の各ボタンを順に押すと、式の欄は `計算式: 0.5 = 0.5`、結果の欄と入力欄は `0.5` に変わります。

0で割る入力の直後に電卓画面の計算記号ボタンを押す場合は、入力欄に残る `0` を新しい計算の最初の数字として使います。残った `0` は答えではありません。電卓画面の「C」ボタンでも入力と式を消せます。

数値に変換できる入力同士でも、掛け算などの結果が `float` で表せる範囲を超える場合があります。[`calculator.py` の262〜365行](./calculator.py#L262-L365)は、答えを表示する前に `math.isfinite(answer)` で結果も調べます。結果が無限大や `nan` なら「計算結果が大きすぎます。Cで消してやり直してください」と表示し、保存した式を空にします。入力欄には最後に入力した数字、式の欄には計算前の式が残ります。電卓画面の「C」ボタンを押して入力・式・案内を消してから、新しい計算を始めてください。

## Tk9-9. 小数の答えと今回の内容

`float` は小数を近い値で保存するため、たとえば `0.1 + 0.2` の答えは `0.30000000000000004` と表示される場合があります。この電卓は答えを丸めずに表示します。お金の計算のように小数を正確に扱う用途の完成品ではありません。[Python公式の小数の計算の説明](https://docs.python.org/3/tutorial/floatingpoint.html)で、小数を近い値として保存する理由を確認できます。

- `append_decimal_point` は、小数点が既にあるかを調べ、2個目の小数点を追加しません。空欄なら `0.` を入れます。
- `read_number` は、入力欄の文字列を `float` の数値に変換し、変換できない入力を電卓の結果の欄へ案内します。
- 計算記号を保存する処理も、答えを出す処理も、`read_number` が数値を返すまで式を変更しません。入力ミスを直した後は、保存済みの式から計算を続けられます。
- 電卓画面の小数点ボタンは、計算直後に押すと前の答えを消して `0.` から入力を始めます。正常な計算直後の計算記号ボタンは、前の答えから計算を続けます。

コードを変更して起動し直す場合は、電卓の画面を閉じてください。`calculator.py` と `app.py` をCtrl + S（macOSはCommand + S）で保存し、VS Codeの **表示（View）→ ターミナル（Terminal）** で、Tk9を起動したターミナルが入力待ちへ戻ったことを確認してください。Windowsは `python app.py`、macOS / Linuxは `python3 app.py` と入力してEnterキーを押してください。保存したTk9の電卓が起動します。
