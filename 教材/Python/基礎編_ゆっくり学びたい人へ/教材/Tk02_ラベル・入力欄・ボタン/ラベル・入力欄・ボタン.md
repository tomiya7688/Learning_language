# Tk2. ラベル・入力欄・ボタン

Tk1でウィンドウが開くようになりました。でも、中は空っぽです。電卓を作るにも、数字を入れる欄も計算を頼むボタンもありません。

> **「画面出たけど、何もできんやん！！！」**

文字を入力する欄と、押したら結果が出るボタンが欲しいところです。この章では、名前を入力して「挨拶する」ボタンを押すと、その名前で挨拶を表示する画面を作ってみてください。計算はまだせず、入力欄とボタンが反応することを確かめます。

---

## Tk2-1. 今回作るもの

画面には、

- 名前を入力する欄
- 「挨拶する」ボタン
- 結果を表示する文字

これが、このコードで用意する部品です。

たとえば、

```text
名前を入力: たろう
```

と入力してボタンを押すと、

```text
こんにちは たろう
```

と表示されます。

前のTk1では、空のウィンドウを表示するところまででした。

今回は、そのウィンドウに**部品を置いて、利用者の操作に反応させます。**

---

## Tk2-2. なぜ部品が必要なの？

Tk1で、文字だけだったプログラムからウィンドウへ進みました。

でも、出しただけでは、

```text
[         空のウィンドウ         ]
```

です。

利用者からすると、

> **「画面出たけど、何もできんやん！！！」**

となります。

次の題材は、**入力欄やボタンを操作できる画面**です。

そこでGUIでは、

- 説明を表示する
- 文字を入力してもらう
- ボタンを押してもらう
- 結果を表示する

このプログラムは、それぞれの役割の部品を並べます。

tkinterでは、こうした部品を**ウィジェット（Widget）**と呼びます。

---

## Tk2-3. 部品を順番に置く

[greeting_gui.py](./greeting_gui.py) を開いてください。

`greeting` は「挨拶」、`gui` は「画面を使って操作する仕組み」という意味で使われます。

今回は、

```text
説明用Label
↓
名前入力用Entry
↓
挨拶するButton
↓
結果表示用Label
```

の順に置いてください。

あとから入力内容を読んだり表示を書き換えたりするので、それぞれ `name_label`、`name_entry`、`greet_button`、`result_label` という名前で持ちます。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 入力された名前で挨拶を表示する show_greeting を定義する
def show_greeting():
    # name に name_entry に入力された文字列を入れる
    name = name_entry.get()
    # result_label の表示を「こんにちは 」と name をつなげた文字列に変える
    result_label.config(text=f"こんにちは {name}")


# window に tkinterのTkクラスから作ったウィンドウを入れる
window = tkinter.Tk()
# window のタイトルを「挨拶アプリ」にする
window.title("挨拶アプリ")
# window の大きさを横400、縦220にする
window.geometry("400x220")

# name_label に window 内で「名前を入力してください」と表示するラベルを入れる
name_label = tkinter.Label(window, text="名前を入力してください")
# name_label を window 内に配置する
name_label.pack()

# name_entry に window 内の1行の入力欄を入れる
name_entry = tkinter.Entry(window)
# name_entry を window 内に配置する
name_entry.pack()

# greet_button に window 内で「挨拶する」と表示し、押すと show_greeting を呼ぶボタンを入れる
greet_button = tkinter.Button(window, text="挨拶する", command=show_greeting)
# greet_button を window 内に配置する
greet_button.pack()

# result_label に window 内で空の文字列を表示するラベルを入れる
result_label = tkinter.Label(window, text="")
# result_label を window 内に配置する
result_label.pack()

# window の画面を表示し、操作を待ち続ける
window.mainloop()
```

## Tk2-4. Labelとは

`Label` は、画面に文字を表示するための部品です。

まず、入力欄の説明が必要なのでLabelを1つ作ってください。

名前に関する説明なので、`name_label` にしてください。

```python
# name_label に window 内で「名前を入力してください」と表示するラベルを入れる
name_label = tkinter.Label(window, text="名前を入力してください")
```

ここでは、

```text
名前を入力してください
```

という文字を表示するLabelを作っています。

`window` を最初に渡しているのは、

> このウィンドウの中に置く部品ですよ

という意味です。

---

## Tk2-5. Entryとは

`Entry` は、1行の文字入力欄です。

次のコードは、名前を入力する欄を作る処理です。

あとで入力内容を取り出すので、名前は `name_entry` にしてください。

```python
# name_entry に window 内の1行の入力欄を入れる
name_entry = tkinter.Entry(window)
```

この部品へ、利用者が名前を入力できます。

たとえば、

```text
たろう
```

と入力した内容は、あとでプログラムから取り出せます。

---

## Tk2-6. Buttonとは

`Button` は、押せるボタンです。

次のコードは、挨拶を実行するボタンを作る処理です。

役割が分かるように、名前は `greet_button` にしてください。

```python
# greet_button に window 内で「挨拶する」と表示し、押すと show_greeting を呼ぶボタンを入れる
greet_button = tkinter.Button(
    window,
    text="挨拶する",
    command=show_greeting
)
```

`text` は、ボタンに表示する文字です。

```text
挨拶する
```

と表示されます。

そして、

```python
# ボタンが押されたときに呼ぶ処理として show_greeting を指定する
command=show_greeting
```

で、

> このボタンが押されたら `show_greeting` を実行する

と設定しています。

---

## Tk2-7. なぜ `show_greeting()` ではないの？

ここはとても大切です。

ボタンを作るときは、

```python
# ボタンが押されたときに呼ぶ処理として show_greeting を指定する
command=show_greeting
```

と書いてください。

```python
# show_greeting をその場で呼び出し、その戻り値を command に指定する
command=show_greeting()
```

とは書きません。

`()` を付けると、その場ですぐ関数を実行してしまいます。

今回は、

> 今すぐ実行するのではなく、ボタンが押されたときに実行してほしい

ので、関数名だけを渡してください。

```text
show_greeting()   → 今すぐ実行する
show_greeting     → あとで呼べるよう関数そのものを渡す
```

ボタンの `command` には関数名を渡してください。`()` を付けずに渡すと、ボタンが押されたときにその関数を実行できます。

---

## Tk2-8. `.get()` で入力内容を取り出す

ボタンが押されると、次の関数が実行されます。

```python
# 入力された名前で挨拶を表示する show_greeting を定義する
def show_greeting():
    # name に name_entry に入力された文字列を入れる
    name = name_entry.get()
    # result_label の表示を「こんにちは 」と name をつなげた文字列に変える
    result_label.config(text=f"こんにちは {name}")
```

まず、

```python
# name に name_entry に入力された文字列を入れる
name = name_entry.get()
```

このコードで、プログラムはEntryに入力された文字を取り出します。

`.get()` は、

> この入力欄に今入っている内容をください

というイメージです。

たとえばEntryに、

```text
たろう
```

と入っていれば、

```text
name → "たろう"
```

となります。

---

## Tk2-9. 表示内容を書き換える

次に、

```python
# result_label の表示を「こんにちは 」と name をつなげた文字列に変える
result_label.config(text=f"こんにちは {name}")
```

この行で、プログラムが挨拶を作って表示する処理を実行します。

`config()` は、作った部品の設定をあとから変更するために使えます。

今回は、結果表示用Labelの `text` を変更しています。

結果を表示する場所も先に作っておきます。

まだ結果はないので、最初の文字は空にしてください。

```python
# result_label に window 内で空の文字列を表示するラベルを入れる
result_label = tkinter.Label(window, text="")
```

あとでボタンが押されたら、このLabelを書き換えます。

ボタンが押されたあとに、

```text
こんにちは たろう
```

へ変更してください。

---

## Tk2-10. `pack()` は何をしている？

部品を作っただけでは、画面上に配置されません。

そこで、

```python
# name_label を window 内に配置する
name_label.pack()
# name_entry を window 内に配置する
name_entry.pack()
# greet_button を window 内に配置する
greet_button.pack()
# result_label を window 内に配置する
result_label.pack()
```

のように `pack()` を使っています。

`pack()` は、

> この部品をウィンドウの中へ配置する

ための方法のひとつです。

`pack()` は、既定では呼び出した順に部品を上から配置します。この例では、ラベル・入力欄・ボタン・結果表示の順に並びます。

ほかの配置方法として、行と列を使う `grid()` と、座標を使う `place()` があります。

---

## Tk2-11. イベント駆動とは？

これまでのプログラムは、

```text
上から順番に実行
        ↓
終わる
```

という流れが中心でした。

GUIでは少し違います。

ウィンドウを表示したあと、

```text
利用者が入力する
        ↓
ボタンを押す
        ↓
そのとき関数を実行する
```

という形になります。

このように、

> 何かの出来事が起きたときに処理する

考え方を**イベント駆動**と呼びます。

ボタンを押すこともイベントのひとつです。

---

## Tk2-12. イベントがなかったらどうなる？

もしGUIが利用者の操作を待たず、最初から全部実行してしまったらどうなるでしょうか。

名前を入力する前に、

```text
こんにちは
```

と表示されてしまうかもしれません。

プログラム側が、

> 「たぶんこの人はそろそろボタンを押すだろう」

と勝手に予想して動くわけにはいきません。

そこでGUIでは、

> ボタンが押されたら、この処理をする

という形で処理を結び付けます。

これがイベント駆動の基本です。

## Tk2-13. 関数をここでも使っている

7章で学んだ関数が、GUIでもそのまま使われています。

```python
# 入力された名前で挨拶を表示する show_greeting を定義する
def show_greeting():
    # name に name_entry に入力された文字列を入れる
    name = name_entry.get()
    # result_label の表示を「こんにちは 」と name をつなげた文字列に変える
    result_label.config(text=f"こんにちは {name}")
```

この関数を、

```python
# ボタンが押されたときに呼ぶ処理として show_greeting を指定する
command=show_greeting
```

でボタンへ登録しています。

つまり、

```text
ボタンを押す
    ↓
show_greeting を呼ぶ
    ↓
Entryから文字を取る
    ↓
Labelを書き換える
```

という流れです。

## Tk2-14. 変数も再利用している

3章で学んだ変数も使っています。

たとえば、

```python
# name に name_entry に入力された文字列を入れる

```

では、入力された名前を `name` に保存しています。

このコードは、あとで各部品を使うために、部品ごとに名前を付けています。

そのため、

```python

result_label
greet_button
```

のように名前を付けて保存しておきます。

GUIでは、入力内容を読む、表示を書き換える、ボタンを操作する、といった後の処理で同じ部品をもう一度使うことがよくあります。

## Tk2-16. 自分で変えてみる

表示する文章を変えてみてください。

たとえば、

```python
# result_label の表示を name と「さん、ようこそ！」をつなげた文字列に変える
result_label.config(text=f"{name}さん、ようこそ！")
```

にすると、

```text
たろうさん、ようこそ！
```

と表示できます。

ボタンの文字も、

```python
# ボタンに表示する文字を「表示する」にする
text="表示する"
```

のように自由に変更できます。

## Tk2-17. 入力が空だったら？

今のプログラムでは、名前を何も入力せずにボタンを押しても、

```text
こんにちは
```

と表示されます。

これはエラーではありません。

ただ、実際のアプリなら、

> 「名前を入力してください」

と表示したくなるかもしれません。

そのような処理では、5章で学んだ**条件分岐**が使えます。

GUIでも、これまで学んだ文法を組み合わせていきます。

## Tk2-18. ここまでで覚えること

この章で扱った内容をまとめます。

1. `Label` で文字を表示できる

4. `.get()` でEntryの内容を取り出せる
5. `config()` でLabelなどの表示を変更できる

9. 変数や関数など、これまでの基礎文法をGUIでもそのまま使える
