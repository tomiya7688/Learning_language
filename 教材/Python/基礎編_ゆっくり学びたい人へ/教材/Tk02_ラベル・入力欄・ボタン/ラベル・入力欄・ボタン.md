# Tk2. tkinterで名前を入力して挨拶する

空のウィンドウだけでは、数字を入力したりボタンを押したりできません。電卓を作るには、画面に入力欄やボタンを置く必要があります。

> **「画面は出たけど、何も操作できない！！！」**

この章では、名前を入力し、「挨拶する」ボタンを押すと、入力した名前を使った挨拶を表示するプログラムを作ります。名前を入力する場所はウィンドウ内の入力欄です。

## Tk2-1. 今回作るもの

ウィンドウには、文字を表示する部品（`Label`）、名前を入力する欄（`Entry`）、「挨拶する」ボタン（`Button`）を置きます。挨拶の結果も `Label` に表示します。

入力欄に `たろう` と入力して「挨拶する」ボタンを押すと、画面に `こんにちは たろう` と表示されます。

```text
名前を入力してください
[ たろう ]  ← ここが文字を入力する欄
[挨拶する]
こんにちは たろう
```

## Tk2-2. 部品と操作を `GreetingApp` にまとめる

この画面には、文字を表示する `Label`、文字を入力する欄 `Entry`、押して処理を始める `Button` があります。ボタンを押したときの処理は、入力欄から名前を読み取り、結果表示を書き換えます。部品をファイルの先頭に置き、処理を別々の場所へ書くと、どの処理がどの部品を使うのか見失いやすくなります。

そこで、ウィンドウ、部品、ボタンを押したときの処理を `GreetingApp` クラスにまとめます。こうすると、`GreetingApp` が自分の入力欄と表示欄を使って挨拶できます。

Tk01の `App` は空のウィンドウを表していました。この章では名前を使った挨拶の画面だと分かるように、クラス名を `GreetingApp`（挨拶のアプリ）にしています。Tk01と同様に、画面の準備を `__init__`、操作を待つ処理を `run()` に分けます。準備中に操作待ちを始めると、ウィンドウを閉じるまで `__init__` の実行が終わらず、`GreetingApp()` の次の行へ進めないためです。

画面の準備中に名前を読み取ると、利用者が入力する前の空の入力欄を読んでしまいます。入力した後にボタンを押したときだけ名前を読み取れるように、名前を読み取って挨拶を表示する処理を `show_greeting()` に分け、ボタンに実行する処理として指定します。

起動処理をファイルの先頭へ直接書くと、別のファイルから `import` で読み込んだときも画面が開きます。`GreetingApp()` で画面を準備し、`app.run()` で操作を待つ順番を `main()` にまとめ、ファイル末尾で直接実行された場合だけ `main()` を実行する形にします。

## Tk2-3. `app.py` 全体

[`app.py`](./app.py) を開いてください。この章のアプリを起動する入口の名前は `app.py` です。Tk01からTk07までは章ごとに別のフォルダを使い、起動ファイル名を `app.py` に揃えています。

このコードの元ファイル：[`app.py` 全体（1〜64行）](./app.py#L1-L64)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter


# 名前入力欄と挨拶表示をまとめる GreetingApp クラスを定義する
class GreetingApp:
    # GreetingApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.window に tkinter.Tk() で作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「挨拶アプリ」にする
        self.window.title("挨拶アプリ")
        # self.window の大きさを横400、縦220にする
        self.window.geometry("400x220")

        # self.name_label に名前の入力を案内するLabelを入れる
        self.name_label = tkinter.Label(self.window, text="名前を入力してください")
        # self.name_label を self.window 内に配置する
        self.name_label.pack()

        # self.name_entry に1行の名前入力欄を入れる
        self.name_entry = tkinter.Entry(self.window)
        # self.name_entry を self.window 内に配置する
        self.name_entry.pack()

        # self.greet_button に挨拶を表示するボタンを入れる
        self.greet_button = tkinter.Button(
            self.window,
            text="挨拶する",
            # ボタンを押したときに呼ぶ処理として self.show_greeting を登録する
            command=self.show_greeting,
        )
        # self.greet_button を self.window 内に配置する
        self.greet_button.pack()

        # self.result_label に空の文字列を表示するLabelを入れる
        self.result_label = tkinter.Label(self.window, text="")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

    # 入力された名前で挨拶する show_greeting を定義する
    def show_greeting(self):
        # name に self.name_entry から取り出した文字列を入れる
        name = self.name_entry.get()
        # self.result_label の表示を「こんにちは 」と name をつないだ文字列に変える
        self.result_label.config(text=f"こんにちは {name}")

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()


# アプリの起動処理を main にまとめる
def main():
    # app に GreetingApp() で作ったアプリを入れる
    app = GreetingApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

## Tk2-4. `self` はどのアプリを指すの？

`GreetingApp()` は、この画面の部品と処理をまとめたアプリを1つ作ります。クラスの中で使う `self` は、その作成中のアプリ自身を指します。

たとえば `self.name_entry` は「このアプリの名前入力欄」、`self.result_label` は「このアプリの結果表示欄」です。`self.` を付けて保存しておくと、ボタン処理など別のメソッドからも同じ部品を使えます。

このアプリを作る `__init__` は、ウィンドウと画面の部品を用意します。元ファイルは [`app.py` の5〜39行](./app.py#L5-L39)です。

## Tk2-5. `Label` で文字を表示する

`Label` はウィンドウに文字を表示する部品です。名前入力欄の説明と、挨拶の結果を表示するために使います。

このコードの元ファイル：[`app.py` の16〜19行](./app.py#L16-L19)。

```python
        # self.name_label に名前の入力を案内するLabelを入れる
        self.name_label = tkinter.Label(self.window, text="名前を入力してください")
        # self.name_label を self.window 内に配置する
        self.name_label.pack()
```

`tkinter.Label(self.window, ...)` は、`self.window` の中に置くLabelを作ります。`text` に指定した「名前を入力してください」が画面に表示されます。`pack()` は、作ったLabelをウィンドウに配置します。

## Tk2-6. `Entry` で名前を入力する

`Entry` は、利用者が1行の文字を入力する欄です。入力欄に名前を入力してください。

このコードの元ファイル：[`app.py` の21〜24行](./app.py#L21-L24)。

```python
        # self.name_entry に1行の名前入力欄を入れる
        self.name_entry = tkinter.Entry(self.window)
        # self.name_entry を self.window 内に配置する
        self.name_entry.pack()
```

`self.name_entry` は、あとでボタン処理が名前を読み取るために、入力欄を保存しておく名前です。画面上で文字を入力する場所は、この `Entry` です。

## Tk2-7. `Button` を押したときに処理する

`Button` は、利用者が押すボタンです。`command` に処理を指定すると、利用者がそのボタンを押したときに、Tkinterが指定した処理を呼び出します。

このコードの元ファイル：[`app.py` の26〜34行](./app.py#L26-L34)。

```python
        # self.greet_button に挨拶を表示するボタンを入れる
        self.greet_button = tkinter.Button(
            self.window,
            text="挨拶する",
            # ボタンを押したときに呼ぶ処理として self.show_greeting を登録する
            command=self.show_greeting,
        )
        # self.greet_button を self.window 内に配置する
        self.greet_button.pack()
```

`text="挨拶する"` は、ボタンに表示する文字です。`command=self.show_greeting` は、「挨拶する」ボタンが押されたときに `show_greeting` メソッドを呼ぶ指定です。

`command` に渡す `self.show_greeting` には `()` を付けません。`()` を付けた `self.show_greeting()` は、その場で処理を実行します。ボタンを作る時点ではなく、あとで押された時に動かしたいので、メソッド名を指定します。

比較用の説明例です。これは実ファイルへ書くコードではありません。

```python
command=self.show_greeting()
```

この例はボタンを作る時点で処理を呼び出してしまうため、ボタンを押した時に実行する指定になりません。正しいコードは、[`app.py` の31行](./app.py#L31)にある `command=self.show_greeting,` です。

## Tk2-8. `.get()` で入力欄の文字を取り出す

「挨拶する」ボタンを押すと、`show_greeting()` が実行されます。このメソッドは `self.name_entry.get()` で入力欄の文字を取り出します。

このコードの元ファイル：[`app.py` の41〜46行](./app.py#L41-L46)。

```python
    # 入力された名前で挨拶する show_greeting を定義する
    def show_greeting(self):
        # name に self.name_entry から取り出した文字列を入れる
        name = self.name_entry.get()
        # self.result_label の表示を「こんにちは 」と name をつないだ文字列に変える
        self.result_label.config(text=f"こんにちは {name}")
```

入力欄に `たろう` と入力した場合、`self.name_entry.get()` は文字列 `たろう` を取り出します。`name` は、その文字列を一時的に保存する変数です。

このコードで作る `self.name_entry` と、入力欄から取り出した文字列を保存する `name` は別のものです。`self.name_entry` は画面の部品、`name` は利用者が入力した文字です。

## Tk2-9. `config()` で挨拶を表示する

`self.result_label.config(...)` は、結果表示用Labelの設定を変更します。ボタンを押したときに、`text` を「こんにちは」と入力された名前をつないだ文字列へ変えます。

このコードの元ファイル：[`app.py` の45〜46行](./app.py#L45-L46)。

```python
        # self.result_label の表示を「こんにちは 」と name をつないだ文字列に変える
        self.result_label.config(text=f"こんにちは {name}")
```

挨拶を表示するLabelは、アプリを作るときに空の文字列で用意します。ボタンを押す前は何も表示せず、押した後に `config()` が表示を変えます。

このコードの元ファイル：[`app.py` の36〜39行](./app.py#L36-L39)。

```python
        # self.result_label に空の文字列を表示するLabelを入れる
        self.result_label = tkinter.Label(self.window, text="")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()
```

## Tk2-10. `pack()` で部品を画面に置く

部品を作っただけでは、ウィンドウに表示されません。`pack()` を呼び出すと、その部品をウィンドウ内に配置できます。

たとえば、[`app.py` の18〜19行](./app.py#L18-L19)では、名前の説明Labelをウィンドウに配置しています。

```python
        # self.name_label を self.window 内に配置する
        self.name_label.pack()
```

この章では、Label、Entry、Button、結果表示Labelの順に `pack()` を呼び出します。そのため、部品は上から順に並びます。

## Tk2-11. ボタンを押した後の流れ

利用者が名前を入力して「挨拶する」ボタンを押すと、プログラムは次の順に処理します。

1. Tkinterがボタンのクリックを受け取ります。
2. Tkinterが `self.show_greeting` を呼び出します。
3. `show_greeting()` が `self.name_entry.get()` で入力された名前を読み取ります。
4. `show_greeting()` が `self.result_label.config(...)` で挨拶を書き込みます。

ボタンを押すなど、画面上の出来事に応じて処理を実行する考え方を**イベント駆動**と呼びます。この章では、「ボタンが押された」という出来事がきっかけです。

## Tk2-12. `main()` からアプリを起動する

`main()` が `GreetingApp()` でアプリを作り、`app.run()` でウィンドウを表示します。起動の手順を `main()` にまとめると、アプリ全体を始める場所が `app.py` の中で分かります。

このコードの元ファイル：[`app.py` の54〜64行](./app.py#L54-L64)。

```python
# アプリの起動処理を main にまとめる
def main():
    # app に GreetingApp() で作ったアプリを入れる
    app = GreetingApp()
    # app のウィンドウを表示し、利用者の操作を待つ
    app.run()


# このファイルを直接実行したときだけ main() を呼び出す
if __name__ == "__main__":
    main()
```

`app.py` を直接実行すると、Pythonは `__name__` に `"__main__"` を設定します。そのため、最後の `main()` が動き、挨拶アプリのウィンドウが開きます。別のPythonファイルから `app.py` を読み込んだだけなら `main()` は動かず、ウィンドウも開きません。

## Tk2-13. 実行して名前を入力する

VS Codeで、この章の [`app.py`](./app.py) を開き、Ctrl + S（macOSではCommand + S）で保存してください。前に起動したTkinterのウィンドウが残っている場合は、そのウィンドウの閉じるボタンを押してください。前の実行を終えた場合は、VS Codeの **表示（View）→ ターミナル（Terminal）** を選び、実行に使ったターミナルで `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。

1. Windowsでは、エクスプローラーでこの章の `app.py` が入ったフォルダを開いてください。上部のアドレスバーをクリックし、表示されたフォルダのパスをCtrl + Cでコピーしてください。macOS / Linuxでは、VS Codeのエクスプローラーでこの章のフォルダを右クリックし、**パスのコピー（Copy Path）** を選んでください。
2. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んでターミナルを開き、次のコマンドを入力してください。引用符の中へ、手順1でコピーしたフォルダのパスを貼り付けてください。

   ```text
   cd "ここにコピーしたフォルダのパスを貼り付ける"
   ```

3. Enterキーを押してください。ターミナルの現在のフォルダが、この章の `app.py` のあるフォルダに変わります。
4. Windowsでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python app.py
   ```

   `python` が見つからないというメッセージが出た場合は、同じターミナルに `py app.py` と入力し、Enterキーを押してください。

   macOS / Linuxでは、同じターミナルに次のコマンドを入力し、Enterキーを押してください。

   ```text
   python3 app.py
   ```

ウィンドウが開いている間、Tkinterは操作を待ち続けるため、このターミナルには次のコマンドを入力できません。変更後にもう一度起動する場合は、先にウィンドウを閉じてください。

ウィンドウが開いたら、入力欄をクリックして名前を入力してください。「挨拶する」ボタンを押すと、結果表示欄に `こんにちは` と入力した名前が表示されます。

## Tk2-14. 挨拶の文章を変える

挨拶の文章を変える場合は、`app.py` の `GreetingApp.show_greeting` にある45〜46行を、説明コメントも含めて書き換えてください。変更する元の行は [`app.py` の45〜46行](./app.py#L45-L46)です。

次のコードは、45〜46行を置き換える変更後の例です。コメントも変更し、実際に表示する挨拶と説明を揃えてください。置き換える元の範囲：[`app.py` の45〜46行](./app.py#L45-L46)。

```python
        # self.result_label の表示を name の名前と「さん、ようこそ！」に変える
```

挨拶を変更した `app.py` を、次の手順で再実行してください。実行に使うターミナルの現在のフォルダは、Tk2-13で移動したこの章のフォルダのままです。

1. 起動中のアプリのウィンドウで、閉じるボタンを押してください。Tkinterが操作を待つ処理を終了し、実行に使ったターミナルでコマンドを入力できるようになります。
2. VS Codeで変更した `app.py` をCtrl + S（macOSではCommand + S）で保存してください。
3. VS Codeの **表示（View）→ ターミナル（Terminal）** を選んで、直前の実行に使ったターミナルを開いてください。ターミナルに `PS C:\...>` や `$` などの入力待ちの表示が戻ったことを確認してください。この表示は入力しないでください。
4. Windowsでは、同じターミナルに `python app.py` と入力し、Enterキーを押してください。直前に `py app.py` で起動した場合は、今回も `py app.py` と入力してEnterキーを押してください。macOS / Linuxでは、同じターミナルに `python3 app.py` と入力し、Enterキーを押してください。

`たろう` と入力して「挨拶する」ボタンを押すと、`たろうさん、ようこそ！` と表示されます。

## Tk2-15. 名前を入力しなかった場合

名前を入力せずに「挨拶する」ボタンを押すと、`name` は空の文字列です。配布版の `f"こんにちは {name}"` のままなら、プログラムは `こんにちは `（最後に半角スペースあり）を表示します。画面では末尾の空白が見えないため、`こんにちは` と表示されます。

Tk2-14「挨拶の文章を変える」で `f"{name}さん、ようこそ！"` へ変更した場合は、名前が空なので `さん、ようこそ！` と表示されます。表示する文章は、現在保存している挨拶の式によって変わります。どちらの場合も、入力欄が空という理由ではエラーになりません。

空の入力を受け付けたくない場合は、条件分岐を使って表示を変えられます。この章のコードにはその条件分岐を入れていないため、入力が空でも挨拶を表示します。
