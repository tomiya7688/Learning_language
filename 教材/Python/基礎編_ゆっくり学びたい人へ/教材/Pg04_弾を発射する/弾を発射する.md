# Pg4. pygame「弾を発射する」

Pg3では、プレイヤーを矢印キーで動かせるようになりました。

でも、まだ敵を攻撃できません。

> **「弾1発しか撃てんの？？？シューティングやぞ！」**

このプログラムは、スペースキーを押すとプレイヤーから弾を発射します。

そしてここで、リストが必要になります。

---

## Pg4-1. 今回作るもの

[player_shooting.py](./player_shooting.py) を開いてください。

`player` は「プレイヤー」、`shooting` は「射撃」という意味です。

スペースキーを押すたびに弾が増え、上へ飛んでいきます。

## Pg4-2. サンプルコード

### 画面更新の間隔を調整する `clock`

`pygame.time.Clock()` は、画面更新の間隔を調整するための時計を用意します。このプログラムは `clock` という名前で使い、繰り返しの最後にある `clock.tick(60)` で、1秒間の画面更新を最大60回に制限します。[pygameの公式説明](https://www.pygame.org/docs/ref/time.html#pygame.time.Clock.tick)

```python
# pygame をインポートする
import pygame

# pygame を初期化する
pygame.init()

# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
# pygame画面のタイトルに「弾を発射する」をセットする
pygame.display.set_caption("弾を発射する")

# 画面更新の間隔を調整する時計を用意する（後でclock.tick(60)に使う）
# clock に pygame.time.Clock() で作った時計を入れる
clock = pygame.time.Clock()

# player_x に320を入れる
player_x = 320
# player_y に400を入れる
player_y = 400
# player_speed に5を入れる
player_speed = 5

# bullets に空のリストを入れる
bullets = []
# bullet_speed に8を入れる
bullet_speed = 8

# running に True を入れる
running = True

# running が True の間、繰り返す
while running:
    # pygameで起きたイベントを1つずつ event に入れて繰り返す
    for event in pygame.event.get():
        # event.type が pygame.QUIT なら
        if event.type == pygame.QUIT:
            # running に False を入れる
            running = False

        # event.type が pygame.KEYDOWN なら
        if event.type == pygame.KEYDOWN:
            # event.key が pygame.K_SPACE なら
            if event.key == pygame.K_SPACE:
                # bullets に [player_x, player_y - 20] を追加する
                bullets.append([player_x, player_y - 20])

    # keys に pygame.key.get_pressed() の戻り値を入れる
    keys = pygame.key.get_pressed()

    # keys[pygame.K_LEFT] が True なら
    if keys[pygame.K_LEFT]:
        # player_x に player_x から player_speed を引いた値を入れる
        player_x = player_x - player_speed

    # keys[pygame.K_RIGHT] が True なら
    if keys[pygame.K_RIGHT]:
        # player_x に player_x と player_speed を足した値を入れる
        player_x = player_x + player_speed

    # keys[pygame.K_UP] が True なら
    if keys[pygame.K_UP]:
        # player_y に player_y から player_speed を引いた値を入れる
        player_y = player_y - player_speed

    # keys[pygame.K_DOWN] が True なら
    if keys[pygame.K_DOWN]:
        # player_y に player_y と player_speed を足した値を入れる
        player_y = player_y + player_speed

    # player_x に max(20, min(620, player_x)) の値を入れる
    player_x = max(20, min(620, player_x))
    # player_y に max(20, min(460, player_y)) の値を入れる
    player_y = max(20, min(460, player_y))

    # bullets から bullet を1つずつ取り出して繰り返す
    for bullet in bullets:
        # bullet[1] に bullet[1] から bullet_speed を引いた値を入れる
        bullet[1] = bullet[1] - bullet_speed

    # bullets に bullet[1] > -20 の bullet だけを入れる
    bullets = [bullet for bullet in bullets if bullet[1] > -20]

    # screen を (10, 10, 30) で塗る
    screen.fill((10, 10, 30))

    # player_points に (player_x, player_y - 20)、(player_x - 20, player_y + 20)、(player_x + 20, player_y + 20) を入れる
    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    # screen に (100, 200, 255) と player_points を使った多角形を描く
    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    # bullets から bullet を1つずつ取り出して繰り返す
    for bullet in bullets:
        # screen に (255, 240, 100) と (bullet[0] - 3, bullet[1] - 10, 6, 20) を使った四角形を描く
        pygame.draw.rect(
            screen,
            (255, 240, 100),
            (bullet[0] - 3, bullet[1] - 10, 6, 20)
        )

    # このフレームの描画内容を画面に反映する
    pygame.display.flip()

    # 1秒間に60回を上限にして clock を進める
    clock.tick(60)

# pygame を終了する
pygame.quit()
```

## Pg4-3. 弾は1個とは限らない

最初の1発だけなら、

```python
# bullet_x に player_x の値を入れる
bullet_x = player_x
# bullet_y に player_y の値を入れる
bullet_y = player_y
```

でも作れます。

でも2発目は？

```python
# bullet2_x に入れる値を ... で省略している
bullet2_x = ...
# bullet2_y に入れる値を ... で省略している
bullet2_y = ...
```

3発目は？

```python
# bullet3_x に入れる値を ... で省略している
bullet3_x = ...
# bullet3_y に入れる値を ... で省略している
bullet3_y = ...
```

> **「何発撃つか分からんのに、全部変数作るん？？？」**

それでは日が暮れます。

だから、

```python
# bullets に空のリストを入れる
bullets = []
```

というリストに弾をまとめます。

## Pg4-4. 弾を追加する

スペースキーを押したとき、

```python
# bullets に [player_x, player_y - 20] を追加する
bullets.append([player_x, player_y - 20])
```

としています。

これは、

> 今のプレイヤー位置から新しい弾を1個追加する

という意味です。

1発の弾は、

```python
[x, y]
```

の2つの数字で持っています。

---

## Pg4-5. なぜKEYDOWNを使うの？

プレイヤー移動では、

```python
# 現在どのキーが押されているかを取得する
pygame.key.get_pressed()
```

を使いました。

これは、キーを押している間ずっと動かしたいからです。

でも弾まで同じやり方にすると、スペースキーを押している間、毎フレーム弾が増えます。

60FPSなら1秒で何十発も出てしまいます。

なので今回は、

```python
# event.type が pygame.KEYDOWN なら
if event.type == pygame.KEYDOWN:
```

で、

> **キーを押した瞬間**

だけを見るようにしています。

---

## Pg4-6. スペースキーだけを見る

```python
# event.key が pygame.K_SPACE なら
if event.key == pygame.K_SPACE:
```

で、

> 押されたキーがスペースキーだったら

この `if` のコードで、プログラムは押されたキーがスペースキーかどうかを判定します。

これで、スペースキー1回につき弾1発になります。

---

## Pg4-7. 弾を動かす

```python
# bullets から bullet を1つずつ取り出して繰り返す
for bullet in bullets:
    # bullet[1] に bullet[1] から bullet_speed を引いた値を入れる
    bullet[1] = bullet[1] - bullet_speed
```

このコードで、プログラムはすべての弾を上へ動かします。

1発の弾は、

```python
[x, y]
```

なので、

```python
bullet[0]
```

がx、

```python
bullet[1]
```

がyです。

このプログラムは、弾を上へ動かすためにyの値を減らします。

## Pg4-8. ここでも「まとめる」が効く

弾が10発あっても、

```python
# bullets から bullet を1つずつ取り出して繰り返す
for bullet in bullets:
```

と書けば、全部に同じ処理をできます。

`bullets` は、画面にある弾をまとめて保存するリストです。`for bullet in bullets` は、そのリストから弾を1つずつ取り出し、同じ処理を行います。リストの詳しい説明は[10章「リスト」](../10_リスト/リスト.md)にあります。

## Pg4-9. 画面外の弾を消す

そのままだと、画面の外へ飛んでいった弾もずっとリストに残ります。

見えないのにデータだけ増え続けます。

> **「もう画面におらん弾までいつまで覚えとんねん！」**

なので、

```python
# bullets に bullet[1] > -20 の bullet だけを入れる
bullets = [bullet for bullet in bullets if bullet[1] > -20]
```

このコードで、プログラムはまだ画面の近くにいる弾だけ残します。

## Pg4-10. リスト内包表記で画面外の弾を除く

```python
# bullets に bullet[1] > -20 の bullet だけを入れる
bullets = [bullet for bullet in bullets if bullet[1] > -20]
```

この書き方をリスト内包表記と呼びます。このコードは `for` で `bullets` の弾を1つずつ確認し、`if` の条件 `bullet[1] > -20` を満たす弾だけで新しいリストを作ります。リスト内包表記の詳しい説明は[10章「リスト」](../10_リスト/リスト.md)にあります。

## Pg4-11. 弾を描く

弾は動くだけでは見えないので、1発ずつ四角形として描きます。

```python
# bullets から bullet を1つずつ取り出して繰り返す
for bullet in bullets:
    # screen に (255, 240, 100) と (bullet[0] - 3, bullet[1] - 10, 6, 20) を使った四角形を描く
    pygame.draw.rect(
        screen,
        (255, 240, 100),
        (bullet[0] - 3, bullet[1] - 10, 6, 20)
    )
```

まず、

```python
# bullets から bullet を1つずつ取り出して繰り返す
for bullet in bullets:
```

で、`bullets` に入っている弾を1発ずつ取り出しています。

- `bullets` → 弾全部をまとめたリスト
- `bullet` → 今から描く弾1発
- `bullet[0]` → その弾の横位置
- `bullet[1]` → その弾の縦位置

です。

### `pygame.draw.rect()` の3つの入力

`pygame.draw.rect()` は四角形を描く関数です。

今回は左から順に、

```text
screen
→ どの画面へ描くか

(255, 240, 100)
→ 何色で描くか

(bullet[0] - 3, bullet[1] - 10, 6, 20)
→ 四角形の左端・上端・幅・高さ
```

を渡しています。

`(255, 240, 100)` はRGBです。

```text
赤 = 255
緑 = 240
青 = 100
```

なので、明るい黄色系の弾になります。

ここでの255・240・100は**色の強さ**です。次に出てくる3・10・6・20は**ゲーム画面上のピクセル数**なので、同じ数字でも意味が違います。

### 最後の4つの数字を読む

四角形を指定している部分は、

```python
(bullet[0] - 3, bullet[1] - 10, 6, 20)
```

です。

`pygame.draw.rect()` に渡す四角形は、

```text
左端のx
上端のy
幅
高さ
```

の順です。

そのため今回は、

```text
bullet[0] - 3
→ 四角形の左端

bullet[1] - 10
→ 四角形の上端

6
→ 幅6ピクセル

20
→ 高さ20ピクセル
```

となります。

### なぜ3と10を引くの？

弾を追加するときは、

```python
# bullets に [player_x, player_y - 20] を追加する
bullets.append([player_x, player_y - 20])
```

として、弾の位置を1つの点として記録しています。

このコードでは、その点が**弾の中心**です。

一方、四角形を描くときは左上の位置が必要です。

幅は6ピクセルなので、その半分は3ピクセルです。

```text
6 ÷ 2 = 3
```

高さは20ピクセルなので、その半分は10ピクセルです。

```text
20 ÷ 2 = 10
```

そこで中心から、

- 左へ3ピクセル
- 上へ10ピクセル

このプログラムは、ずらした場所を四角形の左上にします。

つまり、

```python
bullet[0] - 3
bullet[1] - 10
```

としているのは、**幅6・高さ20の四角形の中心を、弾として記録した座標へ合わせるため**です。

```python
# bullet_speed に8を入れる

```

数字を変えると、


なら遅く、

## Pg4-14. 自分で変えてみる

### 弾を速くする

`player_shooting.py` の **26行目** を変更してください。

VS Codeで **Ctrl + F**、macOSでは **Command + F** を押して、

```text
bullet_speed = 8
```

を検索してください。

変更前:

```python
# bullet_speed に8を入れる
bullet_speed = 8
```

変更後:

```python
# bullet_speed に12を入れる
bullet_speed = 12
```

保存して、もう一度 `player_shooting.py` を実行してください。

スペースキーで撃った弾が、変更前より速く上へ進めば成功です。

### 弾を太くする

今度は **102行目** を変更してください。

Ctrl + F、macOSではCommand + Fで、

```text
(bullet[0] - 3, bullet[1] - 10, 6, 20)
```

を検索してください。

変更前:

```python
(bullet[0] - 3, bullet[1] - 10, 6, 20)
```

変更後:

```python
(bullet[0] - 5, bullet[1] - 10, 10, 20)
```

幅を6ピクセルから10ピクセルへ変えました。

幅10の半分は5なので、中心を同じ位置へ合わせるため、

```python
bullet[0] - 3
```

も、

```python
bullet[0] - 5
```

へ変えてください。

幅だけ10へ変えて `-3` のままにすると、四角形の中心が弾として記録している横位置からずれてしまいます。

保存して再実行し、弾の中心位置はほぼそのままで横幅だけ太くなれば成功です。

## Pg4-16. ここまでで覚えること

1. 弾が複数あるのでリストにまとめる
2. `append()` で新しい弾を追加できる
3. `KEYDOWN` でキーを押した瞬間を扱える
4. `pygame.K_SPACE` でスペースキーを判定できる
5. `for` で全部の弾を動かせる
6. 上へ動かすにはyを減らす
7. 画面外の弾はリストから消す
8. `pygame.draw.rect()` で弾を描ける
9. 同じ種類のものが増えるとき、リストへまとめると扱いやすい
