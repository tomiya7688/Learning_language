# Pg4. pygame「弾を発射する」

Pg3では、プレイヤーを矢印キーで動かせるようになりました。でも、シューティングゲームなのに、まだ弾を撃てません。

> **「動くだけ？弾を撃ちたい！」**

この章のプログラムは、スペースキーを押すたびに自機から弾を発射します。前の弾が飛んでいる間にも、次の弾を撃てます。敵は次の章で加えるため、今回は弾が上へ飛んでいくところを確かめてください。

## 起動してから1回の更新が終わるまで

`main.py` の `main()` がpygameを初期化し、`Game()` を作って `run()` を呼びます。`Game` は画面と時計を持ち、入力・更新・描画を順に呼びます。`Battle` は1回の戦闘の自機・敵・弾を管理します。移動と描画は各機体や弾自身のメソッド（クラス内の関数）へ任せます。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

`main.py` の最後の `if __name__ == "__main__":` は、直接実行したときだけmain()を呼ぶ条件です。補助ファイルを読み込んだだけではゲームを起動しません。`finally` のpygame.quit()はエラーが起きた場合も終了時の片付けを行います。

### 起動用の `main.py`

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # game はゲーム全体。起動・繰り返し・画面切り替えを担当します。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 弾が増えたら、役割ごとにファイルを分ける

自機の位置、何発もの弾、キー入力、描画を1つの繰り返しへ足していくと、弾を直したいのにゲーム全体から探すことになります。自機は `player.py`、弾は `bullet.py`、戦闘の更新は `battle.py`、画面の繰り返しは `game.py` へ分けてください。

Pythonのコードを書いた `.py` ファイルを、別のファイルから読み込むときは `import` を使います。このように読み込めるファイルを「モジュール」と呼びます。

`from player import Player` は、同じフォルダの `player.py` から `Player` を読み込む指定です。`.py` は書きません。`import settings` は `settings.py` を読み込み、`settings.PLAYER_SPEED` のようにファイルの名前を付けて中の値を使います。

読み込んだだけでゲームが起動しないように、起動処理を `main()` と `if __name__ == "__main__":` の中に置いてあります。起動するPythonファイルは `main.py` です。`player.py` や `settings.py` を単独で実行してもゲームは始まりません。

### `Game` と `Battle` の役割

`Game`（ゲーム）は描画先・時計・実行中の状態を持ちます。`run`（実行）は「入力を受け取る → 更新する → 描く → 表示する → 次の更新まで待つ」という順序だけを扱います。

`Battle`（戦闘）は自機と弾の一覧を持ち、`handle_event`（操作を受け取る）、`update`（状態を更新する）、`draw`（描く）に処理を分けています。自機そのものの移動や発射は `Player` に任せます。これで、弾の移動を探すときは `Bullet.move()` を開けます。

### 弾1発を `Bullet` にする

`Bullet`（弾）は `rect`（位置と大きさ）、`speed`（縦方向の速さ）、`color`（赤・緑・青の色）を持ちます。自機は `shoot`（発射）で弾を1発作り、戦闘側の `bullets`（弾の一覧）へ加えます。弾の一覧は `[]` で空から始まり、`append` で要素を末尾へ加えます。

自機の弾は幅6、高さ20ピクセル、速さは `-8` です。yが減ると上へ動くため、上向きは負の値にします。`is_off_screen`（画面外か）は、弾の下辺が0より上、または上辺が画面の高さより下にあるかを返します。

`bullets[:]` は弾の一覧のコピーです。元の一覧から弾を削除しながらコピーを順に読むことで、隣の弾を飛ばさず処理できます。`return` は呼び出した側へ結果を返す指定です。

`settings.py` の大文字の名前は、この例では固定した設定値を表します。たとえば `PLAYER_SPEED` は自機の速さ、`BULLET_SPEED` は弾の速さです。大文字だからPythonが書き換えを禁止するわけではありません。

## 設定値の場所と意味

`settings.py` の値はこの章の初期設定です。位置と大きさの単位はピクセル、速さは1回の更新で動くピクセル数、間隔は更新回数です。最大60回/秒の場合、90回は約1.5秒、120回は約2秒です。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | 画面の幅 | `640` |
| `HEIGHT` | 画面の高さ | `480` |
| `FPS` | 1秒あたりの更新回数の上限 | `60` |
| `PLAYER_X` | 自機の最初の中心の横位置 | `320` |
| `PLAYER_Y` | 自機の最初の中心の縦位置 | `400` |
| `PLAYER_SPEED` | 自機の移動の速さ | `5` |
| `BULLET_SPEED` | 自機の弾の速さ（発射時に負にして上へ動かす） | `8` |

自機の中心(320, 400)は画面の中央より下です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。

### `game.py` の `Game.run`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# run の処理を定義する
def run(self):
    # self.running が成り立つ間、繰り返す
    while self.running:
        # self.handle_events() を実行する
        self.handle_events()
        # not self.running が成り立つなら
        if not self.running:
            # この繰り返しを終える
            break

        # self.battle.update() を実行する
        self.battle.update()

        # self.battle.draw(self.screen) を実行する
        self.battle.draw(self.screen)

        # pygame.display.flip() を実行する
        pygame.display.flip()
        # self.clock.tick(settings.FPS) を実行する
        self.clock.tick(settings.FPS)
```

### `bullet.py` の `Bullet`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# Bullet という型を定義する
class Bullet:
    # __init__ の処理を定義する
    def __init__(self, x, y, speed, size, color):
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, size[0], size[1]) を入れる
        self.rect = pygame.Rect(0, 0, size[0], size[1])
        # self.rect.center に (x, y) を入れる
        self.rect.center = (x, y)
        # speed は速さ。1回の更新で動く距離で、単位はピクセルです。
        # self.speed に speed を入れる
        self.speed = speed
        # color は色。赤・緑・青の強さを0〜255で指定します。
        # self.color に color を入れる
        self.color = color

    # move の処理を定義する
    def move(self):
        # self.rect.y に self.speed を足す
        self.rect.y += self.speed

    # is_off_screen の処理を定義する
    def is_off_screen(self):
        # self.rect.bottom < 0 or self.rect.top > settings.HEIGHT を返す
        return self.rect.bottom < 0 or self.rect.top > settings.HEIGHT

    # draw の処理を定義する
    def draw(self, screen):
        # pygame.draw.rect(screen, self.color, self.rect) を実行する
        pygame.draw.rect(screen, self.color, self.rect)
```

## 実行したときの画面と操作

矢印キーで動かし、Spaceキーを押すと黄色い弾が上へ飛びます。押して離す操作を繰り返すと続けて撃てます。

キー操作はゲームのウィンドウをクリックしてから行ってください。

Spaceキーは押して離すたびに1発出ます。矢印キーは押している間、移動します。

## 保存先へ移動して `main.py` を実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の `main.py` を保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python main.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。

## 1か所変えて比べる

VS Codeで `settings.py` を開き、Windows / LinuxはCtrl + F、macOSはCommand + Fで `BULLET_SPEED = 8` を検索してください。弾の速さを8から12へ変更してください。Windows / LinuxはCtrl + S、macOSはCommand + Sで保存してください。

再実行は、VS Codeの **表示 → ターミナル** で先ほどのターミナルを開いてください。Windowsは `.\.venv\Scripts\python.exe main.py`、macOS / Linuxは `.venv/bin/python main.py` を入力してEnterキーを押してください。変更前と比べてください。閉じる前のウィンドウがあれば、先に閉じてください。
