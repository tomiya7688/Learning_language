# Pg16. pygame「クリア画面を作る」

Pg14まででボスを倒せるゲームになりました。でも、倒した瞬間に画面が閉じてしまい、勝った結果を画面で見られません。

> **「ボス倒した瞬間ウィンドウ消えるんかい！！！」**

この章では、ボスを倒したあとにGAME CLEAR!と表示するクリア画面を作ってください。その画面では戦闘を進めず、結果を表示したままにします。

画面の切り替わりは、次の2つです。

```text
ゲーム中
↓
クリア画面
```

## 起動してから1回の更新が終わるまで

`main.py` はPygameを使う準備をして、`game.py` の `Game.run()` を始めます。`Game.run()` は閉じる操作を確かめてから、現在の画面を更新し、描いた内容をウィンドウへ表示します。戦闘中は `PlayingScreen.update()` が自機・敵・弾を動かし、タイトル・クリア・ゲームオーバーの画面では戦闘を進めません。

`game.py` は、いま表示する画面を `current_screen` に保存します。`Game.run()` は繰り返しのたびに `current_screen.handle_event()` へ操作を渡し、`current_screen.update()` で画面の状態を変え、`current_screen.draw(self.screen)` で絵や文字を描きます。`pygame.display.flip()` が描いた内容をウィンドウに表示します。`PlayingScreen.update()` だけが戦闘中の自機・敵・弾を動かします。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

`main.py` を直接実行すると、Pythonは `main()` を動かし、`game.py` の `Game` がゲーム画面を開きます。別のPythonファイルから `main.py` を読み込んだだけでは、`main()` は動かず、ウィンドウも開きません。読者がウィンドウの閉じるボタンを押すと、`Game.handle_events()` は `pygame.event.get()` から閉じる操作の知らせ `pygame.QUIT` を受け取り、`self.running` を `False` にします。`Game.run()` はその値を見て画面更新の繰り返しを終え、`main.py` に戻ります。

`main.py` の `try:` の下にはゲームの起動と実行を書きます。Pythonはその処理が正常に終わった場合も途中でエラーが起きた場合も、`finally:` の下にある `pygame.quit()` を実行してPygameを終了します。エラーが起きた場合は、Pygameを終了してからPythonがエラーを表示します。

### 起動用の `main.py`

このコードの元ファイル：[`main.py` の 1〜24行](./main.py#L1-L24)。

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # Pythonは try: の処理が終わったときもエラーで中断したときも、finally: の下の pygame.quit() を実行する
    try:
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygameを終了する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 戦闘中とクリア後を、別の画面として扱う

戦闘中の描画へクリアの文字を足すだけだと、その裏で敵の弾や自機が動き続けます。画面ごとに入力・更新・描画を分け、戦闘を更新するのは `PlayingScreen`（戦闘画面）だけにします。

`playing_view.py` に `PlayingScreen`、`clear_view.py` に `ClearScreen`（クリア画面）を置きます。`view` は表示する画面という意味です。どちらも `handle_event(event)`、`update()`、`draw(screen)` を用意します。Gameは `current_screen`（現在の画面）のこの3つを呼ぶだけです。

`PlayingScreen.update()` が戦闘を進め、自機のHP、ボスのHPの順に結果を調べます。ボスを倒したら `Game.show_clear()` が現在の画面を `ClearScreen` へ替えます。自機とボスが同時に倒れた場合は自機が倒れた結果を優先します。この章では自機が倒れると終了します。

`ClearScreen.update()` はすぐに `return` するため、戦闘を進めません。クリア画面は `GAME CLEAR!` と `You defeated the boss!`（ボスを倒した！）を描きます。`heading_font` は見出し用72、`sub_font` は補足用32ピクセルです。`Font(None, ...)` のNoneはpygame同梱の標準フォントの指定で、英数字を表示します。

文字を中央へ置く処理は `ui.py` の `draw_centered_text`（中央に文字を描く）へまとめます。文字の画像を作り、その長方形の中心を指定して画面へ描きます。

## 設定値の場所と意味

`settings.py` は、ゲーム内容を調整する数値をまとめた Python ファイルです。`PLAYER_SPEED = 5` は、自機を押した矢印の方向へ画面更新1回あたり5ピクセル動かします。縦横の矢印キーを同時に押すと、両方向へそれぞれ5ピクセル動きます。`player.py` は `settings.PLAYER_SPEED` を使って自機を動かします。`game.py` は `settings.WIDTH` と `settings.HEIGHT` で画面の幅と高さを決め、`settings.FPS` で1秒あたりの画面更新回数の上限を決めます。

画面を1回更新するとは、ゲーム内の位置や状態を進めて、画面を書き直すことです。画面の位置・幅・高さはピクセル（画面上の点1つ）で表します。速さは1回の画面更新で動くピクセル数、敵の出現間隔や弾の発射間隔は次の動作までの画面更新回数です。間隔の数値は秒ではありません。`FPS = 60` は1秒間に画面を更新する回数の上限を60回にします。画面が毎秒60回更新されているときは、60回が約1秒、90回が約1.5秒、120回が約2秒です。更新が毎秒60回より少ない場合は、間隔にかかる時間が長くなります。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | ゲーム画面の横幅（ピクセル） | `640` |
| `HEIGHT` | ゲーム画面の縦幅（ピクセル） | `480` |
| `FPS` | ゲーム画面を1秒間に更新する回数の上限（回/秒） | `60` |
| `PLAYER_X` | 自機の最初の中心位置。画面左端からの距離（ピクセル） | `320` |
| `PLAYER_Y` | 自機の最初の中心位置。画面上端からの距離（ピクセル） | `400` |
| `PLAYER_SPEED` | 押した矢印の方向へ1回の画面更新で進む距離。縦横同時に押すと両方向へ進みます（ピクセル/回） | `5` |
| `BULLET_SPEED` | 自機の弾が画面を1回更新する間に上へ動く距離（ピクセル/回） | `8` |
| `ENEMY_SPEED` | 通常の敵が画面を1回更新する間に下へ動く距離（ピクセル/回） | `1` |
| `PLAYER_HP` | 自機がゲーム開始時に持つ体力の値 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾が画面を1回更新する間に下へ動く距離（ピクセル/回） | `4` |
| `SPAWN_POSITIONS_X` | 敵を出す順に並べた横位置。各値は画面左端から敵の中心までの距離（ピクセル） | `(120, 320, 520, 220, 420, 100, 540)` |
| `SPAWN_INTERVAL` | 次の敵が出現するまでの画面更新回数。90回なら約1.5秒（FPS=60の場合） | `90` |
| `ENEMY_FIRE_INTERVALS` | 出現順の敵ごとに、次の弾を撃つまでの画面更新回数を並べた一覧 | `(60, 90, 120, 75, 105, 80, 110)` |
| `BOSS_X` | ボスの中心位置。画面左端からの距離（ピクセル） | `320` |
| `BOSS_Y` | ボスの中心位置。画面上端からの距離（ピクセル） | `90` |
| `BOSS_HP` | ボスが登場したときに持つ体力の値 | `50` |
| `BOSS_BULLET_SPEED` | ボスの弾が画面を1回更新する間に下へ動く距離（ピクセル/回） | `4` |
| `BOSS_FIRE_INTERVAL` | ボスが次の弾を撃つまでの画面更新回数。120回なら約2秒（FPS=60の場合） | `120` |
| `BOSS_BULLET_WIDTH` | ボスの弾の横幅（ピクセル） | `48` |
| `BOSS_BULLET_HEIGHT` | ボスの弾の高さ（ピクセル） | `48` |
| `BACKGROUND_SPEED` | 背景が画面を1回更新する間に下へ動く距離（ピクセル/回） | `2` |

自機の中心(320, 400)は画面の中央より下、ボスの中心(320, 90)は上側です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。機体の `rect` は位置と大きさを一緒に持ち、移動・描画・命中に同じ長方形を使います。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `playing_view.py` の `PlayingScreen`

[`playing_view.py` の1〜34行](./playing_view.py#L1-L34)にある `PlayingScreen` の定義を、下のコードに置き換えてください。

このコードの元ファイル：[`playing_view.py` の 1〜34行](./playing_view.py#L1-L34)。

```python
# PlayingScreen という型を定義する
class PlayingScreen:
    # __init__ の処理を定義する
    def __init__(self, game):
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # self.game に game を入れる
        self.game = game

    # handle_event の処理を定義する
    def handle_event(self, event):
        # self.game.battle.handle_event(event) を実行する
        self.game.battle.handle_event(event)

    # update の処理を定義する
    def update(self):
        # self.game.battle.update() を実行する
        self.game.battle.update()
        # self.game.battle.is_game_over() が成り立つなら
        if self.game.battle.is_game_over():

            # print('GAME OVER') を実行する
            print("GAME OVER")
                        # self.game.running を False にし、ゲーム画面の繰り返しを終える
            self.game.running = False

        # self.game.battle.is_clear() が成り立つなら
        elif self.game.battle.is_clear():
            # self.game.show_clear() を実行する
            self.game.show_clear()

    # draw の処理を定義する
    def draw(self, screen):
        # self.game.battle.draw(screen) を実行する
        self.game.battle.draw(screen)
```

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。
