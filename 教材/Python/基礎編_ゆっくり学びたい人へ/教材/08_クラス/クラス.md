# 8. クラス

7章では、[挨拶文を作る処理を `make_greeting` 関数](../07_関数/greeting_function.py#L1-L5)にまとめました。今回は、たろうとはなこの名前に点数も加え、生徒ごとの結果を表示します。名前と点数を別々に扱うと、表示するときに違う生徒の点数を組み合わせてしまうことがあります。

> **「この80点、誰の点数？名前と点数をセットで扱いたい！」**

生徒ひとり分の名前と点数を一緒に持たせ、その生徒の結果を表示する処理もまとめたいところです。Pythonで情報と処理を持つ新しい種類の値を定義する書き方を、**クラス** と呼びます。この章では、生徒を表す `Student` クラスを使ってください。`Student` は「生徒」という意味です。

## 8-1. 名前と点数が別々だと何に困る？

7章で学んだ関数を使い、名前と点数を表示する書き方から考えます。次は比較用の例です。実際に保存するコードは8-3にあります。

```python
# name1（1人目の名前）に「たろう」を保存します。
name1 = "たろう"
# score1（1人目の点数）に80を保存します。
score1 = 80
# name2（2人目の名前）に「はなこ」を保存します。
name2 = "はなこ"
# score2（2人目の点数）に95を保存します。
score2 = 95

# show_result は「結果を表示する」という意味です。
# name（名前）と score（点数）を受け取る関数を定義します。
def show_result(name, score):
    # name と score をコロンで区切って表示します。
    print(name, ":", score)

# 1人目の名前と点数で show_result を呼び出します。
show_result(name1, score1)
# 2人目の名前と点数で show_result を呼び出します。
show_result(name2, score2)
```

`show_result(name1, score1)` は `たろう : 80`、`show_result(name2, score2)` は `はなこ : 95` と表示します。ところが、呼び出すときに `show_result(name1, score2)` と組み合わせると、たろうの名前に、はなこの95点が付いてしまいます。

名前と点数をひとり分ずつ持つ値にすれば、表示するたびに名前用と点数用の変数を組み合わせずに済みます。`Student` クラスには、その生徒の名前・点数と、その情報を使って結果を表示する処理をまとめます。

## 8-2. 生徒ひとり分の情報と処理をまとめる

`Student` クラスから作る生徒ひとり分の値を **インスタンス** と呼びます。たろうとはなこには、それぞれ別のインスタンスを作ってください。

インスタンスに持たせる名前や点数などの情報を **属性** と呼びます。`name` は「名前」、`score` は「点数」という意味で、`Student` の属性名にも使います。

名前と点数は、生徒を作るときに受け取って保存する必要があります。その処理を `__init__` という関数に書きます。`__init__` は、作った生徒に最初の名前と点数を保存するために、Pythonが実行する関数です。`self` は、その関数がいま扱っている生徒ひとり分を受け取る名前です。

結果の表示も、生徒自身が持つ名前と点数を使う処理なので、`Student` の中の `show_result` という関数にまとめます。クラスの中に定義した関数を **メソッド** と呼びます。

元ファイル：[`student_class.py` の1〜14行](./student_class.py#L1-L14)。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）を、その生徒の name 属性（名前を保存する場所）に保存します。
        self.name = name
        # score（受け取った生徒の点数）を、その生徒の score 属性（点数を保存する場所）に保存します。
        self.score = score

    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`self.name = name` は、受け取った名前 `name` を、その生徒の属性 `self.name` に保存する行です。`self.score = score` は、受け取った点数 `score` を、その生徒の属性 `self.score` に保存する行です。

`name` と `self.name` は別の名前です。`name` は `__init__` が受け取る値の名前、`self.name` はその生徒に保存した名前を使うための書き方です。今回のPythonコードでは、`self.name` を作るための宣言を別の行に書く必要はありません。`self.name = name` の行で属性を作り、値を保存します。

## 8-4. `class` の書き方と範囲

クラスを定義するときは、`class`、空白、クラス名、`:` の順に書いてください。今回の定義は `class Student:` です。

`Student` に入れるメソッドの `def` は、`class Student:` より半角スペース4個分右に字下げしてください。メソッドの処理は、`def` よりさらに半角スペース4個分右に字下げしてください。この字下げを **インデント** と呼びます。

元ファイル：[`student_class.py` の1〜9行](./student_class.py#L1-L9)。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）を、その生徒の name 属性（名前を保存する場所）に保存します。
        self.name = name
        # score（受け取った生徒の点数）を、その生徒の score 属性（点数を保存する場所）に保存します。
        self.score = score
```

`main` は `Student` クラスの外に置くので、`def main():` の行頭を字下げしません。`Student` クラスの範囲は、その手前までです。

## 8-5. `__init__` で受け取った値はどこへ入る？

`Student("たろう", 80)` を実行すると、Pythonはたろうのインスタンスを作り、`__init__` に次の値を渡します。

| `__init__` の中の名前 | この呼び出しで使う値 | この例での使い方 |
| --- | --- | --- |
| `self` | 今作った、たろうのインスタンス | 名前と点数を持たせる対象 |
| `name` | `"たろう"` | `self.name` に保存 |
| `score` | `80` | `self.score` に保存 |

元ファイル：[`student_class.py` の3〜9行](./student_class.py#L3-L9)。

```python
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）を、その生徒の name 属性（名前を保存する場所）に保存します。
        self.name = name
        # score（受け取った生徒の点数）を、その生徒の score 属性（点数を保存する場所）に保存します。
        self.score = score
```

`Student("たろう", 80)` の括弧には、名前と点数の2つを指定します。`self` に入るインスタンスはPythonが渡すので、呼び出す側で `self` を書く必要はありません。

はなこを作る `Student("はなこ", 95)` では、別のインスタンスに名前と点数が保存されます。はなこを作っても、たろうの名前と80点はそのまま残ります。

## 8-6. 関数もクラスにまとめられる

**関数もクラスにまとめられる**ので、`show_result` を `Student` の中に定義しています。クラスの中の関数をメソッドと呼びます。

元ファイル：[`student_class.py` の11〜14行](./student_class.py#L11-L14)。

```python
    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`student.show_result()` を実行すると、Pythonは `student` が表す生徒を `self` に渡します。`show_result` は、その生徒の `self.name` と `self.score` を表示します。

## 8-7. 字下げはどの処理に属するかを表す

元ファイル：[`student_class.py` の11〜14行](./student_class.py#L11-L14)。


## 8-10. `self` は、どちらの生徒？

`self` という名前が常にたろうを表すわけではありません。`show_result` の `self` は、メソッドを呼び出した生徒を受け取ります。

| メソッドの呼び出し | `show_result` の `self` が受け取る生徒 | 表示 |
| --- | --- | --- |
| `student.show_result()` | `student` が表す、たろう | `たろう : 80` |
| `student2.show_result()` | `student2` が表す、はなこ | `はなこ : 95` |

元ファイル：[`student_class.py` の11〜14行](./student_class.py#L11-L14)。

```python
    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`self.name` は、その呼び出しで受け取った生徒の名前です。`self.score` も同じ生徒の点数なので、`show_result` を呼び出す側で名前と点数を別々に組み合わせる必要がありません。

## 8-11. 関数との関係

7章の関数は、挨拶文を作る処理を名前で呼び出すために使いました。8章の `Student` は、生徒ひとり分の情報と、その情報を使う処理をまとめるために使っています。

関数はクラスの中にも外にも定義できます。今回の `show_result` は生徒の情報を使うので `Student` の中、`main` は生徒を作って表示する順序を決めるのでクラスの外にあります。

### 名前だけを表示するメソッドを加える

生徒の名前だけを表示する場所が増えたとき、毎回 `print(student.name)` や `print(student2.name)` と書く代わりに、名前の表示も生徒の処理としてまとめられます。`Student` に、名前だけを表示する `show_name` メソッドを加えてください。`show_name` は「名前を表示する」という意味です。

次は、直前の学級名付きコードに `show_name` と、はなこの名前を表示する呼び出しを加えた変更例です。`student_class.py` の全体を次のコードに置き換えてください。直前の学級名付きコードの1〜49行が対象です。先頭のコメントから末尾の `main()` まで置き換えてください。Ctrl + F（macOSはCommand + F）で `class Student:` を探すか、Ctrl + A（macOSはCommand + A）で全体を選んでください。

変更例のもとにする配布版：[student_class.py 全体（1〜43行）](./student_class.py#L1-L43)。次は、学級名と名前表示を加えた変更後のコードです。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score, class_name):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）を、その生徒の name 属性（名前を保存する場所）に保存します。
        self.name = name
        # score（受け取った生徒の点数）を、その生徒の score 属性（点数を保存する場所）に保存します。
        self.score = score
        # class_name（学級名）を、この生徒の class_name 属性に保存します。
        self.class_name = class_name

    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)

    # この生徒の名前だけを表示する処理を定義します。
    def show_name(self):
        # この生徒の name 属性（名前）を表示します。
        print(self.name)


# main（主な処理）に、生徒を作って表示する順序をまとめます。
def main():
    # Student（生徒）から、たろうのインスタンスを作ります。
    # student（たろうの生徒データを使う名前）で、この生徒のインスタンスを使えるようにします。
    student = Student("たろう", 80, "A")

    # student（たろうの生徒データ）の name（名前）を表示します。
    print(student.name)

    # student（たろうの生徒データ）の score（点数）を表示します。
    print(student.score)

    # student（たろうの生徒データ）の show_result（結果表示）を実行します。
    student.show_result()
    # student（たろう）の class_name（学級名）を表示します。
    print(student.class_name)

    # Student（生徒）から、はなこのインスタンスを作ります。
    # student2（はなこの生徒データを使う名前）で、この生徒のインスタンスを使えるようにします。
    student2 = Student("はなこ", 95, "B")

    # student2（はなこの生徒データ）の show_result（結果表示）を実行します。
    student2.show_result()
    # student2（はなこ）の class_name（学級名）を表示します。
    print(student2.class_name)
    # student2（はなこ）の show_name（名前表示）を実行します。
    student2.show_name()


# このファイルを直接実行した場合かどうかを調べます。
if __name__ == "__main__":
    # 生徒を作って表示する main を呼び出します。
    main()
```

`student_class.py` を保存し、同じターミナルで `python student_class.py`（Windows）または `python3 student_class.py`（macOS / Linux）をもう一度実行してください。次の7行が表示されます。

```text
たろう
80
たろう : 80
A
はなこ : 95
B
はなこ
```

最後の `はなこ` は、追加した `student2.show_name()` の表示です。`show_name` の `self` は、はなこのインスタンスを受け取っています。

## 8-14. 今回の内容

- クラスは、情報と処理を持つ新しい種類の値を定義する書き方。
- `Student(...)` は、生徒ひとり分のインスタンスを作る。
- `__init__` は、作るときに受け取った名前と点数を属性に保存する。
- `student` は生徒を使う変数名、`student.name` はその生徒の名前を取り出す書き方。
- `student.show_result()` は、その生徒の結果を表示するメソッドの呼び出し。
- `self` は、メソッドがいま扱っている生徒を受け取る名前。
- 生徒を作る順序や表示する順序は `main` にまとめる。
