# 8. クラス

生徒が増えるたびに、名前と点数を別々の変数で管理すると、「この点数は誰のもの？」と分からなくなりやすくなります。名前と点数をひとり分ずつまとめて扱い、結果を表示できるようにします。

> **「この80点、誰の点数？名前と点数をセットで扱いたい！」**

この章では、生徒ひとり分の名前と点数をまとめて扱い、その生徒の結果を表示します。そのために、まずPythonで新しい種類の値を定義する **クラス** を使います。

---

## 8-1. クラスで新しい型を定義する

ここまでで、変数と関数を学びました。変数は、値に名前を付けて、あとからその名前で使うためのものです。

たとえば、生徒について、

```python
# student_name（生徒の名前）に「たろう」を結び付けます。
student_name = "たろう"
# student_score（生徒の点数）に80を結び付けます。
student_score = 80

# show_result（結果を表示する処理）を定義します。
def show_result():
    # 名前と点数をコロンで区切って表示します。
    print(student_name, ":", student_score)
```

`student_name` は「生徒の名前」、`student_score` は「生徒の点数」を表す変数名です。`=` の左側に名前、右側にその名前で使いたい値を書きます。

Pythonでは、`student_name` の型や名前を先に書く宣言行はありません。`student_name = "たろう"` と書くと、名前と値が結び付きます。

この書き方でも表示できます。しかし、生徒が増えると、プログラムの中で名前・点数・表示する処理の組み合わせを別々に管理することになります。

プログラムが大きくなると、

```text
生徒の名前
生徒の点数
生徒を表示する関数
商品の名前
商品の値段
商品を表示する関数
設定の値
設定を変更する関数
...
```

のように、変数と関数がどんどん増えていきます。

そこで、名前と点数、そして結果を表示する処理をひとまとめにします。`class` は、新しい種類の値と、その値が持つ情報や処理を定義する書き方です。

この章では、生徒を表す `Student` クラスを定義します。

---

## 8-2. 名前と点数をひとり分ずつまとめる

次のコードでは、`Student`（生徒）という新しい種類の値を定義します。この定義を **クラス** と呼びます。

クラスから作った生徒ひとり分の値を **インスタンス** と呼びます。インスタンスは、自分の名前と点数を持ちます。

まず、クラスの中に、名前と点数を受け取って保存する処理を書きます。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）の値を、その生徒の name 属性に結び付けます。
        self.name = name
        # score（受け取った生徒の点数）の値を、その生徒の score 属性に結び付けます。
        self.score = score

    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`name` と `score` は、生徒を作るときに受け取る値の名前です。`self.name` と `self.score` は、その値を生徒ひとり分に保存するための名前です。ドットの左側が生徒、右側がその生徒の情報です。

`self.name = name` は、「受け取った `name` の値を、いま作っている生徒の `name` として保存する」という意味です。`self.score = score` も同じ形です。

このように、Pythonでは `self.name = name` の行で属性を設定します。属性名を先に宣言する行はありません。

この関係を図にすると、次のようになります。

```text
Student
├─ __init__ (初期化メソッド)
└─ show_result (メソッド)

student インスタンス
├─ name = "たろう"
└─ score = 80
```

クラスは生徒の情報や処理を定義し、作ったインスタンスはそれぞれ自分の `name` と `score` を持ちます。

## 8-3. サンプルコード

[student_class.py](./student_class.py) を開いてください。

`student` は英語で「生徒」という意味です。次のコードでは `student` という変数名に、たろうのインスタンスを結び付けます。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）の値を、その生徒の name 属性に結び付けます。
        self.name = name
        # score（受け取った生徒の点数）の値を、その生徒の score 属性に結び付けます。
        self.score = score

    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)


# Student（生徒）から、たろうのインスタンスを作ります。
# student（たろうの生徒データを使うための名前）に、その値を結び付けます。
student = Student("たろう", 80)

# student（たろうの生徒データ）の name（名前）を表示します。
print(student.name)

# student（たろうの生徒データ）の score（点数）を表示します。
print(student.score)

# student（たろうの生徒データ）の show_result（結果表示）を実行します。
student.show_result()

# Student（生徒）から、はなこのインスタンスを作ります。
# student2（はなこの生徒データを使うための名前）に、その値を結び付けます。
student2 = Student("はなこ", 95)

# student2（はなこの生徒データ）の show_result（結果表示）を実行します。
student2.show_result()
```

実行結果:

```text
たろう
80
たろう : 80
はなこ : 95
```

## 8-4. `class` でクラスを定義する

クラスを定義するときは `class` と書き、その後ろにクラス名を書きます。

```python
`class Student:`

この行は、

> `Student` という名前のクラスを定義するコード

という意味です。次の行から右に字下げした部分がクラスの中身です。

この章では、生徒ひとり分を作る処理と、結果を表示する処理をクラスの中に定義します。

---

## 8-5. 作るときに名前と点数を保存する

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに、名前と点数を受け取ります。
    def __init__(self, name, score):
        # name（受け取った生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（受け取った生徒の点数）をこの生徒に保存します。
        self.score = score
```

`__init__` は、生徒のインスタンスを作るときにPythonが呼び出す処理です。

たとえば `Student("たろう", 80)` と書くと、Pythonは生徒ひとり分を作ります。`name` は「たろう」、`score` は `80` を受け取ります。`self` は、そのとき作っている生徒ひとり分を表します。

`self.name = name` と書くと、受け取った名前を作った生徒に保存します。`self.score = score` は点数を保存します。別の生徒を作れば、その生徒自身の名前と点数が保存されます。

---

## 8-6. メソッドを定義する

クラスの中には、値を使った処理も定義できます。次の `show_result` は名前と点数を表示します。

```python
class Student:
    # 生徒ひとり分を作るときに、名前と点数を保存します。
    def __init__(self, name, score):
        # name（受け取った生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（受け取った生徒の点数）をこの生徒に保存します。
        self.score = score

    # この生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

クラスの中に定義した関数を **メソッド** と呼びます。インスタンスからメソッドを呼ぶと、そのインスタンスが `self` に渡ります。

そのため、`student.show_result()` と書けば、`student` の名前と点数が表示されます。

---

## 8-7. クラスの中もインデントする

クラスの中身は、`class Student:` より右に字下げして書きます。メソッドの中身は、さらに右へ字下げします。

```python
class Student:
    # 生徒ひとり分を作る処理です。
    def __init__(self, name, score):
        # 受け取った名前をこの生徒に保存します。
        self.name = name
        # 受け取った点数をこの生徒に保存します。
        self.score = score
```

字下げによって、`__init__` が `Student` の中にあり、代入文が `__init__` の中にあることを表します。

---

## 8-8. `Student(...)` でインスタンスを作る

サンプルでは、次の行で生徒ひとり分を作り、`student` という名前で使えるようにしています。

```python
# student（たろうの生徒データを使う名前）に、たろうの値を結び付けます。
student = Student("たろう", 80)
```

`student` は、`Student` から作ったたろうのインスタンスを使うための変数名です。Pythonでは、この例の `student` を先に宣言する行はありません。`student = ...` と書くと、右側で作った値と `student` という名前が結び付きます。そのとき `__init__` が呼び出され、名前と点数が保存されます。

たとえば、次のように別々の値を持つインスタンスを作れます。

```python
# student（たろうの生徒データを使う名前）に、たろうの値を結び付けます。
student = Student("たろう", 80)
# student2（はなこの生徒データを使う名前）に、はなこの値を結び付けます。
student2 = Student("はなこ", 95)
```

`student.name` は `"たろう"`、`student2.name` は `"はなこ"` です。`student` と `student2` は別々の値に結び付いているため、それぞれの名前と点数を保てます。

---

## 8-9. `student.name` の `.` は何？

```python
# student の name（名前）を表示します。
print(student.name)
```

この行は、`student` という名前で使っている生徒の `name`（名前）を表示します。この属性は、`__init__` の `self.name = name` で保存したものです。

ドットの左側が情報を持っている値で、右側がその値から取り出す情報の名前です。

同じように、

```python
# student の show_result（結果表示）を実行します。
student.show_result()
```

は、`student` の `show_result`（結果を表示する処理）を呼び出します。このとき `student` が `self` としてメソッドに渡ります。

---

## 8-10. `self` はインスタンス自身

サンプルには、

```python
# show_result（結果表示）の処理を定義します。
def show_result(self):
    # self（いま扱っている生徒）の名前と点数を表示します。
    print(self.name, ":", self.score)
```

と `self` が出てきます。

`self` は、メソッドがいま扱っているインスタンスを指す引数の名前です。インスタンスからメソッドを呼ぶと、そのインスタンスが自動で渡ります。

そのため、

```python
self.name
```

は、「いま扱っている生徒の `name`（名前）」という意味です。この例では、`__init__` で保存した名前を参照しています。

## 8-13. 自分で変えてみる

`student_class.py` の `Student.__init__` に学級名 `class_name` を受け取る部分を追加し、`self.class_name` に保存してください。保存できたか確かめるため、`student.class_name` を表示します。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るとき、名前・点数・学級名を受け取ります。
    def __init__(self, name, score, class_name):
        # name（生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（生徒の点数）をこの生徒に保存します。
        self.score = score
        # class_name（学級名）をこの生徒に保存します。
        self.class_name = class_name

    # この生徒の結果を表示する処理です。
    def show_result(self):
        # この生徒の名前と点数を表示します。
        print(self.name, ":", self.score)


# student（たろうの生徒データを使う名前）に値を結び付けます。
student = Student("たろう", 80, "A")
# student の class_name（学級名）を表示します。
print(student.class_name)
```

`Student(...)` に名前・点数・学級名を指定すると、その値が生徒ひとり分に保存されます。実行すると `A` と表示されます。

元の `Student` に別のメソッドを追加することもできます。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに名前と点数を受け取ります。
    def __init__(self, name, score):
        # name（生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（生徒の点数）をこの生徒に保存します。
        self.score = score

    # 生徒の結果を表示する処理です。
    def show_result(self):
        # この生徒の名前と点数を表示します。
        print(self.name, ":", self.score)

    # 生徒の名前だけを表示する処理です。
    def show_name(self):
        # この生徒の名前を表示します。
        print(self.name)
```

`show_name()` を呼び出すと、そのインスタンスに保存した名前だけが表示されます。`self.name` が「いま扱っている生徒の名前」を表すことを確認してください。
