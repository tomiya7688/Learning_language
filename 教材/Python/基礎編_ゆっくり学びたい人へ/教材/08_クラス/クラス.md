# 8. クラス

この章では、**クラス**というものを扱います。

例えば、こんな状況を考えましょう。クラスの生徒の名前と、数学・国語の点数を扱いたいときです。

名前（name）、数学（Math）、国語（kokugo）、点数（score）を、生徒ごとに別々の変数にすると、こんなふうになります。

```python
Hanako_name = "Hanako"  # はなこの名前
Hanako_Math_score = 80  # はなこの数学の点数
Hanako_kokugo_score = 50  # はなこの国語の点数

Taro_name = "Taro"  # たろうの名前
Taro_Math_score = 40  # たろうの数学の点数
Taro_kokugo_score = 60  # たろうの国語の点数
```

……生徒が増えるたびに、名前と2教科の点数の変数も増えていきます。

> **「いや覚えてられんわ！」**

名前も数学の点数も、同じはなこの情報ですよね。だったら、ひとまとめにできないでしょうか。「はなこの名前」「はなこの数学の点数」と書けると、誰の情報かも分かりそうです。

## 8-1. 生徒の情報をクラスにまとめる

そこで使うのがクラスです。生徒のクラス（`Student`）に、名前と2教科の点数をまとめてみましょう。あとで、その生徒の結果を見せる関数もここに書けます。

例えば、はなこを作るときはこう書きます。名前は「Hanako」、数学は80点、国語は50点です。ファイルに書くのはあとにして、まずこの1行を見てください。

```python
# 名前・数学の点数・国語の点数を指定して、はなこの変数（hanako）に代入します。
hanako = Student(name="Hanako", math_score=80, kokugo_score=50)
```

たろうなら、`taro = Student(name="Taro", math_score=40, kokugo_score=60)` です。括弧の中の `math_score=40` は「数学の点数は40」ということです。同じように、名前と国語の点数も書いています。

生徒のクラス（`Student`）は共通ですが、そこから作るはなことたろうは別々の生徒です。このようにクラスをもとに作ったものを、**実体（インスタンス）**と呼びます。

### はなことたろうに設定する情報

| 生徒 | 名前（name） | 数学の点数（math_score） | 国語の点数（kokugo_score） |
| --- | --- | --- | --- |
| はなこ | `"Hanako"` | `80` | `50` |
| たろう | `"Taro"` | `40` | `60` |

では、生徒のクラス（`Student`）の中身を読んでみましょう。

## 8-2. 名前と点数を設定する `__init__`

`__init__` は、最初の設定を書く関数です。生徒を作ると、`__init__` が実行されます。

たろうを作るところで、何が起きるのか見てみましょう。

```python
# 名前・数学の点数・国語の点数を指定して、たろうの変数（taro）に代入します。
taro = Student(name="Taro", math_score=40, kokugo_score=60)
```

括弧の中に書いた名前（`name`）の `"Taro"`、数学の点数（`math_score`）の `40`、国語の点数（`kokugo_score`）の `60` を、初期設定の関数が受け取ります。

では、関数の中にある `self` は誰でしょうか。今作っている生徒自身、つまりたろうです。`self.name` は「たろう自身の名前」、`self.math_score` は「たろう自身の数学の点数」、`self.kokugo_score` は「たろう自身の国語の点数」です。

このように、生徒が持っている名前や点数を **属性** と呼びます。`.` の右側に `name` と書けば名前、`math_score` と書けば数学の点数を表します。

元ファイル：[`student_class.py` の1〜10行](./student_class.py#L1-L10)。

```python
# 生徒のクラス（Student）を宣言します。
class Student:
    # 初期設定の関数（__init__）を宣言します。
    def __init__(self, name, math_score, kokugo_score):
        # 受け取った名前（name）を、生徒自身（self）の名前に設定します。
        self.name = name
        # 受け取った数学の点数（math_score）を、生徒自身の数学の点数に設定します。
        self.math_score = math_score
        # 受け取った国語の点数（kokugo_score）を、生徒自身の国語の点数に設定します。
        self.kokugo_score = kokugo_score
```

`self.name = name` を見てください。右側の `name` は、さっき受け取った `"Taro"` です。それを左側の `self.name` に代入すると、たろう自身の名前が `"Taro"` になります。

`self.math_score = math_score` で、たろう自身の数学の点数を40点に、`self.kokugo_score = kokugo_score` で、国語の点数を60点に設定しています。

同じ書き方ではなこを作っても、たろうの点数とは混ざりません。はなこは数学80点・国語50点、たろうは数学40点・国語60点と、それぞれの点数を持ちます。

## 8-3. 生徒の結果を見せる関数を加える

名前と点数がそろいました。今度は、この生徒の結果を画面に出したいですね。結果を見せる関数も、生徒のクラスの中にまとめてみましょう。

元ファイル：[`student_class.py` の12〜15行](./student_class.py#L12-L15)。

```python
    # 生徒の結果を見せる関数（show_result）を宣言します。
    def show_result(self):
        # 生徒自身の名前・数学の点数・国語の点数を、1行にして表示します。
        print(f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点")
```

`def` の前には空白が4個ありますね。これで「生徒のクラスの中にある関数」となります。さらに4個右へずらした `print` が、この関数で行う処理です。詳しい見方は[8-5「行頭の空白で中身を分ける」](#8-5-行頭の空白で中身を分ける)でも確認できます。

はなこの結果を見せたいときは、`hanako.show_result()` と書きます。この関数が実行されると、画面にはこう出ます。

```text
Hanako: 数学 80点、国語 50点
```

表示に使っている `f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点"` の `{}` には、はなこの名前（`"Hanako"`）、数学の点数（`80`）、国語の点数（`50`）が入ります。たろうの結果を見せるなら、`taro.show_result()` と書けば同じ関数を使えます。

## 8-5. 行頭の空白で中身を分ける

行頭に空白を入れて、右へずらして書くことを **字下げ（インデント）**と呼びます。

元ファイル：[`student_class.py` の1〜10行](./student_class.py#L1-L10)。

```python
# 生徒のクラス（Student）を宣言します。
class Student:
    # 初期設定の関数（__init__）を宣言します。
    def __init__(self, name, math_score, kokugo_score):
        # 受け取った名前（name）を、生徒自身（self）の名前に設定します。
        self.name = name
        # 受け取った数学の点数（math_score）を、生徒自身の数学の点数に設定します。
        self.math_score = math_score
        # 受け取った国語の点数（kokugo_score）を、生徒自身の国語の点数に設定します。
        self.kokugo_score = kokugo_score
```

- `class Student:` は、行頭から書いています。
- `def __init__(...)` は、行頭に空白4個があります。これが、生徒のクラスの中の関数です。
- `self.name = name` は、行頭に空白8個があります。これが、初期設定の関数の処理です。

主な処理を書く `def main():` は行頭から書いているので、生徒のクラスの外にあります。

## 8-6. 関数もクラスにまとめられる

名前や点数だけでなく、**関数もクラスにまとめられる**んですね。先ほどの、結果を見せる関数もその一つです。クラスの中に宣言した関数は、**メソッドとも呼びます**。

`hanako.show_result()` も `taro.show_result()` も、結果を見せる関数を実行する文です。メソッドと呼んでも、関数であることは同じです。

## 8-9. はなこの名前は `hanako.name`

`.` の左側は誰の情報か、右側は何の情報かを表します。

### 名前と点数の読み方

| 書き方 | 読み方 | 値 |
| --- | --- | --- |
| `hanako.name` | はなこの名前 | `"Hanako"` |
| `hanako.math_score` | はなこの数学の点数 | `80` |

| `taro.math_score` | たろうの数学の点数 | `40` |
| `taro.kokugo_score` | たろうの国語の点数 | `60` |

例えば、`print(hanako.math_score)` と書くと、はなこの数学の点数である `80` が表示されます。

```python
    print(f"{hanako.name}の学級: {hanako.class_name}")
    # たろうの結果を見せる関数（taro.show_result）を実行します。
    taro.show_result()
    # たろうの名前（taro.name）と学級名（taro.class_name）を表示します。
    print(f"{taro.name}の学級: {taro.class_name}")


# このファイルを直接実行した場合だけ、main() を実行します。
if __name__ == "__main__":
    # 主な処理をする関数（main）を実行します。
    main()
```

### 名前を見せる関数も加えてみよう

名前だけを見たいときに、毎回点数まで出るのは困りますね。名前を見せる関数（`show_name`）も加えてみましょう。生徒のクラスの最後に、こう書きます。

#### 追加する関数

```python
    # 生徒の名前を見せる関数（show_name）を宣言します。
    def show_name(self):
        # 生徒自身の名前（self.name）を表示します。
        print(self.name)
```

関数を書いただけでは、まだ名前は表示されません。`main` の最後に `taro.show_name()` を加えて、実行する順番に入れましょう。

#### `main` の最後の変更前

直前の学級名付きコードからの抜粋です。

```python
    # たろうの名前（taro.name）と学級名（taro.class_name）を表示します。
    print(f"{taro.name}の学級: {taro.class_name}")
```

#### `main` の最後の変更後

```python
    # たろうの名前（taro.name）と学級名（taro.class_name）を表示します。
    print(f"{taro.name}の学級: {taro.class_name}")
    # たろうの名前を見せる関数（taro.show_name）を実行します。
    taro.show_name()
```

#### 名前を見せる関数を加えたファイル全体

直前の学級名付きコードでは、17行目の `print` までが、生徒のクラスの中身です。Ctrl + F（macOSはCommand + F）で `def show_result` を探しても確認できます。その後ろに `show_name` を加えた全体が次のコードです。さっきの学級名を加えたコード（1〜42行）を、次のコード全体で置き換えてください。

変更例のもとにする配布版：[student_class.py 全体（1〜36行）](./student_class.py#L1-L36)。

```python
# 生徒のクラス（Student）を宣言します。
class Student:
    # 初期設定の関数（__init__）を宣言します。
    def __init__(self, name, math_score, kokugo_score, class_name):
        # 受け取った名前（name）を、生徒自身（self）の名前に設定します。
        self.name = name
        # 受け取った数学の点数（math_score）を、生徒自身の数学の点数に設定します。
        self.math_score = math_score
        # 受け取った国語の点数（kokugo_score）を、生徒自身の国語の点数に設定します。
        self.kokugo_score = kokugo_score
        # 受け取った学級名（class_name）を、生徒自身の学級名に設定します。
        self.class_name = class_name

    # 生徒の結果を見せる関数（show_result）を宣言します。
    def show_result(self):
        # 生徒自身の名前・数学の点数・国語の点数を、1行にして表示します。
        print(f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点")

    # 生徒の名前を見せる関数（show_name）を宣言します。
    def show_name(self):
        # 生徒自身の名前（self.name）を表示します。
        print(self.name)


# 主な処理をする関数（main）を宣言します。
def main():
    # はなこの変数（hanako）を宣言します。
    # 名前「Hanako」、数学80点、国語50点、学級名「A」の生徒を代入します。
    hanako = Student(name="Hanako", math_score=80, kokugo_score=50, class_name="A")
    # たろうの変数（taro）を宣言します。
    # 名前「Taro」、数学40点、国語60点、学級名「B」の生徒を代入します。
    taro = Student(name="Taro", math_score=40, kokugo_score=60, class_name="B")

    # はなこの結果を見せる関数（hanako.show_result）を実行します。
    hanako.show_result()
    # はなこの名前（hanako.name）と学級名（hanako.class_name）を表示します。
    print(f"{hanako.name}の学級: {hanako.class_name}")
    # たろうの結果を見せる関数（taro.show_result）を実行します。
    taro.show_result()
    # たろうの名前（taro.name）と学級名（taro.class_name）を表示します。
    print(f"{taro.name}の学級: {taro.class_name}")
    # たろうの名前を見せる関数（taro.show_name）を実行します。
    taro.show_name()


# このファイルを直接実行した場合だけ、main() を実行します。
if __name__ == "__main__":
    # 主な処理をする関数（main）を実行します。
    main()
```

保存して同じターミナルで再実行してみましょう。コマンドは `python student_class.py`（Windows）または `python3 student_class.py`（macOS / Linux）です。

#### 名前を見せる関数を加えた結果

```text

Hanakoの学級: A
Taro: 数学 40点、国語 60点
Taroの学級: B
Taro
```

最後の `Taro` が、追加した `taro.show_name()` の表示です。

## 8-14. 今回の内容

- クラスに、生徒が持つ情報と、その情報を扱う関数をまとめられる。
- クラスをもとに作ったはなこやたろうを、実体（インスタンス）と呼ぶ。
- `__init__` は、生徒を作ったときに実行される、初期設定の関数。
- `self.name = name` は、受け取った名前を、生徒自身の名前に設定する文。
- `hanako.name` は、はなこの名前を指定する書き方。
- `hanako.show_result()` と書くと、はなこの名前と点数を見せる関数が実行される。
