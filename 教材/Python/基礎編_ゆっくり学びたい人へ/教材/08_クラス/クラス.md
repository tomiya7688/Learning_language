# 8. クラス

生徒が増えるたびに、名前と点数を別々の変数で管理すると、「この点数は誰のもの？」と分からなくなりやすくなります。名前と点数をひとり分ずつまとめて扱い、結果を表示できるようにします。

> **「この80点、誰の点数？名前と点数をセットで扱いたい！」**

この章では、生徒ひとり分の名前と点数をまとめて扱い、その生徒の結果を表示します。そのために、まずPythonで新しい種類の値を定義する **クラス** を使います。

---

## 8-1. クラスで新しい種類の値を定義する

ここまでで、変数と関数を学びました。変数は、値に名前を付けて、あとからその名前で使うためのものです。

次のコードでは、生徒の名前を `student_name` に、点数を `student_score` に保存し、2つの値を表示する `show_result` 関数を定義します。

```python
# student_name（生徒の名前）に「たろう」を保存します。
student_name = "たろう"
# student_score（生徒の点数）に80を保存します。
student_score = 80

# show_result（結果を表示する処理）を定義します。
def show_result():
    # 名前と点数をコロンで区切って表示します。
    print(student_name, ":", student_score)
```

`student_name` は「生徒の名前」、`student_score` は「生徒の点数」を表す変数名です。`=` の左側に名前、右側にその名前で使いたい値を書きます。たとえば、`student_name = "たろう"` と書くと、このプログラムでは `student_name` という名前で「たろう」を使えます。

このコードは、名前と点数を表示する `show_result` 関数を定義します。ただし、`show_result()` を呼び出す行がないため、このコードを実行しても画面には何も表示されません。

生徒ごとに名前と点数を別々の変数へ保存すると、生徒が増えるたびに変数も増えます。変数が増えると、どの名前と点数がひとり分なのか分かりにくくなります。

プログラムが扱う生徒や商品、設定が増えると、次のような変数や関数も増えていきます。

```text
生徒の名前
生徒の点数
生徒を表示する関数
商品の名前
商品の値段
商品を表示する関数
設定の値
設定を変更する関数
...
```

そこで、名前と点数、そして結果を表示する処理をひとまとめにします。`class` は、新しい種類の値と、その値が持つ情報や処理を定義する書き方です。

この章では、生徒を表す `Student` クラスを定義します。

---

## 8-2. 名前と点数をひとり分ずつまとめる

次のコードでは、`Student`（生徒）という新しい種類の値を定義します。この定義を **クラス** と呼びます。

クラスから作った生徒ひとり分の値を **インスタンス** と呼びます。インスタンスは、自分の名前と点数を持ちます。

インスタンスに保存する名前や点数などの情報を **属性** と呼びます。このコードでは、生徒の名前と点数をインスタンスの属性として保存します。

まず、クラスの中に、名前と点数を受け取って保存する処理を書きます。

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに呼び出す処理を定義します。
    def __init__(self, name, score):
        # self は、いま作っている生徒ひとり分を表します。
        # name（受け取った生徒の名前）を、その生徒の name 属性（名前を保存する場所）に保存します。
        self.name = name
        # score（受け取った生徒の点数）を、その生徒の score 属性（点数を保存する場所）に保存します。
        self.score = score

    # 生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`Student` から生徒を作るとき、Pythonは受け取った名前を `name`、点数を `score` という名前で使います。`self.name` はその生徒の名前を保存する属性で、`self.score` はその生徒の点数を保存する属性です。

`self.name = name` と書くと、Pythonは `self.name` 属性を作り、受け取った名前を保存します。`self.score = score` と書くと、Pythonは `self.score` 属性を作り、受け取った点数を保存します。

`Student` クラスが定義する処理と、`student` インスタンスが保存する情報を図にすると、次のようになります。

```text
Student
├─ __init__ (生徒を作るときに呼び出す処理)
└─ show_result (結果を表示する処理)

student インスタンス
├─ name = "たろう"
└─ score = 80
```

`Student` クラスは、生徒ひとり分の情報と、その情報を使う処理を定義します。`Student` クラスから作ったインスタンスは、それぞれ自分の `name` と `score` を持ちます。

## 8-4. `class` でクラスを定義する

Pythonでは、行の先頭に空白を入れて右へずらすことを **インデント（字下げ）** と呼びます。

クラスを定義するときは `class` と書き、その後ろにクラス名を書きます。

`class Student:` は、`Student` という名前のクラスを定義する行です。

`class Student:` の後で、行の先頭を空白で右へずらした行が `Student` クラスの中身です。

この章では、生徒ひとり分を作る処理と、結果を表示する処理をクラスの中に定義します。

---

## 8-5. 作るときに名前と点数を保存する

```python
# Student（生徒）という新しい種類の値を定義します。
class Student:
    # 生徒ひとり分を作るときに、名前と点数を受け取ります。
    def __init__(self, name, score):
        # name（受け取った生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（受け取った生徒の点数）をこの生徒に保存します。
        self.score = score
```

`__init__` は、生徒のインスタンスを作るときにPythonが呼び出す処理です。

`Student("たろう", 80)` と書くと、Pythonは `Student` クラスから生徒ひとり分のインスタンスを作ります。

Pythonは、そのインスタンスを `__init__` の `self` に渡します。Pythonは、文字列 `"たろう"` を `name` に、数値 `80` を `score` に渡します。

`self` は、`__init__` がいま作っている生徒ひとり分を表します。

`self.name = name` と書くと、Pythonは受け取った名前を、その生徒の `name` 属性に保存します。`self.score = score` と書くと、Pythonは受け取った点数を、その生徒の `score` 属性に保存します。

別の `Student(...)` を実行すると、Pythonは別の生徒の名前と点数を、その生徒自身の属性に保存します。

---

## 8-6. メソッドを定義する

クラスの中に定義した関数を **メソッド** と呼びます。`show_result` メソッドは、`self` という名前で受け取った生徒の名前と点数を表示します。

```python
class Student:
    # 生徒ひとり分を作るときに、名前と点数を保存します。
    def __init__(self, name, score):
        # name（受け取った生徒の名前）をこの生徒に保存します。
        self.name = name
        # score（受け取った生徒の点数）をこの生徒に保存します。
        self.score = score

    # この生徒の結果を表示する処理を定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`student.show_result()` を実行すると、Pythonは `student` に結び付いたインスタンスを `show_result` の `self` に渡します。`show_result` は、そのインスタンスの名前と点数を表示します。

## 8-7. クラスの中もインデントする

Pythonでは、行の先頭に空白を入れて右へずらすことを **字下げ** と呼びます。

`class Student:` の中身は、`class Student:` より右に字下げして書きます。メソッドの中身は、メソッドの行よりさらに右へ字下げします。

```python
class Student:
    # 生徒ひとり分を作る処理です。
    def __init__(self, name, score):
        # 受け取った名前をこの生徒に保存します。
        self.name = name
        # 受け取った点数をこの生徒に保存します。
        self.score = score
```

このコードでは、`def __init__` の行を `class Student:` より右に字下げしているため、`__init__` は `Student` クラスの中にあります。

`self.name = name` の行を `def __init__` よりさらに右に字下げしているため、この行は `__init__` の中にあります。

## 8-9. `student.name` の `.` は何？

```python
# student の name（名前）を表示します。
print(student.name)
```

`print(student.name)` は、`student` という変数に結び付いた生徒の名前を画面に表示します。`student.name` は、`Student.__init__` の `self.name = name` で保存した名前です。

このコードでは、ドットの左側にインスタンスを使う名前を書き、右側にそのインスタンスから取り出す属性名や呼び出すメソッド名を書きます。たとえば、`student.name` は名前を取り出し、`student.show_result()` は結果を表示する処理を呼び出します。

生徒の結果を表示するときは、`student` の後ろにドットと `show_result` を続けて書きます。

```python
# student の show_result（結果表示）を実行します。
student.show_result()
```

`student.show_result()` は、`student` に結び付いたインスタンスの `show_result` メソッドを呼び出します。Pythonは、そのインスタンスをメソッドの `self` に渡します。

---

## 8-10. `self` はインスタンス自身

`Student` クラスの `show_result` メソッドは、`self` という名前で呼び出した生徒のインスタンスを受け取ります。

```python
# Student（生徒）クラスを定義します。
class Student:
    # show_result（結果表示）メソッドを定義します。
    def show_result(self):
        # この生徒の名前と点数をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

`self` は、メソッドを呼び出したインスタンスを受け取るために、このコードで使っている名前です。`student.show_result()` を実行すると、Pythonは `student` に結び付いたインスタンスを `show_result` の `self` に渡します。

`self.name` は、`self` が受け取った生徒の名前を表す属性です。

```python
self.name
```

`Student.__init__` の `self.name = name` は、受け取った名前を、その生徒の `self.name` に保存します。

6. Windowsでは `python student_class.py`、macOS / Linuxでは `python3 student_class.py` とVS Codeのターミナルに入力してください。
7. Enterキーを押してください。

実行すると、画面に `たろう` と表示されます。Pythonは、`student` に結び付いたインスタンスを `show_name` の `self` に渡します。

## 8-14. 今回の内容

この章では、次の書き方を使いました。

1. クラスは新しい種類の値を定義する書き方
2. `class` でクラスを作る
3. クラスの中はインデントする
4. `__init__` はインスタンスを作るときに呼び出される
5. `self.name = name` のように、受け取った値をインスタンスに保存できる
6. `student = Student(...)` と書くと、`student` という名前でインスタンスを使える
7. `student.name` のように書いて、`student` に保存した名前を取り出せる
8. `Student(...)` でインスタンスを作って使う
9. インスタンスからメソッドを呼ぶと、そのインスタンスが `self` に渡る
