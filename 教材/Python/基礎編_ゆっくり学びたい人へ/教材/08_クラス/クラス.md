# 8. クラス

この章では、**クラス**というものを扱います。

例えば、こんな状況を考えましょう。クラスの生徒の名前と、数学・国語の点数を扱いたいときです。

`name` は「名前」、`Math` は「数学」、`kokugo` は「国語」、`score` は「点数」です。生徒ごとに別々の変数を作ると、次のようになります。このコードは困り事を考えるための例です。

```python
Hanako_name = "Hanako"  # はなこの名前
Hanako_Math_score = 80  # はなこの数学の点数
Hanako_kokugo_score = 50  # はなこの国語の点数

Taro_name = "Taro"  # たろうの名前
Taro_Math_score = 40  # たろうの数学の点数
Taro_kokugo_score = 60  # たろうの国語の点数
```

……生徒が増えるたびに、名前と2教科の点数の変数も増えていきます。

> **「いや覚えてられんわ！」**

はなこの情報なのに、名前・数学・国語で変数がばらばらです。ひとり分をまとめて、「はなこの名前」「はなこの数学の点数」と取り出せるようにしたいところです。

## 8-1. ひとり分のデータを作る

`Student`（生徒）というクラスに、名前・数学の点数・国語の点数をまとめる書き方を決めます。クラスは、同じ種類のデータの持ち方と、そのデータを使う処理を定義するものです。

`Student("Hanako", 80, 50)` は、「名前はHanako、数学は80点、国語は50点」という生徒ひとり分のデータを作る書き方です。`Student("Taro", 40, 60)` なら、別の生徒ひとり分を作ります。

こうしてクラスから作った**具体的なひとり分のデータを、インスタンス（実体）**と呼びます。`Student` は作り方を定義するクラス、はなこやたろうのデータは、その作り方で作った別々の実体です。

| 生徒の実体 | 名前 | 数学 | 国語 |
| --- | --- | --- | --- |
| はなこのデータ | `"Hanako"` | `80`点 | `50`点 |
| たろうのデータ | `"Taro"` | `40`点 | `60`点 |

ここからは、これらの実体を作る `Student` クラスを書いていきます。

## 8-2. `__init__` と `self.name` を読む

`__init__` は、クラスから作った実体を使い始めるための**初期設定を書く関数**です。`Student` の例では、名前と数学・国語の点数を記録する初期設定を書きます。

Pythonは `Student("Taro", 40, 60)` でたろうの実体を作ると、その実体と括弧で指定した値を `__init__` に渡して実行します。

- `self` は、いま初期設定をしている実体です。この呼び出しでは、たろうの実体を受け取ります。
- `name` は `"Taro"`、`math_score` は `40`、`kokugo_score` は `60` を受け取ります。
- `self.name` は「その実体自身（self）の名前（name）」です。`.` で、その実体が持つ情報を指定します。

実体が持つ名前や点数などの情報を **属性** と呼びます。`self.math_score` はその生徒自身の数学の点数、`self.kokugo_score` はその生徒自身の国語の点数です。

元ファイル：[`student_class.py` の1〜10行](./student_class.py#L1-L10)。

```python
# 名前と数学・国語の点数をまとめる Student（生徒）クラスを定義します。
class Student:
    # 生徒データの初期設定をする __init__ 関数を定義します。
    def __init__(self, name, math_score, kokugo_score):
        # name（名前）で受け取った値を、self（設定中の生徒データ）の name（名前）にします。
        self.name = name
        # math_score で受け取った数学の点数を、この生徒の math_score にします。
        self.math_score = math_score
        # kokugo_score で受け取った国語の点数を、この生徒の kokugo_score にします。
        self.kokugo_score = kokugo_score
```

`self.name = name` は、`name` で受け取った名前を、`self` が表す実体の名前にする行です。たろうの初期設定なら、受け取った `"Taro"` を、たろうの実体の `name` にします。

同じように、`self.math_score = math_score` で受け取った数学40点を、`self.kokugo_score = kokugo_score` で受け取った国語60点を、その実体に記録します。Pythonでは、これらの属性を用意するための宣言を、代入より前の別の行に書く必要はありません。

## 8-3. 全体を保存して実行する

生徒の名前と点数をひとり分にまとめたので、結果の表示も、その生徒の情報を使う `show_result`（結果表示）関数にまとめます。この関数も `Student` クラスの中に書いてください。

`hanako.show_result()` と書くと、Pythonがはなこの実体を `self` に渡して、結果表示関数を実行します。`taro.show_result()` なら、たろうの実体を使います。

`show_result` は、名前と2教科の点数を1行で表示します。`f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点"` の `{}` に、その生徒の名前と点数が入ります。

## 8-4. `class` の書き方と字下げ

`class`、空白、クラス名、`:` の順に書くと、クラスを定義できます。今回のクラス名は `Student` です。

元ファイル：[`student_class.py` の1〜10行](./student_class.py#L1-L10)。

```python
# 名前と数学・国語の点数をまとめる Student（生徒）クラスを定義します。
class Student:
    # 生徒データの初期設定をする __init__ 関数を定義します。
    def __init__(self, name, math_score, kokugo_score):
        # name（名前）で受け取った値を、self（設定中の生徒データ）の name（名前）にします。
        self.name = name
        # math_score で受け取った数学の点数を、この生徒の math_score にします。
        self.math_score = math_score
        # kokugo_score で受け取った国語の点数を、この生徒の kokugo_score にします。
        self.kokugo_score = kokugo_score
```

`Student` の中の `def` は半角スペース4個分、その関数の処理はさらに4個分、合計8個分字下げします。`self.name = name` は `__init__` の中なので、8個分の字下げがあります。

`def main():` は生徒のデータの持ち方を定義する処理ではないので、クラスの外に置き、行頭を字下げしません。`Student` クラスの範囲は `def main():` の手前までです。

## 8-5. どの値を受け取り、どこへ記録する？

ここは8-2の対応の復習です。**値の対応が分かっている場合は、8-6へ進んで構いません。**

`Student("Taro", 40, 60)` と書いた場合は、次の対応になります。

| `__init__` の名前 | 受け取る値 | 初期設定での役割 |
| --- | --- | --- |
| `self` | 今作ったたろうの実体 | 名前や点数を持たせる対象 |
| `name` | `"Taro"` | `self.name` に記録 |
| `math_score` | `40` | `self.math_score` に記録 |
| `kokugo_score` | `60` | `self.kokugo_score` に記録 |

`self` に入る実体はPythonが渡します。`Student(...)` の括弧で指定するのは、名前・数学・国語の3つです。

はなこの初期設定では、同じ `__init__` がはなこの実体と `"Hanako"`、`80`、`50` を受け取ります。それぞれの実体に値を記録するので、はなこの80点と、たろうの40点を別々に持てます。

**関数もクラスにまとめられる**ので、結果表示関数 `show_result` も `Student` の中に定義しています。クラスの中に定義した関数を **メソッド** と呼びます。

```python

        print(f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点")

`hanako.show_result()` は、はなこのデータを使って結果表示関数を実行します。`taro.show_result()` は、たろうのデータを使って、同じ関数を実行します。

## 8-9. `hanako.name` は、はなこの名前

`.` の左側は、どの実体の情報を使うかを表します。右側は、その実体のどの情報を使うかを表します。

| 書き方 | 読み方 | 値 |
| --- | --- | --- |
| `hanako.name` | はなこ（hanako）の名前（name） | `"Hanako"` |
| `hanako.math_score` | はなこの数学の点数 | `80` |
| `hanako.kokugo_score` | はなこの国語の点数 | `50` |
| `taro.name` | たろう（taro）の名前（name） | `"Taro"` |
| `taro.math_score` | たろうの数学の点数 | `40` |
| `taro.kokugo_score` | たろうの国語の点数 | `60` |

`hanako.name` の `hanako` は生徒の実体を使う変数名、`name` はその生徒の名前という情報です。

## 8-11. 関数とクラスの分け方

`show_result` は、その生徒の情報を使う結果表示関数なので、`Student` の中にあります。`main` は、生徒の実体を作って結果表示関数を実行する主な処理なので、`Student` の外にあります。

        # class_name（学級名）で受け取った値を、この生徒の class_name にします。
        self.class_name = class_name

    # 生徒の結果を表示する show_result 関数を定義します。
    def show_result(self):
        # self.name は生徒自身の名前、self.math_score は数学、self.kokugo_score は国語の点数です。
        # この生徒の名前と2教科の点数を1行にして表示します。
        print(f"{self.name}: 数学 {self.math_score}点、国語 {self.kokugo_score}点")

    # 生徒の名前だけを表示する show_name 関数を定義します。
    def show_name(self):
        # self.name（この生徒自身の名前）を表示します。
        print(self.name)


# 主な処理をする main 関数を定義します。
def main():
    # hanako（はなこ）という変数を、この行で作ります。
    # 名前「Hanako」、数学80点、国語50点、学級名「A」の生徒データを作り、hanako に代入します。
    hanako = Student("Hanako", 80, 50, "A")
    # taro（たろう）という変数を、この行で作ります。
    # 名前「Taro」、数学40点、国語60点、学級名「B」の生徒データを作り、taro に代入します。
    taro = Student("Taro", 40, 60, "B")

    # hanako（はなこのデータ）の show_result（結果表示）関数を実行します。
    hanako.show_result()
    # hanako.name（はなこの名前）と hanako.class_name（はなこの学級名）を表示します。
    print(f"{hanako.name}の学級: {hanako.class_name}")
    # taro（たろうのデータ）の show_result（結果表示）関数を実行します。
    taro.show_result()
    # taro.name（たろうの名前）と taro.class_name（たろうの学級名）を表示します。
    print(f"{taro.name}の学級: {taro.class_name}")
    # taro（たろうのデータ）の show_name（名前表示）関数を実行します。
    taro.show_name()


# このファイルを直接実行した場合だけ、main() を実行します。
if __name__ == "__main__":
    # 主な処理をする main 関数を実行します。
    main()
```

保存して同じターミナルで再実行してください。コマンドは `python student_class.py`（Windows）または `python3 student_class.py`（macOS / Linux）です。

```text
Hanako: 数学 80点、国語 50点
Hanakoの学級: A
Taro: 数学 40点、国語 60点
Taroの学級: B
Taro
```

最後の `Taro` が、`taro.show_name()` の表示です。名前表示関数の `self` は、たろうの実体を受け取っています。

## 8-14. 今回の内容

- `Student` クラスに、生徒のデータの持ち方と、そのデータを使う処理を定義する。
- `Student(...)` で具体的なひとり分のデータを作る。作った実体をインスタンスと呼ぶ。
- `__init__` は、その実体を使い始めるための初期設定を書く関数。
- `self.name = name` は、受け取った名前を、その実体の名前にする。
- `hanako` や `taro` は、作った実体を使う変数。
- `hanako.name` は、はなこの名前を取り出す書き方。
- `hanako.show_result()` は、はなこのデータで結果表示関数を実行する書き方。
