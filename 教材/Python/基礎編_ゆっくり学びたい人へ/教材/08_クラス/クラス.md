# 8. クラス

この章では、`class` 文でクラスを定義し、そのクラスからインスタンスを作って使う方法を学びます。

クラスは、Pythonで新しい型を定義する仕組みです。クラスには属性やメソッドを定義できます。

クラスから作る個々の値をインスタンスと呼びます。この例では、生徒1人分の名前と点数を持つ値を作ります。

---

## 8-1. クラスで新しい型を定義する

ここまでで、変数と関数を学びました。

たとえば、生徒について、

```python
student_name = "たろう"
student_score = 80

def show_result():
    print(student_name, ":", student_score)
```

と書けます。

これでも動きます。

でも、プログラムが大きくなると、

```text
生徒の名前
生徒の点数
生徒を表示する関数
商品の名前
商品の値段
商品を表示する関数
設定の値
設定を変更する関数
...
```

のように、変数と関数がどんどん増えていきます。

プログラムでは、扱うデータに合わせて独自の型を定義できます。Pythonでは `class` 文を使い、その型の属性やメソッドを定義します。

この章では、生徒を表す `Student` 型を定義します。

---

## 8-2. 今回作るもの

今回は、生徒を表す `Student` クラスを定義します。

`Student` に、インスタンスを初期化する `__init__` と、結果を表示する `show_result()` を定義します。

`__init__` で受け取った名前と点数は、それぞれのインスタンスに保存します。

```python
# Student という新しい型を定義します。
class Student:
    # インスタンスを作るときに名前と点数を受け取るメソッドを定義します。
    def __init__(self, name, score):
        # 受け取った name をこのインスタンスの name 属性に代入します。
        self.name = name

        # 受け取った score をこのインスタンスの score 属性に代入します。
        self.score = score

    # name と score を表示するメソッドを定義します。
    def show_result(self):
        # name と score をコロンで区切って表示します。
        print(self.name, ":", self.score)
```

これを見ると、

```text
Student
├─ __init__ (初期化メソッド)
└─ show_result (メソッド)

student インスタンス
├─ name = "たろう"
└─ score = 80
```

`Student` クラスがメソッドを定義し、作ったインスタンスがそれぞれの `name` と `score` を持ちます。

---

## 8-3. サンプルコード

[student_class.py](./student_class.py) を開いてください。

`student` は「生徒」、`class` は「クラス」という意味です。

```python
# Student という新しい型を定義します。
class Student:
    # インスタンスを作るときに名前と点数を受け取るメソッドを定義します。
    def __init__(self, name, score):
        # 受け取った name をこのインスタンスの name 属性に代入します。
        self.name = name

        # 受け取った score をこのインスタンスの score 属性に代入します。
        self.score = score

    # name と score を表示するメソッドを定義します。
    def show_result(self):
        # name と score をコロンで区切って表示します。
        print(self.name, ":", self.score)


# Student クラスから、たろうのインスタンスを作ります。
student = Student("たろう", 80)

# student を通じて name 属性を表示します。
print(student.name)

# student を通じて score 属性を表示します。
print(student.score)

# student の show_result() を呼び出します。
student.show_result()

# Student クラスから、はなこのインスタンスを作ります。
student2 = Student("はなこ", 95)

# student2 の show_result() を呼び出します。
student2.show_result()
```

実行結果:

```text
たろう
80
たろう : 80
はなこ : 95
```

## 8-4. `class` でクラスを定義する

クラスを作るときは `class` を使います。

```python
class Student:
```

これは、

> `Student` という名前のクラスを定義します

という意味です。インデントした行がクラス本体になります。

クラス本体に代入文や関数定義を書くと、それらはクラスの属性になります。

---

## 8-5. `__init__` で初期値を受け取る

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
```

`__init__` は、インスタンスを作るときにPythonから呼び出されるメソッドです。

`Student("たろう", 80)` のようにクラスを呼び出すと、Pythonはインスタンスを作り、そのインスタンスを `self` として `__init__` を呼び出します。`name` と `score` は受け取る値の名前です。

`self.name` と `self.score` は、作ったインスタンスの属性です。別々に作ったインスタンスは、それぞれ別の名前と点数を持てます。

一方、クラス本体に直接 `school_name = "桜高校"` のように書くと、クラス属性になります。クラス属性はクラスに定義され、各インスタンスに個別の値を保存するものではありません。この章の `name` と `score` は、`self.name` と `self.score` へ代入して設定するインスタンス属性です。

---

## 8-6. メソッドを定義する

クラス本体には関数も定義できます。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show_result(self):
        print(self.name, ":", self.score)
```

これで `Student.show_result` が定義されました。

クラスの属性として定義された関数は **メソッド** と呼ばれます。インスタンスからメソッドを呼び出すと、そのインスタンスが第1引数として渡されます。

そのため、この例では `student.show_result()` を呼び出すと、`student` が `self` として渡されます。

---

## 8-7. クラスの中もインデントする

関数や条件分岐と同じように、クラスの中も右へずらして書きます。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
```

このインデントによって、

> `__init__` が `Student` クラスのメソッドであり、その中の代入文がメソッド本体である

とPythonへ伝えています。

---

## 8-8. `Student(...)` でインスタンスを作る

サンプルでは、

```python
student = Student("たろう", 80)
```

と書いています。

`student` は `Student` クラスから作ったインスタンスです。クラスを呼び出すとインスタンスが作られ、そのとき `__init__` が呼び出されて `name` と `score` が設定されます。

たとえば、次のように別々の値を持つインスタンスを作れます。

```python
student = Student("たろう", 80)
student2 = Student("はなこ", 95)
```

`student.name` は `"たろう"`、`student2.name` は `"はなこ"` です。

---

## 8-9. `student.name` の `.` は何？

```python
print(student.name)
```

は、`student` インスタンスの `name` 属性を参照します。この属性は `__init__` の `self.name = name` で設定されています。

```text
student . name
   ↑       ↑
インスタンス インスタンス属性
```

です。

同じように、

```python
student.show_result()
```

は、`student` を通じて `show_result` メソッドを呼び出します。このとき `student` がメソッドの第1引数になります。

---

## 8-10. `self` はインスタンス自身

サンプルには、

```python
def show_result(self):
    print(self.name, ":", self.score)
```

と `self` が出てきます。

`self` はPythonの予約語ではありません。このメソッドでは第1引数の名前として使っており、インスタンス経由で呼び出すと、そのインスタンスが第1引数として渡されます。

そのため、

```python
self.name
```

は、

> `self` を通じて参照する `name` 属性

という意味です。この例では `name` は `__init__` で設定したインスタンス属性です。

---

## 8-11. 関数との関係

7章では、関数を、

> 処理をひとまとめにする仕組み

として学びました。

クラスは関数とは役割が異なります。クラス定義は新しい型を作り、その型の属性やメソッドを定義します。

```text
関数
→ 呼び出せる処理を定義する

クラス
→ 新しい型と、その属性やメソッドを定義する
```

この章の例では、生徒に関係する属性やメソッドを同じクラスに定義しています。

---

## 8-12. この章で扱う範囲

この章では、`__init__` で初期値を受け取り、インスタンス属性とメソッドを使うところまで扱います。

継承、`super()`、`__init__` 以外の特殊メソッドなどは、この章では扱いません。

## 8-13. 自分で変えてみる

インスタンス属性を1つ追加してみましょう。

```python
class Student:
    def __init__(self, name, score, class_name):
        self.name = name
        self.score = score
        self.class_name = class_name

    def show_result(self):
        print(self.name, ":", self.score)


student = Student("たろう", 80, "A")
print(student.class_name)
```

作るときには、名前と点数に加えて学級名も渡します。`student.class_name` は `"A"` です。

元の `Student` に別のメソッドを追加することもできます。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show_result(self):
        print(self.name, ":", self.score)

    def show_name(self):
        print(self.name)
```

メソッド内で `self.name` のようにインスタンスから属性を参照する書き方を確認してみてください。

## 8-14. ここまでで覚えること

この章で使った書き方を確認しましょう。

1. クラスは新しい種類の値（型）を定義する仕組み
2. `class` でクラスを作る
3. クラスの中はインデントする
4. `__init__` でインスタンスを初期化できる
5. `self.name` のようにインスタンス属性を設定できる
6. `A.B` で `A` の属性 `B` を参照できる
7. `Student(...)` でインスタンスを作って使う
8. インスタンスからメソッドを呼ぶと、そのインスタンスが第1引数へ渡される
