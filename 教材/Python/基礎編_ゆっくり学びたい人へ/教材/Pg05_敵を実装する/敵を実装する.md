# Pg5. pygame「敵を実装する」

Pg4では、プレイヤーから弾を撃てるようになりました。

でも、まだ何も倒せません。

> **「撃てるようになった。で、何を撃つん？？？」**

今回のプログラムは、画面上から敵を出し、弾が当たると敵を消します。

ここまで来ると、一気にシューティングゲームらしくなります。

---

## Pg5-1. 今回作るもの

[enemy_collision.py](./enemy_collision.py) を開いてください。

`enemy` は「敵」、`collision` は「衝突・当たり判定」という意味です。

今回は、

```text
敵が上から降りてくる
↓
スペースキーで撃つ
↓
弾が当たる
↓
敵が消える
```

この章のプログラムは、ここまでの機能を持つゲームです。

## Pg5-2. サンプルコード

### 画面更新の間隔を調整する `clock`

`pygame.time.Clock()` は、画面更新の間隔を調整するための時計を用意します。このプログラムは `clock` という名前で使い、繰り返しの最後にある `clock.tick(60)` で、1秒間の画面更新を最大60回に制限します。[pygameの公式説明](https://www.pygame.org/docs/ref/time.html#pygame.time.Clock.tick)

```python
# pygame をインポートする
import pygame

# pygame を初期化する
pygame.init()

# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
# pygame画面のタイトルに「敵を実装する」をセットする
pygame.display.set_caption("敵を実装する")

# 画面更新の間隔を調整する時計を用意する（後でclock.tick(60)に使う）
# clock に pygame.time.Clock() で作った時計を入れる
clock = pygame.time.Clock()

# player_x に320を入れる
player_x = 320
# player_y に400を入れる
player_y = 400
# player_speed に5を入れる
player_speed = 5

# bullets に空のリストを入れる
bullets = []
# bullet_speed に8を入れる
bullet_speed = 8

# enemies に [160, 80]、[320, 40]、[480, 100] を入れる
enemies = [
    [160, 80],
    [320, 40],
    [480, 100]
]
# enemy_speed に1を入れる
enemy_speed = 1

# running に True を入れる
running = True

# running が True の間、繰り返す
while running:
    # pygameで起きたイベントを1つずつ event に入れて繰り返す
    for event in pygame.event.get():
        # event.type が pygame.QUIT なら
        if event.type == pygame.QUIT:
            # running に False を入れる
            running = False

        # event.type が pygame.KEYDOWN なら
        if event.type == pygame.KEYDOWN:
            # event.key が pygame.K_SPACE なら
            if event.key == pygame.K_SPACE:
                # bullets に [player_x, player_y - 20] を追加する
                bullets.append([player_x, player_y - 20])

    # keys に pygame.key.get_pressed() の戻り値を入れる
    keys = pygame.key.get_pressed()

    # keys[pygame.K_LEFT] が True なら
    if keys[pygame.K_LEFT]:
        # player_x に player_x から player_speed を引いた値を入れる
        player_x = player_x - player_speed

    # keys[pygame.K_RIGHT] が True なら
    if keys[pygame.K_RIGHT]:
        # player_x に player_x と player_speed を足した値を入れる
        player_x = player_x + player_speed

    # keys[pygame.K_UP] が True なら
    if keys[pygame.K_UP]:
        # player_y に player_y から player_speed を引いた値を入れる
        player_y = player_y - player_speed

    # keys[pygame.K_DOWN] が True なら
    if keys[pygame.K_DOWN]:
        # player_y に player_y と player_speed を足した値を入れる
        player_y = player_y + player_speed

    # player_x に max(20, min(620, player_x)) の値を入れる
    player_x = max(20, min(620, player_x))
    # player_y に max(20, min(460, player_y)) の値を入れる
    player_y = max(20, min(460, player_y))

    # bullets から bullet を1つずつ取り出して繰り返す
    for bullet in bullets:
        # bullet[1] に bullet[1] から bullet_speed を引いた値を入れる
        bullet[1] = bullet[1] - bullet_speed

    # bullets に bullet[1] > -20 の bullet だけを入れる
    bullets = [bullet for bullet in bullets if bullet[1] > -20]

    # enemies から enemy を1つずつ取り出して繰り返す
    for enemy in enemies:
        # enemy[1] に enemy[1] と enemy_speed を足した値を入れる
        enemy[1] = enemy[1] + enemy_speed

    # bullets_to_remove に空のリストを入れる
    bullets_to_remove = []
    # enemies_to_remove に空のリストを入れる
    enemies_to_remove = []

    # bullets から bullet を1つずつ取り出して繰り返す
    for bullet in bullets:
        # bullet_rect に pygame.Rect(bullet[0] - 3, bullet[1] - 10, 6, 20) をセットする
        bullet_rect = pygame.Rect(
            bullet[0] - 3,
            bullet[1] - 10,
            6,
            20
        )

        # enemies から enemy を1つずつ取り出して繰り返す
        for enemy in enemies:
            # enemy_rect に pygame.Rect(enemy[0] - 20, enemy[1] - 15, 40, 30) をセットする
            enemy_rect = pygame.Rect(
                enemy[0] - 20,
                enemy[1] - 15,
                40,
                30
            )

            # bullet_rect.colliderect(enemy_rect) が True なら
            if bullet_rect.colliderect(enemy_rect):
                # bullets_to_remove に bullet を追加する
                bullets_to_remove.append(bullet)
                # enemies_to_remove に enemy を追加する
                enemies_to_remove.append(enemy)

    # bullets_to_remove から bullet を1つずつ取り出して繰り返す
    for bullet in bullets_to_remove:
        # bullet が bullets に含まれているなら
        if bullet in bullets:
            # bullets から bullet を削除する
            bullets.remove(bullet)

    # enemies_to_remove から enemy を1つずつ取り出して繰り返す
    for enemy in enemies_to_remove:
        # enemy が enemies に含まれているなら
        if enemy in enemies:
            # enemies から enemy を削除する
            enemies.remove(enemy)

    # screen を (10, 10, 30) で塗る
    screen.fill((10, 10, 30))

    # player_points に (player_x, player_y - 20)、(player_x - 20, player_y + 20)、(player_x + 20, player_y + 20) を入れる
    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    # screen に (100, 200, 255) と player_points を使った多角形を描く
    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    # bullets から bullet を1つずつ取り出して繰り返す
    for bullet in bullets:
        # screen に (255, 240, 100) と (bullet[0] - 3, bullet[1] - 10, 6, 20) を使った四角形を描く
        pygame.draw.rect(
            screen,
            (255, 240, 100),
            (bullet[0] - 3, bullet[1] - 10, 6, 20)
        )

    # enemies から enemy を1つずつ取り出して繰り返す
    for enemy in enemies:
        # screen に (255, 100, 100) と (enemy[0] - 20, enemy[1] - 15, 40, 30) を使った四角形を描く
        pygame.draw.rect(
            screen,
            (255, 100, 100),
            (enemy[0] - 20, enemy[1] - 15, 40, 30)
        )

    # このフレームの描画内容を画面に反映する
    pygame.display.flip()

    # 1秒間に60回を上限にして clock を進める
    clock.tick(60)

# pygame を終了する
pygame.quit()
```

## Pg5-5. 敵の見た目

今回は敵を四角形で描きます。

```python
# screen に (255, 100, 100) と (enemy[0] - 20, enemy[1] - 15, 40, 30) を使った四角形を描く
pygame.draw.rect(
    screen,
    (255, 100, 100),
    (enemy[0] - 20, enemy[1] - 15, 40, 30)
)
```

`pygame.draw.rect()` は、四角形を**実際に画面へ描く**関数です。

今回は左から順に、

```text
screen
→ どの画面へ描くか

(255, 100, 100)
→ 何色で描くか

(enemy[0] - 20, enemy[1] - 15, 40, 30)
→ 左端・上端・幅・高さ
```

`(255, 100, 100)` はRGBです。

```text
赤 = 255
緑 = 100
青 = 100
```

赤が強いので、敵は赤系の色になります。ここでの255・100・100は**色の強さ**です。

最後の4つは、敵の位置と大きさをピクセル単位で指定しています。

```text
enemy[0] - 20
→ 左端のx座標

enemy[1] - 15
→ 上端のy座標

40
→ 幅40ピクセル

30
→ 高さ30ピクセル
```

`enemy` は、`enemies` から1体ずつ取り出した**敵1体**です。

```text
enemy[0] → その敵の横位置
enemy[1] → その敵の縦位置
```

このコードでは、この座標が敵の中心です。

幅40の半分は20、高さ30の半分は15なので、

```text
40 ÷ 2 = 20
30 ÷ 2 = 15
```

中心から20ピクセル左、15ピクセル上を左上にすると、**幅40・高さ30の四角形の中心をenemyの座標へ合わせられます**。

このプログラムは、プレイヤーを青い三角形、敵を赤い四角形で描き、画面上で見分けられるようにします。

最後の方で同梱素材へ差し替えます。

## Pg5-6. 当たり判定が必要

弾と敵を描いただけでは、重なっても何も起きません。

> **「当たってるやん！なんで素通りすんねん！！！」**

そこで、

> 弾の場所と敵の場所が重なっているか

を調べます。

これが **当たり判定** です。

---

## Pg5-7. `pygame.Rect` を使う

このプログラムは、当たり判定をする前に、弾と敵の**位置と大きさを持つ四角**を用意します。

まず弾です。

```python
# bullet_rect に pygame.Rect(bullet[0] - 3, bullet[1] - 10, 6, 20) をセットする
bullet_rect = pygame.Rect(
    bullet[0] - 3,
    bullet[1] - 10,
    6,
    20
)
```

`pygame.Rect()` は、

```text
左端のx
上端のy
幅
高さ
```

の順で四角形の情報を受け取ります。

弾は幅6・高さ20なので、半分の3と10を引き、弾の座標を四角形の中心へ合わせています。

敵も同じです。

```python
# enemy_rect に pygame.Rect(enemy[0] - 20, enemy[1] - 15, 40, 30) をセットする
enemy_rect = pygame.Rect(
    enemy[0] - 20,
    enemy[1] - 15,
    40,
    30
)
```

敵は幅40・高さ30なので、プログラムは半分の20と15を引いて中心を合わせます。

大事なのは、**`pygame.Rect()` を実行しただけでは画面には何も描かれない**ことです。

ここでは、あとで位置の比較に使える四角形の情報を用意しています。

---

## Pg5-8. Rectは「位置と大きさを持つ四角」

`Rect` は、左上の位置・幅・高さを持つ四角形です。

このプログラムは当たり判定にRectを使います。**Rectそのものが当たり判定専用というわけではありません**。

```text
pygame.Rect(...)
→ 四角形の位置と大きさを用意する
→ 画面には描かない

pygame.draw.rect(...)
→ 四角形を実際に画面へ描く
```

今描いている弾と敵も四角形なので、同じ位置と大きさのRectを用意すると分かりやすいです。

```text
弾
┌──┐
│  │
│  │
└──┘

敵
┌────────┐
│        │
└────────┘
```

次に、この2つのRectが重なっているかを調べます。

## Pg5-9. `colliderect()`

```python
# bullet_rect.colliderect(enemy_rect) が True なら
if bullet_rect.colliderect(enemy_rect):
```

では、

```text
bullet_rect → 弾の四角形
enemy_rect  → 敵の四角形
```

を比較しています。

`bullet_rect.colliderect(enemy_rect)` は、

- 2つのRectが重なっている → `True`
- 重なっていない → `False`

この処理の結果が、上に示した値です。

`if` は結果が `True` のときだけ中の処理を実行するので、この1行は、

> **弾の四角形と敵の四角形が重なったら、次の処理をする**

という意味です。

重なったときは、

```python
# bullets_to_remove に bullet を追加する
bullets_to_remove.append(bullet)
# enemies_to_remove に enemy を追加する
enemies_to_remove.append(enemy)
```

として、当たった弾と敵をあとで消すリストへ入れます。

重なっていなければ `False` なので、この2行は実行されません。

## Pg5-10. その場ですぐ消さない理由

`for` でリストを順番に見ている途中に、そのリストから要素を消すと、処理が分かりにくくなったり、飛ばしてしまうことがあります。

なので今回は、

```text
当たったものを記録
↓
判定が全部終わる
↓
あとからまとめて消す
```

という流れにしています。

## Pg5-11. 当たった弾を消す

```python
# bullets_to_remove から bullet を1つずつ取り出して繰り返す
for bullet in bullets_to_remove:
    # bullet が bullets に含まれているなら
    if bullet in bullets:
        # bullets から bullet を削除する
        bullets.remove(bullet)
```

このコードで、プログラムは当たった弾を消します。
