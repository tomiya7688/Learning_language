## 起動から終了までを `main()` にまとめる

`def main():` は、起動時の処理に `main`（メイン）という名前を付けています。`main()` の `()` は、この名前の処理を呼び出す指定です。字下げされた行がその処理に含まれます。

画面を作る処理は `main()` の中にあります。`if __name__ == "__main__":` は、このファイルを直接実行したときにだけ `main()` を呼ぶ条件です。別ファイルから読み込んだだけではウィンドウを開きません。

`pygame.init()` はpygameを使う準備、`pygame.quit()` は終了時の片付けです。`try` の中でエラーが起きても、`finally` の中の片付けは行われます。

`screen` は描画先、`clock` は時計、`running` は実行を続けるかを表します。`running` が `False` になると繰り返しを終えます。ウィンドウを閉じる操作は `pygame.QUIT` というイベント（操作や変化を知らせる情報）で届きます。

`pygame.display.set_mode((640, 480))` の数値は幅640、高さ480ピクセルです。左上が `(0, 0)` で、右へ進むほどx、下へ進むほどyが増えます。`fill((10, 10, 30))` は赤・緑・青の強さを0〜255で指定した暗い青で塗る処理です。

`pygame.display.flip()` は描いた内容を表示へ反映します。`clock.tick(60)` は更新を最大60回/秒に調整します。時計は移動距離そのものを決めません。

## 自機の位置と描画を `Player` にまとめる

自機の位置だけを独立した変数にすると、描く処理とどの自機の位置なのかを照らし合わせる必要があります。この章では、自機の位置と自機を描く処理を `Player` にまとめます。

`class Player:` は `Player`（プレイヤー）という新しい型の定義です。`player = Player()` で、その型の自機を1つ作ります。型の定義と、作った自機そのものは別です。

`__init__` は作るときに呼ばれる処理です。`self` はその自機自身を指します。`self.rect` は自機ごとに持つ位置と大きさです。クラスの中で定義した `draw` のような関数を「メソッド」と呼び、`player.draw(screen)` でこの自機を描く処理を呼びます。

`pygame.Rect(0, 0, 40, 40)` は左・上・幅・高さを指定した長方形です。自機の中心を `(320, 400)` に置き、`midtop`（上辺の中央）、`bottomleft`（左下）、`bottomright`（右下）の3点を結んで三角形を描きます。`pygame.draw.polygon` は複数の点を結んだ形を描く道具です。

`rect` はrectangle（長方形）の略です。今後は移動と当たり判定にもこの位置を使います。画面を更新する `main()` に自機の形の計算を混ぜず、`Player.draw()` に置いてください。

### `player_ship.py` の `Player`

次の箇所は、上の表の完成コードにも入っています。追加する場合は、そのファイルの対応する定義をこの章の版へ置き換えてください。

```python
# Player という型を定義する
class Player:
    # __init__ の処理を定義する
    def __init__(self):
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, 40, 40) を入れる
        self.rect = pygame.Rect(0, 0, 40, 40)
        # self.rect.center に (320, 400) を入れる
        self.rect.center = (320, 400)

    # draw の処理を定義する
    def draw(self, screen):
        # points は自機の三角形を結ぶ3点の一覧です。
        # points に [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright] を入れる
        points = [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright]
        # pygame.draw.polygon(screen, (100, 200, 255), points) を実行する
        pygame.draw.polygon(screen, (100, 200, 255), points)
```

## この章のコード全体

```python
# pygame を読み込む
import pygame

# Player という型を定義する
class Player:
    # __init__ の処理を定義する
    def __init__(self):
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, 40, 40) を入れる
        self.rect = pygame.Rect(0, 0, 40, 40)
        # self.rect.center に (320, 400) を入れる
        self.rect.center = (320, 400)

    # draw の処理を定義する
    def draw(self, screen):
        # points は自機の三角形を結ぶ3点の一覧です。
        # points に [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright] を入れる
        points = [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright]
        # pygame.draw.polygon(screen, (100, 200, 255), points) を実行する
        pygame.draw.polygon(screen, (100, 200, 255), points)

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # 終了時にfinallyの片付けが行われるように、ゲームを動かす
    try:
        # screen は画面。pygameが用意した描画先です。
        # screen に pygame.display.set_mode((640, 480)) を入れる
        screen = pygame.display.set_mode((640, 480))
        # pygame.display.set_caption('プレイヤーを表示する') を実行する
        pygame.display.set_caption('プレイヤーを表示する')

        # clock は時計。画面更新を最大60回/秒に調整します。
        # clock に pygame.time.Clock() を入れる
        clock = pygame.time.Clock()

        # player はプレイヤー。ここでは操作する自機です。
        # player に Player() を入れる
        player = Player()

        # running は実行中かどうか。Falseで繰り返しを終えます。
        # running に True を入れる
        running = True
        # running が成り立つ間、繰り返す
        while running:
            # pygame.event.get() から event を1つずつ取り出して繰り返す
            for event in pygame.event.get():
                # event.type == pygame.QUIT が成り立つなら
                if event.type == pygame.QUIT:
                    # running は実行中かどうか。Falseで繰り返しを終えます。
                    # running に False を入れる
                    running = False
            # not running が成り立つなら
            if not running:
                # この繰り返しを終える
                break

            # screen.fill((10, 10, 30)) を実行する
            screen.fill((10, 10, 30))

            # player.draw(screen) を実行する
            player.draw(screen)

            # pygame.display.flip() を実行する
            pygame.display.flip()
            # clock.tick(60) を実行する
            clock.tick(60)
    finally:
        # pygame.quit() を実行する
        pygame.quit()

# __name__ == '__main__' が成り立つなら
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 保存先へ移動して、入口ファイルを実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の入口ファイルを保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe player_ship.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python player_ship.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。

## 1か所変えて比べる

再実行は、VS Codeの **表示 → ターミナル** で先ほどのターミナルを開いてください。Windowsは `.\.venv\Scripts\python.exe player_ship.py`、macOS / Linuxは `.venv/bin/python player_ship.py` を入力してEnterキーを押してください。変更前と比べてください。閉じる前のウィンドウがあれば、先に閉じてください。
