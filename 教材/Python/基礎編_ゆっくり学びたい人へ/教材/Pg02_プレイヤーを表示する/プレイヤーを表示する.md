## Pg2-2. サンプルコード

### 画面更新の間隔を調整する `clock`

`pygame.time.Clock()` は、画面更新の間隔を調整するための時計を用意します。このコードでは `clock` という名前で使い、繰り返しの最後にある `clock.tick(60)` で、1秒間の画面更新を最大60回に制限します。[pygameの公式説明](https://www.pygame.org/docs/ref/time.html#pygame.time.Clock.tick)

```python
# pygame をインポートする
import pygame

# pygame を初期化する
pygame.init()

# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
# pygame画面のタイトルに「プレイヤーを表示する」をセットする
pygame.display.set_caption("プレイヤーを表示する")

# 画面更新の間隔を調整する時計を用意する（後でclock.tick(60)に使う）
# clock に pygame.time.Clock() で作った時計を入れる
clock = pygame.time.Clock()

# player_x に320を入れる
player_x = 320
# player_y に400を入れる
player_y = 400

# running に True を入れる
running = True

# running が True の間、繰り返す
while running:
    # pygameで起きたイベントを1つずつ event に入れて繰り返す
    for event in pygame.event.get():
        # event.type が pygame.QUIT なら
        if event.type == pygame.QUIT:
            # running に False を入れる
            running = False

    # screen を (10, 10, 30) で塗る
    screen.fill((10, 10, 30))

    # player_points に (player_x, player_y - 20)、(player_x - 20, player_y + 20)、(player_x + 20, player_y + 20) を入れる
    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    # screen に (100, 200, 255) と player_points を使った多角形を描く
    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    # このフレームの描画内容を画面に反映する
    pygame.display.flip()

    # 1秒間に60回を上限にして clock を進める
    clock.tick(60)

# pygame を終了する
pygame.quit()
```

実行すると、暗い背景の下側に三角形のプレイヤーが表示されます。

## Pg2-3. 座標って何？

画面の場所は、数字で指定します。

pygameでは基本的に、

```text
左上
(0, 0)
  ┌────────→ x
  │
  │
  │
  ↓
  y
```

という向きです。

横方向が `x`、縦方向が `y` です。

---

## Pg2-4. xは横、yは縦

今回は、

```python
# player_x に320を入れる
player_x = 320
# player_y に400を入れる
player_y = 400
```

としています。

640×480の画面なので、

```text
x = 320
→ だいたい横の中央

y = 400
→ 画面のかなり下
```

です。

シューティングゲームの自機らしく、下の方へ置いています。

---

## Pg2-5. 座標は難しいものではない

座標は、画面のどこに図形を置くかを数字で表したものです。

たとえば、

```python
# player_x に100を入れる
player_x = 100
# player_y に100を入れる
player_y = 100
```

へ変えると、プレイヤーは左上寄りへ移動します。

まだキー操作はありません。

数字を変えたら場所が変わる、だけ確認してください。

## Pg2-6. 背景を塗る

最初に、ゲーム画面全体を一色で塗ります。

```python
# screen を (10, 10, 30) で塗る
screen.fill((10, 10, 30))
```

`screen` は、最初に

```python
# screen に640×480のpygame画面をセットする
screen = pygame.display.set_mode((640, 480))
```

で作ったゲーム画面に付けた名前です。

`fill` は「満たす」という意味で、`screen.fill(...)` はその画面を指定した色で塗りつぶします。

`screen.fill((10, 10, 30))` は、括弧が2重に見えます。

- 外側の `(...)` は `fill` を呼び出すための括弧
- 内側の `(10, 10, 30)` は1色分の3つの数字

です。

色の3つの数字は、順番に **赤・緑・青** を表します。この表し方をRGBと呼びます。

```text
赤 = 10
緑 = 10
青 = 30
```

それぞれ **0〜255の整数** で指定します。

- `0` は、その色の光を使わない
- `255` は、その色を最大まで使う

という意味です。

今回は赤10・緑10・青30なので、全体としてかなり暗く、少し青みのある背景になります。

この3つの数字は位置や大きさではなく、**色を決める数字**です。

---

## Pg2-7. なんで毎回背景を塗るの？

pygameでは、ゲームループのたびにその瞬間の画面を描き直します。

今回なら、

```text
画面全体をfillで塗る
↓
プレイヤーを描く
↓
flip()で画面へ反映する
↓
また最初から
```

という順番です。

`fill()` が「背景だけ」を自動で見分けて塗っているわけではありません。**screen全体を塗りつぶす**処理です。

そのため、プレイヤーを描いたあとに `fill()` すると、せっかく描いたプレイヤーまで上から塗りつぶして見えなくなります。

> **「一回描いたらずっと置いといてくれんの？」**

毎回、背景から順に現在の状態を描き直すことで、動いて見える画面を作ります。

---

## Pg2-8. プレイヤーの形を決める

今回は三角形を使います。

```python
# player_points に (player_x, player_y - 20)、(player_x - 20, player_y + 20)、(player_x + 20, player_y + 20) を入れる
player_points = [
    (player_x, player_y - 20),
    (player_x - 20, player_y + 20),
    (player_x + 20, player_y + 20)
]
```

三角形には3つの角があります。

その3か所を座標で指定しています。

---

## Pg2-9. 3つの点を日本語で読む

この部分も、記号だけで見る必要はありません。

```python
(player_x, player_y - 20)
```

は、

> プレイヤーの中心から20ピクセル上

```python
(player_x - 20, player_y + 20)
```

は、

> 20ピクセル左、20ピクセル下

```python
(player_x + 20, player_y + 20)
```

は、

> 20ピクセル右、20ピクセル下

です。

ここでの `20` は、ゲーム画面上の**距離を表すピクセル数**です。

Pg2-6のRGBにも数字が出てきましたが、そちらは色の強さです。同じ数字でも、コードの場所によって意味と単位が違います。

つまり `player_points` では、

> **上に1点、下に2点を置いて三角形を作っている**

ということです。

---

## Pg2-10. `pygame.draw.polygon()`

3つの点が決まったので、実際に三角形を描きます。

```python
# screen に (100, 200, 255) と player_points を使った多角形を描く
pygame.draw.polygon(screen, (100, 200, 255), player_points)
```

`pygame.draw` には図形を描く機能がまとまっていて、`polygon` は「多角形」を描く関数です。

この関数には、左から順に3つのものを渡しています。

```text
screen
→ どの画面へ描くか

(100, 200, 255)
→ 何色で描くか

player_points
→ どの点を結んで形を作るか
```

`(100, 200, 255)` もRGBです。

```text
赤 = 100
緑 = 200
青 = 255
```

青が最大で、緑も強めなので、明るい水色になります。

`player_points` の中にある座標はピクセル単位です。RGBの100・200・255とは別の種類の数字です。

今回は `player_points` に3点あるので、その3点を結んだ三角形が `screen` に描かれます。

この時点ではまだ画面への表示更新はしていません。あとで `pygame.display.flip()` を呼んで、このフレームで描いた内容を画面へ反映します。

## Pg2-11. なんで画像を使わないの？

最終的には、自機・敵・ボスを教材に同梱した画像へ差し替える予定です。

でも、最初から画像を使うと、

- 画像ファイルの場所
- 読み込み
- 透明部分
- サイズ調整

などを準備する必要があります。

なので最初は、

> **図形だけでゲームを作る**

ことにします。

ゲームの仕組みが完成したあとで、見た目だけ画像へ差し替えます。

## Pg2-12. `pygame.display.flip()`

図形を描いただけでは、画面へ反映されません。

```python
# このフレームの描画内容を画面に反映する
pygame.display.flip()
```

で、

> **今回描いた画面を表示する**

と考えてください。

ゲームループでは、

```text
描く
↓
flip()
↓
描く
↓
flip()
↓
...
```

を繰り返します。

## Pg2-13. 60FPSにする

今回は、

```python
# 画面更新の間隔を調整する時計を用意する（後でclock.tick(60)に使う）
# clock に pygame.time.Clock() で作った時計を入れる
clock = pygame.time.Clock()
```

を最初に作り、

```python
# 1秒間に60回を上限にして clock を進める
clock.tick(60)
```

をゲームループの最後に入れています。

これは、

> 1秒間にだいたい60回まで

という目安でゲームループを回すために使います。

何も制限しないと、PCが出せるだけ全力でループし続けてしまいます。

> **「止まってる三角形1個にCPU全力出すな！」**

ということで、今のうちに上限を入れておきます。

## Pg2-16. 色も変えてみる

今度はプレイヤーの色を変えてみましょう。

`player_ship.py` の `pygame.draw.polygon(...)` と書かれた行を変更します。

変更する行を見つけるには、VS Codeで **Ctrl + F** を押してください。macOSでは **Command + F** です。

検索欄に、

```text
pygame.draw.polygon(
```

と入力すると、変更する行を見つけられます。

変更前は、

```python
# screen に (100, 200, 255) と player_points を使った多角形を描く
pygame.draw.polygon(screen, (100, 200, 255), player_points)
```

です。

この1行を、

```python
# screen に (255, 100, 100) と player_points を使った多角形を描く
pygame.draw.polygon(screen, (255, 100, 100), player_points)
```

へ置き換えてください。新しい `draw.polygon()` を下へ追加するのではなく、**元の1行のRGBだけを変更**します。

`(255, 100, 100)` は、赤が最大で、緑と青が100なので赤っぽい色になります。

ファイルを保存して、もう一度 `player_ship.py` を実行してください。

三角形の位置や形はそのままで、色だけが水色から赤系へ変われば成功です。

RGBは3つの数字を自分で変えて試せます。

- `(0, 0, 0)` → 黒
- `(255, 255, 255)` → 白
- `(255, 0, 0)` → 赤

どれを試す場合も、同じ `pygame.draw.polygon(...)` の行のRGBを置き換えて、保存してから再実行します。
