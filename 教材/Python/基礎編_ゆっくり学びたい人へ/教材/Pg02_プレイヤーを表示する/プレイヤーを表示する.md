## `main.py` と `game.py` の役割

実行用コードがある章では、起動するファイルを `main.py` に揃えています。Pg15は次の学習先を選ぶ案内ページなので、実行用コードはありません。`main.py` はpygameを使う準備をし、`game.py` の `Game` を起動します。ゲームの画面と繰り返しは `game.py` に書きます。自機の位置と描画は、この章から `player.py` の `Player` に書きます。ゲームの機能を増やすときは、`main.py` ではなく、その機能を担当するファイルへ追加します。

`main.py` の `main()` は起動時の処理をまとめた関数です。`from game import Game` は、同じフォルダの `game.py` から `Game` を読み込む指定です。この教材のように `main.py` を直接実行すると、Pythonは `if __name__ == "__main__":` の次にある `main()` を実行します。`main()` は `game.py` の `Game` を起動し、`Game` がゲーム画面を開きます。別のファイルから `main.py` を読み込んだだけでは、Pythonは `main()` を実行せず、ゲーム画面も開きません。

Pg1の `Game.run()` には、ウィンドウを閉じる操作の確認と画面の描画を書きました。これから自機の動きや敵の処理を足すと、すべてを `run()` に置いた場合に画面更新の流れが追いにくくなります。操作確認は `handle_events()`、画面の描画は `draw()` に分け、`run()` にはそれらを呼び出す順を残します。

## 自機の位置と描画を `Player` にまとめる

自機の位置だけを独立した変数にすると、描く処理とどの自機の位置なのかを照らし合わせる必要があります。この章では、自機の位置と自機を描く処理を `Player` にまとめます。

`class Player:` は `Player`（プレイヤー）という新しい型の定義です。`Player()` はその型から自機を1つ作ります。`game.py` の `self.player = Player()` は、作った自機を `Game` の `self.player` に保存します。型の定義と、作った自機そのものは別です。

`__init__` は自機を作ったときに呼ばれ、位置と大きさを用意する処理です。`Player` の中の `self` はその自機自身を指します。`self.rect` は自機ごとに持つ位置と大きさです。クラスの中で定義した `draw` のような関数を「メソッド」と呼びます。`game.py` の `self.player.draw(self.screen)` は、画面 `self.screen` に自機 `self.player` を描く処理を呼びます。

`pygame.Rect(0, 0, 40, 40)` は左・上・幅・高さを指定した長方形です。自機の中心を `(320, 400)` に置き、`midtop`（上辺の中央）、`bottomleft`（左下）、`bottomright`（右下）の3点を結んで三角形を描きます。`pygame.draw.polygon` は複数の点を結んだ形を描く道具です。

`rect` はrectangle（長方形）の略です。今後は移動と当たり判定にもこの位置を使います。画面の繰り返しを担当する `game.py` に自機の形の計算を混ぜず、`player.py` の `Player.draw()` に置いてください。

### `player.py` の `Player`

[`player.py` の5〜20行](./player.py#L5-L20)にある `Player` の定義を、下のコードに置き換えてください。

このコードの元ファイル：[`player.py` の 5〜20行](./player.py#L5-L20)。

```python
# Player という型を定義する
class Player:
    # __init__ の処理を定義する
    def __init__(self):
        # rect はrectangle（長方形）の略。位置・大きさと当たり判定に使います。
        # self.rect に pygame.Rect(0, 0, 40, 40) を入れる
        self.rect = pygame.Rect(0, 0, 40, 40)
        # self.rect.center に (320, 400) を入れる
        self.rect.center = (320, 400)

    # draw の処理を定義する
    def draw(self, screen):
        # points は自機の三角形を結ぶ3点の一覧です。
        # points に [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright] を入れる
        points = [self.rect.midtop, self.rect.bottomleft, self.rect.bottomright]
        # pygame.draw.polygon(screen, (100, 200, 255), points) を実行する
        pygame.draw.polygon(screen, (100, 200, 255), points)
```

## この章のコード

### `main.py`

このコードの元ファイル：[`main.py` の 1〜24行](./main.py#L1-L24)。

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # Pythonは try: の処理が終わったときもエラーで中断したときも、finally: の下の pygame.quit() を実行する
    try:
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygameを終了する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

### `game.py`

このコードの元ファイル：[`game.py` の 1〜54行](./game.py#L1-L54)。

```python
# pygame を読み込む
import pygame
# player から Player を読み込む
from player import Player

# Game という型を定義する
class Game:
    # __init__ の処理を定義する
    def __init__(self):
        # 横640、高さ480ピクセルのウィンドウを開き、あとで色や絵を描く画面を self.screen に保存する
        self.screen = pygame.display.set_mode((640, 480))
        # pygame.display.set_caption("プレイヤーを表示する") を実行する
        pygame.display.set_caption("プレイヤーを表示する")
        # pygame.time.Clock() で、画面更新の間隔を測る self.clock を作る
        self.clock = pygame.time.Clock()
        # self.player に Player() を入れる
        self.player = Player()
        # self.running を True にして、ゲーム画面の繰り返しを続ける
        self.running = True

    # run の処理を定義する
    def run(self):
        # self.running が True の間、ゲーム画面を更新する
        while self.running:
            # self.handle_events() を実行する
            self.handle_events()
            # self.running が False なら、次の画面更新をせず繰り返しを終える
            if not self.running:
                # 画面更新を繰り返す while を終える
                break
            # self.draw() を実行する
            self.draw()
            # pygame.display.flip() を実行する
            pygame.display.flip()
            # 画面更新を1秒間に最大60回に抑える
            self.clock.tick(60)

    # handle_events の処理を定義する
    def handle_events(self):
        # Pygameに届いた操作の知らせを1つずつ取り出して確認する
        for event in pygame.event.get():
            # event.type が pygame.QUIT なら、ウィンドウを閉じる操作を受けています。
            if event.type == pygame.QUIT:
                # self.running を False にし、ゲーム画面の繰り返しを終える
                self.running = False
                # 残りの操作を確認せず、操作確認の繰り返しを終える
                break

    # draw の処理を定義する
    def draw(self):
        # self.screen.fill((10, 10, 30)) を実行する
        self.screen.fill((10, 10, 30))
        # self.player.draw(self.screen) を実行する
        self.player.draw(self.screen)
```

## 保存先へ移動して `main.py` を実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の `main.py`、`game.py`、`player.py` を保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python main.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。

再実行は、VS Codeの **表示 → ターミナル** で先ほどのターミナルを開いてください。Windowsは `.\.venv\Scripts\python.exe main.py`、macOS / Linuxは `.venv/bin/python main.py` を入力してEnterキーを押してください。変更前と比べてください。閉じる前のウィンドウがあれば、先に閉じてください。
