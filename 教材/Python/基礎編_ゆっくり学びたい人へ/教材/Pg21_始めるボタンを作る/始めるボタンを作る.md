# Pg21. pygame「始めるボタンを作る」

Pg20では、タイトル画面でSpaceキーを押すとゲームが始まるようになりました。キーボードの案内を読むだけでなく、画面上のボタンを押して始めたい場合もあります。

> **「ここを押せば始まる、って見て分かるボタンが欲しい！」**

この章のゲームには、**START（開始）ボタン** があります。左クリックすると、最初の状態からプレイを始められます。

## 起動してから1回の更新が終わるまで

`main.py` の `main()` がpygameを初期化し、`Game()` を作って `run()` を呼びます。`Game` は画面と時計を持ち、入力・更新・描画を順に呼びます。`Battle` は1回の戦闘の自機・敵・弾を管理します。移動と描画は各機体や弾自身のメソッド（クラス内の関数）へ任せます。

現在の画面は `current_screen` に入っています。Gameが呼ぶのはその画面の `handle_event`（入力）、`update`（更新）、`draw`（描画）です。戦闘を進めるのはPlayingScreenだけです。

`self` はそのクラスから作ったもの自身です。`self.player` はその戦闘が持つ自機、`self.bullets` はその戦闘が持つ弾の一覧です。`__init__` は作るときの初期値を用意します。`from player import Player` は同じフォルダのplayer.pyから自機の型を読み込む指定です。

`main.py` を直接実行すると、Pythonは `if __name__ == "__main__":` の次にある `main()` を実行し、`game.py` の `Game` を起動します。`Game` がゲーム画面を開きます。別のファイルから `main.py` を読み込んだだけでは、Pythonは `main()` を実行せず、ゲーム画面も開きません。`finally` の `pygame.quit()` は、ゲームが正常に終わった場合も、エラーで中断した場合も実行されます。

### 起動用の `main.py`

このコードの元ファイル：[`main.py` の 1〜24行](./main.py#L1-L24)。

```python
# pygame を読み込む
import pygame
# game から Game を読み込む
from game import Game

# main の処理を定義する
def main():
    # pygame.init() を実行する
    pygame.init()
    # ゲームが正常に終わってもエラーで終わっても pygame.quit() を実行する
    try:
        # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
        # game に Game() を入れる
        game = Game()
        # game.run() を実行する
        game.run()
    finally:
        # pygameを終了する
        pygame.quit()

# このファイルを直接実行したときだけ main() を実行する
if __name__ == "__main__":
    # main() を実行する
    main()
```

## 開始操作をタイトルのボタンへ替える

タイトル画面の `buttons`（ボタン一覧）へ、左220、上330、幅200、高さ60のSTART（始める）を追加します。押した後の処理は `game.start_game` です。

この章からは、タイトルのSpaceキーでは開始しません。STARTの内側を左クリックしてください。新しい `Battle` が作られ、現在の画面が `PlayingScreen` へ替わります。クリア後にタイトルへ戻ってもう一度STARTを押した場合も、前の戦闘を引き継ぎません。

## 設定値の場所と意味

`settings.py` は、ゲーム内容を調整する数値をまとめた Python ファイルです。`PLAYER_SPEED = 5` は、自機を押した矢印の方向へ画面更新1回あたり5ピクセル動かします。縦横の矢印キーを同時に押すと、両方向へそれぞれ5ピクセル動きます。`player.py` は `settings.PLAYER_SPEED` を使って自機を動かします。`game.py` は `settings.WIDTH` と `settings.HEIGHT` で画面の幅と高さを決め、`settings.FPS` で1秒あたりの画面更新回数の上限を決めます。

画面を1回更新するとは、ゲーム内の位置や状態を進めて、画面を書き直すことです。画面の位置・幅・高さはピクセル（画面上の点1つ）で表します。速さは1回の画面更新で動くピクセル数、敵の出現間隔や弾の発射間隔は次の動作までの画面更新回数です。間隔の数値は秒ではありません。`FPS = 60` は1秒間に画面を更新する回数の上限を60回にします。画面が毎秒60回更新されているときは、60回が約1秒、90回が約1.5秒、120回が約2秒です。更新が毎秒60回より少ない場合は、間隔にかかる時間が長くなります。

| 名前 | 意味 | この章の値 |
| --- | --- | --- |
| `WIDTH` | ゲーム画面の横幅（ピクセル） | `640` |
| `HEIGHT` | ゲーム画面の縦幅（ピクセル） | `480` |
| `FPS` | ゲーム画面を1秒間に更新する回数の上限（回/秒） | `60` |
| `PLAYER_X` | 自機の最初の中心位置。画面左端からの距離（ピクセル） | `320` |
| `PLAYER_Y` | 自機の最初の中心位置。画面上端からの距離（ピクセル） | `400` |
| `PLAYER_SPEED` | 押した矢印の方向へ1回の画面更新で進む距離。縦横同時に押すと両方向へ進みます（ピクセル/回） | `5` |
| `BULLET_SPEED` | 自機の弾が画面を1回更新する間に上へ動く距離（ピクセル/回） | `8` |
| `ENEMY_SPEED` | 通常の敵が画面を1回更新する間に下へ動く距離（ピクセル/回） | `1` |
| `PLAYER_HP` | 自機がゲーム開始時に持つ体力の値 | `3` |
| `ENEMY_BULLET_SPEED` | 通常の敵の弾が画面を1回更新する間に下へ動く距離（ピクセル/回） | `4` |
| `SPAWN_POSITIONS_X` | 敵を出す順に並べた横位置。各値は画面左端から敵の中心までの距離（ピクセル） | `(120, 320, 520, 220, 420, 100, 540)` |
| `SPAWN_INTERVAL` | 次の敵が出現するまでの画面更新回数。90回なら約1.5秒（FPS=60の場合） | `90` |
| `ENEMY_FIRE_INTERVALS` | 出現順の敵ごとに、次の弾を撃つまでの画面更新回数を並べた一覧 | `(60, 90, 120, 75, 105, 80, 110)` |
| `BOSS_X` | ボスの中心位置。画面左端からの距離（ピクセル） | `320` |
| `BOSS_Y` | ボスの中心位置。画面上端からの距離（ピクセル） | `90` |
| `BOSS_HP` | ボスが登場したときに持つ体力の値 | `50` |
| `BOSS_BULLET_SPEED` | ボスの弾が画面を1回更新する間に下へ動く距離（ピクセル/回） | `4` |
| `BOSS_FIRE_INTERVAL` | ボスが次の弾を撃つまでの画面更新回数。120回なら約2秒（FPS=60の場合） | `120` |
| `BOSS_BULLET_WIDTH` | ボスの弾の横幅（ピクセル） | `48` |
| `BOSS_BULLET_HEIGHT` | ボスの弾の高さ（ピクセル） | `48` |
| `BACKGROUND_SPEED` | 背景が画面を1回更新する間に下へ動く距離（ピクセル/回） | `2` |

自機の中心(320, 400)は画面の中央より下、ボスの中心(320, 90)は上側です。色の3つの値は赤・緑・青で、0が暗く255が明るい指定です。機体の `rect` は位置と大きさを一緒に持ち、移動・描画・命中に同じ長方形を使います。

HP表示はpygame-ce同梱のFreeSans Bold（freesansbold.ttf）を `pygame.font.Font(None, 36)` で用意します。Noneは自分でフォントのファイルを指定しないという意味で、36はピクセル単位のサイズです。標準フォントでは英数字を表示し、日本語対応を前提にしません。

### `title_view.py` の `TitleScreen.__init__`

[`title_view.py` の11〜26行](./title_view.py#L11-L26)にある `TitleScreen.__init__` の定義を、下のコードに置き換えてください。

このコードの元ファイル：[`title_view.py` の 11〜26行](./title_view.py#L11-L26)。

```python
# __init__ の処理を定義する
def __init__(self, game):
    # game はゲーム全体を表し、ゲーム画面や実行状態を持ちます。
    # self.game に game を入れる
    self.game = game
    # heading_font は見出し用のフォントです。
    # self.heading_font に pygame.font.Font(None, 64) を入れる
    self.heading_font = pygame.font.Font(None, 64)

    # sub_font は補足文用のフォントです。
    # self.sub_font に pygame.font.Font(None, 32) を入れる
    self.sub_font = pygame.font.Font(None, 32)
    # buttons はボタンの一覧。表示する文字と押した後の処理を持ちます。
    # self.buttons に [Button((220, 330, 200, 60), 'START', game.start_game)] を入れる
    self.buttons = [
        Button((220, 330, 200, 60), 'START', game.start_game),
    ]
```

## 保存先へ移動して `main.py` を実行する

VS Codeの **ファイル（File）→ フォルダーを開く（Open Folder）** から、この章のファイルを保存したフォルダを開いてください。

フォルダの場所を書いた文字列を「パス」と呼びます。コピー元は、この章の `main.py` を保存したフォルダです。

- Windows：エクスプローラーでそのフォルダを開き、上部のアドレス欄をクリックして、パス全体をCtrl + Cでコピーしてください。
- macOS：Finderでそのフォルダを選び、Option + Command + Cでパスをコピーしてください。
- Linux（GNOMEのファイル）：そのフォルダを開き、Ctrl + Lで場所の欄を表示してCtrl + Cでコピーしてください。

VS Codeの **表示（View）→ ターミナル（Terminal）** を開いてください。次の引用符の中を、いまコピーした保存先のパスへ置き換えて入力し、Enterキーを押してください。WindowsはCtrl + V、macOSはCommand + V、LinuxはCtrl + Shift + Vで貼り付けてください。

```text
cd "コピーした保存先フォルダのパス"
```

このフォルダにゲーム用のPython実行環境 `.venv` がまだなければ、次の作成と追加を行ってください。pygame-ceは画面描画や入力に使う追加の道具です。インストールする名前は `pygame-ce`、コードで読み込む名前は `pygame` です。既にこのフォルダの `.venv` に追加済みなら、実行のコマンドへ進んでください。

### Windows

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame-ce
```

`-m venv` は専用のPython実行環境を作る指定、`-m pip install` はそのPythonへ道具を追加する指定です。追加にはインターネット接続が必要です。

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.\.venv\Scripts\python.exe main.py
```

### macOS / Linux

VS Codeの **表示 → ターミナル** で同じターミナルを表示してください。次を1行ずつ入力し、その都度Enterキーを押してください。1行目が終わってから2行目へ進んでください。

```text
python3 -m venv .venv
.venv/bin/python -m pip install pygame-ce
```

VS Codeの **表示 → ターミナル** で同じターミナルを表示し、次を入力してEnterキーを押してください。

```text
.venv/bin/python main.py
```

ウィンドウを閉じるとプログラムが終了します。`No module named pygame` なら追加と実行に同じ `.venv` のPythonを使っているか確認してください。補助ファイル名が出て `No module named ...` となる場合は、上のファイル一覧から保存漏れを探してください。
