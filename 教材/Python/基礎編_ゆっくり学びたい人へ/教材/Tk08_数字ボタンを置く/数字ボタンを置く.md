# Tk8. 数字ボタンを置く

> **「数字を毎回キーボードで打つのは面倒！電卓の数字ボタンを押して入力したい！」**

この章の電卓は、0〜9の数字ボタンと計算記号をクリックして、整数の足し算・引き算・掛け算・割り算ができる電卓です。たとえば電卓画面の「1」「0」「+」「2」「=」の各ボタンを順に押すと、`答え: 12.0` と表示されます。

数字の配置は、電卓で使われることが多い上段が「7・8・9」、下段が「1・2・3」の並びに合わせます。足し算・引き算・答えを出すボタンは算数の「+」「-」「=」、掛け算と割り算はPythonで使う「*」「/」に合わせます。「C」は英語のClear（消去）の頭文字です。入力や式を最初からやり直すために使います。

小数点のボタンは次のTk9で追加します。この章の数字ボタンから入力できるのは整数です。割り算の答えは `5.0` や `2.5` のように小数になることもあります。

## Tk8-1. 数字ごとに同じ処理を書かずにまとめる

「1」と「2」のボタンは、どちらも入力欄へ数字を1文字追加するボタンです。数字ごとに同じ追加処理を書けば、入力方法を変えるときに10か所を直すことになります。数字を追加する処理は `append_digit` にまとめ、ボタンごとに追加する数字を指定します。`append_digit` は「数字を追加する」という意味です。

ボタンを10個作る処理も似ています。表示する数字と配置する行・列を一覧にし、`create_digit_buttons` が一覧を順に読んでボタンを作ります。`create_digit_buttons` は「数字ボタンを作る」という意味です。クラス内で定義した関数を「メソッド」と呼びます。画面の準備だけを行うメソッドなので、電卓を作るときに一度だけ実行します。

入力欄へ数字を単純に追加するだけでは、答えが残る入力欄で電卓画面の「2」ボタンを押すと、答えの末尾へ「2」がくっついてしまいます。新しい数字から計算するため、計算直後の数字ボタンは答えを消してから数字を入れる操作にします。一方、計算直後に電卓画面の「+」などの計算記号ボタンを押した場合は、その答えを次の計算に使います。

計算後の入力欄を置き換えるかどうかも、対象の電卓の情報です。`self.replace_input` に覚えさせます。`replace_input` は「入力を置き換える」という意味です。`True` は次の数字ボタンで置き換える状態、`False` は入力中の数字の末尾へ追加する状態を表します。

数字を間違えたときは、電卓画面の「C」ボタンを押して入力・保存済みの式・表示をまとめて消せるようにします。計算後の数字入力でも同じ消去が必要なので、消去処理を `clear` にまとめて両方から使います。`clear` は「消す」という意味です。

## Tk8-2. 電卓の情報と操作を同じクラスに持たせる

画面、入力済みの式、次の数字を置き換えるかどうか、数字を追加する操作は、同じ電卓に関する情報と操作です。置き換えるかを決める情報と、消す入力欄を電卓の外へ別々に置くと、数字ボタンがどの電卓の状態を読み、どの入力欄を消すのかを対応させにくくなります。`CalculatorApp` のメソッドが同じ `self`（操作対象の電卓）の置換状態を読み、同じ `self` の入力欄と式を消す構成にすると、判定する情報と操作する画面が同じ電卓に属すると分かります。`CalculatorApp` にまとめます。クラスは、同じ対象の情報と操作をまとめて定義する仕組みです。`CalculatorApp` は「電卓アプリ」という意味です。

`CalculatorApp()` で作った個々の電卓を「インスタンス」と呼びます。クラス内の `self` は、操作対象の電卓を指します。数字と計算記号を入力順に保存する一覧は `self.calculation_parts` です。Pythonで複数の値を順に保存する一覧を「リスト」と呼びます。

画面を作る `__init__` は電卓を作ったときに実行されます。`run` は画面を表示し、利用者の操作を待ち続ける処理です。準備するタイミングと操作を待つタイミングが違うため、別のメソッドへ分けます。

「+」「-」「*」「/」のボタン用のメソッドは、数字と計算記号を保存する `add_operator` を使います。電卓画面の「=」ボタンを押したときだけ答えを出すため、計算する処理は `calculate` に分けます。`calculate` は「計算する」という意味です。掛け算・割り算を先に処理し、その後で足し算・引き算を計算します。

機能を変更するファイルは `calculator.py`、電卓を起動するファイルは `app.py` です。`app.py` の `main` は電卓を作って操作待ちを始める処理だけを担当します。`calculator` は「電卓」、`app` は「アプリ」、`main` は起動時に実行する中心の処理を表す名前です。

Tk8用の新しいフォルダを作り、次の `calculator.py` と `app.py` を両方保存してください。配布ファイルを使う場合も、両方のリンクを開いてコードを保存してください。自分で書く場合は、VS Codeで新しいファイルを2つ作り、それぞれの全体コードを書いてください。どちらの場合も、ファイル名の末尾の `.py` まで入力し、同じTk8用のフォルダへ保存してください。

### calculator.py：数字ボタンと計算処理

元ファイル：[`calculator.py` 全体](./calculator.py)。

```python
# tkinterを、このプログラムで使えるようにする
import tkinter
# functools から、処理に指定する値を先に固定する partial を読み込む
from functools import partial


# 電卓の入力欄・計算途中の式・結果表示・計算処理をまとめる CalculatorApp クラスを定義する
class CalculatorApp:
    # CalculatorApp の画面と部品を用意する __init__ を定義する
    def __init__(self):
        # self.calculation_parts（計算式の部品）に空のリストを入れる
        self.calculation_parts = []
        # self.replace_input（次の数字ボタンで入力を置き換えるか）に False を入れる
        self.replace_input = False

        # self.window（ウィンドウ）に tkinterのTkクラスから作ったウィンドウを入れる
        self.window = tkinter.Tk()
        # self.window のタイトルを「数字ボタンを置く」にする
        self.window.title("数字ボタンを置く")
        # self.window の大きさを横420、縦600にする
        self.window.geometry("420x600")

        # self.number_label（数字の案内）に self.window 内で「数字」と表示するラベルを入れる
        self.number_label = tkinter.Label(self.window, text="数字")
        # self.number_label を self.window 内に配置する
        self.number_label.pack()

        # self.number_entry（数字の入力欄）に self.window 内の1行の入力欄を入れる
        self.number_entry = tkinter.Entry(self.window)
        # self.number_entry を self.window 内に配置する
        self.number_entry.pack()

        # self.expression_label（計算式の表示）に self.window 内で「計算式:」と表示するラベルを入れる
        self.expression_label = tkinter.Label(self.window, text="計算式:")
        # self.expression_label を self.window 内に配置する
        self.expression_label.pack()

        # self.addition_button（足し算ボタン）に self.window 内で「+」と表示し、押すと self.select_addition を呼ぶボタンを入れる
        self.addition_button = tkinter.Button(
            self.window,
            text="+",
            # ボタンを押したときに呼ぶ処理として self.select_addition を登録する
            command=self.select_addition,
        )
        # self.addition_button を self.window 内に配置する
        self.addition_button.pack()

        # self.subtraction_button（引き算ボタン）に self.window 内で「-」と表示し、押すと self.select_subtraction を呼ぶボタンを入れる
        self.subtraction_button = tkinter.Button(
            self.window,
            text="-",
            # ボタンを押したときに呼ぶ処理として self.select_subtraction を登録する
            command=self.select_subtraction,
        )
        # self.subtraction_button を self.window 内に配置する
        self.subtraction_button.pack()

        # self.multiplication_button（掛け算ボタン）に self.window 内で「*」と表示し、押すと self.select_multiplication を呼ぶボタンを入れる
        self.multiplication_button = tkinter.Button(
            self.window,
            text="*",
            # ボタンを押したときに呼ぶ処理として self.select_multiplication を登録する
            command=self.select_multiplication,
        )
        # self.multiplication_button を self.window 内に配置する
        self.multiplication_button.pack()

        # self.division_button（割り算ボタン）に self.window 内で「/」と表示し、押すと self.select_division を呼ぶボタンを入れる
        self.division_button = tkinter.Button(
            self.window,
            text="/",
            # ボタンを押したときに呼ぶ処理として self.select_division を登録する
            command=self.select_division,
        )
        # self.division_button を self.window 内に配置する
        self.division_button.pack()

        # self.equals_button（計算を行うボタン）に self.window 内で「=」と表示し、押すと self.calculate を呼ぶボタンを入れる
        self.equals_button = tkinter.Button(
            self.window,
            text="=",
            # ボタンを押したときに呼ぶ処理として self.calculate を登録する
            command=self.calculate,
        )
        # self.equals_button を self.window 内に配置する
        self.equals_button.pack()

        # self.result_label（結果表示）に self.window 内で「答え:」と表示するラベルを入れる
        self.result_label = tkinter.Label(self.window, text="答え:")
        # self.result_label を self.window 内に配置する
        self.result_label.pack()

        # 数字ボタンと消去ボタンを作って配置する self.create_digit_buttons を呼び出す
        self.create_digit_buttons()

    # 数字ボタンと消去ボタンを配置する create_digit_buttons を定義する
    def create_digit_buttons(self):
        # self.digits_frame（数字ボタンの枠）に self.window 内の部品をまとめる枠を入れる
        self.digits_frame = tkinter.Frame(self.window)
        # self.digits_frame を self.window 内に配置する
        self.digits_frame.pack()
        # digit_positions（数字と配置位置）に、数字の文字列・行番号・列番号の組を並べたリストを入れる
        digit_positions = [
            ("7", 0, 0), ("8", 0, 1), ("9", 0, 2),
            ("4", 1, 0), ("5", 1, 1), ("6", 1, 2),
            ("1", 2, 0), ("2", 2, 1), ("3", 2, 2),
            ("0", 3, 1),
        ]
        # digit（数字）・row（行）・column（列）に digit_positions の各組の値を入れ、次の処理を繰り返す
        for digit, row, column in digit_positions:
            # button（数字ボタン）に、digit を表示し、押すと self.append_digit に digit を指定して実行するボタンを入れる
            button = tkinter.Button(
                self.digits_frame,
                text=digit,
                width=4,
                # digit を指定した self.append_digit の処理を、ボタンを押したときの処理として登録する
                command=partial(self.append_digit, digit),
            )
            # button を row 行・column 列へ配置し、左右と上下に4ピクセルずつ間を空ける
            button.grid(row=row, column=column, padx=4, pady=4)
        # self.clear_button（消去ボタン）に、Cを表示し、押すと self.clear を実行するボタンを入れる
        self.clear_button = tkinter.Button(
            self.digits_frame, text="C", width=4, command=self.clear
        )
        # self.clear_button を3行・0列へ配置し、左右と上下に4ピクセルずつ間を空ける
        self.clear_button.grid(row=3, column=0, padx=4, pady=4)

    # 入力欄へ数字を追加する append_digit を定義する
    def append_digit(self, digit):
        # digit（追加する数字）には、押された数字ボタンの文字列が入る
        # self.replace_input が True なら、次の処理を実行する
        if self.replace_input:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()
        # self.number_entry の末尾へ digit を挿入する
        self.number_entry.insert(tkinter.END, digit)

    # 入力・計算式・結果表示を空にする clear を定義する
    def clear(self):
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.expression_label の表示を「計算式:」に変える
        self.expression_label.config(text="計算式:")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「次の数字を入力してください」に変える
            self.result_label.config(text="次の数字を入力してください")
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False

    # 入力された数字と「+」を計算式に追加する select_addition を定義する
    def select_addition(self):
        # 「+」を指定して self.add_operator を呼び出す
        self.add_operator("+")

    # 入力された数字と「-」を計算式に追加する select_subtraction を定義する
    def select_subtraction(self):
        # 「-」を指定して self.add_operator を呼び出す
        self.add_operator("-")

    # 入力された数字と「*」を計算式に追加する select_multiplication を定義する
    def select_multiplication(self):
        # 「*」を指定して self.add_operator を呼び出す
        self.add_operator("*")

    # 入力された数字と「/」を計算式に追加する select_division を定義する
    def select_division(self):
        # 「/」を指定して self.add_operator を呼び出す
        self.add_operator("/")

    # 計算式に最後の数字を追加し、掛け算と割り算を先に計算して答えを表示する calculate を定義する
    def calculate(self):
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「最後の数字を入力してください」に変える
            self.result_label.config(text="最後の数字を入力してください")
            # calculate の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))

        # 掛け算と割り算を先に計算する
        # addition_and_subtraction_parts（足し算と引き算の部品）に self.calculation_parts の先頭の値を入れたリストを入れる
        addition_and_subtraction_parts = [self.calculation_parts[0]]

        # index（一覧の番号）に1から self.calculation_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(self.calculation_parts), 2):
            # operator（演算子）に self.calculation_parts の番号 index にある値を入れる
            operator = self.calculation_parts[index]
            # number（次の数値）に self.calculation_parts の番号 index + 1 にある値を入れる
            number = self.calculation_parts[index + 1]

            # operator が「*」なら、次の処理を実行する
            if operator == "*":
                # addition_and_subtraction_parts の末尾の要素に、その値と number を掛けた値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] * number
                )
            # operator が「*」ではなく「/」なら、次の処理を実行する
            elif operator == "/":
                # number が0なら、次の処理を実行する
                if number == 0:
                    # self.result_label の表示を「0では割れません」に変える
                    self.result_label.config(text="0では割れません")
                    # self.calculation_parts の要素をすべて削除する
                    self.calculation_parts.clear()
                    # self.replace_input に True を入れる
                    self.replace_input = True
                    # calculate の処理をここで終える
                    return

                # addition_and_subtraction_parts の末尾の要素に、その値を number で割った値を入れる
                addition_and_subtraction_parts[-1] = (
                    addition_and_subtraction_parts[-1] / number
                )
            # operator が「*」でも「/」でもなければ、次の処理を実行する
            else:
                # addition_and_subtraction_parts の末尾に operator を追加する
                addition_and_subtraction_parts.append(operator)
                # addition_and_subtraction_parts の末尾に number を追加する
                addition_and_subtraction_parts.append(number)

        # 残った足し算と引き算を左から計算する
        # answer（答え）に addition_and_subtraction_parts の先頭の値を入れる
        answer = addition_and_subtraction_parts[0]

        # index に1から addition_and_subtraction_parts の要素数未満までの番号を2ずつ増やして入れ、次の処理を繰り返す
        for index in range(1, len(addition_and_subtraction_parts), 2):
            # operator に addition_and_subtraction_parts の番号 index にある値を入れる
            operator = addition_and_subtraction_parts[index]
            # number に addition_and_subtraction_parts の番号 index + 1 にある値を入れる
            number = addition_and_subtraction_parts[index + 1]

            # operator が「+」なら、次の処理を実行する
            if operator == "+":
                # answer に answer と number を足した値を入れる
                answer = answer + number
            # operator が「+」でなければ、次の処理を実行する
            else:
                # answer に answer から number を引いた値を入れる
                answer = answer - number

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものと「 = 」と answer の値を付けた文字列に変える
        self.expression_label.config(
            text=(
                "計算式: "
                + " ".join(str(part) for part in self.calculation_parts)
                + f" = {answer}"
            )
        )
        # self.result_label の表示を「答え: 」と answer の値を含む文字列に変える
        self.result_label.config(text=f"答え: {answer}")

        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.number_entry の先頭に answer を文字列にした値を挿入する
        self.number_entry.insert(0, str(answer))
        # self.replace_input に True を入れる
        self.replace_input = True

    # ウィンドウを表示する run を定義する
    def run(self):
        # self.window を表示し、利用者の操作を待ち続ける
        self.window.mainloop()
```

## Tk8-5. 数字ボタンだけで10 + 2を計算する

新しく開いた電卓で、次のボタンをクリックしてください。数字はキーボードから入力する必要がありません。

1. 電卓画面の「1」ボタンを押してから電卓画面の「0」ボタンを押してください。「数字」の入力欄には `10` と表示されます。式の欄は `計算式:`、結果の欄は `答え:` のままです。
2. 電卓画面の「+」ボタンを押してください。式の欄に `計算式: 10.0 +` と表示され、数字の入力欄が空になります。
3. 電卓画面の「2」ボタンを押してください。数字の入力欄には `2` と表示されます。式の欄は `計算式: 10.0 +` のままです。
4. 電卓画面の「=」ボタンを押してください。式の欄は `計算式: 10.0 + 2.0 = 12.0`、結果の欄は `答え: 12.0` に変わり、数字の入力欄にも `12.0` が入ります。`.0` は小数部分が0であることを表します。

### 答えから続ける場合と、新しい数字から始める場合

入力欄に答えの `12.0` がある状態で電卓画面の「*」ボタンを押してください。式の欄は `計算式: 12.0 *` に変わり、入力欄が空になります。電卓画面の「3」「=」の各ボタンを順に押すと、式の欄は `計算式: 12.0 * 3.0 = 36.0`、結果の欄は `答え: 36.0`、入力欄は `36.0` に変わります。

答えの `36.0` がある状態で電卓画面の「8」ボタンを押してください。前の答えと式が消え、入力欄が `8`、式の欄が `計算式:`、結果の欄が `答え:` に変わります。電卓画面の「/」「2」「=」の各ボタンを順に押すと、式の欄に `計算式: 8.0 / 2.0 = 4.0`、結果の欄と入力欄に `4.0` が表示されます。

### 入力を間違えた場合

電卓画面の「C」ボタンを押してください。入力欄が空になり、式の欄は `計算式:`、結果の欄は `答え:` に戻ります。入力中の数字と保存した計算式の両方を消す操作です。たとえば電卓画面の「9」「+」「2」の各ボタンを順に押した途中でも、電卓画面の「C」ボタンを押せば `9 +` の保存済みの式と `2` の入力を消せます。

電卓画面の「1」「0」「/」「0」「=」の各ボタンを順に押してください。結果の欄は「0では割れません」に変わります。式の欄は `計算式: 10.0 /`、入力欄は `0` のままですが、保存済みの式は空になります。その後電卓画面の「8」ボタンを押すと表示と入力が消去され、入力欄に新しい `8` が入ります。電卓画面の「/」「2」「=」の各ボタンを順に押すと、答えの `4.0` が表示されます。

## Tk8-6. ボタンの数字と位置を一覧にする

元ファイル：[`calculator.py` の96〜126行](./calculator.py#L96-L126)。

```python
    # 数字ボタンと消去ボタンを配置する create_digit_buttons を定義する
    def create_digit_buttons(self):
        # self.digits_frame（数字ボタンの枠）に self.window 内の部品をまとめる枠を入れる
        self.digits_frame = tkinter.Frame(self.window)
        # self.digits_frame を self.window 内に配置する
        self.digits_frame.pack()
        # digit_positions（数字と配置位置）に、数字の文字列・行番号・列番号の組を並べたリストを入れる
        digit_positions = [
            ("7", 0, 0), ("8", 0, 1), ("9", 0, 2),
            ("4", 1, 0), ("5", 1, 1), ("6", 1, 2),
            ("1", 2, 0), ("2", 2, 1), ("3", 2, 2),
            ("0", 3, 1),
        ]
        # digit（数字）・row（行）・column（列）に digit_positions の各組の値を入れ、次の処理を繰り返す
        for digit, row, column in digit_positions:
            # button（数字ボタン）に、digit を表示し、押すと self.append_digit に digit を指定して実行するボタンを入れる
            button = tkinter.Button(
                self.digits_frame,
                text=digit,
                width=4,
                # digit を指定した self.append_digit の処理を、ボタンを押したときの処理として登録する
                command=partial(self.append_digit, digit),
            )
            # button を row 行・column 列へ配置し、左右と上下に4ピクセルずつ間を空ける
            button.grid(row=row, column=column, padx=4, pady=4)
        # self.clear_button（消去ボタン）に、Cを表示し、押すと self.clear を実行するボタンを入れる
        self.clear_button = tkinter.Button(
            self.digits_frame, text="C", width=4, command=self.clear
        )
        # self.clear_button を3行・0列へ配置し、左右と上下に4ピクセルずつ間を空ける
        self.clear_button.grid(row=3, column=0, padx=4, pady=4)
```

`tkinter.Frame(self.window)` は、電卓のウィンドウ内に部品をまとめる枠を作ります。`self.digits_frame` が数字ボタンを置く枠です。ウィンドウ内の枠は `pack()` で並べ、枠の内側の数字ボタンは `grid()` で行と列へ配置します。`pack` と `grid` は、部品を置く場所を決めるTkinterの操作です。同じ親の中で混ぜず、ウィンドウ内と枠内で分けています。

`digit_positions` は「数字と配置位置」という意味です。`("7", 0, 0)` は、表示して追加する数字が `"7"`、行番号が0、列番号が0という組です。Pythonで丸括弧に値をまとめた組を「タプル」と呼びます。行は上から、列は左から0、1、2と数えます。0のボタンだけは、4段目の中央を表す行3・列1へ置きます。Cは行3・列0です。

`for digit, row, column in digit_positions:` は、一覧の組を1つずつ読み、数字を `digit`、行番号を `row`、列番号を `column` に入れて、字下げされたボタン作成を繰り返します。「7」「8」など表示する数字が変わっても、作る処理は同じです。

`width=4` は、ボタンの幅を使っているフォントの文字4個分を基準にした大きさにします。1文字だけの数字よりボタンを広くするための値です。`padx=4` は左右、`pady=4` は上下に4ピクセルずつ余白を設ける指定です。隣のボタンとの間を空けています。

ウィンドウの `geometry("420x600")` は横420・縦600ピクセルの初期サイズです。数字ボタンを4段追加するため、[Tk7の縦400の指定](../Tk07_割り算を用意する/calculator.py#L16-L17)から、[Tk8の縦600の指定](./calculator.py#L20-L21)へ増やしています。色や文字、ボタンの実際の大きさはOSやフォントによって変わります。

## Tk8-7. 押したときに、そのボタンの数字を追加する

数字ボタンの `command=partial(self.append_digit, digit)` は、ボタンを押したときに使う数字を先に指定します。`partial` 自体を実行しても、`append_digit` はまだ実行されません。Tkinterがボタン操作を受け取ると、登録した処理が、保存された数字を指定して `append_digit` を実行します。

たとえば「7」のボタンは `"7"` を指定した処理を登録します。「8」のボタンを作るために繰り返しの変数 `digit` が変わっても、「7」のボタンに保存した指定は `"7"` のままです。ボタンを押す前に `self.append_digit(digit)` を実行してしまう記述とは、実行するタイミングが違います。

`from functools import partial` は、Pythonに同梱された道具のファイル `functools` から、値の一部を先に指定する `partial` を読み込みます。追加インストールは必要ありません。指定した処理と値を組にして後から実行する働きは、[Python公式のpartialの説明](https://docs.python.org/3/library/functools.html#functools.partial)でも確認できます。

元ファイル：[`calculator.py` の128〜136行](./calculator.py#L128-L136)。

```python
    # 入力欄へ数字を追加する append_digit を定義する
    def append_digit(self, digit):
        # digit（追加する数字）には、押された数字ボタンの文字列が入る
        # self.replace_input が True なら、次の処理を実行する
        if self.replace_input:
            # 同じ電卓の入力・計算式・結果表示を空にする self.clear を呼び出す
            self.clear()
        # self.number_entry の末尾へ digit を挿入する
        self.number_entry.insert(tkinter.END, digit)
```

`self.number_entry.insert(tkinter.END, digit)` は、数字の入力欄の末尾へ `digit` の文字列を挿入します。`tkinter.END` は末尾を指定する名前です。「1」の後に電卓画面の「0」ボタンを押すと、`"1"` の末尾へ `"0"` を加え、入力欄の文字列が `"10"` になります。この段階では数値の足し算をしていません。

`self.replace_input` が `True` の場合は、`append_digit` が先に `clear()` を実行します。前の答えや0で割る入力を消してから、押した数字を入力欄へ入れます。初回や数字入力の途中は `False` なので、既に入力した数字を消さずに続けて追加します。

## Tk8-8. 計算後に何を押したかで、答えの扱いを分ける

[`CalculatorApp.calculate` の202〜297行](./calculator.py#L202-L297)は正常な計算後に入力欄へ答えを入れ、`self.replace_input` を `True` にします。0で割る入力を見つけて計算を止めた場合も `True` にします。次の数字ボタンで新しい入力を始めるためです。

正常に計算した後、電卓画面の計算記号ボタンを押すと、`add_operator` は入力欄に残る答えを式のリストへ追加してから入力欄を空にし、`self.replace_input` を `False` にします。次の数字ボタンでは、答えが保存済みの式を消去せず、次の数字を入力します。

0で割る入力の後には、答えはありません。入力欄に残る `0` は割る数として入力した数字です。電卓画面の「1」「0」「/」「0」「=」の各ボタンを押した後に、電卓画面の「+」ボタンを押すと、`add_operator` は残った `0` を新しい式へ保存します。式の欄は `計算式: 0.0 +`、結果の欄は `答え:` に変わり、入力欄は空になります。電卓画面の「2」「=」の各ボタンを押すと、式の欄は `計算式: 0.0 + 2.0 = 2.0`、結果の欄と入力欄は `2.0` に変わります。残った `0` を使いたくない場合は、電卓画面の数字ボタンを押すか電卓画面の「C」ボタンで消去して、新しい数字から始めてください。

元ファイル：[`calculator.py` の151〜180行](./calculator.py#L151-L180)。

```python
    # 入力された数字と operator を計算式に追加する add_operator を定義する
    def add_operator(self, operator):
        # operator（演算子）には、この電卓のボタン処理が指定した計算記号が入る
        # number_text（入力文字列）に self.number_entry に入力された文字列を入れる
        number_text = self.number_entry.get()

        # number_text が空の文字列なら、次の処理を実行する
        if number_text == "":
            # self.result_label の表示を「次の数字を入力してください」に変える
            self.result_label.config(text="次の数字を入力してください")
            # add_operator の処理をここで終える
            return

        # self.calculation_parts の末尾に number_text を float で数値に変換した値を追加する
        self.calculation_parts.append(float(number_text))
        # self.calculation_parts の末尾に operator を追加する
        self.calculation_parts.append(operator)

        # part（式の部品）として self.calculation_parts の値を順に取り出し、str(part) で文字列に変換する
        # self.expression_label の表示を「計算式: 」に、self.calculation_parts の各値を文字列にして空白でつないだものを付けた文字列に変える
        self.expression_label.config(
            text="計算式: " + " ".join(str(part) for part in self.calculation_parts)
        )

        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False
```

`get()` は入力欄の文字列を読み取る操作です。`float(number_text)` は数字の文字列を小数も扱える数値に変え、リストの `append` が数値と計算記号を末尾へ保存します。`str(part)` はリストの値を表示用の文字列に変え、`" ".join(...)` が文字列を空白でつなぎます。`delete(0, tkinter.END)` は入力欄の先頭から末尾までを削除します。入力欄が空なら、電卓は「次の数字を入力してください」と表示し、式を追加せずに処理を終えます。

## Tk8-9. Cで式と入力をまとめて消す

元ファイル：[`calculator.py` の138〜149行](./calculator.py#L138-L149)。

```python
    # 入力・計算式・結果表示を空にする clear を定義する
    def clear(self):
        # self.calculation_parts の要素をすべて削除する
        self.calculation_parts.clear()
        # self.number_entry の先頭から末尾までの文字列を削除する
        self.number_entry.delete(0, tkinter.END)
        # self.expression_label の表示を「計算式:」に変える
        self.expression_label.config(text="計算式:")
        # self.result_label の表示を「答え:」に変える
        self.result_label.config(text="答え:")
        # self.replace_input に False を入れる
        self.replace_input = False
```

`self.calculation_parts.clear()` は入力済みの式のリストを空にし、入力欄の `delete` は画面の文字列を消します。保存した式と画面の入力は別々なので、片方だけを消すと以前の値が残ってしまいます。`clear` は両方を消し、式と結果の表示も初期状態へ戻します。`self.replace_input` を `False` にするため、電卓画面の「C」ボタンを押した後は数字を続けて入力できます。

## Tk8-10. 入力できる内容と今回の内容

入力欄へキーボードから数字を入力することもできます。計算直後に新しい数字をキーボードから入力する場合は、先に電卓画面の「C」ボタンを押してください。数字ボタンによる答えの置き換えは `append_digit` が行う処理であり、キーボードの入力はそのメソッドを実行しません。

数字以外の入力を案内する処理は入っていません。たとえばキーボードで `abc` と入力して計算記号を押すと、`float` が数値へ変換できず `ValueError` が起き、Tkinterが起動に使ったターミナルへエラーを表示します。電卓画面の「C」ボタンを押すと入力と式を消せるため、新しい数字を入力できます。

- 数字ボタンは、`append_digit` で押した数字を入力欄へ追加します。
- `create_digit_buttons` は数字と位置の一覧を読み、同じ作成処理で10個の数字ボタンを作ります。
- `partial` は、そのボタンの数字を先に指定し、ボタンが押されたときに使う処理を用意します。
- `replace_input` は、数字ボタンで答えを置き換えるか、入力中の数字に追加するかを区別します。
- Cは入力と保存済みの式を消します。数字ボタンも計算処理も、同じ `CalculatorApp` の情報を操作します。

コードを変更してもう一度起動する場合は、電卓の画面を閉じ、VS Codeの **表示（View）→ ターミナル（Terminal）** で実行したターミナルが入力待ちへ戻ったことを確認してください。`calculator.py` と `app.py` をCtrl + S（macOSはCommand + S）で保存し、同じターミナルにWindowsは `python app.py`、macOS / Linuxは `python3 app.py` と入力してEnterキーを押してください。保存したTk8の電卓が起動します。
