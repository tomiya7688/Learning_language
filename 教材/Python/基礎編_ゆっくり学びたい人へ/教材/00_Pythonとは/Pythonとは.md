# 0. Python とは？

この章では、まず「Pythonって何？」から説明します。

---

## 0-1. この教材で作れるようになるもの

この教材で扱う完成品の例です。

- **電卓**：数字を入力して、足し算・引き算・掛け算・割り算ができる電卓。
- **メモを保存するアプリ**：書いた文章をパソコンに保存し、あとから開いて読み返せるアプリ。
- **シューティングゲーム**：矢印キーでキャラクターを動かし、弾を撃って敵を倒すゲーム。

最初に作るのは、画面に「Hello World!」と1行表示するプログラムです。そのあと、名前を入力したり、数字を計算したりする書き方を学びます。

9章で、基本の続きを学ぶか、電卓・ブラウザの画面・ゲームを作るかを選びます。

まずは、[次の章でPythonを使う準備をしましょう](../01_環境構築/環境構築ガイド.md)。

---

## 0-2. Python はプログラミング言語

**プログラミング言語** は、コンピュータを動かすために書く言語です。Pythonは、そのひとつです。

Pythonで書いたプログラムの中身を **コード** と呼びます。

---

## 0-3. Python の特徴

Pythonの文法は、まだ読みやすいです。

たとえば、画面に文字を表示するコードは次のように書けます。

```python
print("Hello, World!")
```

この1行は、「Hello, World!」という文字を画面に表示する、という意味です。

---

## 0-4. Python 2 と Python 3

Pythonには **Python 2** と **Python 3** という大きな系列があります。

この教材では **Python 3** を使います。

古い Web ページや古い書籍では Python 2 のコードが残っていることがあります。

そのため、検索して見つけたコードが現在の Python でそのまま動かない場合は、
古い Python を前提にしていないか確認するとよいでしょう。

---

## 0-5. Python のファイル

Python のソースコードは、一般的に `.py` という拡張子のファイルへ保存します。

例:

```text
hello.py
calculator.py
game.py
```

この `.py` ファイルの中に Python のコードを書きます。

---

## 0-6. Python を学ぶときに大切なこと

この教材では、

1. 小さなコードを見る
2. 実際に動かす
3. コードを少し変更する
4. 何が変わったか確認する
5. 必要な文法を少しずつ覚える

という流れで進めます。

エラーが出ることも学習の一部です。
エラーメッセージの読み方や、つまずきやすい点も必要に応じて説明します。

次の1章では、Pythonを動かすために必要なものをインストールします。そのあと、2章でコードを書き、ファイルに保存して動かします。
