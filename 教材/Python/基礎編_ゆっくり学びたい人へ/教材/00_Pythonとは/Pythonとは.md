# 0. Python とは？

この章では、Python がどのようなプログラミング言語なのかを確認します。

---

## 0-1. この教材を一通り終えると何ができる？

**この教材を読み終えた暁にはあなたはPythonで好きなアプリが作れるようになるだろう**

この教材では、たとえば次のものを作ります。

- **電卓**：2つの数字を入力して「計算する」ボタンを押すと、足した答えが表示されます。そこから引き算・掛け算・割り算も追加します。
- **メモを保存するプログラム**：書いた文章をパソコンに保存し、あとから開いて読み返せます。
- **名前を入力して挨拶する画面**：名前を入力すると、「こんにちは」と自分の名前が表示されます。
- **シューティングゲーム**：矢印キーでキャラクターを動かし、弾を撃って敵を倒します。

最初に作るのは、画面に「Hello World!」と1行表示するプログラムです。そのあと、名前を入力したり、数字を計算したりする書き方を学びます。

9章で、基本の続きを学ぶか、電卓・ブラウザの画面・ゲームを作るかを選びます。

まずは、[次の章でPythonを使う準備をしましょう](../01_環境構築/環境構築ガイド.md)。

---

## 0-2. Python はプログラミング言語

Python は、コンピュータに「文字を表示する」「数字を計算する」などの指示を書くための言葉です。このような言葉を **プログラミング言語** と呼びます。

Pythonで書いた指示を **コード** と呼び、その指示をまとめたものが **プログラム** です。

---

## 0-3. Python の特徴

Pythonの文法は、まだ読みやすいです。

たとえば、画面に文字を表示するコードは次のように書けます。

```python
print("Hello, World!")
```

このコードは、

> Hello, World! という文字を画面に表示する

ためのプログラムです。

この例では、1行で文字を表示しています。

---

## 0-4. Python はインタプリタ型の言語

Python のコードは、一般的には Python の実行環境を使って実行します。

たとえば、

```text
hello.py
```

という Python ファイルがある場合、Windows では、

```powershell
python hello.py
```

のように実行します。

macOS / Linux では、

```bash
python3 hello.py
```

のように実行することがあります。

Python のコードを動かすには、Python の実行環境が必要です。

---

## 0-5. Python 2 と Python 3

Python には過去に **Python 2** と **Python 3** という大きな系列がありました。

現在、この教材では **Python 3** を扱います。

古い Web ページや古い書籍では Python 2 のコードが残っていることがあります。

そのため、検索して見つけたコードが現在の Python でそのまま動かない場合は、
古い Python を前提にしていないか確認するとよいでしょう。

---

## 0-6. Python のファイル

Python のソースコードは、一般的に `.py` という拡張子のファイルへ保存します。

例:

```text
hello.py
calculator.py
game.py
```

この `.py` ファイルの中に Python のコードを書きます。

---

## 0-7. Python を学ぶときに大切なこと

この教材では、

1. 小さなコードを見る
2. 実際に動かす
3. コードを少し変更する
4. 何が変わったか確認する
5. 必要な文法を少しずつ覚える

という流れで進めます。

エラーが出ることも学習の一部です。
エラーメッセージの読み方や、つまずきやすい点も必要に応じて説明します。
