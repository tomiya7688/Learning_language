# 0. Python とは？

> **「Pythonってそもそも何？これで何が作れるの？」**

この章では、まず「Pythonって何？」から説明します。

---

## 0-1. この教材で作れるようになるもの

**この教材を読み終えた暁にはあなたはPythonで好きなアプリが作れるようになるだろう**

スマートフォンやパソコンで使う電卓やメモ帳のようなものを、**アプリ** と呼びます。この教材で作るアプリには、次のようなものがあります。

- **電卓**：数字を入力して、足し算・引き算・掛け算・割り算ができる電卓。
- **メモを保存するアプリ**：書いた文章をパソコンに保存し、あとから開いて読み返せるアプリ。
- **シューティングゲーム**：矢印キーでキャラクターを動かし、弾を撃って敵を倒すゲーム。

はじめは、画面に「Hello World!」と文字を表示するところから作ります。続いて、入力した名前で挨拶を表示したり、2つの数字を足して答えを表示したりするものを作ります。

9章まで進むと、電卓を作る道、シューティングゲームを作る道、ブラウザで使う画面を作る道に分かれます。ブラウザは、インターネットのページを見るアプリです。9章では、作りたいものを選んでください。Pythonの書き方を先に練習したい場合も、9章に進み先の案内があります。

まずは、[次の章でPythonを使う準備をしてください](../01_環境構築/環境構築ガイド.md)。

## 0-2. プログラムとPython

電卓で「2 + 3」を計算すると、画面に「5」が表示されます。このような計算や文字の表示など、コンピュータで行う動き方を書いたものを **プログラム** といいます。

**プログラミング言語** は、コンピュータを動かすために書く言語です。Pythonは、プログラミング言語のひとつです。

プログラムに書く文字や記号の並びを **コード** と呼びます。次の節で、Pythonのコードと、動かした結果を見てください。

---

## 0-3. コードを書くと、どうなる？

Pythonには、コードを書くときの決まりがあります。この決まりを **文法** といいます。Pythonの文法は、まだ読みやすく、書きやすいです。

たとえば、文字を画面に表示するPythonのコードは、次の1行です。ここではコードと結果を見比べてください。コードを書く準備は1章で、実際に書いて動かす操作は2章で説明します。

**書くコードの例**

```python
print("Hello World!")
```

この1行は、「Hello World!」という文字を画面に表示する、という意味です。このコードを動かすと、次の文字が表示されます。

**動かしたときに表示される文字**

```text
Hello World!
```

この教材では、コードを書くために **Visual Studio Code（VS Code）** というアプリを使います。VS Codeの画面下に開く、操作のための文章を入力したり、動かした結果を読んだりする欄を **ターミナル** といいます。上のコードを動かしたときの「Hello World!」も、その欄に表示されます。

---

## 0-4. Python 2 と Python 3

Pythonには、**Python 2** と **Python 3** があります。Python 2は古いもので、その後に作られたPython 3が現在使われています。

この教材で使うのは **Python 3** です。

インターネットの古い記事や古い本には、Python 2で書いたコードが載っていることがあります。Python 2とPython 3では書き方が違う箇所があるため、Python 2のコードはそのままでは動かないことがあります。

---

## 0-5. 書いたコードをファイルへ保存する

パソコンに保存する文章や画像、コードなどのまとまりを **ファイル** と呼びます。Pythonのコードも、名前を付けたファイルへ保存すると、あとから開いて続きを書けます。

Pythonのコードを保存するときは、`hello.py` のように、ファイル名の最後を `.py` にしてください。ファイル名の最後に付く `.py` のような部分を **拡張子** といい、ファイルの種類を表します。

`hello.py` では、`hello` が付けた名前で、`.py` が拡張子です。名前の部分は、作るものに合わせて付けられます。

| ファイル名の例 | 名前の意味 |
| --- | --- |
| `hello.py` | `hello` は英語で「こんにちは」 |
| `calculator.py` | `calculator` は英語で「電卓」 |
| `game.py` | `game` は英語で「ゲーム」 |

コードを保存したファイルをPythonで動かすことを、**Pythonファイルを実行する** といいます。たとえば0-3のコードをファイルに保存して実行すると、ターミナルに「Hello World!」と表示されます。

## 0-6. Python を学ぶときに大切なこと

2章以降でコードを書くときは、次の順番で進めてください。

1. コードを見る
2. コードを書いて、動かしてみてください。
3. コードの中身を少し変えてみてください。
4. コードを動かし直して、変わった部分を見てください。

たとえば2章では、「Hello World!」を表示するコードを書いて動かしたあと、「Pythonの勉強を始めます」と表示するように書き換えます。保存してもう一度動かすと、表示される文章も変わります。2章では、この変更と、保存して動かし直す操作を順に説明します。

書いたコードが動かないときは、画面に理由を知らせる文章が出ることがあります。問題の場所や原因を知らせる文章を **エラーメッセージ** といいます。第2章では、書き間違えたコードと、直したコードを見比べながら説明します。

次の1章では、Pythonを動かすために必要なもののインストール手順を説明します。続く2章では、コードを書いてファイルに保存し、動かす手順を説明します。
