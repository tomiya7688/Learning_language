# Pg3. pygame「プレイヤーを操作する」

Pg2では、画面へプレイヤーを表示しました。

でも、まだそこに立っているだけです。

> **「主人公出た。で、動かんの？？？」**

今回は、矢印キーを押してプレイヤーを上下左右へ動かします。

本質はかなり単純です。

> **キーを押している間、座標を少しずつ変える**

これだけです。

---

## Pg3-1. 今回作るもの

[player_movement.py](./player_movement.py) を開いてください。

`player` は「プレイヤー」、`movement` は「動き・移動」という意味です。

矢印キーで自機を動かせるようにします。

---

## Pg3-2. サンプルコード

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("プレイヤーを操作する")

clock = pygame.time.Clock()

player_x = 320
player_y = 400
player_speed = 5

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()

    if keys[pygame.K_LEFT]:
        player_x = player_x - player_speed

    if keys[pygame.K_RIGHT]:
        player_x = player_x + player_speed

    if keys[pygame.K_UP]:
        player_y = player_y - player_speed

    if keys[pygame.K_DOWN]:
        player_y = player_y + player_speed

    player_x = max(20, min(620, player_x))
    player_y = max(20, min(460, player_y))

    screen.fill((10, 10, 30))

    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    pygame.display.flip()

    clock.tick(60)

pygame.quit()
```

実行して、矢印キーを押してください。

プレイヤーが上下左右へ動けば成功です。

---

## Pg3-3. キー入力を調べる

```python
keys = pygame.key.get_pressed()
```

で、

> **今どのキーが押されているか**

を調べられます。

Pg1では、

```python
pygame.event.get()
```

で「起きた操作」を見ました。

今回は、

> **今この瞬間に押されているキー**

を見ます。

---

## Pg3-4. 左キーを押したら

```python
if keys[pygame.K_LEFT]:
    player_x = player_x - player_speed
```

は、

> 左キーが押されていたら、xを少し減らす

という意味です。

xは右へ行くほど大きくなります。

だから、左へ行きたいなら減らします。

---

## Pg3-5. 右キーを押したら

```python
if keys[pygame.K_RIGHT]:
    player_x = player_x + player_speed
```

右へ行くときは、xを増やします。

```text
左へ
→ xを減らす

右へ
→ xを増やす
```

です。

---

## Pg3-6. 上下はyを変える

上へ動くときは、

```python
player_y = player_y - player_speed
```

下へ動くときは、

```python
player_y = player_y + player_speed
```

です。

pygameの座標は、下へ行くほどyが大きくなります。

```text
上へ
→ yを減らす

下へ
→ yを増やす
```

です。

---

## Pg3-7. なんで毎回ちょっとずつ？

```python
player_speed = 5
```

として、1回のゲームループごとに5だけ座標を変えています。

60FPSなら、だいたい1秒間に何十回も位置が変わります。

だから、

```text
320
↓
325
↓
330
↓
335
↓
...
```

と少しずつ動いているのに、画面では滑らかに移動して見えます。

> **「ワープじゃなくて、細かく何回も動かしてるだけか！」**

そういうことです。

---

## Pg3-8. 速度を変えてみる

```python
player_speed = 5
```

を、

```python
player_speed = 2
```

にすると遅くなります。

```python
player_speed = 10
```

にすると速くなります。

移動速度を1か所の変数にしておくと、あとから調整しやすくなります。

---

## Pg3-9. そのままだと画面外へ消える

座標をずっと変え続けると、プレイヤーは画面の外まで行けてしまいます。

> **「主人公どこまで行くねん！画面から逃げるな！」**

そこで、移動できる範囲を制限します。

---

## Pg3-10. xを画面内に収める

```python
player_x = max(20, min(620, player_x))
```

少し見慣れないですが、本質は、

> **player_xを20〜620の範囲に収める**

です。

プレイヤーの三角形は左右へ20広がるので、

```text
左端
→ 20

右端
→ 640 - 20 = 620
```

にしています。

---

## Pg3-11. yも画面内に収める

```python
player_y = max(20, min(460, player_y))
```

も同じです。

画面の高さは480で、自機は上下へ20広がるので、

```text
上端
→ 20

下端
→ 480 - 20 = 460
```

にしています。

---

## Pg3-12. `min()` と `max()` を日本語で読む

たとえば、

```python
min(620, player_x)
```

は、

> 620とplayer_xの小さい方

です。

だからplayer_xが700になっても620になります。

次に、

```python
max(20, ...)
```

で、

> 20より小さくならない

ようにしています。

つまり、

> **20より小さくせず、620より大きくしない**

という意味です。

---

## Pg3-13. WASDにしたい場合

矢印キーの代わりにWASDでも動かせます。

```python
if keys[pygame.K_a]:
    player_x = player_x - player_speed

if keys[pygame.K_d]:
    player_x = player_x + player_speed

if keys[pygame.K_w]:
    player_y = player_y - player_speed

if keys[pygame.K_s]:
    player_y = player_y + player_speed
```

今回は分かりやすさ優先で、教材本体は矢印キーにします。

---

## Pg3-14. ここまでで何が起きている？

ゲームループの中で毎回、

```text
イベントを見る
↓
押されているキーを見る
↓
座標を変える
↓
画面外へ出ないよう制限する
↓
背景を描く
↓
今の座標にプレイヤーを描く
↓
画面へ反映
```

を繰り返しています。

これで、

> **キーを押すとキャラクターが動く**

ようになります。

---

## Pg3-15. ここまでで覚えること

1. `pygame.key.get_pressed()` で今押されているキーを調べられる
2. 左右移動はxを変える
3. 上下移動はyを変える
4. 1フレームごとに少しずつ座標を変えると滑らかに動く
5. 移動量は `player_speed` のような変数にまとめると調整しやすい
6. 座標を制限しないと画面外へ出られる
7. `min()` と `max()` を使って範囲内へ収められる
