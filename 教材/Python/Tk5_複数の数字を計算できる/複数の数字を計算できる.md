# Tk5. 複数の数字を計算できる

Tk4では、

```text
12 + 8
```

や、

```text
12 - 8
```

のように、数字2個まで計算できました。

でも普通の電卓なら、

```text
1 + 2 - 3 + 4
```

くらい続けて入力したいです。

> **「毎回2個で終わるんかい！！！」**

ということで、今回は**計算式そのものを覚える**ようにします。

---

## Tk5-1. 今回作るもの

[multi_number_calculator.py](./multi_number_calculator.py) を開いてください。

今回は入力欄を1つにします。

使い方は、

```text
1 を入力
↓
+ を押す
↓
2 を入力
↓
- を押す
↓
3 を入力
↓
+ を押す
↓
4 を入力
↓
= を押す
```

です。

結果は、

```text
1 + 2 - 3 + 4 = 4
```

となります。

---

## Tk5-2. 2つの入力欄を卒業する

Tk4までは、

```text
1つ目の数字
2つ目の数字
```

と、入力欄が2つありました。

でもこのままだと、

```text
3つ目は？
4つ目は？
5つ目は？
```

となります。

> **「何個Entry置く気やねん！！！」**

そこでTk5からは、

> **1つの入力欄へ順番に数字を入れる**

形にします。

---

## Tk5-3. 計算式を覚える

最初に、

```python
calculation_parts = []
```

を用意します。

ここへ、

```text
数字
演算子
数字
演算子
数字
...
```

の順番で追加していきます。

たとえば、

```text
1 + 2 - 3 + 4
```

なら、内部では、

```python
[
    1.0,
    "+",
    2.0,
    "-",
    3.0,
    "+",
    4.0
]
```

のようになります。

今は、

> **計算に必要なものを順番に並べて覚えている**

くらいで十分です。

---

## Tk5-4. + や - を押したときに数字を追加する

```python
def add_operator(operator):
    number_text = number_entry.get()
```

まず今入力されている数字を取ります。

数字が入っていたら、

```python
calculation_parts.append(float(number_text))
calculation_parts.append(operator)
```

とします。

たとえば `+` を押したなら、

```text
1.0
+
```

が追加されます。

---

## Tk5-5. append() は何？

```python
calculation_parts.append(...)
```

は、

> **後ろへ1個追加する**

という意味です。

たとえば、

```python
calculation_parts = [1.0, "+"]
```

のあとに、

```python
calculation_parts.append(2.0)
```

とすると、

```python
[1.0, "+", 2.0]
```

になります。

詳しいリストの説明は正番号の10章で扱います。

このTkルートでは、

> **順番に覚えておきたいから使っている**

と分かれば十分です。

---

## Tk5-6. 同じ処理を + と - で使う

今回は、

```python
def add_operator(operator):
```

という共通の関数を作っています。

`+` ボタンなら、

```python
def select_addition():
    add_operator("+")
```

`-` ボタンなら、

```python
def select_subtraction():
    add_operator("-")
```

です。

つまり、

> **何の演算子を追加するかだけ変えて、同じ処理を使う**

ようにしています。

次に掛け算を増やすときも、この形なら増やしやすいです。

---

## Tk5-7. 演算子を押したら入力欄を空にする

```python
number_entry.delete(0, tkinter.END)
```

で、入力欄を空にします。

そうしないと、

```text
1
↓
+を押す
↓
まだ1が残っている
↓
次の2を入れにくい
```

となります。

> **「次の数字入れたいんだから空けてくれ！！！」**

ということです。

---

## Tk5-8. 今の計算式を画面にも出す

```python
expression_label.config(
    text="計算式: " + " ".join(
        str(part)
        for part in calculation_parts
    )
)
```

で、

```text
計算式: 1.0 + 2.0 -
```

のように表示します。

内部で何を覚えているかが画面にも見えるので、

> **今どこまで入力したか**

が分かります。

---

## Tk5-9. = を押したら最後の数字を追加する

`=` を押したときは、

```python
calculation_parts.append(
    float(number_text)
)
```

で最後の数字を追加します。

たとえば、

```text
1 + 2 - 3 + 4
```

なら、ここで最後の `4` が入ります。

---

## Tk5-10. 最初の数字から始める

計算するときは、

```python
answer = calculation_parts[0]
```

とします。

今回なら最初の数字です。

たとえば、

```python
[1.0, "+", 2.0, "-", 3.0]
```

なら、

```python
answer = 1.0
```

から始めます。

---

## Tk5-11. 演算子と次の数字を順番に見る

```python
for index in range(
    1,
    len(calculation_parts),
    2
):
```

で、

```text
1番目
3番目
5番目
...
```

を見ます。

ここには、

```text
+
-
+
...
```

という演算子が入っています。

次の、

```python
number = calculation_parts[index + 1]
```

で、その演算子の次にある数字を取ります。

---

## Tk5-12. + なら足す、- なら引く

```python
if operator == "+":
    answer = answer + number
else:
    answer = answer - number
```

とします。

今は `+` と `-` しかありません。

なので、

```text
+なら足す
それ以外なら引く
```

で動きます。

---

## Tk5-13. eval() は使わない

Pythonには文字列をそのまま式として実行できる方法もあります。

でも今回は使いません。

なぜなら、

> **今は「計算式をどう覚えて、どう順番に処理するか」を学びたい**

からです。

```text
文字列を渡したら勝手に計算してくれた
```

では、中で何をしているか分かりません。

この章では、自分で順番に計算します。

---

## Tk5-14. 計算が終わったら次へ備える

計算後は、

```python
calculation_parts.clear()
```

で、覚えていた計算式を空にします。

さらに、

```python
number_entry.delete(0, tkinter.END)
number_entry.insert(0, str(answer))
```

として、答えを入力欄へ入れます。

これで、

```text
1 + 2 = 3
↓
その3から続けて計算
```

もしやりたければ、そのまま次の演算子を押せます。

---

## Tk5-15. Tk4から何が変わった？

Tk4は、

```text
数字1
数字2
演算子1個
```

でした。

Tk5では、

```text
数字
演算子
数字
演算子
数字
...
```

を順番に覚えます。

つまり、

> **「2つの数字を計算する」から「計算式を作る」へ変わりました。**

ここからかなり電卓らしくなってきます。

---

## Tk5-16. ここまでで覚えること

1. 入力欄を1つにして順番に数字を入れられる
2. `calculation_parts` に数字と演算子を順番に覚えられる
3. `append()` で後ろへ追加できる
4. 演算子を押したら入力欄を空にできる
5. `=` で最後の数字を追加して計算できる
6. 繰り返しで演算子と数字を順番に処理できる
7. 共通処理を `add_operator()` にまとめると演算子を増やしやすい

---

## Tk5-17. 次は掛け算

今は、

```text
+
-
```

だけです。

次は、

> **「掛け算ないん？？？」**

となります。

Tk6では `*` を追加します。

このとき、今回作った `add_operator()` がそのまま役に立ちます。
