# 4. 数値と計算

この章では、利用者が入力した数字を使って計算します。

今回作るのは、**2つの数字を入力すると足し算してくれる小さな電卓**です。

---

## 4-1. 今回作るもの

実行例:

```text
1つ目の数字を入力してください: 12
2つ目の数字を入力してください: 8
答えは 20 です
```

前の章では入力した文字をそのまま使いました。

今回は、

> 入力する  
> ↓  
> 数字として扱える形にする  
> ↓  
> 計算する  
> ↓  
> 結果を表示する

という流れを作ります。

### なぜ数値として扱う必要があるの？

人間から見ると `10` も `20` も数字です。

しかし、プログラムでは「数字のように見える文字」と「計算できる数値」は別物です。

もし文字のまま足してしまうと、

```text
10 + 20
```

を計算したつもりなのに、

```text
1020
```

となることがあります。

120円のお会計を計算したかったのに、突然1020円になったら困ります。

> **「そんくらい小学生でもできるぞ！！！」**

となるので、「見た目が数字」ではなく「本当に数値として扱われているか」が重要です。

そこで、入力された文字を `int()` や `float()` で数値へ変換し、**計算できる形にしてから使う**必要があります。

---

## 4-2. 2つの数字を受け取って計算する

[simple_addition.py](./simple_addition.py) を開いてください。

`simple` は「簡単な」、`addition` は「足し算」という意味です。

まず、1つ目と2つ目の数字をそれぞれ保存する場所を用意します。

名前は `number1` と `number2` にしましょう。

入力は最初は文字列なので、`int()` で整数へ変換してから保存します。

足した結果もあとで表示したいので、`answer` に保存します。

```python
# 1つ目の入力を受け取り、int() で整数に変換して number1 に保存します。
number1 = int(input("1つ目の数字を入力してください: "))

# 2つ目の入力も整数に変換して number2 に保存します。
number2 = int(input("2つ目の数字を入力してください: "))

# number1 と number2 を足し、その結果を answer に保存します。
answer = number1 + number2

# answer に保存した計算結果を表示します。
print("答えは", answer, "です")
```

---

## 4-3. まず、文字列同士で足してみる

`input()` の結果は文字列です。

なので、変換せずにそのまま `+` するとどうなるか試してみます。

```python
number1 = input("1つ目の数字を入力してください: ")
number2 = input("2つ目の数字を入力してください: ")

answer = number1 + number2

print("答えは", answer, "です")
```

入力:

```text
1つ目の数字を入力してください: 10
2つ目の数字を入力してください: 20
```

結果:

```text
答えは 1020 です
```

> **「そんくらい小学生でもできるぞ！！！」**

10と20を足して30にしたかったのに、文字列なので `"10"` と `"20"` がそのままつながっています。

つまり、

```text
"10" + "20"
→ "1020"
```

です。

だから、計算したいなら先に数値へ変換します。

---

## 4-4. なぜ `int()` が必要なの？

`input()` で受け取った値は、入力した内容が数字に見えても **文字列** です。

たとえば、

```python
number = input("数字を入力してください: ")
```

で `10` と入力しても、Pythonでは最初、

```text
"10"
```

という文字として扱われます。

そのままでは、数として計算したいときに困ります。

そこで、

```python
int("10")
```

のように `int()` を使って、整数へ変換します。

---

## 4-5. 文字の足し算と数字の足し算は違う

次の2つは結果が違います。

文字列:

```python
print("10" + "20")
```

結果:

```text
1020
```

整数:

```python
print(10 + 20)
```

結果:

```text
30
```

文字列では、`+` は文字をつなげます。

数字では、`+` は足し算になります。

見た目が同じ `10` でも、

- `"10"` は文字列
- `10` は整数

です。

---

## 4-6. 計算結果も変数に入れられる

足した結果は、このあと表示するために残しておきたいので、`answer` に保存しましょう。

```python
answer = number1 + number2
```

これで、`number1 + number2` の計算結果が `answer` に入ります。

たとえば、

```text
number1 → 12
number2 → 8
```

なら、

```text
answer → 20
```

となります。

変数には、利用者が入力した値だけでなく、
**計算した結果も保存できます。**

---

## 4-7. よく使う計算記号

Pythonでは、次のような記号で計算できます。

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `+` | 足し算 | `10 + 3` |
| `-` | 引き算 | `10 - 3` |
| `*` | 掛け算 | `10 * 3` |
| `/` | 割り算 | `10 / 3` |
| `//` | 小数部分を切り下げる割り算 | `10 // 3` |
| `%` | 余り | `10 % 3` |
| `**` | 累乗 | `2 ** 3` |

すべてを今すぐ暗記する必要はありません。

まずは `+`、`-`、`*`、`/` が使えれば十分です。

---

## 4-8. 小数を扱いたいとき

`int()` は整数へ変換します。

小数を扱いたい場合は `float()` を使います。

```python
price = float(input("値段を入力してください: "))
```

たとえば、

```text
12.5
```

のような値を入力できます。

---

## 4-9. 数字以外を入力するとどうなる？

次のプログラムで、

```python
number = int(input("数字を入力してください: "))
```

としたときに、

```text
abc
```

のような数字ではない文字を入力すると、エラーになります。

今は、

> `int()` は、整数に変換できる文字を受け取る必要がある

と覚えておけば十分です。

入力ミスを安全に処理する方法は、後の章で扱います。

---

## 4-10. 自分で変えてみる

足し算を掛け算に変えてみましょう。

```python
number1 = int(input("1つ目の数字を入力してください: "))
number2 = int(input("2つ目の数字を入力してください: "))

answer = number1 * number2

print("答えは", answer, "です")
```

さらに `-` や `/` に変えて、結果がどうなるか試してみてください。

---

## 4-11. ここまでで覚えること

この章では、次のことが分かれば十分です。

1. `input()` の結果は最初は文字列
2. `int()` で整数へ変換できる
3. `float()` で小数を扱える
4. `+`、`-`、`*`、`/` などで計算できる
5. 計算結果も変数に保存できる
