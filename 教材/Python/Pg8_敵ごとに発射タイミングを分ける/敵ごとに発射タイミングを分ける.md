# Pg8. pygame「敵ごとに発射タイミングを分ける」

Pg7で、敵が順番に増えるようになりました。

実際に遊んでみると、

> **「全員同時に撃ってくる。つまんない！！！」**

敵が何体いても、全員が同じタイマーを見ているので一斉に撃ちます。

今回は、

> **敵1体ごとに、自分専用の発射タイマーを持たせる**

ようにします。

そのために、ここでクラスを軽く使います。

クラスの文法講座はしません。

> **「こういう時に使えるんだ」**

が分かれば十分です。

---

## Pg8-1. 今回作るもの

[enemy_fire_timing.py](./enemy_fire_timing.py) を開いてください。

今回は敵1体ごとに、

- x座標
- y座標
- 発射間隔
- 発射タイマー

を持たせます。

---

## Pg8-2. なんでクラスを使うの？

今までは敵の座標だけを、

```python
[x座標, y座標]
```

のように持っていました。

でも今度は敵ごとに、

```text
座標
発射間隔
発射タイマー
```

まで必要です。

全部バラバラに管理すると、

> **「このタイマーどの敵のやつやねん！！！」**

となります。

そこで、

> **関係する変数と関数をまとめる**

ためにクラスを使います。

---

## Pg8-3. Enemyクラス

```python
class Enemy:
    def __init__(self, x, fire_interval):
        self.x = x
        self.y = -20
        self.fire_interval = fire_interval
        self.fire_timer = 0
```

これでEnemy1体ごとに、

- `x`
- `y`
- `fire_interval`
- `fire_timer`

を持てます。

難しい言葉は今は要りません。

> **敵1体ぶんの情報をまとめて持てる**

くらいでOKです。

---

## Pg8-4. 敵ごとに発射間隔を変える

```python
enemy_fire_intervals = [
    60,
    90,
    120,
    75,
    105,
    80,
    110
]
```

とします。

敵を作るときに、

```python
Enemy(
    spawn_positions_x[spawn_index],
    enemy_fire_intervals[spawn_index]
)
```

として、それぞれ別の発射間隔を渡します。

---

## Pg8-5. 敵自身のタイマーを進める

```python
def ready_to_fire(self):
    self.fire_timer = self.fire_timer + 1

    if self.fire_timer >= self.fire_interval:
        self.fire_timer = 0
        return True

    return False
```

敵ごとに `fire_timer` が別なので、

> **敵Aが60まで数えていても、敵Bのタイマーは別**

です。

---

## Pg8-6. 撃つタイミングが来た敵だけ撃つ

```python
for enemy in enemies:
    if enemy.ready_to_fire():
        enemy_bullets.append([
            enemy.x,
            enemy.y + 20
        ])
```

これで全員が同じ瞬間に撃つのではなく、

> **それぞれ自分のタイミングで撃つ**

ようになります。

---

## Pg8-7. 座標も enemy.x / enemy.y になる

クラスを使ったので、

```python
enemy[0]
enemy[1]
```

ではなく、

```python
enemy.x
enemy.y
```

と書けます。

どっちが何の座標かも分かりやすくなります。

---

## Pg8-8. クラスは深追いしない

ここでは、

- 継承
- カプセル化
- 設計論

などには進みません。

この章で覚えるのは、

> **敵1体ごとに別の状態を持たせたい時、クラスでまとめられる**

これだけです。

詳しいクラスは正番号の「8. クラス」で扱います。

---

## Pg8-9. ここまでで覚えること

1. 全員で1個のタイマーを使うと同時発射になる
2. 敵ごとに別の発射タイマーを持たせられる
3. クラスで敵1体ぶんの変数と処理をまとめられる
4. `enemy.fire_timer` はその敵専用のタイマー
5. `Enemy` から作った敵はそれぞれ別の状態を持てる
