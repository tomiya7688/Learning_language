# 5. 条件分岐

この章では、入力された値によって処理を変える方法を学びます。

今回作るのは、**入力した点数によって結果を変える判定プログラム**です。

---

## 5-1. 今回作るもの

実行すると点数を入力します。

```text
点数を入力してください: 82
```

入力した点数によって、表示される結果が変わります。

例:

```text
とても良い結果です
```

別の点数なら、

```text
合格です
```

または、

```text
もう一度挑戦しましょう
```

のように結果を変えます。

これまでのプログラムは、基本的に上から順番に同じ処理を実行していました。

今回は、

> 条件を確認する  
> ↓  
> 条件に合う処理だけ実行する

という動きを作ります。

### なぜ条件分岐が必要なの？

プログラムは、何も条件を付けなければ上から順番に処理します。

たとえばアンケートで、

```text
性別を選んでください: 男性
```

と答えたとします。

ところが、条件分岐を使わずに、

```python
print("あなたは男性です")
print("あなたは女性です")
```

と書いてあれば、

```text
あなたは男性です
あなたは女性です
```

と両方表示されてしまいます。

プログラムは「これは今は表示しないほうがいいかな」と自分で判断してはくれません。

そこで、

> この条件ならこの処理  
> 別の条件なら別の処理

と決めるために **条件分岐** を使います。

---

## 5-2. サンプルコード

[score_check.py](./score_check.py) を開いてください。

`score` は「点数」、`check` は「確認する・判定する」という意味です。

```python
# input() で受け取った文字を int() で整数に変換します。
score = int(input("点数を入力してください: "))

# 80点以上なら、この処理を実行します。
if score >= 80:
    print("とても良い結果です")

# 60点以上80点未満なら、この処理を実行します。
elif score >= 60:
    print("合格です")

# それ以外の場合は、この処理を実行します。
else:
    print("もう一度挑戦しましょう")
```

---

## 5-3. `if` とは

`if` は、

> **もし条件が成り立つなら、この処理をする**

という意味で使います。

たとえば、

```python
if score >= 80:
    print("とても良い結果です")
```

は、

> もし `score` が80以上なら、  
> 「とても良い結果です」と表示する

という意味です。

---

## 5-4. `>=` は何を表している？

```python
score >= 80
```

の `>=` は、

> 左の値が右の値以上

という意味です。

よく使う比較記号は次のとおりです。

| 記号 | 意味 |
| --- | --- |
| `==` | 等しい |
| `!=` | 等しくない |
| `>` | より大きい |
| `<` | より小さい |
| `>=` | 以上 |
| `<=` | 以下 |

---

## 5-5. `=` と `==` は違う

ここは特に間違えやすいところです。

```python
score = 80
```

の `=` は、

> 右側の値を左側の変数へ入れる

ために使います。

一方、

```python
score == 80
```

の `==` は、

> `score` と `80` が同じか比較する

ために使います。

つまり、

```text
=   → 値を入れる
==  → 同じか調べる
```

です。

---

## 5-6. `elif` とは

`elif` は、

> それまでの条件には当てはまらなかったが、次の条件ならどうか

を確認するために使います。

```python
elif score >= 60:
    print("合格です")
```

この行が確認されるのは、最初の

```python
if score >= 80:
```

に当てはまらなかった場合です。

そのため、ここまで来た時点で `score` は80未満です。

そこで、

```python
score >= 60
```

を確認することで、

> 60点以上80点未満

の値を扱えます。

---

## 5-7. `else` とは

`else` は、

> それまでのどの条件にも当てはまらなかった場合

に実行されます。

```python
else:
    print("もう一度挑戦しましょう")
```

今回の場合、

- 80点以上ではない
- 60点以上でもない

ということなので、60点未満のときに実行されます。

---

## 5-8. 条件は上から順番に確認される

次のコードでは、

```python
if score >= 80:
    print("とても良い結果です")
elif score >= 60:
    print("合格です")
else:
    print("もう一度挑戦しましょう")
```

条件は上から順番に確認されます。

たとえば `90` を入力すると、

```python
score >= 80
```

が成立します。

その時点でこの一連の条件分岐では、
後ろの `elif` や `else` は実行されません。

---

## 5-9. インデントとは

Python では、条件に当てはまったときに実行する処理を、
少し右へずらして書きます。

```python
if score >= 80:
    print("とても良い結果です")
```

この右側へのずれを **インデント** と呼びます。

Pythonではインデントが文法の一部です。

次のように書くと正しくありません。

```python
if score >= 80:
print("とても良い結果です")
```

この教材では、インデントには **半角スペース4個** を基本として使います。

VS Codeでは Enter キーを押したときに、
必要なインデントを自動で入れてくれることがあります。

---

## 5-10. `:` を忘れない

`if`、`elif`、`else` の行の最後には `:` を書きます。

```python
if score >= 80:
```

```python
elif score >= 60:
```

```python
else:
```

この `:` を忘れるとエラーになります。

---

## 5-11. 自分で変えてみる

判定する点数を変えてみましょう。

たとえば、

```python
if score >= 90:
    print("最高評価です")
elif score >= 70:
    print("合格です")
else:
    print("再挑戦です")
```

のようにできます。

また、点数以外にも、

- 年齢
- 金額
- 気温
- ゲームの得点
- 在庫数

など、数値によって処理を変えたい場面で同じ考え方を使えます。

---

## 5-12. GUIでも条件分岐を使う

GUIアプリでも条件分岐はよく使います。

たとえば、

- 入力欄が空なら警告を出す
- 正しい値なら次の画面へ進む
- チェックボックスがONなら処理する
- 点数によって表示するメッセージを変える

といった処理です。

この章で学ぶ `if` は、
GUIへ進んでもそのまま使います。

---

## 5-13. ここまでで覚えること

この章では、次のことが分かれば十分です。

1. `if` で条件に合うときだけ処理できる
2. `elif` で別の条件を追加できる
3. `else` でそれ以外を扱える
4. `==`、`>=`、`<=` などで値を比較できる
5. `=` と `==` は意味が違う
6. Pythonではインデントが重要
7. `if`、`elif`、`else` の行末には `:` が必要

次は、同じ処理を何度も行う **繰り返し** に進みます。
