# Pg4. pygame「弾を発射する」

Pg3では、プレイヤーを矢印キーで動かせるようになりました。

でも、まだ敵を攻撃できません。

> **「弾1発しか撃てんの？？？シューティングやぞ！」**

今回は、スペースキーを押すとプレイヤーから弾が飛ぶようにします。

そしてここで、リストが必要になります。

---

## Pg4-1. 今回作るもの

[player_shooting.py](./player_shooting.py) を開いてください。

`player` は「プレイヤー」、`shooting` は「射撃」という意味です。

スペースキーを押すたびに弾が増え、上へ飛んでいきます。

---

## Pg4-2. サンプルコード

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("弾を発射する")

clock = pygame.time.Clock()

player_x = 320
player_y = 400
player_speed = 5

bullets = []
bullet_speed = 8

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                bullets.append([player_x, player_y - 20])

    keys = pygame.key.get_pressed()

    if keys[pygame.K_LEFT]:
        player_x = player_x - player_speed

    if keys[pygame.K_RIGHT]:
        player_x = player_x + player_speed

    if keys[pygame.K_UP]:
        player_y = player_y - player_speed

    if keys[pygame.K_DOWN]:
        player_y = player_y + player_speed

    player_x = max(20, min(620, player_x))
    player_y = max(20, min(460, player_y))

    for bullet in bullets:
        bullet[1] = bullet[1] - bullet_speed

    bullets = [bullet for bullet in bullets if bullet[1] > -20]

    screen.fill((10, 10, 30))

    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    for bullet in bullets:
        pygame.draw.rect(
            screen,
            (255, 240, 100),
            (bullet[0] - 3, bullet[1] - 10, 6, 20)
        )

    pygame.display.flip()

    clock.tick(60)

pygame.quit()
```

---

## Pg4-3. 弾は1個とは限らない

最初の1発だけなら、

```python
bullet_x = player_x
bullet_y = player_y
```

でも作れます。

でも2発目は？

```python
bullet2_x = ...
bullet2_y = ...
```

3発目は？

```python
bullet3_x = ...
bullet3_y = ...
```

> **「何発撃つか分からんのに、全部変数作るん？？？」**

それでは日が暮れます。

だから、

```python
bullets = []
```

というリストに弾をまとめます。

---

## Pg4-4. 弾を追加する

スペースキーを押したとき、

```python
bullets.append([player_x, player_y - 20])
```

としています。

これは、

> 今のプレイヤー位置から新しい弾を1個追加する

という意味です。

1発の弾は、

```python
[x, y]
```

の2つの数字で持っています。

---

## Pg4-5. なぜKEYDOWNを使うの？

プレイヤー移動では、

```python
pygame.key.get_pressed()
```

を使いました。

これは、キーを押している間ずっと動かしたいからです。

でも弾まで同じやり方にすると、スペースキーを押している間、毎フレーム弾が増えます。

60FPSなら1秒で何十発も出てしまいます。

なので今回は、

```python
if event.type == pygame.KEYDOWN:
```

で、

> **キーを押した瞬間**

だけを見るようにしています。

---

## Pg4-6. スペースキーだけを見る

```python
if event.key == pygame.K_SPACE:
```

で、

> 押されたキーがスペースキーだったら

という判定をします。

これで、スペースキー1回につき弾1発になります。

---

## Pg4-7. 弾を動かす

```python
for bullet in bullets:
    bullet[1] = bullet[1] - bullet_speed
```

で、すべての弾を上へ動かします。

1発の弾は、

```python
[x, y]
```

なので、

```python
bullet[0]
```

がx、

```python
bullet[1]
```

がyです。

上へ動かしたいので、yを減らします。

---

## Pg4-8. ここでも「まとめる」が効く

弾が10発あっても、

```python
for bullet in bullets:
```

と書けば、全部に同じ処理をできます。

> **同じ種類のものが何個あるか分からないから、リストにまとめて繰り返す**

という形です。

10章のリストをまだ読んでいなくても、

> **「弾がいっぱいあるから1個にまとめてるんだな」**

くらいで十分です。

---

## Pg4-9. 画面外の弾を消す

そのままだと、画面の外へ飛んでいった弾もずっとリストに残ります。

見えないのにデータだけ増え続けます。

> **「もう画面におらん弾までいつまで覚えとんねん！」**

なので、

```python
bullets = [bullet for bullet in bullets if bullet[1] > -20]
```

で、まだ画面の近くにいる弾だけ残します。

---

## Pg4-10. この1行、いきなり難しく見える

```python
bullets = [bullet for bullet in bullets if bullet[1] > -20]
```

は、今は全部覚えなくて構いません。

日本語にすると、

> bulletsの中から、yが-20より大きい弾だけ残す

です。

あとでリスト内包表記を詳しく学んでも構いません。

今は、

> **画面外へ行った弾を捨てている**

と読めれば十分です。

---

## Pg4-11. 弾を描く

```python
for bullet in bullets:
    pygame.draw.rect(
        screen,
        (255, 240, 100),
        (bullet[0] - 3, bullet[1] - 10, 6, 20)
    )
```

で、全部の弾を細長い四角形として描いています。

`pygame.draw.rect()` は四角形を描く機能です。

今回は、

```text
横 6
縦 20
```

の細い弾にしています。

---

## Pg4-12. 弾の速度

```python
bullet_speed = 8
```

で、1フレームにどれだけ上へ進むかを決めています。

数字を変えると、

```python
bullet_speed = 4
```

なら遅く、

```python
bullet_speed = 15
```

なら速くなります。

あとでゲームバランスを調整するときにも、こういう数字を変えます。

---

## Pg4-13. 今回の流れ

ゲームループの中で、

```text
イベントを見る
↓
スペースキーを押したら弾を追加
↓
プレイヤーを動かす
↓
全部の弾を動かす
↓
画面外の弾を消す
↓
背景を描く
↓
プレイヤーを描く
↓
全部の弾を描く
↓
画面へ反映
```

を繰り返しています。

これで、ようやく

> **動いて撃てる**

ところまで来ました。

## Pg4-15. まだ敵はいない

今は撃てますが、何も倒せません。

> **「で、何撃つん？？？」**

次のPg5で敵を追加します。

そして、弾と敵が当たったら敵が消えるようにします。

ここから一気にシューティングゲームらしくなります。

---

## Pg4-16. ここまでで覚えること

1. 弾が複数あるのでリストにまとめる
2. `append()` で新しい弾を追加できる
3. `KEYDOWN` でキーを押した瞬間を扱える
4. `pygame.K_SPACE` でスペースキーを判定できる
5. `for` で全部の弾を動かせる
6. 上へ動かすにはyを減らす
7. 画面外の弾はリストから消す
8. `pygame.draw.rect()` で弾を描ける
9. 同じ種類のものが増えるとき、リストへまとめると扱いやすい
