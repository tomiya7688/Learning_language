# Pg2. pygame「プレイヤーを表示する」

Pg1では、ゲームのウィンドウを表示して、閉じる操作を受け取れるようになりました。

でも、まだ画面には何もいません。

> **「誰もおらんやん！主人公どこ行った！！！」**

今回は、シューティングゲームの自機を画面へ表示します。

まだ動きません。

まずは、

> **画面のどこに、何を描くか**

を覚えます。

---

## Pg2-1. 今回作るもの

[player_ship.py](./player_ship.py) を開いてください。

`player` は「プレイヤー」、`ship` は「機体・船」という意味です。

今回は外部画像を使わず、pygameの図形だけで簡単な自機を描きます。

```text
      ▲
     / \
    /   \
   /_____\
```

のような三角形のイメージです。

この段階では見た目の豪華さより、

> **画面へ自分で何かを描けた**

ことを優先します。

---

## Pg2-2. サンプルコード

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("プレイヤーを表示する")

clock = pygame.time.Clock()

player_x = 320
player_y = 400

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((10, 10, 30))

    player_points = [
        (player_x, player_y - 20),
        (player_x - 20, player_y + 20),
        (player_x + 20, player_y + 20)
    ]

    pygame.draw.polygon(screen, (100, 200, 255), player_points)

    pygame.display.flip()

    clock.tick(60)

pygame.quit()
```

実行すると、暗い背景の下側に三角形のプレイヤーが表示されます。

---

## Pg2-3. 座標って何？

画面の場所は、数字で指定します。

pygameでは基本的に、

```text
左上
(0, 0)
  ┌────────→ x
  │
  │
  │
  ↓
  y
```

という向きです。

横方向が `x`、縦方向が `y` です。

---

## Pg2-4. xは横、yは縦

今回は、

```python
player_x = 320
player_y = 400
```

としています。

640×480の画面なので、

```text
x = 320
→ だいたい横の中央

y = 400
→ 画面のかなり下
```

です。

シューティングゲームの自機らしく、下の方へ置いています。

---

## Pg2-5. 座標は難しいものではない

座標と聞くと難しそうですが、今は、

> **「画面のどこ？」を数字で言っているだけ**

です。

たとえば、

```python
player_x = 100
player_y = 100
```

へ変えると、プレイヤーは左上寄りへ移動します。

まだキー操作はありません。

数字を変えたら場所が変わる、だけ確認してください。

---

## Pg2-6. 背景を塗る

ゲームループの中に、

```python
screen.fill((10, 10, 30))
```

があります。

これは画面全体を塗る処理です。

```text
(10, 10, 30)
```

は色を表しています。

順番は、

```text
赤
緑
青
```

です。

それぞれ0〜255くらいの数字で指定します。

今回は暗い青っぽい背景にしています。

---

## Pg2-7. なんで毎回背景を塗るの？

pygameでは、ゲームループのたびに画面を作り直すのが基本です。

今回なら、

```text
背景を塗る
↓
プレイヤーを描く
↓
画面へ反映する
↓
また最初から
```

を繰り返します。

> **「一回描いたらずっと置いといてくれんの？」**

と思うかもしれませんが、ゲームでは次の章からプレイヤーが動きます。

そのため、毎回その瞬間の状態を描き直します。

---

## Pg2-8. プレイヤーの形を決める

今回は三角形を使います。

```python
player_points = [
    (player_x, player_y - 20),
    (player_x - 20, player_y + 20),
    (player_x + 20, player_y + 20)
]
```

三角形には3つの角があります。

その3か所を座標で指定しています。

---

## Pg2-9. 3つの点を日本語で読む

この部分も、記号だけで見る必要はありません。

```python
(player_x, player_y - 20)
```

は、

> プレイヤーの中心より20上

```python
(player_x - 20, player_y + 20)
```

は、

> 左へ20、下へ20

```python
(player_x + 20, player_y + 20)
```

は、

> 右へ20、下へ20

です。

つまり、

> **上に1点、下に2点を置いて三角形を作っている**

だけです。

---

## Pg2-10. `pygame.draw.polygon()`

```python
pygame.draw.polygon(screen, (100, 200, 255), player_points)
```

で、三角形を描いています。

大まかには、

```text
screen
→ どこへ描く？

(100, 200, 255)
→ 何色？

player_points
→ どんな形？
```

です。

`polygon` は「多角形」という意味です。

今回は3点なので三角形になります。

---

## Pg2-11. なんで画像を使わないの？

最終的には、自機・敵・ボスを教材に同梱した画像へ差し替える予定です。

でも、最初から画像を使うと、

- 画像ファイルの場所
- 読み込み
- 透明部分
- サイズ調整

など、今はまだ不要な話が増えます。

なので最初は、

> **図形だけでゲームを作る**

ことにします。

ゲームの仕組みが完成したあとで、見た目だけ画像へ差し替えます。

---

## Pg2-12. `pygame.display.flip()`

図形を描いただけでは、画面へ反映されません。

```python
pygame.display.flip()
```

で、

> **今回描いた画面を表示する**

と考えてください。

ゲームループでは、

```text
描く
↓
flip()
↓
描く
↓
flip()
↓
...
```

を繰り返します。

---

## Pg2-13. 60FPSにする

今回は、

```python
clock = pygame.time.Clock()
```

を最初に作り、

```python
clock.tick(60)
```

をゲームループの最後に入れています。

これは、

> 1秒間にだいたい60回まで

という目安でゲームループを回すために使います。

何も制限しないと、PCが出せるだけ全力でループし続けてしまいます。

> **「止まってる三角形1個にCPU全力出すな！」**

ということで、今のうちに上限を入れておきます。

---

## Pg2-14. 今は動かなくて正解

この章では、キーを押してもプレイヤーは動きません。

それで正解です。

今回は、

1. 座標を決める
2. 背景を描く
3. プレイヤーを描く
4. 画面へ反映する

だけに集中します。

次のPg3で、この `player_x` と `player_y` をキー入力によって変えます。

## Pg2-15. 自分で場所を変えてみる

たとえば、

```python
player_x = 100
player_y = 200
```

に変えてみてください。

次に、

```python
player_x = 500
player_y = 100
```

も試してみます。

数字を変えるだけで位置が変わることが分かれば十分です。

---

## Pg2-16. 色も変えてみる

プレイヤーの色、

```python
(100, 200, 255)
```

を、

```python
(255, 100, 100)
```

などへ変えてみてください。

今はRGBの細かい知識を覚える必要はありません。

数字を変えると色が変わる、くらいで構いません。

## Pg2-17. ここまでで覚えること

1. 画面上の場所はxとyの座標で表せる
2. xは横、yは縦
3. pygameでは左上がだいたい `(0, 0)`
4. `screen.fill()` で背景を塗れる
5. `pygame.draw.polygon()` で多角形を描ける
6. 三角形は3つの点を指定して作れる
7. ゲームでは毎フレーム背景とキャラクターを描き直す
8. `pygame.display.flip()` で描いた内容を画面へ反映する
9. `Clock.tick(60)` でループ速度を抑えられる
10. 今は図形で作り、最後に画像素材へ差し替える
