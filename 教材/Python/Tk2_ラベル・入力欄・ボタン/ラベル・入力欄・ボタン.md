# Tk2. ラベル・入力欄・ボタン

この章では、tkinterのウィンドウに部品を置いて、**実際に操作できるGUI**を作ります。

今回作るのは、

> 名前を入力する  
> ↓  
> ボタンを押す  
> ↓  
> 画面に挨拶を表示する

という小さなアプリです。

---

## Tk2-1. 今回作るもの

画面には、

- 名前を入力する欄
- 「挨拶する」ボタン
- 結果を表示する文字

を置きます。

たとえば、

```text
名前を入力: たろう
```

と入力してボタンを押すと、

```text
こんにちは たろう
```

と表示されます。

前のTk1では、空のウィンドウを表示するところまででした。

今回は、そのウィンドウに**部品を置いて、利用者の操作に反応させます。**

---

## Tk2-2. なぜ部品が必要なの？

空のウィンドウだけでもGUIではあります。

でも、ずっと空のままだと、

```text
[         空のウィンドウ         ]
```

利用者は、

> 「……で、私は何をすれば？」

となってしまいます。

そこでGUIでは、

- 説明を表示する
- 文字を入力してもらう
- ボタンを押してもらう
- 結果を表示する

といった役割ごとに部品を置きます。

tkinterでは、こうした部品を**ウィジェット（Widget）**と呼びます。

---

## Tk2-3. サンプルコード

[greeting_gui.py](./greeting_gui.py) を開いてください。

`greeting` は「挨拶」、`gui` は「画面を使って操作する仕組み」という意味で使われます。

```python
import tkinter


# ボタンが押されたときに実行する関数です。
def show_greeting():
    name = name_entry.get()
    result_label.config(text=f"こんにちは {name}")


# ウィンドウを作ります。
window = tkinter.Tk()
window.title("挨拶アプリ")
window.geometry("400x220")

# 説明を表示します。
name_label = tkinter.Label(window, text="名前を入力してください")
name_label.pack()

# 名前を入力する欄です。
name_entry = tkinter.Entry(window)
name_entry.pack()

# 押せるボタンです。
greet_button = tkinter.Button(window, text="挨拶する", command=show_greeting)
greet_button.pack()

# 結果を表示するラベルです。
result_label = tkinter.Label(window, text="")
result_label.pack()

# ウィンドウを表示し続けます。
window.mainloop()
```

---

## Tk2-4. Labelとは

`Label` は、画面に文字を表示するための部品です。

```python
name_label = tkinter.Label(window, text="名前を入力してください")
```

ここでは、

```text
名前を入力してください
```

という文字を表示するLabelを作っています。

`window` を最初に渡しているのは、

> このウィンドウの中に置く部品ですよ

という意味です。

---

## Tk2-5. Entryとは

`Entry` は、1行の文字入力欄です。

```python
name_entry = tkinter.Entry(window)
```

この部品へ、利用者が名前を入力できます。

たとえば、

```text
たろう
```

と入力した内容は、あとでプログラムから取り出せます。

---

## Tk2-6. Buttonとは

`Button` は、押せるボタンです。

```python
greet_button = tkinter.Button(
    window,
    text="挨拶する",
    command=show_greeting
)
```

`text` は、ボタンに表示する文字です。

```text
挨拶する
```

と表示されます。

そして、

```python
command=show_greeting
```

で、

> このボタンが押されたら `show_greeting` を実行する

と設定しています。

---

## Tk2-7. なぜ `show_greeting()` ではないの？

ここはとても大切です。

ボタンを作るときは、

```python
command=show_greeting
```

と書きます。

```python
command=show_greeting()
```

とは書きません。

`()` を付けると、その場ですぐ関数を実行してしまいます。

今回は、

> 今すぐ実行するのではなく、ボタンが押されたときに実行してほしい

ので、関数名だけを渡します。

```text
show_greeting()   → 今すぐ実行する
show_greeting     → あとで呼べるよう関数そのものを渡す
```

くらいに覚えておけば十分です。

---

## Tk2-8. `.get()` で入力内容を取り出す

ボタンが押されると、次の関数が実行されます。

```python
def show_greeting():
    name = name_entry.get()
    result_label.config(text=f"こんにちは {name}")
```

まず、

```python
name = name_entry.get()
```

で、Entryに入力された文字を取り出します。

`.get()` は、

> この入力欄に今入っている内容をください

というイメージです。

たとえばEntryに、

```text
たろう
```

と入っていれば、

```text
name → "たろう"
```

となります。

---

## Tk2-9. 表示内容を書き換える

次に、

```python
result_label.config(text=f"こんにちは {name}")
```

を実行します。

`config()` は、作った部品の設定をあとから変更するために使えます。

今回は、結果表示用Labelの `text` を変更しています。

最初は、

```python
result_label = tkinter.Label(window, text="")
```

なので何も表示していません。

ボタンが押されたあとに、

```text
こんにちは たろう
```

へ変更します。

---

## Tk2-10. `pack()` は何をしている？

部品を作っただけでは、画面上に配置されません。

そこで、

```python
name_label.pack()
name_entry.pack()
greet_button.pack()
result_label.pack()
```

のように `pack()` を使っています。

`pack()` は、

> この部品をウィンドウの中へ配置する

ための方法のひとつです。

今回はまず、上から順番に並べられれば十分です。

tkinterにはほかにも `grid()` や `place()` がありますが、最初から全部覚える必要はありません。

---

## Tk2-11. イベント駆動とは？

これまでのプログラムは、

```text
上から順番に実行
        ↓
終わる
```

という流れが中心でした。

GUIでは少し違います。

ウィンドウを表示したあと、

```text
利用者が入力する
        ↓
ボタンを押す
        ↓
そのとき関数を実行する
```

という形になります。

このように、

> 何かの出来事が起きたときに処理する

考え方を**イベント駆動**と呼びます。

ボタンを押すこともイベントのひとつです。

---

## Tk2-12. イベントがなかったらどうなる？

もしGUIが利用者の操作を待たず、最初から全部実行してしまったらどうなるでしょうか。

名前を入力する前に、

```text
こんにちは
```

と表示されてしまうかもしれません。

プログラム側が、

> 「たぶんこの人はそろそろボタンを押すだろう」

と勝手に予想して動くわけにはいきません。

そこでGUIでは、

> ボタンが押されたら、この処理をする

という形で処理を結び付けます。

これがイベント駆動の基本です。

---

## Tk2-13. 関数をここでも使っている

7章で学んだ関数が、GUIでもそのまま使われています。

```python
def show_greeting():
    name = name_entry.get()
    result_label.config(text=f"こんにちは {name}")
```

この関数を、

```python
command=show_greeting
```

でボタンへ登録しています。

つまり、

```text
ボタンを押す
    ↓
show_greeting を呼ぶ
    ↓
Entryから文字を取る
    ↓
Labelを書き換える
```

という流れです。

---

## Tk2-14. 変数も再利用している

3章で学んだ変数も使っています。

たとえば、

```python
name = name_entry.get()
```

では、入力された名前を `name` に保存しています。

また、

```python
name_entry
result_label
greet_button
```

も変数です。

GUIでは、作った部品をあとから使うために、部品そのものを変数へ保存することがよくあります。

## Tk2-16. 自分で変えてみる

表示する文章を変えてみましょう。

たとえば、

```python
result_label.config(text=f"{name}さん、ようこそ！")
```

にすると、

```text
たろうさん、ようこそ！
```

と表示できます。

ボタンの文字も、

```python
text="表示する"
```

のように自由に変更できます。

---

## Tk2-17. 入力が空だったら？

今のプログラムでは、名前を何も入力せずにボタンを押しても、

```text
こんにちは
```

と表示されます。

これはエラーではありません。

ただ、実際のアプリなら、

> 「名前を入力してください」

と表示したくなるかもしれません。

そのような処理では、5章で学んだ**条件分岐**が使えます。

GUIでも、これまで学んだ文法を組み合わせていきます。

## Tk2-19. ここまでで覚えること

この章では、次のことが分かれば十分です。

1. `Label` で文字を表示できる
2. `Entry` で文字を入力できる
3. `Button` で押せるボタンを作れる
4. `.get()` でEntryの内容を取り出せる
5. `config()` でLabelなどの表示を変更できる
6. `command=関数名` でボタンと関数を結び付けられる
7. GUIでは利用者の操作を待って処理する
8. この考え方をイベント駆動と呼ぶ
9. 変数や関数など、これまでの基礎文法をGUIでもそのまま使える
