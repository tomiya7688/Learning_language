## GUI について

Python で GUI アプリを作りたい人も多いため、
GUI は基礎文法をすべて終えてから扱うのではなく、**最低限の基礎を学んだ段階で早めに扱います。**

また、GUI の章から読み始める人がいることも想定し、
その章だけ読んでも進められるように、必要な変数・関数・イベントなどは章内でも簡単に説明します。

そのため、GUI 以前の章をすべて読んでいなくても、
必要に応じて戻りながら学習できる構成にします。
