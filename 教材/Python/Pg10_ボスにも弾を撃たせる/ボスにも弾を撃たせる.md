# Pg10. pygame「ボスにも弾を撃たせる」

Pg9で、ついにボスが出るようになりました。

HPも50あります。

見た目もデカいです。

……でも、

> **「ボス出たけどなんもしてこんやんけ！！！」**

ただそこにいるだけです。

これではデカい的が増えただけです。

今回は、ボスにも攻撃させます。

---

## Pg10-1. 今回作るもの

[boss_attack.py](./boss_attack.py) を開いてください。

今回追加するのは、ボス専用の弾です。

```text
ボスが出る
↓
ボスが弾を撃つ
↓
弾が下へ飛ぶ
↓
プレイヤーに当たる
```

これで、やっとボスが「攻撃してくる相手」になります。

---

## Pg10-2. ボス専用の弾を用意する

```python
boss_bullets = []
boss_bullet_speed = 4
boss_fire_interval = 60
boss_fire_timer = 0
```

通常敵の弾とは別に、ボス弾を管理します。

仕組み自体はPg6でやった敵弾とほぼ同じです。

---

## Pg10-3. ボスが出たら撃つ

ボスが出た瞬間に、

```python
bullets.clear()

boss_bullets.append([
    boss_x,
    boss_y + 40
])
```

として、最初の1発を撃たせます。

その後は、

```python
boss_fire_timer = boss_fire_timer + 1

if boss_fire_timer >= boss_fire_interval:
    boss_bullets.append([
        boss_x,
        boss_y + 40
    ])
    boss_fire_timer = 0
```

で、一定間隔ごとに撃ちます。

---

## Pg10-4. ボス弾を下へ動かす

```python
for boss_bullet in boss_bullets:
    boss_bullet[1] = boss_bullet[1] + boss_bullet_speed
```

通常敵の弾と同じで、yを増やせば下へ進みます。

---

## Pg10-5. ボス弾にも当たり判定をつける

```python
boss_bullet_rect = pygame.Rect(
    boss_bullet[0] - boss_bullet_width // 2,
    boss_bullet[1],
    boss_bullet_width,
    boss_bullet_height
)
```

プレイヤーに当たったらHPを減らします。

これで、

> **ボスが弾を撃ってくる**

ところまでできました。

---

## Pg10-6. じゃあ遊んでみる

実際に動かしてみます。

ボスが出ました。

弾も撃ってきます。

……

> **「いやデカすぎ！！！避ける場所ないやん！！！」**
