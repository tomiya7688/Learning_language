## Pg10-1. 今回作るもの

[boss_attack.py](./boss_attack.py) を開いてください。

今回追加するのは、ボス専用の弾です。

```text
ボスが出る
↓
ボスが弾を撃つ
↓
弾が下へ飛ぶ
↓
プレイヤーに当たる
```

これで、やっとボスが「攻撃してくる相手」になります。

## Pg10-2. ボス専用の弾を用意する

ボス専用の弾と、その動き・発射間隔を表す値を用意します。

```python
# boss_bullets に空のリストを入れる
boss_bullets = []
# boss_bullet_speed に4を入れる
boss_bullet_speed = 4
# boss_fire_interval に60を入れる
boss_fire_interval = 60
# boss_fire_timer に0を入れる
boss_fire_timer = 0
# boss_bullet_width に700を入れる
boss_bullet_width = 700
# boss_bullet_height に80を入れる
boss_bullet_height = 80
```

`boss_bullets` は、今画面にある**ボス弾の一覧**です。

ゲーム開始時はまだボス弾が1発もないので、空のリスト `[]` から始めます。

`boss_bullet_speed = 4` は、ボス弾が**1フレームに4ピクセル**進むという意味です。

`boss_fire_interval = 60` は、次のボス弾を撃つまでに数える**60フレーム**です。

`boss_fire_timer = 0` は、そのフレーム数を0から数え始めるための値です。

ここで、

```text
4
→ 1フレームで進む距離（ピクセル）

60
→ 発射までに数える時間（フレーム数）
```

なので、同じ数字でも単位が違います。

`boss_bullet_width` と `boss_bullet_height` は、ボス弾の幅と高さをピクセル単位で持つ値です。

```text
boss_bullet_width = 700
→ 幅700ピクセル

boss_bullet_height = 80
→ 高さ80ピクセル
```

ここでは、今あるコードの値が何を表しているかだけ確認します。

## Pg10-3. ボスが出たら撃つ

ボスが出た瞬間に、最初の1発を追加します。

```python
# bullets を空にする
bullets.clear()

# boss_bullets に [boss_x, boss_y + 40] を追加する
boss_bullets.append([
    boss_x,
    boss_y + 40
])
```

`boss_bullets.append(...)` は、ボス弾の一覧へ新しい弾1発の位置を追加する処理です。

1発のボス弾は、

```python
# x と y をリストに入れる
[x, y]
```

の2つの数字で持ちます。

このコードでは、

```text
boss_bullet[0]
→ ボス弾の横方向の中心x

boss_bullet[1]
→ ボス弾の上端y
```

として使います。

最初の値は、

```python
# boss_x を参照する
boss_x
```

なので、ボスの横位置と同じ場所が弾の横方向の中心になります。

縦位置は、

```python
# boss_y と40を足す
boss_y + 40
```

です。

`boss_y` はボスの中心yなので、そこから40ピクセル下へずらした位置を、**ボス弾の上端y**として保存します。

ボス本体は高さ60なので、中心から下端までは30ピクセルです。`boss_y + 40` はその下端よりさらに10ピクセル下の位置になります。

その後は、

```python
# boss_fire_timer に boss_fire_timer と1を足した値を入れる
boss_fire_timer = boss_fire_timer + 1

# boss_fire_timer が boss_fire_interval 以上なら
if boss_fire_timer >= boss_fire_interval:
    # boss_bullets に [boss_x, boss_y + 40] を追加する
    boss_bullets.append([boss_x, boss_y + 40])
    # boss_fire_timer に0を入れる
    boss_fire_timer = 0
```

でフレーム数を数え、60フレームに達したら同じ位置から次の弾を追加します。

発射したら `boss_fire_timer = 0` に戻し、また0から数え直します。

---

## Pg10-4. ボス弾を下へ動かす

発射したボス弾を1発ずつ下へ動かします。

```python
# boss_bullets から boss_bullet を1つずつ取り出して繰り返す
for boss_bullet in boss_bullets:
    # boss_bullet[1] に boss_bullet[1] と boss_bullet_speed を足した値を入れる
    boss_bullet[1] = boss_bullet[1] + boss_bullet_speed
```

`boss_bullet[1]` は、ボス弾の上端yです。

`boss_bullet_speed = 4` なので、ゲームループが1回進むたびに、

```text
現在の上端y + 4ピクセル
```

となります。

pygameではyが増えると下へ進むので、これでボス弾が下へ移動します。

## Pg10-5. ボス弾にも当たり判定をつける

プレイヤーと重なったか調べるため、ボス弾と同じ位置・大きさのRectを用意します。

```python
# boss_bullet_rect に pygame.Rect(boss_bullet[0] - boss_bullet_width // 2, boss_bullet[1], boss_bullet_width, boss_bullet_height) をセットする
boss_bullet_rect = pygame.Rect(
    boss_bullet[0] - boss_bullet_width // 2,
    boss_bullet[1],
    boss_bullet_width,
    boss_bullet_height
)
```

`pygame.Rect()` に渡している4つは、

```text
左端のx
上端のy
幅
高さ
```

です。

### 左端のx

```python
# boss_bullet[0] から boss_bullet_width // 2 を引く
boss_bullet[0] - boss_bullet_width // 2
```

`boss_bullet[0]` は弾の横方向の中心xです。

`boss_bullet_width // 2` は、弾の幅の半分を整数で求める部分です。

今の幅は700なので、

```text
700 // 2 = 350
```

です。

中心から350ピクセル左へずらすと、幅700の四角形の左端を求められます。

### 上端のy

```python
# boss_bullet[1] を参照する
boss_bullet[1]
```

は、発射時からボス弾の**上端y**として保存しているため、そのまま使います。

### 幅と高さ

```python
# boss_bullet_width を参照する
boss_bullet_width
# boss_bullet_height を参照する
boss_bullet_height
```

をそのままRectの幅と高さに使います。

ここで `pygame.Rect()` がしているのは、**位置と大きさを持つ四角を用意することだけ**です。

Rectを作っただけでは、画面に弾を描いたり、HPを減らしたりはしません。

次に、

```python
# boss_bullet_rect.colliderect(player_rect) が True なら
if boss_bullet_rect.colliderect(player_rect):
    # boss_bullets_to_remove に boss_bullet を追加する
    boss_bullets_to_remove.append(boss_bullet)
    # player_hp に player_hp から1を引いた値を入れる
    player_hp = player_hp - 1
```

で、ボス弾のRectとプレイヤーのRectが重なっているかを調べます。

`colliderect()` が `True` になったときだけ、当たったボス弾を消す対象へ入れ、プレイヤーHPを1減らします。

画面へ実際に描いているのは、後ろにある、

```python
# screen に (255, 80, 80) と (boss_bullet[0] - boss_bullet_width // 2, boss_bullet[1], boss_bullet_width, boss_bullet_height) を使った四角形を描く
pygame.draw.rect(
    screen,
    (255, 80, 80),
    (
        boss_bullet[0] - boss_bullet_width // 2,
        boss_bullet[1],
        boss_bullet_width,
        boss_bullet_height
    )
)
```

です。

描画側も、当たり判定側と同じ左端・上端・幅・高さを使っています。

```text
pygame.Rect(...)
→ 当たり判定に使う四角を用意

colliderect(...)
→ プレイヤーと重なったか調べる

pygame.draw.rect(...)
→ ボス弾を画面へ描く
```

という役割の違いがあります。
