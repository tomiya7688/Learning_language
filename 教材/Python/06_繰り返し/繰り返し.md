# 6. 繰り返し

この章では、同じ処理を何度も実行する方法を学びます。

今回作るのは、**指定した回数だけメッセージを表示するプログラム**です。

---

## 6-1. 今回作るもの

実行すると、何回表示するか入力します。

```text
何回表示しますか: 3
```

すると、次のように表示されます。

```text
1回目です
2回目です
3回目です
```

同じような `print()` を3回書けば、3回表示することはできます。

```python
print("メッセージ")
print("メッセージ")
print("メッセージ")
```

しかし、10回、100回、1000回と増えていくと大変です。

そこで使うのが **繰り返し** です。

### なぜ繰り返しが必要なの？

3回くらいなら、同じ `print()` を3行書いても何とかなります。

では、

```text
「こんにちは」を1000回表示してください
```

と言われたらどうでしょうか。

繰り返しを使わない場合、

```python
print("こんにちは")
print("こんにちは")
print("こんにちは")
# このあとも延々と続く……
```

と、同じ処理を1000回書くことになります。

書くのも大変ですが、途中で「やっぱり2000回にして」と言われたらさらに大変です。

繰り返しを使えば、**同じ処理を1回だけ書いて、必要な回数だけ実行する**ことができます。

---

## 6-2. サンプルコード

[repeat_message.py](./repeat_message.py) を開いてください。

`repeat` は「繰り返す」、`message` は「メッセージ」という意味です。

```python
# 何回表示するかを入力します。
count = int(input("何回表示しますか: "))

# range(count) で、0 から count - 1 まで順番に値を作ります。
for i in range(count):
    # i は 0 から始まるので、表示するときは 1 を足します。
    print(f"{i + 1}回目です")
```

---

## 6-3. `for` とは

`for` は、

> **決められた回数だけ、同じ処理を繰り返す**

ときによく使います。

今回の、

```python
for i in range(count):
    print(f"{i + 1}回目です")
```

では、`print()` が `count` 回実行されます。

---

## 6-4. `range()` とは

`range()` は、繰り返しで使う連続した整数を作ります。

たとえば、

```python
range(3)
```

では、

```text
0
1
2
```

という3つの値を順番に使えます。

3回繰り返すのに、値が `0`、`1`、`2` になるのが最初は少し不思議に見えるかもしれません。

Pythonでは、番号を0から数える場面がよくあります。

---

## 6-5. `i` は毎回変わる

次のコードでは、

```python
for i in range(3):
    print(i)
```

実行結果は、

```text
0
1
2
```

になります。

`i` には、繰り返すたびに別の値が入ります。

1回目では `0`、2回目では `1`、3回目では `2` です。

`i` という名前は短いのでよく使われますが、必ず `i` にする必要はありません。

たとえば、

```python
for number in range(3):
    print(number)
```

でも同じように動きます。

---

## 6-6. なぜ `i + 1` と書くの？

今回のサンプルでは、

```python
print(f"{i + 1}回目です")
```

と書いています。

`range(count)` で最初に入る値は `0` です。

そのまま表示すると、

```text
0回目です
1回目です
2回目です
```

となってしまいます。

人に見せる番号としては1回目から始めたいので、表示するときだけ `1` を足しています。

---

## 6-7. `f"..."` とは

今回のコードでは、

```python
print(f"{i + 1}回目です")
```

のように、文字列の前へ `f` を付けています。

これは **f文字列** と呼ばれる書き方です。

`{ }` の中に変数や計算を書くと、その結果を文字列の中へ入れられます。

たとえば、

```python
name = "Python"
print(f"{name}を勉強します")
```

と書くと、

```text
Pythonを勉強します
```

と表示されます。

今は、

> 文字の中へ変数の値を入れる方法

くらいに覚えておけば十分です。

---

## 6-8. 繰り返す処理はインデントする

`for` でも、繰り返す処理は右へずらして書きます。

```python
for i in range(3):
    print(i)
```

このインデントされた `print(i)` が、繰り返される処理です。

次のようにインデントしないと正しくありません。

```python
for i in range(3):
print(i)
```

この教材では、インデントには **半角スペース4個** を基本として使います。

---

## 6-9. `:` を忘れない

`for` の行の最後にも `:` が必要です。

```python
for i in range(3):
```

この `:` を忘れるとエラーになります。

---

## 6-10. 繰り返しの外に処理を書く

次のコードを見てみましょう。

```python
for i in range(3):
    print(i)

print("終わりました")
```

`print(i)` はインデントされているので3回実行されます。

一方、

```python
print("終わりました")
```

は `for` の外にあるので、繰り返しが終わったあとに1回だけ実行されます。

---

## 6-11. 自分で変えてみる

表示内容を変えてみましょう。

たとえば、

```python
count = int(input("何回応援しますか: "))

for i in range(count):
    print(f"{i + 1}回目: がんばれ！")
```

のようにできます。

また、回数を入力せず、

```python
for i in range(5):
    print("こんにちは")
```

と書けば、必ず5回表示できます。

---

## 6-12. `while` という繰り返しもある

Pythonには `for` のほかに `while` という繰り返しもあります。

`while` は、

> 条件が成り立っている間、繰り返す

ときに使います。

たとえばゲームで、

- HPが0になるまで続ける
- 正しい入力が来るまで待つ

といった処理で使えます。

ただし、条件がずっと変わらないと繰り返しが終わらないことがあります。

そのため、この章ではまず `for` と `range()` を使った繰り返しを中心に覚えます。

---

## 6-13. GUIでも繰り返しを使う

GUIアプリでも、繰り返しは使います。

たとえば、

- 複数の項目を順番に表示する
- ボタンをまとめて作る
- 入力されたデータを一覧表示する
- 同じ種類の部品を複数配置する

といった処理です。

このあと扱うリストとも組み合わせることで、複数のデータをまとめて処理できるようになります。
