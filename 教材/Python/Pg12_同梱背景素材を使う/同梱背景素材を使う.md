# Pg12. pygame「同梱背景素材を使う」

Pg11では、丸い星をコードで描いて背景を流しました。

スクロールの仕組みは分かりました。

でも、

> **「ずっと丸だけってのも寂しいな！！！」**

今回は、リポジトリに同梱した背景画像へ差し替えます。

敵の動きも、弾も、ボスも変えません。

> **見た目だけ画像に変えます。**

---

## Pg12-1. 今回使うもの

[bundled_background.py](./bundled_background.py) を開いてください。

背景素材は、

[assets/space_background.png](./assets/space_background.png)

です。

これはこの教材用に作ったオリジナル素材です。

外部素材は使っていません。

---

## Pg12-2. 画像を読み込む

まず、

```python
background_image = pygame.image.load(
    str(background_path)
).convert()
```

で背景画像を読み込みます。

`pygame.image.load()` は、

> **画像ファイルをpygameで使えるように読み込む**

ためのものです。

---

## Pg12-3. 画像ファイルはどこにある？

今回は、

```python
from pathlib import Path
```

を使って、

```python
background_path = (
    Path(__file__).parent
    / "assets"
    / "space_background.png"
)
```

としています。

`Path(__file__).parent` は、

> **今動かしている.pyファイルがあるフォルダ**

くらいに考えてください。

そこから、

```text
assets
↓
space_background.png
```

を探します。

これなら、別の場所からPythonを実行しても教材ファイルを見つけやすくなります。

---

## Pg12-4. ゲーム画面の大きさへ合わせる

同梱素材は160×120です。

ゲーム画面は640×480なので、

```python
background_image = pygame.transform.scale(
    background_image,
    (640, 480)
)
```

で拡大します。

今回は背景用なので、

> **画面いっぱいに表示できればOK**

です。

---

## Pg12-5. 1枚だけだと穴が空く

背景画像を1枚だけ下へ動かすと、

```text
画像が下へ動く
↓
上側が空く
↓
真っ黒な穴が見える
```

となります。

> **「背景流したら後ろ真っ黒やん！！！」**

そこで同じ背景を2枚使います。

---

## Pg12-6. 背景を上下に2枚並べる

```python
background_y_1 = 0
background_y_2 = -480
```

とします。

最初は、

```text
2枚目  y = -480
────────────
1枚目  y = 0
────────────
画面下 y = 480
```

という並びです。

2枚目は画面のすぐ上で待っています。

---

## Pg12-7. 2枚とも下へ動かす

```python
background_y_1 = background_y_1 + background_speed
background_y_2 = background_y_2 + background_speed
```

とします。

Pg11では星1個ずつのy座標を動かしました。

Pg12では、

> **背景画像そのもののy座標**

を動かします。

やっている本質は同じです。

---

## Pg12-8. 下へ抜けた画像を上へ戻す

```python
if background_y_1 >= 480:
    background_y_1 = background_y_2 - 480

if background_y_2 >= 480:
    background_y_2 = background_y_1 - 480
```

とします。

1枚が画面下へ抜けたら、

> **もう1枚の上へつなぎ直す**

だけです。

これで、

```text
背景1
↓
背景2
↓
背景1
↓
背景2
↓
...
```

とずっと流れ続けます。

---

## Pg12-9. 2枚とも描く

描画は、

```python
screen.blit(
    background_image,
    (0, background_y_1)
)

screen.blit(
    background_image,
    (0, background_y_2)
)
```

です。

`blit()` は、

> **画像をこの場所へ描く**

ために使います。

今回はx座標はどちらも0で、y座標だけ動かします。

---

## Pg12-10. 背景は一番先に描く

Pg11と同じく、背景は最初に描きます。

```text
背景画像
↓
プレイヤー
↓
弾
↓
敵
↓
ボス
```

です。

> **背景なんだから後ろにいろ！！！**

これは画像になっても同じです。

---

## Pg12-11. ゲームの仕組みは変わっていない

Pg11から変えたのは、主に背景だけです。

```text
Pg11
丸い星をdraw.circle()で描く

Pg12
画像をimage.load()で読み込んでblit()する
```

敵の座標も、

プレイヤーの移動も、

当たり判定も、

ボスHPもそのままです。

> **素材を変えてもゲームロジックはそのまま使える。**

ここが大事です。

## Pg12-13. ここまでで覚えること

1. `pygame.image.load()` で画像を読み込める
2. `Path(__file__).parent` から同梱素材の場所を作れる
3. `pygame.transform.scale()` で画像サイズを変えられる
4. `blit()` で画像を描ける
5. 背景を2枚つなぐと切れ目なくスクロールできる
6. 素材を変えてもゲームロジックはそのまま使える
