# 5. 条件分岐

## この章のゴール

プレイヤーの予想と答えを比べて、結果に合ったヒントを表示します。

ここまでに使った入力と変数を組み合わせて、数当てゲームの基本を作ります。

---

## コード

`guess.c`に、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    int answer = 42;
    int guess = 0;

    printf("1から100までの数字を予想してください: ");

    if (scanf("%d", &guess) != 1) {
        printf("数字ではないため終了します。\n");
        return 1;
    }

    if (guess < 1 || guess > 100) {
        printf("1から100までの数字を入力してください。\n");
        return 1;
    }

    if (guess == answer) {
        printf("正解です！\n");
    } else if (guess > answer) {
        printf("もっと小さい数字です。\n");
    } else {
        printf("もっと大きい数字です。\n");
    }

    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [guess.c](./guess.c)

---

## 実行例

答えより大きい`60`を入力すると、次のように表示されます。

```text
1から100までの数字を予想してください: 60
もっと小さい数字です。
```

答えの`42`を入力すると、次のように表示されます。

```text
1から100までの数字を予想してください: 42
正解です！
```

---

## コードの意味を確認する

### 入力を確認する

```c
if (scanf("%d", &guess) != 1) {
```

数字を読み取れなかった場合は、メッセージを表示して終了します。

```c
if (guess < 1 || guess > 100) {
```

`||`は「どちらか一方でも成り立つ」という意味です。

ここでは、入力が1より小さいか、100より大きい場合を確認しています。

### 同じか調べる

```c
if (guess == answer) {
    printf("正解です！\n");
}
```

`if`は、条件が成り立つときだけ波かっこの中を実行します。

`==`は、左右の値が同じか調べる記号です。数字を変数へ入れる`=`とは役割が違います。

### 別の条件を調べる

```c
else if (guess > answer) {
    printf("もっと小さい数字です。\n");
}
```

最初の条件が成り立たなかった場合に、次の条件を調べます。

`>`は、左側が右側より大きいか調べる記号です。

### それ以外を処理する

```c
else {
    printf("もっと大きい数字です。\n");
}
```

ここまでの条件がどれも成り立たなかった場合に実行されます。

このプログラムでは、予想が答えより小さい場合です。

## 書き換えてみる

答えを1から100までの好きな数字へ変えて、表示されるヒントを確認しましょう。

```c
int answer = 73;
```

正解したときの文章も変えてみます。

```c
printf("当たりです！おめでとう！\n");
```

まだ予想できるのは1回だけです。次の章では、正解するまで繰り返せるようにします。

## この章のまとめ

- `if`で条件が成り立つときの処理を書ける
- `else if`で別の条件を追加できる
- `else`でどの条件にも当てはまらない場合を処理できる
- `==`は同じか、`>`は左側が大きいかを調べる
- `||`で、2つの条件のどちらかが成り立つか調べられる
- 入力、変数、条件分岐を組み合わせると数当てゲームを作れる
