# 5. 条件分岐

## この章のゴール

第4章では、予想と答えの差を数字で表示しました。
しかし、このままではプレイヤーが差を見て判断する必要があります。

この章では、予想が答えより大きいか小さいかをプログラムが判定し、
「もっと大きい」「もっと小さい」「正解」のどれかを表示します。

このように、状況に応じて実行する処理を切り替える方法を条件分岐といいます。
条件分岐は、ゲームの勝敗判定、メニューの選択、パスワードの一致確認などにも使われます。

---

## コード

`guess.c`に、次のコードを書きます。

```c
// printfとscanfを使うため、標準入出力の宣言を読み込む
#include <stdio.h>

// C言語のプログラムで最初に実行されるmain関数を書く
int main(void) {
    // 数当てゲームの答えを保存する
    int answer = 42;

    // 入力された予想を保存する
    int guess = 0;

    // 入力を促す文章を表示する
    printf("1から100までの数字を予想してください: ");

    // 入力された整数を1つ読み取り、guessの保存場所へ書き込む
    scanf("%d", &guess);

    // 予想と答えが同じか調べる
    if (guess == answer) {
        // 正解したことを表示する
        printf("正解です！\n");
    // 不正解で、予想が答えより大きいか調べる
    } else if (guess > answer) {
        // 答えを絞るためのヒントを表示する
        printf("もっと小さい数字です。\n");
    // 正解でも答えより大きくもない場合に実行する
    } else {
        // 答えを絞るためのヒントを表示する
        printf("もっと大きい数字です。\n");
    }

    // 正常終了を表す0をOSへ返す
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [guess.c](./guess.c)

リンクを開くと、完成したコードと自分で書いたコードを見比べられます。

リポジトリをダウンロードまたはクローンしている場合、`guess.c`はこのページと同じフォルダにあります。
ターミナルで`guess.c`があるフォルダへ移動し、次のコマンドを実行します。

### Windows

```powershell
gcc guess.c -o guess.exe
.\guess.exe
```

### macOS

```bash
clang guess.c -o guess
./guess
```

この章では、プレイヤーが1から100までの整数を入力するものとして進めます。
文字や範囲外の数字が入力された場合の処理は、ここでは扱いません。

## 実行例

プログラムの答えには`42`が設定されています。

### 答えより大きい数字を入力した場合

プレイヤーが`60`を入力すると、答えを小さくするヒントが表示されます。

```text
1から100までの数字を予想してください: 60
もっと小さい数字です。
```

### 答えと同じ数字を入力した場合

プレイヤーが`42`を入力すると、正解のメッセージが表示されます。

```text
1から100までの数字を予想してください: 42
正解です！
```

実行例のコロンより後ろにある`60`と`42`は、プレイヤーがキーボードから入力した数字です。

## コードの意味を確認する

### 答えを決める

```c
int answer = 42;
```

整数を保存する変数`answer`を作り、数当てゲームの正解として`42`を入れています。
この値と、プレイヤーが入力して`guess`へ保存された値を比較します。

### 波かっこで処理をまとめる

```text
if (条件) {
    条件が成り立ったときの処理
}
```

`{`は処理のまとまりの始まり、`}`は終わりを表します。

このまとまりを**ブロック**と呼びます。`if`の条件が成り立った場合だけ、ブロック内の処理が上から順番に実行されます。

### 同じか調べる

```c
if (guess == answer) {
    printf("正解です！\n");
}
```

`if`は、条件が成り立つときだけ波かっこの中を実行します。

`==`は、左右の値が同じか調べる記号です。数字を変数へ入れる`=`とは役割が違います。

この条件全体は「入力した予想`guess`が正解`answer`と同じなら、`正解です！`と表示する」という意味です。

### 別の条件を調べる

```c
if (guess == answer) {
    printf("正解です！\n");
} else if (guess > answer) {
    printf("もっと小さい数字です。\n");
}
```

`else if`は、直前の`if`ブロックを閉じる`}`の後ろに続けて書きます。

直前の`if`が成り立たなかった場合だけ、`else if`の条件を調べます。

`>`は、左側が右側より大きいか調べる記号です。

### 比較に使う記号

2つの値を比べる記号を**比較演算子**と呼びます。

| 記号 | 成り立つ条件 | 成り立つ例 |
| --- | --- | --- |
| `==` | 左右の値が等しい | `3 == 3` |
| `!=` | 左右の値が等しくない | `3 != 5` |
| `>` | 左側の値が右側の値より大きい | `5 > 3` |
| `<` | 左側の値が右側の値より小さい | `3 < 5` |
| `>=` | 左側の値が右側の値以上 | `5 >= 5` |
| `<=` | 左側の値が右側の値以下 | `3 <= 3` |

数学で使う`≧`や`≦`ではなく、C言語では`>=`や`<=`と書きます。
記号の順番を逆にした`=>`や`=<`は使えません。
また、`=`は変数へ値を入れる記号、`==`は左右の値が等しいか調べる記号です。

### それ以外を処理する

```c
if (guess == answer) {
    printf("正解です！\n");
} else if (guess > answer) {
    printf("もっと小さい数字です。\n");
} else {
    printf("もっと大きい数字です。\n");
}
```

`else`は、最後の`if`または`else if`ブロックを閉じる`}`の後ろに続けて書きます。
`else`には条件を書かず、それより前の条件がすべて成り立たなかった場合に実行されます。

このプログラムでは、予想が答えより小さい場合に、
`もっと大きい数字です。`と表示します。

## 書き換えてみる

予想が答えより大きいか調べていた条件を、予想が答えより小さいか調べる条件へ書き換えます。

変更前の条件分岐は、次のとおりです。

```c
// 予想と答えが同じか調べる
if (guess == answer) {
    // 正解したことを表示する
    printf("正解です！\n");
// 不正解で、予想が答えより大きいか調べる
} else if (guess > answer) {
    // 答えを絞るためのヒントを表示する
    printf("もっと小さい数字です。\n");
// 正解でも答えより大きくもない場合に実行する
} else {
    // 答えを絞るためのヒントを表示する
    printf("もっと大きい数字です。\n");
}
```

`else if`の比較を`>`から`<`へ変え、2つのヒントも入れ替えます。

```c
// 予想と答えが同じか調べる
if (guess == answer) {
    // 正解したことを表示する
    printf("正解です！\n");
// 不正解で、予想が答えより小さいか調べる
} else if (guess < answer) {
    // 答えを絞るためのヒントを表示する
    printf("もっと大きい数字です。\n");
// 正解でも答えより小さくもない場合に実行する
} else {
    // 答えを絞るためのヒントを表示する
    printf("もっと小さい数字です。\n");
}
```

変更後は、`guess < answer`が成り立つときに「もっと大きい数字です。」と表示します。
それより前の条件がどちらも成り立たない場合、`guess`は`answer`より大きいため、`else`で「もっと小さい数字です。」と表示します。

`guess.c`を保存し、ターミナルで次のコマンドを1行ずつ実行します。各行を入力したらEnterキーを押してください。
1行目で一度コンパイルし、2行目の実行コマンドは入力する数字を変えながら3回実行します。

### Windows

```powershell
gcc guess.c -o guess.exe
.\guess.exe
```

### macOS

```bash
clang guess.c -o guess
./guess
```

答えが`42`の場合、次のように表示されれば、書き換え後も3つの分岐が正しく動いています。

| 入力する数字 | 表示される文章 |
| --- | --- |
| `20` | `もっと大きい数字です。` |
| `60` | `もっと小さい数字です。` |
| `42` | `正解です！` |

---

## この章のまとめ

- `if`で条件が成り立つときの処理を書ける
- `else if`で別の条件を追加できる
- `else`でどの条件にも当てはまらない場合を処理できる
- `==`や`>`などの比較演算子で、2つの値を比べられる
- 入力、変数、条件分岐を組み合わせると数当てゲームを作れる
