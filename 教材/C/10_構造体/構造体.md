# 10. 構造体

## この章のゴール

プレイヤー名、スコア、クリアしたステージ数を
一つのゲーム成績としてまとめます。

関係のある複数の値を一つにまとめたいときは、構造体が便利です。

---

## コード

`game_result.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

typedef struct {
    char player_name[32];
    int score;
    int cleared_stages;
} GameResult;

int main(void) {
    GameResult result = {"Player1", 1250, 4};

    printf("プレイヤー: %s\n", result.player_name);
    printf("スコア: %d点\n", result.score);
    printf("クリア数: %dステージ\n", result.cleared_stages);

    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [game_result.c](./game_result.c)

第2章と同じように、コンパイルしてから実行します。

実行すると、次のように表示されます。

```text
プレイヤー: Player1
スコア: 1250点
クリア数: 4ステージ
```

---

## コードの意味を確認する

### ゲーム成績の型を作る

```c
typedef struct {
    char player_name[32];
    int score;
    int cleared_stages;
} GameResult;
```

ここでは、三つの値をまとめた`GameResult`という型を作っています。

構造体の中にある一つ一つの変数を、メンバーと呼びます。

### ゲーム成績を作る

```c
GameResult result = {"Player1", 1250, 4};
```

作成した`GameResult`型を使い、`result`という変数を作ります。

値は、構造体で決めたメンバーと同じ順番で書きます。

### メンバーを使う

```c
printf("スコア: %d点\n", result.score);
```

構造体の変数名とメンバー名を`.`でつなぐと、
まとめた値を一つずつ使えます。

---

## 書き換えてみる

ゲーム成績を好きな内容へ変えてみましょう。

```c
GameResult result = {"Player2", 2000, 6};
```

さらに、残りの体力を表す`remaining_hp`を、
`GameResult`の波かっこの中へ追加してみましょう。

```c
typedef struct {
    char player_name[32];
    int score;
    int cleared_stages;
    int remaining_hp;
} GameResult;

GameResult result = {"Player2", 2000, 6, 80};
```

メンバーを追加したため、`result`を作るときの値も一つ増やしています。
最後の`80`が、`remaining_hp`へ入る値です。

---

## この章のまとめ

- 構造体は、関係のある複数の値を一つにまとめられる
- `typedef struct`で、新しい型を作れる
- 構造体の中の変数をメンバーと呼ぶ
- `構造体の変数名.メンバー名`で、まとめた値を使える
