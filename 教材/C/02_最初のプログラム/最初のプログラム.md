# 2. 最初のプログラム

## この章のゴール

ソースファイルをコンパイルして実行し、画面に文字を表示します。

画面への表示は、計算結果やエラーの原因を確認するときにも使う基本操作です。

```text
おはよう世界！
```

この章で、コードの作成から実行結果の確認までを一度行います。

---

## コードを書く

`hello.c`というファイルを作り、次のコードを書きます。

```c
// printfを使うため、標準入出力の宣言を読み込む
#include <stdio.h>

// C言語のプログラムで最初に実行されるmain関数を書く
int main(void) {
    // 文字列を表示し、最後に改行する
    printf("おはよう世界！\n");

    // 正常終了を表す0をOSへ返す
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [hello.c](./hello.c)

リンクを開くと、完成したコードと自分で書いたコードを見比べられます。

リポジトリをダウンロードまたはクローンしている場合、`hello.c`はこのページと同じフォルダにあります。

ターミナルでそのフォルダへ移動し、次のコマンドを実行すると、サンプルをそのまま試せます。

---

## コンパイルする

ターミナルで、使用しているOSのコマンドを実行します。

### Windows

```powershell
gcc hello.c -o hello.exe
```

- `gcc`は、GCCコンパイラを起動するコマンドです。
- `hello.c`は、コンパイルするソースファイルです。
- `-o hello.exe`は、完成するプログラムの名前を`hello.exe`に指定します。

### macOS

```bash
clang hello.c -o hello
```

- `clang`は、Clangコンパイラを起動するコマンドです。
- `hello.c`は、コンパイルするソースファイルです。
- `-o hello`は、完成するプログラムの名前を`hello`に指定します。

コンパイルに成功すると、Windowsでは`hello.exe`、macOSでは`hello`というファイルが作られ、
ターミナルが次のコマンドを入力できる状態へ戻ります。

コードやファイル名に誤りがある場合は、`error:`を含むメッセージが表示されます。

その場合は、メッセージに表示されたファイル名と行番号を確認してコードを直し、同じコマンドをもう一度実行します。

---

## 実行する

### Windows

```powershell
.\hello.exe
```

`.\`は、現在のフォルダにあるプログラムを指定する書き方です。

### macOS

```bash
./hello
```

`./`は、現在のフォルダにあるプログラムを指定する書き方です。

次のように表示されれば完成です。

```text
おはよう世界！
```

---

## コードの意味を確認する

ここからは、動かしたコードを一つずつ確認します。

`//`から行末までは、コードの働きを説明するコメントです。

コメントは人が読むための文章なので、プログラムの動作には影響しません。

### 表示機能を使う準備

```c
// printfを使うため、標準入出力の宣言を読み込む
#include <stdio.h>
```

`stdio.h`は、標準入出力に関する宣言をまとめたヘッダファイルです。

この行により、コンパイラが`printf`の名前や使い方を確認できます。

ヘッダファイルは`stdio.h`以外にもあり、文字列を扱う`string.h`や、
数学関数を使うための`math.h`など、利用する機能に合わせて読み込みます。

### プログラムの開始場所

```c
// C言語のプログラムで最初に実行されるmain関数を書く
int main(void) {
```

#### 関数を定義する

関数とは、ひとまとまりの処理に名前を付けたものです。

関数の名前と処理内容を書くことを、**関数を定義する**といいます。
この行から対応する`}`までが、`main`関数の定義です。

`{`と`}`で囲まれた部分に、関数が行う処理を書きます。

#### 関数の種類

C言語で使う関数には、Cの標準ライブラリにあらかじめ用意されている
**標準ライブラリ関数**と、自分で定義する**ユーザー定義関数**があります。

`printf`は標準ライブラリ関数です。

`printf`にも処理本体がありますが、標準ライブラリ側に用意されているため、
このファイルに`{`と`}`で囲まれた処理本体を書く必要はありません。

用意されている関数の処理を実行することを、**関数を呼び出す**といいます。

#### `main`の役割

`main`は自分で中身を書く関数ですが、
C言語のプログラムの開始場所として、名前と役割が決められた特別な関数です。

プログラムを起動すると`main`が自動的に呼び出され、
`main`の中に書かれた処理が上から順番に実行されます。

`void`は、`main`が呼び出し時の値を受け取らないことを表します。

### 文字を表示する

```c
// 文字列を表示し、最後に改行する
printf("おはよう世界！\n");
```

`printf("...");`と書くと、標準ライブラリ関数の`printf`を呼び出せます。

かっこの中には、表示したい文字列を指定します。

`"`で囲まれた`おはよう世界！\n`が、表示する文字列です。

`\n`は、表示位置を次の行へ移す改行文字です。

改行したい位置へ、`"`で囲まれた文字列の一部として書きます。

```c
printf("1行目\n2行目\n");
```

この例では、`1行目`と`2行目`が別の行に表示されます。

行末の`;`は、一つの処理が終わる位置を表します。

### プログラムを終了する

```c
// 正常終了を表す0をOSへ返す
return 0;
```

`return`は、`main`を終了してOSへ値を返します。

`0`は正常終了を表す終了コードです。

エラーで終了するときは、一般に`0`以外の値を返します。

---

## 書き換えてみる

元のコードにある次の行を、

```c
printf("おはよう世界！\n");
```

次の行へ置き換えます。

```c
// 表示する文字列を変更する
printf("C言語の学習を始めます！\n");
```

変更したら、もう一度コンパイルしてから実行します。

次のように表示されれば、変更が反映されています。

```text
C言語の学習を始めます！
```

---

## この章のまとめ

- C言語のファイルには`.c`を付ける
- 書いたコードはコンパイルしてから実行する
- `printf`で文字を表示できる
- コードを変更したら、もう一度コンパイルする
