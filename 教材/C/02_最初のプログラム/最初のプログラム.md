# 2. 最初のプログラム

## この章のゴール

画面に次の文字を表示します。

```text
おはよう世界！
```

まずはコードの意味より、
**書く、コンパイルする、実行する**という流れを確認します。

---

## コードを書く

`hello.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    printf("おはよう世界！\n");
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [hello.c](./hello.c)

---

## コンパイルする

ターミナルで、使用しているOSのコマンドを実行します。

### Windows

```powershell
gcc hello.c -o hello.exe
```

### macOS

```bash
clang hello.c -o hello
```

エラーが表示されず、次の入力待ちに戻れば成功です。

---

## 実行する

### Windows

```powershell
.\hello.exe
```

### macOS

```bash
./hello
```

次のように表示されれば完成です。

```text
おはよう世界！
```

---

## コードの意味を確認する

ここからは、動かしたコードを一つずつ確認します。

### 表示機能を使う準備

```c
#include <stdio.h>
```

画面へ文字を表示する機能を使うための準備です。

今は「よく使う便利な機能を読み込んでいる」と考えれば大丈夫です。

### プログラムの開始場所

```c
int main(void) {
```

プログラムは、`main`から動き始めます。

詳しい意味は、関数を学ぶ章で説明します。

### 文字を表示する

```c
printf("おはよう世界！\n");
```

`printf`は、文字や数字を表示する機能です。

`\n`は、表示したあとに改行するという意味です。

### プログラムを終了する

```c
return 0;
```

プログラムが正常に終わったことを伝えます。

---

## 書き換えてみる

表示する文章を好きな内容へ変えてみましょう。

```c
printf("C言語の学習を始めます！\n");
```

変更したら、もう一度コンパイルしてから実行します。

---

## この章のまとめ

- C言語のファイルには`.c`を付ける
- 書いたコードはコンパイルしてから実行する
- `printf`で文字を表示できる
- コードを変更したら、もう一度コンパイルする
