# 6. 繰り返し

## この章のゴール

正解するまで何度でも入力できる、数当てゲームを作ります。

同じ処理を繰り返すために、`while`を使います。

---

## コード

`number_guessing_loop.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    const int answer = 42;
    int guess = 0;
    int attempts = 0;

    printf("1から100までの数字を当ててください。\n");

    while (guess != answer) {
        printf("予想した数字: ");

        if (scanf("%d", &guess) != 1) {
            printf("数字ではないため終了します。\n");
            return 1;
        }

        if (guess < 1 || guess > 100) {
            printf("1から100までの数字を入力してください。\n");
            return 1;
        }

        attempts++;

        if (guess < answer) {
            printf("もっと大きい数字です。\n");
        } else if (guess > answer) {
            printf("もっと小さい数字です。\n");
        }
    }

    printf("正解です！ %d回で当たりました。\n", attempts);
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [number_guessing_loop.c](./number_guessing_loop.c)

## コンパイルして実行する

### Windows

```powershell
gcc -std=c17 -Wall -Wextra -pedantic number_guessing_loop.c -o number_guessing_loop.exe
.\number_guessing_loop.exe
```

### macOS

```bash
clang -std=c17 -Wall -Wextra -pedantic number_guessing_loop.c -o number_guessing_loop
./number_guessing_loop
```

正解するまで予想を入力できれば成功です。

## コードの意味を確認する

### 変更しない答えを作る

```c
const int answer = 42;
```

`const`を付けた変数は、途中で値を変更しません。

ゲーム中に答えが変わらないことを、コード上でも分かりやすくしています。

### 入力できたか確認する

```c
if (scanf("%d", &guess) != 1) {
    printf("数字ではないため終了します。\n");
    return 1;
}
```

`scanf`で整数を一つ読み取れた場合は`1`になります。

数字を読み取れなかった場合は、`return 1`でエラーとして終了します。

1から100の範囲かどうかも、第5章と同じ条件分岐で確認しています。

### 条件を満たす間は繰り返す

```c
while (guess != answer) {
```

`while`は、丸かっこの中の条件が成り立つ間、波かっこの中を繰り返します。

`guess != answer`は「予想と正解が同じではない」という意味です。

正解すると条件が成り立たなくなり、繰り返しが終わります。

### 回数を数える

```c
attempts++;
```

`++`は、変数の値を1増やす書き方です。

入力するたびに`attempts`が1増えるため、正解までの回数を数えられます。

### 終わらない繰り返しに注意する

`while`の条件がずっと成り立つと、繰り返しが終わりません。

今回のコードでは、入力した数字を毎回`guess`へ保存して条件を変えています。

---

## 回数が決まっている場合

回数が決まっている処理には、`for`も使えます。

```c
for (int i = 1; i <= 3; i++) {
    printf("%d回目\n", i);
}
```

このコードは、1回目から3回目までを順番に表示します。

---

## 書き換えてみる

- `answer`を別の数字へ変える
- ヒントの文章を自分の言葉へ変える
- 正解までの回数に応じてメッセージを変える
- `for`を使い、1から10までの数字を表示する

変更したら、もう一度コンパイルして実行します。

---

## この章のまとめ

- `while`は、条件が成り立つ間、処理を繰り返す
- `for`は、回数が決まっている繰り返しに使いやすい
- `++`で変数の値を1増やせる
- 繰り返しの条件が変わる処理を忘れない
