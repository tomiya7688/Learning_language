# 8. 配列と文字列

## この章のゴール

プレイヤー名と予想した数字の履歴を残せる、数当てゲームを作ります。

複数の値をまとめて扱う**配列**と、文章を扱う**文字列**を使います。

---

## コード

`guess_history.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

#define MAX_GUESSES 10

int main(void) {
    const int answer = 42;
    char player_name[21];
    int guesses[MAX_GUESSES];
    int attempts = 0;
    int cleared = 0;

    printf("プレイヤー名を20文字以内の半角英数字で入力してください: ");

    if (scanf("%20s", player_name) != 1) {
        printf("名前を読み取れませんでした。\n");
        return 1;
    }

    printf("1から100までの数字を当ててください。\n");

    while (attempts < MAX_GUESSES && cleared == 0) {
        int guess;

        printf("%d回目の予想: ", attempts + 1);

        if (scanf("%d", &guess) != 1) {
            printf("数字ではないため終了します。\n");
            return 1;
        }

        if (guess < 1 || guess > 100) {
            printf("1から100までの数字を入力してください。\n");
            return 1;
        }

        guesses[attempts] = guess;
        attempts++;

        if (guess < answer) {
            printf("もっと大きい数字です。\n");
        } else if (guess > answer) {
            printf("もっと小さい数字です。\n");
        } else {
            cleared = 1;
        }
    }

    printf("\n%sさんの予想履歴: ", player_name);

    for (int i = 0; i < attempts; i++) {
        printf("%d ", guesses[i]);
    }

    printf("\n");

    if (cleared == 1) {
        printf("%d回で正解しました！\n", attempts);
    } else {
        printf("%d回以内に正解できませんでした。\n", MAX_GUESSES);
    }

    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [guess_history.c](./guess_history.c)

## コンパイルして実行する

### Windows

```powershell
gcc -std=c17 -Wall -Wextra -pedantic guess_history.c -o guess_history.exe
.\guess_history.exe
```

### macOS

```bash
clang -std=c17 -Wall -Wextra -pedantic guess_history.c -o guess_history
./guess_history
```

最後にプレイヤー名と予想履歴が表示されれば成功です。

## コードの意味を確認する

### 保存できる予想の数を決める

```c
#define MAX_GUESSES 10
```

`MAX_GUESSES`を、予想を保存できる最大数として使います。

数字を直接何度も書かず、名前を付けて一か所で管理できます。

### 整数をまとめて保存する

```c
int guesses[MAX_GUESSES];
```

`guesses`は、整数を10個まで保存できる配列です。

```c
guesses[attempts] = guess;
```

配列の一つ一つの場所は、`[0]`、`[1]`、`[2]`のように番号を付けて使います。

最初の番号は1ではなく0です。この番号を**添字**と呼びます。

### 配列の中身を順番に使う

```c
for (int i = 0; i < attempts; i++) {
    printf("%d ", guesses[i]);
}
```

`for`で添字を0から順番に変えると、保存した予想を一つずつ表示できます。

### 2つの条件を確認する

```c
while (attempts < MAX_GUESSES && cleared == 0) {
```

`&&`は「両方の条件が成り立つ」という意味です。

予想回数が上限より少なく、まだ正解していない間だけ繰り返します。

`cleared`は、未正解なら`0`、正解したら`1`にしています。

### 文字列を保存する

```c
char player_name[21];
```

C言語では、文字列を`char`の配列として扱います。

この配列には、半角英数字の名前を20文字まで保存できます。残りの1文字分は、文字列の終わりを表すために使われます。

```c
scanf("%20s", player_name);
```

`%20s`は、最大20文字の文字列を読み取る指定です。

この方法では空白より後ろを読み取れないため、名前は空白を入れずに入力します。

### 配列の大きさを超えない

存在しない添字を使うと、プログラムが正しく動かない原因になります。

今回のコードは`attempts < MAX_GUESSES`を条件にして、配列の外へ書き込まないようにしています。

---

## 書き換えてみる

- `MAX_GUESSES`を5や15へ変える
- 正解の数字を変える
- 履歴を1行に一つずつ表示する
- 一番大きかった予想を探して表示する

配列の大きさを変えたときは、ゲーム終了時の文章も合わせて確認しましょう。

---

## この章のまとめ

- 配列を使うと、同じ種類の値をまとめて保存できる
- 配列の添字は0から始まる
- 文字列は`char`の配列として扱う
- 配列の大きさを超えないようにする
