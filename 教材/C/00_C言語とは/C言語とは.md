# 0. C言語とは？

## この章のゴール

この章では、次の2つが分かれば十分です。

- C言語で何が作られているのか
- 書いたプログラムをどうやって動かすのか

細かい用語やコードは、まだ暗記しなくて大丈夫です。

---

## C言語は何に使われている？

C言語は、コンピュータや機械を動かす土台として使われている言語です。

たとえば、次のような分野で使われています。

- パソコンやスマートフォンの基本システム
- 家電や自動車に組み込まれたプログラム
- ゲームやアプリの一部
- 高速な処理が必要なソフトウェア

この教材で、いきなり大規模なシステムを作るわけではありません。

最初は、文字を表示するだけの小さなプログラムから始めます。
その後、次のようなものを作ります。

- 簡単な計算プログラム
- 入力によって結果が変わるプログラム
- 数当てゲーム
- ゲームの成績をまとめるプログラム

---

## C言語はどうやって動かす？

C言語では、書いたコードをそのまま実行できません。

次の3段階で動かします。

```text
1. コードを書く
        ↓
2. 実行できる形へ変換する
        ↓
3. できあがったプログラムを実行する
```

2番の「実行できる形へ変換する」作業を、**コンパイル**と呼びます。

コンパイルに使う道具が、**コンパイラ**です。

今は、次の一文だけ覚えておけば進めます。

> C言語は、書いたあとにコンパイルしてから実行する。

---

## 最初に動かすコード

この教材で最初に動かすコードです。

今は内容を理解しようとせず、どんな見た目なのか眺めるだけで構いません。

```c
#include <stdio.h>

int main(void) {
    printf("おはよう世界！\n");
    return 0;
}
```

実行すると、次のように表示されます。

```text
おはよう世界！
```

コードの意味は、実際に動かす章で一つずつ説明します。

この章で、記号や英単語を覚える必要はありません。

---

## C言語のファイル

C言語で書いたファイルには、名前の最後に`.c`が付きます。

```text
hello.c
calculator.c
number_game.c
```

最初は、

> `.c`が付いていたらC言語のファイル

と分かれば十分です。

---

## この教材の進め方

この教材では、次の流れを繰り返します。

```text
完成例を見る
    ↓

    ↓

    ↓
結果の変化を見る
```

文法をすべて暗記してから作品を作るのではありません。

作りながら、必要になった知識を少しずつ覚えます。
