# 3. 入力と変数

## この章のゴール

プレイヤーが入力した数字を、画面に表示します。

ここでは、次の2つを使います。

- 数字を覚えておく「変数」
- キーボードから数字を受け取る`scanf`

この数字を、あとで数当てゲームの予想として使います。

---

## コード

`input.c`に、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    int guess = 0;

    printf("1から100までの数字を入力してください: ");
    scanf("%d", &guess);

    printf("入力した数字は%dです。\n", guess);
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [input.c](./input.c)

今回は、1から100までの整数が入力されるものとして進めます。

---

## 実行例

`42`と入力した場合は、次のように表示されます。

```text
1から100までの数字を入力してください: 42
入力した数字は42です。
```

コードを変更したら、第2章と同じようにコンパイルしてから実行します。

---

## コードの意味を確認する

### 数字を覚えておく

```c
int guess = 0;
```

`int`は、整数を覚えておくための型です。

`guess`は変数の名前です。変数は、数字を入れておく箱のようなものです。

最初は`0`を入れています。

### 入力を受け取る

```c
scanf("%d", &guess);
```

`scanf`は、キーボードから入力を受け取ります。

`%d`は「整数を受け取る」という目印です。

`&guess`は、受け取った数字を`guess`へ入れるために必要です。今は`&`も含めて使うと覚えれば大丈夫です。

### 変数の数字を表示する

```c
printf("入力した数字は%dです。\n", guess);
```

文章の中の`%d`が、`guess`に入っている数字へ置き換わります。

---

## 書き換えてみる

案内の文章を、好きな内容へ変えてみましょう。

```c
printf("あなたの予想を入力してください: ");
```

変更したら、もう一度コンパイルして実行します。

---

## この章のまとめ

- `int`で整数を覚える変数を作れる
- `scanf`でキーボードから数字を受け取れる
- `printf`の`%d`で変数の数字を表示できる
- 入力した数字を変数に保存すると、あとで計算や判定に使える
