# 3. 入力と変数

## この章のゴール

プログラムの案内が表示されたら、1から100の中から整数を1つ入力してEnterキーを押し、
入力した数字を画面に表示します。

ソースコードを書き換えなくても、実行するたびに別の数字を扱えるようになります。
電卓、クイズ、ゲームなど、利用者の入力によって結果が変わるプログラムで使う方法です。

ここでは、次の2つを使います。

- 数字を覚えておく「変数」
- キーボードから整数を1つ受け取る`scanf`

---

## コード

`input.c`に、次のコードを書きます。

```c
// printfとscanfを使うため、標準入出力の宣言を読み込む
#include <stdio.h>

// C言語のプログラムで最初に実行されるmain関数を書く
int main(void) {
    // 整数を保存する変数guessを作り、0を入れる
    int guess = 0;

    // 1から100の中から整数を1つ入力するよう案内する
    printf("1から100の中から整数を1つ入力してください: ");

    // 入力された整数を1つ読み取り、guessの保存場所へ書き込む
    scanf("%d", &guess);

    // %dをguessの値に置き換えて表示する
    printf("入力した数字は%dです。\n", guess);

    // 正常終了を表す0をOSへ返す
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [input.c](./input.c)

リンクを開くと、完成したコードと自分で書いたコードを見比べられます。

リポジトリをダウンロードまたはクローンしている場合、`input.c`はこのページと同じフォルダにあります。

ターミナルで`input.c`があるフォルダへ移動し、次のコマンドを実行します。

コマンドは上から1行ずつ入力し、1行ごとにEnterキーを押します。
1行目でコンパイルし、コンパイルが終わったら2行目でプログラムを実行します。

### Windows

```powershell
gcc input.c -o input.exe
.\input.exe
```

### macOS

```bash
clang input.c -o input
./input
```

このプログラムは、整数を読み取れたか、入力された整数が1から100の範囲内かを確認していません。

2行目のコマンドでプログラムを実行すると、案内が表示されて入力待ちになります。
その時点で、1から100の中から整数を1つ入力してEnterキーを押してください。

---

## 実行例

プログラムを実行すると、`1から100の中から整数を1つ入力してください:`と表示され、入力待ちになります。

そこで`42`を入力してEnterキーを押すと、次のように表示されます。

```text
1から100の中から整数を1つ入力してください: 42
入力した数字は42です。
```

コードを変更したら、上に掲載したコンパイルコマンドをもう一度実行してから、プログラムを実行します。

---

## コードの意味を確認する

### 数字を覚えておく

```c
int guess = 0;
```

`int`は、整数を覚えておくための型です。

`guess`は変数の名前です。変数は、数字を入れておく箱のようなものです。

変数を作ると同時に、最初の値を入れることを**初期化**といいます。

`int guess = 0;`は、整数を保存する変数`guess`を作り、`0`で初期化するという意味です。

ここでの`0`は、整数が入力される前に入れておく仮の値です。
プログラムが`scanf`の行へ進み、利用者が整数を1つ入力すると、`0`は入力された数字へ置き換わります。

### 入力を受け取る

```c
scanf("%d", &guess);
```

プログラムが`scanf`の行へ進むと、入力待ちになります。
`scanf`は、キーボードから整数を1つ受け取ります。

`%d`は、整数を1つ読み取る指定です。

変数`guess`の値は、コンピュータのメモリ上に保存されます。

`&guess`の`&`は、`guess`が保存されている場所のアドレスを取り出す記号です。
`scanf`はそのアドレスを受け取り、読み取った1つの整数を`guess`へ書き込みます。

### 変数の数字を表示する

```c
printf("入力した数字は%dです。\n", guess);
```

文章の中の`%d`が、`guess`に入っている数字へ置き換わります。

---

## 書き換えてみる

元のコードにある次の行を、

```c
printf("1から100の中から整数を1つ入力してください: ");
```

次の行へ置き換えます。

```c
printf("1から100の中から予想する整数を1つ入力してください: ");
```

変更したら、もう一度コンパイルして実行します。

実行して案内が表示されたら、`25`を入力してEnterキーを押します。
次のように表示されれば、変更が反映されています。

```text
1から100の中から予想する整数を1つ入力してください: 25
入力した数字は25です。
```

---

## この章のまとめ

- `int`で整数を覚える変数を作れる
- `scanf`の`%d`で、キーボードから整数を1つ受け取れる
- `printf`の`%d`で変数の数字を表示できる
- 入力した数字を変数に保存すると、計算や判定に使える
