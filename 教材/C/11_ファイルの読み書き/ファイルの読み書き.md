# 11. ファイルの読み書き

## この章のゴール

ゲームのスコアをファイルへ保存し、もう一度読み込みます。

プログラムが終了したあとも結果を残したいときは、
ファイルへの書き込みを使います。

---

## コード

`save_and_load.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    int score = 1250;
    int loaded_score = 0;

    FILE *file = fopen("game_result.txt", "w");

    if (file == NULL) {
        printf("保存用のファイルを開けませんでした。\n");
        return 1;
    }

    fprintf(file, "%d\n", score);
    fclose(file);

    file = fopen("game_result.txt", "r");

    if (file == NULL) {
        printf("読込用のファイルを開けませんでした。\n");
        return 1;
    }

    if (fscanf(file, "%d", &loaded_score) != 1) {
        printf("スコアを読み込めませんでした。\n");
        fclose(file);
        return 1;
    }

    fclose(file);

    printf("読み込んだスコア: %d点\n", loaded_score);

    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [save_and_load.c](./save_and_load.c)

第2章と同じように、コンパイルしてから実行します。

実行すると、`game_result.txt`が作られ、次のように表示されます。

ファイルは、ターミナルでプログラムを実行したフォルダに作られます。

```text
読み込んだスコア: 1250点
```

`game_result.txt`には、次の内容が保存されます。

```text
1250
```

---

## コードの意味を確認する

### 書き込み用にファイルを開く

```c
FILE *file = fopen("game_result.txt", "w");
```

`fopen`は、ファイルを開く関数です。

`FILE *file`は、開いたファイルを操作するための情報を受け取る変数です。

`"w"`を指定すると、書き込み用に開きます。
同じ名前のファイルがある場合は、内容が新しく書き直されます。

### ファイルを開けたか確認する

```c
if (file == NULL) {
```

ファイルを開けなかった場合、`fopen`は`NULL`を返します。

先に確認することで、開けていないファイルを使わずに済みます。

### スコアを書き込む

```c
fprintf(file, "%d\n", score);
```

`fprintf`は、指定したファイルへ文字や数字を書き込みます。

書き込みが終わったら、`fclose(file)`でファイルを閉じます。

### 読み込み用に開く

```c
file = fopen("game_result.txt", "r");
```

`"r"`を指定すると、読み込み用に開きます。

### スコアを読み込む

```c
if (fscanf(file, "%d", &loaded_score) != 1) {
    printf("スコアを読み込めませんでした。\n");
    fclose(file);
    return 1;
}
```

`fscanf`は、ファイルの内容を変数へ読み込みます。

`&loaded_score`で、読み込んだ値を書き込む変数の場所を渡しています。
これはポインタの章で使った方法と同じです。

`!= 1`で、整数を一つ読み取れたか確認しています。

---

## 書き換えてみる

保存するスコアを変更してみましょう。

```c
int score = 3000;
```

実行後に`game_result.txt`を開き、
変更したスコアが保存されているか確認してください。

ファイル名を`high_score.txt`などへ変えることもできます。

---

## この章のまとめ

- `fopen`でファイルを開く
- `"w"`は書き込み、`"r"`は読み込みに使う
- `fprintf`でファイルへ書き込める
- `fscanf`でファイルから読み込める
- 使い終わったファイルは`fclose`で閉じる
