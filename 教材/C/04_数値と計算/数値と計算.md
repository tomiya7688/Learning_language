# 4. 数値と計算

## この章のゴール

プレイヤーが入力した数字と、プログラムが持っている答えの差を計算します。

計算結果を見ると、予想した数字が答えより大きいか小さいか分かります。
この結果は、利用者へ「もっと大きい」「もっと小さい」というヒントを出す判定に使えます。

---

## コード

`calculation.c`に、次のコードを書きます。

```c
// printfとscanfを使うため、標準入出力の宣言を読み込む
#include <stdio.h>

// C言語のプログラムで最初に実行されるmain関数を書く
int main(void) {
    // 数当てゲームの答えを保存する
    int answer = 42;

    // 入力された予想を保存する
    int guess = 0;

    // 予想と答えの差を保存する
    int difference = 0;

    // 入力を促す文章を表示する
    printf("1から100までの数字を予想してください: ");

    // 入力された整数をguessの保存場所へ書き込む
    scanf("%d", &guess);

    // 予想から答えを引き、差を保存する
    difference = guess - answer;

    // 入力された予想を表示する
    printf("あなたの予想: %d\n", guess);

    // プログラムに設定した答えを表示する
    printf("答え: %d\n", answer);

    // 計算した差を表示する
    printf("予想 - 答え = %d\n", difference);

    // 正常終了を表す0をOSへ返す
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [calculation.c](./calculation.c)

リンクを開くと、完成したコードと自分で書いたコードを見比べられます。

リポジトリをダウンロードまたはクローンしている場合、`calculation.c`はこのページと同じフォルダにあります。
ターミナルで`calculation.c`があるフォルダへ移動し、次のコマンドを実行します。

### Windows

```powershell
gcc calculation.c -o calculation.exe
.\calculation.exe
```

### macOS

```bash
clang calculation.c -o calculation
./calculation
```

このプログラムには入力エラーの確認を入れていません。
実行時は、1から100までの整数を入力してください。

---

## 実行例

`50`と入力した場合は、次のように表示されます。

```text
1から100までの数字を予想してください: 50
あなたの予想: 50
答え: 42
予想 - 答え = 8
```

計算結果がマイナスなら予想は答えより小さく、プラスなら答えより大きいと分かります。

`0`なら、予想と答えが同じです。

---

## コードの意味を確認する

### 答えと計算結果を覚えておく

```c
int answer = 42;
int difference = 0;
```

`answer`には、数当てゲームの答えを入れています。

`difference`には、計算した差を入れます。

### 引き算する

```c
difference = guess - answer;
```

`guess`から`answer`を引き、その結果を`difference`へ入れています。

代入を表す`=`は、右側の`guess - answer`を計算してから、
その結果を左側に書かれた変数`difference`へ保存します。

### よく使う計算記号

| 記号 | 計算 | 例 |
| --- | --- | --- |
| `+` | 足し算 | `a + b` |
| `-` | 引き算 | `a - b` |
| `*` | 掛け算 | `a * b` |
| `/` | 割り算 | `a / b` |
| `%` | 余り | `a % b` |

整数同士を`/`で割った結果も整数になるため、小数部分は残りません。
C言語では、小数部分を取り除き、`0`に近い方向の整数にします。

たとえば、`7 / 2`は`3`、`-7 / 2`は`-3`です。

`0`で割る計算には結果を決められないため、`/`や`%`の右側に`0`を置くことはできません。
実行時に`0`で割ると、プログラムが異常終了するなど、動作が保証されません。

---

## 書き換えてみる

答えを1から100までの好きな数字へ変えてみましょう。

変更前は`42`です。

```c
int answer = 42;
```

たとえば、変更後を`73`にします。

```c
int answer = 73;
```

次に、元のコードにある、

```c
difference = guess - answer;
```

を、次のように書き換えて、引く順番を逆にします。

```c
difference = answer - guess;
```

計算結果のプラスとマイナスがどう変わるか確認します。

---

## この章のまとめ

- 変数には計算結果も入れられる
- `+`、`-`、`*`、`/`、`%`で計算できる
- `=`の右側を計算して、結果を左側の変数へ入れる
- 予想と答えの差から、どちらが大きいか分かる
