# 4. 数値と計算

## この章のゴール

プレイヤーが入力した数字と、プログラムが持っている答えの差を計算します。

計算結果を見ると、予想した数字が答えより大きいか小さいか分かります。

---

## コード

`calculation.c`に、次のコードを書きます。

```c
#include <stdio.h>

int main(void) {
    int answer = 42;
    int guess = 0;
    int difference = 0;

    printf("1から100までの数字を予想してください: ");
    scanf("%d", &guess);

    difference = guess - answer;

    printf("あなたの予想: %d\n", guess);
    printf("答え: %d\n", answer);
    printf("予想 - 答え = %d\n", difference);
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [calculation.c](./calculation.c)

今回は、1から100までの整数が入力されるものとして進めます。

---

## 実行例

`50`と入力した場合は、次のように表示されます。

```text
1から100までの数字を予想してください: 50
あなたの予想: 50
答え: 42
予想 - 答え = 8
```

計算結果がマイナスなら予想は答えより小さく、プラスなら答えより大きいと分かります。

`0`なら、予想と答えが同じです。

---

## コードの意味を確認する

### 答えと計算結果を覚えておく

```c
int answer = 42;
int difference = 0;
```

`answer`には、数当てゲームの答えを入れています。

`difference`には、あとで計算した差を入れます。

### 引き算する

```c
difference = guess - answer;
```

`guess`から`answer`を引き、その結果を`difference`へ入れています。

右側の計算が先に行われ、結果が左側の変数へ入ります。

### よく使う計算記号

| 記号 | 計算 | 例 |
| --- | --- | --- |
| `+` | 足し算 | `a + b` |
| `-` | 引き算 | `a - b` |
| `*` | 掛け算 | `a * b` |
| `/` | 割り算 | `a / b` |
| `%` | 余り | `a % b` |

整数同士を`/`で割ると、小数点以下は切り捨てられます。

`/`や`%`の右側に`0`を置くことはできません。

---

## 書き換えてみる

答えを1から100までの好きな数字へ変えてみましょう。

```c
int answer = 73;
```

次に、引く順番も逆にしてみましょう。

```c
difference = answer - guess;
```

計算結果のプラスとマイナスがどう変わるか確認します。

---

## この章のまとめ

- 変数には計算結果も入れられる
- `+`、`-`、`*`、`/`、`%`で計算できる
- `=`の右側を計算して、結果を左側の変数へ入れる
- 予想と答えの差から、どちらが大きいか分かる
