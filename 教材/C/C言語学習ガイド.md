# C言語学習ガイド

C言語の開発環境を準備し、機能を追加しながら数当てゲームを作る教材です。

教材を完了すると、次のことができます。

- C言語のソースファイルをコンパイルして実行する
- 変数、条件分岐、繰り返し、関数、配列を使ってプログラムを組み立てる
- ポインタと構造体を使ってデータを操作する
- プログラムの結果をファイルへ保存し、読み込む
