# C言語学習ガイド

C言語を初めて学ぶ人向けの教材です。

文法をすべて覚えてから作品を作るのではなく、
小さなプログラムを動かしながら必要な知識を学びます。

## 最初の目標

最初は、画面へ文字を表示するプログラムを動かします。

その後は、入力や条件分岐を追加しながら、
小さな数当てゲームを作ります。

後半では、ゲームの処理を整理し、
結果をファイルへ保存できるようにします。

## 進め方

すべてを暗記する必要はありません。

各章のサンプルを動かし、少し書き換えて、
結果がどう変わるかを確認しながら進めてください。
