# 9. ポインタ

## この章のゴール

関数から、呼び出し元の変数を書き換えます。

今回は、ゲームのスコアにボーナスを加えるプログラムを作ります。

ポインタには細かな仕組みもありますが、まずは
**変数の場所を関数へ伝える方法**として使ってみましょう。

---

## コード

`update_score.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

void add_bonus(int *score, int bonus) {
    *score = *score + bonus;
}

int main(void) {
    int score = 250;

    printf("ボーナス前: %d点\n", score);
    add_bonus(&score, 100);
    printf("ボーナス後: %d点\n", score);

    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [update_score.c](./update_score.c)

第2章と同じように、コンパイルしてから実行します。

実行すると、次のように表示されます。

```text
ボーナス前: 250点
ボーナス後: 350点
```

---

## コードの意味を確認する

### 変数の場所を受け取る

```c
void add_bonus(int *score, int bonus) {
```

`int *score`は、`int`型の変数がある場所を受け取ります。

普通の`int`を渡すと、関数には値のコピーが渡されます。
ポインタを使うと、呼び出し元の変数を直接書き換えられます。

### 呼び出し元の値を書き換える

```c
*score = *score + bonus;
```

`*score`は、受け取った場所にある実際の値を表します。

ここでは、その値に`bonus`を加えています。

### 変数の場所を渡す

```c
add_bonus(&score, 100);
```

`&score`は、変数`score`がある場所を表します。

この場所を渡しているため、`add_bonus`の中から
`main`にある`score`を書き換えられます。

---

## 書き換えてみる

最初のスコアと、加えるボーナスを変えてみましょう。

```c
int score = 500;
add_bonus(&score, 250);
```

実行結果が何点になるか、先に予想してから試してみてください。

---

## この章のまとめ

- ポインタは、変数の場所を扱うために使える
- `&変数名`で、その変数がある場所を渡せる
- `*ポインタ名`で、その場所にある値を読み書きできる
- ポインタを使うと、関数から呼び出し元の変数を書き換えられる
