# 1. C言語の環境構築

> **このページは仮案です。**
>
> Windowsの導入方法は、レビュー後に詳しい手順を追加します。

C言語の学習には、次の2つを使います。

- コードを書くためのエディタ
- コードを実行できる形へ変換するコンパイラ

## エディタ

この教材では、Visual Studio Codeを使用する予定です。

- [Visual Studio Code公式サイト](https://code.visualstudio.com/)

## Windows

Windowsでは、MinGW-w64向けのGCCツールチェーンの利用を検討しています。

- [MinGW-w64公式サイト](https://www.mingw-w64.org/)

具体的な導入方法は、動作確認を行ってから追記します。

## macOS

macOSでは、AppleのCommand Line Toolsに含まれるClangを使用する予定です。

ターミナルで、次のコマンドから導入できます。

```bash
xcode-select --install
```

- [Apple公式: Command Line Toolsの導入](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools)
