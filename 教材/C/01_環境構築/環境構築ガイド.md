# 1. C言語の環境構築

C言語の学習には、次の2つを使います。

- コードを書くためのエディタ「Visual Studio Code」
- コードを実行できる形へ変換するコンパイラ

WindowsではGCC、macOSではClangというコンパイラを導入します。

---

## Windows

### 1. Visual Studio Codeを導入する

[Visual Studio Code公式サイト](https://code.visualstudio.com/)から、
Windows版をダウンロードしてインストールします。

Visual Studio Codeを起動したら、左側の拡張機能アイコンを選び、
`C/C++`と検索してMicrosoft製の「C/C++」拡張機能をインストールします。

### 2. MSYS2を導入する

[MSYS2公式サイト](https://www.msys2.org/)からインストーラーをダウンロードし、
初期設定のままインストールします。

インストール完了時にMSYS2を起動すると、UCRT64環境のターミナルが開きます。

### 3. GCCを導入する

開いたMSYS2のターミナルへ、次のコマンドを入力します。

```bash
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
```

このコマンドは、C言語のコンパイルに使うGCCなどをまとめて導入します。

インストールするパッケージを選ぶ画面では`Enter`キーを押し、
続行するか聞かれたら`Y`を入力して`Enter`キーを押します。

### 4. GCCへパスを通す

Windowsの検索欄で「環境変数」と検索し、
「環境変数を編集」を開きます。

ユーザー環境変数の`Path`を選んで「編集」から「新規」を押し、
次の場所を追加します。

```text
C:\msys64\ucrt64\bin
```

MSYS2のインストール先を変更した場合は、
実際のインストール先にある`ucrt64\bin`を指定します。

設定後は、開いているPowerShellをすべて閉じてから開き直します。

### 5. GCCを確認する

PowerShellを開いて、次のコマンドを実行します。

```powershell
gcc --version
```

`gcc`のバージョン情報が表示されれば導入完了です。

`gcc`が見つからないと表示された場合は、
PowerShellを開き直したか、`Path`へ追加した場所が正しいか確認します。

- [VS Code公式: WindowsでGCCを使う手順](https://code.visualstudio.com/docs/cpp/config-mingw)
- [MSYS2公式: インストール手順](https://www.msys2.org/docs/installer/)

---

## macOS

### 1. Visual Studio Codeを導入する

[Visual Studio Code公式サイト](https://code.visualstudio.com/)から、
macOS版をダウンロードしてインストールします。

Visual Studio Codeを起動したら、左側の拡張機能アイコンを選び、
`C/C++`と検索してMicrosoft製の「C/C++」拡張機能をインストールします。

### 2. ターミナルを開く

`command`キーと`space`キーを同時に押してSpotlight検索を開き、
「ターミナル」と入力してターミナルアプリを起動します。

ターミナルは、文字でコンピュータへ命令を入力するアプリです。

### 3. Clangを導入する

ターミナルへ次のコマンドを入力します。

```bash
xcode-select --install
```

このコマンドは、Clangを含むAppleのCommand Line Toolsの
インストール画面を開きます。表示された案内に従ってインストールします。

すでに導入済みと表示された場合は、そのまま次へ進みます。

### 4. Clangを確認する

インストール後、ターミナルで次のコマンドを実行します。

```bash
clang --version
```

`clang`のバージョン情報が表示されれば導入完了です。

- [Apple公式: Command Line Toolsの導入](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools)

---

## コンパイルと実行を確認する

Visual Studio Codeで、このリポジトリの`Learning_language`フォルダを開きます。

画面上部の「ターミナル」から「新しいターミナル」を選び、
次のコマンドで確認用ファイルがあるフォルダへ移動します。

### Windows

```powershell
cd "教材\C\02_最初のプログラム"
gcc hello.c -o hello.exe
.\hello.exe
```

### macOS

```bash
cd "教材/C/02_最初のプログラム"
clang hello.c -o hello
./hello
```

どちらのOSでも、次の文字が表示されれば、コンパイラによる変換と実行ができています。

```text
おはよう世界！
```

`error:`を含むメッセージが表示された場合は、現在開いているフォルダと入力したファイル名を確認します。
`gcc`または`clang`が見つからない場合は、このページのバージョン確認まで戻り、コンパイラの設定を確認します。
