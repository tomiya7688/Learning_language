# 7. 関数

## この章のゴール

数当てゲームの処理を、役割ごとの関数に分けます。

長い処理を小さく分けて、読みやすく直しやすいプログラムにします。

---

## コード

`number_guessing_functions.c`というファイルを作り、次のコードを書きます。

```c
#include <stdio.h>

void show_hint(int guess, int answer) {
    if (guess < answer) {
        printf("もっと大きい数字です。\n");
    } else if (guess > answer) {
        printf("もっと小さい数字です。\n");
    } else {
        printf("正解です！\n");
    }
}

int calculate_score(int attempts) {
    int score = 100 - (attempts - 1) * 10;

    if (score < 10) {
        return 10;
    }

    return score;
}

int main(void) {
    const int answer = 42;
    int guess = 0;
    int attempts = 0;

    printf("1から100までの数字を当ててください。\n");

    while (guess != answer) {
        printf("予想した数字: ");

        if (scanf("%d", &guess) != 1) {
            printf("数字ではないため終了します。\n");
            return 1;
        }

        if (guess < 1 || guess > 100) {
            printf("1から100までの数字を入力してください。\n");
            return 1;
        }

        attempts++;
        show_hint(guess, answer);
    }

    printf("挑戦回数: %d回\n", attempts);
    printf("スコア: %d点\n", calculate_score(attempts));
    return 0;
}
```

同じ内容のサンプルファイルもあります。

- [number_guessing_functions.c](./number_guessing_functions.c)

## コンパイルして実行する

### Windows

```powershell
gcc -std=c17 -Wall -Wextra -pedantic number_guessing_functions.c -o number_guessing_functions.exe
.\number_guessing_functions.exe
```

### macOS

```bash
clang -std=c17 -Wall -Wextra -pedantic number_guessing_functions.c -o number_guessing_functions
./number_guessing_functions
```

ヒント、挑戦回数、スコアが表示されれば成功です。

---

## コードの意味を確認する

### 関数を作る

```c
void show_hint(int guess, int answer) {
```

`show_hint`は、入力した数字に合わせてヒントを表示する関数です。

`guess`と`answer`は、関数が処理に使う値です。このように関数へ渡す値を**引数**と呼びます。

先頭の`void`は、この関数が値を返さないことを表します。

### 関数を呼び出す

```c
show_hint(guess, answer);
```

関数は、名前を書いて呼び出します。

この行では、現在の予想と正解を`show_hint`へ渡しています。

### 計算結果を返す

```c
int calculate_score(int attempts) {
```

`calculate_score`は、挑戦回数からスコアを計算する関数です。

先頭の`int`は、この関数が整数を返すことを表します。

```c
return score;
```

`return`を使うと、関数を呼び出した場所へ計算結果を返せます。

### mainも関数

これまで使ってきた`main`も関数です。

C言語のプログラムは、`main`関数から動き始めます。

---

## 書き換えてみる

- `calculate_score`の計算方法を変える
- あいさつを表示する`show_title`関数を追加する
- 正解したときだけ特別な文章を表示する
- 関数名を変えて、呼び出す側も同じ名前へ変える

関数名は、その関数の役割が分かる名前にしましょう。

---

## この章のまとめ

- 関数を使うと、処理を役割ごとに分けられる
- 引数を使うと、関数へ値を渡せる
- `return`を使うと、関数から値を返せる
- 値を返さない関数には`void`を使う
