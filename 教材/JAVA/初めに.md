# Java：初めに・目次

> 「Javaでプログラムを作りたいけど、どこから始めればいい？」

Javaを初めて学ぶ場合は、[0. Javaとは？](./00_Javaとは/Javaとは.md)を開いてください。Javaを書く道具の準備から始める場合は、[1. 環境構築](./01_環境構築/環境構築.md)を開いてください。

## 読む順番

0. [Javaとは？](./00_Javaとは/Javaとは.md)：第0章は、Javaで作れるものと、コードを保存するファイルを紹介します。
1. [環境構築](./01_環境構築/環境構築.md)：第1章は、Javaを書く・動かすための道具を準備する手順を説明します。
2. [最初のプログラム](./02_最初のプログラム/最初のプログラム.md)：第2章は、`Hello World!`という文字を表示するプログラムの例を説明します。
