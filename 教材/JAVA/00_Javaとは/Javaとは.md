# 0. Java とは？

この章では、まず Java ってなに？ということを説明します。

## 0-1. この教材を一通り終えると何ができる？

この教材を読み終えた頃には、あなたは Java で基本的なアプリケーションやプログラムが作れるようになっているでしょう。

この教材では、たとえば次のようなものを作ります。

* **電卓**: 2つの数字を入力して「計算する」ボタンを押すと、計算結果が表示されます。足し算・引き算・掛け算・割り算、sinとcosを使った簡単な関数電卓も作ります。

* **メモを残すプログラム**: 書いた文章をテキストファイルとして保存し、あとから読み返せるようにします。

* **簡単なゲーム**: キャラクターを動かして点数を競うようなミニゲームを作ります。

最初に作るのは、画面に "Hello World!" と表示するプログラムです。そのあと、名前を入力したり、計算をしたりするプログラムを作っていきます。

まずは Java を使う準備をしましょう。

---

## 0-2. Java はプログラミング言語

プログラミング言語は、コンピュータを動かすために書く言語です。Java は、そのひとつです。

Java で書いたプログラムの中身を**コード**と呼びます。

Java は世界中で広く使われており、Webシステムやスマホアプリ（Android）、大規模な企業システムなど、さまざまな場所で活躍しています。

---

## 0-3. Java の特徴

Java は「一度書けば、どこでも動く」という大きな特徴を持っています。Windows でも Mac でも Linux でも同じように動作します。

## 0-4. Java のバージョンとJDK

Javaには長年の歴史があり、定期的に新しいバージョン (Java 17, Java 21 など) リリースされています。

この教材では、現在多く使われている標準的なJava (LTSバージョン) を扱います。

Javaのプログラムを開発して動かすためにはJDK (Java Development Kit) というツールキットが必要になります。次の章で詳しくインストール手順を解説します。

## 0-5. Javaのファイル

Javaのソースコードでは、一般的に「.java」という拡張子のファイルへ保存します。

たとえば、

```text
HelloWorld.java
Calculator.java
Game.java
```

この「.java」ファイルの中に、Javaのコードを書きます。

## 0-6. Javaを学ぶときに大切なこと

この教材では、

小さなコードを見る

実際に動かす

コードを少し変更する

何が変わったか確認する

必要な文法を少しずつ覚える

という流れで進めます。

エラーが出ることも学習の一部です。エラーメッセージの読み方や、つまずきやすい点も必要に応じて説明します。

次の章では、Java を動かすために必要なもの（JDK や VS Code の設定）をインストールします。そのあと、実際にコードを書き、ファイルに保存して動かします。
