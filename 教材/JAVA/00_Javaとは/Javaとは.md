# 0. Java とは？

> **「電卓やメモアプリを自分で作るには、何から始めればいい？」**

## 0-1. Java はどんな言語？

Java は、コンピュータを動かすために書く言語である**プログラミング言語**のひとつです。

Java で書いたプログラム（コンピュータに行わせる計算や表示などを書いたもの）の中身を**コード**と呼びます。

## 0-2. Java で何が作れる？

Java では、たとえば次のようなアプリ（パソコンなどで使うプログラム）を作れます。

* **電卓**：足し算・引き算・掛け算・割り算ができるアプリ。

* **メモアプリ**：書いた文章をパソコンに保存し、あとから開いて読み返せるアプリ。

* **ゲーム**：キーボードでキャラクターを動かし、点数を競うゲーム。

電卓やゲームを書き始める前に、自分のパソコンで Java のプログラムが動くことを確かめる必要があります。[第2章](../02_最初のプログラム/最初のプログラム.md)には、`Hello World!` と表示する短いプログラムの例があります。

---

## 0-3. Java の特徴

Java は「Write Once, Run Anywhere（一度書けば、どこでも動く）」をスローガンに掲げています。「一度書けば、どこでも動く」は、Windows、macOS、Linux など、異なる種類のパソコンでも同じ Java プログラムを動かせるようにする考え方です。

ただし、Java のプログラムを実行するパソコンには、実行対象の Java プログラムに対応する実行環境（Java のプログラムを動かすためのソフトウェア）が必要です。特定の種類のパソコンだけで使える機能に頼るプログラムは、ほかの種類のパソコンでは同じように動くとは限りません。[Oracle の説明](https://docs.oracle.com/en/database/oracle/oracle-database/26/jjdev/Java-overview.html)でも、Java で特定の環境に依存するコードを書けることが示されています。

## 0-4. Java を書いて動かすための道具

Java のコードを書くときは、文章を編集するアプリ **Visual Studio Code（VS Code）** を使ってください。

**JDK（Java Development Kit）** は、Java のプログラムを実行できる形式に変換する道具と、Java のプログラムを動かす実行環境をまとめたものです。

## 0-5. Java のファイル

Java のコードは、通常、名前の最後が `.java` のファイルに保存されます。ファイル名の末尾に付けて種類を表す `.java` のような部分を、**拡張子**と呼びます。

Java のコードを保存するファイル名の例：

```text
HelloWorld.java
Calculator.java
Game.java
```

第2章のサンプルは、[`HelloWorld.java`](../02_最初のプログラム/HelloWorld.java) に保存されています。
