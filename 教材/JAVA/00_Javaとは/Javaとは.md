# 0. Java とは？

> **「電卓やメモアプリを自分で作るには、何から始めればいい？」**

## 0-1. Java で何が作れる？

Java では、たとえば次のようなアプリを作れます。

* **電卓**：足し算・引き算・掛け算・割り算ができるアプリ。

* **メモアプリ**：書いた文章をパソコンに保存し、あとから開いて読み返せるアプリ。

* **ゲーム**：キーボードでキャラクターを動かし、点数を競うゲーム。

電卓やゲームを書き始める前に、自分のパソコンで Java のプログラムが動くことを確かめる必要があります。第2章では、`Hello World!` と表示する短いプログラムで、保存・実行・表示を確かめてください。

---

## 0-2. Java はプログラミング言語

プログラミング言語は、コンピュータを動かすために書く言語です。Java は、そのひとつです。

Java で書いたプログラムの中身を**コード**と呼びます。

## 0-3. Java の特徴

Java は「Write Once, Run Anywhere（一度書けば、どこでも動く）」をスローガンに掲げています。Windows、macOS、Linux など、異なる種類のパソコンでも同じ Java プログラムを動かせるようにする考え方です。

ただし、実行するパソコンには、そのプログラムに対応する Java の実行環境（Java のプログラムを動かすためのソフトウェア）が必要です。特定の種類のパソコンだけで使える機能に頼るプログラムは、ほかの種類のパソコンでは同じように動くとは限りません。[Oracle の説明](https://docs.oracle.com/en/database/oracle/oracle-database/26/jjdev/Java-overview.html)でも、Java で特定の環境に依存するコードを書けることが示されています。

## 0-4. Java を書いて動かすための道具

Java のプログラムを書くときは、JDK（Java Development Kit）という道具一式を使います。JDK には、書いたプログラムを実行できる形式に変換する道具と、Java のプログラムを動かす実行環境が含まれます。

## 0-5. Java のファイル

Java のコードは、通常、名前の最後が `.java` のファイルに保存されます。ファイル名の末尾に付けて種類を表す `.java` のような部分を、**拡張子**と呼びます。

たとえば、

```text
HelloWorld.java
Calculator.java
Game.java
```

`HelloWorld.java`、`Calculator.java`、`Game.java` は、Java のコードを保存するファイル名の例です。第2章では `HelloWorld.java` にコードを書いて保存してください。

## 0-6. 進め方

第2章では、`HelloWorld.java` を実行し、表示する文章を書き換えてもう一度実行してください。変更前と変更後の表示を比べると、コードのどの部分が表示する文章に対応するかを確かめられます。

コードを書く・動かすための道具を用意するところから始める場合は、次の **[1. 環境構築](../01_環境構築/環境構築.md)** を開いてください。
