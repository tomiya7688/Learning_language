# 1. Javaを書く・動かすための準備（Windows）

> 「コードを書くアプリは入れたのに、Javaが動かない！」

Javaのコードを書くには編集用のアプリ、Javaのコードを動かすにはJDKという道具が必要です。コードを書く・動かす道具を用意し、使えるように設定する作業を、**環境構築（かんきょうこうちく）**と呼びます。

このページはWindows 11向けです。Macを使う場合は[Mac向けの環境構築](./Mac向けの環境構築.md)、Linuxを使う場合は[Linux向けの環境構築](./Linux向けの環境構築.md)を開いてください。MacとLinuxの説明は制作中です。

## 用意する道具

| 道具 | この章での役割 |
| --- | --- |
| Visual Studio Code（VS Code） | Javaのコードを入力・編集するアプリです。 |
| JDK（Java Development Kit） | Javaのコードを実行できる形式へ変換する `javac` と、Javaのプログラムを動かす `java` を含む道具です。 |
| Extension Pack for Java | VS CodeへJavaの編集・実行などの機能を追加する拡張機能です。JDK本体とは別に入れます。 |

この章では、Microsoftが配布する **Microsoft Build of OpenJDK 25** をJDKの導入例に使います。GUIライブラリはこの章で選びません。[MicrosoftのJDK配布ページ](https://learn.microsoft.com/en-us/java/openjdk/download)・[VS Code公式：Java用拡張機能とJDK](https://code.visualstudio.com/docs/java/java-tutorial)

## 1-1. VS Codeを入れて日本語にする

既にVS Codeを使っている場合は、メニューの表示言語を確認してください。メニューが日本語なら[1-2. JDK本体をインストールする](#1-2-jdk本体をインストールする)へ進んでください。メニューが英語なら、以下の手順5〜7で日本語表示の機能を追加してください。

1. ブラウザで[VS Codeのダウンロードページ](https://code.visualstudio.com/download)を開いてください。Windows向けの配布物を選ぶページが表示されます。
2. Windowsの **設定 → システム → バージョン情報** を開き、**システムの種類** を確認してください。`x64` のプロセッサと表示された場合は、ダウンロードページのWindows **User Installer / x64** を選んでください。`ARM` のプロセッサと表示された場合は **User Installer / Arm64** を選んでください。User Installerは、自分のWindowsアカウントへVS Codeを入れるファイルです。x64とArm64は、パソコンの処理装置であるプロセッサの種類を表します。[Microsoft公式：システムの種類の確認](https://support.microsoft.com/en-au/windows/experience/compatibility/32-bit-and-64-bit-windows-frequently-asked-questions)
3. エクスプローラーの **ダウンロード** を開き、保存された `VSCodeUserSetup-` で始まる `.exe` ファイルをダブルクリックしてください。VS Codeのインストール画面が開きます。`.exe` はWindowsで実行するファイルの名前の末尾です。
4. VS Codeのインストール画面で使用条件を確認して同意し、**次へ（Next）** を押してください。保存先などの設定画面は初期値で進み、**インストール（Install）** を押してください。完了画面の **完了（Finish）** を押すと、VS Codeを起動できます。[VS Code公式：Windowsへの導入](https://code.visualstudio.com/docs/setup/windows)
5. VS Codeの左側の四角が並んだ **拡張機能（Extensions）** をクリックしてください。拡張機能を検索・追加する画面が表示されます。
6. VS Codeの拡張機能の検索欄へ `Japanese Language Pack for Visual Studio Code` を入力してください。Microsoftが公開する同名の項目を選び、**Install** を押してください。日本語表示のための拡張機能が入ります。
7. VS Codeを一度閉じ、WindowsのスタートメニューからVisual Studio Codeを開いてください。メニューが日本語になります。表示が英語のままなら、VS Codeの **View → Command Palette** を開き、`Configure Display Language` を入力して選んでください。言語の一覧で `ja` を選び、再起動の案内に従ってください。[VS Code公式：表示言語](https://code.visualstudio.com/docs/configure/locales)

## 1-2. JDK本体をインストールする

既に同じMicrosoftのJDK 25を入れてある場合は、重ねて別形式のインストーラーを使わず、次の確認へ進んでください。[Microsoft公式：インストール方法の選択](https://learn.microsoft.com/en-us/java/openjdk/install#install-on-windows)

JDKをダウンロードしただけでは、まだ使える状態になりません。保存したインストーラーを開き、導入を最後まで行ってください。インストーラーは、ソフトウェアをパソコンへ入れるためのプログラムです。

1. Windowsの **設定 → システム → バージョン情報** を開き、**システムの種類** を確認してください。`x64` のプロセッサならx64用、`ARM` のプロセッサならARM64用のJDKを選びます。Windowsという名前だけでは、JDKの配布物を一つに決められません。
2. ブラウザで[MicrosoftのJDK配布ページ](https://learn.microsoft.com/en-us/java/openjdk/download#openjdk-25)を開いてください。**OpenJDK 25** の表で、Platformが **Windows**、Architectureが手順1で確認した **x64** または **AArch64 / ARM64**、Typeが **exe** の行のダウンロードリンクをクリックしてください。名前が `microsoft-jdk-25` で始まるWindows用の `.exe` ファイルが保存されます。
3. エクスプローラーの **ダウンロード** を開き、保存された `microsoft-jdk-25` で始まる `.exe` ファイルをダブルクリックしてください。JDKのインストール画面が開きます。Windowsから変更を許可するか尋ねられた場合は、JDKの導入を進めるため **はい** を選んでください。
4. JDKのインストール画面で使用条件を確認し、画面の **次へ（Next）** で設定を進めてください。インストール先と機能は初期値を使い、**インストール（Install）** を押してください。完了画面の **完了（Finish）** を押すと、JDK本体の導入が終わります。このインストーラーは初期設定でPATHへJDKの道具を登録します。PATHは、ターミナルが `java` などの名前から道具を見つける場所の設定です。[Microsoft公式：WindowsへのJDK導入](https://learn.microsoft.com/en-us/java/openjdk/install#install-on-windows)
5. VS Codeやターミナルを開いていた場合は一度閉じ、WindowsのスタートメニューからVS Codeを開き直してください。開き直したVS Codeで、JDKを入れた後のPATH設定を使えます。

既に同じMicrosoftのJDK 25を入れてある場合は、重ねて別形式のインストーラーを使わず、次の確認へ進んでください。[Microsoft公式：インストール方法の選択](https://learn.microsoft.com/en-us/java/openjdk/install#install-on-windows)

## 1-3. ターミナルでjavaとjavacを確認する

ターミナルは、コマンドという操作用の文字列を入力し、結果の文字を読む場所です。Javaのコードを入力する編集画面とは別の場所です。

1. VS Codeの **表示 → ターミナル** を開いてください。画面下にコマンドを入力する欄が表示されます。
2. VS Codeのターミナルへ次を入力し、入力したコマンドを実行するためにEnterキーを押してください。`java` が使える場合は、Javaのバージョンが表示されます。今回入れたJDK 25が使われているなら、最初の行に `25` で始まるバージョンが表示されます。

```text
java --version
```

3. VS Codeの **表示 → ターミナル** で、手順2のターミナルを表示してください。次を入力してEnterキーを押してください。`javac` が使える場合は、`javac 25` で始まるバージョンが表示されます。`java` の表示だけでは、コードを変換する `javac` も使えるとは判断できません。

```text
javac --version
```

バージョンの例は `25.0.4` のような形です。25の後ろの数字は、更新に応じて変わります。

### javaやjavacが見つからない場合

「認識されません」などのエラーが出た場合は、JDKのインストールを完了したか確認し、VS Code全体を閉じて開き直してください。VS Codeの **表示 → ターミナル** を開き、`java --version` と `javac --version` を1行ずつ入力して、その都度Enterキーを押してください。両方のバージョンが表示されれば、次の拡張機能の追加へ進めます。

導入後も道具が見つからない場合は、JDKのインストーラーをもう一度開き、PATHを更新する機能が有効か確認してください。[Microsoft公式：PATHを更新する機能](https://learn.microsoft.com/en-us/java/openjdk/install#install-on-windows)

### 以前のJavaのバージョンが表示される場合

別のJDKが先に見つかっている可能性があります。VS Codeの **表示 → ターミナル** を開き、次を1行ずつ入力し、その都度Enterキーを押してください。`where.exe` が、Windowsが見つける `java` と `javac` のファイルの場所を表示します。

```text
where.exe java
where.exe javac
```

複数の場所が表示された場合は、PATHで先に見つかるJDKが使われます。JDK 25を入れても、以前のJDKの場所がPATHの前の方に残っている場合があります。JDK 25の `bin` フォルダを前へ移すと、JDK 25の道具を先に見つけられます。`bin` は、JDKの中で `java.exe` や `javac.exe` を置くフォルダです。

1. Windowsのスタートメニューで `システム環境変数の編集` を検索し、同名の項目を開いてください。システムのプロパティ画面が開きます。
2. システムのプロパティ画面の **環境変数** をクリックしてください。上側に自分のアカウントの **ユーザー環境変数**、下側にパソコン全体の **システム環境変数** が表示されます。
3. 環境変数画面のユーザー環境変数の `Path` を選んで **編集** を押してください。登録された場所の一覧が開きます。MicrosoftのJDK 25の `bin` を指す行を確認してください。JDK 25の場所がユーザー側にない場合は **キャンセル** で戻り、システム環境変数の `Path` を選んで **編集** を押し、JDK 25の場所を確認してください。
4. JDK 25の `bin` の行を選び、**上へ** を押して、以前のJDKを指す行より上へ移してください。JDK 25の行と以前のJDKの行が別の一覧にある場合は、システム環境変数のPATHがユーザー環境変数のPATHより先に使われます。JDK 25がユーザー側、以前のJDKがシステム側にある場合は、ユーザー側のJDK 25の行を選んで **編集** で場所をコピーし、**キャンセル** で戻ってください。システム側の `Path` の **編集 → 新規** へコピーした場所を追加し、**上へ** で以前のJDKより上に移してください。システム側の編集には管理者の権限が必要です。
5. 場所の一覧の **OK**、環境変数画面の **OK**、システムのプロパティ画面の **OK** を順に押してください。PATHの変更が保存されます。JDK以外の行は保存前のまま維持してください。
6. VS Code全体を閉じ、WindowsのスタートメニューからVS Codeを開いてください。保存したPATHを新しく開いたVS Codeが使います。
7. VS Codeの **表示 → ターミナル** を開いてください。`java --version` と `javac --version` を1行ずつ入力し、その都度Enterキーを押してください。両方でJDK 25のバージョンが表示されるか確認してください。

JDK 25の場所がどちらのPATHにも見つからない場合は、JDKのインストーラーでPATHを登録する機能を確認してください。JDK 25の導入先が分からないまま、別のフォルダ名を推測して登録しないでください。[Microsoft公式：JDKとPATHの登録](https://learn.microsoft.com/en-us/java/openjdk/install#install-on-windows)

## 1-4. VS CodeへJava用の機能を追加する

Extension Pack for Javaは、VS CodeへJavaの編集・実行などの機能を足す拡張機能です。JDK本体は「1-2. JDK本体をインストールする」で別に入れます。

1. VS Codeの左側の **拡張機能** を開き、検索欄へ `Extension Pack for Java` を入力してください。Microsoftが公開する同名の項目を選び、**インストール** を押してください。VS CodeへJava用の機能が追加されます。[VS Code公式：Java用拡張機能](https://code.visualstudio.com/docs/java/java-tutorial#_installing-extensions)
## 1-5. 第2章用のフォルダとtest.javaを作る

第2章は `test.java` というファイルへコードを書きます。ファイルを入れる作業用フォルダを先に決めておくと、保存したコードの場所を実行時に探さずに済みます。

1. エクスプローラーで **ドキュメント** を開き、`Java学習` フォルダがあるか確認してください。`Java学習` がある場合は、既存のフォルダを使ってください。`Java学習` がない場合だけ、**新規作成 → フォルダー** で `Java学習` を作ってください。作業用フォルダがドキュメントに表示されます。
2. VS Codeの **ファイル → フォルダーを開く** から、ドキュメントの `Java学習` を選んでください。VS Codeの左側のファイル一覧に作業用フォルダが表示されます。
3. VS Codeの左側のファイル一覧に `test.java` がある場合は、`test.java` をクリックして開いてください。既存のコードは、この準備の段階では変更せず、手順4の新規保存も省略してください。`test.java` がない場合だけ、**ファイル → 新しいテキストファイル** を選んでください。コードを入力する空の編集画面が開きます。
4. 新規ファイルを作った場合だけ、編集画面から保存へ進むため、保存用のCtrl + Sを押してください。保存先に `Java学習` フォルダを選び、ファイル名に `test.java` を入力して **保存** を押してください。VS Codeの左側に `test.java` が表示されます。名前の末尾の `.java` はJavaのコードを保存するファイルの種類を示します。

ここまで終わったら、[2. 最初のプログラム](../02_最初のプログラム/最初のプログラム.md)を開いてください。第2章では、作成または確認した `test.java` を使って、保存・変換・実行を行います。
