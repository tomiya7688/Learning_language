# 変数（データの入れ物）

プログラムの中で、数値を保管したり、文字を覚えさせておいたりしたいときに使うのが**変数（へんすう）**です。
変数は、よく**「データをしまっておく箱」**に例えられます。

## 1. 変数とは？（箱のイメージ）

例えば、ゲームのスコアやプレイヤーの名前をプログラムで扱いたいとします。
データをそのまま書いておくこともできますが、「箱（変数）」に名前をつけて入れておくと、後から中身を取り出したり、別の値に変えたりできてとても便利です。

Javaで変数を使うときは、**「どんな種類のデータをいれる箱か（型）」** と **「箱の名前」** をあらかじめ決めるルールがあります。

## 2. よく使うデータの種類（型）

Javaでは、入れるデータの種類によって「型（かた）」を使い分ける必要があります。

| 型の名前 | 意味 | 扱えるデータの例 |
| :---: | :---: | :---: |
| `int` | 整数 | `10`,`5`,`-50` |
| `double` | 小数 | `3.14`,`0.5` |
| `String` | 文字列 | `"こんにちは"`,`"Java"` |
| `boolean` | 真偽値（正しいか間違いか） | `true`,`false` |

boolean 型で使う true と false は、日常会話ではあまり馴染みがありませんが、プログラムの世界では「条件に合っているか（Yes/No）」を判定するときに使います。

## 3. 変数の使い方（宣言と代入）

変数を使うには、大きく分けて **「宣言（箱を作る）」**  と **「代入（中身を入れる）」** の2つのステップがあります。

### 基本的な書き方

```java
// ① 変数の宣言（int型で score という名前の箱を作る）
int score;

// ② 代入（すでに作った score の箱に 100 という値を入れる）
score = 100;
```

※「箱を作る（宣言）」と「最初の中身を入れる（代入）」を同時に行うこともできます（初期化といいます）。

```java
int score = 100; // 箱を作ると同時に 100 を入れる
```

## 4. ＋による文字列の連結（数字との違いの注意！）

第4章で学んだ `+` 演算子は、数値を足すだけでなく、「文字列」と「変数の中身」をくっつける（連結する）ときにも大活躍します。

サンプルコード①（後で実行するときにコピーして使ってください）

```java
public class test {
    public static void main(String[] args) {
        // 文字列同士をくっつける
        String message = "こんにちは、" + "世界！";
        System.out.println(message);

        // 整数を入れる変数と、文字をくっつける
        int score = 85;
        System.out.println("スコアは " + score + " 点です");
    }
}
```

出力結果①

こんにちは、世界！
スコアは 85 点です

となりました。＋を使うことで、文章と変数の中身をきれいに繋げて出力できるようになりました。

## 5. 注意！数字の「足し算」と「文字の連結」の違い

ここで、初心者がよく引っかかる「数字のたし算」と「文字の連結」の決定的な違いを見ておきましょう。

以下のコードを(A,B,C)を見てみてください。

サンプルコード②

```java
public class test {
    public static void main(String[] args) {
        // A. 数値同士のたし算（int型同士）
        System.out.println(8 + 5);

        // B. 文字列同士の連結（ダブルクォーテーションで囲む）
        System.out.println("8" + "5");

        // C. 数値と文字列を混ぜてみた場合
        System.out.println(8 + "5");
    }
}
```

出力結果②

13
85
85

### なぜこうなるのか？（詳しい解説）

A. 8 + 5（数値のたし算）:
両方とも「数字（int型）」なので、Javaが正しく算数の「たし算」として計算し、結果は 13 になります。

B. "8" + "5"（文字の連結）:
ダブルクォーテーション（""）で囲まれているものは「文字（String型）」として扱われます。Javaは文字の + を見ると「横にそのままくっつけるんだな！」と判断するため、結果は 85 になります。

C. 8 + "5"（数値と文字の混同）:
Javaの世界では、「文字列」と「それ以外のデータ（数値など）」が + でくっつけられるとき、自動的に数値も文字に変換されるというルールがあります。そのため、8 が自動的に文字の "8" に変わり、"5" とくっついて 85 になってしまいます。

このように、「いま扱っているデータが『数字』なのか『文字』なのか」を意識することが、Javaプログラミングの大きな一歩になります。

## 6.実際に動かしてみよう

それでは、実際にコードを書いて動きを確認してみましょう。

手順

1. 05_変数 フォルダの中にある 変数.md と同じ場所に、新しく test.java を作成します。

2. エディタにサンプルコードを入力し、保存（ Ctrl + S ）します。

3. VS Codeの左側にあるファイル一覧の 05_変数 フォルダを右クリックし、「統合ターミナルで開く」 を選択します。

4. ターミナルに以下のコマンドを入力して Enter を押し、コンパイルします。

```bash
javac -encoding UTF-8 test.java
```

5. コンパイルに成功したら、以下のコマンドを入力して Enter を押し、実行します。

```bash
java -cp . test
```
