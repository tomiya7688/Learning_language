# 2. 最初のプログラム

この章では、Java で最初のプログラムを作成して実行します。題材としてまずはとにかく一行表示してみます。

> **とりまなんか表示しておけ！おはよう世界！**

```text
Hello World!
```

---

## 2-1. なぜ最初に文字を表示するの？

最初から難しいことをやる必要はありません。

まずは、

```java
public class HelloWorld{
    public static void main(String[] args){
        // コンソールに "Hello World!" と表示する
        System.out.println("Hello World!");
    }
}
```

を動かします。
