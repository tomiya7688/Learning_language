# 2. 最初のプログラム

この章の題材は、画面に「Hello World!」と表示するJavaのプログラムです。コードを書いて実行し、結果を確認してください。

> **とりまなんか表示しておけ！おはよう世界！**

```text
Hello World!
```

---

## 2-1. なぜ最初に文字を表示するの？

最初から難しいことをやる必要はありません。

まずは、

```java
public class HelloWorld{
    public static void main(String[] args){
        // コンソールに "Hello World!" と表示する
        System.out.println("Hello World!");
    }
}
```

このコードで、プログラムは背景の縦位置を更新します。
