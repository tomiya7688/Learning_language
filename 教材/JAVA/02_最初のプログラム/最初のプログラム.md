# 2. 最初のプログラム

この章では、Java で最初のプログラムを作成して実行します。題材としてまずはとにかく一行表示してみます。

まずは「Hello World!」と表示するプログラムで、ファイルを保存し、実行して、結果が出ることを確かめてください。

```text
Hello World!
```

> **とりまなんか表示しておけ！おはよう世界！**

最初に表示する文字は自由です。この章は、最初の動作確認でよく使われる「Hello World!」を表示する例から始めます。

## 2-1. なぜ最初に短いプログラムを動かすの？

短いプログラムから始めると、保存・実行・表示を確かめやすくなります。何故最初が短いかと言うと、動くかもわからんのにいっぱい書いても仕方ない、ということです。

この例は、`test` という名前を指定してプログラムを動かします。Javaが最初に行う文字表示を、実行の始点になる `main` にまとめ、`main` を `test` という名前のクラスに置きます。クラスは、プログラムのまとまりに名前を付ける書き方です。`java -cp . test` の `test` も、実行するまとまりの名前を指定します。

元ファイル：[test.java 全体（1〜8行）](./test.java#L1-L8)。

```java
// class testの中の処理をtestという名前でまとめます。ファイル名はtest.javaにしてください。
public class test {
    // mainは、このプログラムを実行したときに最初に動く処理です。
    public static void main(String[] args) {
        // System.out.printlnが、括弧の中で指定した文字列を実行用ターミナルへ1行表示します。
        System.out.println("Hello World!");
    }
}
```

## 2-2. コードの解説

`class test { ... }` の中の処理を、`test` という名前でまとめます。ファイル名は `test.java` にしてください。

Javaは `main` から実行を始めます。文字を表示する処理は、`main` の `{` と `}` の間へ書いてください。この例の `public static void main(String[] args)` は、実行を始める処理を定義するための書き方です。[test.java 1〜8行](./test.java#L1-L8)

ここで見てほしいのは `System.out.println("Hello World!");` のコードです。

`System.out.println` の()のなかにある二つの""(ダブルクォーテーション)の間に表示させたい文字を入れると見事、その文字がターミナルに表示されます。文字列は、プログラムが文字として扱う内容です。Javaのコードでは、文字列を半角の `"` で囲んで書いてください。[test.java 5〜6行](./test.java#L5-L6)

`System.out.println` の括弧内を `"apple"` に変更して保存・実行すると、ターミナルに `apple` と表示されます。括弧内を `"あいうえお"` に変更して保存・実行すると、ターミナルに `あいうえお` と表示されます。保存と実行は、次の「2-3. 保存して実行する」の手順で行ってください。[test.java 6行](./test.java#L6)

## 2-3. 保存して実行する

第1章でJavaを書く・動かす道具を準備してから、次の手順を行ってください。この章の操作手順はWindows向けです。Mac/Linux向けの操作手順は追加中です。

1. Windowsのエクスプローラーで、作業用の `Java学習` フォルダを確認してください。第1章で作成済みの `Java学習` がある場合は、同じフォルダを使ってください。作業用フォルダがまだない場合だけ、エクスプローラーで `Java学習` という名前のフォルダを作ってください。
2. VS Codeの **ファイル → フォルダーを開く** で、使う `Java学習` フォルダを選んでください。VS Codeの左側に作業用フォルダが表示されます。
3. VS Codeの左側のファイル一覧に `test.java` がある場合は、`test.java` をクリックして開いてください。`test.java` がまだない場合は、**ファイル → 新しいテキストファイル** を選んでください。開いた編集画面へ、「2-1. なぜ最初に短いプログラムを動かすの？」に掲載した `test.java` のコード全体を入力してください。
4. 編集したコードを保存するため、保存用のCtrl + Sを押してください。第1章で保存済みの `test.java` を開いている場合は、同じファイルの内容が更新されます。名前のない新規ファイルへ入力した場合は、保存先に `Java学習` を選び、ファイル名に `test.java` を入力して **保存** を押してください。保存後、VS Codeの左側に `test.java` が表示されます。
5. VS Codeの **表示 → ターミナル** を開いてください。ターミナルの文字入力欄が画面下に表示されます。
6. エクスプローラーで `test.java` を入れた `Java学習` フォルダを開いてください。長い保存場所を手入力して間違えないよう、上部のアドレス欄をクリックし、コピー用のCtrl + Cでフォルダのパス（保存場所を表す文字列）をコピーしてください。
7. VS Codeのターミナルへ、次の引用符の中をコピーしたフォルダのパスに置き換えて入力し、入力したコマンドを実行するためEnterキーを押してください。コピーした保存場所をそのまま使うため、貼り付け用のCtrl + Vでパスを貼り付けてください。ターミナルで作業する場所が、`test.java` の保存先へ変わります。

```text
cd "コピーしたJava学習フォルダのパス"
```

8. VS Codeの **表示 → ターミナル** で、保存先へ移動したターミナルを表示してください。次を入力し、Enterキーを押してください。`javac` はJavaのコードを実行できる形式へ変換する道具です。変換が成功すると、保存先に `test.class` ができます。エラーが表示された場合は手順9へ進まず、エラーで示された `test.java` の箇所を直して保存し、手順8をもう一度行ってください。

```text
javac -encoding UTF-8 test.java
```

`-encoding UTF-8` は、コード内の日本語をUTF-8という文字の保存形式で読む指定です。VS Codeで `test.java` を保存するときも、画面下の文字コードの表示が **UTF-8** であることを確認してください。

9. 手順8の変換でエラーが表示されなかった場合だけ、VS Codeの **表示 → ターミナル** で保存先へ移動したターミナルを表示してください。次を入力し、Enterキーを押してください。`java -cp . test` は、現在のフォルダにある `test` のプログラムを動かす指定です。`test` の後ろへ `.java` は付けません。プログラムが動くと、ターミナルに `Hello World!` と表示されます。

```text
java -cp . test
```

プログラムが動くと、ターミナルに次の1行が表示されます。

```text
Hello World!
```

コードの文字を変更した場合は、Ctrl + Sで `test.java` を保存し、手順8の変換をもう一度行ってください。変換でエラーが表示されなかった場合だけ、手順9の実行へ進んでください。変換をやり直さなかった場合や変換が失敗した場合は、以前の `test.class` が残り、変更前のプログラムが動く場合があります。

次の画像は、VS CodeのJava拡張機能の実行ボタンを使った、本文とは別の実行方法の例です。画像の保存先は `Documents`、本文の保存先は `Java学習` なので、保存場所とターミナルのコマンドは一致しません。この章では手順8・9のコマンド入力で実行してください。画像に見える `x:` はエディターの補助表示で、入力するコードには含めません。

## よくあるミス

### 1. ;(セミコロン)を入れ忘れる

❌ 行末の `;` がありません。

```java
System.out.println("Hello World!")
```

⭕ 行末に半角の `;` を書いてください。

```java
System.out.println("Hello World!");
```

### 2. 全角で書いている

❌ 括弧と引用符が全角です。

```java
System.out.println（”Hello World!”）;
```

⭕ 括弧と引用符を半角で書いてください。

```java
System.out.println("Hello World!");
```

### 3. 小文字で打っている

❌ `system` の先頭が小文字です。

```java
system.out.println("Hello World!");
```

⭕ `System` の先頭を大文字の `S` で書いてください。

```java
System.out.println("Hello World!");
```

ほかにも「l(エル)」を「i(アイ)」と誤字をしていたりがあるので困ったらコピペして頂ければと思います。

コピーするのは「2-1. なぜ最初に短いプログラムを動かすの？」の `test.java` のコード全体です。VS Codeで作業用フォルダの `test.java` を開き、ファイルの内容全体を選んで貼り付けてください。保存と実行は「2-3. 保存して実行する」の手順4・8・9で行ってください。
