# 2. 最初のプログラム

Javaを用意しても、まだ自分のコードが動くかは確かめていません。いきなり長いプログラムを書いて動かなかったら、どこを直すかを探すのが大変です。

まずは「Hello World!」と表示するプログラムで、ファイルを保存し、実行して、結果が出ることを確かめてください。

> **とりまなんか表示しておけ！おはよう世界！**

```text
Hello World!
```

---

## 2-1. なぜ最初に文字を表示するの？

最初から難しいことをやる必要はありません。

まずは、

```java
public class HelloWorld{
    public static void main(String[] args){
        // コンソールに "Hello World!" と表示する
        System.out.println("Hello World!");
    }
}
```

このコードで、プログラムは背景の縦位置を更新します。
