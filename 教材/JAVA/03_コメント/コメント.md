# 3. コメントを書こう

プログラミングでは、コードの中に「人間に向けたメモ書き」を残すことができます。
このメモ書きのことを **コメント** と呼びます。

コメントはプログラムの実行時には完全に無視されるため、どれだけ書いても処理のスピードや動作に影響を与えません。

## 1. なぜコメントを書くの？

コードを書いた直後は「何を処理しているか」が自分で分かっていても、数日後見返したときに忘れてしまっていることがよくあります。
また、他の人と一緒に開発するときにも、コメントがあると親切です。

* **未来の自分のため:** 後から見返したときにコードの意味を思い出しやすくする
* **チームのため:** 自分の書いたコードの役割を他の人に分かりやすく伝える

## 2. コメントの書き方（2種類）

Javaには、主に2つのコメントの書き方があります。

### ① 1行コメント（ `//` ）
スラッシュを2つ（ `//` ）書くと、**その行の `//` 以降がすべてコメント**になります。
ちょっとした補足や短いメモを書くときによく使われます。

```java
public class Main {
    public static void main(String[] args) {        
        // ここは1行コメントです（実行されません）
        System.out.println("Hello, World!"); // 行の末尾にメモを書くこともできます
    }
} 
```

### ② 複数行のコメント (/* ~ */)

`/*` と `*/` で囲まれた範囲は、何行にわたってもすべてコメントになります。
長めの解説やプログラムの全体の概要を書くときに便利です。

```java
public class Main {
    public static void main(String[] args) {
        /* 
         ここからここまで、
         改行してもすべてコメントになります。
         プログラムの説明などを長く書きたいときに使います。
        */
        System.out.println("複数行コメントの練習です！");
    }
}
```

## 3. コメントアウト（超重要テクニック！）
プログラムを書いていると、「この命令を消さずに、一時的に動かなくして試してみたい」という場面が出てきます。
コードの先頭に `//` を付けて、プログラムを一時的に無効化するテクニックを `「コメントアウト」` と呼びます。

### 試してみよう

test.java ファイルを開き、以下のコードに書き換えて保存（ Ctrl + S または Cmd + S ）し、実行してみてください。

```java
public class Main {
    public static void main(String[] args) {
        
        // 1. 1行コメント：行の末尾までがコメントになります
        System.out.println("Hello, World!"); // ここにメモを書くこともできます

        /* 
         2. 複数行コメント：
         このように改行しても
         囲まれた部分はすべてコメントになります。
        */
        System.out.println("コメントの練習中！");

        // 3. コメントアウトの例：
        // 以下の処理は実行したくないので、先頭に // をつけて一時的に無効化（コメントアウト）しています
        // System.out.println("この文章は表示されません。");
        
    }
}
```

実行すると下の図のように `Hello, World!` と `コメントの練習中` だけが出てきてコメントアウトした `この文章は表示されません` は表示されていません。
表示したいときは先頭の `//` を消すだけでOKです。

## 4.よくある失敗と注意点

### 全角のスラッシュに注意

コメントに使うスラッシュ `//` は、必ず半角で入力してください。全角の `／／` にしてしまうと文法エラーになります。

NGコード：(全角スラッシュ)

```java
／／　ここにメモを書きます
System.out.println("Hello");
```

OKコード：(半角スラッシュ)

```java
//ここにメモを書きます
System.out.println("Hello");
```
