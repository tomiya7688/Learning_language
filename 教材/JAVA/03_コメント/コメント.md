# 3. コメントを書こう

プログラミングでは、コードの中に「人間に向けたメモ書き」を残すことができます。
このメモ書きのことを **コメント** と呼びます。

コメントはプログラムの実行時には完全に無視されるため、どれだけ書いても処理のスピードや動作に影響を与えません。

## 1. なぜコメントを書くの？

コードを書いた直後は「何を処理しているか」が自分で分かっていても、数日後見返したときに忘れてしまっていることがよくあります。
また、他の人と一緒に開発するときにも、コメントがあると親切です。

* **未来の自分のため:** 後から見返したときにコードの意味を思い出しやすくする
* **チームのため:** 自分の書いたコードの役割を他の人に分かりやすく伝える

## 2. コメントの書き方（2種類）

Javaには、主に2つのコメントの書き方があります。

### ① 1行コメント（ `//` ）
スラッシュを2つ（ `//` ）書くと、**その行の `//` 以降がすべてコメント**になります。
ちょっとした補足や短いメモを書くときによく使われます。

```java
public class test {
    public static void main(String[] args) {
        // ここは1行コメントです（実行されません）
        System.out.println("Hello, World!"); // 行の末尾にメモを書くこともできます
    }
}
```

### ② 複数行のコメント (/* ~ */)

`/*` と `*/` で囲まれた範囲は、何行にわたってもすべてコメントになります。
長めの解説やプログラムの全体の概要を書くときに便利です。

```java
public class test {
    public static void main(String[] args) {
        /*
         ここからここまで、
         改行してもすべてコメントになります。
         プログラムの説明などを長く書きたいときに使います。
        */
        System.out.println("複数行コメントの練習です！");
    }
}
```

## 3. コメントアウト（超重要テクニック！）と実行手順

プログラムを書いていると、「この命令を消さずに、一時的に動かなくして試してみたい」という場面が出てきます。
コードの先頭に `//` を付けて、**その行だけ一時的に実行されないように無効化するテクニック** を `「コメントアウト」` と呼びます。

### 試してみよう(windowsの手順)

1. 第2章の `test.java` を残すため、エクスプローラーで `Java学習` フォルダを開き、その中へ今回の練習用の `03_コメント` フォルダを新しく作ってください。

2. VS Codeの **ファイル → 新しいテキストファイル** を選び、下のコードを打ってみよう。

```java
public class test {
    public static void main(String[] args) {

        // 1. 1行コメント：行の末尾までがコメントになります
        System.out.println("Hello, World!"); // ここにメモを書くこともできます

        /*
         2. 複数行コメント：
         このように改行しても
         囲まれた部分はすべてコメントになります。
        */
        System.out.println("コメントの練習中！");

        // 3. コメントアウトの例：
        // 以下の処理は実行したくないので、先頭に // をつけて一時的に無効化（コメントアウト）しています
        // System.out.println("この文章は表示されません。");

    }
}
```

3. Ctrl + Sを押し、手順1で作った `Java学習` の中の `03_コメント` フォルダへ、`test.java` という名前で保存してください。ファイル名はコードの `public class test` に合わせています。画面下の文字コードの表示が **UTF-8** であることも確認してください。

4. エクスプローラーで今回の `test.java` を入れた `03_コメント` フォルダを開き、上部のアドレス欄をクリックして、Ctrl + Cでフォルダのパス（保存場所を表す文字列）をコピーしてください。

5. VS Codeの **表示 → ターミナル** を選んでください。開いたターミナルへ `cd ""` と入力し、引用符の間に手順4でコピーしたパスをCtrl + Vで貼り付けて、Enterキーを押してください。ターミナルで作業する場所が、今回の `test.java` を保存したフォルダへ変わります。

6. 同じターミナルへ、以下のコマンドを入力し、Enterキーを押してコンパイル（実行できる形式への変換）をしてください。

```text
javac -encoding UTF-8 test.java
```

`-encoding UTF-8` は、ファイルの日本語をUTF-8という文字の保存形式で読む指定です。変換に成功すると、同じフォルダに `test.class` ができます。エラーが出た場合は、示されたコードの箇所を直してCtrl + Sで保存し、手順6をもう一度行ってください。

7. 手順6でエラーが出なかった場合だけ、同じターミナルへ以下のコマンドを入力し、Enterキーを押して実行してください。`java -cp . test` は、現在のフォルダにある `test` のプログラムを動かす指定です。

```text
java -cp . test
```

実行すると下の図のように `Hello, World!` と `コメントの練習中！` だけが出てきて、コメントアウトした `この文章は表示されません。` は表示されていません。

```text
Hello, World!
コメントの練習中！
```

### コメントアウトを外してみよう

1. VS Codeで今回保存した `03_コメント` フォルダの `test.java` を開き、`// System.out.println("この文章は表示されません。");` の先頭の `//` を消してみよう。Ctrl + Fで `この文章は表示されません。` を検索しても見つけられます。
2. Ctrl + Sを押して保存してください。
3. VS Codeの **表示 → ターミナル** で、手順5で保存先へ移動した同じターミナルを表示してください。閉じてしまった場合は、上の手順4〜5でターミナルを開き直して保存先へ移動してください。
4. `javac -encoding UTF-8 test.java` と入力してEnterキーを押してください。変換でエラーが出た場合はコードを直して保存し、もう一度変換してください。
5. 変換でエラーが出なかった場合だけ、`java -cp . test` と入力し、Enterキーを押してください。今度は3行目に `この文章は表示されません。` も表示されます。

```text
Hello, World!
コメントの練習中！
この文章は表示されません。
```

## 4.よくある失敗と注意点

### 全角のスラッシュに注意

コメントに使うスラッシュ `//` は、必ず半角で入力してください。全角の `／／` にしてしまうと文法エラーになります。

NGコード：(全角スラッシュ)

```java
／／　ここにメモを書きます
System.out.println("Hello");
```

OKコード：(半角スラッシュ)

```java
//ここにメモを書きます
System.out.println("Hello");
```
