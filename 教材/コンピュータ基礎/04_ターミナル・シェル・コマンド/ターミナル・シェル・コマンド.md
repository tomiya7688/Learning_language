# 4. ターミナル・シェル・コマンド

プログラミングを始めると、

```text
python app.py
cd フォルダ名
pip install ...
```

のような文字を入力する場面がよくあります。

これらをどこへ入力するのか分からないと、
説明書を読んでも「何をすればよいのか」が分かりにくくなります。

この章では、**ターミナル・シェル・コマンドの違い**と、
最低限の使い方を説明します。

---

## 4-1. ターミナルとは

**ターミナル**は、文字を使ってコンピュータを操作するための画面やアプリケーションです。

代表例:

- Windows Terminal
- VS Code の統合ターミナル
- macOS の「ターミナル」
- Linux の各種ターミナルアプリ

ターミナルを開くと、文字を入力できる画面が表示されます。

---

## 4-2. シェルとは

ターミナルの中で入力されたコマンドを解釈するプログラムを **シェル** と呼びます。

代表例:

- PowerShell
- コマンドプロンプト（cmd）
- bash
- zsh

大まかには、

> ターミナル = 文字を入力する画面  
> シェル = 入力されたコマンドを解釈する仕組み

と考えると分かりやすいです。

---

## 4-3. コマンドとは

**コマンド**は、コンピュータへ操作を指示するために入力する命令です。

例:

```text
python app.py
cd Documents
dir
ls
```

入力したあと Enter キーを押すと実行されます。

---

## 4-4. Pythonコードを入力する場所とは別

初学者が特に混同しやすいところです。

```python
print("Hello")
```

は **Pythonのコード** です。

一方、

```text
python hello.py
```

は **ターミナルへ入力するコマンド** です。

通常は、

```text
Pythonコード → .py ファイルへ書く
コマンド     → ターミナルへ入力する
```

と分けます。

---

## 4-5. VS Code のターミナル

VS Code を使っている場合は、
別のアプリを開かなくてもターミナルを使えます。

メニューから、

```text
ターミナル → 新しいターミナル
```

を選びます。

この教材では、特に理由がなければ
**VS Code の統合ターミナルを使って構いません。**

---

## 4-6. Windowsでは何を使えばいい？

Windowsでは主に、

- PowerShell
- コマンドプロンプト
- Windows Terminal

を見かけます。

Windows Terminal は、PowerShellなどを開くためのターミナルアプリです。

この教材では、Windowsの例は主に **PowerShell** で説明します。

---

## 4-7. macOS / Linuxでは？

macOSでは `zsh`、
Linuxでは `bash` などがよく使われます。

Pythonを実行するときも、

Windows:

```powershell
python app.py
```

macOS / Linux:

```bash
python3 app.py
```

のように、環境によって少し違うことがあります。

---

## 4-8. 行の先頭にある文字は入力するの？

説明書では、次のように書かれている場合があります。

```text
$ python3 app.py
```

または、

```text
PS C:\Users\sample> python app.py
```

このとき、

```text
$
PS C:\Users\sample>
```

は入力する文字ではなく、ターミナル側が表示している目印であることが多いです。

実際に入力するのは `python3 app.py` や `python app.py` の部分です。

---

## 4-9. 今どのフォルダにいるかが重要

ターミナルには「現在いるフォルダ」があります。

これを **カレントディレクトリ** と呼びます。

`app.py` が別のフォルダにある状態で、

```text
python app.py
```

と実行すると、ファイルが見つからないことがあります。

そのため、

- 今どこにいるか
- 実行したいファイルがどこにあるか

を意識する必要があります。

---

## 4-10. コマンドをコピーするときの注意

WebサイトやAIの回答からコマンドをコピーすることもあります。

ただし、意味の分からないコマンドをそのまま実行すると、

- ファイルを削除する
- 設定を書き換える
- ソフトをインストールする

などの操作が行われることがあります。

特に `sudo` や管理者権限が必要なコマンドは、
PC全体へ影響する場合があります。

最初のうちは、**このコマンドは何をするのか**を確認してから実行する習慣をつけましょう。

---

## 4-11. 最初に覚えるコマンド

すべてを覚える必要はありません。

| やりたいこと | Windows | macOS / Linux |
| --- | --- | --- |
| 現在地を確認 | `pwd` | `pwd` |
| 中身を見る | `dir` | `ls` |
| フォルダ移動 | `cd` | `cd` |
| Python実行 | `python ファイル名.py` | `python3 ファイル名.py` |

分からなくなったら、その都度確認すれば問題ありません。
