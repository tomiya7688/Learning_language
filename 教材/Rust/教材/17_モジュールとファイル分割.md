# 17. モジュールとファイル分割

計算処理が増えると、画面に表示する処理と計算する処理が一つのファイルに混ざって読みにくくなります。コードを分けましょう。

**この章でできること：** 別のRustファイルに定義した足し算を呼び出す。

## コードを見る

[配布した `lesson17_modules/main.rs` の全体](../examples/lesson17_modules/main.rs#L1-L6)を、VS Codeで開いてください。次のコードは配布ファイルと同じ内容です。

```rust
mod math;

fn main() {
    // math.rsの足し算を使って表示する
    println!("合計: {}", math::add(3, 4));
}
```


**もう一つの配布ファイル：** [`math.rs`](../examples/lesson17_modules/math.rs)

```rust
// 他のファイルから呼び出せる加算関数
pub fn add(left: i32, right: i32) -> i32 {
    left + right
}
```

`main.rs` が起動の入口、`math.rs` が計算処理を担当します。2つのファイルを `examples/lesson17_modules/` に保存してください。

## 実行する

[初めに](../初めに.md)の手順でVS Codeから `教材/Rust` フォルダを開き、**表示 → ターミナル** で次のコマンドを入力して Enter キーを押してください。

```text
cargo run --example lesson17_modules
```

ターミナルへ表示される内容：

```text
合計: 7
```


## コードの読み方

`mod math;` は、同じフォルダの `math.rs` にあるコードをこのプログラムから使えるようにします。`math` は数学、`add` は足すという意味です。`pub` は、別のモジュールからも使えるように公開する指定です。`math::add(3, 4)` でその関数を呼び出します。`src` や `examples` はコードを入れるフォルダです。

## 変更して試す

VS Codeで `lesson17_modules/main.rs` を開き、次の部分を変更してみましょう。

`math.rs` の `left + right` を `left * right` に変え、`main.rs` も `math::add(3, 4)` を呼ぶまま実行してください。表示は `12` になります。ただし関数名 `add` と動作が一致しなくなるため、確認後は戻してください。

試した後に元のコードへ戻すと、ほかのページの説明と同じ動作で学習を続けられます。
