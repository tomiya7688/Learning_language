# 08. 関数で計算をまとめる

足し算を何度も書く場合、計算方法に名前を付けると呼び出す場所が読みやすくなります。

**この章でできること：** 2つの整数を受け取って合計を返す関数を使う。

## コードを見る

[配布した `lesson08_functions.rs` の全体](../examples/lesson08_functions.rs#L1-L10)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
// 2つの整数を受け取り、合計を返す
fn add(left: i32, right: i32) -> i32 {
    left + right
}

fn main() {
    // add関数の戻り値を表示する
    let answer = add(3, 4);
    println!("答え: {}", answer);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson08_functions
```



ターミナルで確認する表示：

```text
答え: 7
```

## コードの読み方

`fn add(left: i32, right: i32) -> i32` の `add` は加算する関数名、`left` と `right` は受け取る値（引数）、`-> i32` は返す値（戻り値）の型です。最後の `left + right` に `;` が付いていないため、計算結果を呼び出し元へ返します。

## 変更して試す

VS Codeで `examples/lesson08_functions.rs` に対応する `lesson08_functions.rs` を開き、次の部分を変更してみましょう。

`add(3, 4)` の2番目の数字を `10` に変えて再実行してください。答えが `13` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
