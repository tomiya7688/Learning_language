# 09. 配列とタプル

テストの点数が3つあったら、1つずつ違う変数名にするより、まとめた方が扱いやすくなります。

**この章でできること：** 同じ種類の値を配列へ、異なる種類の値をタプルへまとめる。

## コードを見る

[配布した `lesson09_arrays_tuples.rs` の全体](../examples/lesson09_arrays_tuples.rs#L1-L11)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 同じ型の点数を3個まとめる
    let scores = [80, 90, 70];
    println!("最初の点数: {}", scores[0]);
    println!("2番目の点数: {}", scores[1]);

    // 名前と点数を一組にする
    let student = ("あおい", 80);
    let (name, score) = student;
    println!("{}: {}点", name, score);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson09_arrays_tuples
```



ターミナルで確認する表示：

```text
最初の点数: 80
2番目の点数: 90
あおい: 80点
```

## コードの読み方

`[80, 90, 70]` は配列です。配列は同じ型の値を決まった個数まとめ、`scores[0]` で最初の値を取り出します。番号は0から始まります。`("あおい", 80)` はタプルで、名前と点数のような異なる型の値をまとめられます。`let (name, score)` で二つを分けて取り出します。

## 変更して試す

VS Codeで `examples/lesson09_arrays_tuples.rs` に対応する `lesson09_arrays_tuples.rs` を開き、次の部分を変更してみましょう。

`scores[1]` を `scores[2]` に変えて保存・再実行してください。2番目の点数の表示が `70` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
