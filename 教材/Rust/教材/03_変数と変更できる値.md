# 03. 変数と変更できる値

点数が変わるたびに、計算式の数字を全部書き直すのは大変です。値に名前を付けて使ってみましょう。

**この章でできること：** 変数に点数を入れ、加点して合計を表示する。

## コードを見る

[配布した `lesson03_variables.rs` の全体](../examples/lesson03_variables.rs#L1-L9)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // score は固定の点数
    let score = 80;
    // bonus は後から増やせる追加点
    let mut bonus = 5;
    bonus += 10;

    println!("合計: {}", score + bonus);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson03_variables
```



ターミナルで確認する表示：

```text
合計: 95
```

## コードの読み方

`let` は値に名前を付けます。`score` は英語で点数、`bonus` は追加点です。Rustの通常の変数は途中で値を書き換えられません。`let mut bonus` の `mut` は mutable（変更可能）の略で、`bonus += 10` を許可します。`{}` は表示するときに値を差し込む場所です。

## 変更して試す

VS Codeで `examples/lesson03_variables.rs` に対応する `lesson03_variables.rs` を開き、次の部分を変更してみましょう。

`let mut bonus = 5;` を `let mut bonus = 20;` に変え、保存して再実行してください。合計が `110` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
