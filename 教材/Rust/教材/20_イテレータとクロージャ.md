# 20. イテレータとクロージャ

点数の一覧から合格点だけを取り出し、全員に5点加算する場合、繰り返しを手書きする以外の方法もあります。

**この章でできること：** 一覧を順に調べ、条件に合う値を変換して新しい一覧にする。

## コードを見る

[配布した `lesson20_iterators.rs` の全体](../examples/lesson20_iterators.rs#L1-L13)を、VS Codeで開いてください。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 元の点数の一覧
    let scores = vec![50, 70, 80, 95];

    // 合格点だけを取り出し、それぞれ5点加算する
    let passed: Vec<i32> = scores
        .into_iter()
        .filter(|point| *point >= 60)
        .map(|point| point + 5)
        .collect();

    println!("{:?}", passed);
}
```


## 実行する

[初めに](../初めに.md)の手順でVS Codeから `教材/Rust` フォルダを開き、**表示 → ターミナル** で次のコマンドを入力して Enter キーを押してください。

```text
cargo run --example lesson20_iterators
```

ターミナルへ表示される内容：

```text
[75, 85, 100]
```


## コードの読み方

イテレータ（iterator）は値を順番に取り出す仕組みです。`into_iter()` は一覧の値を取り出し、`filter` は条件に合う値だけ残し、`map` は残った値を変換し、`collect` は新しい一覧へ集めます。`|point| ...` はクロージャと呼ばれる名前のない短い関数です。`filter` の中は参照を受け取るため `*point` で数を取り出しています。

## 変更して試す

VS Codeで `lesson20_iterators.rs` を開き、次の部分を変更してみましょう。

`*point >= 60` の `60` を `80` に変えて再実行してください。70点の値は結果から除外され、`[85, 100]` になります。

試した後に元のコードへ戻すと、ほかのページの説明と同じ動作で学習を続けられます。
