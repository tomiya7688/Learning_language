# 21. ファイルの読み書き

プログラムを終了したあとでもメモを残したいなら、文字をファイルへ保存する必要があります。

**この章でできること：** 文字列をファイルへ保存し、読み戻して表示する。

## コードを見る

[配布した `lesson21_files.rs` の全体](../examples/lesson21_files.rs#L1-L13)を、VS Codeで開いてください。次のコードは配布ファイルと同じ内容です。

```rust
use std::fs;
use std::io;

fn main() -> io::Result<()> {
    // 学習用の名前でファイルへ文字を保存する
    let file_name = "rust_lesson21_memo.txt";
    fs::write(file_name, "Rustを勉強中\n")?;

    // 保存した文字をファイルから読み戻す
    let memo = fs::read_to_string(file_name)?;
    print!("{}", memo);
    Ok(())
}
```


## 実行する

[初めに](../初めに.md)の手順でVS Codeから `教材/Rust` フォルダを開き、**表示 → ターミナル** で次のコマンドを入力して Enter キーを押してください。

```text
cargo run --example lesson21_files
```

ターミナルへ表示される内容：

```text
Rustを勉強中
```


**注意：** `cargo run` を実行した `教材/Rust` フォルダに `rust_lesson21_memo.txt` が保存されます。同名のファイルが既にある場合、内容を上書きします。教材専用の名前以外へ変更する場合は、上書きしてよいファイルか確認してください。

## コードの読み方

`fs::write` は指定した名前のファイルに文字を書き込み、既存の内容があれば上書きします。`fs::read_to_string` はファイルを読み、文字列として返します。`?` はファイル操作に失敗した場合に、そのエラーを呼び出し元へ返す記号です。`io::Result<()>` は成功か入出力の失敗かを返す関数の型です。

## 変更して試す

VS Codeで `lesson21_files.rs` を開き、次の部分を変更してみましょう。

`"Rustを勉強中\n"` を `"Rustのメモ\n"` に変えて再実行してください。表示とファイルの中身の両方が変わります。

試した後に元のコードへ戻すと、ほかのページの説明と同じ動作で学習を続けられます。
