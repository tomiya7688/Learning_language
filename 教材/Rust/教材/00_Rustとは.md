# 00. Rustとは？

Rust（ラスト）は、ゲームの仕組み、道具、Webサービスなどを作るためのプログラミング言語です。プログラミング言語とは、コンピューターへ手順を伝えるための書き方です。

Rustは、プログラムが使うメモリ（実行中のデータを置く場所）を安全に扱えるよう、コードを実行する前に多くの間違いを調べます。間違った使い方があると、コンパイラ（人が書いたコードを実行可能な形に変換する道具）がエラーを出すことがあります。

この教材では最初から難しい仕組みを暗記しません。文字の表示、入力、計算を先に試し、後半でRustならではの**所有権（値を管理する責任）**と**借用（所有権を移さずに使うこと）**を扱います。

## 学習の進め方

1. [01. Rustの準備](./01_Rustの準備.md)で動かす道具を用意しましょう。
2. [02. 最初のプログラム](./02_最初のプログラム.md)で文字を表示しましょう。
3. 各章のコードを実行してから、1か所変更して結果の違いを確かめましょう。

各章のコードは、互いに別々に動く実行例です。途中の章だけ開いても、その章のコードを試せます。
