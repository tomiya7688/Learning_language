# 13. 参照と借用

関数に文字列を見せたいだけなのに、毎回所有権を渡したり複製したりするのは無駄です。

**この章でできること：** 文字列を読み取りだけ借り、別の関数で変更可能な形で借りる。

## コードを見る

[配布した `lesson13_borrowing.rs` の全体](../examples/lesson13_borrowing.rs#L1-L19)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
// 文字列を変更せずに読む
fn length_of(text: &str) -> usize {
    text.len()
}

// 呼び出し元のStringへ印を付ける
fn append_mark(text: &mut String) {
    text.push('!');
}

fn main() {
    // 同じ文字列を読み取り、後で変更する
    let mut message = String::from("Rust");
    let size = length_of(&message);
    println!("変更前のバイト数: {}", size);

    append_mark(&mut message);
    println!("変更後: {}", message);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson13_borrowing
```



ターミナルで確認する表示：

```text
変更前のバイト数: 4
変更後: Rust!
```

## コードの読み方

参照（reference）は値そのものを移さず、その値を使うための手がかりです。`&str` は文字列を読み取るための参照です。`&mut String` は変更できる借用（borrowing）で、ここでは `append_mark` が元の `message` に `!` を付けます。同時に競合する変更を防ぐため、Rustは借用の使い方を検査します。

## 変更して試す

VS Codeで `examples/lesson13_borrowing.rs` に対応する `lesson13_borrowing.rs` を開き、次の部分を変更してみましょう。

`text.push('!')` の `!` を `?` に変えて保存・再実行してください。最後の表示は `Rust?` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
