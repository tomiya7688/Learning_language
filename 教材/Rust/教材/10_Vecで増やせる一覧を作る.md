# 10. Vecで増やせる一覧を作る

点数が後から増える場合、個数が決まった配列より、要素を増やせる一覧が便利です。

**この章でできること：** Vecへ点数を追加し、合計を計算する。

## コードを見る

[配布した `lesson10_vec.rs` の全体](../examples/lesson10_vec.rs#L1-L14)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 後から点数を増やせる一覧を作る
    let mut scores = vec![70, 80];
    scores.push(90);

    // 一覧から1個ずつ点数を取り出す
    for score in &scores {
        println!("点数: {}", score);
    }

    // 点数をすべて合計する
    let total: i32 = scores.iter().sum();
    println!("合計: {}", total);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson10_vec
```



ターミナルで確認する表示：

```text
点数: 70
点数: 80
点数: 90
合計: 240
```

## コードの読み方

`Vec`（ベクター）は要素を追加できる一覧です。`vec![...]` で作り、`push` で末尾へ追加します。`for score in &scores` は一覧の要素を一つずつ読みます。`iter().sum()` は各要素を順番に取り出して合計します。`i32` は整数の型で、合計を代入する際に明示しています。

## 変更して試す

VS Codeで `examples/lesson10_vec.rs` に対応する `lesson10_vec.rs` を開き、次の部分を変更してみましょう。

`scores.push(90)` を `scores.push(100)` に変えて再実行してください。合計は `250` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
