# 22. テストで動作を確かめる

送料無料の条件を変えたあとに、ちょうど境目の金額が正しく判定されるか毎回手で確認するのは大変です。

**この章でできること：** 自動テストで3000円と2999円の境目を確認する。

## コードを見る

[配布した `lesson22_tests.rs` の全体](../examples/lesson22_tests.rs#L1-L24)を、VS Codeで開いてください。次のコードは配布ファイルと同じ内容です。

```rust
// 注文金額が3000円以上なら送料無料
fn is_free_shipping(total: u32) -> bool {
    total >= 3000
}

fn main() {
    println!("送料無料: {}", is_free_shipping(3000));
}

// cargo testのときだけ実行する確認処理
#[cfg(test)]
mod tests {
    use super::is_free_shipping;

    #[test]
    fn free_at_3000_yen() {
        assert!(is_free_shipping(3000));
    }

    #[test]
    fn not_free_at_2999_yen() {
        assert!(!is_free_shipping(2999));
    }
}
```


## 実行する

[初めに](../初めに.md)の手順でVS Codeから `教材/Rust` フォルダを開き、**表示 → ターミナル** で次のコマンドを入力して Enter キーを押してください。

```text
cargo run --example lesson22_tests
```

ターミナルへ表示される内容：

```text
送料無料: true
```


## テストを実行する

VS Codeで `教材/Rust` を開き、ターミナルへ次のコマンドを入力して Enter を押してください。

```text
cargo test --example lesson22_tests
```

配布版なら2件のテストが成功（`ok`）します。通常の `cargo run` ではテスト関数は実行されません。

## コードの読み方

`#[cfg(test)]` はテスト実行時だけ使うコード、`#[test]` はテストする関数を表します。`assert!` は条件が真であること、`assert!(!...)` は条件が偽であることを確かめます。`cargo test --example lesson22_tests` を実行すると、期待と異なる結果の場合はテストが失敗します。

## 変更して試す

VS Codeで `lesson22_tests.rs` を開き、次の部分を変更してみましょう。

`total >= 3000` を `total > 3000` に変えて保存し、テストコマンドを再実行してください。3000円のテストが失敗します。確認後は `>=` に戻してテストを通しましょう。

試した後に元のコードへ戻すと、ほかのページの説明と同じ動作で学習を続けられます。
