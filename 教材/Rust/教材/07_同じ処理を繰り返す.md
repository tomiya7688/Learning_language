# 07. 同じ処理を繰り返す

3回表示したいだけなのに、同じ `println!` を3行コピーするのは手間です。繰り返しを使ってみましょう。

**この章でできること：** 回数が決まっている繰り返しと、条件で続ける繰り返しを使う。

## コードを見る

[配布した `lesson07_loops.rs` の全体](../examples/lesson07_loops.rs#L1-L13)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 1から3まで順番に表示する
    for number in 1..=3 {
        println!("for: {}", number);
    }

    // count が2になるまで繰り返す
    let mut count = 0;
    while count < 2 {
        println!("while: {}", count);
        count += 1;
    }
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson07_loops
```



ターミナルで確認する表示：

```text
for: 1
for: 2
for: 3
while: 0
while: 1
```

## コードの読み方

`for number in 1..=3` は1、2、3を順番に `number` に入れます。`..=` は終点を含む範囲です。`while count < 2` は `count` が2未満の間、処理を繰り返します。`count += 1` を忘れると繰り返しが終わらないため、更新する場所も確認してください。

## 変更して試す

VS Codeで `examples/lesson07_loops.rs` に対応する `lesson07_loops.rs` を開き、次の部分を変更してみましょう。

`1..=3` を `1..=5` に変えて再実行してください。`for` の表示が5回になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
