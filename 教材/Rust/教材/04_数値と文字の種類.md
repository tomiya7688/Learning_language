# 04. 数値と文字の種類

金額と名前を一つの変数へ同じように保存すると、計算できるものとできないものが分からなくなります。Rustの型を見てみましょう。

**この章でできること：** 整数、小数、真偽値、1文字、文字列を表示する。

## コードを見る

[配布した `lesson04_types.rs` の全体](../examples/lesson04_types.rs#L1-L14)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 値の種類を型で表す
    let apples: i32 = 3;
    let price: f64 = 120.5;
    let sold_out: bool = false;
    let grade: char = 'A';
    let item: &str = "りんご";

    println!("りんご: {}個", apples);
    println!("値段: {}円", price);
    println!("売り切れ: {}", sold_out);
    println!("評価: {}", grade);
    println!("商品: {}", item);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson04_types
```



ターミナルで確認する表示：

```text
りんご: 3個
値段: 120.5円
売り切れ: false
評価: A
商品: りんご
```

## コードの読み方

型は、値がどんな種類かを示します。`i32` はマイナスも扱える整数、`f64` は小数、`bool` は `true`（はい）か `false`（いいえ）、`char` は1文字、`&str` は文字列を参照する型です。`let 名前: 型 = 値;` と書くと型を指定できます。

## 変更して試す

VS Codeで `examples/lesson04_types.rs` に対応する `lesson04_types.rs` を開き、次の部分を変更してみましょう。

`apples` を `5` に変更して保存・再実行してください。表示される個数が `5` になります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
