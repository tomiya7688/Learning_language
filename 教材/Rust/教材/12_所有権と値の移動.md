# 12. 所有権と値の移動

Rustでは、文字列を別の変数へ代入したあと、元の変数を使えない場合があります。なぜでしょうか。

**この章でできること：** Stringの所有権が移動する例と、複製する例を確認する。

## コードを見る

[配布した `lesson12_ownership.rs` の全体](../examples/lesson12_ownership.rs#L1-L10)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // Stringの所有権をfirstからsecondへ移す
    let first = String::from("Rust");
    let second = first;
    println!("移動後: {}", second);

    // cloneは文字列の中身を複製する
    let copied = second.clone();
    println!("複製: {}", copied);
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson12_ownership
```


所有権の例では、まず配布版が正常に動くことを確認してください。
ターミナルで確認する表示：

```text
移動後: Rust
複製: Rust
```

## コードの読み方

所有権（ownership）は値を管理する責任のことです。`let second = first;` では `String` の所有権が `second` へ移ります。この後 `first` を使おうとするとコンパイル時にエラーになります。`clone()` は中身を新しく複製するので、元の値と複製した値をそれぞれ使えます。整数のような `Copy` 型は代入時にコピーされる点が異なります。

## 変更して試す

VS Codeで `examples/lesson12_ownership.rs` に対応する `lesson12_ownership.rs` を開き、次の部分を変更してみましょう。

`println!("移動後: {}", second);` の下へ `println!("元: {}", first);` を追記して保存し、`cargo check --example lesson12_ownership` を実行してください。実行前の検査で、移動後の `first` を使えないというエラーを確認できます。確認後は追記した行を削除してください。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
