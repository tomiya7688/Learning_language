# 05. キーボードから入力する

最初から決められた名前だけでなく、実行した人が入力した名前で挨拶してみましょう。

**この章でできること：** キーボードから受け取った名前を表示する。

## コードを見る

[配布した `lesson05_input.rs` の全体](../examples/lesson05_input.rs#L1-L15)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
use std::io;

fn main() {
    // 受け取った文字を保存する場所を用意する
    let mut name = String::new();
    println!("名前を入力してください：");

    // Enterまでに入力された文字を受け取る
    io::stdin()
        .read_line(&mut name)
        .expect("入力を読み取れませんでした");

    // 入力末尾の改行を除いて挨拶する
    println!("こんにちは、{}さん！", name.trim());
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson05_input
```

入力待ちになったら名前を書いて Enter を押してください。

ターミナルで確認する表示例：

```text
名前を入力してください：
（例：あおい と入力し Enter）
こんにちは、あおいさん！
```

## コードの読み方

`use std::io;` は標準ライブラリ（Rustに標準で入っている機能）から入出力を使う準備です。`String::new()` で入力用の空の文字列を作ります。`read_line(&mut name)` はEnterまでの入力を `name` へ書き込みます。`trim()` で末尾の改行を取り除き、`println!` で表示します。`expect` は読み取り失敗時に原因を表示して終了します。

## 変更して試す

VS Codeで `examples/lesson05_input.rs` に対応する `lesson05_input.rs` を開き、次の部分を変更してみましょう。

挨拶の `こんにちは` を `ようこそ` に変えて保存・再実行し、名前を入力してください。入力した名前の前が `ようこそ` に変わります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
