# 14. 構造体とメソッド

生徒ごとの名前と点数を別々の変数に分けると、人数が増えたときに取り違えやすくなります。一人分をまとめましょう。

**この章でできること：** 構造体に名前と点数をまとめ、合格判定を呼び出す。

## コードを見る

[配布した `lesson14_structs.rs` の全体](../examples/lesson14_structs.rs#L1-L22)を、VS Codeで開いてください。次のコードは配布ファイルと同じ内容です。

```rust
// 生徒1人分の情報をまとめる
struct Student {
    name: String,
    score: u32,
}

// Studentから使える判定処理を定義する
impl Student {
    fn passed(&self) -> bool {
        self.score >= 60
    }
}

fn main() {
    // あおいさんのデータを作る
    let student = Student {
        name: String::from("あおい"),
        score: 75,
    };

    println!("{}の合格判定: {}", student.name, student.passed());
}
```


## 実行する

[初めに](../初めに.md)の手順でVS Codeから `教材/Rust` フォルダを開き、**表示 → ターミナル** で次のコマンドを入力して Enter キーを押してください。

```text
cargo run --example lesson14_structs
```

ターミナルへ表示される内容：

```text
あおいの合格判定: true
```


## コードの読み方

`struct Student` は、生徒に必要な情報をまとめる構造体（struct）の定義です。`name` は名前、`score` は点数です。`impl Student` の中にある `passed` は、`Student` の値に対して呼び出せるメソッド（その値に関係する処理）です。`&self` は生徒のデータを変更せず参照します。

## 変更して試す

VS Codeで `lesson14_structs.rs` を開き、次の部分を変更してみましょう。

`score: 75` を `score: 50` に変更し、再実行してください。合格判定は `false` になります。

試した後に元のコードへ戻すと、ほかのページの説明と同じ動作で学習を続けられます。
