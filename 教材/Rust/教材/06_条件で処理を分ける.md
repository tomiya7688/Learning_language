# 06. 条件で処理を分ける

同じ点数でも、合格と不合格では表示する言葉を変えたいことがあります。点数の条件を比べてみましょう。

**この章でできること：** 60点以上かどうかで表示を切り替える。

## コードを見る

[配布した `lesson06_if.rs` の全体](../examples/lesson06_if.rs#L1-L10)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // 60点以上を合格とする
    let score = 75;

    if score >= 60 {
        println!("合格");
    } else {
        println!("不合格");
    }
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson06_if
```



ターミナルで確認する表示：

```text
合格
```

## コードの読み方

`if score >= 60` は、`score` が60以上のときだけ最初の `{}` 内を実行します。`else` は条件が成り立たないときに実行します。Rustの `if` の条件には `true` / `false` になる式を書き、丸括弧は不要です。

## 変更して試す

VS Codeで `examples/lesson06_if.rs` に対応する `lesson06_if.rs` を開き、次の部分を変更してみましょう。

`let score = 75;` を `55` に変え、再実行してください。今度は `不合格` と表示されます。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
