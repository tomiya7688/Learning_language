# 02. 最初のプログラム

Rustを入れたら、最初に「コードを動かせた」と分かる文字を表示してみましょう。

**この章でできること：** ターミナルへ「こんにちは、Rust！」と表示する。

## コードを見る

[配布した `lesson02_hello.rs` の全体](../examples/lesson02_hello.rs#L1-L4)を、VS Codeで開いてください。ソースコードはプログラムの元になる文章です。次のコードは配布ファイルと同じ内容です。

```rust
fn main() {
    // ターミナルに文字を表示する
    println!("こんにちは、Rust！");
}
```

## 実行する

[初めに](../初めに.md)で説明したとおり、VS Codeで `教材/Rust` を開き、**ターミナル**（コマンドを入力する画面）へ次の一行を入力して Enter を押してください。

```text
cargo run --example lesson02_hello
```



ターミナルで確認する表示：

```text
こんにちは、Rust！
```

## コードの読み方

`fn main()` は実行を始める関数（処理のまとまり）です。`println!` は文字を表示して改行するマクロです。マクロは `!` が付く特別な呼び出しです。`"..."` は表示したい文字列、`;` は文の終わりを示します。

## 変更して試す

VS Codeで `examples/lesson02_hello.rs` に対応する `lesson02_hello.rs` を開き、次の部分を変更してみましょう。

`println!` の引用符内を `Rustを始めました！` に変更して保存し、再実行してください。ターミナルの表示も同じ文字へ変わります。

同じ実行コマンドで変化を確かめ、次の章へ進む前に配布版へ戻すと、以後の説明と一致します。
