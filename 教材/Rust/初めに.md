# Rust：初めに

Rustを初めて使う人のための、日本語の学習教材です。最初に文字を表示し、入力や計算を試してから、Rust特有の所有権・借用まで進みます。

**まずは [00. Rustとは？](./教材/00_Rustとは.md) を開いてください。** 道具の導入から始めたい場合は [01. Rustの準備](./教材/01_Rustの準備.md) を開いてください。

## サンプルを実行する

[01. Rustの準備](./教材/01_Rustの準備.md)の手順でRustを用意し、教材一式をPCへ保存します。VS Codeでこの `Rust` フォルダを開き、**表示 → ターミナル** から次のコマンドを入力して Enter を押してください。

```text
cargo run --example lesson02_hello
```

`Cargo.toml` はRustのプロジェクトの設定です。`examples` フォルダには章ごとの実行可能なサンプルがあります。各ページに記載された `cargo run --example ...` を使って、ほかの章も単独で実行できます。
