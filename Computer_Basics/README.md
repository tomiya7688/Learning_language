# コンピュータ基本用語・OS操作

このディレクトリでは、プログラミング言語そのものとは別に、
**コンピュータを操作するうえで必要になる基本用語と OS の操作**をまとめます。

プログラミングを始めると、言語の文法より先に、

- ファイルやフォルダはどこにあるのか
- ターミナルとは何か
- PATH とは何か
- 管理者権限とは何か
- プロセスとは何か
- ネットワーク設定はどこを見るのか

といった、OS やコンピュータ側の知識が必要になることがあります。

これらは Python、C、Java、Rust など、どの言語でも共通して役立つため、
言語別教材から独立した共通教材として扱います。

## 目標

最終的には、Windows / macOS / Linux の基本操作について、
プログラミング学習で困らない程度まで一通り確認できる内容を目指します。

特定の OS だけに存在する機能は、その OS 専用の説明として区別します。

## この教材で重視すること

用語の定義だけではなく、

- どこで使うのか
- なぜ必要なのか
- 実際にどのコマンドや画面で確認できるのか
- 初学者が何と何を混同しやすいのか
- 問題が起きたとき、何から確認するのか

まで説明します。

「PATH を通す」「カレントディレクトリへ移動する」のように、
経験者には当然でも、初学者には意味が分かりにくい表現を
できるだけそのまま放置しないことを方針とします。
