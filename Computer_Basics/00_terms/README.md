# 0. コンピュータと OS の基本用語

この章では、これから何度も登場する基本的な用語を確認します。

すべてを暗記する必要はありません。
分からなくなったときに戻って確認できれば十分です。

---

## コンピュータ

コンピュータは、命令に従って計算やデータ処理を行う機械です。

一般的な PC では、大きく分けると、

- CPU
- メモリ
- ストレージ
- 入出力装置
- OS
- アプリケーション

などが協力して動作しています。

---

## ハードウェア

実際に触れることができる機械部分を **ハードウェア** と呼びます。

例:

- CPU
- メモリ
- SSD
- HDD
- キーボード
- マウス
- ディスプレイ

---

## ソフトウェア

コンピュータ上で動作するプログラムやデータを **ソフトウェア** と呼びます。

例:

- Windows
- macOS
- Linux
- Web ブラウザ
- Visual Studio Code
- Python

---

## OS

OS は **Operating System（オペレーティングシステム）** の略です。

代表例:

- Windows
- macOS
- Linux

OS は、アプリケーションとハードウェアの間に入り、
ファイル、メモリ、画面、キーボード、ネットワークなどを管理します。

プログラムを書くときも、実際には OS の機能を利用しながら動いています。

---

## アプリケーション

OS の上で動く、利用者向けのソフトウェアを一般に **アプリケーション** と呼びます。

例:

- Chrome
- Firefox
- Visual Studio Code
- メモ帳
- ゲーム

---

## ファイル

データを保存する単位のひとつです。

例:

```text
hello.py
photo.png
memo.txt
```

ファイル名の末尾にある `.py`、`.png`、`.txt` などは **拡張子** と呼ばれます。

---

## フォルダ / ディレクトリ

ファイルや別のフォルダをまとめるための入れ物です。

Windows の画面では **フォルダ** という言葉がよく使われ、
ターミナルや技術資料では **ディレクトリ** という言葉がよく使われます。

初学者の段階では、

> フォルダとディレクトリは、ほぼ同じものを指している

と考えて構いません。

---

## パス

ファイルやフォルダがどこにあるのかを表す文字列です。

Windows の例:

```text
C:\Users\sample\Documents\hello.py
```

Linux / macOS の例:

```text
/home/sample/hello.py
```

---

## コマンド

コンピュータへ操作を指示するために入力する命令です。

例:

```text
cd
dir
ls
python
```

同じ操作でも OS や使用するシェルによってコマンドが異なることがあります。

---

## ターミナル

文字を入力してコンピュータを操作するための画面やアプリケーションです。

例:

- Windows Terminal
- PowerShell
- コマンドプロンプト
- macOS の Terminal
- Linux の各種ターミナル

---

## シェル

ターミナルで入力されたコマンドを解釈し、
OS に処理を依頼するソフトウェアです。

例:

- PowerShell
- bash
- zsh

**ターミナル** と **シェル** は同じ意味で使われることもありますが、
厳密には別のものです。

大まかには、

> ターミナル = 入出力するための画面
>
> シェル = その中でコマンドを解釈する仕組み

と考えると分かりやすいです。

---

## プロセス

実行中のプログラムを OS が管理するときの単位です。

同じアプリケーションを複数起動すると、
複数のプロセスとして動くことがあります。

Windows のタスクマネージャーや、
Linux の `ps` などで確認できます。

---

## メモリ

実行中のプログラムが一時的にデータを置く場所です。

一般に PC の「RAM」と呼ばれるものがこれにあたります。

電源を切ると、通常は内容が失われます。

---

## ストレージ

ファイルを長期間保存するための装置です。

例:

- SSD
- HDD
- USB メモリ

メモリとは役割が異なります。

---

## CPU

プログラムの命令を実行する中心的な装置です。

計算、比較、データ移動など、多くの処理を担当します。

---

## ここではまだ覚えなくてよいもの

この先、

- 環境変数
- PATH
- IP アドレス
- DNS
- ポート
- 権限
- ファイルシステム
- マウント

なども登場します。

これらはそれぞれの章で詳しく扱うため、
この段階で覚える必要はありません。
