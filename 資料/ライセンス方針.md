# Learning_language ライセンス運用方針

この資料は、Learning_language の公式リポジトリへ教材・コード・画像などを追加するときの**制作・保守ルール**をまとめたものです。

利用者に対する正式なライセンス条件は、リポジトリ直下の [LICENSE](../LICENSE) にある MIT License を正本とします。

この資料は MIT License 本文を変更したり、追加の利用制限を設けたりするものではありません。

## 基本方針

Learning_language 本体は MIT License で公開します。

このリポジトリのために新しく作成する次のものは、原則としてリポジトリ本体と同じ MIT License で公開できるものにします。

- Markdown教材
- サンプルコード
- 図・画像
- pygame等で使用する教材用素材
- リポジトリ制作のための補助資料

自作物を追加するときは、別ライセンスへする特別な理由がない限り、個別に独自条件を追加しません。

## 公式リポジトリへ同梱してよい素材

公式リポジトリへファイルそのものを追加する場合は、**再配布条件まで確認できる素材だけ**を使用します。

追加してよい例:

- Learning_language 用に自作した素材
- MIT Licenseなど、再配布条件が明確で条件を満たせる第三者素材
- 作者・配布元・ライセンス・必要なnoticeを確認できる素材

「利用できる」と「このGitHubリポジトリへ再配布できる」は別です。

個人利用や作品内利用が許可されていても、素材ファイルそのものの再配布が禁止されている場合は、公式リポジトリへ同梱しません。

## 同梱しない素材

次のような素材は、公式リポジトリへファイルとして追加しません。

- ライセンスが確認できない素材
- 「フリー素材」とだけ書かれ、具体的な利用条件が確認できない素材
- 再配布禁止の素材
- 配布元の利用規約と、リポジトリでの公開方法が両立しない素材
- 作者や出所を確認できない素材
- 必要なCopyright noticeやLicense noticeを保持できない素材

判断できない場合は「使えるだろう」と推測して追加せず、条件を確認できる素材へ置き換えます。

## 第三者のMIT素材を使う場合

MIT License の素材であっても、無表記でコピーしてよいわけではありません。

第三者のMIT素材を公式リポジトリへ同梱する場合は、元の条件に従って少なくとも次を保持します。

- 作者または権利者
- 配布元
- 元のCopyright notice
- MIT License notice
- 必要に応じて元ファイル名や変更の有無

このリポジトリ本体もMITだからという理由で、第三者のCopyright noticeを削除しません。

## 外部サイトから利用者自身に取得してもらう場合

教材本文から外部サイトを案内し、利用者自身に素材を取得してもらう方式は、**素材を公式リポジトリへ同梱することとは分けて扱います**。

この方式を使う場合でも、教材では少なくとも次を確認します。

- 正式な配布元へ案内しているか
- 教材で想定する利用方法が配布元の条件に合っているか
- 再配布禁止の素材を、このリポジトリへコピーしていないか

外部サイト上の素材を案内するだけの場合、その素材のライセンスをLearning_languageのMIT Licenseへ変更したことにはなりません。

## assets README に記録すること

教材フォルダへ素材を同梱する場合は、対応する `assets/README.md` から出所を追えるようにします。

最低限、素材ごとに次を記載します。

| 項目 | 内容 |
| --- | --- |
| ファイル名 | リポジトリ内のファイル名 |
| 内容 | 何に使う素材か |
| 作成元・引き継ぎ元 | 自作した章、またはどこから引き継いだか |
| ライセンス | MIT等の適用ライセンス |

第三者素材の場合は、これに加えて次も記録します。

- 作者
- 配布元
- 元ライセンス
- 必要なCopyright / License notice
- 必要に応じて変更の有無

同じ画像を後続章へコピーする場合も、「この章で新規作成」とは書かず、元の作成章と引き継ぎ元が追える形にします。

## 教材本文とライセンス情報の分担

読者向け教材本文には、その章を理解するために必要な素材情報だけを書きます。

たとえば、

> この画像は、この教材用に作成したオリジナル素材です。

のような短い説明は教材本文に置けます。

一方、次のような制作・管理情報は `assets/README.md` やこの資料へ分離します。

- 採用しなかった素材の話
- 素材選定時の内部事情
- 第三者noticeの詳細
- リポジトリ全体で共通するライセンス判断基準

教材ごとに同じライセンス運用ルールを長く繰り返さないようにします。

## LICENSE 本文の扱い

リポジトリ直下の `LICENSE` は、正式なMIT License本文として扱います。

教材独自の事情を理由に、MIT License本文へ次のような独自制限を追加しません。

- 商用利用禁止
- 改変禁止
- 再配布禁止
- 教材用途限定
- AI利用禁止など、MIT本文にない追加条件

制作上のルールと、利用者に適用されるライセンス条件は分離します。

## 新しい素材を追加するときの確認

新しい素材を公式リポジトリへ入れる前に、次を確認します。

1. 自作か第三者作成か
2. 第三者素材なら作者・正式な配布元が分かるか
3. ライセンス全文または利用条件を確認できるか
4. GitHub上で素材ファイル自体を再配布できるか
5. Copyright / License noticeの保持条件を満たせるか
6. 対応する `assets/README.md` に出所とライセンスを書いたか
7. ライセンスが不明な場合に推測で追加していないか

この確認を通せない素材は、公式リポジトリへ同梱しません。
