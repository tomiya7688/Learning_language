# 変更したPythonコードの整形

リポジトリのルートで実行してください。開発用のRuffは `requirements-dev.txt` に0.15.22を固定しています。

初回の準備：

```powershell
python -m pip install -r requirements-dev.txt
```

今回の8章のコードを整形するコマンド：

```powershell
python tools/format.py
```

書き換えずに確認するコマンド：

```powershell
python tools/format.py --check
```

別のPythonファイルを変更する作業では、コマンド末尾にパスを並べて対象を指定できます。対象は現在のチェックアウト内の `.py` に限定しています。

教材Markdownの原文と、本文の抜粋・行番号に対応する既存サンプルを、一括では整形しません。用語だけを変更する作業も、原文の改行を保ちます。8章のコードは今回の修正対象としてRuffを実行し、整形した後に本文の抜粋と行番号を同期します。
